# isHexadecimal

## تشریح

`isHexadecimal` ګوري چې ورکړل شوی قدر یو هیکساډېسمل سټرینګ لېټرل دی که نه، چې لازمي `0x`/`0X` مخکښ توری ولري.

### د کارولو بېلګه

د `isHexadecimal` څخه د کانفیګورېشن ارزښتونو، API payload فیلډونو، یا CLI آرګومېنټونو د تصدیق لپاره کار واخلئ چې باید د
هیکساډېسمل سټرینګ لېټرلونو په توګه ورکړل شي (لکه IDs، masks، یا addresses) او باید شاوخوا سپین‌ځای ونه لري.

> **د TypeScript کاروونکو لپاره یادونه:**
>
> کله چې اړتیا لرئ د کاروونکي داخلې یا سریالایز شوې ډاټا د سخت هیکساډېسمل لېټرل سټرینګ په توګه (د `0x`/`0X` مخکښ توري په
> ګډون) د پارس یا کنورټ کولو نه مخکې تصدیق کړئ، `isHexadecimal` وکاروئ.

### ګټې

- دا تصدیق کوی چی یو قدر سټرینګ دے او د سخت هیکساډېسمل لېټرل فارمیټ سره سمون خوري (د `0x`/`0X` مخکښ توری لازمي دی).
- هغه سټرینګونه ردوي چې په سر یا پای کې سپېس/سپین‌ځای ولري، چې د پډ شوې داخلې د ناڅاپي منلو مخه نیسي.
- اختیاري نښه (sign) ملاتړ کوي او د مخکښ توري او عددونو په برخه کې د لوی/وړو تورو پروا نه کوي، او په باوري ډول `true`/
  `false` بېرته ورکوي.

## کارونه

### سینټکس

فنکشن:

- `isHexadecimal(value)`

پارامېټرونه:

- `value`: هغه قدر چې باید وکتل شي.

### د فنکشن محلي امپورټ

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); //‎ رښتیا
isHexadecimal("-0Xff"); //‎ رښتیا
isHexadecimal("1A2B"); //‎ ناسم (مخکښ نښه نشته)
isHexadecimal(" 0x1A2B"); //‎ ناسم (په پیل کې سپین‌تش)
isHexadecimal(0x1a2b); //‎ ناسم (شته‌لیک نه دی)
```

### د شی ګلوبل امپورټ

د فنکشنونو د شی د ګلوبل مېتودونو په توګه د امپورټ لپاره دا وکاروئ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

بيا لاندې مېتود به په ګلوبل ډول موجود وي:

- `Type.isHexadecimal(value)`
