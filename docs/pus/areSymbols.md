# areSymbols

## تشریح

ګوري چې داخلېدنه يو ډک اراې ده چې عناصر يې ټول سمبولونه دي، او `true` يا `false` واپس کوي.

### د کارولو بېلګه

تائيد کړئ چې د تنظيماتو يو ډګر (لکه د ځانګړو کليدونو لېست چې د سمبولونو په توګه استازيتوب کېږي) يو غير تش اراې دی چې
يواځې سمبولونه لري، مخکې له دې چې په هغو API ګانو کې يې وکاروئ چې `symbol[]` ته اړتيا لري.

> **د TypeScript کاروونکو لپاره یادونه:**
>
> `areSymbols` وکاروئ څو ناڅرګنده داخلېدنه د `symbol[]` په توګه له چلند کولو مخکې تائيد کړئ؛ دا د غير-اراې او تشو
> اراېګانو لپاره `false` واپس کوي.

### ګټې

- `true` يواځې هغه وخت واپس کوي چې داخلېدنه يو غير تش اراې وي او هر عنصر يې يو سمبول وي.
- د ناسم مثبتو پايلو مخه نيسي، ځکه غير-اراې او تش اراې د دننني د ډک-اراې د کتنې له لارې ردوي.
- د رنټايم ډول-ساتونکي (type guard) په توګه ګټور دی، څو د نورو پروسس کولو نه مخکې يواځې-سمبول لېستونه تائيد کړي.

## کارونه

### سینټکس

فنکشن:

- `areSymbols(array)`

پارامېټرونه:

- `array`: هغه اراې چې د سمبول عناصرو لپاره به وکتل شي.

### د فنکشن محلي امپورټ

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  //‎‎ a په اجرايي وخت کې یوازې-سمبول ارایه ده
  const first = a[0];
  console.log(typeof first); //‎ "symbol"
}

console.log(areSymbols(b)); //‎ false
```

### د شی ګلوبل امپورټ

د فنکشنونو د شی د ګلوبل مېتودونو په توګه د امپورټ لپاره دا وکاروئ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

بيا لاندې مېتود به په ګلوبل ډول موجود وي:

- `Type.areSymbols(array)`
