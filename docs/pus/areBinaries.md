# areBinaries

## تشریح

ګوري چې ورکړل شوی ارزښت د معتبر باینري سټرینګونو یو نا تش اری دی که نه، او یوازې هغه وخت `true` بېرته ورکوي چې ټول توکي
تصدیق تېر کړي.

### د کارولو بېلګه

`areBinaries` هغه وخت وکاروئ چې تاسو یو نامعلوم لېست (لکه له JSON، فورمونو، یا APIs څخه) ترلاسه کوئ او اړتیا لرئ چې د
پارس یا پروسس کولو مخکې ډاډ ترلاسه کړئ چې دا د باینري سټرینګونو یو نا تش اری دی.

> **د TypeScript کاروونکو لپاره یادونه:**
>
> `areBinaries` د نامعلوم اِنپټ د تصدیق لپاره وکاروئ مخکې له دې چې باینري سټرینګونه عددونو/BigInts ته واړوئ؛ دا ډاډ
> ورکوي چې اری نا تش دی او هر عنصر یو معتبر باینري سټرینګ دی.

### ګټې

- دا تصدیق کوی چې یو ارزښت یو نا تش اری (array) دی چې پکې هر عنصر یو معتبر باینري سټرینګ وي.
- یو ساده بولین پایله (`true`/`false`) بېرته ورکوي چې د ګارډونو، ژر بېرته ستنېدو (early returns)، او د اِنپټ تصدیق لپاره
  مناسبه ده.
- د هغو اریو په ردولو سره چې پکې هر ډول غیر-باینري ننوتنه وي، د وروسته پړاو پارس کولو تېروتنې مخنیوی کوي.

## کارونه

### سینټکس

فنکشن:

- `areBinaries(array)`

پارامېټرونه:

- `array`: هغه ارزښت چې باید وکتل شي.

### د فنکشن محلي امپورټ

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); //‎ رښتیا
console.log(areBinaries(b)); //‎ ناسم
console.log(areBinaries([])); //‎ ناسم
```

### د شی ګلوبل امپورټ

د فنکشنونو د شی د ګلوبل مېتودونو په توګه د امپورټ لپاره دا وکاروئ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

بيا لاندې مېتود به په ګلوبل ډول موجود وي:

- `Type.areBinaries(array)`
