# isEmpty

## تشریح

Муайян мекунад, ки оё қимати додашуда холӣ аст ё не, ва барои `null`, `undefined`, сатрҳои холӣ/бо фосила, массивҳои
холӣ, `Map`/`Set`-и холӣ, ё объектҳое, ки ягон хосияти шуморишавандаи худӣ надоранд, `true` бармегардонад.

### د کارولو بېلګه

`isEmpty`-ро барои валидацияи воридот ва ошкор кардани қиматҳои набуда/холӣ дар чандин навъи додаҳо истифода баред (
масалан, майдонҳои форма, payload-ҳои API, объектҳои конфигуратсия), ки дар онҳо `null`, `undefined`, сатрҳои бо фосила,
коллексияҳои холӣ ва объектҳои бе хосият бояд ҳамчун холӣ ҳисобида шаванд.

> **د TypeScript کاروونکو لپاره یادونه:**
>
> `isEmpty` як утилитаи баргардонандаи булеан аст (на предикати навъи TypeScript), бинобар ин худ аз худ навъҳоро танг (
> narrow) намекунад; онро барои валидация/шохабандӣ истифода баред, на барои тангкунии вақти компилятсия.

### ګټې

- Барои санҷишҳои холигӣ `null` ва `undefined`-ро ҳамчун `true` ҳисоб мекунад.
- Сатрҳои танҳо аз фосила иборатро бо буридан (trim) пеш аз санҷидани дарозӣ холӣ мешуморад.
- Навъҳои маъмули контейнерҳоро (массивҳо, `Map`, `Set`) ва объектҳои оддиро, ки ягон хосияти шуморишавандаи (
  enumerable) худӣ надоранд, дастгирӣ мекунад.
- Бо истифода аз санҷишҳои `hasOwnProperty` аз ҳисоб кардани хосиятҳои меросӣ худдорӣ мекунад.
- Натиҷаи оддии булеанӣ (`true`/`false`) бармегардонад, ки барои guard-ҳо ва валидация мувофиқ аст.

## کارونه

### سینټکس

فنکشن:

- `isEmpty(value)`

پارامېټرونه:

- `value`: Қимате, ки барои холӣ будан санҷида мешавад.

### د فنکشن محلي امپورټ

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### د شی ګلوبل امپورټ

د فنکشنونو د شی د ګلوبل مېتودونو په توګه د امپورټ لپاره دا وکاروئ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

بيا لاندې مېتود به په ګلوبل ډول موجود وي:

- `Type.isEmpty(value)`
