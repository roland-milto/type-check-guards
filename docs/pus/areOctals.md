# areOctals

## تشریح

`areOctals` ټاکي چې ورکړل شوی ارزښت د معتبر اوکتل سټرینګونو یو غیر تش ارې (array) دی که نه.

### د کارولو بېلګه

`areOctals` هغه وخت وکاروئ چې د کاروونکي انپټ، د کانفیګورېشن ارزښتونه، یا د API پېلوډونه تصدیقوئ چې باید اوکتل لېټرلونه
ولري (لکه د فایل د اجازې مودونه `0o755`) او تاسو غواړئ تش ارې یا هر ډول ناسمې ننوتنې د `false` په بېرته ورکولو سره رد
کړئ.

> **د TypeScript کاروونکو لپاره یادونه:**
>
> `areOctals` وکاروئ څو ډاډ ترلاسه کړئ چې تاسو یو غیر تش `unknown[]` لرئ چې هره ننوتنه یې یو معتبر اوکتل سټرینګ وي، مخکې
> له دې چې یې بدل کړئ (لکه د `Number(...)` له لارې یا د خپل پارس کولو په وسیله).

### ګټې

- تصدیق کوي چې یو ارزښت یو غیر تش ارې (array) دی چې هر عنصر یې یو اوکتل (octal) سټرینګ وي، او یوازې هغه وخت `true` بېرته
  ورکوي چې ټول توکي بریالي شي.
- ژر ناکامېږي: کله چې یو غیر اوکتل عنصر وموندل شي، سمدستي `false` بېرته ورکوي.
- د پارس کولو یا د اوکتل سټرینګونو د بدلون (convert) څخه مخکې د ګارډ په توګه ګټور دی، څو د رن‌ټایم تېروتنو او د
  ناسم/ناهمغږي انپټ د چلند مخه ونیسي.

## کارونه

### سینټکس

فنکشن:

- `areOctals(array)`

پارامېټرونه:

- `array`: هغه ارزښت چې باید وکتل شي.

### د فنکشن محلي امپورټ

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  //‎‎ value د اکتال سټرینګونو یو تش نه‌خالي اراې ده
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### د شی ګلوبل امپورټ

د فنکشنونو د شی د ګلوبل مېتودونو په توګه د امپورټ لپاره دا وکاروئ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

بيا لاندې مېتود به په ګلوبل ډول موجود وي:

- `Type.areOctals(array)`
