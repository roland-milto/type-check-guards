# isDecimal

## تشریح

`isDecimal` ګوري چې آیا یو ارزښت د اعشاري سټرینګ استازیتوب دی، بې له مخکیني/وروستي سپین‌ځای څخه او د سم اعشاري بڼې سره.

### د کارولو بېلګه

د فورم فیلډونه، API payloads، یا د تنظیماتو ارزښتونه اعتبارسنج کړئ چې باید د اعشاري سټرینګ (اختیاري نښه لرونکی) په توګه،
بې له هر ډول شاوخوا سپین‌ځای څخه، وړاندې شي—مخکې له دې چې یې پارس یا ذخیره کړئ.

> **د TypeScript کاروونکو لپاره یادونه:**
>
> `isDecimal` د کاروونکي داخلې د اعتبارسنجۍ لپاره وکاروئ مخکې له دې چې یې واړوئ (لکه د `Number(value)` په وسیله)، په
> ځانګړي ډول کله چې سپین‌ځای باید رد شي.

### ګټې

- په کلکه تصدیق کوي چې داخل شوی ارزښت یو سټرینګ دی او د اعشاري-لیټرل بڼې سره سمون خوري.
- مخکینی او وروستی سپین‌ځای (whitespace) ردوي (د کنټرول کرکټرونو په ګډون) څو له مبهم پارس کولو څخه مخنیوی وشي.
- د regex چلولو نه مخکې چټک مخکیني چکونه (د ډول چک او د لومړي/وروستي کرکټر چک) ترسره کوي.
- یو ساده بولین پایله (`true`/`false`) بېرته ورکوي چې د ګارډونو او د داخلې د اعتبارسنجۍ لپاره مناسبه ده.

## کارونه

### سینټکس

فنکشن:

- `isDecimal(value)`

پارامېټرونه:

- `value`: هغه ارزښت چې د اعشاري سټرینګ د بڼې لپاره یې باید وکتل شي.

### د فنکشن محلي امپورټ

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    //‎‎ v دلته یو سټرینګ دی (په رن‌ټایم کې تایید شوی)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### د شی ګلوبل امپورټ

د فنکشنونو د شی د ګلوبل مېتودونو په توګه د امپورټ لپاره دا وکاروئ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

بيا لاندې مېتود به په ګلوبل ډول موجود وي:

- `Type.isDecimal(value)`
