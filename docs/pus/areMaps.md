# areMaps

## تشریح

`areMaps` ایہ طے کردی اے کہ دِتّی گئی ارے خالی نئیں تے اوہدے سارے عناصر `Map` انسٹنس نیں۔

### د کارولو بېلګه

نامعلوم اِن پُٹ (مثلاً JSON parsing، بیرونی APIs، یا ڈائنامک سورسز توں) نوں ویلیڈیٹ کرو، اس توں پہلاں کہ اوہنوں `Map`
آبجیکٹس دی اک غیر خالی لسٹ سمجھیا جاوے۔

> **د TypeScript کاروونکو لپاره یادونه:**
>
> خالی ارے لئی `false` واپس کردی اے؛ ایہ صرف اوہدوں `true` واپس کردی اے جدوں ارے بھری ہوئی ہووے تے ہر عنصر اک `Map`
> ہووے۔

### ګټې

- یقینی بناندی اے جو ہر عنصر اک `Map` انسٹنس اے، تے صرف اوہدوں `true` واپس کردی اے جدوں پوری ارے چیک پاس کرے۔
- ڈیزائن دے مطابق خالی ارے نوں رد کردی اے، جس نال “کوئی ڈیٹا نئیں” نوں غلطی نال درست اِن پُٹ سمجھ لین توں بچاؤ ہوندا اے۔
- `Map`-خاص آپریشنز (مثلاً `.get()`, `.set()`, iteration) نوں اک کلیکشن اُتے چلاؤن توں پہلاں گارڈ دے طور تے فائدہ مند
  اے۔

## کارونه

### سینټکس

فنکشن:

- `areMaps(array)`

پارامېټرونه:

- `array`: چیک کرن لئی ارے۔

### د فنکشن محلي امپورټ

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  //‎‎ items په اجرايي وخت کې تضمین کېږي چې د Map بېلګو یو غیر تش ارایه وي
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  //‎‎ ناسم (false) د دې لپاره: تش ارایه‌ګانې، یا ارایه‌ګانې چې هر ډول غیر-Map ارزښت ولري
}

```

### د شی ګلوبل امپورټ

د فنکشنونو د شی د ګلوبل مېتودونو په توګه د امپورټ لپاره دا وکاروئ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

بيا لاندې مېتود به په ګلوبل ډول موجود وي:

- `Type.areMaps(array)`
