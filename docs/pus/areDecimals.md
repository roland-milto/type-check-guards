# areDecimals

## تشریح

ګوري چې ایا په اری کې ټول عناصر اعشاري شمېرې دي او اری ډک دی، او `true` یا `false` بېرته ورکوي.

### د کارولو بېلګه

د کاروونکي له خوا ورکړل شوي لېستونه (لکه د CSV ستنې یا د فورم انپټونه) اعتبار سنجوي، څو ډاډ ترلاسه شي چې اری تش نه دی او
هره ننوتنه اعشاري ارزښت دی، مخکې له دې چې پارس یا محاسبې ترسره شي.

> **د TypeScript کاروونکو لپاره یادونه:**
>
> کله چې تاسې ته د `unknown[]` لپاره یو چټک بولین چک پکار وي چې هم تش نه وي او هم هر عنصر یې د اعشاري بڼې استازیتوب کوي،
`areDecimals` وکاروئ.

### ګټې

- یقینی کوي چې انپټ د توکو د اعتبار سنجونې نه مخکې یو ډک اری وي، او د تشو لېستونو د ناڅاپي منلو مخه نیسي.
- هر عنصر د `isDecimal` په وسیله اعتبار سنجوي، نو ګډ یا ناسم ارزښتونه سمدستي `false` پایله ورکوي.
- یو ساده بولین پایله (`true`/`false`) برابروي چې د ګارډونو او د ژر-بېرته-ستنېدنې د اعتبار سنجونې بهیرونو لپاره مناسبه
  ده.

## کارونه

### سینټکس

فنکشن:

- `areDecimals(array)`

پارامېټرونه:

- `array`: هغه اری چې باید وکتل شي.

### د فنکشن محلي امپورټ

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); //‎ رښتیا
console.log(areDecimals(b)); //‎ ناسم
console.log(areDecimals(c)); //‎ ناسم
```

### د شی ګلوبل امپورټ

د فنکشنونو د شی د ګلوبل مېتودونو په توګه د امپورټ لپاره دا وکاروئ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

بيا لاندې مېتود به په ګلوبل ډول موجود وي:

- `Type.areDecimals(array)`
