# areNaNs

## تشریح

`areNaNs` जांचदा ऐ कि ऐरे दे सारे अनसर `NaN` नें अते `true` सिरिफ ओह्दो वक़्त वापस करदा ऐ जदों हर इक अनसर `NaN` होवे।

### د کارولو بېلګه

आउंदी डेटा दी तस्दीक करो जिथे `NaN` नूं सेंटिनल क़ीमत वजों इस्तेमाल कीता जांदा ऐ अते तुहानूं यक़ीनी बनाना होवे कि पूरा
ऐरे खास तौर ते सिरिफ `NaN` तोں ही बन्या होवे (मिसाल वजों, पूरी तरह ग़ायब अददी सिलसिले दी पहचान)।

> **د TypeScript کاروونکو لپاره یادونه:**
>
> `areNaNs` उस वक़्त इस्तेमाल करो जदों तुहानूं एह तस्दीक करनी होवे कि ऐरे विच सिरिफ अददी `NaN` क़ीमत ही मौजूद ऐ (
> स्ट्रिंग-टू-नंबर जबरन तब्दीली तोں बग़ैर)।

### ګټې

- `true` सिरिफ ओह्दो वक़्त वापस करदा ऐ जदों हर इक अनसर `NaN` होवे (सख़्त तमाम-अनसर जांच)।
- स्ट्रिंगां नूं नंबरां विच जबरन तब्दील नहीं करदा; "NaN" वरगियां क़ीमतां गैर-`NaN` रहंदियां नें अते नतीजा `false`
  बनांदियां नें।
- गैर-भरे होए ऐरेआं लई `false` वापस करदा ऐ, जिस नाल खाली इनपुट ते गलती नाल `true` होण तोں बचाव होंदा ऐ।

## کارونه

### سینټکس

فنکشن:

- `areNaNs(array)`

پارامېټرونه:

- `array`: `NaN` क़ीमतां लई जांचण वास्ते ऐरे।

### د فنکشن محلي امپورټ

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); //‎ رښتیا
const b = areNaNs([NaN, 1, NaN]); //‎ ناسم
const c = areNaNs([NaN, "NaN", NaN]); //‎ ناسم
const d = areNaNs([NaN, null, NaN]); //‎ ناسم
const e = areNaNs([] as unknown[]); //‎ ناسم
```

### د شی ګلوبل امپورټ

د فنکشنونو د شی د ګلوبل مېتودونو په توګه د امپورټ لپاره دا وکاروئ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

بيا لاندې مېتود به په ګلوبل ډول موجود وي:

- `Type.areNaNs(array)`
