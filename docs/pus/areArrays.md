# areArrays

## تشریح

`areArrays` معلوموي چې یو ارزښت یو ډک دوه-بعدي اراې ده که نه، چې توکي یې ټول اراې ګانې وي.

### د کارولو بېلګه

د `areArrays` څخه د جدولیزو یا مېټرېکس-ته ورته داخلونو (لکه د CSV قطارونه، د ګریډ ډاټا، یا ګروپ شوې لېستونه) د تصدیق
لپاره کار واخلئ مخکې له دې چې د قطار/ستون عملیات ترسره کړئ؛ که داخل اراې نه وي، تش وي، یا کوم غیر-اراې عنصر ولري،
`false` بېرته ورکوي.

> **د TypeScript کاروونکو لپاره یادونه:**
>
> کله چې اړتیا لرئ ډاډ ترلاسه کړئ چې یو ارزښت تش نه 2D اراې ده او هر قطار یې اراې دی، د nested اراې ګانو له تکرار یا
> اندېکس کولو مخکې `areArrays` وکاروئ.

### ګټې

- تصدیق کوي چې داخلېدونکی ارزښت یو تش نه دوه-بعدي اراې ده چې هر عنصر یې خپله یو اراې وي.
- یو ساده بولین پایله (`true`/`false`) بېرته ورکوي چې د ګارډونو او ژر وتلو لپاره مناسبه ده.
- د اجرا پر مهال تېروتنې مخه نیسي کله چې وروسته کوډ د اراې-په-اراې عملیات فرض کوي (لکه د قطارونو map کول).

## کارونه

### سینټکس

فنکشن:

- `areArrays(array)`

پارامېټرونه:

- `array`: هغه داخلېدونکی ارزښت چې باید وکتل شي.

### د فنکشن محلي امپورټ

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  //‎‎ value یو دوه‌بعدي ارايه ده چې عناصر يې ارايې دي
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### د شی ګلوبل امپورټ

د فنکشنونو د شی د ګلوبل مېتودونو په توګه د امپورټ لپاره دا وکاروئ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

بيا لاندې مېتود به په ګلوبل ډول موجود وي:

- `Type.areArrays(array)`
