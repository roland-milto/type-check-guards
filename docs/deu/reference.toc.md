# Funktionsreferenzen

## Funktionen

| Funktion                                    | Beschreibung                                                                                                                                                                                                            |
|---------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [areArrays](areArrays.md)                   | `areArrays` bestimmt, ob ein Wert ein gefülltes zweidimensionales Array ist, dessen Elemente allesamt Arrays sind.                                                                                                      |
| [areBigInts](areBigInts.md)                 | `areBigInts` bestimmt, ob ein Wert ein nicht-leeres Array ist, das ausschließlich `bigint`-Werte enthält.                                                                                                               |
| [areBinaries](areBinaries.md)               | Prüft, ob der bereitgestellte Wert ein nicht leeres Array aus gültigen Binärzeichenfolgen ist, und gibt nur dann `true` zurück, wenn alle Elemente die Validierung bestehen.                                            |
| [areBooleans](areBooleans.md)               | `areBooleans` prüft, ob ein gegebenes nicht leeres Array ausschließlich Boolean-Werte enthält, und gibt `true` zurück, wenn dies der Fall ist, andernfalls `false`.                                                     |
| [areBuffers](areBuffers.md)                 | `areBuffers` prüft, ob der bereitgestellte Wert ein nicht-leeres, vollständig gefülltes Array ist, in dem jedes Element ein `Buffer` ist, und gibt in diesem Fall `true` und andernfalls `false` zurück.                |
| [areDates](areDates.md)                     | `areDates` bestimmt, ob ein gegebenes Array gefüllt ist und ausschließlich `Date`-Objekte enthält, und gibt nur dann `true` zurück, wenn alle Elemente gültige Datumswerte sind.                                        |
| [areDecimals](areDecimals.md)               | Prüft, ob alle Elemente in einem Array Dezimalzahlen sind und das Array gefüllt ist, und gibt `true` oder `false` zurück.                                                                                               |
| [areEqual](areEqual.md)                     | `areEqual` prüft, ob alle Elemente in einem Array einem gegebenen erwarteten Wert entsprechen, und gibt nur für nicht leere Arrays `true` zurück, bei denen jedes Element übereinstimmt.                                |
| [areErrors](areErrors.md)                   | Prüft, ob ein Array nicht leer ist und ausschließlich `Error`-Objekte enthält, und gibt `true` oder `false` zurück.                                                                                                     |

| [areFinite](areFinite.md)                   | `areFinite` prüft, ob ein Wert ein nicht-leeres Array ist, dessen Elemente allesamt endliche Zahlen sind, und gibt in diesem Fall `true` zurück, andernfalls `false`.                                                   |

| [areHexadecimals](areHexadecimals.md)       | Prüft, ob alle Elemente in einem Array hexadezimale Zeichenketten sind, und gibt `true` nur für nicht-leere Arrays zurück, in denen jedes Element gültig ist.                                                           |
| [areIndexesFound](areIndexesFound.md)       | `areIndexesFound` prüft, ob ein Wert ein nicht-leeres Array ist, dessen Elemente allesamt gültige Indizes sind, und gibt in diesem Fall `true` zurück, andernfalls `false`.                                             |
| [areIntegers](areIntegers.md)               | `areIntegers` bestimmt, ob alle Elemente in einem gegebenen Array ganze Zahlen sind, und gibt `true` zurück, wenn dies der Fall ist, andernfalls `false`.                                                               |
| [areJson](areJson.md)                       | Prüft, ob alle Elemente eines Arrays JSON-Strings sind, und gibt nur dann `true` zurück, wenn das Array befüllt ist und jedes Element gültiges JSON ist; andernfalls wird `false` zurückgegeben.                        |
| [areMaps](areMaps.md)                       | `areMaps` bestimmt, ob ein gegebenes Array nicht leer ist und alle seine Elemente `Map`-Instanzen sind.                                                                                                                 |
| [areNaNs](areNaNs.md)                       | `areNaNs` prüft, ob alle Elemente in einem Array `NaN` sind, und gibt nur dann `true` zurück, wenn jedes Element `NaN` ist.                                                                                             |
| [areNullOrUndefined](areNullOrUndefined.md) | Prüft, ob alle Elemente im angegebenen Array `null` oder `undefined` sind.                                                                                                                                              |
| [areNumbers](areNumbers.md)                 | `areNumbers` prüft, ob ein Wert ein nicht-leeres Array ist, in dem alle Elemente Zahlen sind.                                                                                                                           |

| [areObjects](areObjects.md)                 | `areObjects` prüft, ob ein bereitgestelltes gefülltes Array ausschließlich Objekte enthält.                                                                                                                             |
| [areOctals](areOctals.md)                   | `areOctals` bestimmt, ob der bereitgestellte Wert ein nicht-leeres Array gültiger Oktalzeichenketten ist.                                                                                                               |
| [areOfType](areOfType.md)                   | Prüft, ob alle Elemente im angegebenen `array` vom angegebenen `type` sind.                                                                                                                                             |

| [areSets](areSets.md)                       | Prüft, ob ein gegebenes nicht-leeres Array ausschließlich `Set`-Instanzen enthält, und gibt in diesem Fall `true` zurück, andernfalls `false`.                                                                          |
| [areStreams](areStreams.md)                 | `areStreams` bestimmt, ob ein Wert ein gefülltes Array ist, in dem jedes Element ein `Stream` ist.                                                                                                                      |

| [areWeakMaps](areWeakMaps.md)               | `areWeakMaps` prüft, ob ein Wert ein nicht-leeres Array ist, in dem jedes Element eine `WeakMap` ist, und gibt nur in diesem Fall `true` zurück, andernfalls `false`.                                                   |
