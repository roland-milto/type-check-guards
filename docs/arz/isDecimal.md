# isDecimal

## وصف

`isDecimal` بيشيّك إذا كانت القيمة تمثيل سترينج لرقم عشري من غير مسافات في الأول/الآخر وبصيغة عشرية سليمة.

### حالة الاستخدام

تحقق من حقول الفورم، أو بيانات الـ API، أو قيم الإعدادات اللي لازم تتبعت كسترينج رقم عشري (وممكن بإشارة) من غير أي
مسافات حواليها، قبل ما تعملها parsing أو تخزنها.

> **ملاحظة لمستخدمي TypeScript:**
>
> استخدم `isDecimal` عشان تتحقق من إدخال المستخدم قبل ما تحوله (مثلاً بـ `Number(value)`)، خصوصًا لما لازم ترفض أي
> مسافات.

### مميزات

- بيتحقق بشكل صارم إن الإدخال سترينج وبيطابق نمط رقم عشري حرفي.
- بيرفض المسافات في الأول والآخر (بما فيها حروف التحكم) عشان يتجنب تفسير ملتبس.
- فحوصات سريعة قبل تشغيل الـ regex (فحص النوع وأول/آخر حرف).
- بيرجع نتيجة بوليان بسيطة (`true`/`false`) مناسبة للـ guards والتحقق من الإدخال.

## الاستخدام

### الصياغة

الدالة:

- `isDecimal(value)`

المعاملات:

- `value`: القيمة اللي هيتعملها فحص إنها بصيغة سترينج رقم عشري.

### استيراد الدالة محليًا

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    //‎‎ v هنا سترينج (اتأكدنا منها وقت التشغيل)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### استيراد كائن عام

استخدم الاستيراد ده علشان تستورد الدوال كطرق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ساعتها هتبقى الطريقة دي متاحة بشكل عام:

- `Type.isDecimal(value)`
