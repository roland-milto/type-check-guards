|---------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [areArrays](areArrays.md)                   | `areArrays` määrittää, onko arvo täytetty kaksiulotteinen taulukko, jonka kaikki alkiot ovat taulukoita.                                                                                                                                                            |

| [areBooleans](areBooleans.md)               | `areBooleans` tarkistaa, sisältääkö annettu ei-tyhjä taulukko vain boolean-arvoja, palauttaen `true`, jos näin on, ja `false` muussa tapauksessa.                                                                                                                   |
| [areBuffers](areBuffers.md)                 | `areBuffers` tarkistaa, onko annettu arvo ei-tyhjä, täytetty taulukko, jossa jokainen alkio on `Buffer`, ja palauttaa tällöin `true` ja muussa tapauksessa `false`.                                                                                                 |
| [areDates](areDates.md)                     | `areDates` määrittää, onko annettu taulukko täytetty ja sisältääkö se vain `Date`-olioita, palauttaen `true` vain silloin, kun kaikki alkiot ovat kelvollisia päivämääriä.                                                                                          |
| [areDecimals](areDecimals.md)               | Tarkistaa, ovatko kaikki taulukon alkiot desimaalilukuja ja onko taulukko täytetty, palauttaen `true` tai `false`.                                                                                                                                                  |

| [areErrors](areErrors.md)                   | Tarkistaa, onko taulukko ei-tyhjä ja sisältää vain `Error`-olioita, palauttaen `true` tai `false`.                                                                                                                                                                  |

| [areFilledArrays](areFilledArrays.md)       | `areFilledArrays` tarkistaa, onko kaksiulotteinen taulukko ei-tyhjä ja ovatko kaikki sen alitaulukot ei-tyhjiä.                                                                                                                                                     |
| [areFinite](areFinite.md)                   | `areFinite` tarkistaa, onko arvo ei-tyhjä taulukko, jonka alkiot ovat kaikki äärellisiä lukuja, ja palauttaa `true` jos näin on, ja muuten `false`.                                                                                                                 |

| [areHexadecimals](areHexadecimals.md)       | Tarkistaa, ovatko kaikki taulukon alkiot heksadesimaalimerkkijonoja, ja palauttaa `true` vain ei-tyhjille taulukoille, joissa jokainen alkio on kelvollinen.                                                                                                        |
| [areIndexesFound](areIndexesFound.md)       | `areIndexesFound` tarkistaa, onko arvo ei-tyhjä taulukko, jonka kaikki alkiot ovat kelvollisia indeksejä, ja palauttaa `true`, jos näin on, ja muuten `false`.                                                                                                      |
| [areIntegers](areIntegers.md)               | `areIntegers` määrittää, ovatko kaikki annetun taulukon alkiot kokonaislukuja, ja palauttaa `true`, jos ovat, ja `false` muussa tapauksessa.                                                                                                                        |
| [areJson](areJson.md)                       | Tarkistaa, ovatko taulukon kaikki alkiot JSON-merkkijonoja, ja palauttaa `true` vain, jos taulukko on täytetty ja jokainen alkio on kelvollista JSONia; muussa tapauksessa palauttaa `false`.                                                                       |
| [areMaps](areMaps.md)                       | `areMaps` määrittää, onko annettu taulukko ei-tyhjä ja ovatko kaikki sen alkiot `Map`-instansseja.                                                                                                                                                                  |
| [areNaNs](areNaNs.md)                       | `areNaNs` tarkistaa, ovatko kaikki taulukon alkiot `NaN`, ja palauttaa `true` vain, jos jokainen alkio on `NaN`.                                                                                                                                                    |
| [areNullOrUndefined](areNullOrUndefined.md) | Tarkistaa, ovatko kaikki annetun taulukon alkiot `null` tai `undefined`.                                                                                                                                                                                            |

| [areOfType](areOfType.md)                   | Tarkistaa, ovatko kaikki annetun `array`-taulukon alkiot määritettyä `type`-tyyppiä.                                                                                                                                                                                |
| [areOneOfType](areOneOfType.md)             | `areOneOfType` tarkistaa, ovatko kaikki ei-tyhjän taulukon alkiot jotakin määritetyistä ajonaikaisista tyypeistä.                                                                                                                                                   |
| [arePlainObjects](arePlainObjects.md)       | Tarkistaa, ovatko taulukon kaikki alkiot tavallisia objekteja, ja palauttaa `true` vain, jos jokainen alkio täyttää ehdon.                                                                                                                                          |

| [areSets](areSets.md)                       | Tarkistaa, sisältääkö annettu ei-tyhjä taulukko vain `Set`-instansseja, palauttaen `true`, jos näin on, ja `false` muussa tapauksessa.                                                                                                                              |
