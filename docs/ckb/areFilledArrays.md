# areFilledArrays

## وەسف

`areFilledArrays` دەزانێت کە ئایا ئارایەکی دوو-ڕەهەندی بەتاڵ نییە و هەموو ئارایە لاوەکییەکانی بەتاڵ نین.

### دۆخی بەکارهێنان

`areFilledArrays` بەکاربهێنە بۆ پشتڕاستکردنەوەی تێخستنی خشتەیی یان ماتریس-وەشە (وەک ڕیزەکانی CSV، داتای گرید، ئەنجامە
گرووپکراوەکان) بۆ ئەوەی بتوانیت بە سەلامەتی دڵنیابیت کە لانی کەم یەک ئارای لاوەکی هەیە و هیچ یەکێک لە ئارایە لاوەکییەکان
بەتاڵ نییە.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> کاتێک `areFilledArrays` بەکاربهێنە کە پێویستت بە دڵنیاییە کە ئارایەکی 2D لانی کەم یەک ڕیز هەیە و هەر ڕیزێک لانی کەم
> یەک ئەندام هەیە پێش ئەوەی لەسەری بگەڕێیتەوە یان بە ئیندێکس دەستی پێ بکەیت.

### سوودەکان

- دڵنیایی دەکاتەوە کە ئارای دەرەوە بەتاڵ نییە و هەروەها هەر ئارای ناوەوەش بەتاڵ نییە، تەنها ئەو کاتە `true` دەگەڕێنێتەوە
  کە هەردوو مەرجەکە جێبەجێ بن.
- لەگەڵ هەر جۆرێک لە ئەندامەکان لە ناو ئارایە لاوەکییەکان کار دەکات (وەک ژمارە، دەق، شت، ئارای ناوەناو) چونکە تەنها دۆخی
  “پڕبوون”ی ئارایەکە دەپشکنێت، نە ناوەڕۆکی ئەندامەکان.
- ئەنجامێکی سادەی بولی (`true`/`false`) پێشکەش دەکات کە گونجاوە بۆ گارد/پارێزەر پێش پرۆسەکردنی داتای دوو-ڕەهەندی.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areFilledArrays(array)`

پارامەتەرەکان:

- `array`: ئارای دوو-ڕەهەندییەکە بۆ پشکنین.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areFilledArrays } from "@type-check/guards";

const a: unknown[][] = [[1]];
const b: unknown[][] = [["a", "b"], [1, 2, 3]];
const c: unknown[][] = [[{}, []], ["string"]];
const d: unknown[][] = [[]];
const e: unknown[][] = [[], [1, 2, 3]];
const f: unknown[][] = [];

console.log(areFilledArrays(a)); //‎ ڕاست
console.log(areFilledArrays(b)); //‎ ڕاست
console.log(areFilledArrays(c)); //‎ ڕاست
console.log(areFilledArrays(d)); //‎ هەڵە
console.log(areFilledArrays(e)); //‎ هەڵە
console.log(areFilledArrays(f)); //‎ هەڵە

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areFilledArrays(array)`
