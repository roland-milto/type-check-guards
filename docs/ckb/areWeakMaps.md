# areWeakMaps

## وەسف

`areWeakMaps` دەپشکنێت کە ئایا بەهایەک ئارایەیەکی نابەتاڵە کە هەر توخمێکی `WeakMap` ـە؛ تەنها لەو حاڵەتەدا `true`
دەگەڕێنێتەوە و لە حاڵەتەکانی تر `false`.

### دۆخی بەکارهێنان

داتای کاتی-جێبەجێکردن پشتڕاست بکەوە (وەک JSON ـی پارسکراو، تێچووی پلاگین، یان ڕێکخستنی بە شێوەیەکی نەرم-جۆر) بۆ
دڵنیابوون لەوەی ئارایەیەکی نابەتاڵە لە نموونەکانی `WeakMap` پێکدێت پێش ئەوەی بەسەریدا بگەڕێیت و مێتۆدەکانی `WeakMap`
بانگ بکەیت؛ کاتێک هەر توخمێک `WeakMap` نەبێت یان ئارایەکە بەتاڵ بێت `false` دەگەڕێنێتەوە.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areWeakMaps` بەکاربهێنە بۆ پشتڕاستکردنەوەی تێچووی نەزانراو پێش ئەوەی وەک `WeakMap[]` ـێکی نابەتاڵ مامەڵەی لەگەڵ
> بکەیت؛ بۆ ئارایە بەتاڵەکان `false` دەگەڕێنێتەوە.

### سوودەکان

- دڵنیایی دەکات کە هەر توخمێک لە ئارایەی پێشکەشکراودا نموونەیەکی `WeakMap` ـە.
- بۆ ئارایە بەتاڵەکان `false` دەگەڕێنێتەوە، وەک ڕێگری لەوەی بە هەڵە “هیچ داتایەک نییە” وەک تێچووی دروست وەربگیرێت.
- وەک پاسەوانێک بەسوودە پێش ئەنجامدانی کارە تایبەتەکانی `WeakMap` لەسەر هەموو دانەکان.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areWeakMaps(array)`

پارامەتەرەکان:

- `array`: ئەو ئارایەیە کە دەپشکنرێت بۆ بوونی نموونەکانی `WeakMap`.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  //‎‎ لیستەکە ئارایەکی بەتاڵ‌نەبووی نمونەکانی WeakMap ـە
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  //‎‎ ئارایەکی بەتاڵ‌نەبووی WeakMap[] نییە
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areWeakMaps(array)`
