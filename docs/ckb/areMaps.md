# areMaps

## وەسف

`areMaps` دیاری دەکات کە ئایا ئارەیەکی دیاریکراو نابەتاڵە و هەموو توخمەکانی نموونەی `Map` ـن.

### دۆخی بەکارهێنان

دڵنیابوون لە تێچووی نەناسراو (وەک لە JSON parsing، API ـە دەرەکییەکان، یان سەرچاوە داینامیکییەکان) پێش ئەوەی وەک لیستێکی
نابەتاڵ لە تەنها `Map` ـەکان مامەڵەی لەگەڵ بکەیت.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> بۆ ئارەی بەتاڵ `false` دەگەڕێنێتەوە؛ تەنها ئەو کاتە `true` دەگەڕێنێتەوە کە ئارەکە پڕ بێت و هەر توخمێک `Map` بێت.

### سوودەکان

- دڵنیایی دەکات کە هەر توخمێک نموونەیەکی `Map` ـە، تەنها ئەو کاتە `true` دەگەڕێنێتەوە کە تەواوی ئارەیەکە لە پشکنینەکە
  دەرچووە.
- بە شێوەی بنەڕەتی ئارەی بەتاڵ ڕەت دەکاتەوە، بۆ ڕێگری لەوەی بە هەڵە “هیچ داتا نییە” وەک دەرچوونی دروست وەرگیرا بێت.
- وەک گاردێک سوودمەندە پێش ئەنجامدانی کارە تایبەتەکانی `Map` (وەک `.get()`، `.set()`، و گەڕان/iteration) لەسەر کۆمەڵێک.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areMaps(array)`

پارامەتەرەکان:

- `array`: ئارەیەکە بۆ پشکنین.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  //‎‎ items بە دڵنیاییەوە لە کاتی جێبەجێکردندا دەبێت ئارایەکێکی نا بەتاڵ بێت لە نموونەکانی Map
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  //‎‎ هەڵە بۆ: ئارایە بەتاڵەکان، یان ئارایەکان کە هەر نرخێکی نا-Map تێدایە
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areMaps(array)`
