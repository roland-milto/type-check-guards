# areHexadecimals

## وەسف

پشکنین دەکات کە ئایا هەموو توخمەکانی ناو ئارایەکە سترینگی هێکسادێسیمالن، و تەنها بۆ ئارایە نەپووچەکان کە هەر بڕگەیەک
دروستە `true` دەگەڕێنێتەوە.

### دۆخی بەکارهێنان

`areHexadecimals` بەکاربهێنە بۆ دڵنیاکردنەوەی تێچووی بەکارهێنەر یان داتای دەرەکی (وەک ID، چێکسەم، کۆدی ڕەنگ بەبێ
پێشەوەی '#') پێش ئەنجامدانی پارسکردنی هێکسادێسیمال یان پرۆسەکردنی زیاتر.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areHexadecimals` بەکاربهێنە بۆ دڵنیاکردنەوەی تێچووی نەناسراو پێش پارسکردن یان گۆڕینی بەهاکان (بۆ نموونە، پێش
`parseInt(value, 16)` یان گۆڕینەکانی BigInt).

### سوودەکان

- دڵنیایی دەکات کە هەر توخمێک سترینگی هێکسادێسیمالە و تەنها ئەو کاتە `true` دەگەڕێنێتەوە کە هەموو بڕگەکان هاوشێوەبن.
- بە شێوەی بنەڕەتی ئارای بەتاڵ ڕەت دەکاتەوە و بۆ داتای تێنەبوو `false` دەگەڕێنێتەوە.
- ئەنجامێکی سادەی بولی (`true`/`false`) پێشکەش دەکات کە گونجاوە بۆ گاردەکان و دڵنیاکردنەوەی زوو-گەڕانەوە.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areHexadecimals(array)`

پارامەتەرەکان:

- `array`: ئەو ئارایەی دەبێت پشکنرێت بۆ توخمە سترینگە هێکسادێسیمالەکان.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areHexadecimals } from "@type-check/guards";

const a = areHexadecimals(["1A", "3F", "B2"]);
const b = areHexadecimals(["1A", "3G", "B2"]);
const c = areHexadecimals([10 as unknown as string, "3F", "B2"] as unknown[]);
const d = areHexadecimals([]);

console.log(a, b, c, d);
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areHexadecimals(array)`
