# areEqual

## وەسف

`areEqual` پشکنین دەکات کە ئایا هەموو ئەندامەکانی ئارایەکە لەگەڵ بەهایەکی چاوەڕوانکراو یەکسانن، و `true` تەنها بۆ ئارایە
نا بەتاڵەکان دەگەڕێنێتەوە کە هەر دانەیەک هاوشێوەیە.

### دۆخی بەکارهێنان

دڵنیابوون لەوەی لیستێک تەنها یەک بەهای ڕێگەپێدراو لەخۆدەگرێت (وەک هەموو نیشانەکانی دۆخ `true` بن، هەموو ڕۆڵەکان
`"admin"` بن، یان هەموو ژمارەکان یەکسانی کۆنستانتێکی پێویست بن) لە کاتێکدا هاتووچۆی بەتاڵ وەک نادروست (`false`) مامەڵەی
لەگەڵ دەکرێت.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areEqual` بەکاربهێنە کاتێک پێویستت بە پشکنینی توندی هەموو دانەکان هەیە؛ بۆ ئارایە بەتاڵەکان و هەر هاتووچۆیەکی
> نا-ئارای یان نا-پڕ `false` دەگەڕێنێتەوە.

### سوودەکان

- `true` تەنها ئەو کاتە دەگەڕێنێتەوە کە هەموو ئەندامەکان لەگەڵ بەهای چاوەڕوانکراو یەکسان بن؛ ئەگەر نا، `false`
  دەگەڕێنێتەوە.
- زوو دەوەستێت: هەر کاتێک ئەندامێکی ناهاوشێوە بدۆزرێتەوە، وەستانی پشکنین دەکات.
- لە دژە هاتووچۆی نادروست پارێزگاری دەکات بەوەی `false` دەگەڕێنێتەوە کاتێک هاتووچۆکە ئارایەکی پڕ نەبێت.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areEqual(value, expected)`

پارامەتەرەکان:

- `value`: ئەو ئارایەیە کە دەبێت پشکنرابێت.
- `expected`: ئەو ئەندامەیە کە هەر دانەی ئارایەکە پێی هاوبەش دەکرێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areEqual(value, expected)`
