# areFalse

## وەسف

`areFalse` پشکنین دەکات ئایا هەموو توخمەکان لە ئارەیەکی پێدراو بە توندی بوولیانی `false` ـن.

### دۆخی بەکارهێنان

پشتڕاستکردنەوەی ئەوەی لیستێک لە feature flags، پشکنینەکان، یان ئەنجامەکانی guard هەموویان `false` ـن پێش ئەوەی بەردەوام
بیت (بۆ نموونە، دڵنیابوون لەوەی هیچ دۆخی قەدەغەکەرێک ئامادە نییە).

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> کاتێک پێویستت بە پشتڕاستکردنەوەیەکی توند هەیە کە ئارەکە بەتاڵ نەبێت و تەنها بەهای بوولیانی `false` تێدایە، `areFalse`
> بەکاربهێنە.

### سوودەکان

- دڵنیایی دەدات هەر توخمێک بە توندی `false` بێت (بێ گۆڕینی truthy/falsey).
- بۆ نا-ئارەیەکان یان ئارەی بەتاڵ `false` دەگەڕێنێتەوە، چونکە بەهۆی `isFilledArray` پێویستی بە ئارەی پڕ دەکات.
- بۆ کارامەیی، لە یەکەم توخمێکی نا-`false` وەست دەکات.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areFalse(array)`

پارامەتەرەکان:

- `array`: ئارەیەک کە دەبێت پشکنرێت، کە توخمەکانی لە هەر جۆرێک دەبن.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areFalse } from "@type-check/guards";

const a = areFalse([false, false, false]); //‎ ڕاست
const b = areFalse([false, true, false]);  //‎ هەڵە
const c = areFalse([false, "false", false]); //‎ هەڵە
const d = areFalse([]); //‎ هەڵە
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areFalse(array)`
