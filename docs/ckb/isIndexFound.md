# isIndexFound

## وەسف

`isIndexFound` دیاری دەکات ئایا بەهایەکی دیاریکراو ژمارەیەکی تەواوی نەهێنراوە، کە واتە ئیندێکس دۆزرایەوە.

### دۆخی بەکارهێنان

دڵنیابوون لەوەی ئەنجامی گەڕان ئیندێکسێکی بەکارهێنراوە (ژمارەی تەواو `>= 0`) ـە پێش ئەوەی بە ئیندێکسکردن لە array یان
string ـەکەدا بەکاریبهێنیت، بۆ ڕێگری لە بەکارهێنانی هەڵەیی `-1` یان بەها نائامارەکان.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isIndexFound` بەکاربهێنە دوای کردارەکانی وەک `indexOf`، `findIndex`، یان گەڕانە تایبەتەکان کە `-1` (یان بەها
> نادروستەکانی تر) دەتوانێت “نەدۆزرایەوە” پیشان بدات. کاتێک `true` دەگەڕێنێتەوە، ئەو بەهایە ژمارەیە و پارێزراوە بۆ
> بەکارهێنان وەک ئیندێکسی array/string.

### سوودەکان

- پارێزەری جۆرێکی سادە دابین دەکات بۆ دۆزینەوەی ئەوەی ئایا ئیندێکسێک دۆزرایەوە یان نا، بە پشکنینی ژمارەی تەواوی
  نەهێنراو (non-negative).
- تەنها بۆ بەها ئیندێکس-وەکە دروستەکان `true` دەگەڕێنێتەوە (ژمارە تەواوەکان `>= 0`)، بەها سالبەکان، نەتەواوەکان، و
  نائامارەکان ڕەت دەکاتەوە.
- یارمەتی دەدات لە دووربوونەوە لە هەڵەکانی off-by-one و sentinel-value کاتێک لەگەڵ API ـەکان کار دەکەیت کە `-1`
  دەگەڕێننەوە بۆ “نەدۆزرایەوە”.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isIndexFound(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەبێت پشکنرێت بۆ ئەوەی ژمارەیەکی تەواوی نەهێنراو بێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  //‎‎ idx لێرە ژمارەیە و >= 0 ـە
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

//‎‎ بەکارهێنانی باو لەگەڵ indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isIndexFound(value)`
