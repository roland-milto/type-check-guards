# isFilledArray

## وەسف

پشکنین دەکات کە ئایا `value` ئارەیەکە بە لانیکەم یەک ئەندام، و `true` یان `false` دەگەڕێنێتەوە.

### دۆخی بەکارهێنان

بەکارهێنانی `isFilledArray` بۆ پشتڕاستکردنەوەی داتای هاتوو (وەک payload ـی API، بەهاکانی فۆرم، ڕێکخستن) پێش ئەوەی لەسەری
بگەڕێیتەوە (iterate)، یەکەم ئەندام دەستپێبکەیت، یان لۆجیکی جێبەجێ بکەیت کە پێویستی بە لانیکەم یەک دانە شت هەیە.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isFilledArray` پارێزەری کاتی جێبەجێبوونە (runtime guard) کە boolean دەگەڕێنێتەوە؛ جۆری ئەندامەکان زیاتر تەنها بە
> دڵنیابوون لەوەی ئارەکە بەتاڵ نییە ناڕاستەوخۆ ناچڕێتەوە.

### سوودەکان

- پشکنینێکی سادە و خێرا بۆ ئارەیەکی بەتاڵ نەبوو بە بەکارهێنانی `Array.isArray` و پشکنینی درێژی.
- یارمەتی دەدات هەڵەکانی کاتی جێبەجێبوون (runtime) دوور بخەیتەوە کاتێک کۆد وا دادەنێت ئارەکە لانیکەم یەک ئەندام هەیە.
- ئەنجامی ڕوون و دوودەمی: `true` دەگەڕێنێتەوە بۆ ئارەی بەتاڵ نەبوو و `false` بۆ دیکە حاڵەتەکان.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isFilledArray(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەستپێدەکەیت بۆ پشکنین کە ئایا ئارەیەکی بەتاڵ نەبووە.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isFilledArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && isFilledArray(input)) {
  //‎‎ input لە کاتی جێبەجێکردندا ئارایەکی بەتاڵ نییە
  console.log(input[0]);
} else {
  console.log("Not a non-empty array");
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isFilledArray(value)`
