# isTrue

## وەسف

`isTrue` دیاری دەکات کە ئایا قیمەتێکی دیاریکراو بە شێوەی توند یەکسانە بە `true` یان نا.

### دۆخی بەکارهێنان

`isTrue` بەکاربهێنە بۆ ڕاستپشکنینی ئاڵاکان، گۆڕینی تایبەتمەندی (feature toggles)، یان قیمەتەکانی ڕێکخستن کە تەنها
لیتەراڵی `true` دەبێت پەسەند بکرێت و هەموو شتێکی تر دەبێت وەک `false` مامەڵەی لەگەڵ بکرێت.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isTrue` بەکاربهێنە کاتێک پێویستتە تەنها لیتەراڵی بولی `true` وەربگریت، نەک تەنها قیمەتە ڕاست‌وەکەکان.

### سوودەکان

- پشکنینێکی توند دەدات بۆ لیتەراڵی بولی `true` (بێ کۆئێرشن).
- یارمەتیدەدات جیا بکەیتەوە `true` لە قیمەتە ڕاست‌وەکەکان وەک `1`، `"true"`، یان `{}`.
- هەڵسوکەوتێکی سادە و پێشبینی‌کراو گونجاوە بۆ گاردەکان و پایپڵاینەکانی ڕاستپشکنین.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isTrue(value)`

پارامەتەرەکان:

- `value`: ئەو قیمەتەی دەبێت پشکنرێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      //‎ ڕاست
const b = isTrue(1);         //‎ هەڵە
const c = isTrue("true");   //‎ هەڵە

if (isTrue(a)) {
  //‎‎ a لێرە ڕاستە
}
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isTrue(value)`
