# areObjects

## وەسف

`areObjects` دەپشکنێت ئایا ئەڕەیەکی پڕی پێشکەشکراو تەنها شیءی تێدایە.

### دۆخی بەکارهێنان

`areObjects` بەکاربهێنە کاتێک ئەڕەیەکی نەناسراوت وەرگرتووە (وەک لە JSON parsing یان API ـە دەرەکییەکان) و پێویستتە
دڵنیابیت کە بەتاڵ نییە و هەموو ئەندامەکان شیءن پێش ئەوەی بگەڕێیتەوە و دەستت بگات بە تایبەتمەندییەکانی شیء.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areObjects` بەکاربهێنە بۆ پشتڕاستکردنەوەی `unknown[]` پێش ئەوەی ئەندامەکان وەک شیء مامەڵەیان لەگەڵ بکەیت؛ بۆ ئەڕەی
> بەتاڵ `false` دەگەڕێنێتەوە.

### سوودەکان

- `true` دەگەڕێنێتەوە تەنها کاتێک هاتووچۆکە ئەڕەیەکی پڕ بێت و هەموو ئەندامەکان شیء بن.
- زوو دەوەستێت و `false` دەگەڕێنێتەوە هەر کاتێک یەکەم ئەندامی ناشیء بدۆزرێتەوە.
- یارمەتیدەدات بۆ پشتڕاستکردنەوەی هاتووچۆی نەناسراو پێش ئەنجامدانی کارە تایبەتەکانی شیء.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areObjects(array)`

پارامەتەرەکان:

- `array`: ئەو ئەڕەیەی دەپشکنرێت بۆ ئەوەی بزانرێت ئەندامەکانی شیءن یان نا.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areObjects } from "@type-check/guards";

const value: unknown = [{}, { a: 1 }, new Date()];

if (Array.isArray(value) && areObjects(value)) {
  //‎‎ value بریتییە لە ئارایەکەی پڕ لە ئۆبجێکت
  console.log("All items are objects:", value.length);
} else {
  console.log("Not a filled array of objects");
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areObjects(array)`
