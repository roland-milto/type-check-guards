# areNumbers

## وەسف

`areNumbers` پشکنین دەکات کە ئایا بەهایەک ئەڕەیەکی بەتاڵ نەبێت و هەموو ئەندامەکانی ژمارە بن.

### دۆخی بەکارهێنان

داتای دابینکراو لەلایەن بەکارهێنەر یان API پشتڕاست بکەوە بۆ دڵنیابوون لەوەی ئەڕەیەکی بەتاڵ نەبێت لە ژمارەکان پێش ئەوەی
کۆی گشتی، ناوەند، یان هەر کۆکردنەوەی ژمارەیی تر حساب بکەیت.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areNumbers` بەکاربهێنە بۆ پشتڕاستکردنەوەی ئەڕەیە نا ناسراوەکان پێش ئەنجامدانی ژماردنە ژمارەییەکان؛ `false`
> دەگەڕێنێتەوە بۆ ئەڕەی بەتاڵ و بۆ ئەڕەیەکان کە هەر بەهایەکی نا-ژمارەیان تێدایە.

### سوودەکان

- تەنها کاتێک `true` دەگەڕێنێتەوە کە هاتووچۆکە ئەڕەیەکی بەتاڵ نەبێت و هەموو ئەندامەکان ژمارە بن.
- ڕێگری لە دەرئەنجامە هەڵەکان دەکات بە ڕەتکردنەوەی ئەڕەی بەتاڵ و هاتووچۆی نا-ئەڕەیی.
- وەک پاسەوانێک پێش کارە ژمارەییەکان (وەک کۆکردنەوە، ناوەندگرتن) سوودمەندە بۆ دووربوون لە هەڵەکانی کاتی جێبەجێکردن.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areNumbers(array)`

پارامەتەرەکان:

- `array`: ئەڕەیەکە کە دەبێت بپشکنرێت بۆ ئەوەی ئەندامەکانی ژمارە بن.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areNumbers(array)`
