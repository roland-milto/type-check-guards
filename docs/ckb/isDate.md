# isDate

## وەسف

`isDate` دیاری دەکات ئایا بەهای پێشکەشکراو `Date` ـە، `true` دەگەڕێنێتەوە بۆ نموونەکانی `Date` و `false` بۆ هەموو شتێکی
تر.

### دۆخی بەکارهێنان

بەها نەزانراوەکان پشتڕاست بکە و تەنک بکەوە (وەک داتای داواکاری، بەهاکانی ڕێکخستن، یان JSON ـی پارسکراو) پێش ئەنجامدانی
کردارەکانی `Date` وەک فۆرماتکردن، بەراوردکردن، یان بانگکردنی `toISOString()`.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isDate` بەکاربهێنە بۆ تەنککردنەوەی `unknown` بۆ `Date` لە کاتی جێبەجێکردن؛ تەنها بۆ نموونە ڕاستەقینەکانی `Date`
`true` دەگەڕێنێتەوە (نەک ڕیزبەندیی بەروار).

### سوودەکان

- پارێزگایەکی سادەی کاتی جێبەجێکردن دابین دەکات بۆ پشتڕاستکردنەوەی ئەوەی ئایا بەهایەک `Date` ـە.
- یارمەتی دەدات هەڵەکانی جۆر (type errors) ڕوونەدەن بە دڵنیابوون لەوەی تەنها نموونەکانی `Date` لە پشکنین تێپەڕ دەبن.
- سوودمەندە بۆ پشکنینی هاتووچۆی نەزانراو (وەک payload ـی API) پێش بەکارهێنانی مێتۆدە تایبەتەکانی بەروار.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isDate(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەبێت بپشکنرێت بۆ جۆری `Date`.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isDate } from "@type-check/guards";

const input: unknown = new Date();

if (isDate(input)) {
  //‎‎ input لێرە Date ـە
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a Date");
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isDate(value)`
