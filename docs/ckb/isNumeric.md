# isNumeric

## وەسف

`isNumeric` دیاری دەکات کە ئایا `value` ـێکی دیاریکراو بە ژمارەیی دادەنرێت یان نا، بە پشکنینی جۆری چارەسەرکراوی بەرامبەر
`NUMERIC_TYPES`.

### دۆخی بەکارهێنان

بەکارهێنانی `isNumeric` بۆ پشتڕاستکردنەوەی هاتووچۆکان (وەک payload ـی API، نرخەکانی فۆرم، ڕێکخستن) پێش ئەنجامدانی کارە
ژمارەییەکان، و بۆ وەرگرتنی یەکسانی جۆرە ژمارە-هاوشێوەکان (وەک `BigInt`) بە پێی `NUMERIC_TYPES`.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isNumeric` پێشبینەرێکە کە بۆلی دەگەڕێنێتەوە؛ وەک پشکنینێکی کاتی-جێبەجێکردن (runtime) مامەڵەی لەگەڵ بکە بۆ ئەوەی
> بزانیت ئایا نرخێک دەچێتە ناو کۆمەڵە جۆرە ژمارەییە دیاریکراوەکانی کتێبخانەکە یان نا.

### سوودەکان

- بەکارهێنانی `getTypeOf` لەگەڵ `NUMERIC_TYPES` بۆ یەکخستنەوەی لۆجیکی ناسینەوەی ژمارەیی و هێشتنەوەی پشکنینەکان بە
  یەکسانی لە سەرانسەری بنچینەکۆدێکدا.
- گەڕاندنەوەی بۆلییەکی سادە (`true`/`false`) بۆ ئاسانکردنی دابەشکردن و بەکارهێنانی شێوازی guard.
- پشتگیری لە چەند شێوازێکی جیاواز لە نوێنەرایەتی ژمارەیی (وەک `number`، `BigInt`) وەک لەلایەن `NUMERIC_TYPES`
  دیاریکراون.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isNumeric(value)`

پارامەتەرەکان:

- `value`: ئەو نرخەیە کە دەبێت بپشکنرێت بۆ جۆری ژمارەیی.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    //‎‎ v بە پێی یاساکانی جۆری لایبرەرییەکە بە ژمارەیی دادەنرێت
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isNumeric(value)`
