# isOneOfType

## وەسف

`isOneOfType` دیاری دەکات ئایا `value` ـێکی دیاریکراو لەگەڵ لانیکەم یەکێک لە ڕستە جۆرە پێشکەشکراوەکان هاوتا دەبێت، و
`true` دەگەڕێنێتەوە ئەگەر هەر هاوتایەک بدۆزرێتەوە و `false` ئەگەر نا.

### دۆخی بەکارهێنان

دڵنیابوون لە داتای شڵ یان داتای دەرەکی (وەک JSON ـی پارسکراو، پارامەتەرەکانی query) بە ڕێگەدان بە چەند جۆری ڕێگەپێدراوی
کاتی جێبەجێکردن (وەک `number` یان `string`) پێش ئەوەی بەردەوام بیت بە لۆجیکی زیاتر.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isOneOfType` بەکاربهێنە کاتێک دەتەوێت لە کاتی جێبەجێکردن پشکنینێک بکەیت کە بەهایەک لەگەڵ هەر یەکێک لە چەند جۆرێکی
> ڕێگەپێدراو هاوتا دەبێت؛ `true` دەگەڕێنێتەوە ئەگەر لانیکەم یەک جۆر هاوتا بوو، ئەگەر نا `false`.

### سوودەکان

- لە یەک بانگکردنەوەدا بەهایەک دەکاتە پشکنین بەرامبەر چەند جۆرێکی ڕێگەپێدراو، و `true` دەگەڕێنێتەوە لە یەکەم
  هاوتاکردنەوەدا.
- لەگەڵ هاتووچۆی `unknown` کار دەکات، کە بەسوودە لە سنووری کاتی جێبەجێکردن (وەک داتای دەرەکی، تێخستەی بەکارهێنەر).
- ئەنجامی سادەی boolean (`true`/`false`) کە باش دەگونجێت لەگەڵ لۆجیکی مەرجی و گەڕانەوەی زوو.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isOneOfType(value, types)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەبێت پشکنین بکرێت بەرامبەر ئەو جۆرانەی دیاریکراون.
- `types`: ئارایەک لە ڕستەی جۆر (type strings) کە جۆرە ئەگەرییەکانی بەهاکە پیشان دەدات.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  //‎‎ input لە کاتی جێبەجێکردندا ئۆبجێکتە
}

console.log(isOneOfType(3, ["number", "string"])); //‎ ڕاستە
console.log(isOneOfType("hello", ["number", "boolean"])); //‎ هەڵەیە

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isOneOfType(value, types)`
