# areDates

## وەسف

`areDates` دیاری دەکات کە ئارایەکی دیاریکراو پڕە و تەنها `Date` ـەکان لەخۆ دەگرێت، و تەنها کاتێک `true` دەگەڕێنێتەوە کە
هەموو ئەندامەکان بەرواری دروستن.

### دۆخی بەکارهێنان

لە `areDates` بەکاربهێنە بۆ پشتڕاستکردنەوەی هاتنەژوورێکی نەزانراو (وەک JSON ـی پارسکراو، داتای فۆرم، payload ـی API) پێش
ئەوەی لۆجیکی تایبەت بە بەروار جێبەجێ بکەیت وەک ڕیزکردن بە پێی کات، فۆرماتکردن، یان هەژمارکردنی مەودا.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> تەنها بۆ ئارایە نابەتاڵەکان `true` دەگەڕێنێتەوە کە هەموو ئەندامەکانیان `Date` ـن؛ ئارایە بەتاڵەکان `false` دەدەن.

### سوودەکان

- دڵنیایی دەکات کە پێش پشتڕاستکردنەوەی ناوەڕۆکی، ئارایەک بەتاڵ نەبێت، و ڕێگری دەکات لەوەی بۆ دەرچوونە بەتاڵەکان `true`
  بگەڕێتەوە.
- هەموو ئەندامێک پشتڕاست دەکاتەوە کە نمونەیەکی `Date` ـە، و لە یەکەم ناگونجانییەوە دەستبەجێ `false` دەگەڕێنێتەوە.
- وەک پشکنینێکی جۆری گارد بەسوودە پێش ئەنجامدانی کارە تایبەت بە بەروار لەسەر ئەندامەکانی ئارایەک.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areDates(array)`

پارامەتەرەکان:

- `array`: ئەو ئارایەیە کە دەبێت بپشکنرێت بۆ `Date` ـەکان.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areDates } from "@type-check/guards";

const a: unknown[] = [new Date(), new Date("2021-01-01")];
const b: unknown[] = [];
const c: unknown[] = [new Date(), "not a date"];

console.log(areDates(a)); //‎ ڕاست
console.log(areDates(b)); //‎ هەڵە
console.log(areDates(c)); //‎ هەڵە

if (areDates(a)) {
  const timestamps = a.map(d => d.getTime());
  console.log(timestamps);
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areDates(array)`
