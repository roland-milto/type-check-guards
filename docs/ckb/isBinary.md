# isBinary

## وەسف

`isBinary` دیاری دەکات کە ئایا بەهایەک ڕیزەنووسی دووانەیە (بە دڵخوازانە پێشگرەوەی `0b`/`0B` هەبێت) و `true` یان `false`
دەگەڕێنێتەوە.

### دۆخی بەکارهێنان

ڕیزەنووسە دابینکراوە لەلایەن بەکارهێنەر (وەک خانەکانی فۆرم، ئارگیومێنتەکانی CLI، بەهاکانی ڕێکخستن) پشتڕاست بکەوە بۆ
ئەوەی دڵنیابیت تەنها ژمارە دووانەکان پیشان دەدەن، بە دڵخوازانە پێشگرەوەی `0b`/`0B` هەبێت، پێش ئەوەی پرۆسەی زیاتر بکەیت.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isBinary` بەکاربهێنە وەک type guard پێش ئەوەی ڕیزەنووسێک بخوێنیتەوە یان بیگۆڕیت بۆ `BigInt`/`Number` بۆ ئەوەی لە
> هاتووچۆی نادروست دووربیتەوە.

### سوودەکان

- ڕیزەنووسی دووانە وەردەگرێت، بە پێشگرەوەی `0b`/`0B` یان بەبێ ئەوە.
- ڕیزەنووسی بەتاڵ و ڕیزەنووسەکان کە بۆشایی لە سەرەتا/کۆتاییان هەیە ڕەت دەکاتەوە (ASCII ≤ 32).
- `true`/`false` دەگەڕێنێتەوە بەبێ ئەوەی هەڵە فڕێبدات، بۆیە بۆ هاتووچۆی نادیار سەلامەتە.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isBinary(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەبێت پشکنرێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); //‎ ڕاست
const b = isBinary("1010");   //‎ ڕاست
const c = isBinary("0b1020"); //‎ هەڵە
const d = isBinary(0b1010);     //‎ هەڵە

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isBinary(value)`
