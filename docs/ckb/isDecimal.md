# isDecimal

## وەسف

`isDecimal` دەپشکنێت کە ئایا بەهایەک وێنەی ڕیزەنووسی دەهەمییە بەبێ بۆشایی لە سەرەتا/کۆتایی و بە فۆرماتێکی دەهەمیی دروست.

### دۆخی بەکارهێنان

دڵنیایی‌کردنی خانەکانی فۆرم، payload ـی API، یان بەهاکانی ڕێکخستن کە دەبێت وەک ڕیزەنووسی دەهەمی (بە ئیمزای هەڵبژاردەیی)
پێشکەش بکرێن بەبێ هیچ بۆشاییەکی دەوروبەر، پێش لێکدانەوە یان هەڵگرتن.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isDecimal` بەکاربهێنە بۆ دڵنیایی‌کردنی هاتووەی بەکارهێنەر پێش ئەوەی بیگۆڕیت (بۆ نموونە بە `Number(value)`)، بە
> تایبەتی کاتێک دەبێت بۆشایی ڕەت بکرێتەوە.

### سوودەکان

- بە توندی دڵنیایی دەکات کە هاتووەکە ڕیزەنووسە و لەگەڵ شێوازی decimal-literal دەگونجێت.
- بۆشایی سەرەتا و کۆتایی (لەوانەش کاراکتەری کۆنترۆڵ) ڕەت دەکاتەوە بۆ ئەوەی لێکدانەوەی ناڕوون ڕوونەدات.
- پێشپشکنینی خێرا (پشکنینی جۆر و کاراکتەری یەکەم/کۆتایی) پێش ئەوەی regex جێبەجێ بکات.
- ئەنجامێکی سادەی boolean دەگەڕێنێتەوە (`true`/`false`) کە گونجاوە بۆ guards و دڵنیایی‌کردنی هاتووە.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isDecimal(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەبێت بپشکنرێت بۆ فۆرماتی ڕیزەنووسی دەهەمی.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    //‎‎ v لێرەدا سترینگێکە (لە کاتی جێبەجێکردندا پشتڕاستکراوە)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isDecimal(value)`
