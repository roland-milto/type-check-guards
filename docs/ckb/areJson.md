# areJson

## وەسف

پشکنین دەکات کە ئایا هەموو ئەندامەکانی یەک ئارای سترینگی JSONن، تەنها ئەگەر ئارایەکە پڕ بێت و هەر دانەیەک JSONی دروست
بێت `true` دەگەڕێنێتەوە؛ ئەگەر نا `false` دەگەڕێنێتەوە.

### دۆخی بەکارهێنان

دڵنیابوون لە داتای هاتوو (بۆ نموونە لە query params، environment variables، یان APIی دەرەکی) کاتێک چاوەڕوانی ئارایەک لە
سترینگەکانی JSON-encoded دەکەیت و دەتەوێت ئارای بەتاڵ یان هەر دانەیەکی نا-JSON ڕەت بکەیتەوە.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areJson` بەکاربهێنە کاتێک پێویستتە دڵنیابیت کە `unknown[]` تەنها سترینگی JSON لەخۆ دەگرێت پێش ئەوەی بیانپارسی (بۆ
> نموونە بە `JSON.parse`).

### سوودەکان

- تەنها ئەو کاتە `true` دەگەڕێنێتەوە کە هەموو ئەندامەکان سترینگی JSONی دروست بن؛ ئەگەر نا، `false` دەگەڕێنێتەوە.
- بەخێرایی دەشکێت: هەر کاتێک یەک ئەندامی نا-JSON بدۆزرێتەوە، وەستان دەکات لە پشکنین.
- بە شێوەیەکی بنەڕەتی ئارای بەتاڵ ڕەت دەکاتەوە و بۆ داتای پڕنەکراو `false` دەگەڕێنێتەوە.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areJson(array)`

پارامەتەرەکان:

- `array`: ئەو ئارایەی دەبێت پشکنرێت بۆ ئەوەی ببینرێت ئەندامەکانی سترینگی JSONن.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); //‎ ڕاستە
const mixed = areJson(["{\"a\":1}", 123 as unknown]); //‎ هەڵە
const empty = areJson([]); //‎ هەڵە

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areJson(array)`
