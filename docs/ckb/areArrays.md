# areArrays

## وەسف

`areArrays` دیاری دەکات کە ئایا بەهایەک ئەڕەیەکی دوو-ڕەهەندیی پڕە کە دانەکانی هەموویان ئەڕە بن.

### دۆخی بەکارهێنان

بۆ پشتڕاستکردنەوەی هاتووچۆی خشتەیی یان ماتریس-وەش (وەک ڕیزەکانی CSV، داتای تۆڕ، یان لیستی گرووپکراو) پێش ئەنجامدانی
کارەکانی ڕیز/ستوون `areArrays` بەکاربهێنە؛ ئەگەر هاتووچۆکە ئەڕە نەبێت، بەتاڵ بێت، یان هەر ئەندامێکی نا-ئەڕەی تێدا هەبێت
`false` دەگەڕێنێتەوە.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> کاتێک پێویستتە دڵنیابیت کە بەهایەک ئەڕەیەکی دوو-ڕەهەندیی نا بەتاڵە و هەر ڕیزێک ئەڕەیە پێش ئەوەی لەسەر ئەڕە ناوخۆییەکان
> بگەڕێیتەوە یان ئیندێکس بکەیت، `areArrays` بەکاربهێنە.

### سوودەکان

- دڵنیایی دەکاتەوە کە هاتووچۆکە ئەڕەیەکی دوو-ڕەهەندییەی نا بەتاڵە و هەموو ئەندامێکی ئەوەش ئەڕەیە.
- ئەنجامێکی سادەی بوولیان دەگەڕێنێتەوە (`true`/`false`) کە گونجاوە بۆ گارد و دەرچوونی زوو.
- یارمەتی دەدات هەڵەکانی کاتی جێبەجێبوون ڕێگری بکرێت کاتێک کۆدی دواتر وا دەزانێت کارکردن لەسەر ئەڕەی ناوخۆیی هەیە (وەک
  map کردنی ڕیزەکان).

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areArrays(array)`

پارامەتەرەکان:

- `array`: هاتووچۆکەیە کە دەبێت پشکنرێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  //‎‎ value ئارایەکی دووڕەهەندییە کە ئارایەکان وەک ئەندامەکانن
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areArrays(array)`
