# areBinaries

## وەسف

پشکنین دەکات کە ئایا بەها پێشکەشکراوەکە ئارایەیەکی بەتاڵ نەبووە لە سترینگی باینەریی دروست و `true` تەنها دەگەڕێنێتەوە
ئەگەر هەموو دانەکان پشتڕاستکرانەوەیان تێپەڕاند.

### دۆخی بەکارهێنان

کاتێک لیستێکی نەناسراو وەردەگریت (وەک لە JSON، فۆرمەکان، یان API ـەکان) و پێویستتە دڵنیابیت کە ئارایەیەکی بەتاڵ نەبووە
لە سترینگی باینەرییە پێش ئەوەی parsing یان پرۆسەی بکەیت، `areBinaries` بەکاربهێنە.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> لە `areBinaries` بەکاربهێنە بۆ پشتڕاستکردنەوەی هاتووی نەناسراو پێش گۆڕینی سترینگی باینەری بۆ ژمارە/BigInt؛ دڵنیایی
> دەکاتەوە کە ئارایەکە بەتاڵ نییە و هەر توخمێک سترینگی باینەریی دروستە.

### سوودەکان

- دڵنیایی دەکاتەوە کە بەهاکە ئارایەیەکی بەتاڵ نەبووە و هەر توخمێک تێیدا سترینگی باینەریی دروستە.
- ئەنجامێکی سادەی boolean دەگەڕێنێتەوە (`true`/`false`) کە گونجاوە بۆ guard، گەڕانەوەی زوو، و پشتڕاستکردنەوەی هاتووەکان.
- هەڵەکانی پاشەوەی parsing ڕێگری لێدەکات بە ڕەتکردنەوەی ئەو ئارایانەی کە هەر توخمێکی ناباینەرییان تێدایە.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areBinaries(array)`

پارامەتەرەکان:

- `array`: ئەو بەهایەی کە دەبێت پشکنرێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); //‎ ڕاست
console.log(areBinaries(b)); //‎ هەڵە
console.log(areBinaries([])); //‎ هەڵە
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areBinaries(array)`
