# isOctal

## وەسف

دیاری دەکات کە ئایا بەهایەک سترینگی لیتەرالی ئۆکتالی دروستە (وەک `0o755`) یان نا.

### دۆخی بەکارهێنان

دڵنیابوون لە هاتووچۆی بەکارهێنەر یان بەهاکانی ڕێکخستن کە دەبێت وەک سترینگی لیتەرالی ئۆکتال دەربکەون (بۆ نموونە، مۆدی
مۆڵەتەکانی فایل وەک `0o644`) پێش ئەوەی پارس یان گۆڕانکارییان بکەیت.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isOctal` پارێزەری جۆرە (`value is string`). دوای ئەنجامی `true`، TypeScript گۆڕاوە پشکنراوەکە تەنک دەکاتەوە بۆ
`string`.

### سوودەکان

- پارێزەری جۆری توند دابین دەکات: تەنها ئەو کاتە `true` دەگەڕێنێتەوە کە هاتووچۆکە سترینگێک بێت کە لەگەڵ فۆرماتی لیتەرالی
  ئۆکتال دەگونجێت.
- سترینگە بەتاڵەکان و سترینگەکان بە سپەیس/بۆشایی سەرەتا/کۆتایی (کۆنترۆڵ/سپەیسی ASCII) ڕەت دەکاتەوە، کە هاوشێوەبوونە
  هەڵەکان کەم دەکاتەوە.
- نیشانەی هەڵبژاردەیی پشتگیری دەکات و بێ-هەستی بە گەورە/بچووکە بۆ پێشگرەکەی `0o`/`0O`.
- لەگەڵ هاتووچۆی نا-سترینگ بە نەرمی مامەڵە دەکات بەوەی `false` دەگەڕێنێتەوە لە جیاتی ئەوەی هەڵە فڕێبدات.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isOctal(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەبێت پشکنین بکرێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); //‎ ڕاست
console.log(isOctal(b)); //‎ ڕاست
console.log(isOctal(c)); //‎ هەڵە
console.log(isOctal(d)); //‎ هەڵە

if (isOctal(a)) {
  //‎‎ a لێرەدا ڕیزەنووسە
  const normalized = a.toLowerCase();
  console.log(normalized);
}
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isOctal(value)`
