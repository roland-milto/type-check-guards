# isValidDate

## وەسف

`isValidDate` پشکنین دەکات کە ئایا بەهایەکی دیاریکراو `Date` ـێکی دروستە و تەنها بۆ بەروارە ڕاستەقینە و نەنادروستەکان
`true` دەگەڕێنێتەوە.

### دۆخی بەکارهێنان

پشتڕاستکردنەوەی هاتووچۆی بەکارهێنەر یان داتای API کە دەکرێت بەروار تێدابێت، بۆ دڵنیابوون لەوەی بەهاکە نموونەیەکی
ڕاستەقینەی `Date` ـە و بەروارێکی نادروست نییە پێش ئەنجامدانی ژمێریاری بەروار، فۆرماتکردن، یان بەراورد.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> پێش بانگکردنی مێتۆدەکانی `Date` (وەک `toISOString`, `getTime`) لەسەر بەهاکان کە جۆرییان `unknown` ـە، `isValidDate`
> بەکاربهێنە بۆ دڵنیابوون لەوەی نموونەی `Date` ـی دروستن.

### سوودەکان

- دڵنیایی دەکاتەوە کە بەهایەک نموونەی `Date` ـە و تەنها ڕیزبەندی یان ژمارەیەکی وەک بەروار نییە.
- بەروارە نادروستەکان ڕەت دەکاتەوە (وەک `new Date("invalid")`) بە پشکنینی بەهای کاتی `NaN`.
- پارێزەری سادەی boolean ـە کە بە ئاسانی لە مەرجەکان و پایپڵاینەکانی پشتڕاستکردنەوە بەکاردێت.
- یارمەتیدەدات هەڵەکانی کاتی جێبەجێبوون ڕێگری لێبکات کاتێک مێتۆدەکانی بەروار بانگ دەکەیت، بەوەی سەرەتا دڵنیایی لە
  هاتووچۆی دەرچوونەکە دەکات.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isValidDate(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەبێت پشکنرێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isValidDate } from "@type-check/guards";

const input: unknown = new Date();

if (isValidDate(input)) {
  //‎‎ input بریتییە لە نموونەیەکی Date ی دروست
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a valid Date");
}

console.log(isValidDate(new Date("invalid"))); //‎ هەڵە
console.log(isValidDate("2025-12-22")); //‎ هەڵە

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isValidDate(value)`
