# isHexadecimal

## وەسف

`isHexadecimal` پشکنین دەکات کە ئایا بەهایەکی دیاریکراو لیتراڵێکی سترینگی هێکسادێسیمالە بە پێشگرێکی ناچار `0x`/`0X`.

### دۆخی بەکارهێنان

`isHexadecimal` بەکاربهێنە بۆ دڵنیایی‌کردنەوەی بەهاکانی ڕێکخستن، خانەکانی payload ـی API، یان ئارگیومێنتەکانی CLI کە
دەبێت وەک لیتراڵی سترینگی هێکسادێسیمال پێشکەش بکرێن (وەک ID ـەکان، ماسکەکان، یان ناونیشانەکان) و نابێت بۆشایی
دەوروبەرییان تێدا بێت.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isHexadecimal` بەکاربهێنە کاتێک پێویستت بە دڵنیایی‌کردنەوەی تێچووی بەکارهێنەر یان داتای serialize کراو هەیە وەک
> سترینگێکی لیتراڵی هێکسادێسیمال بە شێوەیەکی توند (لەگەڵ پێشگرەکەی `0x`/`0X`) پێش ئەوەی parse یان گۆڕینی بکەیت.

### سوودەکان

- دڵنیایی دەکاتەوە کە بەهایەک سترینگە و لەگەڵ فۆرماتێکی توندی لیتراڵی هێکسادێسیمال دەگونجێت (پێویستی بە پێشگرەکەی `0x`/
  `0X` هەیە).
- سترینگەکان ڕەت دەکاتەوە کە بۆشایی پێشەوە یان دوایەوەیان هەیە، یارمەتیدەدات لە دوورخستنەوەی قبوڵکردنی هەڵەیی داتای
  پڕکراو.
- پشتگیری لە نیشانەی هەڵبژاردەیی دەکات و بۆ پێشگر و ژمارەکان case-insensitive ـە، بە شێوەیەکی پێشبینی‌کراو `true`/
  `false` دەگەڕێنێتەوە.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isHexadecimal(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەبێت پشکنین بکرێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); //‎ ڕاست
isHexadecimal("-0Xff"); //‎ ڕاست
isHexadecimal("1A2B"); //‎ هەڵە (پێشگر نەماوە)
isHexadecimal(" 0x1A2B"); //‎ هەڵە (بۆشایی لە سەرەتا)
isHexadecimal(0x1a2b); //‎ هەڵە (ڕیزەنووس نییە)
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isHexadecimal(value)`
