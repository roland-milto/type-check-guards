# areTrue

## وەسف

دەپشکنێت کە ئایا ئارایەکی نابەتاڵ تەنها بەها بولیەنی `true` لەخۆ دەگرێت.

### دۆخی بەکارهێنان

`areTrue` بەکاربهێنە بۆ دڵنیابوون لەوەی کۆمەڵێک پێش‌مەرج یان feature flag هەموویان چالاکن (هەموو بەهاکان `true`ن) پێش
ئەوەی بەردەوام بیت، لەگەڵ ئەوەشدا ئارایە بەتاڵەکان یان هەڵەدارەکان وەک نەدڵنیا/نەسەلمێنراو وەردەگیرێن (`false`).

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areTrue` بۆ ئارایەکی بەتاڵ و بۆ ئارایەکان کە هەر بەهایەکیان بە شێوەیەکی توندوتیژ `true` نەبێت، `false` دەگەڕێنێتەوە.

### سوودەکان

- تەنها ئەو کاتە `true` دەگەڕێنێتەوە کە هەموو ئەندامەکان بە شێوەیەکی توندوتیژ `true` بن و ئارایەکە بەتاڵ نەبێت.
- زۆر زوو وەستێت: هەر کاتێک یەکەم جار بەهایەکی نا-`true` بدۆزرێتەوە، دەگەڕێنێتەوە `false`.
- هەڵەیەکان ڕەت دەکاتەوە (نا-ئارایەکان یان ئارایە بەتاڵەکان) بە گەڕاندنەوەی `false`.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areTrue(array)`

پارامەتەرەکان:

- `array`: ئەو ئارایەیە کە دەپشکنرێت بۆ ئەوەی هەموو بەهاکان `true` بن.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areTrue } from "@type-check/guards";

const a = areTrue([true, true, true]);
const b = areTrue([true, false, true]);
const c = areTrue([]);
const d = areTrue([true, "string" as unknown, true]);

console.log(a, b, c, d);
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areTrue(array)`
