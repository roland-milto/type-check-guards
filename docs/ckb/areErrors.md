# areErrors

## وەسف

دەپشکنێت کە ئایا ڕیزەیەک نابەتاڵە و تەنها ئۆبجێکتەکانی `Error` تێدایە، و `true` یان `false` دەگەڕێنێتەوە.

### دۆخی بەکارهێنان

پشتڕاستکردنەوەی ئەوە کە `unknown[]` ـێکی لە کاتی جێبەجێکردنەوەدا پێدراوە (وەک کۆکراوەی شکسته‌کان، ئەنجامەکانی
پشتڕاستکردنەوە، یان داتای deserialize کراو) لیستێکی نابەتاڵە لە ئۆبجێکتەکانی `Error` ـە پێش ئەوەی دەست بە تێپەڕاندن،
تۆمارکردن، یان دووبارە هەڵدانەوەی بکەیت.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areErrors` تەنها ئەو کاتە `true` دەگەڕێنێتەوە کە ڕیزەکە پڕ بێت و هەموو توخمێک `Error` بێت؛ بۆ ڕیزەی بەتاڵ یان ئەگەر
> هەر توخمێک `Error` نەبێت `false` دەگەڕێنێتەوە.

### سوودەکان

- دڵنیایی دەدات کە هەر توخمێک نموونەیەکی `Error` ـە، کە ڕێگە بە مامەڵەکردنی پارێزراو لە هەڵە و تۆمارکردن دەدات.
- ڕیزە بەتاڵەکان ڕەت دەکاتەوە، وەک ڕێگری لەوەی دۆخی «هیچ هەڵەیەک نییە» بە هەڵە وەک لیستی هەڵەی دروست وەرگیرێت.
- وەک پاسەوانێکی کاتی-جێبەجێکردن باش کار دەکات کاتێک مامەڵە لەگەڵ دەستپێکەوتەکانی `unknown[]` دەکەیت (وەک لە API ـەکان
  یان بلۆکی `catch`).

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areErrors(array)`

پارامەتەرەکان:

- `array`: ئەو ڕیزەیەی دەبێت بپشکنرێت بۆ بوونی تەنها ئۆبجێکتەکانی `Error`.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areErrors } from "@type-check/guards";

const value: unknown = [new Error("error1"), new TypeError("error2")];

if (Array.isArray(value) && areErrors(value)) {
  //‎‎ value ئەڕایەکەی بێ بەتاڵە لە ئۆبجێکتی Error
  for (const err of value) {
    console.error(err.name, err.message);
  }
} else {
  console.log("Not a non-empty Error[]");
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areErrors(array)`
