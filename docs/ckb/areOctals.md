# areOctals

## وەسف

`areOctals` دیاری دەکات ئایا بەهای پێشکەشکراو ئارایەیەکی بەتاڵ نییە لە سترینگی ئۆکتالی دروست.

### دۆخی بەکارهێنان

`areOctals` بەکاربهێنە کاتێک داتای بەکارهێنەر، بەهاکانی ڕێکخستن، یان payload ـی API پشتڕاست دەکەیتەوە کە دەبێت ئۆکتال
لیتیراڵی تێدابێت (بۆ نموونە مۆدی مۆڵەتی فایل وەک `0o755`) و دەتەوێت ئارایە بەتاڵەکان یان هەر دانەیەکی نادروست ڕەت
بکەیتەوە بە گەڕاندنەوەی `false`.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areOctals` بەکاربهێنە بۆ دڵنیابوون لەوەی `unknown[]` ـێکی بەتاڵ نییە هەیە کە هەر دانەیەکی تێیدا سترینگی ئۆکتالی
> دروستە پێش ئەوەی بیگۆڕیت (بۆ نموونە بە `Number(...)` یان پارسکردنی تایبەت).

### سوودەکان

- دڵنیایی دەکاتەوە کە بەهایەک ئارایەیەکی بەتاڵ نییە و هەموو ئەندامەکانی سترینگی ئۆکتالن، و تەنها کاتێک `true`
  دەگەڕێنێتەوە کە هەموو دانەکان تێپەڕبن.
- زوو دەوەستێت: هەر کاتێک ئەندامێکی نا-ئۆکتال بدۆزرێتەوە دەستبەجێ `false` دەگەڕێنێتەوە.
- وەک پاسەوانێک پێش پارسکردن یان گۆڕینی سترینگی ئۆکتال بەکاردێت بۆ دوورخستنەوەی هەڵەکانی کاتی جێبەجێکردن و مامەڵەکردنی
  ناهاوسەنگی لەسەر داتای هاتوو.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areOctals(array)`

پارامەتەرەکان:

- `array`: ئەو بەهایەی دەبێت پشکنرێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  //‎‎ value ئەڕایەکەیەکی نەبەتاڵە لە ڕیزبەندییەکانی ژمارەی ئۆکتال
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areOctals(array)`
