# isFloat

## وەسف

`isFloat` دیاری دەکات ئایا `value` ـێکی دیاریکراو ژمارەیەکی فڵۆتی سنووردارە (ژمارەیەک کە ژمارە تەواو نییە) یان نا.

### دۆخی بەکارهێنان

پشتڕاستکردنەوەی ژمارەی دابینکراو لەلایەن بەکارهێنەر کاتێک بەها فڕاکشنی پێویستە (وەک نرخەکان، پێوانەکان، ڕێژەکان) و
ڕەتکردنەوەی ژمارە تەواوەکان، `NaN`، و ژمارە نا-سنووردارەکان.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isFloat` بەکاربهێنە کاتێک پێویستتە تەنها ژمارەی سنووردار و نا-تەواو وەربگریت؛ ژمارە تەواوەکان و ژمارە نا-سنووردارەکان
> ڕەت دەکاتەوە.

### سوودەکان

- تەنها بۆ ژمارەیەکی سنووردار و نا-تەواو (`true`) دەگەڕێنێتەوە (ژمارە تەواوەکان، `NaN`، `Infinity`، و `-Infinity`
  لەخۆناگرێت).
- لەگەڵ هەر جۆرێک لە هاتنەژوورەوە کار دەکات (`unknown`) و بە سەلامەتی تەنها بە پشکنینی `typeof value === "number"` باریک
  دەکاتەوە.
- پارێزەرە ژمارەییە ناوخۆییەکان (`Number.isInteger`, `Number.isFinite`) بەکاردەهێنێت بۆ هەڵسوکەوتێکی پێشبینی‌کراو.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isFloat(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی کە دەپشکنرێت بۆ ئەوەی بزانرێت ئایا ژمارەی فڵۆت (floating-point) ـە.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isFloat } from "@type-check/guards";

const inputs: unknown[] = [3.14, -0.1, 1e-7, 42, "3.14", NaN, Infinity];

for (const value of inputs) {
  if (isFloat(value)) {
    //‎‎ value ژمارەیە لە کاتی جێبەجێکردندا؛ سنووردارە و ژمارەی تەواو نییە
    const rounded = value.toFixed(2);
    console.log("float:", value, "rounded:", rounded);
  } else {
    console.log("not a float:", value);
  }
}
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isFloat(value)`
