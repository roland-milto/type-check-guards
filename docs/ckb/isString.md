# isString

## وەسف

`isString` دیاری دەکات کە ئایا بەهایەکی دیاریکراو ڕیزەنووسە یان نا.

### دۆخی بەکارهێنان

لە runtime ـدا تێچوونی بەکارهێنەر، خانەکانی payload ـی API، یان بەهاکانی ڕێکخستن پشتڕاست بکەوە بۆ دڵنیابوون لەوەی بەهاکە
ڕیزەنووسە پێش ئەوەی کردارەکانی ڕیزەنووس بەکاربهێنیت (وەک trimming، splitting، گۆڕینی حاڵەت).

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isString` بەکاربهێنە بۆ پشتڕاستکردنەوەی `unknown` یان بەهاکانی بە جۆری لاواز پێش بانگکردنی مێتۆدەکانی ڕیزەنووس؛ تەنها
> کاتێک `true` دەگەڕێنێتەوە کە `typeof value === "string"`.

### سوودەکان

- پشکنینێکی سادە و خێرا بە بەکارهێنانی `typeof`.
- ئەنجامێکی بۆڵی پێشبینی‌کراو دەگەڕێنێتەوە: `true` بۆ ڕیزەنووسەکان، ئەگەرنا `false`.
- بۆ هەردوو ڕیزەنووسی بەتاڵ و نابەتاڵ کاردەکات.
- وەک پارێزەری runtime ـێکی سووک سوودمەندە پێش ئەنجامدانی کردارە تایبەت بە ڕیزەنووس.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isString(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەبێت تاقی بکرێتەوە بۆ جۆری ڕیزەنووس.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isString } from "@type-check/guards";

const input: unknown = "Hello World";

if (isString(input)) {
  //‎‎ input لێرە سترینگە
  console.log(input.toUpperCase());
} else {
  console.log("Not a string");
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isString(value)`
