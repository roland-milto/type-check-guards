# isNaN

## وەسف

دیاری دەکات کە ئایا `value` ـی پێشکەشکراو `NaN` ـە لە جۆری `number` ـدا بەبێ گۆڕینی سترینگ.

### دۆخی بەکارهێنان

ڕێکخستنی هاتووچۆی بێ متمانە یان بە شێوەی شڵ (وەک payload ـی API، بەهای فۆرم، JSON ـی پارسکراو) بۆ دۆزینەوەی بەهای
تایبەتی `NaN` و مامەڵەکردن لەگەڵی بە شێوەی ڕوون، لە کاتێکدا هاتووچۆی ناژمارە وەک `NaN` ناژمێردرێت.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isNaN` بەکاربهێنە کاتێک پێویستت بە دۆزینەوەی بەهای تایبەتی ژمارەیی `NaN` هەیە، لەگەڵ دڵنیابوون لەوەی هاتووچۆکە
> بەراستی `number` ـە (هیچ گۆڕینی سترینگ بۆ ژمارە ناکرێت).

### سوودەکان

- پشکنینی ئەوە دەکات کە ئایا بەهایەک `NaN` ـە یان نا، بەبێ ئەوەی بەها ناژمارەکان (وەک سترینگ) بگۆڕێتە ژمارە.
- `true` تەنها بۆ ئەو بەهایانە دەگەڕێنێتەوە کە هەردووکیان جۆری `number` ـن و `NaN` ـن.
- بۆ هاتووچۆی `unknown` پارێزراوە و دوور دەکەوێتەوە لە هەڵە-ئەنجامەکان لە گۆڕانکارییە ناڕاستەوخۆکان.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isNaN(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەبێت پشکنرێت کە ئایا `NaN` ـە لە جۆری `number` ـدا.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); //‎ ڕاست
console.log(isNaN(b)); //‎ هەڵە
console.log(isNaN(c)); //‎ هەڵە

if (isNaN(a)) {
  //‎‎ a ژمارەیە و بە تایبەتی NaN ـە
}
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isNaN(value)`
