# areSymbols

## وەسف

دەپشکنێت کە ئایا هاتووچۆکە ئارایەکی پڕە کە ئەندامەکانی هەموویان سیمبۆڵن، و `true` یان `false` دەگەڕێنێتەوە.

### دۆخی بەکارهێنان

پشتڕاستکردنەوە بکە کە خانەیەکی ڕێکخستن (بۆ نموونە، لیستێک لە کلیلی یەکتا کە وەک سیمبۆڵ نیشان دەدرێن) ئارایەکی بەتاڵ
نەبێت و تەنها سیمبۆڵی تێدا بێت پێش بەکارهێنانی لە API ـەکاندا کە `symbol[]` داوای دەکەن.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areSymbols` بەکاربهێنە بۆ پشتڕاستکردنەوەی هاتووچۆی نەناسراو پێش ئەوەی وەک `symbol[]` مامەڵەی لەگەڵ بکەیت؛ بۆ
> نا-ئارایەکان و ئارایە بەتاڵەکان `false` دەگەڕێنێتەوە.

### سوودەکان

- تەنها کاتێک `true` دەگەڕێنێتەوە کە هاتووچۆکە ئارایەکی بەتاڵ نەبێت و هەموو ئەندامەکانیش سیمبۆڵ بن.
- ڕێگری لە دەرئەنجامی هەڵە دەکات بە ڕەتکردنەوەی نا-ئارایەکان و ئارایە بەتاڵەکان لە ڕێگەی پشکنینی ناوخۆی filled-array.
- وەک پارێزەری جۆری کاتی-جێبەجێکردن بەسوودە بۆ پشتڕاستکردنەوەی لیستی تەنها-سیمبۆڵ پێش پرۆسەکردنی دواتر.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areSymbols(array)`

پارامەتەرەکان:

- `array`: ئەو ئارایەیە کە دەبێت بپشکنرێت بۆ ئەوەی بزانرێت ئەندامەکانی سیمبۆڵن.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  //‎‎ a لە کاتی ڕەنکردندا ئارایەکی تەنها-سیمبوڵە
  const first = a[0];
  console.log(typeof first); //‎ "symbol"
}

console.log(areSymbols(b)); //‎ false
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areSymbols(array)`
