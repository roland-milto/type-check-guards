# isInteger

## وەسف

دیاری دەکات کە `value` ـێکی دیاریکراو ژمارەیەکی تەواوی سەلامەتە یان نا.

### دۆخی بەکارهێنان

هاتووچۆی بێ متمانە پشتڕاست بکەوە (وەک query params، JSON payloads، environment variables) پێش ئەوەی وەک ژمارەیەکی تەواو
بەکاری بهێنیت بۆ ئیندێکسی ئارایە، پەڕەکردن (pagination)، ژمێرەرەکان، یان database IDs.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isInteger` بەکاربهێنە بۆ پشتڕاستکردنەوەی هاتووچۆی نەناسراو پێش ئەوەی وەک ژمارەیەکی تەواوی ژمارەیی مامەڵەی لەگەڵ
> بکەیت؛ تەنها ئەو کاتە `true` دەگەڕێنێتەوە کە `typeof value === "number"` و `Number.isSafeInteger(value)`.

### سوودەکان

- هەردوو جۆر و سەلامەتی ژمارەیی پشکنین دەکات: تەنها ئەو کاتە `true` دەگەڕێنێتەوە کە هاتووچۆکە ژمارە بێت و ژمارەیەکی
  تەواوی سەلامەت بێت.
- لە هەڵە باوەکان لەگەڵ گۆڕینی ژمارەیی ڕێگری دەکات: ڕیزەنووسەکان وەک "5" بە دروستی `false` دەگەڕێننەوە.
- ژمارە ناتەواوەکان و ژمارە تەواوە ناسەلامەتەکان ڕەت دەکاتەوە، بۆیە گونجاوە بۆ ID، ژمێرەرەکان، و ئیندێکسکردنی ئارایە.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isInteger(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی کە دەبێت بپشکنرێت بۆ ئەوەی ژمارەیەکی تەواوە یان نا.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      //‎ ڕاستە
const b = isInteger(-100);   //‎ ڕاستە
const c = isInteger("5");    //‎ هەڵە
const d = isInteger(5.5);    //‎ هەڵە
const e = isInteger(null);   //‎ هەڵە

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isInteger(value)`
