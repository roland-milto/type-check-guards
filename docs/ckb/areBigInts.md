# areBigInts

## وەسف

`areBigInts` دیاری دەکات کە ئایا بەهایەک ئارایەکی نا-بەتاڵە کە تەنها بەهاکانی `bigint` تێدایە.

### دۆخی بەکارهێنان

دڵنیابوون لە داتای نەناسراو (وەک داتای وەک-JSONی خوێندراو، payload ـی API، یان پارامەتەرەکانی فەنکشن کە بە `unknown`
تایپ کراون) بۆ ئەوەی دڵنیابیت کە ئارایەکی نا-بەتاڵە لە بەهاکانی `bigint` پێش پڕۆسەکردن؛ تەنها ئەو کاتە `true`
دەگەڕێنێتەوە کە هەموو توخمەکان `bigint` بن، ئەگەرنا `false`.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areBigInts` بەکاربهێنە وەک پارێزەری runtime پێش ئەنجامدانی کارەکانی تەنها-`bigint` (وەک ژمێریاری، بەراوردکردن) لەسەر
> داتای نەناسراو.

### سوودەکان

- دڵنیایی دەکات کە هەر توخمێک `bigint` ـە، تەنها ئەو کاتە `true` دەگەڕێنێتەوە کە تەواوی ئارایەکە هاوشێوە بێت.
- بە شێوەیەکی بنەڕەتی ئارای نەبوون و ئارای بەتاڵ ڕەت دەکاتەوە (لە ڕێگەی `isFilledArray`)، بۆ ڕێگریکردن لە پەسەندکردنی
  هەڵەیی داتای نادروست.
- شکستی خێرا: هەر کاتێک توخمێکی نا-`bigint` بدۆزێتەوە، دەستبەجێ `false` دەگەڕێنێتەوە.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areBigInts(array)`

پارامەتەرەکان:

- `array`: ئەو بەهایەی بۆ پشکنین.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areBigInts } from "@type-check/guards";

const a: unknown = [10n, 20n];
const b: unknown = [10n, 20];
const c: unknown = [];

console.log(areBigInts(a)); //‎ ڕاست
console.log(areBigInts(b)); //‎ هەڵە
console.log(areBigInts(c)); //‎ هەڵە
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areBigInts(array)`
