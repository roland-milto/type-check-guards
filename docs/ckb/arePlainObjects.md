# arePlainObjects

## وەسف

دەپشکنێت کە ئایا هەموو توخمەکانی ئارایەکە ئۆبجێکتی سادەن، و تەنها ئەگەر هەر توخمێک شایستە بێت `true` دەگەڕێنێتەوە.

### دۆخی بەکارهێنان

داتای دەرەکی یان بێ-جۆر (وەک JSONی پارسکراو، payloadی API، ناردنی فۆرم) پشتڕاست بکەوە بۆ ئەوەی دڵنیابیت کە ئارایەیەکی
نا-بەتاڵت وەرگرتووە کە هەر تێچوونێک تێیدا ئۆبجێکتی سادەیە پێش ئەوەی دەست بە تێپەڕاندن و خوێندنەوەی تایبەتمەندییەکان
بکەیت.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `arePlainObjects` بەکاربهێنە بۆ پشتڕاستکردنەوەی هاتووچۆی نەناسراو پێش ئەوەی وەک `Record<string, unknown>[]` (یان شێوەی
> ئۆبجێکتی توندتر) لە TypeScript دا مامەڵەی پێ بکەیت.

### سوودەکان

- دڵنیایی دەکات کە هەر توخمێک لە ئارایەی هاتوو تەنها ئۆبجێکتێکی سادەیە، و تەنها کاتێک `true` دەگەڕێنێتەوە کە هەموو
  دانەکان هاوشێوەبن.
- هاتووچۆی نادروست زوو ڕەت دەکاتەوە (نە-ئارایەکان یان ئارایە بەتاڵەکان) بە گەڕاندنەوەی `false`.
- هەردوو ئۆبجێکتەکانی object-literal و ئۆبجێکتەکانی `Object.create(null)` وەک ئۆبجێکتی سادەی دروست هەژمار دەکات.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `arePlainObjects(array)`

پارامەتەرەکان:

- `array`: ئەو ئارایەیە کە دەبێت بپشکنرێت بۆ توخمەکانی ئۆبجێکتی سادە.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { arePlainObjects } from "@type-check/guards";

const a = arePlainObjects([{ a: 1 }, { b: 2 }]); //‎ ڕاست
const b = arePlainObjects([{}, Object.create(null)]); //‎ ڕاست
const c = arePlainObjects([{ a: 1 }, 2 as unknown]); //‎ هەڵە
const d = arePlainObjects([] as unknown[]); //‎ هەڵە
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.arePlainObjects(array)`
