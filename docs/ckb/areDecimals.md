# areDecimals

## وەسف

پشکنین دەکات کە ئایا هەموو ئەندامەکان لە ئەرەیەکدا ژمارەی دەهەمیین و ئەرەکە پڕە، و `true` یان `false` دەگەڕێنێتەوە.

### دۆخی بەکارهێنان

پشتڕاستکردنەوەی لیستەکانی پێشکەشکراوی بەکارهێنەر (وەک ستوونەکانی CSV یان تێخستنەکانی فۆڕم) بۆ دڵنیابوون لەوەی ئەرەکە
بەتاڵ نییە و هەر تێکچوونێک بەهایەکی دەهەمییە پێش پارسکردن یان هەژمارکردن.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areDecimals` بەکاربهێنە کاتێک پێویستت بە پشکنینێکی خێرای بولیانی هەیە کە `unknown[]` بەتاڵ نەبێت و هەموو ئەندامەکانیش
> وێنەیەکی ژمارەی دەهەمیین بن.

### سوودەکان

- دڵنیایی دەکاتەوە کە تێچوونەکە پڕە لە ئەرەیەک پێش ئەوەی بڕگەکان پشتڕاست بکاتەوە، وەکە ڕێگری دەکات لە وەرگرتنی هەڵەیی
  لیستی بەتاڵ.
- هەموو ئەندامێک بە `isDecimal` پشتڕاست دەکاتەوە، بۆیە تێکەڵبوون یان بەها نادروستەکان دەبنە هۆی ئەنجامی دەستبەجێی
  `false`.
- ئەنجامێکی سادەی بولیانی (`true`/`false`) پێشکەش دەکات کە گونجاوە بۆ گاردەکان و شێوازەکانی پشتڕاستکردنەوەی
  زوو-گەڕانەوە.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areDecimals(array)`

پارامەتەرەکان:

- `array`: ئەو ئەرەیەی دەبێت پشکنرێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); //‎ ڕاست
console.log(areDecimals(b)); //‎ هەڵە
console.log(areDecimals(c)); //‎ هەڵە
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areDecimals(array)`
