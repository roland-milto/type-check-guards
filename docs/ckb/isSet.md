# isSet

## وەسف

دیاری دەکات ئایا بەهایەکی دیاریکراو `Set` ـە.

### دۆخی بەکارهێنان

دڵنیابوون لە تێچوونەکان لە سەرچاوە دەرەکییەکان (وەک پارسکردنی JSON، تێچوونی بەکارهێنەر، یان API ـەکانی لای سێیەم) بۆ
ئەوەی دڵنیابیت بەهایەک `Set` ـە پێش ئەنجامدانی کارەکانی `Set`.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isSet` بەکاربهێنە بۆ سنووردارکردنی بەهاکانی `unknown` پێش ئەوەی API ـە تایبەتەکانی `Set` وەک `.add`، `.has`، یان
`.size` بانگ بکەیت.

### سوودەکان

- پشکنینێکی سادەی کاتی جێبەجێکردن دابین دەکات بۆ دڵنیابوون لەوەی ئایا بەهایەک `Set` ـە.
- یارمەتی دەدات هەڵەکانی جۆر (type errors) ڕێگری لێبکرێت بە ڕێگەی دابەشکردنی زوو کاتێک بەهایەک `Set` نییە.
- لەگەڵ هەر ناوەڕۆکی `Set` ـێک کار دەکات (بەتاڵ یان پڕ) و بە شێوەیەکی یەکسان `true`/`false` دەگەڕێنێتەوە.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isSet(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی بۆ پشکنین.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  //‎‎ a لە کاتی جێبەجێکردندا Set ـە
  console.log(a.size);
}

console.log(isSet(b)); //‎ هەڵە
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isSet(value)`
