# isMap

## وەسف

دەپشکنێت ئایا `value` ـی دراو `Map` ـە، ئەگەر وابێت `true` دەگەڕێنێتەوە و ئەگەر نا `false`.

### دۆخی بەکارهێنان

کاتێک بەهایەکی `unknown` وەردەگریت (وەک لە پارسکردنی JSON، API ـە دەرەکییەکان، یان هاتنەژوورەوەی بەکارهێنەر) و پێویستتە
دڵنیابیت کە `Map` ـە پێش ئەنجامدانی کارەکانی `Map`، `isMap` بەکاربهێنە.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `isMap` پارێزەرێکی کاتی-جێبەجێکردنە کە ئەگەر بەکە `Map` بێت `true` دەگەڕێنێتەوە و ئەگەر نا `false`؛ بەکاری بهێنە بۆ
> تاسککردنی `unknown` پێش بانگکردنی API ـەکانی `Map`.

### سوودەکان

- پشکنینێکی خێرای کاتی-جێبەجێکردن دابین دەکات بۆ ئەوەی بزانرێت ئایا بەهایەک `Map` ـە.
- یارمەتی دەدات هەڵەکانی جۆر (type errors) ڕوونەدەن بە پاراستنی ڕێگاکانی کۆد کە پێویستیان بە مێتۆدەکانی `Map` وەک `get`،
  `set`، و `has` هەیە.
- وەک هەنگاوێکی پشتڕاستکردنەوەی سووک باش کاردەکات کاتێک لەگەڵ هاتنەژوورەوەی `unknown` کاردەکەیت.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `isMap(value)`

پارامەتەرەکان:

- `value`: ئەو بەهایەی دەپشکنرێت.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { isMap } from "@type-check/guards";

const input: unknown = new Map<string, number>([["a", 1]]);

if (isMap(input)) {
  input.set("b", 2);
  const a = input.get("a");
  console.log(a);
} else {
  console.log("Not a Map");
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.isMap(value)`
