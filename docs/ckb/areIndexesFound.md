# areIndexesFound

## وەسف

`areIndexesFound` دەپشکنێت کە ئایا بەهایەک ئارەیەکی نەپووچە و هەموو ئەندامەکانی ئیندێکسە دروستن یان نا، ئەگەر وابێت
`true` دەگەڕێنێتەوە و ئەگەر نا `false`.

### دۆخی بەکارهێنان

دڵنیابوون لە داتای پێشکەشکراوی بەکارهێنەر یان داتای دەرەکی (وەک JSONی پارسکراو) کە پێشبینی دەکرێت لیستێک لە ئیندێکسەکان
بێت، پێش ئەوەی بەکاری بهێنیت بۆ دەستگەیشتن یان بڕینەوەی ئارەکان.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areIndexesFound` بەکاربهێنە بۆ دڵنیابوون لە هاتووچۆی نەناسراو پێش ئەوەی ئەندامەکانی وەک ئیندێکسی ئارەی مامەڵەی لەگەڵ
> بکرێت؛ بۆ ئارەی بەتاڵ و بۆ ئارەیەک کە بەهای نائێندێکس تێدایە `false` دەگەڕێنێتەوە.

### سوودەکان

- تەنها ئەو کاتە `true` دەگەڕێنێتەوە کە هاتووچۆکە ئارەیەکی پڕ بێت و هەموو ئەندامەکانیش ئیندێکسێکی دروست بن.
- زوو دەوەستێت: هەر کاتێک ئەندامێکی نائێندێکس ببینێت، دەستبەجێ `false` دەگەڕێنێتەوە.
- وەک پاسەوانێک بەسوودە پێش ئەوەی بەهاکان وەک شوێنی ئارەی یان ئۆفسێت بەکاربهێنرێن.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areIndexesFound(array)`

پارامەتەرەکان:

- `array`: ئارەیەکە کە دەبێت بپشکنرێت بۆ گونجانی ئیندێکس.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areIndexesFound } from "@type-check/guards";

const a: unknown[] = [0, 1, 2];
const b: unknown[] = [0, "a", 2];
const c: unknown[] = [];

console.log(areIndexesFound(a)); //‎ ڕاست
console.log(areIndexesFound(b)); //‎ هەڵە
console.log(areIndexesFound(c)); //‎ هەڵە

if (areIndexesFound(a)) {
  //‎‎ لێرەدا، `a` پشتڕاست دەکرێتەوە کە ئارایەکی پڕە لە ئیندێکسەکان.
  const firstIndex = a[0];
  console.log(firstIndex);
}

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areIndexesFound(array)`
