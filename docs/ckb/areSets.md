# areSets

## وەسف

دەپشکنێت کە ئایا ئارایەکی دیاریکراوی بەتاڵ نەبێت تەنها نموونەکانی `Set` لەخۆدەگرێت، ئەگەر وا بێت `true` دەگەڕێنێتەوە و
ئەگەر نا `false`.

### دۆخی بەکارهێنان

دڵنیابوون لەوەی بەهایەک (وەک لە هاتووچۆی بەکارهێنەر، JSON parsing، یان API ـە دەرەکییەکان) ئارایەکی بەتاڵ نەبێت لە تەنها
ئۆبجێکتەکانی `Set` پێش ئەوەی هەر سێتێک پرۆسەس بکەیت.

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areSets` بەکاربهێنە بۆ دڵنیابوون لە هاتووچۆی نەناسراو پێش ئەوەی بگەڕێیتەوە و API ـەکانی `Set` (وەک `.size`، `.has`،
`.add`) لەسەر هەر ئەندامێک بانگ بکەیت.

### سوودەکان

- `true` دەگەڕێنێتەوە تەنها کاتێک کە هاتووچۆکە ئارایەکی بەتاڵ نەبێت و هەموو ئەندامێک نموونەیەکی `Set` بێت.
- ڕێگری دەکات لە دەرئەنجامی هەڵە بۆ ئارایە بەتاڵەکان بەوەی `false` دەگەڕێنێتەوە کاتێک ئارایەکە هیچ ئەندامێکی نییە.
- وەک پاسەوانێکی کاتی-جێبەجێبوون بەسوودە پێش ئەنجامدانی کردارە تایبەتەکانی `Set` لەسەر هەر ئەندامێک.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areSets(array)`

پارامەتەرەکان:

- `array`: ئەو ئارایەیە کە دەبێت بپشکنرێت بۆ بوونی نموونەکانی `Set`.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  //‎‎ a لە کاتی جێبەجێکردندا ئارایەکە لە نموونەکانی Set پێکهاتووە
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); //‎ هەڵە
console.log(areSets(c)); //‎ هەڵە

```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areSets(array)`
