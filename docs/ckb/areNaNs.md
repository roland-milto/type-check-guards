# areNaNs

## وەسف

`areNaNs` دەکاتەوە کە ئایا هەموو ئەندامەکانی ئارایەکە `NaN`ن و تەنها ئەگەر هەموو ئەندامەکان `NaN` بن `true`
دەگەڕێنێتەوە.

### دۆخی بەکارهێنان

پشتڕاستکردنەوەی داتای هاتوو کاتێک `NaN` وەک بەهای نیشانە (sentinel) بەکاردەهێنرێت و دەبێت دڵنیابیت کە تەواوی ئارایەکە
تەنها لە `NaN` پێکهاتووە (بۆ نموونە، دۆزینەوەی زنجیرەی ژمارەیی کە هەمووی ونە).

> **تێبینی بۆ بەکارهێنەرانی TypeScript:**
>
> `areNaNs` بەکاربهێنە کاتێک پێویستت بە پشتڕاستکردنەوەیە کە ئارایەکە تەنها بەهای ژمارەیی `NaN`ی تێدایە (بێ گۆڕینی
> ڕیزەنووس بۆ ژمارە).

### سوودەکان

- تەنها کاتێک `true` دەگەڕێنێتەوە کە هەموو ئەندامەکان `NaN` بن (پشکنینی توندی هەموو-ئەندامەکان).
- ڕیزەنووسەکان بە ژمارە ناگۆڕێت؛ بەهاکانی وەک "NaN" هێشتا نا-`NaN` دەمێننەوە و ئەنجامەکە دەکەنە `false`.
- بۆ ئارایە نە پڕکراوەکان `false` دەگەڕێنێتەوە، وەک پاراستن لە `true`ی هەڵە لەسەر دەرچوونی بەتاڵ.

## بەکارهێنان

### ڕستەسازی

فەنکشەن:

- `areNaNs(array)`

پارامەتەرەکان:

- `array`: ئەو ئارایەیە کە دەبێت بپشکنرێت بۆ بەهاکانی `NaN`.

### هاوردەکردنی فەنکشەن بە شێوەی ناوخۆیی

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); //‎ ڕاست
const b = areNaNs([NaN, 1, NaN]); //‎ هەڵە
const c = areNaNs([NaN, "NaN", NaN]); //‎ هەڵە
const d = areNaNs([NaN, null, NaN]); //‎ هەڵە
const e = areNaNs([] as unknown[]); //‎ هەڵە
```

### هاوردەکردنی ئۆبجێکت بە شێوەی گشتی

بۆ هاوردەکردنی فەنکشەنەکان وەک مێتۆدی ئۆبجێکتی گشتی, ئەمە بەکاربهێنە:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پاشان ئەم مێتۆدە بە شێوەی گشتی بەردەست دەبێت:

- `Type.areNaNs(array)`
