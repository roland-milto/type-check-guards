# isDecimal

## ਵਰਣਨ

`isDecimal` ਜਾਂਚਦਾ ਹੈ ਕਿ ਕੋਈ ਮੁੱਲ ਬਿਨਾਂ ਅੱਗੇ/ਪਿੱਛੇ ਵ੍ਹਾਈਟਸਪੇਸ ਦੇ ਅਤੇ ਵੈਧ ਦਸ਼ਮਲਵ ਫਾਰਮੈਟ ਨਾਲ ਦਸ਼ਮਲਵ ਸਟਰਿੰਗ ਪ੍ਰਤੀਨਿਧਤਾ ਹੈ
ਜਾਂ ਨਹੀਂ।

### ਵਰਤੋਂ ਦਾ ਮਾਮਲਾ

ਫਾਰਮ ਫੀਲਡਾਂ, API ਪੇਲੋਡਾਂ, ਜਾਂ ਕਨਫਿਗਰੇਸ਼ਨ ਮੁੱਲਾਂ ਨੂੰ ਵੈਲੀਡੇਟ ਕਰੋ ਜੋ ਦਸ਼ਮਲਵ ਸਟਰਿੰਗ (ਚੋਣਵਾਂ ਤੌਰ 'ਤੇ ਸਾਈਨ ਸਮੇਤ) ਵਜੋਂ ਬਿਨਾਂ
ਕਿਸੇ ਆਲੇ-ਦੁਆਲੇ ਵ੍ਹਾਈਟਸਪੇਸ ਦੇ ਦਿੱਤੇ ਜਾਣੇ ਚਾਹੀਦੇ ਹਨ, ਪਾਰਸ ਜਾਂ ਸਟੋਰ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ।

> **TypeScript ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਸੰਕੇਤ:**
>
> `isDecimal` ਨੂੰ ਯੂਜ਼ਰ ਇਨਪੁੱਟ ਨੂੰ ਕਨਵਰਟ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ (ਜਿਵੇਂ `Number(value)` ਨਾਲ) ਵੈਲੀਡੇਟ ਕਰਨ ਲਈ ਵਰਤੋ, ਖਾਸ ਕਰਕੇ ਜਦੋਂ
> ਵ੍ਹਾਈਟਸਪੇਸ ਨੂੰ ਰੱਦ ਕਰਨਾ ਲਾਜ਼ਮੀ ਹੋਵੇ।

### ਫਾਇਦੇ

- ਸਖ਼ਤੀ ਨਾਲ ਜਾਂਚਦਾ ਹੈ ਕਿ ਇਨਪੁੱਟ ਇੱਕ ਸਟਰਿੰਗ ਹੈ ਅਤੇ ਦਸ਼ਮਲਵ-ਲਿਟਰਲ ਪੈਟਰਨ ਨਾਲ ਮੇਲ ਖਾਂਦਾ ਹੈ।
- ਅਸਪਸ਼ਟ ਪਾਰਸਿੰਗ ਤੋਂ ਬਚਣ ਲਈ ਅੱਗੇ ਅਤੇ ਪਿੱਛੇ ਵਾਲੀ ਵ੍ਹਾਈਟਸਪੇਸ (ਕੰਟਰੋਲ ਅੱਖਰਾਂ ਸਮੇਤ) ਨੂੰ ਰੱਦ ਕਰਦਾ ਹੈ।
- ਰੇਗੇਕਸ ਚਲਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਤੇਜ਼ ਪ੍ਰੀ-ਚੈੱਕ (ਟਾਈਪ ਚੈੱਕ ਅਤੇ ਪਹਿਲਾ/ਆਖ਼ਰੀ ਅੱਖਰ) ਕਰਦਾ ਹੈ।
- ਗਾਰਡਾਂ ਅਤੇ ਇਨਪੁੱਟ ਵੈਲੀਡੇਸ਼ਨ ਲਈ ਉਚਿਤ ਇੱਕ ਸਧਾਰਣ ਬੂਲੀਅਨ ਨਤੀਜਾ (`true`/`false`) ਵਾਪਸ ਕਰਦਾ ਹੈ।

## ਵਰਤੋਂ

### ਸਿੰਟੈਕਸ

ਫੰਕਸ਼ਨ:

- `isDecimal(value)`

ਪੈਰਾਮੀਟਰ:

- `value`: ਦਸ਼ਮਲਵ ਸਟਰਿੰਗ ਫਾਰਮੈਟ ਲਈ ਜਾਂਚਣ ਵਾਸਤੇ ਮੁੱਲ।

### ਲੋਕਲ ਫੰਕਸ਼ਨ ਇੰਪੋਰਟ

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    //‎ ਇੱਥੇ v ਇੱਕ ਸਟਰਿੰਗ ਹੈ (ਰਨਟਾਈਮ-ਵੈਲੀਡੇਟ ਕੀਤੀ)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### ਗਲੋਬਲ ਓਬਜੈਕਟ ਇੰਪੋਰਟ

ਫੰਕਸ਼ਨਾਂ ਨੂੰ ਗਲੋਬਲ ਓਬਜੈਕਟ ਮੈਥਡ ਵਜੋਂ ਇੰਪੋਰਟ ਕਰਨ ਲਈ ਵਰਤੋਂ ਕਰੋ:

```ts

```

- `Type.isDecimal(value)`
