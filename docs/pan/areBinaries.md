# areBinaries

ਇਹ ਜਾਂਚਦਾ ਹੈ ਕਿ ਦਿੱਤਾ ਗਿਆ ਮੁੱਲ ਵੈਧ ਬਾਈਨਰੀ ਸਟਰਿੰਗਜ਼ ਦਾ ਗੈਰ-ਖਾਲੀ ਐਰੇ ਹੈ ਜਾਂ ਨਹੀਂ ਅਤੇ `true` ਸਿਰਫ਼ ਤਦ ਹੀ ਵਾਪਸ ਕਰਦਾ ਹੈ ਜਦੋਂ
ਸਾਰੇ ਆਈਟਮ ਵੈਲੀਡੇਸ਼ਨ ਪਾਸ ਕਰਦੇ ਹਨ।

## ਵਰਤੋਂ

### ਸਿੰਟੈਕਸ

ਫੰਕਸ਼ਨ:

- `areBinaries(array)`

ਪੈਰਾਮੀਟਰ:

- `array`: ਜਾਂਚਿਆ ਜਾਣ ਵਾਲਾ ਮੁੱਲ।

### ਲੋਕਲ ਫੰਕਸ਼ਨ ਇੰਪੋਰਟ

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // ਸੱਚ
console.log(areBinaries(b)); // ਝੂਠ
console.log(areBinaries([])); // ਝੂਠ
```
