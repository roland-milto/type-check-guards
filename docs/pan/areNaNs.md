# areNaNs

## ਵਰਣਨ

`areNaNs` ਚੈਕ ਕਰਦਾ ਹੈ ਕਿ ਕੀ ਐਰੇ ਦੇ ਸਾਰੇ ਐਲਿਮੈਂਟ `NaN` ਹਨ ਅਤੇ ਸਿਰਫ਼ ਓਦੋਂ ਹੀ `true` ਵਾਪਸ ਕਰਦਾ ਹੈ ਜਦੋਂ ਹਰ ਐਲਿਮੈਂਟ `NaN`
ਹੋਵੇ।

### ਵਰਤੋਂ ਦਾ ਮਾਮਲਾ

ਆਉਣ ਵਾਲੇ ਡਾਟਾ ਨੂੰ ਵੈਲੀਡੇਟ ਕਰੋ ਜਿੱਥੇ `NaN` ਨੂੰ ਸੈਂਟੀਨਲ ਵੈਲਿਊ ਵਜੋਂ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ ਅਤੇ ਤੁਹਾਨੂੰ ਯਕੀਨੀ ਬਣਾਉਣਾ ਹੋਵੇ ਕਿ ਪੂਰੀ
ਐਰੇ ਸਿਰਫ਼ `NaN` ਤੋਂ ਹੀ ਬਣੀ ਹੈ (ਜਿਵੇਂ ਕਿ ਪੂਰੀ ਤਰ੍ਹਾਂ ਗੁੰਮ ਨਿਊਮੈਰਿਕ ਸੀਰੀਜ਼ ਦੀ ਪਛਾਣ ਕਰਨਾ)।

> **TypeScript ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਸੰਕੇਤ:**
>
> `areNaNs` ਓਦੋਂ ਵਰਤੋ ਜਦੋਂ ਤੁਹਾਨੂੰ ਇਹ ਵੈਲੀਡੇਟ ਕਰਨਾ ਹੋਵੇ ਕਿ ਐਰੇ ਵਿੱਚ ਸਿਰਫ਼ ਨਿਊਮੈਰਿਕ `NaN` ਵੈਲਿਊ ਹੀ ਹੈ (ਸਟ੍ਰਿੰਗ-ਤੋਂ-ਨੰਬਰ
> ਕੋਅਰਸ਼ਨ ਤੋਂ ਬਿਨਾਂ)।

### ਫਾਇਦੇ

- ਸਿਰਫ਼ ਓਦੋਂ ਹੀ `true` ਵਾਪਸ ਕਰਦਾ ਹੈ ਜਦੋਂ ਹਰ ਐਲਿਮੈਂਟ `NaN` ਹੋਵੇ (ਸਖ਼ਤ ਸਾਰੇ-ਐਲਿਮੈਂਟਾਂ ਦੀ ਜਾਂਚ)।
- ਸਟ੍ਰਿੰਗਾਂ ਨੂੰ ਨੰਬਰਾਂ ਵਿੱਚ ਕੋਅਰਸ ਨਹੀਂ ਕਰਦਾ; "NaN" ਵਰਗੀਆਂ ਵੈਲਿਊਆਂ non-`NaN` ਹੀ ਰਹਿੰਦੀਆਂ ਹਨ ਅਤੇ ਨਤੀਜਾ `false` ਬਣਾਉਂਦੀਆਂ
  ਹਨ।
- ਨਾ-ਭਰੀਆਂ ਐਰੇਜ਼ ਲਈ `false` ਵਾਪਸ ਕਰਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਖਾਲੀ ਇਨਪੁੱਟ 'ਤੇ ਅਣਜਾਣੇ ਵਿੱਚ `true` ਆਉਣ ਤੋਂ ਬਚਾਅ ਹੁੰਦਾ ਹੈ।

## ਵਰਤੋਂ

### ਸਿੰਟੈਕਸ

ਫੰਕਸ਼ਨ:

- `areNaNs(array)`

ਪੈਰਾਮੀਟਰ:

- `array`: `NaN` ਵੈਲਿਊਆਂ ਲਈ ਚੈਕ ਕਰਨ ਵਾਲੀ ਐਰੇ।

### ਲੋਕਲ ਫੰਕਸ਼ਨ ਇੰਪੋਰਟ

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // ਸੱਚ
const b = areNaNs([NaN, 1, NaN]); // ਝੂਠ
const c = areNaNs([NaN, "NaN", NaN]); // ਝੂਠ
const d = areNaNs([NaN, null, NaN]); // ਝੂਠ
const e = areNaNs([] as unknown[]); // ਝੂਠ
```

### ਗਲੋਬਲ ਓਬਜੈਕਟ ਇੰਪੋਰਟ

ਫੰਕਸ਼ਨਾਂ ਨੂੰ ਗਲੋਬਲ ਓਬਜੈਕਟ ਮੈਥਡ ਵਜੋਂ ਇੰਪੋਰਟ ਕਰਨ ਲਈ ਵਰਤੋਂ ਕਰੋ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ਫਿਰ ਹੇਠਾਂ ਦਿੱਤਾ ਮੈਥਡ ਗਲੋਬਲੀ ਉਪਲਬਧ ਹੋਵੇਗਾ:

- `Type.areNaNs(array)`
