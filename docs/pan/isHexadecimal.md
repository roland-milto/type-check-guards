# isHexadecimal

## ਵਰਣਨ

`isHexadecimal` ਜਾਂਚਦਾ ਹੈ ਕਿ ਦਿੱਤਾ ਗਿਆ ਮੁੱਲ ਲਾਜ਼ਮੀ `0x`/`0X` ਪ੍ਰੀਫ਼ਿਕਸ ਵਾਲਾ ਹੈਕਸਾਡੈਸੀਮਲ ਸਟਰਿੰਗ ਲਿਟਰਲ ਹੈ ਜਾਂ ਨਹੀਂ।

### ਵਰਤੋਂ ਦਾ ਮਾਮਲਾ

ਕੰਫਿਗਰੇਸ਼ਨ ਮੁੱਲਾਂ, API ਪੇਲੋਡ ਫੀਲਡਾਂ, ਜਾਂ CLI ਆਰਗਿਊਮੈਂਟਾਂ ਨੂੰ ਵੈਲੀਡੇਟ ਕਰਨ ਲਈ `isHexadecimal` ਵਰਤੋ, ਜਿਹੜੇ ਹੈਕਸਾਡੈਸੀਮਲ
ਸਟਰਿੰਗ ਲਿਟਰਲਾਂ ਵਜੋਂ ਹੀ ਦਿੱਤੇ ਜਾਣੇ ਲਾਜ਼ਮੀ ਹਨ (ਜਿਵੇਂ IDs, masks, ਜਾਂ addresses) ਅਤੇ ਜਿਨ੍ਹਾਂ ਵਿੱਚ ਆਲੇ-ਦੁਆਲੇ whitespace ਨਹੀਂ
ਹੋਣਾ ਚਾਹੀਦਾ।

>
> ਜਦੋਂ ਤੁਹਾਨੂੰ ਯੂਜ਼ਰ ਇਨਪੁੱਟ ਜਾਂ ਸੀਰੀਅਲਾਈਜ਼ਡ ਡਾਟਾ ਨੂੰ ਪਾਰਸ ਜਾਂ ਕਨਵਰਟ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਸਖ਼ਤ ਹੈਕਸਾਡੈਸੀਮਲ ਲਿਟਰਲ ਸਟਰਿੰਗ (ਜਿਸ

### ਫਾਇਦੇ

- ਇਹ ਜਾਂਚਦਾ ਹੈ ਕਿ ਕੋਈ ਮੁੱਲ ਸਟਰਿੰਗ ਹੈ ਅਤੇ ਸਖ਼ਤ ਹੈਕਸਾਡੈਸੀਮਲ ਲਿਟਰਲ ਫਾਰਮੈਟ ਨਾਲ ਮੇਲ ਖਾਂਦਾ ਹੈ (ਲਾਜ਼ਮੀ `0x`/`0X` ਪ੍ਰੀਫ਼ਿਕਸ ਦੀ
  ਲੋੜ ਹੁੰਦੀ ਹੈ)।
- ਅੱਗੇ ਜਾਂ ਪਿੱਛੇ ਵਾਲੀ ਖਾਲੀ ਥਾਂ (whitespace) ਵਾਲੀਆਂ ਸਟਰਿੰਗਾਂ ਨੂੰ ਰੱਦ ਕਰਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਪੈਡ ਕੀਤੇ ਇਨਪੁੱਟ ਨੂੰ ਗਲਤੀ ਨਾਲ ਮਨਜ਼ੂਰ

- ਵਿਕਲਪਿਕ ਸਾਈਨ ਨੂੰ ਸਮਰਥਨ ਦਿੰਦਾ ਹੈ ਅਤੇ ਪ੍ਰੀਫ਼ਿਕਸ ਤੇ ਅੰਕਾਂ ਲਈ ਕੇਸ-ਇਨਸੈਂਸਿਟਿਵ ਹੈ, ਅਤੇ ਭਰੋਸੇਯੋਗ ਤਰੀਕੇ ਨਾਲ `true`/`false`

## ਵਰਤੋਂ

### ਸਿੰਟੈਕਸ

ਫੰਕਸ਼ਨ:

- `isHexadecimal(value)`

ਪੈਰਾਮੀਟਰ:

- `value`: ਜਿਸ ਮੁੱਲ ਦੀ ਜਾਂਚ ਕਰਨੀ ਹੈ।

### ਲੋਕਲ ਫੰਕਸ਼ਨ ਇੰਪੋਰਟ

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // ਸੱਚ
isHexadecimal("-0Xff"); // ਸੱਚ
isHexadecimal("1A2B"); // ਝੂਠ (ਪ੍ਰੀਫਿਕਸ ਗੁੰਮ ਹੈ)
isHexadecimal(" 0x1A2B"); // ਝੂਠ (ਅੱਗੇ ਖਾਲੀ ਥਾਂ)
isHexadecimal(0x1a2b); // ਝੂਠ (ਸਤਰ ਨਹੀਂ ਹੈ)
```
