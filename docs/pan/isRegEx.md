# isRegEx

## ਵਰਣਨ

ਇਹ ਨਿਰਧਾਰਤ ਕਰਦਾ ਹੈ ਕਿ ਦਿੱਤੀ ਗਈ ਵੈਲਯੂ `RegExp` ਦੀ ਇੰਸਟੈਂਸ ਹੈ ਜਾਂ ਨਹੀਂ।

### ਵਰਤੋਂ ਦਾ ਮਾਮਲਾ

ਯੂਜ਼ਰ ਵੱਲੋਂ ਦਿੱਤੀਆਂ ਜਾਂ ਡਾਇਨਾਮਿਕ ਵੈਲਯੂਜ਼ (ਜਿਵੇਂ ਕਨਫਿਗਰੇਸ਼ਨ, API ਪੇਲੋਡ, ਪਲੱਗਇਨ ਇਨਪੁੱਟ) ਨੂੰ ਰੈਗੂਲਰ ਐਕਸਪ੍ਰੈਸ਼ਨ ਵਜੋਂ ਵਰਤਣ
ਤੋਂ ਪਹਿਲਾਂ ਵੈਲੀਡੇਟ ਕਰੋ।

> **TypeScript ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਸੰਕੇਤ:**
>
> `isRegEx` ਨੂੰ `unknown` (ਜਾਂ ਯੂਨੀਅਨ) ਵੈਲਯੂਜ਼ ਨੂੰ ਨੈਰੋ ਕਰਨ ਲਈ ਵਰਤੋ, RegExp-ਖਾਸ ਪ੍ਰਾਪਰਟੀਜ਼ ਜਾਂ ਮੈਥਡ ਵਰਤਣ ਤੋਂ ਪਹਿਲਾਂ; ਇਹ
`true` ਸਿਰਫ਼ ਉਹਨਾਂ ਵੈਲਯੂਜ਼ ਲਈ ਵਾਪਸ ਕਰਦਾ ਹੈ ਜੋ `RegExp` ਦੀਆਂ ਇੰਸਟੈਂਸਾਂ ਹੁੰਦੀਆਂ ਹਨ।

### ਫਾਇਦੇ

- ਇੱਕ ਸੌਖਾ ਰਨਟਾਈਮ ਟਾਈਪ ਗਾਰਡ ਦਿੰਦਾ ਹੈ ਤਾਂ ਜੋ ਚੈੱਕ ਕੀਤਾ ਜਾ ਸਕੇ ਕਿ ਕੋਈ ਵੈਲਯੂ `RegExp` ਹੈ ਕਿ ਨਹੀਂ।
- ਜਦੋਂ ਕੋਡ ਨੂੰ ਰੈਗੂਲਰ ਐਕਸਪ੍ਰੈਸ਼ਨ ਦੀ ਉਮੀਦ ਹੁੰਦੀ ਹੈ (ਜਿਵੇਂ `test`, `exec` ਕਾਲ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਜਾਂ `source` ਪੜ੍ਹਨ ਤੋਂ
  ਪਹਿਲਾਂ), ਤਾਂ ਗਲਤੀਆਂ ਤੋਂ ਬਚਾਉਂਦਾ ਹੈ।
- `new RegExp(...)` ਰਾਹੀਂ ਬਣੇ ਰੇਜੈਕਸ ਲਿਟਰਲਾਂ ਅਤੇ ਇੰਸਟੈਂਸਾਂ ਦੋਹਾਂ ਨਾਲ ਕੰਮ ਕਰਦਾ ਹੈ।
- ਨਾਨ-ਰੇਜੈਕਸ ਇਨਪੁੱਟ ਲਈ ਐਰਰ ਸੁੱਟਣ ਤੋਂ ਬਿਨਾਂ ਸਾਫ਼ ਬੂਲੀਅਨ ਨਤੀਜਾ (`true`/`false`) ਵਾਪਸ ਕਰਦਾ ਹੈ।

## ਵਰਤੋਂ

### ਸਿੰਟੈਕਸ

ਫੰਕਸ਼ਨ:

- `isRegEx(value)`

ਪੈਰਾਮੀਟਰ:

- `value`: ਚੈੱਕ ਕੀਤੀ ਜਾਣ ਵਾਲੀ ਵੈਲਯੂ।

### ਲੋਕਲ ਫੰਕਸ਼ਨ ਇੰਪੋਰਟ

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  //‎ ਇੱਥੇ input ਇੱਕ RegExp ਹੈ
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### ਗਲੋਬਲ ਓਬਜੈਕਟ ਇੰਪੋਰਟ

ਫੰਕਸ਼ਨਾਂ ਨੂੰ ਗਲੋਬਲ ਓਬਜੈਕਟ ਮੈਥਡ ਵਜੋਂ ਇੰਪੋਰਟ ਕਰਨ ਲਈ ਵਰਤੋਂ ਕਰੋ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ਫਿਰ ਹੇਠਾਂ ਦਿੱਤਾ ਮੈਥਡ ਗਲੋਬਲੀ ਉਪਲਬਧ ਹੋਵੇਗਾ:

- `Type.isRegEx(value)`
