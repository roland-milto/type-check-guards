# isIndexFound

## ਵਰਣਨ

`isIndexFound` ਇਹ ਨਿਰਧਾਰਤ ਕਰਦਾ ਹੈ ਕਿ ਦਿੱਤੀ ਕਦਰ ਗੈਰ-ਨਕਾਰਾਤਮਕ ਪੂਰਨ ਅੰਕ ਹੈ ਜਾਂ ਨਹੀਂ, ਜਿਸ ਨਾਲ ਇੰਡੈਕਸ ਮਿਲਣ ਦਾ ਸੰਕੇਤ ਮਿਲਦਾ ਹੈ।

### ਵਰਤੋਂ ਦਾ ਮਾਮਲਾ

ਇਹ ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਖੋਜ ਨਤੀਜਾ ਇੱਕ ਵਰਤਣਯੋਗ ਇੰਡੈਕਸ (ਪੂਰਨ ਅੰਕ `>= 0`) ਹੈ, ਐਰੇ ਜਾਂ ਸਟ੍ਰਿੰਗ ਵਿੱਚ ਇੰਡੈਕਸ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ, ਤਾਂ ਜੋ
ਅਣਜਾਣੇ ਵਿੱਚ `-1` ਜਾਂ ਗੈਰ-ਅੰਕੀ ਕਦਰਾਂ ਦੀ ਵਰਤੋਂ ਤੋਂ ਬਚਿਆ ਜਾ ਸਕੇ।

> **TypeScript ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਸੰਕੇਤ:**
>
> `isIndexFound` ਨੂੰ `indexOf`, `findIndex`, ਜਾਂ ਕਸਟਮ ਖੋਜਾਂ ਵਰਗੀਆਂ ਕਾਰਵਾਈਆਂ ਤੋਂ ਬਾਅਦ ਵਰਤੋ ਜਿੱਥੇ `-1` (ਜਾਂ ਹੋਰ ਅਵੈਧ
> ਕਦਰਾਂ) “ਨਹੀਂ ਮਿਲਿਆ” ਦਰਸਾ ਸਕਦੀਆਂ ਹਨ। ਜਦੋਂ ਇਹ `true` ਵਾਪਸ ਕਰਦਾ ਹੈ, ਕਦਰ ਇੱਕ ਨੰਬਰ ਹੁੰਦੀ ਹੈ ਅਤੇ ਐਰੇ/ਸਟ੍ਰਿੰਗ ਇੰਡੈਕਸ ਵਜੋਂ
> ਵਰਤਣ
> ਲਈ ਸੁਰੱਖਿਅਤ ਹੁੰਦੀ ਹੈ।

### ਫਾਇਦੇ

- ਇੱਕ ਸੌਖਾ ਟਾਈਪ ਗਾਰਡ ਦਿੰਦਾ ਹੈ ਜੋ ਗੈਰ-ਨਕਾਰਾਤਮਕ ਪੂਰਨ ਅੰਕ ਦੀ ਜਾਂਚ ਕਰਕੇ ਪਤਾ ਲਗਾਉਂਦਾ ਹੈ ਕਿ ਇੰਡੈਕਸ ਮਿਲਿਆ ਹੈ ਜਾਂ ਨਹੀਂ।
- ਸਿਰਫ਼ ਵੈਧ ਇੰਡੈਕਸ-ਵਰਗੀਆਂ ਕਦਰਾਂ (ਪੂਰਨ ਅੰਕ `>= 0`) ਲਈ ਹੀ `true` ਵਾਪਸ ਕਰਦਾ ਹੈ, ਨਕਾਰਾਤਮਕ, ਗੈਰ-ਪੂਰਨ ਅੰਕ ਅਤੇ ਗੈਰ-ਅੰਕੀ ਕਦਰਾਂ
  ਨੂੰ ਰੱਦ ਕਰਦਾ ਹੈ।
- ਉਹਨਾਂ APIਆਂ ਨਾਲ ਕੰਮ ਕਰਦਿਆਂ ਜਿਹੜੀਆਂ “ਨਹੀਂ ਮਿਲਿਆ” ਲਈ `-1` ਵਾਪਸ ਕਰਦੀਆਂ ਹਨ, off-by-one ਅਤੇ sentinel-value ਵਾਲੀਆਂ ਗਲਤੀਆਂ
  ਤੋਂ ਬਚਾਉਂਦਾ ਹੈ।

## ਵਰਤੋਂ

### ਸਿੰਟੈਕਸ

ਫੰਕਸ਼ਨ:

- `isIndexFound(value)`

ਪੈਰਾਮੀਟਰ:

- `value`: ਜਾਂਚ ਲਈ ਕਦਰ ਕਿ ਕੀ ਇਹ ਗੈਰ-ਨਕਾਰਾਤਮਕ ਪੂਰਨ ਅੰਕ ਹੈ।

### ਲੋਕਲ ਫੰਕਸ਼ਨ ਇੰਪੋਰਟ

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  //‎ इथे idx नंबर ऐ अऊर 0 तों वड्डा/बराबर ऐ
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

//‎ indexOf दे नाल आम इस्तेमाल
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### ਗਲੋਬਲ ਓਬਜੈਕਟ ਇੰਪੋਰਟ

ਫੰਕਸ਼ਨਾਂ ਨੂੰ ਗਲੋਬਲ ਓਬਜੈਕਟ ਮੈਥਡ ਵਜੋਂ ਇੰਪੋਰਟ ਕਰਨ ਲਈ ਵਰਤੋਂ ਕਰੋ:

```ts

```

- `Type.isIndexFound(value)`
