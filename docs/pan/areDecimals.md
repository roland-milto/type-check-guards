# areDecimals

## ਵਰਣਨ

چیک کردا اے کہ اَرے دے سارے عناصر ڈیسمل نمبر نیں تے اَرے بھری ہوئی اے، تے `true` یا `false` واپس کردا اے۔

### ਵਰਤੋਂ ਦਾ ਮਾਮਲਾ

یوزر ولوں دتیاں لسٹاں (مثلاً CSV کالم یا فارم اِن پُٹس) دی ویلیڈیشن کرو تاکہ اَرے خالی نہ ہووے تے ہر انٹری ڈیسمل ویلیو
ہووے، پارسنگ یا کیلکولیشن توں پہلاں۔

> **TypeScript ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਸੰਕੇਤ:**
>
> `areDecimals` اوہدوں استعمال کرو جدوں تہانوں فوری بولین چیک چاہیدا ہووے کہ اک `unknown[]` خالی نہ ہووے تے ہر عنصر اک
> ڈیسمل نمائندگی ہووے۔

### ਫਾਇਦੇ

- آئٹمز دی تصدیق توں پہلاں ایہ یقینی بناندا اے کہ اِن پُٹ اک بھری ہوئی اَرے اے، جس نال خالی لسٹاں نوں غلطی نال قبول کرن
  توں بچاؤ ہوندا اے۔
- ہر عنصر نوں `isDecimal` نال ویلیڈیٹ کردا اے، اس لئی مکسڈ یا غلط ویلیوز فوراً `false` نتیجہ دیندیاں نیں۔
- اک سادہ بولین نتیجہ (`true`/`false`) فراہم کردا اے جو گارڈز تے ارلی-ریٹرن ویلیڈیشن فلوآں لئی مناسب اے۔

## ਵਰਤੋਂ

### ਸਿੰਟੈਕਸ

ਫੰਕਸ਼ਨ:

- `areDecimals(array)`

ਪੈਰਾਮੀਟਰ:

- `array`: چیک کرن لئی اَرے۔

### ਲੋਕਲ ਫੰਕਸ਼ਨ ਇੰਪੋਰਟ

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // ਸੱਚ
console.log(areDecimals(b)); // ਝੂਠ
console.log(areDecimals(c)); // ਝੂਠ
```
