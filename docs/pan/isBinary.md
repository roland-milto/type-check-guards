# isBinary

## ਵਰਣਨ

`isBinary` ਇਹ ਨਿਰਧਾਰਤ ਕਰਦਾ ਹੈ ਕਿ ਕੋਈ ਵੈਲਯੂ ਬਾਈਨਰੀ ਸਟਰਿੰਗ ਹੈ (ਚੋਣਵਾਂ ਤੌਰ ‘ਤੇ `0b`/`0B` ਨਾਲ ਪ੍ਰੀਫਿਕਸ ਕੀਤੀ ਹੋਈ) ਅਤੇ `true`
ਜਾਂ `false` ਵਾਪਸ ਕਰਦਾ ਹੈ।

### ਵਰਤੋਂ ਦਾ ਮਾਮਲਾ

ਯੂਜ਼ਰ ਵੱਲੋਂ ਦਿੱਤੀਆਂ ਸਟਰਿੰਗਾਂ (ਜਿਵੇਂ ਫਾਰਮ ਫੀਲਡ, CLI args, ਕਾਨਫਿਗ ਵੈਲਯੂਜ਼) ਦੀ ਵੈਲੀਡੇਸ਼ਨ ਕਰੋ ਤਾਂ ਜੋ ਇਹ ਯਕੀਨੀ ਬਣੇ ਕਿ ਉਹ
ਸਿਰਫ਼ ਬਾਈਨਰੀ ਅੰਕ ਦਰਸਾਉਂਦੀਆਂ ਹਨ, ਚੋਣਵਾਂ ਤੌਰ ‘ਤੇ `0b`/`0B` ਪ੍ਰੀਫਿਕਸ ਨਾਲ, ਅੱਗੇ ਦੀ ਪ੍ਰੋਸੈਸਿੰਗ ਤੋਂ ਪਹਿਲਾਂ।

> **TypeScript ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਸੰਕੇਤ:**
>
> `isBinary` ਨੂੰ ਸਟਰਿੰਗ ਨੂੰ `BigInt`/`Number` ਵਿੱਚ ਪਾਰਸ ਜਾਂ ਕਨਵਰਟ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਟਾਈਪ ਗਾਰਡ ਵਜੋਂ ਵਰਤੋ ਤਾਂ ਜੋ ਗਲਤ ਇਨਪੁੱਟ
> ਤੋਂ ਬਚਿਆ ਜਾ ਸਕੇ।

### ਫਾਇਦੇ

- `0b`/`0B` ਪ੍ਰੀਫਿਕਸ ਨਾਲ ਜਾਂ ਬਿਨਾਂ ਬਾਈਨਰੀ ਸਟਰਿੰਗਾਂ ਨੂੰ ਸਵੀਕਾਰ ਕਰਦਾ ਹੈ।
- ਖਾਲੀ ਸਟਰਿੰਗਾਂ ਅਤੇ ਅੱਗੇ/ਪਿੱਛੇ ਵ੍ਹਾਈਟਸਪੇਸ (ASCII ≤ 32) ਵਾਲੀਆਂ ਸਟਰਿੰਗਾਂ ਨੂੰ ਰੱਦ ਕਰਦਾ ਹੈ।
- `true`/`false` ਬਿਨਾਂ throw ਕੀਤੇ ਵਾਪਸ ਕਰਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਇਹ ਅਣਜਾਣ ਇਨਪੁੱਟ ਲਈ ਸੁਰੱਖਿਅਤ ਬਣਦਾ ਹੈ।

## ਵਰਤੋਂ

### ਸਿੰਟੈਕਸ

ਫੰਕਸ਼ਨ:

- `isBinary(value)`

ਪੈਰਾਮੀਟਰ:

- `value`: ਜਾਂਚੀ ਜਾਣ ਵਾਲੀ ਵੈਲਯੂ।

### ਲੋਕਲ ਫੰਕਸ਼ਨ ਇੰਪੋਰਟ

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // ਸੱਚ
const b = isBinary("1010");   // ਸੱਚ
const c = isBinary("0b1020"); // ਝੂਠ
const d = isBinary(0b1010);     // ਝੂਠ

```

### ਗਲੋਬਲ ਓਬਜੈਕਟ ਇੰਪੋਰਟ

ਫੰਕਸ਼ਨਾਂ ਨੂੰ ਗਲੋਬਲ ਓਬਜੈਕਟ ਮੈਥਡ ਵਜੋਂ ਇੰਪੋਰਟ ਕਰਨ ਲਈ ਵਰਤੋਂ ਕਰੋ:

```ts

```

- `Type.isBinary(value)`
