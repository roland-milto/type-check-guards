# areJson

## ਵਰਣਨ

ਚੈੱਕ ਕਰਦਾ ਹੈ ਕਿ ਐਰੇ ਦੇ ਸਾਰੇ ਐਲਿਮੈਂਟ JSON ਸਟਰਿੰਗਾਂ ਹਨ ਕਿ ਨਹੀਂ; `true` ਸਿਰਫ਼ ਓਦੋਂ ਹੀ ਵਾਪਸ ਕਰਦਾ ਹੈ ਜਦੋਂ ਐਰੇ ਭਰਿਆ ਹੋਵੇ ਅਤੇ
ਹਰ ਆਈਟਮ ਵੈਧ JSON ਹੋਵੇ; ਨਹੀਂ ਤਾਂ `false` ਵਾਪਸ ਕਰਦਾ ਹੈ।

### ਵਰਤੋਂ ਦਾ ਮਾਮਲਾ

ਆਉਣ ਵਾਲੇ ਡਾਟਾ ਦੀ ਵੈਲੀਡੇਸ਼ਨ ਕਰੋ (ਜਿਵੇਂ query params, environment variables, ਜਾਂ external APIs ਤੋਂ) ਜਿੱਥੇ ਤੁਸੀਂ JSON-ਇਨਕੋਡ
ਕੀਤੀਆਂ ਸਟਰਿੰਗਾਂ ਦੇ ਐਰੇ ਦੀ ਉਮੀਦ ਕਰਦੇ ਹੋ ਅਤੇ ਖਾਲੀ ਐਰੇਜ਼ ਜਾਂ ਕਿਸੇ ਵੀ ਗੈਰ-JSON ਐਂਟਰੀ ਨੂੰ ਰੱਦ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ।

> **TypeScript ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਸੰਕੇਤ:**
>
> `areJson` ਨੂੰ ਓਦੋਂ ਵਰਤੋ ਜਦੋਂ ਤੁਹਾਨੂੰ ਇਹ ਵੈਲੀਡੇਟ ਕਰਨ ਦੀ ਲੋੜ ਹੋਵੇ ਕਿ ਇੱਕ `unknown[]` ਵਿੱਚ ਪਾਰਸ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਸਿਰਫ਼ JSON
> ਸਟਰਿੰਗਾਂ ਹੀ ਹਨ (ਜਿਵੇਂ `JSON.parse` ਨਾਲ)।

### ਫਾਇਦੇ

- `true` ਸਿਰਫ਼ ਓਦੋਂ ਹੀ ਵਾਪਸ ਕਰਦਾ ਹੈ ਜਦੋਂ ਹਰ ਐਲਿਮੈਂਟ ਇੱਕ ਵੈਧ JSON ਸਟਰਿੰਗ ਹੋਵੇ; ਨਹੀਂ ਤਾਂ `false` ਵਾਪਸ ਕਰਦਾ ਹੈ।
- ਤੇਜ਼ੀ ਨਾਲ ਫੇਲ ਹੁੰਦਾ ਹੈ: ਜਿਵੇਂ ਹੀ ਕੋਈ ਗੈਰ-JSON ਐਲਿਮੈਂਟ ਮਿਲਦਾ ਹੈ, ਚੈੱਕ ਕਰਨਾ ਰੋਕ ਦਿੰਦਾ ਹੈ।
- ਡਿਜ਼ਾਇਨ ਮੁਤਾਬਕ ਖਾਲੀ ਐਰੇਜ਼ ਨੂੰ ਰੱਦ ਕਰਦਾ ਹੈ, ਨਾ-ਭਰੇ ਇਨਪੁੱਟ ਲਈ `false` ਵਾਪਸ ਕਰਦਾ ਹੈ।

## ਵਰਤੋਂ

### ਸਿੰਟੈਕਸ

ਫੰਕਸ਼ਨ:

- `areJson(array)`

ਪੈਰਾਮੀਟਰ:

- `array`: JSON ਸਟਰਿੰਗ ਐਲਿਮੈਂਟਾਂ ਲਈ ਚੈੱਕ ਕੀਤਾ ਜਾਣ ਵਾਲਾ ਐਰੇ।

### ਲੋਕਲ ਫੰਕਸ਼ਨ ਇੰਪੋਰਟ

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // ਸੱਚ
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // ਝੂਠ
const empty = areJson([]); // ਝੂਠ

```

### ਗਲੋਬਲ ਓਬਜੈਕਟ ਇੰਪੋਰਟ

ਫੰਕਸ਼ਨਾਂ ਨੂੰ ਗਲੋਬਲ ਓਬਜੈਕਟ ਮੈਥਡ ਵਜੋਂ ਇੰਪੋਰਟ ਕਰਨ ਲਈ ਵਰਤੋਂ ਕਰੋ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ਫਿਰ ਹੇਠਾਂ ਦਿੱਤਾ ਮੈਥਡ ਗਲੋਬਲੀ ਉਪਲਬਧ ਹੋਵੇਗਾ:

- `Type.areJson(array)`
