# areBinaries

## ဖော်ပြချက်

ပေးထားသော တန်ဖိုးသည် မှန်ကန်သော binary string များပါဝင်သည့် အလွတ်မဟုတ်သော အရေး (array) ဟုတ်မဟုတ်ကို စစ်ဆေးပြီး item
အားလုံး validation အောင်မြင်မှသာ `true` ကို ပြန်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

မသိရသေးသော စာရင်းတစ်ခု (ဥပမာ JSON၊ ဖောင်များ၊ သို့မဟုတ် API များမှ) ကို လက်ခံရရှိသောအခါ parsing သို့မဟုတ် processing
မလုပ်မီ ၎င်းသည် binary string များပါဝင်သည့် အလွတ်မဟုတ်သော အရေး (array) ဖြစ်ကြောင်း သေချာစေရန် `areBinaries` ကို
အသုံးပြုပါ။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> binary string များကို numbers/BigInts သို့ ပြောင်းမီ မသိရသေးသော input ကို validate လုပ်ရန် `areBinaries` ကို
> အသုံးပြုပါ; ၎င်းသည် အရေး (array) သည် အလွတ်မဟုတ်ကြောင်းနှင့် အစိတ်အပိုင်းတိုင်းသည် မှန်ကန်သော binary string ဖြစ်ကြောင်း
> အာမခံပေးသည်။

### အားသာချက်များ

- တန်ဖိုးတစ်ခုသည် အလွတ်မဟုတ်သော အရေး (array) ဖြစ်ပြီး အစိတ်အပိုင်းတိုင်းသည် မှန်ကန်သော binary string ဖြစ်ကြောင်း
  စစ်ဆေးပေးသည်။
- guard များ၊ အစောပိုင်း return များနှင့် input validation အတွက် သင့်တော်သော ရိုးရှင်းသော boolean ရလဒ် (`true`/`false`)
  ကို ပြန်ပေးသည်။
- binary မဟုတ်သော entry တစ်ခုခု ပါဝင်နေသော အရေးများကို ပယ်ချခြင်းဖြင့် နောက်ဆက်တွဲ parsing အမှားများကို တားဆီးပေးသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `areBinaries(array)`

ပါရာမီတာများ:

- `array`: စစ်ဆေးမည့် တန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // မှန်
console.log(areBinaries(b)); // မမှန်
console.log(areBinaries([])); // မမှန်
```
