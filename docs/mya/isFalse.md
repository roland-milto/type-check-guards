# isFalse

## ဖော်ပြချက်

`isFalse` သည် ပေးထားသော တန်ဖိုးသည် boolean literal `false` နှင့် အတိအကျ တူညီနေခြင်းရှိမရှိကို စစ်ဆေးသည်။

### အသုံးပြုမှုကိစ္စ

မသိရသေးသော ဒေတာ (ဥပမာ JSON, query params, သို့မဟုတ် user input မှ) ကို အတည်ပြုစစ်ဆေးရာတွင် boolean တန်ဖိုး `false` ကိုသာ
မှန်ကန်သော flag အဖြစ် သတ်မှတ်လိုပြီး အခြားအရာအားလုံးကို ငြင်းပယ်လိုသောအခါ အသုံးပြုသည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> `false` literal ကိုသာ လက်ခံပြီး အခြား falsy တန်ဖိုးအားလုံးကို ငြင်းပယ်ရန်လိုသောအခါ `isFalse` ကို အသုံးပြုပါ; ၎င်းသည်
`value === false` ဖြစ်သည့်အခါတွင်သာ `true` ကို ပြန်ပေးသည်။

### အားသာချက်များ

- အတင်းကျပ်စွာ ပြောင်းလဲညှိနှိုင်းမှု (coercion) မလုပ်ဘဲ boolean literal `false` ကို စစ်ဆေးပေးသည်။
- `0`, `""`, `null`, `undefined` ကဲ့သို့သော falsy တန်ဖိုးများနှင့် `false` ကို ခွဲခြားသတ်မှတ်ရန် ကူညီပေးသည်။
- မသိရသေးသော input ကို အတည်ပြုစစ်ဆေးရာတွင် ရည်ရွယ်ချက်ကို ထင်ရှားစွာ ဖော်ပြပေးသဖြင့် ဖတ်ရှုရလွယ်ကူမှုကို တိုးတက်စေသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `isFalse(value)`

ပါရာမီတာများ:

- `value`: စစ်ဆေးမည့် တန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { isFalse } from "@type-check/guards";

const input: unknown = false;

if (isFalse(input)) {
  // ဒီနေရာမှာ input က တိတိကျကျ false ဖြစ်တယ်
  console.log("Got false");
} else {
  console.log("Not false");
}

```

```ts

```

- `Type.isFalse(value)`
