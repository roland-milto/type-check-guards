# isIndexFound

## ဖော်ပြချက်

`isIndexFound` သည် ပေးထားသောတန်ဖိုးသည် အနုတ်မဟုတ်သော ကိန်းပြည့်ဖြစ်မဖြစ်ကို သတ်မှတ်ပေးပြီး အညွှန်းကို
တွေ့ရှိထားကြောင်းကို ညွှန်ပြသည်။

### အသုံးပြုမှုကိစ္စ

ရှာဖွေမှုရလဒ်သည် အသုံးချနိုင်သော အညွှန်း (ကိန်းပြည့် `>= 0`) ကို ကိုယ်စားပြုနေကြောင်းကို array သို့မဟုတ် string ထဲသို့
index လုပ်မီ အတည်ပြုစစ်ဆေးပြီး `-1` သို့မဟုတ် ကိန်းမဟုတ်သောတန်ဖိုးများကို မတော်တဆ အသုံးပြုမိခြင်းကို တားဆီးရန်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> `indexOf`, `findIndex` သို့မဟုတ် `-1` (သို့မဟုတ် အခြားမမှန်ကန်သောတန်ဖိုးများ) က “မတွေ့” ဟု ညွှန်ပြနိုင်သော custom
> search များပြီးနောက် `isIndexFound` ကို အသုံးပြုပါ။ ၎င်းက `true` ပြန်ပေးသောအခါ တန်ဖိုးသည် ကိန်းဖြစ်ပြီး array/string
> index အဖြစ် အသုံးပြုရန် လုံခြုံသည်။

### အားသာချက်များ

- အညွှန်းကို တွေ့ရှိထားခြင်းရှိမရှိကို အနုတ်မဟုတ်သော ကိန်းပြည့်ဖြစ်ကြောင်း စစ်ဆေးခြင်းဖြင့် ရိုးရှင်းသော type guard
  တစ်ခုကို ပံ့ပိုးပေးသည်။
- မှန်ကန်သော အညွှန်းပုံစံတန်ဖိုးများ (ကိန်းပြည့် `>= 0`) အတွက်သာ `true` ကို ပြန်ပေးပြီး အနုတ်ကိန်းများ၊
  ကိန်းပြည့်မဟုတ်သောတန်ဖိုးများနှင့် ကိန်းမဟုတ်သောတန်ဖိုးများကို ငြင်းပယ်သည်။
- `-1` ကို “မတွေ့” ဟု ပြန်ပေးသော API များနှင့် အလုပ်လုပ်ရာတွင် off-by-one နှင့် sentinel-value အမှားများကို
  ရှောင်ရှားရန် ကူညီပေးသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `isIndexFound(value)`

ပါရာမီတာများ:

- `value`: အနုတ်မဟုတ်သော ကိန်းပြည့်ဖြစ်နေခြင်းကို စစ်ဆေးရန် တန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // ဒီနေရာမှာ idx က ကိန်းဂဏန်းဖြစ်ပြီး 0 ထက်မနည်းပါ
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// indexOf နဲ့ သာမန်အသုံးပြုမှု
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```
