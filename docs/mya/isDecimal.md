# isDecimal

## ဖော်ပြချက်

`isDecimal` သည် တန်ဖိုးတစ်ခုသည် အရှေ့/အနောက် whitespace မပါဘဲ မှန်ကန်သော ဒသမ ဖော်မတ်ရှိသည့် ဒသမ စာကြောင်း
ကိုယ်စားပြုမှု (decimal string representation) ဖြစ်မဖြစ်ကို စစ်ဆေးသည်။

### အသုံးပြုမှုကိစ္စ

ဖောင်ကွက်များ၊ API payloads သို့မဟုတ် configuration တန်ဖိုးများကို parsing သို့မဟုတ် သိမ်းဆည်းမီ၊ အနားပတ်လည် whitespace
မပါဘဲ (လိုအပ်ပါက လက္ခဏာပါနိုင်သော) ဒသမ စာကြောင်းအဖြစ် ပေးရမည့်အခြေအနေများတွင် အတည်ပြုရန်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> `isDecimal` ကို (ဥပမာ `Number(value)` ဖြင့်) ပြောင်းလဲမီ အသုံးပြုသူအဝင်တန်ဖိုးကို အတည်ပြုရန် အသုံးပြုပါ၊ အထူးသဖြင့်
> whitespace ကို လက်မခံရမည့်အခါ။

### အားသာချက်များ

- အဝင်တန်ဖိုးသည် စာကြောင်း (string) ဖြစ်ကြောင်းကို တင်းကျပ်စွာ စစ်ဆေးပြီး ဒသမ-လစ်တရယ် (decimal-literal) ပုံစံနှင့်
  ကိုက်ညီမှုရှိကြောင်း အတည်ပြုသည်။
- မရှင်းလင်းသော parsing ဖြစ်နိုင်ခြေကို ရှောင်ရန် အရှေ့/အနောက် whitespace (control characters အပါအဝင်) ကို လက်မခံပါ။
- regex ကို မလုပ်ဆောင်မီ အမြန်ကြိုတင်စစ်ဆေးမှုများ (type check နှင့် ပထမ/နောက်ဆုံး အက္ခရာ) ကို လုပ်ဆောင်သည်။
- guards နှင့် input validation အတွက် သင့်တော်သော ရိုးရှင်းသည့် boolean ရလဒ် (`true`/`false`) ကို ပြန်ပေးသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `isDecimal(value)`

ပါရာမီတာများ:

- `value`: ဒသမ စာကြောင်း (decimal string) ဖော်မတ်ဖြစ်မဖြစ် စစ်ဆေးရန် တန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // ဒီနေရာမှာ v က စာသား (runtime မှာ စစ်ဆေးအတည်ပြုပြီးသား)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```
