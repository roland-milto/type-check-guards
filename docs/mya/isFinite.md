# isFinite

## ဖော်ပြချက်

ပေးထားသော `value` သည် အဆုံးမရှိမဟုတ်သော `number` ဟုတ်မဟုတ်ကို သတ်မှတ်သည်။

### အသုံးပြုမှုကိစ္စ

ကိန်းဂဏန်းတွက်ချက်မှုများ မလုပ်မီ (ဥပမာ JSON, ဖောင်များ၊ သို့မဟုတ် API များမှ) မသေချာသော input ကို အတည်ပြုရန် `isFinite`
ကို အသုံးပြုပါ၊ ထိုတန်ဖိုးသည် အမှန်တကယ် အဆုံးမရှိမဟုတ်သော ကိန်းဂဏန်းဖြစ်ကြောင်း သေချာစေရန် ဖြစ်သည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> `isFinite` သည် အဆုံးမရှိမဟုတ်သော ကိန်းဂဏန်းများအတွက်သာ `true` ပြန်ပေးပြီး `NaN`, `Infinity` နှင့် ကိန်းဂဏန်းမဟုတ်သော
> တန်ဖိုး မည်သည့်အရာမဆိုအတွက် `false` ပြန်ပေးသည်။

### အားသာချက်များ

- ယုံကြည်စိတ်ချရသော အဆုံးမရှိမဟုတ်မှု စစ်ဆေးမှုအတွက် built-in `Number.isFinite` ကို အသုံးပြုသည်။
- အဆုံးမရှိမဟုတ်သော ကိန်းဂဏန်းများအတွက်သာ `true` ပြန်ပေးပြီး `NaN`, `Infinity` နှင့် ကိန်းဂဏန်းမဟုတ်သော input များအတွက်
  `false` ပြန်ပေးသည်။
- စစ်ဆေးခြင်းနှင့် guarding logic အတွက် သင့်တော်သော ရိုးရှင်းပြီး side-effect မရှိသော predicate ဖြစ်သည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `isFinite(value)`

ပါရာမီတာများ:

- `value`: အဆုံးမရှိမဟုတ်မှုကို စစ်ဆေးရန် တန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { isFinite } from "@type-check/guards";

const inputs: unknown[] = [123, -123.45, "123", Infinity, NaN, null, undefined];

const finiteNumbers = inputs.filter(isFinite);
// finiteNumbers သည်: [123, -123.45]

const value: unknown = 42;
if (isFinite(value)) {
  // ဒီနေရာမှာ value သည် အဆုံးသတ်ရှိသော ကိန်းဂဏန်း ဖြစ်သည်
  const doubled = value * 2;
  console.log(doubled);
}
```
