# areNaNs

## ဖော်ပြချက်

`areNaNs` သည် အာရေးတစ်ခုအတွင်းရှိ အရာဝတ္ထုအားလုံးက `NaN` ဖြစ်/မဖြစ်ကို စစ်ဆေးပြီး အရာဝတ္ထုတိုင်းက `NaN` ဖြစ်တဲ့အခါမှသာ
`true` ကို ပြန်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

`NaN` ကို sentinel value အဖြစ် သုံးထားတဲ့ ဝင်လာသော ဒေတာကို အတည်ပြုရာတွင် အာရေးတစ်ခုလုံးက `NaN` သာဖြစ်နေကြောင်း
သေချာစေရမည် (ဥပမာ၊ အားလုံးပျောက်နေသော ကိန်းဂဏန်း စီးရီးကို ရှာဖွေခြင်း)။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> စာသားကို ကိန်းဂဏန်းအဖြစ် မပြောင်းလဲဘဲ (string-to-number coercion မလုပ်ဘဲ) အာရေးတစ်ခုမှာ ကိန်းဂဏန်း `NaN` တန်ဖိုးသာ
> ပါဝင်နေကြောင်း အတည်ပြုရန် လိုအပ်တဲ့အခါ `areNaNs` ကို အသုံးပြုပါ။

### အားသာချက်များ

- အရာဝတ္ထုတိုင်းက `NaN` ဖြစ်တဲ့အခါမှသာ `true` ကို ပြန်ပေးသည် (အရာဝတ္ထုအားလုံးကို တင်းကျပ်စွာ စစ်ဆေးခြင်း)။
- စာသားကို ကိန်းဂဏန်းအဖြစ် မပြောင်းလဲပေးပါ; "NaN" လို တန်ဖိုးတွေက `NaN` မဟုတ်သေးဘဲ ရလဒ်ကို `false` ဖြစ်စေသည်။
- အရာဝတ္ထုမဖြည့်ထားသော အာရေးများအတွက် `false` ကို ပြန်ပေးပြီး အလွတ် input ပေါ်မှာ မတော်တဆ `true` ဖြစ်သွားခြင်းကို
  တားဆီးသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `areNaNs(array)`

ပါရာမီတာများ:

- `array`: `NaN` တန်ဖိုးများ ရှိ/မရှိ စစ်ဆေးရန် အာရေး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // မှန်
const b = areNaNs([NaN, 1, NaN]); // မှား
const c = areNaNs([NaN, "NaN", NaN]); // မှား
const d = areNaNs([NaN, null, NaN]); // မှား
const e = areNaNs([] as unknown[]); // မှား
```

### အများပြည်သူဆိုင်ရာ အော်ဘျက် အင်ပို့

လုပ်ဆောင်ချက်များကို အများပြည်သူဆိုင်ရာ အော်ဘျက်မက်သဒ်များအဖြစ် အင်ပို့ရန် အောက်ပါတို့ကို အသုံးပြုပါ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

အောက်ပါ မက်သဒ်သည် ထို့နောက် အများပြည်သူဆိုင်ရာ သုံးနိုင်ပါလိမ့်မည်:

- `Type.areNaNs(array)`
