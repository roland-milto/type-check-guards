# isNaN

## ဖော်ပြချက်

စာသားများကို မပြောင်းလဲဘဲ ပေးထားသော `value` သည် `number` အမျိုးအစား၏ `NaN` ဟုတ်မဟုတ် သတ်မှတ်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

ယုံကြည်မရသော သို့မဟုတ် အမျိုးအစားမတိကျသော အဝင်ဒေတာ (ဥပမာ API payloads, form values, parsed JSON) ကို စစ်ဆေးရာတွင်
အထူးတန်ဖိုး `NaN` ကို တွေ့ရှိပြီး ထင်ရှားစွာ ကိုင်တွယ်နိုင်ရန် အသုံးပြုပါ။ ထို့အပြင် နံပါတ်မဟုတ်သော အဝင်တန်ဖိုးများကို
`NaN` မဟုတ်ဟု သတ်မှတ်ပေးသည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> အဝင်တန်ဖိုးသည် တကယ်တမ်း `number` ဖြစ်နေကြောင်းကို သေချာစေပြီး (string ကို number သို့ မပြောင်းလဲဘဲ) အထူး နံပါတ်တန်ဖိုး
`NaN` ကို ရှာဖွေလိုသည့်အခါ `isNaN` ကို အသုံးပြုပါ။

### အားသာချက်များ

- နံပါတ်မဟုတ်သော တန်ဖိုးများ (ဥပမာ စာသား string) ကို နံပါတ်အဖြစ် မပြောင်းလဲဘဲ `NaN` ဟုတ်မဟုတ် စစ်ဆေးပေးသည်။
- `number` အမျိုးအစားလည်း ဖြစ်ပြီး `NaN` လည်း ဖြစ်သော တန်ဖိုးများအတွက်သာ `true` ကို ပြန်ပေးသည်။
- `unknown` အဝင်တန်ဖိုးများအတွက်လည်း လုံခြုံပြီး အလိုအလျောက် ပြောင်းလဲမှုများကြောင့် မှားယွင်းစွာ `true`
  ဖြစ်သွားခြင်းကို ရှောင်ရှားပေးသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `isNaN(value)`

ပါရာမီတာများ:

- `value`: `number` အမျိုးအစားဖြစ်သော `NaN` ဟုတ်မဟုတ် စစ်ဆေးရန် တန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // မှန်
console.log(isNaN(b)); // မမှန်
console.log(isNaN(c)); // မမှန်

if (isNaN(a)) {
  // a သည် ကိန်းဂဏန်းတစ်ခုဖြစ်ပြီး အထူးသဖြင့် NaN ဖြစ်သည်
}
```

### အများပြည်သူဆိုင်ရာ အော်ဘျက် အင်ပို့

လုပ်ဆောင်ချက်များကို အများပြည်သူဆိုင်ရာ အော်ဘျက်မက်သဒ်များအဖြစ် အင်ပို့ရန် အောက်ပါတို့ကို အသုံးပြုပါ:

```ts

```

အောက်ပါ မက်သဒ်သည် ထို့နောက် အများပြည်သူဆိုင်ရာ သုံးနိုင်ပါလိမ့်မည်:

- `Type.isNaN(value)`
