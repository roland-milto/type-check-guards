# areArrays

## ဖော်ပြချက်

`areArrays` သည် တန်ဖိုးတစ်ခုသည် အစိတ်အပိုင်းအားလုံးက အာရေးများဖြစ်နေသော အလွတ်မဟုတ်သော နှစ်ဖက်မြင် အာရေး (2D array)
ဟုတ်မဟုတ်ကို သတ်မှတ်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

row/column လုပ်ဆောင်ချက်များကို မလုပ်ဆောင်မီ ဇယားပုံစံ သို့မဟုတ် မက်ထရစ်ပုံစံ ထည့်သွင်းချက်များ (ဥပမာ CSV rows, grid
data, သို့မဟုတ် grouped lists) ကို အတည်ပြုရန် `areArrays` ကို အသုံးပြုပါ။ ထည့်သွင်းချက်သည် array မဟုတ်ပါက၊ အလွတ်ဖြစ်ပါက၊
သို့မဟုတ် array မဟုတ်သော အစိတ်အပိုင်းတစ်ခုခု ပါဝင်ပါက `false` ကို ပြန်ပေးသည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> nested array များအတွင်းသို့ iterate လုပ်ခြင်း သို့မဟုတ် index ဖြင့် ဝင်ရောက်မလုပ်မီ တန်ဖိုးတစ်ခုသည် အလွတ်မဟုတ်သော 2D
> array ဖြစ်ပြီး row တစ်ခုချင်းစီသည် array ဖြစ်ကြောင်း သေချာစေရန်လိုသည့်အခါ `areArrays` ကို အသုံးပြုပါ။

### အားသာချက်များ

- ထည့်သွင်းထားသောတန်ဖိုးသည် အလွတ်မဟုတ်သော နှစ်ဖက်မြင် အာရေး (2D array) ဖြစ်ပြီး အစိတ်အပိုင်းတိုင်းသည် အာရေး (array)
  ဖြစ်ကြောင်းကို စစ်ဆေးပေးသည်။
- ကာကွယ်ရေး (guards) နှင့် အစောပိုင်းထွက်ခြင်း (early exits) အတွက် သင့်တော်သော ရိုးရှင်းသော boolean ရလဒ် (`true`/
  `false`) ကို ပြန်ပေးသည်။
- နောက်ပိုင်းကုဒ်တွင် nested array လုပ်ဆောင်ချက်များ (ဥပမာ row များကို mapping လုပ်ခြင်း) ကို ယူဆထားသောအခါ runtime error
  များ ဖြစ်ပေါ်ခြင်းကို ကာကွယ်ရန် ကူညီပေးသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `areArrays(array)`

ပါရာမီတာများ:

- `array`: စစ်ဆေးရန် ထည့်သွင်းထားသောတန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value သည် အစိတ်အပိုင်းများအဖြစ် array များပါဝင်သော ၂-အတိုင်းအတာ array တစ်ခုဖြစ်သည်
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

- `Type.areArrays(array)`
