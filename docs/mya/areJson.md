# areJson

## ဖော်ပြချက်

array တစ်ခုအတွင်းရှိ အင်္ဂါရပ်အားလုံးသည် JSON စာတန်းများ ဟုတ်/မဟုတ် စစ်ဆေးပြီး၊ array ထဲမှာ အချက်အလက်ဖြည့်ထားပြီး
အရာအားလုံးက မှန်ကန်တဲ့ JSON ဖြစ်မှသာ `true` ကို ပြန်ပေးသည်။ မဟုတ်ပါက `false` ကို ပြန်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

ဝင်လာတဲ့ ဒေတာ (ဥပမာ query params, environment variables, သို့မဟုတ် external APIs မှ) ကို စစ်ဆေးအတည်ပြုရာမှာ JSON-encoded
စာတန်းများပါသော array တစ်ခုကို မျှော်လင့်ပြီး အလွတ် array များ သို့မဟုတ် JSON မဟုတ်တဲ့ entry များကို ပယ်ချလိုတဲ့အခါ
အသုံးပြုသည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> `unknown[]` ထဲမှာ JSON စာတန်းများသာ ပါဝင်ကြောင်းကို parse မလုပ်ခင် (ဥပမာ `JSON.parse` နဲ့) အတည်ပြုစစ်ဆေးရန်
> လိုအပ်တဲ့အခါ `areJson` ကို အသုံးပြုပါ။

### အားသာချက်များ

- အင်္ဂါရပ်တိုင်းက မှန်ကန်တဲ့ JSON စာတန်းဖြစ်တဲ့အခါမှသာ `true` ကို ပြန်ပေးပြီး၊ မဟုတ်ရင် `false` ကို ပြန်ပေးသည်။
- အမြန်ဆုံး မအောင်မြင်စေသည် (fails fast): JSON မဟုတ်တဲ့ အင်္ဂါရပ်တစ်ခုကို တွေ့တာနဲ့ စစ်ဆေးမှုကို ချက်ချင်း ရပ်တန့်သည်။
- ဒီဇိုင်းအရ အလွတ် array များကို လက်မခံဘဲ၊ အချက်အလက်မဖြည့်ထားတဲ့ input အတွက် `false` ကို ပြန်ပေးသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `areJson(array)`

ပါရာမီတာများ:

- `array`: JSON စာတန်း အင်္ဂါရပ်များ ပါ/မပါ စစ်ဆေးရန် array ဖြစ်သည်။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // မှန်
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // မမှန်
const empty = areJson([]); // မမှန်

```
