# areEqual

## ဖော်ပြချက်

`areEqual` သည် array တစ်ခုအတွင်းရှိ အင်္ဂါရပ်အားလုံးသည် ပေးထားသော မျှော်မှန်းတန်ဖိုးနှင့် တူညီနေသလားကို စစ်ဆေးပြီး၊ item
အားလုံးကိုက်ညီသော မလွတ်သော array များအတွက်သာ `true` ကို ပြန်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

စာရင်းတစ်ခုတွင် ခွင့်ပြုထားသော တန်ဖိုးတစ်မျိုးတည်းသာ ပါဝင်နေကြောင်း အတည်ပြုရန် (ဥပမာ၊ status flags အားလုံး `true`
ဖြစ်ခြင်း၊ roles အားလုံး `"admin"` ဖြစ်ခြင်း၊ သို့မဟုတ် ကိန်းဂဏန်း entries အားလုံးသည် လိုအပ်သော constant တန်ဖိုးနှင့်
တူညီခြင်း) ကို စစ်ဆေးရာတွင် အသုံးပြုနိုင်ပြီး၊ empty input ကို မမှန်ကန်ဟု သတ်မှတ်ကာ (`false`) ပြန်ပေးသည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> item အားလုံးကို တိတိကျကျ စစ်ဆေးရန် လိုအပ်သည့်အခါ `areEqual` ကို အသုံးပြုပါ; empty array များနှင့် array မဟုတ်သော
> သို့မဟုတ် မဖြည့်ထားသော input များအတွက် `false` ကို ပြန်ပေးသည်။

### အားသာချက်များ

- အင်္ဂါရပ်အားလုံးက မျှော်မှန်းထားသော တန်ဖိုးနှင့် ကိုက်ညီသည့်အခါမှသာ `true` ကို ပြန်ပေးပြီး၊ မဟုတ်ပါက `false` ကို
  ပြန်ပေးသည်။
- အမြန်ဆုံး မအောင်မြင်စေသည် (fails fast): မကိုက်ညီသော အင်္ဂါရပ်တစ်ခုကို တွေ့သည်နှင့် စစ်ဆေးမှုကို ချက်ချင်း ရပ်တန့်သည်။
- ထည့်သွင်းမှုသည် ဖြည့်ထားသော array မဟုတ်ပါက `false` ကို ပြန်ပေးခြင်းဖြင့် မမှန်ကန်သော input များမှ ကာကွယ်ပေးသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `areEqual(value, expected)`

ပါရာမီတာများ:

- `value`: စစ်ဆေးမည့် array ဖြစ်သည်။
- `expected`: array အတွင်းရှိ item တစ်ခုချင်းစီနှင့် နှိုင်းယှဉ်မည့် အင်္ဂါရပ် (element) ဖြစ်သည်။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```
