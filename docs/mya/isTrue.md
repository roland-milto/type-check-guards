# isTrue

## ဖော်ပြချက်

`isTrue` သည် ပေးထားသော တန်ဖိုးသည် `true` နှင့် တင်းကျပ်စွာ တူညီခြင်းရှိမရှိကို သတ်မှတ်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

literal `true` ကိုသာ လက်ခံရမည့် flags, feature toggles, သို့မဟုတ် configuration values များကို အတည်ပြုရန် `isTrue` ကို
အသုံးပြုပါ၊ အခြားအရာအားလုံးကို `false` အဖြစ် သတ်မှတ်ရမည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> truthy တန်ဖိုးများကို မဟုတ်ဘဲ boolean literal `true` ကိုသာ လက်ခံရန် လိုအပ်သည့်အခါ `isTrue` ကို အသုံးပြုပါ။

### အားသာချက်များ

- boolean literal `true` ကို တင်းကျပ်စွာ စစ်ဆေးပေးသည် (coercion မလုပ်ပါ)။
- `true` ကို `1`, `"true"`, သို့မဟုတ် `{}` ကဲ့သို့ truthy တန်ဖိုးများနှင့် ခွဲခြားသိနိုင်ရန် ကူညီပေးသည်။
- guards နှင့် validation pipelines များအတွက် သင့်တော်သော ရိုးရှင်းပြီး ခန့်မှန်းနိုင်သော အပြုအမူကို ပေးသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `isTrue(value)`

ပါရာမီတာများ:

- `value`: စစ်ဆေးမည့် တန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // အမှန်
const b = isTrue(1);         // အမှား
const c = isTrue("true");   // အမှား

if (isTrue(a)) {
  // ဒီနေရာမှာ a က အမှန် ဖြစ်တယ်
}
```

### အများပြည်သူဆိုင်ရာ အော်ဘျက် အင်ပို့

လုပ်ဆောင်ချက်များကို အများပြည်သူဆိုင်ရာ အော်ဘျက်မက်သဒ်များအဖြစ် အင်ပို့ရန် အောက်ပါတို့ကို အသုံးပြုပါ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

အောက်ပါ မက်သဒ်သည် ထို့နောက် အများပြည်သူဆိုင်ရာ သုံးနိုင်ပါလိမ့်မည်:

- `Type.isTrue(value)`
