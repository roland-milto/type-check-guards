# areMaps

## ဖော်ပြချက်

`areMaps` သည် ပေးထားသော array တစ်ခုသည် အလွတ်မဟုတ်ပြီး ၎င်း၏ အစိတ်အပိုင်းအားလုံးသည် `Map` instance များဖြစ်ကြောင်းကို
သတ်မှတ်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

မသိရသေးသော input (ဥပမာ JSON parsing မှ၊ ပြင်ပ API များမှ၊ သို့မဟုတ် dynamic source များမှ) ကို `Map` object များ၏
အလွတ်မဟုတ်သော စာရင်းအဖြစ် သဘောထားမီ အတည်ပြုစစ်ဆေးရန်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> အလွတ် array အတွက် `false` ကို ပြန်ပေးသည်။ array ထဲတွင် တန်ဖိုးများဖြင့် ပြည့်နေပြီး အစိတ်အပိုင်းတိုင်းသည် `Map`
> ဖြစ်သည့်အခါမှသာ `true` ကို ပြန်ပေးသည်။

### အားသာချက်များ

- အရာဝတ္ထုတိုင်းဟာ `Map` instance ဖြစ်ကြောင်း သေချာစေပြီး၊ array တစ်ခုလုံးက စစ်ဆေးမှုကို ဖြတ်သန်းတဲ့အခါမှသာ `true` ကို
  ပြန်ပေးသည်။
- ဒီဇိုင်းအရ အလွတ် array များကို လက်မခံဘဲ ပယ်ချသဖြင့် “ဒေတာမရှိ” ကို မှန်ကန်သော input အဖြစ် မတော်တဆ လက်ခံသွားခြင်းကို
  တားဆီးပေးသည်။
- `Map` သီးသန့် လုပ်ဆောင်ချက်များ (ဥပမာ `.get()`, `.set()`, iteration) ကို စုစည်းမှုတစ်ခုလုံးအပေါ် လုပ်ဆောင်မီ guard
  အဖြစ် အသုံးဝင်သည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `areMaps(array)`

ပါရာမီတာများ:

- `array`: စစ်ဆေးရန် array ဖြစ်သည်။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // runtime မှာ items ဟာ Map instance တွေပါဝင်တဲ့ မလွတ်တဲ့ array ဖြစ်တာကို အာမခံထားတယ်
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // false ဖြစ်မယ်: အလွတ် array တွေ၊ သို့မဟုတ် Map မဟုတ်တဲ့ တန်ဖိုးတစ်ခုခု ပါဝင်တဲ့ array တွေ
}

```
