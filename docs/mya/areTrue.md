# areTrue

## ဖော်ပြချက်

မလွတ်လပ်သော array တစ်ခုတွင် boolean `true` တန်ဖိုးများသာ ပါဝင်နေသလား စစ်ဆေးသည်။

### အသုံးပြုမှုကိစ္စ

ဆက်လက်လုပ်ဆောင်မီ ကြိုတင်လိုအပ်ချက်များ သို့မဟုတ် feature flags များအားလုံး ဖွင့်ထားပြီးသား (တန်ဖိုးအားလုံး `true`)
ဖြစ်ကြောင်း အတည်ပြုရန် `areTrue` ကို အသုံးပြုပါ။ အလွတ် သို့မဟုတ် ပုံစံမမှန်သော input များကိုလည်း မပြည့်စုံဟု
သတ်မှတ်ပြီး (`false`) အဖြစ် ကိုင်တွယ်သည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> `areTrue` သည် အလွတ် array အတွက်လည်းကောင်း၊ တိတိကျကျ `true` မဟုတ်သော တန်ဖိုးတစ်ခုခု ပါဝင်သော array များအတွက်လည်းကောင်း
`false` ကို ပြန်ပေးသည်။

### အားသာချက်များ

- အာရေးထဲမှာ အစိတ်အပိုင်းအားလုံးက တိတိကျကျ `true` ဖြစ်ပြီး အာရေးက မလွတ်လပ် (အလွတ်မဟုတ်) သောအခါမှသာ `true` ကို
  ပြန်ပေးသည်။
- အမြန်ဆုံး ရပ်တန့်သည် (fails fast): `true` မဟုတ်သော တန်ဖိုးတစ်ခုကို တွေ့သလို `false` ကို ချက်ချင်း ပြန်ပေးသည်။
- မမှန်ကန်သော input များ (array မဟုတ်ခြင်း သို့မဟုတ် အလွတ် array) ကို `false` ပြန်ပေးခြင်းဖြင့် ပယ်ချသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `areTrue(array)`

ပါရာမီတာများ:

- `array`: `true` တန်ဖိုးများသာ အားလုံးပါဝင်နေသလား စစ်ဆေးရန် အာရေး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { areTrue } from "@type-check/guards";

const a = areTrue([true, true, true]);
const b = areTrue([true, false, true]);
const c = areTrue([]);
const d = areTrue([true, "string" as unknown, true]);

console.log(a, b, c, d);
```


- `Type.areTrue(array)`
