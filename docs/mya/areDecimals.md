# areDecimals

## ဖော်ပြချက်

array တစ်ခုအတွင်းရှိ အင်္ဂါရပ်အားလုံးသည် ဒသမကိန်းများဖြစ်ပြီး array သည် အချက်အလက်ပါရှိကြောင်းကို စစ်ဆေးကာ `true`
သို့မဟုတ် `false` ကို ပြန်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

အသုံးပြုသူပေးသော စာရင်းများ (ဥပမာ CSV ကော်လံများ သို့မဟုတ် ဖောင်ထည့်သွင်းမှုများ) ကို စစ်ဆေးရာတွင် array သည်
အလွတ်မဟုတ်ကြောင်းနှင့် အချက်အလက်တိုင်းသည် ဒသမတန်ဖိုးဖြစ်ကြောင်းကို parsing သို့မဟုတ် တွက်ချက်မှုများ မလုပ်မီ သေချာစေရန်
အသုံးပြုသည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> `unknown[]` တစ်ခုသည် အလွတ်မဟုတ်ကြောင်းနှင့် အင်္ဂါရပ်တိုင်းသည် ဒသမကိန်းကို ကိုယ်စားပြုထားခြင်းဖြစ်ကြောင်းကို အမြန်
> boolean စစ်ဆေးရန်လိုသည့်အခါ `areDecimals` ကို အသုံးပြုပါ။

### အားသာချက်များ

- အိုင်တမ်များကို စစ်ဆေးမီ အဝင်တန်ဖိုးသည် အချက်အလက်ပါသော array ဖြစ်ကြောင်း သေချာစေပြီး အလွတ်စာရင်းများကို မတော်တဆ
  လက်ခံသွားခြင်းကို တားဆီးပေးသည်။
- အင်္ဂါရပ်တိုင်းကို `isDecimal` ဖြင့် စစ်ဆေးသဖြင့် ရောနှောထားသော သို့မဟုတ် မမှန်ကန်သော တန်ဖိုးများရှိပါက ချက်ချင်း
  `false` ကို ပြန်ပေးသည်။
- `true`/`false` ဆိုသော ရိုးရှင်းသော boolean ရလဒ်ကို ပေးသဖြင့် guard များနှင့် early-return စစ်ဆေးမှု
  လုပ်ငန်းစဉ်များတွင် သင့်တော်သည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `areDecimals(array)`

ပါရာမီတာများ:

- `array`: စစ်ဆေးရန် array ဖြစ်သည်။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // မှန်
console.log(areDecimals(b)); // မှား
console.log(areDecimals(c)); // မှား
```
