# isSet

## ဖော်ပြချက်

ပေးထားသော တန်ဖိုးတစ်ခုသည် `Set` ဟုတ်မဟုတ်ကို သတ်မှတ်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

ပြင်ပရင်းမြစ်များမှ (ဥပမာ JSON parsing, အသုံးပြုသူထည့်သွင်းမှု, သို့မဟုတ် third-party API များ) ဝင်လာသော input များကို
စစ်ဆေးအတည်ပြုပြီး `Set` လုပ်ဆောင်ချက်များကို လုပ်ဆောင်မီ တန်ဖိုးတစ်ခုသည် `Set` ဖြစ်ကြောင်း သေချာစေရန် အသုံးပြုသည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> `.add`, `.has`, သို့မဟုတ် `.size` ကဲ့သို့ `Set`-အထူး API များကို ခေါ်မီ `unknown` တန်ဖိုးများကို
> ကျဉ်းမြောင်းသတ်မှတ်ရန် `isSet` ကို အသုံးပြုပါ။

### အားသာချက်များ

- တန်ဖိုးတစ်ခုသည် `Set` ဟုတ်မဟုတ်ကို အလုပ်လုပ်ချိန် (runtime) တွင် ရိုးရှင်းစွာ စစ်ဆေးအတည်ပြုနိုင်စေသည်။
- တန်ဖိုးတစ်ခုသည် `Set` မဟုတ်သည့်အခါ အစောပိုင်းတွင် ခွဲခြားလုပ်ဆောင်နိုင်စေပြီး type error များကို ကာကွယ်ရန် ကူညီပေးသည်။
- `Set` အတွင်းပါဝင်သည့် အကြောင်းအရာမည်သို့ပင်ဖြစ်စေ (အလွတ် သို့မဟုတ် အချက်အလက်ပါဝင်) အလုပ်လုပ်ပြီး `true`/`false` ကို
  တစ်သမတ်တည်း ပြန်ပေးသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `isSet(value)`

ပါရာမီတာများ:

- `value`: စစ်ဆေးရန် တန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // a သည် runtime တွင် Set ဖြစ်သည်
  console.log(a.size);
}

console.log(isSet(b)); // မမှန်
```
