# isFloat

## ဖော်ပြချက်

`isFloat` သည် ပေးထားသော `value` သည် အကန့်အသတ်ရှိသော floating-point ကိန်းဂဏန်း (ကိန်းပြည့်မဟုတ်သော `number`) ဟုတ်မဟုတ်ကို
သတ်မှတ်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

အပိုင်းကိန်းတန်ဖိုးများ လိုအပ်သည့် (ဥပမာ- စျေးနှုန်းများ၊ တိုင်းတာချက်များ၊ နှုန်းထားများ) အသုံးပြုသူပေးသော ကိန်းဂဏန်း
input ကို အတည်ပြုပြီး ကိန်းပြည့်များ၊ `NaN` နှင့် infinity များကို ငြင်းပယ်ရန်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> အကန့်အသတ်ရှိပြီး ကိန်းပြည့်မဟုတ်သော ကိန်းဂဏန်း input များကိုသာ လက်ခံရန်လိုသည့်အခါ `isFloat` ကို အသုံးပြုပါ; ၎င်းသည်
> ကိန်းပြည့်များနှင့် အကန့်အသတ်မရှိသော ကိန်းဂဏန်းများကို ငြင်းပယ်သည်။

### အားသာချက်များ

- ကိန်းပြည့်များ၊ `NaN`၊ `Infinity` နှင့် `-Infinity` ကို ဖယ်ထုတ်ပြီး အကန့်အသတ်ရှိသော (finite) ကိန်းပြည့်မဟုတ်သည့်
  ကိန်းဂဏန်းများအတွက်သာ `true` ကို ပြန်ပေးသည်။
- မည်သည့် input အမျိုးအစား (`unknown`) မဆို အသုံးပြုနိုင်ပြီး `typeof value === "number"` ကို စစ်ဆေးခြင်းဖြင့်
  လုံခြုံစွာ narrow လုပ်ပေးသည်။
- ခန့်မှန်းနိုင်သော အပြုအမူအတွက် built-in numeric guards (`Number.isInteger`, `Number.isFinite`) ကို အသုံးပြုသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `isFloat(value)`

ပါရာမီတာများ:

- `value`: floating-point ကိန်းဂဏန်း ဟုတ်မဟုတ် စစ်ဆေးရန် တန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { isFloat } from "@type-check/guards";

const inputs: unknown[] = [3.14, -0.1, 1e-7, 42, "3.14", NaN, Infinity];

for (const value of inputs) {
  if (isFloat(value)) {
    // value သည် runtime တွင် နံပါတ်ဖြစ်ပြီး၊ အဆုံးမရှိမဟုတ်သလို ကိန်းပြည့်လည်း မဟုတ်ပါ
    const rounded = value.toFixed(2);
    console.log("float:", value, "rounded:", rounded);
  } else {
    console.log("not a float:", value);
  }
}

```
