# areNumbers

## ဖော်ပြချက်

`areNumbers` သည် တန်ဖိုးတစ်ခုက element အားလုံးသည် number ဖြစ်သော အလွတ်မဟုတ်သော array ဟုတ်မဟုတ်ကို စစ်ဆေးသည်။

### အသုံးပြုမှုကိစ္စ

အသုံးပြုသူပေးသော သို့မဟုတ် API မှ ပေးသော ဒေတာကို စုစုပေါင်း၊ ပျမ်းမျှ သို့မဟုတ် အခြား ကိန်းဂဏန်းစုစည်းတွက်ချက်မှုများ
မလုပ်မီ number များပါဝင်သော အလွတ်မဟုတ်သော array ဖြစ်ကြောင်း အတည်ပြုရန်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> `areNumbers` ကို မသေချာသော array များကို ကိန်းဂဏန်းတွက်ချက်မှုများ မလုပ်မီ အတည်ပြုရန် အသုံးပြုပါ; အလွတ် array
> များနှင့် number မဟုတ်သော တန်ဖိုးတစ်ခုခု ပါဝင်သော array များအတွက် `false` ကို ပြန်ပေးသည်။

### အားသာချက်များ

- ထည့်သွင်းထားသောတန်ဖိုးသည် အလွတ်မဟုတ်သော array ဖြစ်ပြီး element အားလုံးသည် number ဖြစ်သည့်အခါမှသာ `true` ကို
  ပြန်ပေးသည်။
- အလွတ် array များနှင့် array မဟုတ်သော input များကို ငြင်းပယ်ခြင်းဖြင့် false positive မဖြစ်စေရန် ကာကွယ်ပေးသည်။
- runtime error မဖြစ်စေရန် (ဥပမာ စုစုပေါင်းတွက်ခြင်း၊ ပျမ်းမျှတွက်ခြင်း) ကဲ့သို့သော ကိန်းဂဏန်းဆိုင်ရာ လုပ်ဆောင်ချက်များ
  မလုပ်မီ guard အဖြစ် အသုံးဝင်သည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `areNumbers(array)`

ပါရာမီတာများ:

- `array`: number element များ ပါဝင်မပါဝင် စစ်ဆေးရန် array ဖြစ်သည်။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### အများပြည်သူဆိုင်ရာ အော်ဘျက် အင်ပို့

လုပ်ဆောင်ချက်များကို အများပြည်သူဆိုင်ရာ အော်ဘျက်မက်သဒ်များအဖြစ် အင်ပို့ရန် အောက်ပါတို့ကို အသုံးပြုပါ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

အောက်ပါ မက်သဒ်သည် ထို့နောက် အများပြည်သူဆိုင်ရာ သုံးနိုင်ပါလိမ့်မည်:

- `Type.areNumbers(array)`
