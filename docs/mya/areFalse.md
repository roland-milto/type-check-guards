# areFalse

## ဖော်ပြချက်

`areFalse` သည် ပေးထားသော array ထဲရှိ အင်္ဂါရပ်အားလုံးသည် boolean `false` ကို တိတိကျကျ ဖြစ်နေသလားကို စစ်ဆေးသည်။

### အသုံးပြုမှုကိစ္စ

ဆက်လက်လုပ်ဆောင်မီ feature flags များ၊ စစ်ဆေးမှုများ သို့မဟုတ် guard ရလဒ်များအားလုံး `false` ဖြစ်နေကြောင်းကို
အတည်ပြုရန် (ဥပမာ၊ တားဆီးနေသော အခြေအနေများ မရှိကြောင်း အတည်ပြုရန်)။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> array သည် အလွတ်မဟုတ်ကြောင်းနှင့် boolean တန်ဖိုး `false` သာ ပါဝင်ကြောင်းကို တိတိကျကျ အတည်ပြုရန် လိုအပ်သည့်အခါ
`areFalse` ကို အသုံးပြုပါ။

### အားသာချက်များ

- အင်္ဂါရပ်တိုင်းကို တိတိကျကျ `false` ဖြစ်နေကြောင်း သေချာစေသည် (`truthy/falsey` အဖြစ် အလိုအလျောက် ပြောင်းလဲသတ်မှတ်ခြင်း
  မရှိ)။
- `isFilledArray` ဖြင့် အချက်အလက်ပါဝင်သော array ကိုသာ လိုအပ်စေခြင်းကြောင့် array မဟုတ်သည့်အရာများ သို့မဟုတ် အလွတ် array
  များအတွက် `false` ကို ပြန်ပေးသည်။
- ထိရောက်မှုအတွက် ပထမဆုံး `false` မဟုတ်သော အင်္ဂါရပ်ကို တွေ့သည်နှင့် ချက်ချင်း ရပ်တန့်သည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `areFalse(array)`

ပါရာမီတာများ:

- `array`: စစ်ဆေးရန် array ဖြစ်ပြီး မည်သည့်အမျိုးအစားမဆို အင်္ဂါရပ်များ ပါဝင်နိုင်သည်။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { areFalse } from "@type-check/guards";

const a = areFalse([false, false, false]); // မှန်
const b = areFalse([false, true, false]);  // မှား
const c = areFalse([false, "false", false]); // မှား
const d = areFalse([]); // မှား
```
