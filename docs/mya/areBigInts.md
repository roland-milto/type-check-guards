# areBigInts

## ဖော်ပြချက်

`areBigInts` သည် တန်ဖိုးတစ်ခုက `bigint` တန်ဖိုးများသာ ပါဝင်သော အလွတ်မဟုတ်တဲ့ အာရေ့ ဖြစ်/မဖြစ်ကို သတ်မှတ်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

မသိရသေးတဲ့ input (ဥပမာ၊ parsed JSON-like data, API payloads, သို့မဟုတ် `unknown` အဖြစ် type သတ်မှတ်ထားတဲ့ function
parameters) ကို စစ်ဆေးပြီး လုပ်ဆောင်မီ `bigint` တန်ဖိုးများ ပါဝင်သော အလွတ်မဟုတ်တဲ့ အာရေ့ ဖြစ်ကြောင်း သေချာစေရန်
အသုံးပြုပါ; အရာဝတ္ထုအားလုံး `bigint` ဖြစ်တဲ့အခါမှသာ `true` ကို ပြန်ပေးပြီး မဟုတ်ရင် `false` ကို ပြန်ပေးသည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> မသိရသေးတဲ့ input ပေါ်မှာ `bigint` သာသုံးနိုင်တဲ့ လုပ်ဆောင်ချက်များ (ဥပမာ၊ သင်္ချာတွက်ချက်မှု၊ နှိုင်းယှဉ်မှု) ကို
> မလုပ်ခင် `areBigInts` ကို runtime guard အဖြစ် အသုံးပြုပါ။

### အားသာချက်များ

- အရာဝတ္ထုတိုင်းဟာ `bigint` ဖြစ်နေကြောင်း သေချာစေပြီး အာရေ့တစ်ခုလုံး ကိုက်ညီတဲ့အခါမှသာ `true` ကို ပြန်ပေးသည်။
- `isFilledArray` ကို အသုံးပြုထားခြင်းကြောင့် ဒီဇိုင်းအရ အာရေ့မဟုတ်တာများနဲ့ အလွတ်အာရေ့များကို လက်မခံဘဲ မမှန်ကန်တဲ့
  input တွေကို မတော်တဆ လက်ခံမိခြင်းကို တားဆီးပေးသည်။
- အမြန်ဆုံး မအောင်မြင်မှု: `bigint` မဟုတ်တဲ့ အရာဝတ္ထုတစ်ခုကို တွေ့တာနဲ့တပြိုင်နက် `false` ကို ပြန်ပေးသည်။
