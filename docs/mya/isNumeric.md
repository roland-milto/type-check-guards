# isNumeric

## ဖော်ပြချက်

`isNumeric` သည် ပေးထားသော `value` ကို `NUMERIC_TYPES` နဲ့ နှိုင်းယှဉ်ပြီး ဖြေရှင်းထားသော type ကို စစ်ဆေးခြင်းအားဖြင့်
ကိန်းဂဏန်းအဖြစ် သတ်မှတ်ထားခြင်း ရှိ/မရှိ ကို ဆုံးဖြတ်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

ကိန်းဂဏန်းဆိုင်ရာ လုပ်ဆောင်ချက်များ မလုပ်မီ input များ (ဥပမာ API payloads, form values, configuration) ကို အတည်ပြုရန်
`isNumeric` ကို အသုံးပြုပါ။ ထို့အပြင် `NUMERIC_TYPES` အရ `BigInt` ကဲ့သို့ numeric-like types များကို တစ်သမတ်တည်း
လက်ခံနိုင်စေသည်။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> `isNumeric` သည် boolean ကို ပြန်ပေးသော predicate ဖြစ်သည်။ တန်ဖိုးတစ်ခုက library က သတ်မှတ်ထားသော numeric type set ထဲမှာ
> ပါဝင်/မပါဝင် ကို runtime မှာ စစ်ဆေးရန် အဖြစ် သဘောထားပြီး အသုံးပြုပါ။

### အားသာချက်များ

- `getTypeOf` နဲ့ `NUMERIC_TYPES` ကို အသုံးပြုပြီး ကိန်းဂဏန်း ခွဲခြားသတ်မှတ်မှု လိုဂစ်ကို တစ်နေရာတည်းမှာ
  စုစည်းထားနိုင်ပြီး codebase တစ်လျှောက် စစ်ဆေးမှုတွေကို တစ်သမတ်တည်း ဖြစ်စေတယ်။
- ခွဲခြားရေး/guard ပုံစံနဲ့ အသုံးပြုရ လွယ်ကူအောင် ရိုးရှင်းတဲ့ boolean (`true`/`false`) ကို ပြန်ပေးတယ်။
- `NUMERIC_TYPES` က သတ်မှတ်ထားသလို ကိန်းဂဏန်း ကိုယ်စားပြုမှု အမျိုးမျိုး (ဥပမာ `number`, `BigInt`) ကို ထောက်ပံ့တယ်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `isNumeric(value)`

ပါရာမီတာများ:

- `value`: ကိန်းဂဏန်း အမျိုးအစား ဟုတ်မဟုတ် စစ်ဆေးရန် တန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    // v ကို စာကြည့်တိုက်ရဲ့ အမျိုးအစား စည်းမျဉ်းများအရ ကိန်းဂဏန်းအဖြစ် သတ်မှတ်ထားသည်
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```
