# isBigInt

## ဖော်ပြချက်

`isBigInt` သည် ပေးထားသော တန်ဖိုးသည် `bigint` အမျိုးအစားဖြစ်/မဖြစ်ကို စစ်ဆေးပြီး BigInt ပရိမစ်များအတွက် `true` ကို
ပြန်ပေးကာ အခြားအရာများအတွက် `false` ကို ပြန်ပေးသည်။

### အသုံးပြုမှုကိစ္စ

BigInt သီးသန့်တွက်ချက်မှုများကို လုပ်ရန် သို့မဟုတ် BigInt သီးသန့် field များတွင် သိမ်းဆည်းရန် မတိုင်မီ
အမျိုးအစားမသတ်မှတ်ထားသော အရင်းအမြစ်များ (ဥပမာ JSON parsing, အသုံးပြုသူထည့်သွင်းမှု, ပြင်ပ API များ) မှ လာသော
တန်ဖိုးများကို အတည်ပြု၍ အမျိုးအစားကျဉ်းမြောင်းစေပါ။

> **TypeScript အသုံးပြုသူများအတွက် မှတ်ချက်:**
>
> BigInt အကိန်းဂဏန်းတွက်ချက်မှု (ဥပမာ `+`, `*`) ကို လုပ်မီ `unknown` ကို `bigint` သို့ ကျဉ်းမြောင်းစေရန် `isBigInt` ကို
> အသုံးပြုပါ။ ထိုလုပ်ဆောင်ချက်များသည် BigInt operand များကို လိုအပ်သည်။

### အားသာချက်များ

- `bigint` ပရိမစ်တစ်အမျိုးအစားအတွက် ရိုးရှင်းပြီး ယုံကြည်စိတ်ချရသော runtime စစ်ဆေးမှုကို ပံ့ပိုးပေးသည်။
- BigInt သီးသန့် လုပ်ဆောင်ချက်များကို လုပ်မီ `unknown` တန်ဖိုးများကို အမျိုးအစားကျဉ်းမြောင်းစေရန် ကူညီပေးသည်။
- မှားယွင်းသော အပြုသဘောရလဒ်များကို ရှောင်ရှားသည်။ ပုံမှန် နံပါတ်များ၊ စာသားများနှင့် အခြားအမျိုးအစားများသည် `false` ကို
  ပြန်ပေးသည်။

## အသုံးပြုခြင်း

### Syntax

လုပ်ဆောင်ချက်:

- `isBigInt(value)`

ပါရာမီတာများ:

- `value`: စစ်ဆေးရန် တန်ဖိုး။

### လုပ်ဆောင်ချက်ကို ဒေသတွင်း အင်ပို့

```ts
import { isBigInt } from "@type-check/guards";

const input: unknown = 10n;

if (isBigInt(input)) {
  const doubled = input * 2n;
  console.log(doubled);
} else {
  console.log("Not a bigint");
}

console.log(isBigInt(10n)); // မှန်
console.log(isBigInt(10));  // မှား
console.log(isBigInt("10")); // မှား
```

### အများပြည်သူဆိုင်ရာ အော်ဘျက် အင်ပို့

လုပ်ဆောင်ချက်များကို အများပြည်သူဆိုင်ရာ အော်ဘျက်မက်သဒ်များအဖြစ် အင်ပို့ရန် အောက်ပါတို့ကို အသုံးပြုပါ:


- `Type.isBigInt(value)`
