# areDates

## Περιγραφή

Το `areDates` καθορίζει αν ένας δεδομένος πίνακας είναι συμπληρωμένος και περιέχει μόνο αντικείμενα `Date`,
επιστρέφοντας `true` μόνο όταν όλα τα στοιχεία είναι έγκυρες ημερομηνίες.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `areDates` για να επικυρώσετε άγνωστη είσοδο (π.χ. αναλυμένο JSON, δεδομένα φόρμας, payloads API) πριν
εκτελέσετε λογική ειδική για ημερομηνίες, όπως ταξινόμηση κατά χρόνο, μορφοποίηση ή υπολογισμό διαστημάτων.

> **Σημείωση για χρήστες TypeScript:**
>
> Επιστρέφει `true` μόνο για μη κενές συστοιχίες όπου κάθε στοιχείο είναι `Date`· οι κενές συστοιχίες επιστρέφουν
`false`.

### Πλεονεκτήματα

- Εξασφαλίζει ότι ένας πίνακας δεν είναι κενός πριν από την επικύρωση του περιεχομένου του, αποτρέποντας την επιστροφή
  `true` για κενές εισόδους.
- Επαληθεύει ότι κάθε στοιχείο είναι στιγμιότυπο `Date`, επιστρέφοντας `false` αμέσως στην πρώτη ασυμφωνία.
- Χρήσιμο ως έλεγχος τύπου guard πριν από την εκτέλεση λειτουργιών ειδικών για ημερομηνίες στα στοιχεία του πίνακα.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areDates(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για αντικείμενα `Date`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areDates } from "@type-check/guards";

const a: unknown[] = [new Date(), new Date("2021-01-01")];
const b: unknown[] = [];
const c: unknown[] = [new Date(), "not a date"];

console.log(areDates(a)); // ἀληθές
console.log(areDates(b)); // ψεῦδος
console.log(areDates(c)); // ψεῦδος

if (areDates(a)) {
  const timestamps = a.map(d => d.getTime());
  console.log(timestamps);
}
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areDates(array)`
