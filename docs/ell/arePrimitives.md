# arePrimitives

## Περιγραφή

Το `arePrimitives` αξιολογεί αν όλα τα στοιχεία σε έναν παρεχόμενο, μη κενό πίνακα είναι πρωτογενείς τύποι.

### Περίπτωση χρήσης

Επικυρώστε ότι τα εισερχόμενα δεδομένα (π.χ. παράμετροι ερωτήματος, τιμές γραμμής CSV ή μια λίστα από IDs/tags)
περιέχουν μόνο πρωτογενείς τιμές πριν από σειριοποίηση, κατακερματισμό, καταγραφή ή πριν τα περάσετε σε APIs που δεν
πρέπει να λαμβάνουν αντικείμενα.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `arePrimitives` όταν χρειάζεται να διασφαλίσετε ότι ένα `unknown[]` περιέχει μόνο πρωτογενείς
> τιμές (string, number, bigint, boolean, symbol, undefined ή null) πριν από περαιτέρω επεξεργασία.

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν κάθε στοιχείο είναι πρωτογενής τιμή, καθιστώντας το αυστηρό έλεγχο για πίνακες «χωρίς
  αντικείμενα/συναρτήσεις».
- Αποτυγχάνει άμεσα: επιστρέφει `false` μόλις εντοπιστεί μη-πρωτογενές στοιχείο.
- Επιστρέφει επίσης `false` για μη-πίνακες και για κενούς πίνακες (μέσω του ελέγχου γεμάτου πίνακα), αποτρέποντας την
  κατά λάθος αποδοχή μη έγκυρης εισόδου.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `arePrimitives(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί ως προς στοιχεία πρωτογενούς τύπου.

### Τοπική εισαγωγή συνάρτησης

```ts
import { arePrimitives } from "@type-check/guards";

const a: unknown[] = [1, "string", true];
const b: unknown[] = [null, undefined, Symbol("x")];
const c: unknown[] = [1, {}, false];

const r1 = arePrimitives(a); // αληθές
const r2 = arePrimitives(b); // αληθές
const r3 = arePrimitives(c); // ψευδές
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.arePrimitives(array)`
