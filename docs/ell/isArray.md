# isArray

## Περιγραφή

Το `isArray` ελέγχει αν μια δεδομένη τιμή είναι πίνακας και επιστρέφει `true` αν είναι, αλλιώς `false`.

### Περίπτωση χρήσης

Επικύρωση άγνωστων δεδομένων (π.χ. parsed JSON ή αποκρίσεις API) ώστε να διασφαλιστεί ότι μια τιμή είναι πίνακας πριν
από επανάληψη, δεικτοδότηση ή πρόσβαση στο `.length`.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `isArray` όταν χρειάζεσαι έλεγχο σε runtime για πίνακες· επιστρέφει boolean και είναι ασφαλές να
> κληθεί με τιμές `unknown`.

### Πλεονεκτήματα

- Χρησιμοποιεί το ενσωματωμένο `Array.isArray` για αξιόπιστη ανίχνευση πινάκων σε διαφορετικά realms (π.χ. iframes).
- Επιστρέφει ένα απλό boolean αποτέλεσμα (`true`/`false`) κατάλληλο για guards και λογική διακλάδωσης.
- Λειτουργεί με οποιονδήποτε τύπο εισόδου επειδή η παράμετρος είναι `unknown`.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isArray(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  // το input είναι πίνακας κατά τον χρόνο εκτέλεσης
  console.log(input.length);
} else {
  console.log("Not an array");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isArray(value)`
