# isFilledArray

## Περιγραφή

Ελέγχει αν το `value` είναι πίνακας με τουλάχιστον ένα στοιχείο, επιστρέφοντας `true` ή `false`.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `isFilledArray` για να επικυρώσετε εισερχόμενα δεδομένα (π.χ. payloads API, τιμές φόρμας, ρυθμίσεις)
πριν από την επανάληψη, την πρόσβαση στο πρώτο στοιχείο ή την εφαρμογή λογικής που απαιτεί τουλάχιστον ένα αντικείμενο.

> **Σημείωση για χρήστες TypeScript:**
>
> Το `isFilledArray` είναι ένας έλεγχος (guard) χρόνου εκτέλεσης που επιστρέφει boolean· δεν περιορίζει τους τύπους των
> στοιχείων πέρα από την επιβεβαίωση ότι ο πίνακας δεν είναι κενός.

### Πλεονεκτήματα

- Απλός, γρήγορος έλεγχος για μη κενό πίνακα χρησιμοποιώντας `Array.isArray` και έλεγχο μήκους.
- Βοηθά στην αποφυγή σφαλμάτων χρόνου εκτέλεσης όταν ο κώδικας υποθέτει ότι ένας πίνακας έχει τουλάχιστον ένα στοιχείο.
- Σαφές αποτέλεσμα boolean: επιστρέφει `true` για μη κενούς πίνακες και `false` διαφορετικά.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isFilledArray(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί αν είναι μη κενός πίνακας.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isFilledArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && isFilledArray(input)) {
  // ἡ εἴσοδος ἐστὶν ἐν τῷ παρόντι χρόνῳ πίναξ οὐ κενός
  console.log(input[0]);
} else {
  console.log("Not a non-empty array");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isFilledArray(value)`
