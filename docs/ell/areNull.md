# areNull

## Περιγραφή

Ελέγχει αν όλα τα στοιχεία στο δοθέν `array` είναι `null`.

### Περίπτωση χρήσης

Επικυρώστε ότι μια στήλη συνόλου δεδομένων, μια λίστα πεδίων API ή ένας πίνακας placeholder περιέχει μόνο τιμές `null`
πριν εφαρμόσετε λογική που υποθέτει ότι όλες οι εγγραφές είναι σκόπιμα κενές.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areNull` όταν χρειάζεστε έναν αυστηρό έλεγχο ότι μια είσοδος είναι μη κενός πίνακας και ότι κάθε
> στοιχείο είναι ακριβώς `null` (όχι `undefined`, όχι ψευδείς τιμές).

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν κάθε στοιχείο είναι `null`, λειτουργώντας ως αυστηρός έλεγχος «όλα ταιριάζουν».
- Απορρίπτει μη-πίνακες και κενούς πίνακες επιστρέφοντας `false`, αποτρέποντας τυχαία αληθή αποτελέσματα σε μη έγκυρη
  είσοδο.
- Λειτουργεί καλά ως έλεγχος προϋπόθεσης πριν από την επεξεργασία δεδομένων που πρέπει να είναι εξ ολοκλήρου `null`.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areNull(array)`

Παράμετροι:

- `array`: Ο πίνακας εισόδου που θα ελεγχθεί για στοιχεία `null`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areNull } from "@type-check/guards";

const a = [null, null];
const b = [null, 1, null];

const allNullA = areNull(a); // αληθές
const allNullB = areNull(b); // ψευδές

const notAnArray = areNull(123 as unknown as unknown[]); // ψευδές
const empty = areNull([]); // ψευδές

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areNull(array)`
