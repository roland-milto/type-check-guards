# areEqual

## Περιγραφή

Το `areEqual` ελέγχει αν όλα τα στοιχεία σε έναν πίνακα είναι ίσα με μια δεδομένη αναμενόμενη τιμή, επιστρέφοντας `true`
μόνο για μη κενές συστοιχίες όπου κάθε στοιχείο ταιριάζει.

### Περίπτωση χρήσης

Επικυρώστε ότι μια λίστα περιέχει μόνο μία επιτρεπόμενη τιμή (π.χ. όλες οι σημαίες κατάστασης είναι `true`, όλοι οι
ρόλοι είναι `"admin"`, ή όλες οι αριθμητικές καταχωρίσεις ισούνται με μια απαιτούμενη σταθερά), αντιμετωπίζοντας την
κενή είσοδο ως μη έγκυρη (`false`).

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areEqual` όταν χρειάζεστε έναν αυστηρό έλεγχο «όλα τα στοιχεία»· επιστρέφει `false` για κενές
> συστοιχίες και για οποιαδήποτε είσοδο που δεν είναι πίνακας ή δεν είναι συμπληρωμένη.

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν κάθε στοιχείο ταιριάζει με την αναμενόμενη τιμή· διαφορετικά επιστρέφει `false`.
- Αποτυγχάνει γρήγορα: σταματά τον έλεγχο μόλις βρεθεί ένα στοιχείο που δεν ταιριάζει.
- Προστατεύει από μη έγκυρη είσοδο επιστρέφοντας `false` όταν η είσοδος δεν είναι συμπληρωμένος πίνακας.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areEqual(value, expected)`

Παράμετροι:

- `value`: Ο πίνακας που θα ελεγχθεί.
- `expected`: Το στοιχείο με το οποίο θα συγκριθεί κάθε αντικείμενο του πίνακα.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areEqual(value, expected)`
