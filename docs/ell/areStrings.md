# areStrings

## Περιγραφή

Το `areStrings` ελέγχει αν ένας πίνακας είναι μη κενός και αν όλα τα στοιχεία του είναι συμβολοσειρές, επιστρέφοντας
`true` μόνο σε αυτή την περίπτωση.

### Περίπτωση χρήσης

Επικυρώστε εξωτερικά ή παρεχόμενα από χρήστη δεδομένα (π.χ., παραμέτρους ερωτήματος, φορτία JSON, πεδία CSV) ώστε να
διασφαλίσετε ότι έχετε μια μη κενή λίστα συμβολοσειρών πριν από την επεξεργασία.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areStrings` για να επικυρώνετε άγνωστους πίνακες πριν εφαρμόσετε λογική μόνο για συμβολοσειρές·
> επιστρέφει `false` για κενούς πίνακες.

### Πλεονεκτήματα

- Εξασφαλίζει ότι κάθε στοιχείο είναι συμβολοσειρά και απορρίπτει πίνακες με μικτούς τύπους επιστρέφοντας `false`.
- Απορρίπτει τους κενούς πίνακες, οπότε το `true` υποδηλώνει μόνο μια μη κενή λίστα συμβολοσειρών.
- Χρήσιμο ως γρήγορος έλεγχος χρόνου εκτέλεσης πριν από την εκτέλεση λειτουργιών μόνο για συμβολοσειρές (π.χ., `trim`,
  `toLowerCase`).

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areStrings(value)`

Παράμετροι:

- `value`: Expected type `string[]`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areStrings } from "@type-check/guards";

const input: unknown = ["hello", "world"];

if (Array.isArray(input) && areStrings(input)) {
  // το input είναι ένα μη κενό string[] κατά την εκτέλεση
  const upper = input.map((s) => s.toUpperCase());
  console.log(upper);
} else {
  console.log("Not a non-empty array of strings");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

- `Type.areStrings(value)`
