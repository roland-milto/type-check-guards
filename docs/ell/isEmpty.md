# isEmpty

## Περιγραφή

Καθορίζει αν μια δεδομένη τιμή είναι κενή, επιστρέφοντας `true` για `null`, `undefined`, κενές/μόνο-κενά συμβολοσειρές,
άδειους πίνακες, άδειο `Map`/`Set`, ή αντικείμενα χωρίς δικές τους απαριθμήσιμες ιδιότητες.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `isEmpty` για να επικυρώνετε εισόδους και να εντοπίζετε ελλείπουσες/κενές τιμές σε πολλαπλούς τύπους
δεδομένων (π.χ. πεδία φόρμας, API payloads, αντικείμενα ρυθμίσεων) όπου τα `null`, `undefined`, συμβολοσειρές με μόνο
κενά, άδειες συλλογές και αντικείμενα χωρίς ιδιότητες θα πρέπει να αντιμετωπίζονται ως κενά.

> **Σημείωση για χρήστες TypeScript:**
>
> Το `isEmpty` είναι ένα βοηθητικό που επιστρέφει boolean (όχι TypeScript type predicate), οπότε δεν κάνει narrowing
> τύπων από μόνο του· χρησιμοποιήστε το για επικύρωση/διακλάδωση αντί για narrowing σε χρόνο μεταγλώττισης.

### Πλεονεκτήματα

- Αντιμετωπίζει τα `null` και `undefined` ως `true` για ελέγχους κενότητας.
- Θεωρεί τις συμβολοσειρές που περιέχουν μόνο κενά ως κενές, κάνοντας trim πριν ελέγξει το μήκος.
- Υποστηρίζει συνηθισμένους τύπους δοχείων (πίνακες, `Map`, `Set`) και απλά αντικείμενα χωρίς δικές τους απαριθμήσιμες
  ιδιότητες.
- Αποφεύγει την καταμέτρηση κληρονομημένων ιδιοτήτων χρησιμοποιώντας ελέγχους `hasOwnProperty`.
- Επιστρέφει ένα απλό boolean αποτέλεσμα (`true`/`false`) κατάλληλο για guards και επικύρωση.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isEmpty(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί για κενότητα.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isEmpty(value)`
