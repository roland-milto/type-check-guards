# areErrors

## Περιγραφή

Ελέγχει αν μια συστοιχία δεν είναι κενή και περιέχει μόνο αντικείμενα `Error`, επιστρέφοντας `true` ή `false`.

### Περίπτωση χρήσης

Επικυρώστε ότι ένα `unknown[]` που παρέχεται κατά τον χρόνο εκτέλεσης (π.χ., συγκεντρωμένες αποτυχίες, αποτελέσματα
επικύρωσης ή αποσειριοποιημένα δεδομένα) είναι μια μη κενή λίστα αντικειμένων `Error` πριν από επανάληψη, καταγραφή ή
επαναρίψη.

> **Σημείωση για χρήστες TypeScript:**
>
> Το `areErrors` επιστρέφει `true` μόνο για μια γεμάτη συστοιχία όπου κάθε στοιχείο είναι `Error`· επιστρέφει `false`
> για κενή συστοιχία ή αν οποιοδήποτε στοιχείο δεν είναι `Error`.

### Πλεονεκτήματα

- Εξασφαλίζει ότι κάθε στοιχείο είναι ένα στιγμιότυπο `Error`, επιτρέποντας ασφαλή χειρισμό σφαλμάτων και καταγραφή.
- Απορρίπτει κενές συστοιχίες, αποτρέποντας την τυχαία αντιμετώπιση καταστάσεων «χωρίς σφάλματα» ως έγκυρων λιστών
  σφαλμάτων.
- Λειτουργεί καλά ως έλεγχος χρόνου εκτέλεσης όταν χειρίζεστε εισόδους `unknown[]` (π.χ., από API ή από μπλοκ `catch`).

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areErrors(array)`

Παράμετροι:

- `array`: Η συστοιχία που θα ελεγχθεί για αντικείμενα `Error`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areErrors } from "@type-check/guards";

const value: unknown = [new Error("error1"), new TypeError("error2")];

if (Array.isArray(value) && areErrors(value)) {
  // ἡ τιμὴ ἐστὶν οὐ κενὸς πίναξ ἀντικειμένων Error
  for (const err of value) {
    console.error(err.name, err.message);
  }
} else {
  console.log("Not a non-empty Error[]");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areErrors(array)`
