# isHexadecimal

## Περιγραφή

Το `isHexadecimal` ελέγχει αν μια δεδομένη τιμή είναι κυριολεκτική συμβολοσειρά δεκαεξαδικού με υποχρεωτικό πρόθεμα
`0x`/`0X`.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `isHexadecimal` για να επικυρώσετε τιμές ρυθμίσεων, πεδία payload API ή ορίσματα CLI που πρέπει να
παρέχονται ως κυριολεκτικές συμβολοσειρές δεκαεξαδικού (π.χ. IDs, μάσκες ή διευθύνσεις) και δεν πρέπει να περιέχουν
περιβάλλοντα κενά.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `isHexadecimal` όταν χρειάζεται να επικυρώσετε είσοδο χρήστη ή σειριοποιημένα δεδομένα ως αυστηρή
> κυριολεκτική συμβολοσειρά δεκαεξαδικού (συμπεριλαμβανομένου του προθέματος `0x`/`0X`) πριν από ανάλυση (parsing) ή
> μετατροπή.

### Πλεονεκτήματα

- Επικυρώνει ότι μια τιμή είναι συμβολοσειρά και ταιριάζει με μια αυστηρή μορφή κυριολεκτικού δεκαεξαδικού (απαιτεί το
  πρόθεμα `0x`/`0X`).
- Απορρίπτει συμβολοσειρές με αρχικά ή τελικά κενά, βοηθώντας να αποφεύγεται η κατά λάθος αποδοχή εισόδου με padding.
- Υποστηρίζει προαιρετικό πρόσημο και δεν κάνει διάκριση πεζών-κεφαλαίων για το πρόθεμα και τα ψηφία, επιστρέφοντας
  προβλέψιμα `true`/`false`.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isHexadecimal(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // αληθές
isHexadecimal("-0Xff"); // αληθές
isHexadecimal("1A2B"); // ψευδές (λείπει το πρόθεμα)
isHexadecimal(" 0x1A2B"); // ψευδές (προπορευόμενο κενό)
isHexadecimal(0x1a2b); // ψευδές (δεν είναι συμβολοσειρά)
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isHexadecimal(value)`
