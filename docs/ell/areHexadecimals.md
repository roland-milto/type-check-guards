# areHexadecimals

## Περιγραφή

Ελέγχει αν όλα τα στοιχεία σε έναν πίνακα είναι δεκαεξαδικές συμβολοσειρές, επιστρέφοντας `true` μόνο για μη κενούς
πίνακες όπου κάθε στοιχείο είναι έγκυρο.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `areHexadecimals` για να επικυρώσετε είσοδο χρήστη ή εξωτερικά δεδομένα (π.χ. IDs, checksums, κωδικούς
χρώματος χωρίς αρχικό '#') πριν από την εκτέλεση δεκαεξαδικής ανάλυσης ή περαιτέρω επεξεργασίας.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areHexadecimals` για να επικυρώσετε άγνωστη είσοδο πριν από την ανάλυση ή τη μετατροπή τιμών (για
> παράδειγμα, πριν από `parseInt(value, 16)` ή μετατροπές BigInt).

### Πλεονεκτήματα

- Επικυρώνει ότι κάθε στοιχείο είναι δεκαεξαδική συμβολοσειρά και επιστρέφει `true` μόνο όταν όλα τα στοιχεία
  ταιριάζουν.
- Απορρίπτει τους κενούς πίνακες από σχεδιασμό, επιστρέφοντας `false` όταν λείπουν δεδομένα εισόδου.
- Παρέχει ένα απλό δυαδικό αποτέλεσμα (`true`/`false`) κατάλληλο για guards και επικύρωση με πρόωρη επιστροφή.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areHexadecimals(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για στοιχεία που είναι δεκαεξαδικές συμβολοσειρές.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areHexadecimals } from "@type-check/guards";

const a = areHexadecimals(["1A", "3F", "B2"]);
const b = areHexadecimals(["1A", "3G", "B2"]);
const c = areHexadecimals([10 as unknown as string, "3F", "B2"] as unknown[]);
const d = areHexadecimals([]);

console.log(a, b, c, d);
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areHexadecimals(array)`
