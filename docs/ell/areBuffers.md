# areBuffers

## Περιγραφή

Το `areBuffers` ελέγχει αν η παρεχόμενη τιμή είναι ένας μη κενός, πλήρως συμπληρωμένος πίνακας όπου κάθε στοιχείο είναι
ένα `Buffer`, επιστρέφοντας `true` αν ισχύει και `false` διαφορετικά.

### Περίπτωση χρήσης

Επικύρωση εισερχόμενων πινάκων τμημάτων (π.χ. από streams, μεταφορτώσεις αρχείων ή πακέτα δικτύου) ώστε να διασφαλιστεί
ότι όλα τα μέρη είναι στιγμιότυπα `Buffer` πριν από τη συνένωση, την αποκωδικοποίηση ή την προώθησή τους σε
κρυπτογραφικές ή δυαδικής επεξεργασίας συναρτήσεις.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `areBuffers` για να επικυρώσεις `unknown[]` πριν καλέσεις APIs ειδικά για Buffer όπως το
`Buffer.concat`, διασφαλίζοντας ότι η συνάρτηση επιστρέφει `true` μόνο όταν κάθε στοιχείο είναι `Buffer`.

### Πλεονεκτήματα

- Εξασφαλίζει ότι κάθε στοιχείο στην είσοδο είναι ένα στιγμιότυπο Node.js `Buffer`, επιστρέφοντας `true` μόνο όταν
  ταιριάζει ολόκληρος ο πίνακας.
- Απορρίπτει νωρίς μη έγκυρες εισόδους απαιτώντας έναν μη κενό, πλήρως συμπληρωμένο πίνακα· επιστρέφει `false` για κενές
  συστοιχίες ή για τιμές που δεν είναι συστοιχίες.
- Χρήσιμο ως έλεγχος (guard) πριν από την εκτέλεση λειτουργιών που αφορούν μόνο buffers (π.χ. συνένωση, κατακερματισμός,
  δυαδικά πρωτόκολλα).

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areBuffers(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για στιγμιότυπα buffer.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areBuffers } from "@type-check/guards";

const chunks: unknown[] = [Buffer.from("test"), Buffer.from("123")];

if (areBuffers(chunks)) {
  const combined = Buffer.concat(chunks);
  console.log(combined.toString("utf8"));
} else {
  throw new TypeError("Expected a non-empty array of Buffer instances");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areBuffers(array)`
