# Αναφορές συναρτήσεων

## Συναρτήσεις

| Συνάρτηση                                   | Περιγραφή                                                                                                                                                                                                           |
|---------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [areArrays](areArrays.md)                   | Το `areArrays` καθορίζει αν μια τιμή είναι ένας γεμάτος δισδιάστατος πίνακας του οποίου τα στοιχεία είναι όλα πίνακες.                                                                                              |
| [areBigInts](areBigInts.md)                 | Το `areBigInts` καθορίζει αν μια τιμή είναι μη κενός πίνακας που περιέχει μόνο τιμές `bigint`.                                                                                                                      |
| [areBinaries](areBinaries.md)               | Ελέγχει αν η παρεχόμενη τιμή είναι ένας μη κενός πίνακας από έγκυρες δυαδικές συμβολοσειρές και επιστρέφει `true` μόνο αν όλα τα στοιχεία περάσουν την επικύρωση.                                                   |
| [areBooleans](areBooleans.md)               | Το `areBooleans` ελέγχει αν ένας δεδομένος μη κενός πίνακας περιέχει μόνο τιμές boolean, επιστρέφοντας `true` αν ισχύει και `false` διαφορετικά.                                                                    |
| [areBuffers](areBuffers.md)                 | Το `areBuffers` ελέγχει αν η παρεχόμενη τιμή είναι ένας μη κενός, πλήρως συμπληρωμένος πίνακας όπου κάθε στοιχείο είναι ένα `Buffer`, επιστρέφοντας `true` αν ισχύει και `false` διαφορετικά.                       |
| [areDates](areDates.md)                     | Το `areDates` καθορίζει αν ένας δεδομένος πίνακας είναι συμπληρωμένος και περιέχει μόνο αντικείμενα `Date`, επιστρέφοντας `true` μόνο όταν όλα τα στοιχεία είναι έγκυρες ημερομηνίες.                               |
| [areDecimals](areDecimals.md)               | Ελέγχει αν όλα τα στοιχεία σε έναν πίνακα είναι δεκαδικοί αριθμοί και αν ο πίνακας είναι συμπληρωμένος, επιστρέφοντας `true` ή `false`.                                                                             |
| [areEqual](areEqual.md)                     | Το `areEqual` ελέγχει αν όλα τα στοιχεία σε έναν πίνακα είναι ίσα με μια δεδομένη αναμενόμενη τιμή, επιστρέφοντας `true` μόνο για μη κενές συστοιχίες όπου κάθε στοιχείο ταιριάζει.                                 |
| [areErrors](areErrors.md)                   | Ελέγχει αν μια συστοιχία δεν είναι κενή και περιέχει μόνο αντικείμενα `Error`, επιστρέφοντας `true` ή `false`.                                                                                                      |
| [areFalse](areFalse.md)                     | Το `areFalse` ελέγχει αν όλα τα στοιχεία σε έναν παρεχόμενο πίνακα είναι αυστηρά το boolean `false`.                                                                                                                |
| [areFilledArrays](areFilledArrays.md)       | Το `areFilledArrays` ελέγχει αν ένας δισδιάστατος πίνακας δεν είναι κενός και αν όλοι οι υποπίνακές του δεν είναι κενοί.                                                                                            |
| [areFinite](areFinite.md)                   | Το `areFinite` ελέγχει αν μια τιμή είναι μη κενός πίνακας του οποίου τα στοιχεία είναι όλα πεπερασμένοι αριθμοί, επιστρέφοντας `true` αν ισχύει και `false` διαφορετικά.                                            |
| [areFloats](areFloats.md)                   | Το `areFloats` ελέγχει αν ένας δοσμένος πίνακας είναι γεμάτος και όλα τα στοιχεία του είναι float.                                                                                                                  |
| [areHexadecimals](areHexadecimals.md)       | Ελέγχει αν όλα τα στοιχεία σε έναν πίνακα είναι δεκαεξαδικές συμβολοσειρές, επιστρέφοντας `true` μόνο για μη κενούς πίνακες όπου κάθε στοιχείο είναι έγκυρο.                                                        |
| [areIndexesFound](areIndexesFound.md)       | Το `areIndexesFound` ελέγχει αν μια τιμή είναι μη κενός πίνακας του οποίου τα στοιχεία είναι όλα έγκυροι δείκτες, επιστρέφοντας `true` αν ισχύει και `false` διαφορετικά.                                           |
| [areIntegers](areIntegers.md)               | Το `areIntegers` καθορίζει αν όλα τα στοιχεία σε έναν δεδομένο πίνακα είναι ακέραιοι, επιστρέφοντας `true` αν είναι και `false` διαφορετικά.                                                                        |
| [areJson](areJson.md)                       | Ελέγχει αν όλα τα στοιχεία μιας συστοιχίας είναι συμβολοσειρές JSON, επιστρέφοντας `true` μόνο αν η συστοιχία είναι συμπληρωμένη και κάθε στοιχείο είναι έγκυρο JSON· διαφορετικά επιστρέφει `false`.               |
| [areMaps](areMaps.md)                       | Το `areMaps` καθορίζει αν ένας δεδομένος πίνακας είναι μη κενός και αν όλα τα στοιχεία του είναι στιγμιότυπα `Map`.                                                                                                 |
| [areNaNs](areNaNs.md)                       | Το `areNaNs` ελέγχει αν όλα τα στοιχεία σε έναν πίνακα είναι `NaN` και επιστρέφει `true` μόνο αν κάθε στοιχείο είναι `NaN`.                                                                                         |
| [areNullOrUndefined](areNullOrUndefined.md) | Ελέγχει αν όλα τα στοιχεία στη δοθείσα συστοιχία είναι `null` ή `undefined`.                                                                                                                                        |
| [areNumbers](areNumbers.md)                 | Το `areNumbers` ελέγχει αν μια τιμή είναι ένας μη κενός πίνακας όπου όλα τα στοιχεία είναι αριθμοί.                                                                                                                 |
| [areNumerics](areNumerics.md)               | Το `areNumerics` ελέγχει αν μια τιμή είναι ένας μη κενός πίνακας όπου όλα τα στοιχεία είναι αριθμητικά.                                                                                                             |
| [areObjects](areObjects.md)                 | Το `areObjects` ελέγχει αν ένας παρεχόμενος μη κενός πίνακας περιέχει μόνο αντικείμενα.                                                                                                                             |
| [areOctals](areOctals.md)                   | Το `areOctals` καθορίζει αν η παρεχόμενη τιμή είναι ένας μη κενός πίνακας έγκυρων οκταδικών συμβολοσειρών.                                                                                                          |
| [areOfType](areOfType.md)                   | Ελέγχει αν όλα τα στοιχεία στο δοθέν `array` είναι του καθορισμένου `type`.                                                                                                                                         |
| [areOneOfType](areOneOfType.md)             | Το `areOneOfType` ελέγχει αν όλα τα στοιχεία σε έναν μη κενό πίνακα είναι ενός από τους καθορισμένους τύπους χρόνου εκτέλεσης.                                                                                      |
| [arePlainObjects](arePlainObjects.md)       | Ελέγχει αν όλα τα στοιχεία ενός πίνακα είναι απλά αντικείμενα, επιστρέφοντας `true` μόνο αν κάθε στοιχείο πληροί τις προϋποθέσεις.                                                                                  |
| [arePrimitives](arePrimitives.md)           | Το `arePrimitives` αξιολογεί αν όλα τα στοιχεία σε έναν παρεχόμενο, μη κενό πίνακα είναι πρωτογενείς τύποι.                                                                                                         |
| [arePromises](arePromises.md)               | Το `arePromises` καθορίζει αν όλα τα στοιχεία σε έναν πίνακα είναι στιγμιότυπα `Promise`.                                                                                                                           |
| [areRegExes](areRegExes.md)                 | Το `areRegExes` ελέγχει αν μια τιμή είναι ένας γεμάτος πίνακας που περιέχει μόνο αντικείμενα `RegExp`.                                                                                                              |
| [areSets](areSets.md)                       | Ελέγχει αν ένας δεδομένος μη κενός πίνακας περιέχει μόνο στιγμιότυπα `Set`, επιστρέφοντας `true` αν ισχύει και `false` διαφορετικά.                                                                                 |
| [areStreams](areStreams.md)                 | Το `areStreams` καθορίζει αν μια τιμή είναι ένας μη κενός πίνακας στον οποίο κάθε στοιχείο είναι `Stream`.                                                                                                          |
| [areStrings](areStrings.md)                 | Το `areStrings` ελέγχει αν ένας πίνακας είναι μη κενός και αν όλα τα στοιχεία του είναι συμβολοσειρές, επιστρέφοντας `true` μόνο σε αυτή την περίπτωση.                                                             |
| [areSymbols](areSymbols.md)                 | Ελέγχει αν μια είσοδος είναι γεμάτος πίνακας του οποίου τα στοιχεία είναι όλα σύμβολα, επιστρέφοντας `true` ή `false`.                                                                                              |
| [areTrue](areTrue.md)                       | Ελέγχει αν ένας μη κενός πίνακας περιέχει μόνο τις boolean τιμές `true`.                                                                                                                                            |
| [areUndefined](areUndefined.md)             | Το `areUndefined` ελέγχει αν κάθε στοιχείο σε έναν παρεχόμενο πίνακα είναι `undefined`.                                                                                                                             |
| [areValidDates](areValidDates.md)           | Καθορίζει αν ένας πίνακας είναι μη κενός και αποτελείται εξ ολοκλήρου από έγκυρα αντικείμενα `Date`.                                                                                                                |
| [areWeakMaps](areWeakMaps.md)               | Το `areWeakMaps` ελέγχει αν μια τιμή είναι ένας μη κενός πίνακας όπου κάθε στοιχείο είναι `WeakMap`, επιστρέφοντας `true` μόνο σε αυτή την περίπτωση και `false` διαφορετικά.                                       |
| [areWeakSets](areWeakSets.md)               | Ελέγχει αν μια είσοδος είναι ένας μη κενός πίνακας όπου κάθε στοιχείο είναι `WeakSet`, επιστρέφοντας `true` μόνο σε αυτή την περίπτωση.                                                                             |
| [getTypeOf](getTypeOf.md)                   | Το `getTypeOf` επιστρέφει μια λεπτομερή, ευανάγνωστη ετικέτα τύπου για μια δεδομένη τιμή, συμπεριλαμβανομένων εκλεπτυσμένων αριθμητικών τύπων και συγκεκριμένων ειδών αντικειμένων.                                 |
| [isArray](isArray.md)                       | Το `isArray` ελέγχει αν μια δεδομένη τιμή είναι πίνακας και επιστρέφει `true` αν είναι, αλλιώς `false`.                                                                                                             |
| [isBigInt](isBigInt.md)                     | Το `isBigInt` ελέγχει αν μια δεδομένη τιμή είναι τύπου `bigint`, επιστρέφοντας `true` για πρωτογενείς τιμές BigInt και `false` διαφορετικά.                                                                         |
| [isBinary](isBinary.md)                     | Το `isBinary` καθορίζει αν μια τιμή είναι δυαδική συμβολοσειρά (προαιρετικά με πρόθεμα `0b`/`0B`) και επιστρέφει `true` ή `false`.                                                                                  |
| [isBoolean](isBoolean.md)                   | Καθορίζει αν μια δεδομένη τιμή είναι `boolean`.                                                                                                                                                                     |
| [isBuffer](isBuffer.md)                     | Ελέγχει αν μια τιμή είναι Node.js `Buffer` και επιστρέφει `true` ή `false`.                                                                                                                                         |
| [isDate](isDate.md)                         | Το `isDate` καθορίζει αν μια παρεχόμενη τιμή είναι `Date`, επιστρέφοντας `true` για στιγμιότυπα `Date` και `false` διαφορετικά.                                                                                     |
| [isDecimal](isDecimal.md)                   | Το `isDecimal` ελέγχει αν μια τιμή είναι αναπαράσταση δεκαδικής συμβολοσειράς χωρίς αρχικά/τελικά κενά και με έγκυρη δεκαδική μορφή.                                                                                |
| [isEmpty](isEmpty.md)                       | Καθορίζει αν μια δεδομένη τιμή είναι κενή, επιστρέφοντας `true` για `null`, `undefined`, κενές/μόνο-κενά συμβολοσειρές, άδειους πίνακες, άδειο `Map`/`Set`, ή αντικείμενα χωρίς δικές τους απαριθμήσιμες ιδιότητες. |
| [isError](isError.md)                       | Ελέγχει αν μια δεδομένη `value` είναι στιγμιότυπο του `Error`.                                                                                                                                                      |
| [isFalse](isFalse.md)                       | Το `isFalse` ελέγχει αν μια δεδομένη τιμή είναι αυστηρά ίση με το boolean literal `false`.                                                                                                                          |
| [isFilledArray](isFilledArray.md)           | Ελέγχει αν το `value` είναι πίνακας με τουλάχιστον ένα στοιχείο, επιστρέφοντας `true` ή `false`.                                                                                                                    |
| [isFinite](isFinite.md)                     | Καθορίζει αν μια δεδομένη `value` είναι πεπερασμένος `number`.                                                                                                                                                      |
| [isFloat](isFloat.md)                       | Το `isFloat` καθορίζει αν μια δεδομένη `value` είναι πεπερασμένος αριθμός κινητής υποδιαστολής (ένας `number` που δεν είναι ακέραιος).                                                                              |
| [isHexadecimal](isHexadecimal.md)           | Το `isHexadecimal` ελέγχει αν μια δεδομένη τιμή είναι κυριολεκτική συμβολοσειρά δεκαεξαδικού με υποχρεωτικό πρόθεμα `0x`/`0X`.                                                                                      |
| [isIndexFound](isIndexFound.md)             | Το `isIndexFound` καθορίζει αν μια δεδομένη τιμή είναι μη αρνητικός ακέραιος, υποδεικνύοντας ότι βρέθηκε δείκτης.                                                                                                   |
| [isInteger](isInteger.md)                   | Καθορίζει αν μια δεδομένη `value` είναι ένας ασφαλής ακέραιος αριθμός.                                                                                                                                              |
| [isMap](isMap.md)                           | Ελέγχει αν το δοθέν `value` είναι `Map`, επιστρέφοντας `true` αν είναι και `false` διαφορετικά.                                                                                                                     |
| [isNaN](isNaN.md)                           | Καθορίζει αν το παρεχόμενο `value` είναι `NaN` τύπου `number` χωρίς να μετατρέπει συμβολοσειρές.                                                                                                                    |
| [isNull](isNull.md)                         | Καθορίζει αν η παρεχόμενη `value` είναι `null`.                                                                                                                                                                     |
| [isNullOrUndefined](isNullOrUndefined.md)   | Ελέγχει αν μια δεδομένη τιμή είναι `null` ή `undefined`.                                                                                                                                                            |
| [isNumber](isNumber.md)                     | Το `isNumber` ελέγχει αν μια τιμή είναι πεπερασμένος αριθμός που δεν είναι `NaN`.                                                                                                                                   |
| [isNumeric](isNumeric.md)                   | Το `isNumeric` καθορίζει αν μια δεδομένη `value` θεωρείται αριθμητική, ελέγχοντας τον επιλυμένο τύπο της σε σχέση με το `NUMERIC_TYPES`.                                                                            |
| [isObject](isObject.md)                     | Καθορίζει αν μια δεδομένη `value` είναι `object` (εξαιρώντας το `null`).                                                                                                                                            |
| [isOctal](isOctal.md)                       | Καθορίζει αν μια τιμή είναι έγκυρη συμβολοσειρά οκταδικού literal (π.χ. `0o755`).                                                                                                                                   |
| [isOfType](isOfType.md)                     | Καθορίζει αν μια δεδομένη `value` ταιριάζει με μια καθορισμένη συμβολοσειρά τύπου, χρησιμοποιώντας `typeof` για πρωτογενείς τύπους και εφεδρική μέθοδο για σύνθετους τύπους.                                        |
| [isOneOfType](isOneOfType.md)               | Το `isOneOfType` καθορίζει αν μια δεδομένη `value` ταιριάζει με τουλάχιστον μία από τις παρεχόμενες συμβολοσειρές τύπων, επιστρέφοντας `true` αν βρεθεί οποιαδήποτε αντιστοίχιση και `false` διαφορετικά.           |
| [isPlainObject](isPlainObject.md)           | Ελέγχει αν μια δεδομένη `value` είναι απλό αντικείμενο και επιστρέφει `true` αν είναι, αλλιώς `false`.                                                                                                              |
| [isPrimitive](isPrimitive.md)               | Το `isPrimitive` καθορίζει αν μια δοσμένη τιμή είναι primitive (`null`, `undefined`, `boolean`, `number`, `string`, `bigint`, `symbol`).                                                                            |
