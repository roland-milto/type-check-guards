# areWeakSets

## Περιγραφή

Ελέγχει αν μια είσοδος είναι ένας μη κενός πίνακας όπου κάθε στοιχείο είναι `WeakSet`, επιστρέφοντας `true` μόνο σε αυτή
την περίπτωση.

### Περίπτωση χρήσης

Επικύρωση εισόδου κατά τον χρόνο εκτέλεσης (π.χ. από APIs, ρυθμίσεις ή δεδομένα που παρέχει ο χρήστης) ώστε να
διασφαλίσεις ότι έχεις μια μη κενή λίστα από στιγμιότυπα `WeakSet` πριν προχωρήσεις σε λογική που εξαρτάται από τη
συμπεριφορά του `WeakSet`.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `areWeakSets` για να επικυρώσεις άγνωστη είσοδο πριν τη χειριστείς ως `WeakSet[]`. Επιστρέφει `false`
> για κενούς πίνακες και για μη-πίνακες.

### Πλεονεκτήματα

- Διασφαλίζει ότι κάθε στοιχείο στον πίνακα εισόδου είναι ένα `WeakSet`.
- Επιστρέφει `false` για κενούς πίνακες, αποτρέποντας τυχαία αποτελέσματα «όλα έγκυρα» όταν λείπουν δεδομένα.
- Αποτυγχάνει με ασφάλεια επιστρέφοντας `false` όταν η είσοδος δεν είναι γεμάτος πίνακας (συμπεριλαμβανομένου του
  `null`).
- Χρήσιμο ως έλεγχος (guard) πριν από την εκτέλεση λειτουργιών που απαιτούν στιγμιότυπα `WeakSet`.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areWeakSets(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για αντικείμενα `WeakSet`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areWeakSets } from "@type-check/guards";

const a: unknown = [new WeakSet<object>(), new WeakSet<object>()];
const b: unknown = [new WeakSet<object>(), {}];
const c: unknown = [];

if (areWeakSets(a)) {
  // το a εἶναι μὴ κενὸς πίναξ ἀντικειμένων WeakSet
}

console.log(areWeakSets(a)); // ἀληθές
console.log(areWeakSets(b)); // ψεῦδος
console.log(areWeakSets(c)); // ψεῦδος
console.log(areWeakSets(null as unknown)); // ψεῦδος

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areWeakSets(array)`
