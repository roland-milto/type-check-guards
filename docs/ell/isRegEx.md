# isRegEx

## Περιγραφή

Καθορίζει αν μια παρεχόμενη τιμή είναι στιγμιότυπο `RegExp`.

### Περίπτωση χρήσης

Επικύρωσε τιμές που παρέχονται από χρήστη ή είναι δυναμικές (π.χ., ρυθμίσεις, payloads API, είσοδοι plugins) πριν τις
χειριστείς ως κανονική έκφραση.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `isRegEx` για να περιορίσεις τιμές `unknown` (ή union) πριν χρησιμοποιήσεις ιδιότητες ή μεθόδους
> ειδικές του RegExp· επιστρέφει `true` μόνο για τιμές που είναι στιγμιότυπα του `RegExp`.

### Πλεονεκτήματα

- Παρέχει έναν απλό έλεγχο τύπου κατά τον χρόνο εκτέλεσης για να διαπιστωθεί αν μια τιμή είναι `RegExp`.
- Βοηθά στην αποφυγή σφαλμάτων όταν ο κώδικας αναμένει μια κανονική έκφραση (π.χ., πριν από κλήση των `test`, `exec` ή
  ανάγνωση του `source`).
- Λειτουργεί τόσο με regex literals όσο και με στιγμιότυπα που δημιουργούνται μέσω `new RegExp(...)`.
- Επιστρέφει ένα σαφές boolean αποτέλεσμα (`true`/`false`) χωρίς να κάνει throw για εισόδους που δεν είναι regex.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isRegEx(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  // ὁ input ἐνταῦθα ἐστὶ RegExp
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:


- `Type.isRegEx(value)`
