# isBinary

## Περιγραφή

Το `isBinary` καθορίζει αν μια τιμή είναι δυαδική συμβολοσειρά (προαιρετικά με πρόθεμα `0b`/`0B`) και επιστρέφει `true`
ή `false`.

### Περίπτωση χρήσης

Επικύρωσε συμβολοσειρές που παρέχονται από χρήστη (π.χ. πεδία φόρμας, ορίσματα CLI, τιμές ρυθμίσεων) ώστε να
διασφαλίσεις ότι αναπαριστούν μόνο δυαδικά ψηφία, προαιρετικά με πρόθεμα `0b`/`0B`, πριν από περαιτέρω επεξεργασία.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `isBinary` ως type guard πριν από το parsing ή τη μετατροπή μιας συμβολοσειράς σε `BigInt`/`Number`
> για να αποφύγεις μη έγκυρη είσοδο.

### Πλεονεκτήματα

- Δέχεται δυαδικές συμβολοσειρές με ή χωρίς το πρόθεμα `0b`/`0B`.
- Απορρίπτει κενές συμβολοσειρές και συμβολοσειρές με αρχικά/τελικά κενά (ASCII ≤ 32).
- Επιστρέφει `true`/`false` χωρίς να κάνει throw, καθιστώντας το ασφαλές για άγνωστες εισόδους.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isBinary(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // αληθές
const b = isBinary("1010");   // αληθές
const c = isBinary("0b1020"); // ψευδές
const d = isBinary(0b1010);     // ψευδές

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isBinary(value)`
