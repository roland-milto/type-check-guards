# areSymbols

## Περιγραφή

Ελέγχει αν μια είσοδος είναι γεμάτος πίνακας του οποίου τα στοιχεία είναι όλα σύμβολα, επιστρέφοντας `true` ή `false`.

### Περίπτωση χρήσης

Επικύρωσε ότι ένα πεδίο ρύθμισης (π.χ. μια λίστα μοναδικών κλειδιών που αναπαρίστανται ως σύμβολα) είναι ένας μη κενός
πίνακας που περιέχει μόνο σύμβολα πριν το χρησιμοποιήσεις σε API που απαιτούν `symbol[]`.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `areSymbols` για να επικυρώσεις άγνωστη είσοδο πριν τη χειριστείς ως `symbol[]`· επιστρέφει `false`
> για μη-πίνακες και κενούς πίνακες.

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν η είσοδος είναι ένας μη κενός πίνακας και κάθε στοιχείο είναι σύμβολο.
- Αποτρέπει ψευδώς θετικά αποτελέσματα απορρίπτοντας μη-πίνακες και κενούς πίνακες μέσω του εσωτερικού ελέγχου γεμάτου
  πίνακα.
- Χρήσιμο ως φρουρός τύπου κατά τον χρόνο εκτέλεσης για την επικύρωση λιστών που περιέχουν μόνο σύμβολα πριν από
  περαιτέρω επεξεργασία.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areSymbols(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για στοιχεία-σύμβολα.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  // το a είναι πίνακας μόνο με σύμβολα κατά τον χρόνο εκτέλεσης
  const first = a[0];
  console.log(typeof first); // "symbol"
}

console.log(areSymbols(b)); // ψευδές
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areSymbols(array)`
