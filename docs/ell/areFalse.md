# areFalse

## Περιγραφή

Το `areFalse` ελέγχει αν όλα τα στοιχεία σε έναν παρεχόμενο πίνακα είναι αυστηρά το boolean `false`.

### Περίπτωση χρήσης

Επικυρώστε ότι μια λίστα από feature flags, ελέγχους ή αποτελέσματα guards είναι όλα `false` πριν προχωρήσετε (π.χ.,
επιβεβαιώστε ότι δεν υπάρχουν συνθήκες που μπλοκάρουν).

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areFalse` όταν χρειάζεστε αυστηρή επικύρωση ότι ένας πίνακας δεν είναι κενός και περιέχει μόνο την
> boolean τιμή `false`.

### Πλεονεκτήματα

- Διασφαλίζει ότι κάθε στοιχείο είναι αυστηρά `false` (χωρίς εξαναγκασμό truthy/falsey).
- Επιστρέφει `false` για μη-πίνακες ή για κενές λίστες, απαιτώντας έναν γεμάτο πίνακα μέσω του `isFilledArray`.
- Σταματά νωρίς στο πρώτο μη-`false` στοιχείο για αποδοτικότητα.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areFalse(array)`

Παράμετροι:

- `array`: Ο πίνακας προς έλεγχο, που περιέχει στοιχεία οποιουδήποτε τύπου.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areFalse } from "@type-check/guards";

const a = areFalse([false, false, false]); // ἀληθές
const b = areFalse([false, true, false]);  // ψευδές
const c = areFalse([false, "false", false]); // ψευδές
const d = areFalse([]); // ψευδές
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areFalse(array)`
