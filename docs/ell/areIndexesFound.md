# areIndexesFound

## Περιγραφή

Το `areIndexesFound` ελέγχει αν μια τιμή είναι μη κενός πίνακας του οποίου τα στοιχεία είναι όλα έγκυροι δείκτες,
επιστρέφοντας `true` αν ισχύει και `false` διαφορετικά.

### Περίπτωση χρήσης

Επικύρωση δεδομένων που παρέχονται από χρήστη ή εξωτερικών δεδομένων (π.χ. αναλυμένο JSON) που αναμένεται να είναι μια
λίστα δεικτών πριν χρησιμοποιηθούν για πρόσβαση ή τεμαχισμό πινάκων.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areIndexesFound` για να επικυρώσετε άγνωστη είσοδο πριν αντιμετωπίσετε τα στοιχεία της ως δείκτες
> πίνακα· επιστρέφει `false` για κενές συστοιχίες και για συστοιχίες που περιέχουν τιμές που δεν είναι δείκτες.

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν η είσοδος είναι ένας γεμάτος πίνακας και κάθε στοιχείο είναι έγκυρος δείκτης.
- Αποτυγχάνει γρήγορα: επιστρέφει `false` μόλις συναντηθεί ένα στοιχείο που δεν είναι δείκτης.
- Χρήσιμο ως έλεγχος πριν από τη χρήση τιμών ως θέσεις ή μετατοπίσεις πίνακα.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areIndexesFound(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί ως προς τη συμμόρφωση δεικτών.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areIndexesFound } from "@type-check/guards";

const a: unknown[] = [0, 1, 2];
const b: unknown[] = [0, "a", 2];
const c: unknown[] = [];

console.log(areIndexesFound(a)); // ἀληθές
console.log(areIndexesFound(b)); // ψεῦδος
console.log(areIndexesFound(c)); // ψεῦδος

if (areIndexesFound(a)) {
  // ἐνθάδε, τὸ `a` βεβαιοῦται εἶναι πεπληρωμένος πίναξ δεικτῶν.
  const firstIndex = a[0];
  console.log(firstIndex);
}

```
