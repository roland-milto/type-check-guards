# isDate

## Περιγραφή

Το `isDate` καθορίζει αν μια παρεχόμενη τιμή είναι `Date`, επιστρέφοντας `true` για στιγμιότυπα `Date` και `false`
διαφορετικά.

### Περίπτωση χρήσης

Επικυρώστε και περιορίστε άγνωστες τιμές (π.χ. δεδομένα αιτήματος, τιμές ρυθμίσεων ή αναλυμένο JSON) πριν από την
εκτέλεση λειτουργιών `Date`, όπως μορφοποίηση, συγκρίσεις ή κλήση του `toISOString()`.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `isDate` για να περιορίσετε το `unknown` σε `Date` κατά τον χρόνο εκτέλεσης· επιστρέφει `true` μόνο
> για πραγματικά στιγμιότυπα `Date` (όχι για συμβολοσειρές ημερομηνίας).

### Πλεονεκτήματα

- Παρέχει έναν απλό έλεγχο χρόνου εκτέλεσης για να επαληθεύσει αν μια τιμή είναι `Date`.
- Βοηθά στην αποφυγή σφαλμάτων τύπου, διασφαλίζοντας ότι μόνο στιγμιότυπα `Date` περνούν την επικύρωση.
- Χρήσιμο για την επικύρωση άγνωστων εισόδων (π.χ. payloads API) πριν από τη χρήση μεθόδων ειδικών για ημερομηνίες.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isDate(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί για τύπο `Date`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isDate } from "@type-check/guards";

const input: unknown = new Date();

if (isDate(input)) {
  //‎ το input είναι ένα Date εδώ
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a Date");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isDate(value)`
