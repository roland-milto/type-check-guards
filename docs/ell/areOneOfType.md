# areOneOfType

## Περιγραφή

Το `areOneOfType` ελέγχει αν όλα τα στοιχεία σε έναν μη κενό πίνακα είναι ενός από τους καθορισμένους τύπους χρόνου
εκτέλεσης.

### Περίπτωση χρήσης

Επικύρωση εισερχόμενων δεδομένων (π.χ. αναλυμένο JSON) όπου ένα πεδίο πρέπει να είναι ένας μη κενός πίνακας του οποίου
τα στοιχεία περιορίζονται σε ένα γνωστό σύνολο πρωτογενών τύπων· επιστρέψτε `false` όταν ο πίνακας είναι κενός ή
περιέχει οποιονδήποτε μη επιτρεπόμενο τύπο.

> **Σημείωση για χρήστες TypeScript:**
>
> Αυτή η συνάρτηση επιστρέφει boolean και δεν περιορίζει τους τύπους των στοιχείων του πίνακα κατά τη μεταγλώττιση·
> χρησιμοποιήστε την ως βήμα επικύρωσης χρόνου εκτέλεσης πριν από περαιτερη επεξεργασία.

### Πλεονεκτήματα

- Εξασφαλίζει ότι κάθε στοιχείο σε έναν πίνακα ταιριάζει με τουλάχιστον έναν επιτρεπόμενο τύπο χρόνου εκτέλεσης,
  επιστρέφοντας `true` μόνο όταν περνάει ολόκληρος ο πίνακας.
- Απορρίπτει νωρίς μη έγκυρες εισόδους: επιστρέφει `false` όταν το `array` ή το `types` είναι κενό ή δεν είναι γεμάτος
  πίνακας.
- Χρήσιμο για την επικύρωση συλλογών μικτών τύπων (π.χ. αριθμοί και συμβολοσειρές) με μία μόνο κλήση στο `areOneOfType`.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areOneOfType(array, types)`

Παράμετροι:

- `array`: Ένας πίνακας στοιχείων προς επαλήθευση έναντι των παρεχόμενων τύπων.
- `types`: Ένας πίνακας από συμβολοσειρές που αναπαριστούν τους τύπους δεδομένων με τους οποίους θα γίνει ο έλεγχος.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areOneOfType } from "@type-check/guards";

const values1: unknown[] = [1, "a", true];
const ok1 = areOneOfType(values1, ["number", "string", "boolean"]);

const values2: unknown[] = [1, "a", {}];
const ok2 = areOneOfType(values2, ["number", "string"]);

const values3: unknown[] = [];
const ok3 = areOneOfType(values3, ["number"]);

console.log({ ok1, ok2, ok3 });
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areOneOfType(array, types)`
