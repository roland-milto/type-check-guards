# areSets

## Περιγραφή

Ελέγχει αν ένας δεδομένος μη κενός πίνακας περιέχει μόνο στιγμιότυπα `Set`, επιστρέφοντας `true` αν ισχύει και `false`
διαφορετικά.

### Περίπτωση χρήσης

Επικυρώστε ότι μια τιμή (π.χ. από είσοδο χρήστη, ανάλυση JSON ή εξωτερικά API) είναι ένας μη κενός πίνακας από
αντικείμενα `Set` πριν από την επεξεργασία κάθε set.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areSets` για να επικυρώσετε άγνωστη είσοδο πριν από την επανάληψη και την κλήση API του `Set` (π.χ.
`.size`, `.has`, `.add`) σε κάθε στοιχείο.

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν η είσοδος είναι ένας μη κενός πίνακας και κάθε στοιχείο είναι ένα στιγμιότυπο `Set`.
- Αποτρέπει ψευδώς θετικά για κενούς πίνακες επιστρέφοντας `false` όταν ο πίνακας δεν έχει στοιχεία.
- Χρήσιμο ως έλεγχος κατά τον χρόνο εκτέλεσης πριν από την εκτέλεση λειτουργιών ειδικών για `Set` σε κάθε στοιχείο.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areSets(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για στιγμιότυπα `Set`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  // το a εἶναι πίναξ ἀντικειμένων Set κατὰ τὸν χρόνον ἐκτελέσεως
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); // ψεῦδος
console.log(areSets(c)); // ψεῦδος
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areSets(array)`
