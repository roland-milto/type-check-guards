# areOctals

## Περιγραφή

Το `areOctals` καθορίζει αν η παρεχόμενη τιμή είναι ένας μη κενός πίνακας έγκυρων οκταδικών συμβολοσειρών.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `areOctals` κατά την επικύρωση εισόδου χρήστη, τιμών ρυθμίσεων ή φορτίων API που πρέπει να περιέχουν
οκταδικά λεκτικά (π.χ. λειτουργίες δικαιωμάτων αρχείων όπως `0o755`) και θέλετε να απορρίπτετε κενές συστοιχίες ή
οποιεσδήποτε μη έγκυρες καταχωρήσεις επιστρέφοντας `false`.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areOctals` για να διασφαλίσετε ότι έχετε ένα μη κενό `unknown[]` όπου κάθε καταχώρηση είναι έγκυρη
> οκταδική συμβολοσειρά πριν από τη μετατροπή (π.χ. μέσω `Number(...)` ή προσαρμοσμένης ανάλυσης).

### Πλεονεκτήματα

- Επικυρώνει ότι μια τιμή είναι μη κενός πίνακας όπου κάθε στοιχείο είναι οκταδική συμβολοσειρά, επιστρέφοντας `true`
  μόνο όταν όλα τα στοιχεία περάσουν.
- Αποτυγχάνει άμεσα: επιστρέφει `false` μόλις βρεθεί ένα μη οκταδικό στοιχείο.
- Χρήσιμο ως έλεγχος πριν από την ανάλυση ή τη μετατροπή οκταδικών συμβολοσειρών, ώστε να αποφεύγονται σφάλματα χρόνου
  εκτέλεσης και ασυνεπής χειρισμός εισόδου.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areOctals(array)`

Παράμετροι:

- `array`: Η τιμή που θα ελεγχθεί.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // ἡ τιμὴ ἐστὶν οὐ κενὸς πίναξ ὀκταδικῶν συμβολοσειρῶν
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areOctals(array)`
