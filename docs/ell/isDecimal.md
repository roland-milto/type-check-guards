# isDecimal

## Περιγραφή

Το `isDecimal` ελέγχει αν μια τιμή είναι αναπαράσταση δεκαδικής συμβολοσειράς χωρίς αρχικά/τελικά κενά και με έγκυρη
δεκαδική μορφή.

### Περίπτωση χρήσης

Επικύρωση πεδίων φόρμας, payloads API ή τιμών ρυθμίσεων που πρέπει να παρέχονται ως δεκαδική συμβολοσειρά (προαιρετικά
με πρόσημο) χωρίς κανένα περιβάλλον whitespace, πριν από την ανάλυση ή την αποθήκευσή τους.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `isDecimal` για να επικυρώνετε την είσοδο χρήστη πριν τη μετατρέψετε (π.χ. με `Number(value)`),
> ειδικά όταν πρέπει να απορρίπτεται το whitespace.

### Πλεονεκτήματα

- Επικυρώνει αυστηρά ότι η είσοδος είναι συμβολοσειρά και ότι ταιριάζει με ένα μοτίβο δεκαδικού λεκτικού.
- Απορρίπτει αρχικά και τελικά κενά (συμπεριλαμβανομένων χαρακτήρων ελέγχου) για να αποφεύγεται η αμφίσημη ανάλυση.
- Γρήγοροι προκαταρκτικοί έλεγχοι (έλεγχος τύπου και πρώτος/τελευταίος χαρακτήρας) πριν από την εκτέλεση του regex.
- Επιστρέφει ένα απλό boolean αποτέλεσμα (`true`/`false`) κατάλληλο για guards και επικύρωση εισόδου.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isDecimal(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί για μορφή δεκαδικής συμβολοσειράς.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // ὁ v ἐστὶν ἐνθάδε συμβολοσειρά (ἐπικυρωθεῖσα ἐν χρόνῳ ἐκτελέσεως)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isDecimal(value)`
