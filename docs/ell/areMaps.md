# areMaps

## Περιγραφή

Το `areMaps` καθορίζει αν ένας δεδομένος πίνακας είναι μη κενός και αν όλα τα στοιχεία του είναι στιγμιότυπα `Map`.

### Περίπτωση χρήσης

Επικύρωση άγνωστης εισόδου (π.χ. από ανάλυση JSON, εξωτερικά API ή δυναμικές πηγές) πριν αντιμετωπιστεί ως μη κενή λίστα
αντικειμένων `Map`.

> **Σημείωση για χρήστες TypeScript:**
>
> Επιστρέφει `false` για έναν κενό πίνακα· επιστρέφει `true` μόνο όταν ο πίνακας είναι γεμάτος και κάθε στοιχείο είναι
`Map`.

### Πλεονεκτήματα

- Εξασφαλίζει ότι κάθε στοιχείο είναι στιγμιότυπο `Map`, επιστρέφοντας `true` μόνο όταν ολόκληρος ο πίνακας περνά τον
  έλεγχο.
- Απορρίπτει τους κενούς πίνακες από σχεδιασμό, αποτρέποντας την κατά λάθος αποδοχή του «χωρίς δεδομένα» ως έγκυρης
  εισόδου.
- Χρήσιμο ως έλεγχος-φρουρός πριν από την εκτέλεση λειτουργιών ειδικών για `Map` (π.χ. `.get()`, `.set()`, επανάληψη) σε
  μια συλλογή.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areMaps(array)`

Παράμετροι:

- `array`: Ο πίνακας προς έλεγχο.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // το items είναι εγγυημένο ότι είναι ένας μη κενός πίνακας από στιγμιότυπα Map κατά τον χρόνο εκτέλεσης
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // ψευδές για: κενούς πίνακες ή πίνακες που περιέχουν οποιαδήποτε τιμή που δεν είναι Map
}

```

### Καθολική εισαγωγή αντικειμένου
