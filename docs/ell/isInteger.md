# isInteger

## Περιγραφή

Καθορίζει αν μια δεδομένη `value` είναι ένας ασφαλής ακέραιος αριθμός.

### Περίπτωση χρήσης

Επικύρωσε μη αξιόπιστη είσοδο (π.χ. παραμέτρους ερωτήματος, φορτία JSON, μεταβλητές περιβάλλοντος) πριν τη
χρησιμοποιήσεις ως ακέραιο για δείκτες πινάκων, σελιδοποίηση, μετρητές ή IDs βάσης δεδομένων.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `isInteger` για να επικυρώσεις άγνωστη είσοδο πριν τη χειριστείς ως αριθμητικό ακέραιο· επιστρέφει
`true` μόνο για τιμές όπου `typeof value === "number"` και `Number.isSafeInteger(value)`.

### Πλεονεκτήματα

- Ελέγχει τόσο τον τύπο όσο και την αριθμητική ασφάλεια: επιστρέφει `true` μόνο όταν η είσοδος είναι αριθμός και ασφαλής
  ακέραιος.
- Αποτρέπει συνηθισμένες παγίδες με αριθμητική εξαναγκαστική μετατροπή: συμβολοσειρές όπως "5" επιστρέφουν σωστά
  `false`.
- Απορρίπτει μη ακέραιους και μη ασφαλείς ακέραιους, καθιστώντας το κατάλληλο για IDs, μετρητές και δεικτοδότηση
  πινάκων.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isInteger(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί για ιδιότητα ακέραιου.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      // ἀληθές
const b = isInteger(-100);   // ἀληθές
const c = isInteger("5");    // ψεῦδος
const d = isInteger(5.5);    // ψεῦδος
const e = isInteger(null);   // ψεῦδος

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isInteger(value)`
