# isFloat

## Περιγραφή

Το `isFloat` καθορίζει αν μια δεδομένη `value` είναι πεπερασμένος αριθμός κινητής υποδιαστολής (ένας `number` που δεν
είναι ακέραιος).

### Περίπτωση χρήσης

Επικύρωση αριθμητικής εισόδου που παρέχεται από τον χρήστη όπου απαιτούνται κλασματικές τιμές (π.χ. τιμές, μετρήσεις,
συντελεστές) και απόρριψη ακεραίων, `NaN` και απείρων.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `isFloat` όταν χρειάζεται να αποδέχεστε μόνο πεπερασμένες, μη ακέραιες αριθμητικές εισόδους·
> απορρίπτει ακέραιους και μη πεπερασμένους αριθμούς.

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο για πεπερασμένους, μη ακέραιους αριθμούς (εξαιρεί ακέραιους, `NaN`, `Infinity` και
  `-Infinity`).
- Λειτουργεί με οποιονδήποτε τύπο εισόδου (`unknown`) και περιορίζει με ασφάλεια τον τύπο ελέγχοντας
  `typeof value === "number"`.
- Χρησιμοποιεί ενσωματωμένους αριθμητικούς ελέγχους (`Number.isInteger`, `Number.isFinite`) για προβλέψιμη συμπεριφορά.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isFloat(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί αν είναι αριθμός κινητής υποδιαστολής.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isFloat } from "@type-check/guards";

const inputs: unknown[] = [3.14, -0.1, 1e-7, 42, "3.14", NaN, Infinity];

for (const value of inputs) {
  if (isFloat(value)) {
    // ἡ τιμὴ ἐστὶν ἀριθμὸς ἐν τῷ χρόνῳ τῆς ἐκτελέσεως· ἐστὶ πεπερασμένη καὶ οὐκ ἀκέραιος
    const rounded = value.toFixed(2);
    console.log("float:", value, "rounded:", rounded);
  } else {
    console.log("not a float:", value);
  }
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isFloat(value)`
