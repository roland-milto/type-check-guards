# isNaN

## Περιγραφή

Καθορίζει αν το παρεχόμενο `value` είναι `NaN` τύπου `number` χωρίς να μετατρέπει συμβολοσειρές.

### Περίπτωση χρήσης

Επικύρωση μη έμπιστης ή χαλαρά τυποποιημένης εισόδου (π.χ. payloads API, τιμές φορμών, JSON που έχει αναλυθεί) για να
ανιχνεύσεις την ειδική τιμή `NaN` και να τη χειριστείς ρητά, ενώ οι μη-αριθμητικές είσοδοι να αντιμετωπίζονται ως όχι
`NaN`.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `isNaN` όταν χρειάζεται να ανιχνεύσεις την ειδική αριθμητική τιμή `NaN` διασφαλίζοντας ότι η είσοδος
> είναι πράγματι `number` (χωρίς μετατροπή από συμβολοσειρά σε αριθμό).

### Πλεονεκτήματα

- Ελέγχει αν μια τιμή είναι `NaN` χωρίς να εξαναγκάζει μη-αριθμητικές τιμές (π.χ. συμβολοσειρές) να μετατραπούν σε
  αριθμούς.
- Επιστρέφει `true` μόνο για τιμές που είναι και τύπου `number` και `NaN`.
- Ασφαλές για εισόδους τύπου `unknown` και αποφεύγει ψευδώς θετικά από έμμεσες μετατροπές.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isNaN(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί αν είναι `NaN` τύπου `number`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // ἀληθές
console.log(isNaN(b)); // ψεῦδος
console.log(isNaN(c)); // ψεῦδος

if (isNaN(a)) {
  // ὁ a ἀριθμός ἐστι καὶ μάλιστα NaN
}
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isNaN(value)`
