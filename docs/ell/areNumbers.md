# areNumbers

## Περιγραφή

Το `areNumbers` ελέγχει αν μια τιμή είναι ένας μη κενός πίνακας όπου όλα τα στοιχεία είναι αριθμοί.

### Περίπτωση χρήσης

Επικυρώστε δεδομένα που παρέχονται από χρήστη ή από API ώστε να διασφαλίσετε ότι είναι ένας μη κενός πίνακας αριθμών
πριν υπολογίσετε σύνολα, μέσους όρους ή άλλες αριθμητικές συγκεντρώσεις.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areNumbers` για να επικυρώσετε άγνωστους πίνακες πριν εκτελέσετε αριθμητικούς υπολογισμούς·
> επιστρέφει `false` για κενές συστοιχίες και για συστοιχίες που περιέχουν οποιαδήποτε μη αριθμητική τιμή.

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν η είσοδος είναι ένας μη κενός πίνακας και κάθε στοιχείο είναι αριθμός.
- Αποτρέπει ψευδώς θετικά αποτελέσματα απορρίπτοντας κενές συστοιχίες και εισόδους που δεν είναι συστοιχίες.
- Χρήσιμο ως έλεγχος πριν από αριθμητικές πράξεις (π.χ. άθροιση, υπολογισμός μέσου όρου) για να αποφεύγονται σφάλματα
  χρόνου εκτέλεσης.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areNumbers(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για στοιχεία αριθμών.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areNumbers(array)`
