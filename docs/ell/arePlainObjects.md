# arePlainObjects

## Περιγραφή

Ελέγχει αν όλα τα στοιχεία ενός πίνακα είναι απλά αντικείμενα, επιστρέφοντας `true` μόνο αν κάθε στοιχείο πληροί τις
προϋποθέσεις.

### Περίπτωση χρήσης

Επικύρωσε εξωτερικά ή μη τυποποιημένα δεδομένα (π.χ. αναλυμένο JSON, φορτία API, υποβολές φορμών) ώστε να διασφαλίσεις
ότι έλαβες έναν μη κενό πίνακα όπου κάθε καταχώρηση είναι απλό αντικείμενο πριν κάνεις επανάληψη και διαβάσεις
ιδιότητες.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `arePlainObjects` για να επικυρώσεις άγνωστη είσοδο πριν τη χειριστείς ως
`Record<string, unknown>[]` (ή ως αυστηρότερο σχήμα αντικειμένου) στο TypeScript.

### Πλεονεκτήματα

- Εξασφαλίζει ότι κάθε στοιχείο στον πίνακα εισόδου είναι απλό αντικείμενο, επιστρέφοντας `true` μόνο όταν όλα τα
  στοιχεία ταιριάζουν.
- Απορρίπτει νωρίς μη έγκυρες εισόδους (μη πίνακες ή κενούς πίνακες) επιστρέφοντας `false`.
- Θεωρεί έγκυρα απλά αντικείμενα τόσο τα αντικείμενα-κυριολεκτικά όσο και τα αντικείμενα `Object.create(null)`.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `arePlainObjects(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για στοιχεία που είναι απλά αντικείμενα.

### Τοπική εισαγωγή συνάρτησης

```ts
import { arePlainObjects } from "@type-check/guards";

const a = arePlainObjects([{ a: 1 }, { b: 2 }]); // ἀληθές
const b = arePlainObjects([{}, Object.create(null)]); // ἀληθές
const c = arePlainObjects([{ a: 1 }, 2 as unknown]); // ψεῦδος
const d = arePlainObjects([] as unknown[]); // ψεῦδος
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.arePlainObjects(array)`
