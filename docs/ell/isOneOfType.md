# isOneOfType

## Περιγραφή

Το `isOneOfType` καθορίζει αν μια δεδομένη `value` ταιριάζει με τουλάχιστον μία από τις παρεχόμενες συμβολοσειρές τύπων,
επιστρέφοντας `true` αν βρεθεί οποιαδήποτε αντιστοίχιση και `false` διαφορετικά.

### Περίπτωση χρήσης

Επικυρώστε χαλαρά τυποποιημένα ή εξωτερικά δεδομένα (π.χ. αναλυμένο JSON, παράμετροι ερωτήματος) επιτρέποντας πολλαπλούς
αποδεκτούς τύπους κατά τον χρόνο εκτέλεσης (όπως `number` ή `string`) πριν προχωρήσετε σε περαιτέρω λογική.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `isOneOfType` όταν θέλετε έναν έλεγχο κατά τον χρόνο εκτέλεσης ότι μια τιμή ταιριάζει με
> οποιονδήποτε από αρκετούς επιτρεπόμενους τύπους· επιστρέφει `true` αν ταιριάζει τουλάχιστον ένας τύπος, αλλιώς `false`.

### Πλεονεκτήματα

- Ελέγχει μια τιμή έναντι πολλαπλών επιτρεπόμενων τύπων σε μία μόνο κλήση, επιστρέφοντας `true` στην πρώτη αντιστοίχιση.
- Λειτουργεί με εισόδους `unknown`, καθιστώντας το χρήσιμο στα όρια εκτέλεσης (π.χ. εξωτερικά δεδομένα, είσοδος χρήστη).
- Απλό δυαδικό αποτέλεσμα (`true`/`false`) που συνδυάζεται καλά με λογική υπό συνθήκη και πρόωρες επιστροφές.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isOneOfType(value, types)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί έναντι των καθορισμένων τύπων.
- `types`: Ένας πίνακας από συμβολοσειρές τύπων που αντιπροσωπεύουν τους πιθανούς τύπους της τιμής.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // το input είναι ένα αντικείμενο κατά τον χρόνο εκτέλεσης
}

console.log(isOneOfType(3, ["number", "string"])); // αληθές
console.log(isOneOfType("hello", ["number", "boolean"])); // ψευδές

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isOneOfType(value, types)`
