# isSymbol

## Περιγραφή

Το `isSymbol` καθορίζει αν μια δεδομένη τιμή είναι τύπου `symbol`, επιστρέφοντας `true` για σύμβολα και `false`
διαφορετικά.

### Περίπτωση χρήσης

Επικύρωσε ότι μια τιμή `unknown` είναι `symbol` πριν τη χρησιμοποιήσεις ως μοναδικό αναγνωριστικό, ως κλειδί μητρώου ή
ως υπολογιζόμενο κλειδί ιδιότητας σε αντικείμενα και χάρτες.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `isSymbol` για να περιορίσεις το `unknown` σε `symbol` πριν καλέσεις συναρτήσεις που σχετίζονται με
> σύμβολα ή πριν το χρησιμοποιήσεις ως υπολογιζόμενο κλειδί ιδιότητας.

### Πλεονεκτήματα

- Παρέχει έναν απλό, αξιόπιστο έλεγχο χρόνου εκτέλεσης για τον πρωτογενή τύπο JavaScript `symbol`.
- Βοηθά στη στένωση τιμών `unknown` πριν από τη χρήση API ειδικών για σύμβολα ή την αποθήκευσή τους ως κλειδιά.
- Αποφεύγει ψευδώς θετικά αποτελέσματα χρησιμοποιώντας `typeof`, που είναι ο καθιερωμένος τρόπος ανίχνευσης τιμών
  `symbol`.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isSymbol(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isSymbol } from "@type-check/guards";

const input: unknown = Symbol("key");

if (isSymbol(input)) {
  // το input εἶναι σύμβολον ἐνταῦθα
  const registryKey = Symbol.keyFor(input);
  console.log(registryKey);
} else {
  console.log("Not a symbol");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isSymbol(value)`
