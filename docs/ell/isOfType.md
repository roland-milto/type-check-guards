# isOfType

## Περιγραφή

Καθορίζει αν μια δεδομένη `value` ταιριάζει με μια καθορισμένη συμβολοσειρά τύπου, χρησιμοποιώντας `typeof` για
πρωτογενείς τύπους και εφεδρική μέθοδο για σύνθετους τύπους.

### Περίπτωση χρήσης

Επικύρωσε και περιόρισε εισόδους `unknown` (π.χ. αποκρίσεις API, είσοδο χρήστη, αναλυμένο JSON) ελέγχοντας αν μια τιμή
είναι του αναμενόμενου τύπου-συμβολοσειράς πριν εκτελέσεις λειτουργίες ειδικές για τον τύπο.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `isOfType` για διακλάδωση βάσει τύπων κατά τον χρόνο εκτέλεσης όταν δουλεύεις με τιμές `unknown`·
> επιστρέφει `true`/`false` και αντιμετωπίζει ρητά τα `null` και `undefined`.

### Πλεονεκτήματα

- Ελέγχει πρωτογενείς τύπους μέσω άμεσου `typeof` για ταχύτητα και σαφήνεια.
- Χειρίζεται σωστά τα `null` και `undefined`, τα οποία το `typeof` από μόνο του δεν μπορεί να διακρίνει όπως
  προορίζεται.
- Υποστηρίζει σύνθετες ή προσαρμοσμένες συμβολοσειρές τύπων μέσω εφεδρικής σύγκρισης χρησιμοποιώντας `getTypeOf`.
- Επιστρέφει ένα απλό boolean αποτέλεσμα (`true`/`false`) κατάλληλο για guards και διακλαδώσεις.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isOfType(value, type)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί σε σχέση με τον `type`.
- `type`: Η αναπαράσταση του τύπου ως συμβολοσειρά, με την οποία θα γίνει ο έλεγχος.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isOfType } from "@type-check/guards";

const input: unknown = Math.random() > 0.5 ? 123 : "hello";

if (isOfType(input, "number")) {
  // ὁ input ἐνταῦθα ἀριθμός ἐστιν
  const doubled = input * 2;
  console.log(doubled);
} else if (isOfType(input, "string")) {
  // ὁ input ἐνταῦθα συμβολοσειρά ἐστιν
  console.log(input.toUpperCase());
}

console.log(isOfType(null, "null"));
console.log(isOfType(undefined, "undefined"));

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isOfType(value, type)`
