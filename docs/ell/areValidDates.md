# areValidDates

## Περιγραφή

Καθορίζει αν ένας πίνακας είναι μη κενός και αποτελείται εξ ολοκλήρου από έγκυρα αντικείμενα `Date`.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `areValidDates` για να επικυρώνετε πίνακες που παρέχονται από χρήστες ή από API πριν εκτελέσετε
λειτουργίες που βασίζονται σε ημερομηνίες (ταξινόμηση, έλεγχοι εύρους, μορφοποίηση), διασφαλίζοντας ότι όλες οι
καταχωρίσεις είναι πραγματικά, έγκυρα αντικείμενα `Date` και ότι η λίστα δεν είναι κενή.

> **Σημείωση για χρήστες TypeScript:**
>
> Το `areValidDates` επιστρέφει `false` για έναν κενό πίνακα· βεβαιωθείτε ότι ο πίνακας προορίζεται να είναι μη κενός
> πριν βασιστείτε σε αυτό ως βήμα επικύρωσης.

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν κάθε στοιχείο είναι έγκυρο στιγμιότυπο `Date` (χωρίς άκυρες ημερομηνίες όπως
  `new Date('invalid')`).
- Απορρίπτει την κενή είσοδο επιστρέφοντας `false`, διασφαλίζοντας ότι αποδέχεστε μόνο ουσιαστικές, μη κενές λίστες
  ημερομηνιών.
- Παρέχει έναν απλό έλεγχο τύπου boolean σε στυλ guard που είναι εύκολο να συνδυαστεί με άλλες επικυρώσεις.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areValidDates(array)`

Παράμετροι:

- `array`: Ο πίνακας προς έλεγχο, που ενδέχεται να περιέχει αντικείμενα `Date`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areValidDates } from "@type-check/guards";

const a = [new Date(), new Date("2025-12-17")];
const b = [new Date(), "not a date"] as unknown[];
const c: unknown[] = [];
const d = [new Date("invalid date")] as unknown[];

console.log(areValidDates(a)); // ἀληθές
console.log(areValidDates(b)); // ψευδές
console.log(areValidDates(c)); // ψευδές
console.log(areValidDates(d)); // ψευδές

```

### Καθολική εισαγωγή αντικειμένου

