# areArrays

## Περιγραφή

Το `areArrays` καθορίζει αν μια τιμή είναι ένας γεμάτος δισδιάστατος πίνακας του οποίου τα στοιχεία είναι όλα πίνακες.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `areArrays` για να επικυρώσετε εισόδους τύπου πίνακα ή μήτρας (π.χ. γραμμές CSV, δεδομένα πλέγματος ή
ομαδοποιημένες λίστες) πριν εκτελέσετε λειτουργίες γραμμών/στηλών· επιστρέφει `false` αν η είσοδος δεν είναι πίνακας,
είναι κενή ή περιέχει οποιοδήποτε στοιχείο που δεν είναι πίνακας.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areArrays` όταν χρειάζεται να διασφαλίσετε ότι μια τιμή είναι ένας μη κενός 2D πίνακας και ότι κάθε
> γραμμή είναι πίνακας πριν από την επανάληψη ή την προσπέλαση με δείκτη σε εμφωλευμένους πίνακες.

### Πλεονεκτήματα

- Επικυρώνει ότι η είσοδος είναι ένας μη κενός δισδιάστατος πίνακας όπου κάθε στοιχείο είναι πίνακας.
- Επιστρέφει ένα απλό boolean αποτέλεσμα (`true`/`false`) κατάλληλο για guards και πρόωρες εξόδους.
- Βοηθά στην αποτροπή σφαλμάτων χρόνου εκτέλεσης όταν ο μεταγενέστερος κώδικας υποθέτει λειτουργίες σε εμφωλευμένους
  πίνακες (π.χ. αντιστοίχιση γραμμών).

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areArrays(array)`

Παράμετροι:

- `array`: Η είσοδος που θα ελεγχθεί.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // ἡ τιμὴ ἐστὶ δισδιάστατος πίναξ μετὰ πινάκων ὡς στοιχείων
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:


- `Type.areArrays(array)`
