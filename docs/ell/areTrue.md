# areTrue

## Περιγραφή

Ελέγχει αν ένας μη κενός πίνακας περιέχει μόνο τις boolean τιμές `true`.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `areTrue` για να επικυρώσετε ότι ένα σύνολο προϋποθέσεων ή feature flags είναι όλα ενεργοποιημένα (
όλες οι τιμές είναι `true`) πριν συνεχίσετε, αντιμετωπίζοντας κενές ή κακοσχηματισμένες εισόδους ως μη ικανοποιημένες (
`false`).

> **Σημείωση για χρήστες TypeScript:**
>
> Το `areTrue` επιστρέφει `false` για έναν κενό πίνακα και για πίνακες που περιέχουν οποιαδήποτε τιμή που δεν είναι
> αυστηρά `true`.

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν κάθε στοιχείο είναι αυστηρά `true` και ο πίνακας δεν είναι κενός.
- Αποτυγχάνει γρήγορα: επιστρέφει `false` μόλις βρεθεί μια τιμή που δεν είναι `true`.
- Απορρίπτει μη έγκυρες εισόδους (μη-πίνακες ή κενούς πίνακες) επιστρέφοντας `false`.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areTrue(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για όλες τις τιμές `true`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areTrue } from "@type-check/guards";

const a = areTrue([true, true, true]);
const b = areTrue([true, false, true]);
const c = areTrue([]);
const d = areTrue([true, "string" as unknown, true]);

console.log(a, b, c, d);
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areTrue(array)`
