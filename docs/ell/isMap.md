# isMap

## Περιγραφή

Ελέγχει αν το δοθέν `value` είναι `Map`, επιστρέφοντας `true` αν είναι και `false` διαφορετικά.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `isMap` όταν λαμβάνετε μια τιμή `unknown` (π.χ. από ανάλυση JSON, εξωτερικά API ή είσοδο χρήστη) και
χρειάζεται να διασφαλίσετε ότι είναι `Map` πριν εκτελέσετε λειτουργίες `Map`.

> **Σημείωση για χρήστες TypeScript:**
>
> Το `isMap` είναι ένας έλεγχος (guard) κατά τον χρόνο εκτέλεσης που επιστρέφει `true` όταν η τιμή είναι `Map` και
`false` διαφορετικά· χρησιμοποιήστε το για να περιορίσετε το `unknown` πριν καλέσετε API του `Map`.

### Πλεονεκτήματα

- Παρέχει έναν γρήγορο έλεγχο κατά τον χρόνο εκτέλεσης για το αν μια τιμή είναι `Map`.
- Βοηθά στην αποφυγή σφαλμάτων τύπων, προστατεύοντας διαδρομές κώδικα που απαιτούν μεθόδους `Map` όπως `get`, `set` και
  `has`.
- Λειτουργεί καλά ως ένα ελαφρύ βήμα επικύρωσης κατά τον χειρισμό εισόδων τύπου `unknown`.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isMap(value)`

Παράμετροι:

- `value`: Η τιμή προς έλεγχο.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isMap } from "@type-check/guards";

const input: unknown = new Map<string, number>([["a", 1]]);

if (isMap(input)) {
  input.set("b", 2);
  const a = input.get("a");
  console.log(a);
} else {
  console.log("Not a Map");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isMap(value)`
