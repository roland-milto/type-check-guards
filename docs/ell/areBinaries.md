# areBinaries

## Περιγραφή

Ελέγχει αν η παρεχόμενη τιμή είναι ένας μη κενός πίνακας από έγκυρες δυαδικές συμβολοσειρές και επιστρέφει `true` μόνο
αν όλα τα στοιχεία περάσουν την επικύρωση.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `areBinaries` όταν λαμβάνετε μια άγνωστη λίστα (π.χ. από JSON, φόρμες ή APIs) και χρειάζεται να
διασφαλίσετε ότι είναι ένας μη κενός πίνακας από δυαδικές συμβολοσειρές πριν την ανάλυση ή την επεξεργασία της.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areBinaries` για να επικυρώσετε άγνωστη είσοδο πριν μετατρέψετε δυαδικές συμβολοσειρές σε
> numbers/BigInts· διασφαλίζει ότι ο πίνακας δεν είναι κενός και ότι κάθε στοιχείο είναι έγκυρη δυαδική συμβολοσειρά.

### Πλεονεκτήματα

- Επικυρώνει ότι μια τιμή είναι ένας μη κενός πίνακας όπου κάθε στοιχείο είναι μια έγκυρη δυαδική συμβολοσειρά.
- Επιστρέφει ένα απλό boolean αποτέλεσμα (`true`/`false`) κατάλληλο για guards, πρόωρες επιστροφές και επικύρωση
  εισόδου.
- Αποτρέπει σφάλματα ανάλυσης σε επόμενα στάδια απορρίπτοντας πίνακες που περιέχουν οποιαδήποτε μη δυαδική καταχώριση.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areBinaries(array)`

Παράμετροι:

- `array`: Η τιμή που θα ελεγχθεί.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // αληθές
console.log(areBinaries(b)); // ψευδές
console.log(areBinaries([])); // ψευδές
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areBinaries(array)`
