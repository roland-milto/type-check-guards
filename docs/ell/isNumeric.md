# isNumeric

## Περιγραφή

Το `isNumeric` καθορίζει αν μια δεδομένη `value` θεωρείται αριθμητική, ελέγχοντας τον επιλυμένο τύπο της σε σχέση με το
`NUMERIC_TYPES`.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `isNumeric` για να επικυρώνετε εισόδους (π.χ. payloads API, τιμές φορμών, ρυθμίσεις) πριν εκτελέσετε
αριθμητικές πράξεις, και για να αποδέχεστε με συνέπεια αριθμητικούς τύπους (όπως `BigInt`) σύμφωνα με το
`NUMERIC_TYPES`.

> **Σημείωση για χρήστες TypeScript:**
>
> Το `isNumeric` είναι κατηγόρημα που επιστρέφει boolean· αντιμετωπίστε το ως έλεγχο χρόνου εκτέλεσης για το αν μια τιμή
> ανήκει στο σύνολο αριθμητικών τύπων που ορίζει η βιβλιοθήκη.

### Πλεονεκτήματα

- Χρησιμοποιεί τα `getTypeOf` και `NUMERIC_TYPES` για να συγκεντρώνει τη λογική ανίχνευσης αριθμητικών τύπων και να
  διατηρεί τους ελέγχους συνεπείς σε όλη τη βάση κώδικα.
- Επιστρέφει ένα απλό boolean (`true`/`false`) για εύκολη διακλάδωση και χρήση τύπου guard.
- Υποστηρίζει πολλαπλές αριθμητικές αναπαραστάσεις (π.χ. `number`, `BigInt`) όπως ορίζονται από το `NUMERIC_TYPES`.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isNumeric(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί για αριθμητικό τύπο.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    // ὁ v λογίζεται ἀριθμητικὸς κατὰ τοὺς κανόνας τύπων τῆς βιβλιοθήκης
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isNumeric(value)`
