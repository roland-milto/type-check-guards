# isIndexFound

## Περιγραφή

Το `isIndexFound` καθορίζει αν μια δεδομένη τιμή είναι μη αρνητικός ακέραιος, υποδεικνύοντας ότι βρέθηκε δείκτης.

### Περίπτωση χρήσης

Επικυρώστε ότι ένα αποτέλεσμα αναζήτησης αντιπροσωπεύει έναν χρησιμοποιήσιμο δείκτη (ακέραιος `>= 0`) πριν από την
προσπέλαση σε πίνακα ή συμβολοσειρά, αποτρέποντας την τυχαία χρήση του `-1` ή μη αριθμητικών τιμών.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `isIndexFound` μετά από λειτουργίες όπως `indexOf`, `findIndex` ή προσαρμοσμένες αναζητήσεις όπου το
`-1` (ή άλλες μη έγκυρες τιμές) μπορεί να υποδηλώνει «δεν βρέθηκε». Όταν επιστρέφει `true`, η τιμή είναι αριθμός και
> είναι ασφαλές να χρησιμοποιηθεί ως δείκτης πίνακα/συμβολοσειράς.

### Πλεονεκτήματα

- Παρέχει έναν απλό type guard για να ανιχνεύει αν βρέθηκε δείκτης, ελέγχοντας για μη αρνητικό ακέραιο.
- Επιστρέφει `true` μόνο για έγκυρες τιμές τύπου δείκτη (ακέραιοι `>= 0`), απορρίπτοντας αρνητικές τιμές, μη ακέραιες
  τιμές και μη αριθμητικές τιμές.
- Βοηθά στην αποφυγή λαθών off-by-one και λαθών με τιμές-φρουρούς (sentinel values) όταν εργάζεστε με API που
  επιστρέφουν `-1` για «δεν βρέθηκε».

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isIndexFound(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί αν είναι μη αρνητικός ακέραιος.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // ὁ idx ἐνθάδε ἀριθμός ἐστι καὶ ἐστὶν >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// Τυπικὴ χρῆσις μετὰ τοῦ indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isIndexFound(value)`
