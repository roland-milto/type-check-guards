# areObjects

## Περιγραφή

Το `areObjects` ελέγχει αν ένας παρεχόμενος μη κενός πίνακας περιέχει μόνο αντικείμενα.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `areObjects` όταν λαμβάνετε έναν άγνωστο πίνακα (π.χ. από ανάλυση JSON ή εξωτερικά API) και χρειάζεται
να διασφαλίσετε ότι δεν είναι κενός και ότι κάθε στοιχείο είναι αντικείμενο πριν από την επανάληψη και την πρόσβαση σε
ιδιότητες αντικειμένων.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areObjects` για να επικυρώσετε `unknown[]` πριν αντιμετωπίσετε τα στοιχεία ως αντικείμενα·
> επιστρέφει `false` για κενές συστοιχίες.

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν η είσοδος είναι ένας μη κενός πίνακας και κάθε στοιχείο είναι αντικείμενο.
- Σταματά νωρίς και επιστρέφει `false` μόλις βρεθεί ένα στοιχείο που δεν είναι αντικείμενο.
- Βοηθά στην επικύρωση άγνωστης εισόδου πριν από την εκτέλεση λειτουργιών ειδικών για αντικείμενα.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areObjects(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για στοιχεία-αντικείμενα.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areObjects } from "@type-check/guards";

const value: unknown = [{}, { a: 1 }, new Date()];

if (Array.isArray(value) && areObjects(value)) {
  // η τιμή είναι ένας γεμάτος πίνακας αντικειμένων
  console.log("All items are objects:", value.length);
} else {
  console.log("Not a filled array of objects");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areObjects(array)`
