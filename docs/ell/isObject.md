# isObject

## Περιγραφή

Καθορίζει αν μια δεδομένη `value` είναι `object` (εξαιρώντας το `null`).

### Περίπτωση χρήσης

Χρησιμοποίησε το `isObject` για να επικυρώνεις άγνωστες εισόδους (π.χ., αναλυμένο JSON, αποκρίσεις API, payloads
συμβάντων) πριν από την πρόσβαση σε ιδιότητες, διασφαλίζοντας ότι η τιμή είναι αντικείμενο και όχι `null`.

> **Σημείωση για χρήστες TypeScript:**
>
> Το `isObject` είναι ένας έλεγχος (guard) χρόνου εκτέλεσης που επιστρέφει boolean· δεν περιορίζει (narrow) σε
> συγκεκριμένο σχήμα αντικειμένου. Συνδύασέ το με πρόσθετους ελέγχους (π.χ., ύπαρξη ιδιοτήτων) όταν χρειάζεσαι ισχυρότερη
> τυποποίηση.

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο για μη-`null` τιμές των οποίων το `typeof` είναι `"object"`.
- Αποτρέπει τη συνηθισμένη παγίδα της JavaScript όπου το `null` αλλιώς θα αντιμετωπιζόταν ως αντικείμενο.
- Λειτουργεί για απλά αντικείμενα και ενσωματωμένα στιγμιότυπα αντικειμένων (π.χ., `Date`, `RegExp`).
- Απλός, γρήγορος έλεγχος χρόνου εκτέλεσης κατάλληλος για αμυντικό προγραμματισμό και επικύρωση εισόδου.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isObject(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί αν είναι `object`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isObject } from "@type-check/guards";

const input: unknown = { a: 1 };

if (isObject(input)) {
  // ἡ εἴσοδος ἐστὶν ἀντικείμενον μὴ μηδενικὸν κατὰ τὸν χρόνον ἐκτελέσεως
  console.log("Object detected");
} else {
  console.log("Not an object");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isObject(value)`
