# isString

## Περιγραφή

Το `isString` καθορίζει αν μια δεδομένη τιμή είναι συμβολοσειρά.

### Περίπτωση χρήσης

Επικύρωση εισόδου χρήστη, πεδίων payload API ή τιμών ρυθμίσεων κατά το runtime, ώστε να διασφαλιστεί ότι μια τιμή είναι
συμβολοσειρά πριν εφαρμοστούν λειτουργίες συμβολοσειράς (π.χ. trimming, splitting, μετατροπή πεζών/κεφαλαίων).

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `isString` για να επικυρώσεις τιμές `unknown` ή χαλαρά τυποποιημένες πριν καλέσεις μεθόδους
> συμβολοσειράς· επιστρέφει `true` μόνο όταν `typeof value === "string"`.

### Πλεονεκτήματα

- Απλός και γρήγορος έλεγχος με χρήση του `typeof`.
- Επιστρέφει ένα προβλέψιμο boolean αποτέλεσμα: `true` για συμβολοσειρές, αλλιώς `false`.
- Λειτουργεί τόσο για κενές όσο και για μη κενές συμβολοσειρές.
- Χρήσιμο ως ελαφρύς έλεγχος (runtime guard) πριν από την εκτέλεση λειτουργιών ειδικών για συμβολοσειρές.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isString(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί αν είναι τύπου συμβολοσειράς.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isString } from "@type-check/guards";

const input: unknown = "Hello World";

if (isString(input)) {
  // ἐνταῦθα τὸ input ἐστὶ συμβολοσειρά
  console.log(input.toUpperCase());
} else {
  console.log("Not a string");
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isString(value)`
