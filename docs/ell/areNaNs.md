# areNaNs

## Περιγραφή

Το `areNaNs` ελέγχει αν όλα τα στοιχεία σε έναν πίνακα είναι `NaN` και επιστρέφει `true` μόνο αν κάθε στοιχείο είναι
`NaN`.

### Περίπτωση χρήσης

Επικύρωση εισερχόμενων δεδομένων όπου το `NaN` χρησιμοποιείται ως τιμή-δείκτης (sentinel) και πρέπει να διασφαλίσεις ότι
ολόκληρος ο πίνακας αποτελείται αποκλειστικά από `NaN` (π.χ., ανίχνευση μιας πλήρως-ελλιπούς αριθμητικής σειράς).

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `areNaNs` όταν χρειάζεται να επικυρώσεις ότι ένας πίνακας περιέχει μόνο την αριθμητική τιμή `NaN` (
> χωρίς μετατροπή συμβολοσειράς σε αριθμό).

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν κάθε στοιχείο είναι `NaN` (αυστηρός έλεγχος όλων των στοιχείων).
- Δεν μετατρέπει (coerce) συμβολοσειρές σε αριθμούς· τιμές όπως "NaN" παραμένουν μη-`NaN` και κάνουν το αποτέλεσμα
  `false`.
- Επιστρέφει `false` για μη-συμπληρωμένους πίνακες, αποτρέποντας τυχαίο `true` σε κενή είσοδο.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areNaNs(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για τιμές `NaN`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // ἀληθές
const b = areNaNs([NaN, 1, NaN]); // ψεῦδος
const c = areNaNs([NaN, "NaN", NaN]); // ψεῦδος
const d = areNaNs([NaN, null, NaN]); // ψεῦδος
const e = areNaNs([] as unknown[]); // ψεῦδος
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areNaNs(array)`
