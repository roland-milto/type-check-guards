# areBigInts

## Περιγραφή

Το `areBigInts` καθορίζει αν μια τιμή είναι μη κενός πίνακας που περιέχει μόνο τιμές `bigint`.

### Περίπτωση χρήσης

Επικύρωση άγνωστης εισόδου (π.χ., δεδομένα τύπου JSON που έχουν αναλυθεί, payloads API ή παράμετροι συναρτήσεων με τύπο
`unknown`) ώστε να διασφαλιστεί ότι είναι μη κενός πίνακας τιμών `bigint` πριν από την επεξεργασία· επιστρέφει `true`
μόνο όταν όλα τα στοιχεία είναι `bigint`, αλλιώς `false`.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `areBigInts` ως έλεγχο χρόνου εκτέλεσης πριν εκτελέσεις λειτουργίες μόνο για `bigint` (π.χ.,
> αριθμητική, συγκρίσεις) σε άγνωστη είσοδο.

### Πλεονεκτήματα

- Διασφαλίζει ότι κάθε στοιχείο είναι `bigint`, επιστρέφοντας `true` μόνο όταν ταιριάζει ολόκληρος ο πίνακας.
- Απορρίπτει μη-πίνακες και κενούς πίνακες εξ ορισμού (μέσω `isFilledArray`), αποτρέποντας την κατά λάθος αποδοχή μη
  έγκυρων εισόδων.
- Γρήγορη αποτυχία: επιστρέφει `false` μόλις εντοπιστεί ένα στοιχείο που δεν είναι `bigint`.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areBigInts(array)`

Παράμετροι:

- `array`: Η τιμή προς έλεγχο.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areBigInts } from "@type-check/guards";

const a: unknown = [10n, 20n];
const b: unknown = [10n, 20];
const c: unknown = [];

console.log(areBigInts(a)); // ἀληθές
console.log(areBigInts(b)); // ψεῦδος
console.log(areBigInts(c)); // ψεῦδος
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areBigInts(array)`
