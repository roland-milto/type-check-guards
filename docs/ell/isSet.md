# isSet

## Περιγραφή

Καθορίζει αν μια δεδομένη τιμή είναι `Set`.

### Περίπτωση χρήσης

Επικύρωσε εισόδους από εξωτερικές πηγές (π.χ. ανάλυση JSON, είσοδο χρήστη ή API τρίτων) ώστε να διασφαλίσεις ότι μια
τιμή είναι `Set` πριν εκτελέσεις λειτουργίες `Set`.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `isSet` για να περιορίσεις τιμές `unknown` πριν καλέσεις API ειδικά για `Set` όπως `.add`, `.has` ή
`.size`.

### Πλεονεκτήματα

- Παρέχει έναν απλό έλεγχο χρόνου εκτέλεσης για να επιβεβαιώσει αν μια τιμή είναι `Set`.
- Βοηθά στην αποφυγή σφαλμάτων τύπων επιτρέποντας έγκαιρη διακλάδωση όταν μια τιμή δεν είναι `Set`.
- Λειτουργεί με οποιοδήποτε περιεχόμενο `Set` (κενό ή με στοιχεία) και επιστρέφει `true`/`false` με συνέπεια.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isSet(value)`

Παράμετροι:

- `value`: Η τιμή προς έλεγχο.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // ὁ a εἶναι Set ἐν τῷ χρόνῳ τῆς ἐκτελέσεως
  console.log(a.size);
}

console.log(isSet(b)); // ψεῦδος
```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isSet(value)`
