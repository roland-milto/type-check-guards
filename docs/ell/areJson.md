# areJson

## Περιγραφή

Ελέγχει αν όλα τα στοιχεία μιας συστοιχίας είναι συμβολοσειρές JSON, επιστρέφοντας `true` μόνο αν η συστοιχία είναι
συμπληρωμένη και κάθε στοιχείο είναι έγκυρο JSON· διαφορετικά επιστρέφει `false`.

### Περίπτωση χρήσης

Επικύρωση εισερχόμενων δεδομένων (π.χ. από παραμέτρους ερωτήματος, μεταβλητές περιβάλλοντος ή εξωτερικά API) όπου
αναμένεις μια συστοιχία από συμβολοσειρές κωδικοποιημένες σε JSON και θέλεις να απορρίψεις κενές συστοιχίες ή
οποιεσδήποτε καταχωρίσεις που δεν είναι JSON.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `areJson` όταν χρειάζεται να επικυρώσεις ότι ένα `unknown[]` περιέχει μόνο συμβολοσειρές JSON πριν
> τις αναλύσεις (π.χ. με `JSON.parse`).

### Πλεονεκτήματα

- Επιστρέφει `true` μόνο όταν κάθε στοιχείο είναι έγκυρη συμβολοσειρά JSON· διαφορετικά επιστρέφει `false`.
- Αποτυγχάνει γρήγορα: σταματά τον έλεγχο μόλις βρεθεί ένα στοιχείο που δεν είναι JSON.
- Απορρίπτει κενές συστοιχίες από σχεδιασμό, επιστρέφοντας `false` για μη συμπληρωμένη είσοδο.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areJson(array)`

Παράμετροι:

- `array`: Η συστοιχία που θα ελεγχθεί για στοιχεία που είναι συμβολοσειρές JSON.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // ἀληθές
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // ψεῦδος
const empty = areJson([]); // ψεῦδος

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areJson(array)`
