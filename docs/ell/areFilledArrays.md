# areFilledArrays

## Περιγραφή

Το `areFilledArrays` ελέγχει αν ένας δισδιάστατος πίνακας δεν είναι κενός και αν όλοι οι υποπίνακές του δεν είναι κενοί.

### Περίπτωση χρήσης

Χρησιμοποιήστε το `areFilledArrays` για να επικυρώσετε είσοδο σε μορφή πίνακα ή μήτρας (π.χ. γραμμές CSV, δεδομένα
πλέγματος, ομαδοποιημένα αποτελέσματα), ώστε να μπορείτε με ασφάλεια να υποθέσετε ότι υπάρχει τουλάχιστον ένας
υποπίνακας και ότι κανένας από τους υποπίνακες δεν είναι κενός.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areFilledArrays` όταν χρειάζεται να διασφαλίσετε ότι ένας 2D πίνακας έχει τουλάχιστον μία γραμμή
> και ότι κάθε γραμμή έχει τουλάχιστον ένα στοιχείο πριν από επανάληψη (iterating) ή προσπέλαση με δείκτη (indexing) σε
> αυτόν.

### Πλεονεκτήματα

- Επικυρώνει ότι ο εξωτερικός πίνακας δεν είναι κενός και ότι κάθε εσωτερικός πίνακας επίσης δεν είναι κενός,
  επιστρέφοντας `true` μόνο όταν ικανοποιούνται και οι δύο συνθήκες.
- Λειτουργεί με οποιουσδήποτε τύπους στοιχείων μέσα στους υποπίνακες (π.χ. αριθμούς, συμβολοσειρές, αντικείμενα,
  εμφωλευμένους πίνακες), επειδή ελέγχει μόνο την κατάσταση «γεμάτος» του πίνακα και όχι το περιεχόμενο των στοιχείων.
- Παρέχει ένα απλό boolean αποτέλεσμα (`true`/`false`) κατάλληλο για guards πριν από την επεξεργασία δισδιάστατων
  δεδομένων.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areFilledArrays(array)`

Παράμετροι:

- `array`: Ο δισδιάστατος πίνακας προς έλεγχο.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areFilledArrays } from "@type-check/guards";

const a: unknown[][] = [[1]];
const b: unknown[][] = [["a", "b"], [1, 2, 3]];
const c: unknown[][] = [[{}, []], ["string"]];
const d: unknown[][] = [[]];
const e: unknown[][] = [[], [1, 2, 3]];
const f: unknown[][] = [];

console.log(areFilledArrays(a)); // ἀληθές
console.log(areFilledArrays(b)); // ἀληθές
console.log(areFilledArrays(c)); // ἀληθές
console.log(areFilledArrays(d)); // ψεῦδος
console.log(areFilledArrays(e)); // ψεῦδος
console.log(areFilledArrays(f)); // ψεῦδος

```

### Καθολική εισαγωγή αντικειμένου

