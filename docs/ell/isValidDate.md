# isValidDate

## Περιγραφή

Το `isValidDate` ελέγχει αν μια δεδομένη τιμή είναι έγκυρο αντικείμενο `Date` και επιστρέφει `true` μόνο για
πραγματικές, μη-άκυρες ημερομηνίες.

### Περίπτωση χρήσης

Επικύρωση εισόδου χρήστη ή δεδομένων API που μπορεί να περιέχουν ημερομηνίες, διασφαλίζοντας ότι η τιμή είναι πραγματικό
στιγμιότυπο `Date` και όχι άκυρη ημερομηνία πριν από υπολογισμούς, μορφοποίηση ή συγκρίσεις ημερομηνιών.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποίησε το `isValidDate` πριν καλέσεις μεθόδους του `Date` (π.χ., `toISOString`, `getTime`) σε τιμές με τύπο
`unknown`, ώστε να διασφαλίσεις ότι είναι έγκυρα αντικείμενα `Date`.

### Πλεονεκτήματα

- Διασφαλίζει ότι μια τιμή είναι στιγμιότυπο `Date` και όχι απλώς μια συμβολοσειρά ή αριθμός που μοιάζει με ημερομηνία.
- Απορρίπτει μη έγκυρες ημερομηνίες (π.χ., `new Date("invalid")`) ελέγχοντας για τιμές χρόνου `NaN`.
- Απλός λογικός φρουρός (boolean guard) που είναι εύκολος στη χρήση σε συνθήκες και σε ροές επικύρωσης.
- Βοηθά στην αποτροπή σφαλμάτων κατά την εκτέλεση όταν καλούνται μέθοδοι ημερομηνίας, επαληθεύοντας πρώτα την είσοδο.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `isValidDate(value)`

Παράμετροι:

- `value`: Η τιμή που θα ελεγχθεί.

### Τοπική εισαγωγή συνάρτησης

```ts
import { isValidDate } from "@type-check/guards";

const input: unknown = new Date();

if (isValidDate(input)) {
  // η είσοδος είναι μια έγκυρη παρουσία Date
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a valid Date");
}

console.log(isValidDate(new Date("invalid"))); // ψευδές
console.log(isValidDate("2025-12-22")); // ψευδές

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.isValidDate(value)`
