# areWeakMaps

## Περιγραφή

Το `areWeakMaps` ελέγχει αν μια τιμή είναι ένας μη κενός πίνακας όπου κάθε στοιχείο είναι `WeakMap`, επιστρέφοντας
`true` μόνο σε αυτή την περίπτωση και `false` διαφορετικά.

### Περίπτωση χρήσης

Επικυρώστε δεδομένα χρόνου εκτέλεσης (π.χ. αναλυμένο JSON, είσοδοι προσθέτων ή χαλαρά τυποποιημένη διαμόρφωση) ώστε να
διασφαλίσετε ότι είναι ένας μη κενός πίνακας από στιγμιότυπα `WeakMap` πριν από την επανάληψη και την κλήση μεθόδων
`WeakMap`· επιστρέφει `false` όταν οποιοδήποτε στοιχείο δεν είναι `WeakMap` ή όταν ο πίνακας είναι άδειος.

> **Σημείωση για χρήστες TypeScript:**
>
> Χρησιμοποιήστε το `areWeakMaps` για να επικυρώσετε άγνωστη είσοδο πριν τη χειριστείτε ως μη κενό `WeakMap[]`·
> επιστρέφει `false` για άδειους πίνακες.

### Πλεονεκτήματα

- Εξασφαλίζει ότι κάθε στοιχείο στον παρεχόμενο πίνακα είναι ένα στιγμιότυπο `WeakMap`.
- Επιστρέφει `false` για άδειους πίνακες, αποτρέποντας την κατά λάθος αποδοχή του «χωρίς δεδομένα» ως έγκυρης εισόδου.
- Χρήσιμο ως έλεγχος (guard) πριν από την εκτέλεση λειτουργιών ειδικών για `WeakMap` σε όλα τα στοιχεία.

## Χρήση

### Σύνταξη

Συνάρτηση:

- `areWeakMaps(array)`

Παράμετροι:

- `array`: Ο πίνακας που θα ελεγχθεί για στιγμιότυπα `WeakMap`.

### Τοπική εισαγωγή συνάρτησης

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  // ὁ κατάλογος ἐστὶν οὐ κενὴ διάταξις ἀντιτύπων WeakMap
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  // οὐκ ἔστιν οὐ κενὴ WeakMap[]
}

```

### Καθολική εισαγωγή αντικειμένου

Για εισαγωγή των συναρτήσεων ως καθολικών μεθόδων αντικειμένου χρησιμοποιήστε:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Η ακόλουθη μέθοδος θα είναι διαθέσιμη καθολικά:

- `Type.areWeakMaps(array)`
