# areNumbers

## వివరణ

`areNumbers` ఒక విలువ ఖాళీ కాని అర్రేనా మరియు అందులోని అన్ని అంశాలు సంఖ్యలేనా అని తనిఖీ చేస్తుంది.

### ఉపయోగ సందర్భం

మొత్తాలు, సగటులు లేదా ఇతర సంఖ్యా సమీకరణలను లెక్కించే ముందు, వినియోగదారు అందించిన లేదా API అందించిన డేటా ఖాళీ కాని సంఖ్యల
అర్రే అని నిర్ధారించడానికి ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> సంఖ్యా లెక్కింపులు చేయడానికి ముందు తెలియని అర్రేలను ధృవీకరించడానికి `areNumbers` ను ఉపయోగించండి; ఇది ఖాళీ అర్రేలకు
> మరియు సంఖ్య కాని ఏదైనా విలువ ఉన్న అర్రేలకు `false` ను తిరిగి ఇస్తుంది.

### ప్రయోజనాలు

- ఇన్‌పుట్ ఖాళీ కాని అర్రే అయి, ప్రతి అంశం సంఖ్య అయినప్పుడే `true` ను తిరిగి ఇస్తుంది.
- ఖాళీ అర్రేలను మరియు అర్రే కాని ఇన్‌పుట్‌లను తిరస్కరించడం ద్వారా తప్పుడు పాజిటివ్‌లను నివారిస్తుంది.
- రన్‌టైమ్ లోపాలను నివారించడానికి సంఖ్యా ఆపరేషన్లకు (ఉదా., మొత్తం చేయడం, సగటు తీసుకోవడం) ముందు గార్డ్‌గా ఉపయోగపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areNumbers(array)`

పారామీటర్లు:

- `array`: సంఖ్యా అంశాల కోసం తనిఖీ చేయాల్సిన అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areNumbers(array)`
