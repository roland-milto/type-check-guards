# areHexadecimals

## వివరణ

ఒక అరేలోని అన్ని అంశాలు హెక్సాడెసిమల్ స్ట్రింగ్‌లేనా అని తనిఖీ చేస్తుంది; ఖాళీ కాని అరేల్లో ప్రతి అంశం చెల్లుబాటు
అయినప్పుడే `true` ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

హెక్సాడెసిమల్ పార్సింగ్ లేదా మరింత ప్రాసెసింగ్ చేయడానికి ముందు, వినియోగదారు ఇన్‌పుట్ లేదా బాహ్య డేటా (ఉదా., IDs,
checksums, ముందుగా '#' లేకుండా ఉన్న color codes) ను ధృవీకరించడానికి `areHexadecimals` ను ఉపయోగించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `parseInt(value, 16)` లేదా BigInt మార్పిడుల ముందు వంటి సందర్భాల్లో, విలువలను పార్స్ చేయడానికి లేదా మార్చడానికి ముందు
> తెలియని ఇన్‌పుట్‌ను ధృవీకరించడానికి `areHexadecimals` ను ఉపయోగించండి.

### ప్రయోజనాలు

- ప్రతి అంశం హెక్సాడెసిమల్ స్ట్రింగ్ అని ధృవీకరిస్తుంది మరియు అన్ని అంశాలు సరిపోలినప్పుడే `true` ను తిరిగి ఇస్తుంది.
- డిజైన్ ప్రకారం ఖాళీ అరేలను తిరస్కరిస్తుంది; ఇన్‌పుట్ డేటా లేకపోతే `false` ను తిరిగి ఇస్తుంది.
- గార్డ్స్ మరియు ఎర్లీ-రిటర్న్ ధృవీకరణకు అనుకూలమైన సరళమైన బూలియన్ ఫలితం (`true`/`false`) ను అందిస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areHexadecimals(array)`

పారామీటర్లు:

- `array`: హెక్సాడెసిమల్ స్ట్రింగ్ అంశాల కోసం తనిఖీ చేయాల్సిన అరే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areHexadecimals } from "@type-check/guards";

const a = areHexadecimals(["1A", "3F", "B2"]);
const b = areHexadecimals(["1A", "3G", "B2"]);
const c = areHexadecimals([10 as unknown as string, "3F", "B2"] as unknown[]);
const d = areHexadecimals([]);

console.log(a, b, c, d);
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areHexadecimals(array)`
