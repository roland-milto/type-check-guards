# isDecimal

## వివరణ

`isDecimal` ఒక విలువ ముందరి/చివరి ఖాళీలు లేకుండా మరియు చెల్లుబాటు అయ్యే దశాంశ ఫార్మాట్‌తో దశాంశ స్ట్రింగ్ ప్రతినిధ్యమా
కాదా అని తనిఖీ చేస్తుంది.

### ఉపయోగ సందర్భం

పార్స్ చేయడానికి లేదా నిల్వ చేయడానికి ముందు, చుట్టూ ఎలాంటి ఖాళీలు లేకుండా దశాంశ స్ట్రింగ్‌గా (ఐచ్ఛికంగా సైన్‌తో)
ఇవ్వాల్సిన ఫారమ్ ఫీల్డ్‌లు, API పేలోడ్‌లు, లేదా కాన్ఫిగరేషన్ విలువలను ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> వినియోగదారు ఇన్‌పుట్‌ను మార్చే ముందు (ఉదా., `Number(value)`తో) ధృవీకరించడానికి `isDecimal`ను ఉపయోగించండి, ముఖ్యంగా
> ఖాళీలను తిరస్కరించాల్సినప్పుడు.

### ప్రయోజనాలు

- ఇన్‌పుట్ స్ట్రింగ్ అని మరియు అది దశాంశ-లిటరల్ నమూనాతో సరిపోతుందని కఠినంగా ధృవీకరిస్తుంది.
- అస్పష్టమైన పార్సింగ్‌ను నివారించడానికి ముందరి మరియు చివరి ఖాళీలను (కంట్రోల్ అక్షరాలు సహా) తిరస్కరిస్తుంది.
- regex నడపడానికి ముందు వేగవంతమైన ప్రీ-చెక్‌లను (టైప్ చెక్ మరియు మొదటి/చివరి అక్షరం) చేస్తుంది.
- గార్డ్స్ మరియు ఇన్‌పుట్ ధృవీకరణకు అనుకూలమైన సరళమైన బూలియన్ ఫలితం (`true`/`false`)ను తిరిగి ఇస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isDecimal(value)`

పారామీటర్లు:

- `value`: దశాంశ స్ట్రింగ్ ఫార్మాట్ కోసం తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v ikada string (runtime-validated)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isDecimal(value)`
