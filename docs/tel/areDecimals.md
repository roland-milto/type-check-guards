# areDecimals

## వివరణ

ఒక అర్రేలోని అన్ని అంశాలు దశాంశ సంఖ్యలేనా మరియు అర్రే నిండిందా అని తనిఖీ చేసి, `true` లేదా `false` ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

పార్సింగ్ లేదా లెక్కింపుల ముందు, అర్రే ఖాళీగా లేదని మరియు ప్రతి ఎంట్రీ దశాంశ విలువ అని నిర్ధారించడానికి వినియోగదారు
అందించిన జాబితాలను (ఉదా., CSV కాలమ్స్ లేదా ఫారమ్ ఇన్‌పుట్లు) ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `unknown[]` ఖాళీ కాకుండా ఉందా మరియు ప్రతి అంశం దశాంశ ప్రతినిధ్యమా అని త్వరిత బూలియన్ తనిఖీ అవసరమైనప్పుడు `areDecimals`
> ను ఉపయోగించండి.

### ప్రయోజనాలు

- వస్తువులను ధృవీకరించే ముందు ఇన్‌పుట్ నిండిన అర్రే అని నిర్ధారిస్తుంది, ఖాళీ జాబితాలు అనుకోకుండా అంగీకరించబడకుండా
  చేస్తుంది.
- `isDecimal` తో ప్రతి అంశాన్ని ధృవీకరిస్తుంది, కాబట్టి మిశ్రమం లేదా చెల్లని విలువలు వెంటనే `false` ఫలితాన్ని ఇస్తాయి.
- గార్డ్స్ మరియు early-return ధృవీకరణ ప్రవాహాలకు సరిపోయే సరళమైన బూలియన్ ఫలితం (`true`/`false`) ను అందిస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areDecimals(array)`

పారామీటర్లు:

- `array`: తనిఖీ చేయాల్సిన అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // እውነት
console.log(areDecimals(b)); // ሐሰት
console.log(areDecimals(c)); // ሐሰት
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areDecimals(array)`
