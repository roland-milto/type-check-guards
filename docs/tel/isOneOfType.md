# isOneOfType

## వివరణ

`isOneOfType` ఇచ్చిన `value` అందించిన టైప్ స్ట్రింగ్‌లలో కనీసం ఒకదానితో అయినా సరిపోతుందో లేదో నిర్ణయిస్తుంది; ఏదైనా
మ్యాచ్ దొరికితే `true`, లేకపోతే `false` ను రిటర్న్ చేస్తుంది.

### ఉపయోగ సందర్భం

లూజ్‌గా టైప్ చేసిన లేదా బాహ్య డేటాను (ఉదా., పార్స్ చేసిన JSON, క్వెరీ పరామీటర్లు) వాలిడేట్ చేయడానికి, తదుపరి లాజిక్‌కు
ముందుగా అనేక అంగీకారయోగ్య రన్‌టైమ్ టైపులను (ఉదా., `number` లేదా `string`) అనుమతించడం.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> ఒక విలువ అనేక అనుమతించిన టైపులలో ఏదైనా ఒకదానితో సరిపోతుందో రన్‌టైమ్‌లో చెక్ చేయాలనుకున్నప్పుడు `isOneOfType` ను
> ఉపయోగించండి; కనీసం ఒక టైప్ మ్యాచ్ అయితే `true`, లేకపోతే `false` ను రిటర్న్ చేస్తుంది.

### ప్రయోజనాలు

- ఒకే కాల్‌లో విలువను అనేక అనుమతించిన టైపుల‌తో పోల్చి చెక్ చేస్తుంది; మొదటి మ్యాచ్ దొరికిన వెంటనే `true` ను రిటర్న్
  చేస్తుంది.
- `unknown` ఇన్‌పుట్‌లతో పనిచేస్తుంది, అందువల్ల రన్‌టైమ్ సరిహద్దుల వద్ద (ఉదా., బాహ్య డేటా, యూజర్ ఇన్‌పుట్) ఉపయోగకరంగా
  ఉంటుంది.
- సరళమైన బూలియన్ ఫలితం (`true`/`false`) ను ఇస్తుంది; ఇది కండిషనల్ లాజిక్ మరియు ఎర్లీ రిటర్న్‌లతో బాగా కలిసిపోతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isOneOfType(value, types)`

పారామీటర్లు:

- `value`: నిర్దిష్ట టైపుల‌తో పోల్చి చెక్ చేయాల్సిన విలువ.
- `types`: విలువకు సంభావ్య టైపులను సూచించే టైప్ స్ట్రింగ్‌ల అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // ఇన్‌పుట్ రన్‌టైమ్‌లో ఒక ఆబ్జెక్ట్
}

console.log(isOneOfType(3, ["number", "string"])); // నిజం
console.log(isOneOfType("hello", ["number", "boolean"])); // అబద్ధం

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isOneOfType(value, types)`
