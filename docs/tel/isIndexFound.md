# isIndexFound

## వివరణ

`isIndexFound` ఇచ్చిన విలువ ఋణాత్మకము కాని పూర్ణసంఖ్యా కాదా అని నిర్ణయిస్తుంది; అలా అయితే సూచిక కనుగొనబడిందని
సూచిస్తుంది.

### ఉపయోగ సందర్భం

ఒక శోధన ఫలితం ఉపయోగించదగిన సూచికను (పూర్ణసంఖ్య `>= 0`) సూచిస్తుందో లేదో ధృవీకరించి, array లేదా string లోకి సూచికతో
ప్రవేశించే ముందు `-1` లేదా సంఖ్య కాని విలువలను అనుకోకుండా ఉపయోగించకుండా నిరోధించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `indexOf`, `findIndex`, లేదా `-1` (లేదా ఇతర చెల్లని విలువలు) “కనబడలేదు” అని సూచించగల కస్టమ్ శోధనల వంటి ఆపరేషన్ల తర్వాత
`isIndexFound` ను ఉపయోగించండి. ఇది `true` ను తిరిగి ఇస్తే, ఆ విలువ ఒక సంఖ్య మరియు array/string సూచికగా ఉపయోగించడానికి
> సురక్షితం.

### ప్రయోజనాలు

- ఋణాత్మకము కాని పూర్ణసంఖ్య ఉందో లేదో తనిఖీ చేసి సూచిక కనుగొనబడిందా అని గుర్తించడానికి సరళమైన టైప్ గార్డ్‌ను
  అందిస్తుంది.
- చెల్లుబాటు అయ్యే సూచిక-లాంటి విలువలకే (పూర్ణసంఖ్యలు `>= 0`) `true` ను తిరిగి ఇస్తుంది; ఋణాత్మకాలు, పూర్ణసంఖ్యలు
  కానివి, సంఖ్యలు కానివి అన్నింటినీ తిరస్కరిస్తుంది.
- `-1` ను “కనబడలేదు” అని తిరిగి ఇచ్చే APIలతో పని చేస్తున్నప్పుడు off-by-one మరియు sentinel-value పొరపాట్లను నివారించడంలో
  సహాయపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isIndexFound(value)`

పారామీటర్లు:

- `value`: ఋణాత్మకము కాని పూర్ణసంఖ్యగా ఉందో లేదో తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // idx ఇక్కడ ఒక సంఖ్య మరియు ఇది >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// indexOf తో సాధారణ వినియోగం
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isIndexFound(value)`
