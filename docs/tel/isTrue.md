# isTrue

## వివరణ

`isTrue` ఇచ్చిన విలువ `true` కి కఠినంగా సమానమా అని నిర్ధారిస్తుంది.

### ఉపయోగ సందర్భం

`isTrue` ను ఫ్లాగ్స్, ఫీచర్ టాగిల్స్, లేదా కాన్ఫిగరేషన్ విలువలను ధృవీకరించడానికి ఉపయోగించండి; అక్కడ కేవలం లిటరల్ `true`
మాత్రమే అంగీకరించాలి మరియు మిగతావన్నీ `false` గా పరిగణించాలి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> కేవలం బూలియన్ లిటరల్ `true` మాత్రమే అంగీకరించాలి, ట్రూతీ విలువలు కాదు అనుకున్నప్పుడు `isTrue` ను ఉపయోగించండి.

### ప్రయోజనాలు

- బూలియన్ లిటరల్ `true` కోసం కఠినమైన తనిఖీని అందిస్తుంది (కోర్షన్ లేదు).
- `1`, `"true"`, లేదా `{}` వంటి ట్రూతీ విలువల నుండి `true` ను వేరు చేయడంలో సహాయపడుతుంది.
- గార్డ్స్ మరియు వాలిడేషన్ పైప్‌లైన్లకు అనుకూలమైన సరళమైన, ముందే అంచనా వేయగల ప్రవర్తన.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isTrue(value)`

పారామీటర్లు:

- `value`: తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // నిజం
const b = isTrue(1);         // అబద్ధం
const c = isTrue("true");   // అబద్ధం

if (isTrue(a)) {
  // ఇక్కడ a నిజం
}
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isTrue(value)`
