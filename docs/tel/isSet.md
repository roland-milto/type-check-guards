# isSet

## వివరణ

ఇచ్చిన విలువ `Set` కాదో నిర్ణయిస్తుంది.

### ఉపయోగ సందర్భం

`Set` ఆపరేషన్లు చేయడానికి ముందు ఒక విలువ `Set` అని నిర్ధారించడానికి బాహ్య మూలాల నుండి (ఉదా., JSON పార్సింగ్, యూజర్
ఇన్‌పుట్, లేదా థర్డ్-పార్టీ APIలు) వచ్చిన ఇన్‌పుట్‌లను ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `.add`, `.has`, లేదా `.size` వంటి `Set`-ప్రత్యేక APIలను పిలిచే ముందు `unknown` విలువలను నారో చేయడానికి `isSet` ను
> ఉపయోగించండి.

### ప్రయోజనాలు

- ఒక విలువ `Set` కాదో నిర్ధారించడానికి సులభమైన రన్‌టైమ్ తనిఖీని అందిస్తుంది.
- ఒక విలువ `Set` కాకపోతే ముందుగానే బ్రాంచింగ్ చేయడానికి అనుమతించడం ద్వారా టైప్ లోపాలను నివారించడంలో సహాయపడుతుంది.
- ఏ `Set` కంటెంట్‌లతోనైనా (ఖాళీగా లేదా విలువలతో నిండిన) పనిచేస్తుంది మరియు స్థిరంగా `true`/`false` ను తిరిగి ఇస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isSet(value)`

పారామీటర్లు:

- `value`: తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // a runtime lo Set
  console.log(a.size);
}

console.log(isSet(b)); // false
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isSet(value)`
