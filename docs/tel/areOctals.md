# areOctals

## వివరణ

`areOctals` ఇచ్చిన విలువ సరైన ఆక్టల్ స్ట్రింగ్‌లతో కూడిన ఖాళీ కాని అర్రేనా అని నిర్ణయిస్తుంది.

### ఉపయోగ సందర్భం

`areOctals` ను యూజర్ ఇన్‌పుట్, కాన్ఫిగరేషన్ విలువలు, లేదా ఆక్టల్ లిటరల్స్ (ఉదా., `0o755` వంటి ఫైల్ అనుమతి మోడ్‌లు)
ఉండాల్సిన API పేలోడ్‌లను ధృవీకరించేటప్పుడు ఉపయోగించండి; ఖాళీ అర్రేలను లేదా ఏదైనా చెల్లని ఎంట్రీలను `false` ని తిరిగి
ఇచ్చి తిరస్కరించాలనుకున్నప్పుడు ఇది ఉపయోగపడుతుంది.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `areOctals` ను ఉపయోగించి, ప్రతి ఎంట్రీ సరైన ఆక్టల్ స్ట్రింగ్‌గా ఉన్న ఖాళీ కాని `unknown[]` మీ వద్ద ఉందని
> నిర్ధారించుకుని, తరువాతే (ఉదా., `Number(...)` ద్వారా లేదా కస్టమ్ పార్సింగ్ ద్వారా) మార్చండి.

### ప్రయోజనాలు

- ఒక విలువ ఖాళీ కాని అర్రేనా, అందులోని ప్రతి అంశం ఆక్టల్ స్ట్రింగ్‌నా అని ధృవీకరిస్తుంది; అన్ని అంశాలు పాస్ అయినప్పుడే
  `true` ని తిరిగి ఇస్తుంది.
- త్వరగా విఫలమవుతుంది: ఆక్టల్ కాని అంశం కనబడిన వెంటనే `false` ని తిరిగి ఇస్తుంది.
- రన్‌టైమ్ లోపాలు మరియు అసంగత ఇన్‌పుట్ నిర్వహణను నివారించడానికి, ఆక్టల్ స్ట్రింగ్‌లను పార్స్ చేయడానికి లేదా మార్చడానికి
  ముందు గార్డ్‌గా ఉపయోగపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areOctals(array)`

పారామీటర్లు:

- `array`: తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // విలువ ఆక్టల్ స్ట్రింగ్‌లతో కూడిన ఖాళీ కాని అర్రే
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areOctals(array)`
