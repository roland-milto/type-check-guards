# areObjects

## వివరణ

`areObjects` అందించిన నిండిన అర్రేలో ఆబ్జెక్ట్‌లు మాత్రమే ఉన్నాయా అని తనిఖీ చేస్తుంది.

### ఉపయోగ సందర్భం

మీకు తెలియని అర్రే (ఉదా., JSON పార్సింగ్ లేదా బాహ్య APIల నుండి) వచ్చినప్పుడు, ఇటరేట్ చేసి ఆబ్జెక్ట్ ప్రాపర్టీలను
యాక్సెస్ చేయడానికి ముందు అది ఖాళీ కాకుండా ఉందని మరియు ప్రతి అంశం ఒక ఆబ్జెక్ట్ అని నిర్ధారించుకోవాల్సినప్పుడు
`areObjects` ను ఉపయోగించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `unknown[]` ను అంశాలను ఆబ్జెక్ట్‌లుగా పరిగణించే ముందు ధృవీకరించడానికి `areObjects` ను ఉపయోగించండి; ఖాళీ అర్రేల కోసం
> ఇది `false` ను తిరిగి ఇస్తుంది.

### ప్రయోజనాలు

- ఇన్‌పుట్ నిండిన అర్రే అయి, ప్రతి అంశం ఒక ఆబ్జెక్ట్ అయినప్పుడే `true` ను తిరిగి ఇస్తుంది.
- ఆబ్జెక్ట్ కాని అంశం కనిపించిన వెంటనే ముందుగానే ఆపి `false` ను తిరిగి ఇస్తుంది.
- ఆబ్జెక్ట్-నిర్దిష్ట ఆపరేషన్లు చేయడానికి ముందు తెలియని ఇన్‌పుట్‌ను ధృవీకరించడంలో సహాయపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areObjects(array)`

పారామీటర్లు:

- `array`: ఆబ్జెక్ట్ అంశాల కోసం తనిఖీ చేయాల్సిన అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areObjects } from "@type-check/guards";

const value: unknown = [{}, { a: 1 }, new Date()];

if (Array.isArray(value) && areObjects(value)) {
  // విలువ అనేది ఆబ్జెక్టులుతో నిండిన అర్రే
  console.log("All items are objects:", value.length);
} else {
  console.log("Not a filled array of objects");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areObjects(array)`
