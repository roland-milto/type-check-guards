# arePlainObjects

## వివరణ

ఒక అర్రేలోని అన్ని అంశాలు సాధారణ ఆబ్జెక్ట్‌లేనా అని తనిఖీ చేస్తుంది; ప్రతి అంశం అర్హత పొందినప్పుడే `true` ను తిరిగి
ఇస్తుంది.

### ఉపయోగ సందర్భం

బాహ్య లేదా టైప్ చేయని డేటాను (ఉదా., పార్స్ చేసిన JSON, API పేలోడ్లు, ఫారమ్ సమర్పణలు) ధృవీకరించి, మీరు ప్రాపర్టీలను
చదవడానికి మరియు ఇటరేట్ చేయడానికి ముందు ప్రతి ఎంట్రీ సాధారణ ఆబ్జెక్ట్‌గా ఉన్న ఖాళీ కాని అర్రేను స్వీకరించారని
నిర్ధారించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> TypeScript లో తెలియని ఇన్‌పుట్‌ను `Record<string, unknown>[]` (లేదా మరింత కఠినమైన ఆబ్జెక్ట్ ఆకారం)గా పరిగణించే ముందు
> దాన్ని ధృవీకరించడానికి `arePlainObjects` ను ఉపయోగించండి.

### ప్రయోజనాలు

- ఇన్‌పుట్ అర్రేలోని ప్రతి అంశం సాధారణ ఆబ్జెక్ట్ అని నిర్ధారిస్తుంది; అన్ని అంశాలు సరిపోలినప్పుడే `true` ను తిరిగి
  ఇస్తుంది.
- `false` ను తిరిగి ఇవ్వడం ద్వారా చెల్లని ఇన్‌పుట్‌లను (అర్రేలు కానివి లేదా ఖాళీ అర్రేలు) ముందుగానే తిరస్కరిస్తుంది.
- ఆబ్జెక్ట్-లిటరల్ ఆబ్జెక్ట్‌లను మరియు `Object.create(null)` ఆబ్జెక్ట్‌లను రెండింటినీ చెల్లుబాటు అయ్యే సాధారణ
  ఆబ్జెక్ట్‌లుగా పరిగణిస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `arePlainObjects(array)`

పారామీటర్లు:

- `array`: సాధారణ ఆబ్జెక్ట్ అంశాల కోసం తనిఖీ చేయాల్సిన అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { arePlainObjects } from "@type-check/guards";

const a = arePlainObjects([{ a: 1 }, { b: 2 }]); // నిజం
const b = arePlainObjects([{}, Object.create(null)]); // నిజం
const c = arePlainObjects([{ a: 1 }, 2 as unknown]); // అబద్ధం
const d = arePlainObjects([] as unknown[]); // అబద్ధం

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.arePlainObjects(array)`
