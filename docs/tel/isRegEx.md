# isRegEx

## వివరణ

ఇచ్చిన విలువ `RegExp` ఇన్‌స్టాన్స్ కాదా అని నిర్ధారిస్తుంది.

### ఉపయోగ సందర్భం

యూజర్ అందించిన లేదా డైనమిక్ విలువలను (ఉదా., కాన్ఫిగరేషన్, API పేలోడ్, ప్లగిన్ ఇన్‌పుట్‌లు) రెగ్యులర్ ఎక్స్‌ప్రెషన్‌గా
పరిగణించే ముందు ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `RegExp`-కు ప్రత్యేకమైన ప్రాపర్టీలు లేదా మెథడ్‌లను ఉపయోగించే ముందు `unknown` (లేదా యూనియన్) విలువలను నారో చేయడానికి
`isRegEx` ను ఉపయోగించండి; ఇది `RegExp` యొక్క ఇన్‌స్టాన్స్‌లైన విలువలకు మాత్రమే `true` ను ఇస్తుంది.

### ప్రయోజనాలు

- `RegExp` అయిన విలువను తనిఖీ చేయడానికి సరళమైన రన్‌టైమ్ టైప్ గార్డ్‌ను అందిస్తుంది.
- కోడ్‌కు రెగ్యులర్ ఎక్స్‌ప్రెషన్ అవసరమైనప్పుడు (ఉదా., `test`, `exec` ను పిలిచే ముందు లేదా `source` ను చదివే ముందు)
  లోపాలను నివారించడంలో సహాయపడుతుంది.
- regex లిటరల్స్‌తో పాటు `new RegExp(...)` ద్వారా సృష్టించిన ఇన్‌స్టాన్స్‌లతో కూడా పనిచేస్తుంది.
- regex కాని ఇన్‌పుట్‌లకు ఎలాంటి ఎర్రర్‌ను త్రో చేయకుండా స్పష్టమైన బూలియన్ ఫలితం (`true`/`false`) ను ఇస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isRegEx(value)`

పారామీటర్లు:

- `value`: తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  // input ఇక్కడ RegExp
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isRegEx(value)`
