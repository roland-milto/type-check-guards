# areArrays

## వివరణ

`areArrays` ఒక విలువ ఖాళీ కాని రెండు-కొలతల అర్రేనా, దాని అంశాలన్నీ అర్రేలేనా అనే విషయాన్ని నిర్ణయిస్తుంది.

### ఉపయోగ సందర్భం

రో/కాలమ్ ఆపరేషన్లు చేయడానికి ముందు ట్యాబ్యులర్ లేదా మ్యాట్రిక్స్‌లాంటి ఇన్‌పుట్‌లను (ఉదా., CSV రోలు, గ్రిడ్ డేటా, లేదా
గ్రూప్ చేసిన లిస్టులు) ధృవీకరించడానికి `areArrays` ను ఉపయోగించండి; ఇన్‌పుట్ అర్రే కాకపోతే, ఖాళీగా ఉంటే, లేదా అర్రే కాని
ఏదైనా అంశం కలిగి ఉంటే ఇది `false` ను తిరిగి ఇస్తుంది.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> నెస్టెడ్ అర్రేలలో ఇటరేట్ చేయడానికి లేదా ఇండెక్స్ చేయడానికి ముందు ఒక విలువ ఖాళీ కాని 2D అర్రే అని, అలాగే ప్రతి రో ఒక
> అర్రే అని నిర్ధారించాల్సినప్పుడు `areArrays` ను ఉపయోగించండి.

### ప్రయోజనాలు

- ఇన్‌పుట్ ఖాళీ కాని రెండు-కొలతల అర్రే అని, అందులోని ప్రతి అంశం కూడా ఒక అర్రేనే అని ధృవీకరిస్తుంది.
- గార్డ్స్ మరియు ముందస్తు ఎగ్జిట్స్‌కు అనుకూలంగా ఉండే సరళమైన బూలియన్ ఫలితం (`true`/`false`)ను తిరిగి ఇస్తుంది.
- తరువాతి కోడ్ నెస్టెడ్ అర్రే ఆపరేషన్లు (ఉదా., రోలను మ్యాప్ చేయడం) అనుకుంటున్నప్పుడు రన్‌టైమ్ లోపాలను నివారించడంలో
  సహాయపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areArrays(array)`

పారామీటర్లు:

- `array`: తనిఖీ చేయాల్సిన ఇన్‌పుట్.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value 2D array; arrays elements ga undi
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areArrays(array)`
