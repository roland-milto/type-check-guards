# areWeakMaps

## వివరణ

`areWeakMaps` ఒక విలువ ఖాళీ కాని అర్రేనా, అందులోని ప్రతి అంశం `WeakMap`నా అని తనిఖీ చేస్తుంది; అలా ఉన్నప్పుడే `true` ను,
లేకపోతే `false` ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

రన్‌టైమ్ డేటా (ఉదా., పార్స్ చేసిన JSON, ప్లగిన్ ఇన్‌పుట్‌లు, లేదా సడలించిన టైపింగ్ ఉన్న కాన్ఫిగరేషన్) ను ధృవీకరించి, అది
ఖాళీ కాని `WeakMap` ఇన్‌స్టాన్స్‌ల అర్రే అని నిర్ధారించిన తర్వాతే ఇటరేట్ చేసి `WeakMap` మెథడ్‌లను పిలవండి; ఏ అంశం
`WeakMap` కాకపోయినా లేదా అర్రే ఖాళీగా ఉన్నా ఇది `false` ను తిరిగి ఇస్తుంది.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> తెలియని ఇన్‌పుట్‌ను ఖాళీ కాని `WeakMap[]`గా పరిగణించే ముందు ధృవీకరించడానికి `areWeakMaps` ను ఉపయోగించండి; ఖాళీ అర్రేల
> కోసం ఇది `false` ను తిరిగి ఇస్తుంది.

### ప్రయోజనాలు

- ఇచ్చిన అర్రేలోని ప్రతి అంశం `WeakMap` ఇన్‌స్టాన్స్ అని నిర్ధారిస్తుంది.
- ఖాళీ అర్రేల కోసం `false` ను తిరిగి ఇస్తుంది, “డేటా లేదు” అనే పరిస్థితిని చెల్లుబాటు అయ్యే ఇన్‌పుట్‌గా పొరపాటున
  అంగీకరించకుండా నిరోధిస్తుంది.
- అన్ని అంశాలపై `WeakMap`-కు ప్రత్యేకమైన ఆపరేషన్లు చేయడానికి ముందు గార్డ్‌గా ఉపయోగపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areWeakMaps(array)`

పారామీటర్లు:

- `array`: `WeakMap` ఇన్‌స్టాన్స్‌ల కోసం తనిఖీ చేయాల్సిన అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  // list WeakMap ఉదాహరణలతో ఖాళీ కాని అరే
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  // ఖాళీ కాని WeakMap[] కాదు
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areWeakMaps(array)`
