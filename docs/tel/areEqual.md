# areEqual

## వివరణ

`areEqual` ఒక అర్రేలోని అన్ని అంశాలు ఇచ్చిన ఆశించిన విలువకు సమానమా అని తనిఖీ చేస్తుంది; ప్రతి అంశం సరిపోలిన నాన్-ఎంప్టీ
అర్రేలకే `true` ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

ఒక జాబితాలో ఒకే అనుమతించిన విలువ మాత్రమే ఉందని ధృవీకరించండి (ఉదా., అన్ని స్టేటస్ ఫ్లాగ్‌లు `true`, అన్ని రోల్స్
`"admin"`, లేదా అన్ని సంఖ్యాత్మక ఎంట్రీలు అవసరమైన స్థిరాంకానికి సమానం) మరియు ఖాళీ ఇన్‌పుట్‌ను చెల్లనిదిగా (`false`)
పరిగణించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> కఠినమైన అన్ని-అంశాల తనిఖీ అవసరమైనప్పుడు `areEqual` ను ఉపయోగించండి; ఇది ఖాళీ అర్రేలకూ, అలాగే ఏదైనా అర్రే కాని లేదా
> నిండని ఇన్‌పుట్‌కూ `false` ను తిరిగి ఇస్తుంది.

### ప్రయోజనాలు

- ప్రతి అంశం ఆశించిన విలువతో సరిపోలినప్పుడు మాత్రమే `true` ను తిరిగి ఇస్తుంది; లేకపోతే `false` ను తిరిగి ఇస్తుంది.
- త్వరగా విఫలమవుతుంది: సరిపోలని అంశం కనబడిన వెంటనే తనిఖీని ఆపేస్తుంది.
- ఇన్‌పుట్ నిండిన అర్రే కాకపోతే `false` ను తిరిగి ఇవ్వడం ద్వారా చెల్లని ఇన్‌పుట్ నుండి రక్షిస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areEqual(value, expected)`

పారామీటర్లు:

- `value`: తనిఖీ చేయాల్సిన అర్రే.
- `expected`: ప్రతి అర్రే అంశంతో పోల్చాల్సిన అంశం.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areEqual(value, expected)`
