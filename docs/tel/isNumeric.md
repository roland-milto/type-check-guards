# isNumeric

## వివరణ

`isNumeric` ఇచ్చిన `value` ను `NUMERIC_TYPES` తో పోల్చి దాని పరిష్కరించిన రకాన్ని తనిఖీ చేయడం ద్వారా అది సంఖ్యాత్మకంగా
పరిగణించబడుతుందో లేదో నిర్ణయిస్తుంది.

### ఉపయోగ సందర్భం

సంఖ్యాత్మక ఆపరేషన్లు చేయడానికి ముందు ఇన్‌పుట్‌లను (ఉదా., API పేచ్‌లోడ్లు, ఫారమ్ విలువలు, కాన్ఫిగరేషన్) ధృవీకరించడానికి,
అలాగే `NUMERIC_TYPES` ప్రకారం `BigInt` వంటి సంఖ్యాత్మక-సదృశ రకాలను సుసంగతంగా అంగీకరించడానికి `isNumeric` ను ఉపయోగించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `isNumeric` బూలియన్‌ను తిరిగి ఇచ్చే ప్రెడికేట్; లైబ్రరీ నిర్వచించిన సంఖ్యాత్మక రకాల సమూహానికి ఒక విలువ చెందుతుందో లేదో
> తెలుసుకునే రన్‌టైమ్ చెక్‌గా దీన్ని పరిగణించండి.

### ప్రయోజనాలు

- `getTypeOf` మరియు `NUMERIC_TYPES` ను ఉపయోగించి సంఖ్యాత్మక గుర్తింపు లాజిక్‌ను కేంద్రీకరిస్తుంది మరియు కోడ్‌బేస్ అంతటా
  తనిఖీలను సుసంగతంగా ఉంచుతుంది.
- సులభమైన బ్రాంచింగ్ మరియు గార్డ్-శైలి వినియోగం కోసం సరళమైన బూలియన్ (`true`/`false`) ను తిరిగి ఇస్తుంది.
- `NUMERIC_TYPES` ద్వారా నిర్వచించినట్లుగా బహుళ సంఖ్యాత్మక ప్రతినిధీకరణలను (ఉదా., `number`, `BigInt`) మద్దతు ఇస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isNumeric(value)`

పారామీటర్లు:

- `value`: సంఖ్యాత్మక రకం ఉందో లేదో తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    // v ቤተ-መጻሕፍቲ ዓይነት ሕጊታት መሰረት ቁጽራዊ እዩ ተባሂሉ ይቑጸር
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isNumeric(value)`
