# isEmpty

## వివరణ

ఇచ్చిన విలువ ఖాళీగా ఉందో లేదో నిర్ణయిస్తుంది; `null`, `undefined`, ఖాళీ/ఖాళీలతో మాత్రమే ఉన్న స్ట్రింగ్‌లు, ఖాళీ అర్రేలు,
ఖాళీ `Map`/`Set`, లేదా స్వంత enumerable ప్రాపర్టీలు లేని ఆబ్జెక్ట్‌లకు `true` ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

`isEmpty` ను ఇన్‌పుట్‌లను వాలిడేట్ చేయడానికి మరియు అనేక డేటా రకాలలో (ఉదా., ఫార్మ్ ఫీల్డ్‌లు, API పేలోడ్‌లు, కాన్ఫిగరేషన్
ఆబ్జెక్ట్‌లు) లేని/ఖాళీ విలువలను గుర్తించడానికి ఉపయోగించండి; ఇక్కడ `null`, `undefined`, ఖాళీలతో ఉన్న స్ట్రింగ్‌లు, ఖాళీ
కలెక్షన్‌లు, మరియు ప్రాపర్టీలు లేని ఆబ్జెక్ట్‌లు ఖాళీగా పరిగణించాలి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `isEmpty` అనేది బూలియన్‌ను తిరిగి ఇచ్చే యుటిలిటీ (TypeScript టైప్ ప్రెడికేట్ కాదు), కాబట్టి ఇది స్వయంగా టైప్‌లను నారో
> చేయదు; కంపైల్-టైమ్ నారోయింగ్ కంటే వాలిడేషన్/బ్రాంచింగ్ కోసం దీన్ని ఉపయోగించండి.

### ప్రయోజనాలు

- ఖాళీదనం తనిఖీల కోసం `null` మరియు `undefined` ను `true` గా పరిగణిస్తుంది.
- పొడవు తనిఖీకి ముందు ట్రిమ్ చేయడం ద్వారా కేవలం ఖాళీలతో ఉన్న స్ట్రింగ్‌లను ఖాళీగా పరిగణిస్తుంది.
- సాధారణ కంటైనర్ రకాలైన (అర్రేలు, `Map`, `Set`) మరియు స్వంత enumerable ప్రాపర్టీలు లేని సాధారణ ఆబ్జెక్ట్‌లకు మద్దతు
  ఇస్తుంది.
- `hasOwnProperty` తనిఖీలను ఉపయోగించడం ద్వారా వారసత్వంగా వచ్చిన ప్రాపర్టీలను లెక్కించకుండా నివారిస్తుంది.
- గార్డ్స్ మరియు వాలిడేషన్‌కు అనుకూలమైన సరళమైన బూలియన్ ఫలితం (`true`/`false`) ను తిరిగి ఇస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isEmpty(value)`

పారామీటర్లు:

- `value`: ఖాళీదనం కోసం తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isEmpty(value)`
