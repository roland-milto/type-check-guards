# areDates

## వివరణ

`areDates` ఇచ్చిన అర్రే నిండి ఉందో మరియు అందులో `Date` ఆబ్జెక్ట్‌లు మాత్రమే ఉన్నాయో నిర్ణయిస్తుంది; అన్ని అంశాలు
చెల్లుబాటు అయ్యే తేదీలు అయినప్పుడే `true` ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

తేదీ-నిర్దిష్ట లాజిక్ (ఉదా., సమయం ఆధారంగా సార్టింగ్, ఫార్మాటింగ్, లేదా రేంజ్‌లను లెక్కించడం) నడపడానికి ముందు తెలియని
ఇన్‌పుట్ (ఉదా., పార్స్ చేసిన JSON, ఫారమ్ డేటా, API పేలోడ్‌లు) ను ధృవీకరించడానికి `areDates` ను ఉపయోగించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `true` ను ఖాళీ కాని అర్రేలకు మాత్రమే ఇస్తుంది, అందులోని ప్రతి అంశం `Date` అయినప్పుడు; ఖాళీ అర్రేలకు `false` వస్తుంది.

### ప్రయోజనాలు

- దాని అంశాలను ధృవీకరించే ముందు అర్రే ఖాళీగా లేదని నిర్ధారిస్తుంది, ఖాళీ ఇన్‌పుట్‌లకు `true` రావడం నివారిస్తుంది.
- ప్రతి అంశం `Date` ఇన్‌స్టాన్స్ అని ధృవీకరిస్తుంది; మొదటి అసమతుల్యత వద్దనే వెంటనే `false` ను తిరిగి ఇస్తుంది.
- అర్రే అంశాలపై తేదీ-నిర్దిష్ట ఆపరేషన్లు చేయడానికి ముందు గార్డ్-శైలి తనిఖీగా ఉపయోగపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areDates(array)`

పారామీటర్లు:

- `array`: `Date` ఆబ్జెక్ట్‌ల కోసం తనిఖీ చేయాల్సిన అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areDates } from "@type-check/guards";

const a: unknown[] = [new Date(), new Date("2021-01-01")];
const b: unknown[] = [];
const c: unknown[] = [new Date(), "not a date"];

console.log(areDates(a)); // నిజం
console.log(areDates(b)); // అబద్ధం
console.log(areDates(c)); // అబద్ధం

if (areDates(a)) {
  const timestamps = a.map(d => d.getTime());
  console.log(timestamps);
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areDates(array)`
