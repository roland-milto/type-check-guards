# isOctal

## వివరణ

ఒక విలువ చెల్లుబాటు అయ్యే ఆక్టల్ లిటరల్ స్ట్రింగ్ (ఉదా. `0o755`) కాదో నిర్ణయిస్తుంది.

### ఉపయోగ సందర్భం

పార్స్ చేయడానికి లేదా మార్చడానికి ముందు, ఆక్టల్ లిటరల్ స్ట్రింగ్‌గా వ్యక్తీకరించాల్సిన యూజర్ ఇన్‌పుట్ లేదా కాన్ఫిగరేషన్
విలువలను (ఉదాహరణకు, `0o644` వంటి ఫైల్ అనుమతి మోడ్‌లు) ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `isOctal` ఒక టైప్ గార్డ్ (`value is string`). `true` ఫలితం వచ్చిన తర్వాత, TypeScript తనిఖీ చేసిన వేరియబుల్‌ను `string`
> గా నారో చేస్తుంది.

### ప్రయోజనాలు

- కఠినమైన టైప్ గార్డ్‌ను అందిస్తుంది: ఇన్‌పుట్ ఆక్టల్ లిటరల్ ఫార్మాట్‌కు సరిపోలే స్ట్రింగ్ అయినప్పుడే `true` ను తిరిగి
  ఇస్తుంది.
- ఖాళీ స్ట్రింగ్‌లను మరియు ముందుభాగం/వెనుకభాగంలో ఖాళీలు (ASCII కంట్రోల్/స్పేస్) ఉన్న స్ట్రింగ్‌లను తిరస్కరిస్తుంది,
  అనుకోకుండా మ్యాచ్‌లు తగ్గుతాయి.
- ఐచ్చిక సైన్‌కు మద్దతు ఇస్తుంది మరియు `0o`/`0O` ప్రిఫిక్స్ విషయంలో కేస్-ఇన్‌సెన్సిటివ్‌గా ఉంటుంది.
- స్ట్రింగ్ కాని ఇన్‌పుట్‌లకు ఎర్రర్ వేయకుండా `false` ను తిరిగి ఇస్తూ సడలింపుగా ఉంటుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isOctal(value)`

పారామీటర్లు:

- `value`: తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); // true
console.log(isOctal(b)); // true
console.log(isOctal(c)); // false
console.log(isOctal(d)); // false

if (isOctal(a)) {
  // a ఇక్కడ string
  const normalized = a.toLowerCase();
  console.log(normalized);
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isOctal(value)`
