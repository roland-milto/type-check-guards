# areTrue

## వివరణ

ఖాళీ కాని అర్రేలో బూలియన్ `true` విలువలే ఉన్నాయా అని తనిఖీ చేస్తుంది.

### ఉపయోగ సందర్భం

కొనసాగించే ముందు ముందస్తు షరతులు లేదా ఫీచర్ ఫ్లాగ్‌లు అన్నీ ఎనేబుల్ అయ్యాయా (అన్ని విలువలు `true`) అని ధృవీకరించడానికి
`areTrue` ను ఉపయోగించండి; ఖాళీ లేదా తప్పుగా ఉన్న ఇన్‌పుట్‌లను తీరనివిగా (`false`) పరిగణిస్తుంది.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `areTrue` ఖాళీ అర్రేకు మరియు ఖచ్చితంగా `true` కాని ఏదైనా విలువ ఉన్న అర్రేలకు `false` ను తిరిగి ఇస్తుంది.

### ప్రయోజనాలు

- ప్రతి అంశం ఖచ్చితంగా `true` గా ఉండి, అర్రే ఖాళీగా లేకపోతేనే `true` ను తిరిగి ఇస్తుంది.
- త్వరగా విఫలమవుతుంది: `true` కాని విలువ కనిపించిన వెంటనే `false` ను తిరిగి ఇస్తుంది.
- చెల్లని ఇన్‌పుట్‌లను (అర్రేలు కానివి లేదా ఖాళీ అర్రేలు) `false` ను తిరిగి ఇవ్వడం ద్వారా తిరస్కరిస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areTrue(array)`

పారామీటర్లు:

- `array`: అన్ని `true` విలువల కోసం తనిఖీ చేయాల్సిన అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areTrue } from "@type-check/guards";

const a = areTrue([true, true, true]);
const b = areTrue([true, false, true]);
const c = areTrue([]);
const d = areTrue([true, "string" as unknown, true]);

console.log(a, b, c, d);
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areTrue(array)`
