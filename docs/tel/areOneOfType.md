# areOneOfType

## వివరణ

`areOneOfType` ఖాళీ కాని అర్రేలోని అన్ని అంశాలు పేర్కొన్న రన్‌టైమ్ టైప్‌లలో ఏదో ఒకటి కిందకి వస్తాయా అని తనిఖీ చేస్తుంది.

### ఉపయోగ సందర్భం

ఇన్‌కమింగ్ డేటాను (ఉదా., పార్స్ చేసిన JSON) ధృవీకరించండి: ఒక ఫీల్డ్ ఖాళీ కాని అర్రేగా ఉండాలి మరియు దాని అంశాలు తెలిసిన
ప్రిమిటివ్ టైప్‌ల సమితికే పరిమితం కావాలి; అర్రే ఖాళీగా ఉన్నా లేదా ఏదైనా అనుమతించని టైప్ ఉంటే `false` ను తిరిగి ఇవ్వండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> ఈ ఫంక్షన్ boolean ను తిరిగి ఇస్తుంది మరియు కంపైల్ టైమ్‌లో అర్రే అంశాల టైప్‌లను న్యారో చేయదు; తదుపరి ప్రాసెసింగ్‌కు
> ముందు రన్‌టైమ్ ధృవీకరణ దశగా దీన్ని ఉపయోగించండి.

### ప్రయోజనాలు

- ఒక అర్రేలోని ప్రతి అంశం కనీసం ఒక అనుమతించిన రన్‌టైమ్ టైప్‌కు సరిపోతుందని నిర్ధారిస్తుంది; మొత్తం అర్రే పాస్ అయినప్పుడే
  `true` ను తిరిగి ఇస్తుంది.
- చెల్లని ఇన్‌పుట్‌లను ముందుగానే తిరస్కరిస్తుంది: `array` లేదా `types` ఖాళీగా ఉన్నప్పుడు లేదా నింపబడిన అర్రే కాకపోతే
  `false` ను తిరిగి ఇస్తుంది.
- `areOneOfType` ను ఒక్కసారి పిలవడం ద్వారా మిశ్రమ-టైప్ సేకరణలను (ఉదా., సంఖ్యలు మరియు స్ట్రింగ్‌లు) ధృవీకరించడానికి
  ఉపయోగపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areOneOfType(array, types)`

పారామీటర్లు:

- `array`: ఇచ్చిన టైప్‌లతో సరిపోల్చి ధృవీకరించాల్సిన అంశాల అర్రే.
- `types`: తనిఖీ చేయాల్సిన డేటా టైప్‌లను సూచించే స్ట్రింగ్‌ల అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areOneOfType } from "@type-check/guards";

const values1: unknown[] = [1, "a", true];
const ok1 = areOneOfType(values1, ["number", "string", "boolean"]);

const values2: unknown[] = [1, "a", {}];
const ok2 = areOneOfType(values2, ["number", "string"]);

const values3: unknown[] = [];
const ok3 = areOneOfType(values3, ["number"]);

console.log({ ok1, ok2, ok3 });
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areOneOfType(array, types)`
