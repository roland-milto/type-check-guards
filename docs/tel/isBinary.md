# isBinary

## వివరణ

`isBinary` ఒక విలువ బైనరీ స్ట్రింగ్‌నా (ఐచ్ఛికంగా `0b`/`0B` ఉపసర్గతో) అని నిర్ణయించి `true` లేదా `false` ను తిరిగి
ఇస్తుంది.

### ఉపయోగ సందర్భం

వినియోగదారు అందించిన స్ట్రింగ్‌లను (ఉదా., ఫారమ్ ఫీల్డ్‌లు, CLI args, కాన్ఫిగ్ విలువలు) మరింత ప్రాసెసింగ్‌కు ముందు, అవి
కేవలం బైనరీ అంకెలనే సూచిస్తున్నాయా (ఐచ్ఛికంగా `0b`/`0B` ఉపసర్గతో) అని నిర్ధారించడానికి ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> స్ట్రింగ్‌ను `BigInt`/`Number` గా పార్స్ చేయడానికి లేదా మార్చడానికి ముందు చెల్లని ఇన్‌పుట్‌ను నివారించేందుకు
`isBinary` ను టైప్ గార్డ్‌గా ఉపయోగించండి.

### ప్రయోజనాలు

- `0b`/`0B` ఉపసర్గతో లేదా లేకుండా బైనరీ స్ట్రింగ్‌లను స్వీకరిస్తుంది.
- ఖాళీ స్ట్రింగ్‌లను మరియు ముందుభాగం/వెనకభాగం ఖాళీలతో (ASCII ≤ 32) ఉన్న స్ట్రింగ్‌లను తిరస్కరిస్తుంది.
- ఎర్రర్ విసరకుండా `true`/`false` ను తిరిగి ఇస్తుంది, కాబట్టి తెలియని ఇన్‌పుట్‌లకు కూడా సురక్షితం.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isBinary(value)`

పారామీటర్లు:

- `value`: పరిశీలించాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // నిజం
const b = isBinary("1010");   // నిజం
const c = isBinary("0b1020"); // అబద్ధం
const d = isBinary(0b1010);     // అబద్ధం

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isBinary(value)`
