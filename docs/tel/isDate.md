# isDate

## వివరణ

`isDate` ఇచ్చిన విలువ `Date` కాదా అని నిర్ణయిస్తుంది; `Date` ఇన్‌స్టాన్స్‌లకు `true`ని, లేకపోతే `false`ని తిరిగి
ఇస్తుంది.

### ఉపయోగ సందర్భం

`toISOString()` ను కాల్ చేయడం, ఫార్మాటింగ్, పోలికలు వంటి `Date` ఆపరేషన్లు చేయడానికి ముందు తెలియని విలువలను (ఉదా.,
రిక్వెస్ట్ డేటా, కాన్ఫిగ్ విలువలు, లేదా పార్స్ చేసిన JSON) ధృవీకరించి న్యారో చేయండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> రన్‌టైమ్‌లో `unknown` ను `Date` గా న్యారో చేయడానికి `isDate` ను ఉపయోగించండి; ఇది నిజమైన `Date` ఇన్‌స్టాన్స్‌లకు
> మాత్రమే `true` ఇస్తుంది (తేదీ స్ట్రింగ్‌లకు కాదు).

### ప్రయోజనాలు

- `Date` అయి ఉందో లేదో నిర్ధారించడానికి ఇది సరళమైన రన్‌టైమ్ గార్డ్‌ను అందిస్తుంది.
- వాలిడేషన్‌లో `Date` ఇన్‌స్టాన్స్‌లు మాత్రమే పాస్ అయ్యేలా చేసి టైప్ లోపాలను నివారించడంలో ఇది సహాయపడుతుంది.
- తేదీకి ప్రత్యేకమైన మెథడ్‌లను ఉపయోగించే ముందు తెలియని ఇన్‌పుట్‌లను (ఉదా., API పేచ్‌లోడ్స్) ధృవీకరించడానికి ఇది
  ఉపయోగపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isDate(value)`

పారామీటర్లు:

- `value`: `Date` టైప్ కోసం తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isDate } from "@type-check/guards";

const input: unknown = new Date();

if (isDate(input)) {
  // ఇక్కడ input ఒక Date
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a Date");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isDate(value)`
