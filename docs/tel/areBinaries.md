# areBinaries

## వివరణ

ఇచ్చిన విలువ చెల్లుబాటు అయ్యే బైనరీ స్ట్రింగ్‌ల ఖాళీ కాని అర్రేనా అని తనిఖీ చేసి, అన్ని అంశాలు ధృవీకరణను దాటినప్పుడే
`true`ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

తెలియని జాబితా (ఉదా., JSON, ఫార్ములు, లేదా APIs నుండి) వచ్చినప్పుడు, దాన్ని పార్స్ చేయడానికి లేదా ప్రాసెస్ చేయడానికి
ముందు అది బైనరీ స్ట్రింగ్‌ల ఖాళీ కాని అర్రే అని నిర్ధారించాల్సిన సందర్భంలో `areBinaries`ను ఉపయోగించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> బైనరీ స్ట్రింగ్‌లను సంఖ్యలు/BigInts‌గా మార్చే ముందు తెలియని ఇన్‌పుట్‌ను ధృవీకరించడానికి `areBinaries`ను ఉపయోగించండి;
> ఇది అర్రే ఖాళీ కాకుండా ఉండేలా మరియు ప్రతి అంశం చెల్లుబాటు అయ్యే బైనరీ స్ట్రింగ్‌గా ఉండేలా నిర్ధారిస్తుంది.

### ప్రయోజనాలు

- ఒక విలువ ఖాళీ కాని అర్రే అని, అందులోని ప్రతి అంశం చెల్లుబాటు అయ్యే బైనరీ స్ట్రింగ్ అని ధృవీకరిస్తుంది.
- గార్డ్స్, ముందస్తు రిటర్న్స్, మరియు ఇన్‌పుట్ ధృవీకరణకు అనుకూలమైన సరళమైన బూలియన్ ఫలితం (`true`/`false`)ను ఇస్తుంది.
- బైనరీ కాని ఎంట్రీ ఏదైనా ఉన్న అర్రేలను తిరస్కరించడం ద్వారా తరువాతి పార్సింగ్ లోపాలను నివారిస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areBinaries(array)`

పారామీటర్లు:

- `array`: తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // నిజం
console.log(areBinaries(b)); // అబద్ధం
console.log(areBinaries([])); // అబద్ధం
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areBinaries(array)`
