# areBooleans

## వివరణ

`areBooleans` ఇచ్చిన ఖాళీ కాని అర్రేలో బూలియన్ విలువలు మాత్రమే ఉన్నాయా అని తనిఖీ చేస్తుంది; ఉంటే `true`, లేకపోతే `false`
ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

వినియోగదారు అందించిన లేదా బాహ్య డేటా (ఉదా., JSON పేలోడ్లు, క్వెరీ పరామ్స్, కాన్ఫిగ్ అర్రేలు) ను ధృవీకరించి, ఖాళీ కాని
జాబితాలో బూలియన్లు మాత్రమే ఉన్నాయని నిర్ధారించిన తర్వాత బూలియన్ లాజిక్‌ను వర్తింపజేయడానికి లేదా `boolean[]` ను ఆశించే
APIలకు పంపడానికి ఉపయోగించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `unknown[]` ను `boolean[]` గా పరిగణించే ముందు దాన్ని ధృవీకరించడానికి `areBooleans` ను ఉపయోగించండి; ఇది ఖాళీ అర్రేల
> కోసం `false` ను తిరిగి ఇస్తుంది, కాబట్టి ఖాళీ జాబితాను అనుమతించాలి అనుకుంటే ఆ సందర్భాన్ని స్పష్టంగా హ్యాండిల్ చేయండి.

### ప్రయోజనాలు

- ప్రతి అంశం బూలియన్‌గా ఉండి, ఇన్‌పుట్ ఖాళీ కాని అర్రే అయినప్పుడే `true` ను తిరిగి ఇస్తుంది.
- ఖాళీ అర్రేలను తిరస్కరించడం ద్వారా ( `false` ను తిరిగి ఇస్తుంది) తప్పుడు పాజిటివ్‌లను నివారిస్తుంది.
- బూలియన్-మాత్రమే ఆపరేషన్లకు ముందు రన్‌టైమ్ గార్డ్‌గా బాగా పనిచేస్తుంది (ఉదా., `every`, `some`, లాజికల్ రిడక్షన్లు).

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areBooleans(array)`

పారామీటర్లు:

- `array`: బూలియన్ అంశాల కోసం తనిఖీ చేయాల్సిన అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areBooleans } from "@type-check/guards";

const values1: unknown[] = [true, false, true];
if (areBooleans(values1)) {
  const allTrue = values1.every(v => v);
  console.log(allTrue);
}

const values2: unknown[] = [];
console.log(areBooleans(values2));

const values3: unknown[] = [true, 1, false];
console.log(areBooleans(values3));
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areBooleans(array)`
