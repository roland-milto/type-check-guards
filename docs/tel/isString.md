# isString

## వివరణ

`isString` ఇచ్చిన విలువ స్ట్రింగ్ కాదా అని నిర్ణయిస్తుంది.

### ఉపయోగ సందర్భం

స్ట్రింగ్ ఆపరేషన్లు (ఉదా., ట్రిమ్ చేయడం, స్ప్లిట్ చేయడం, కేస్ మార్పు) వర్తింపజేయడానికి ముందు విలువ స్ట్రింగ్ అని
నిర్ధారించడానికి రన్‌టైమ్‌లో యూజర్ ఇన్‌పుట్, API పేలోడ్ ఫీల్డ్‌లు, లేదా కాన్ఫిగరేషన్ విలువలను ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> స్ట్రింగ్ మెథడ్‌లను పిలిచే ముందు `unknown` లేదా సడలించిన టైప్ ఉన్న విలువలను ధృవీకరించడానికి `isString` ను ఉపయోగించండి;
`typeof value === "string"` అయినప్పుడే ఇది `true` ను ఇస్తుంది.

### ప్రయోజనాలు

- `typeof` ఉపయోగించి సులభమైన మరియు వేగమైన తనిఖీ.
- అంచనా వేయగల బూలియన్ ఫలితాన్ని ఇస్తుంది: స్ట్రింగ్‌లకు `true`, లేకపోతే `false`.
- ఖాళీ మరియు ఖాళీ కాని స్ట్రింగ్‌ల రెండింటికీ పనిచేస్తుంది.
- స్ట్రింగ్-నిర్దిష్ట ఆపరేషన్లు చేయడానికి ముందు తేలికపాటి రన్‌టైమ్ గార్డ్‌గా ఉపయోగపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isString(value)`

పారామీటర్లు:

- `value`: స్ట్రింగ్ టైప్ కోసం పరీక్షించాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isString } from "@type-check/guards";

const input: unknown = "Hello World";

if (isString(input)) {
  // input ሕልፍ ኣብዚ ስትሪንግ እዩ
  console.log(input.toUpperCase());
} else {
  console.log("Not a string");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isString(value)`
