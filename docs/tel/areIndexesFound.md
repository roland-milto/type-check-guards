# areIndexesFound

## వివరణ

`areIndexesFound` ఒక విలువ ఖాళీ కాని అర్రేనా మరియు దాని అంశాలన్నీ చెల్లుబాటు అయ్యే ఇండెక్సులేనా అని తనిఖీ చేస్తుంది; అవి
అయితే `true`, లేకపోతే `false` ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

అర్రేలను యాక్సెస్ చేయడానికి లేదా స్లైస్ చేయడానికి ఉపయోగించే ముందు, ఇండెక్సుల జాబితా అని భావించే వినియోగదారు అందించిన
లేదా బాహ్య డేటా (ఉదా., పార్స్ చేసిన JSON) ను ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> తెలియని ఇన్‌పుట్‌ను అర్రే ఇండెక్సులుగా పరిగణించే ముందు దాని అంశాలను ధృవీకరించడానికి `areIndexesFound` ను ఉపయోగించండి;
> ఖాళీ అర్రేల కోసం మరియు ఇండెక్స్ కాని విలువలు ఉన్న అర్రేల కోసం ఇది `false` ను తిరిగి ఇస్తుంది.

### ప్రయోజనాలు

- ఇది ఇన్‌పుట్ నిండిన అర్రే అయినప్పుడు మరియు ప్రతి అంశం చెల్లుబాటు అయ్యే ఇండెక్స్ అయినప్పుడు మాత్రమే `true` ను తిరిగి
  ఇస్తుంది.
- త్వరగా విఫలమవుతుంది: ఇండెక్స్ కాని అంశం ఎదురైన వెంటనే `false` ను తిరిగి ఇస్తుంది.
- విలువలను అర్రే స్థానాలు లేదా ఆఫ్‌సెట్లుగా ఉపయోగించే ముందు గార్డ్‌గా ఉపయోగపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areIndexesFound(array)`

పారామీటర్లు:

- `array`: ఇండెక్స్ అనుగుణత కోసం తనిఖీ చేయాల్సిన అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areIndexesFound } from "@type-check/guards";

const a: unknown[] = [0, 1, 2];
const b: unknown[] = [0, "a", 2];
const c: unknown[] = [];

console.log(areIndexesFound(a)); // నిజం
console.log(areIndexesFound(b)); // అబద్ధం
console.log(areIndexesFound(c)); // అబద్ధం

if (areIndexesFound(a)) {
  // ఇక్కడ, `a` సూచికలతో నింపబడిన అర్రేగా నిర్ధారించబడింది.
  const firstIndex = a[0];
  console.log(firstIndex);
}
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areIndexesFound(array)`
