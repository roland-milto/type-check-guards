# areValidDates

## వివరణ

ఒక అర్రే ఖాళీ కాకుండా ఉందా మరియు పూర్తిగా చెల్లుబాటు అయ్యే `Date` ఆబ్జెక్టులతోనే ఉందా అనే విషయాన్ని నిర్ధారిస్తుంది.

### ఉపయోగ సందర్భం

తేదీ ఆధారిత ఆపరేషన్లు (సార్టింగ్, రేంజ్ చెక్స్, ఫార్మాటింగ్) చేయడానికి ముందు, యూజర్ లేదా API అందించిన అర్రేలను వాలిడేట్
చేయడానికి `areValidDates` ను ఉపయోగించండి; అన్ని ఎంట్రీలు నిజమైన, చెల్లుబాటు అయ్యే `Date` ఆబ్జెక్టులేనని మరియు జాబితా
ఖాళీ కాదని నిర్ధారిస్తుంది.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `areValidDates` ఖాళీ అర్రేకు `false` ను తిరిగి ఇస్తుంది; వాలిడేషన్ దశగా దీనిపై ఆధారపడే ముందు అర్రే ఖాళీ కాకుండా
> ఉండాలని ఉద్దేశించబడిందో లేదో నిర్ధారించుకోండి.

### ప్రయోజనాలు

- `new Date('invalid')` వంటి చెల్లని తేదీలు కాకుండా, ప్రతి అంశం చెల్లుబాటు అయ్యే `Date` ఇన్‌స్టాన్స్ అయినప్పుడే `true`
  ను తిరిగి ఇస్తుంది.
- `false` ను తిరిగి ఇవ్వడం ద్వారా ఖాళీ ఇన్‌పుట్‌ను తిరస్కరిస్తుంది; దీంతో అర్థవంతమైన, ఖాళీ కాని తేదీల జాబితాలనే మీరు
  స్వీకరించేలా చేస్తుంది.
- ఇతర వాలిడేషన్లతో సులభంగా కలపగలిగే సరళమైన బూలియన్ గార్డ్-స్టైల్ చెక్‌ను అందిస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areValidDates(array)`

పారామీటర్లు:

- `array`: తనిఖీ చేయాల్సిన అర్రే; ఇందులో `Date` ఆబ్జెక్టులు ఉండే అవకాశం ఉంది.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areValidDates } from "@type-check/guards";

const a = [new Date(), new Date("2025-12-17")];
const b = [new Date(), "not a date"] as unknown[];
const c: unknown[] = [];
const d = [new Date("invalid date")] as unknown[];

console.log(areValidDates(a)); // ᎤᏓᏛᏁᎵᏓ
console.log(areValidDates(b)); // ᎤᏓᏛᏁᎵᏓ ᎾᎿᎭᏛ
console.log(areValidDates(c)); // ᎤᏓᏛᏁᎵᏓ ᎾᎿᎭᏛ
console.log(areValidDates(d)); // ᎤᏓᏛᏁᎵᏓ ᎾᎿᎭᏛ

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areValidDates(array)`
