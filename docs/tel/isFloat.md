# isFloat

## వివరణ

`isFloat` ఇచ్చిన `value` పరిమితమైన ఫ్లోటింగ్-పాయింట్ సంఖ్యా (పూర్ణసంఖ్య కాని `number`) కాదా అని నిర్ణయిస్తుంది.

### ఉపయోగ సందర్భం

భిన్న విలువలు అవసరమైన (ఉదా., ధరలు, కొలతలు, రేట్లు) వినియోగదారు అందించిన సంఖ్యా ఇన్‌పుట్‌ను ధృవీకరించి, పూర్ణసంఖ్యలు,
`NaN`, మరియు అనంతాలను తిరస్కరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> పరిమితమైన, పూర్ణసంఖ్య కాని సంఖ్యా ఇన్‌పుట్‌లను మాత్రమే అంగీకరించాల్సినప్పుడు `isFloat` ను ఉపయోగించండి; ఇది
> పూర్ణసంఖ్యలు మరియు పరిమితంకాని సంఖ్యలను తిరస్కరిస్తుంది.

### ప్రయోజనాలు

- `true` ను కేవలం పరిమితమైన, పూర్ణసంఖ్య కాని సంఖ్యలకే తిరిగి ఇస్తుంది (పూర్ణసంఖ్యలు, `NaN`, `Infinity`, మరియు
  `-Infinity` ను మినహాయిస్తుంది).
- ఏ ఇన్‌పుట్ రకంతోనైనా (`unknown`) పనిచేస్తుంది మరియు `typeof value === "number"` ను తనిఖీ చేసి సురక్షితంగా టైప్‌ను
  సంకుచితం చేస్తుంది.
- అంచనా వేయగల ప్రవర్తన కోసం అంతర్నిర్మిత సంఖ్యా గార్డ్స్ (`Number.isInteger`, `Number.isFinite`) ను ఉపయోగిస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isFloat(value)`

పారామీటర్లు:

- `value`: ఇది ఫ్లోటింగ్-పాయింట్ సంఖ్యా కాదా అని తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isFloat } from "@type-check/guards";

const inputs: unknown[] = [3.14, -0.1, 1e-7, 42, "3.14", NaN, Infinity];

for (const value of inputs) {
  if (isFloat(value)) {
    // విలువ రన్‌టైమ్‌లో సంఖ్య; అది పరిమితమైనది మరియు పూర్ణసంఖ్య కాదు
    const rounded = value.toFixed(2);
    console.log("float:", value, "rounded:", rounded);
  } else {
    console.log("not a float:", value);
  }
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isFloat(value)`
