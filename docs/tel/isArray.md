# isArray

## వివరణ

`isArray` ఇచ్చిన విలువ ఒక అరేనా కాదా అని తనిఖీ చేసి, అరే అయితే `true` లేకపోతే `false` ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

తెలియని డేటాను (ఉదా., పార్స్ చేసిన JSON లేదా API ప్రతిస్పందనలు) ధృవీకరించి, ఇటరేట్ చేయడానికి, ఇండెక్స్ చేయడానికి లేదా
`.length` ను యాక్సెస్ చేయడానికి ముందు ఒక విలువ అరే అని నిర్ధారించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> అరేల కోసం రన్‌టైమ్ చెక్ అవసరమైనప్పుడు `isArray` ను ఉపయోగించండి; ఇది బూలియన్‌ను తిరిగి ఇస్తుంది మరియు `unknown`
> విలువలతో కాల్ చేయడం సురక్షితం.

### ప్రయోజనాలు

- వివిధ రియల్మ్‌లలో (ఉదా., iframes) విశ్వసనీయమైన అరే గుర్తింపుకోసం అంతర్నిర్మిత `Array.isArray` ను ఉపయోగిస్తుంది.
- గార్డ్స్ మరియు బ్రాంచింగ్ లాజిక్‌కు సరిపోయే సరళమైన బూలియన్ ఫలితం (`true`/`false`) ను తిరిగి ఇస్తుంది.
- పారామీటర్ `unknown` కాబట్టి ఏ ఇన్‌పుట్ టైప్‌తోనైనా పనిచేస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isArray(value)`

పారామీటర్లు:

- `value`: తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  // input runtime lo array
  console.log(input.length);
} else {
  console.log("Not an array");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isArray(value)`
