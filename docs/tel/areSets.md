# areSets

## వివరణ

ఇచ్చిన ఖాళీ కాని అర్రేలో `Set` ఇన్‌స్టాన్స్‌లు మాత్రమే ఉన్నాయా అని తనిఖీ చేసి, ఉంటే `true` లేకపోతే `false` ను తిరిగి
ఇస్తుంది.

### ఉపయోగ సందర్భం

ప్రతి సెట్‌ను ప్రాసెస్ చేయడానికి ముందు, ఒక విలువ (ఉదా., యూజర్ ఇన్‌పుట్, JSON పార్సింగ్, లేదా బాహ్య APIల నుండి) ఖాళీ కాని
`Set` ఆబ్జెక్టుల అర్రే అని ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> ప్రతి అంశంపై `Set` APIలను (ఉదా., `.size`, `.has`, `.add`) పిలవడం మరియు ఇటరేట్ చేయడానికి ముందు తెలియని ఇన్‌పుట్‌ను
> ధృవీకరించడానికి `areSets` ను ఉపయోగించండి.

### ప్రయోజనాలు

- ఇన్‌పుట్ ఖాళీ కాని అర్రే అయి, ప్రతి అంశం `Set` ఇన్‌స్టాన్స్ అయినప్పుడే `true` ను తిరిగి ఇస్తుంది.
- అర్రేలో అంశాలు లేకపోతే `false` ను తిరిగి ఇవ్వడం ద్వారా ఖాళీ అర్రేలపై తప్పుడు పాజిటివ్‌లను నివారిస్తుంది.
- ప్రతి అంశంపై `Set`-నిర్దిష్ట ఆపరేషన్లు చేయడానికి ముందు రన్‌టైమ్ గార్డ్‌గా ఉపయోగపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areSets(array)`

పారామీటర్లు:

- `array`: `Set` ఇన్‌స్టాన్స్‌ల కోసం తనిఖీ చేయాల్సిన అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  // a ሕያው ጊዜ ውስጥ የSet ኢንስታንስ ድርድር ነው
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); // ሐሰት
console.log(areSets(c)); // ሐሰት
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areSets(array)`
