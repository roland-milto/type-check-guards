# isHexadecimal

## వివరణ

`isHexadecimal` ఇచ్చిన విలువ తప్పనిసరి `0x`/`0X` ప్రిఫిక్స్‌తో ఉన్న హెక్సాడెసిమల్ స్ట్రింగ్ లిటరల్ కాదా అని తనిఖీ
చేస్తుంది.

### ఉపయోగ సందర్భం

`isHexadecimal` ను కాన్ఫిగరేషన్ విలువలు, API పేలోడ్ ఫీల్డ్‌లు, లేదా CLI ఆర్గ్యుమెంట్లు వంటి వాటిని హెక్సాడెసిమల్
స్ట్రింగ్ లిటరల్స్‌గా (ఉదా., IDs, masks, లేదా addresses) తప్పనిసరిగా ఇవ్వాల్సినప్పుడు మరియు చుట్టూ whitespace
ఉండకూడనప్పుడు ధృవీకరించడానికి ఉపయోగించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> పార్స్ చేయడానికి లేదా కన్వర్ట్ చేయడానికి ముందు, యూజర్ ఇన్‌పుట్ లేదా సీరియలైజ్డ్ డేటాను కఠినమైన హెక్సాడెసిమల్ లిటరల్
> స్ట్రింగ్‌గా ( `0x`/`0X` ప్రిఫిక్స్‌తో సహా) ధృవీకరించాల్సినప్పుడు `isHexadecimal` ను ఉపయోగించండి.

### ప్రయోజనాలు

- ఒక విలువ స్ట్రింగ్ అని మరియు కఠినమైన హెక్సాడెసిమల్ లిటరల్ ఫార్మాట్‌కు సరిపోతుందని ధృవీకరిస్తుంది (`0x`/`0X` ప్రిఫిక్స్
  తప్పనిసరి).
- ముందు లేదా చివర ఖాళీలు (whitespace) ఉన్న స్ట్రింగ్‌లను తిరస్కరిస్తుంది, తద్వారా ప్యాడ్ చేసిన ఇన్‌పుట్ అనుకోకుండా
  అంగీకరించబడకుండా సహాయపడుతుంది.
- ఐచ్ఛిక సైన్‌ను మద్దతు ఇస్తుంది మరియు ప్రిఫిక్స్, అంకెల విషయంలో case-insensitive గా ఉంటుంది; `true`/`false` ను అంచనా
  వేయగలిగేలా తిరిగి ఇస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isHexadecimal(value)`

పారామీటర్లు:

- `value`: తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // true
isHexadecimal("-0Xff"); // true
isHexadecimal("1A2B"); // false (ఉపసర్గ లేదు)
isHexadecimal(" 0x1A2B"); // false (ముందు ఖాళీ స్థలం)
isHexadecimal(0x1a2b); // false (స్ట్రింగ్ కాదు)
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isHexadecimal(value)`
