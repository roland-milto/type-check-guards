# areBuffers

## వివరణ

`areBuffers` అందించిన విలువ ఖాళీ కాని, నింపబడిన అర్రేనా మరియు అందులోని ప్రతి అంశం `Buffer`నా అని తనిఖీ చేస్తుంది; అలా
అయితే `true`, లేకపోతే `false` ని తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

ఇన్‌కమింగ్ చంక్ అర్రేలను (ఉదా., స్ట్రీమ్‌లు, ఫైల్ అప్‌లోడ్లు, లేదా నెట్‌వర్క్ ప్యాకెట్లు నుండి) ధృవీకరించి, అన్ని భాగాలు
`Buffer` ఇన్‌స్టాన్స్‌లేనని నిర్ధారించిన తర్వాతే వాటిని కలపడం, డీకోడ్ చేయడం, లేదా క్రిప్టోగ్రాఫిక్/బైనరీ-ప్రాసెసింగ్
ఫంక్షన్‌లకు పంపడం.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `unknown[]` ను `Buffer.concat` వంటి Buffer-స్పెసిఫిక్ APIలను పిలిచే ముందు ధృవీకరించడానికి `areBuffers` ను ఉపయోగించండి;
> ప్రతి అంశం `Buffer` అయినప్పుడే ఫంక్షన్ `true` ని తిరిగి ఇస్తుందని ఇది నిర్ధారిస్తుంది.

### ప్రయోజనాలు

- ఇన్‌పుట్‌లోని ప్రతి అంశం Node.js `Buffer` ఇన్‌స్టాన్స్ అని నిర్ధారిస్తుంది; మొత్తం అర్రే సరిపోతేనే `true` ని తిరిగి
  ఇస్తుంది.
- ఖాళీ కాని, నింపబడిన అర్రే అవసరం ద్వారా చెల్లని ఇన్‌పుట్‌లను ముందుగానే తిరస్కరిస్తుంది; ఖాళీ అర్రేలకు లేదా అర్రే
  కానివాటికి `false` ని తిరిగి ఇస్తుంది.
- బఫర్-మాత్రమే ఆపరేషన్లు (ఉదా., కలపడం, హ్యాషింగ్, బైనరీ ప్రోటోకాల్స్) చేయడానికి ముందు గార్డ్‌గా ఉపయోగపడుతుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areBuffers(array)`

పారామీటర్లు:

- `array`: బఫర్ ఇన్‌స్టాన్స్‌ల కోసం తనిఖీ చేయాల్సిన అర్రే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areBuffers } from "@type-check/guards";

const chunks: unknown[] = [Buffer.from("test"), Buffer.from("123")];

if (areBuffers(chunks)) {
  const combined = Buffer.concat(chunks);
  console.log(combined.toString("utf8"));
} else {
  throw new TypeError("Expected a non-empty array of Buffer instances");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areBuffers(array)`
