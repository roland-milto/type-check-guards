# isFalse

## వివరణ

`isFalse` ఇచ్చిన విలువ బూలియన్ లిటరల్ `false` కు కఠినంగా సమానమా అని తనిఖీ చేస్తుంది.

### ఉపయోగ సందర్భం

తెలియని డేటాను (ఉదా., JSON, క్వెరీ పరామ్స్, లేదా యూజర్ ఇన్‌పుట్ నుండి) ధృవీకరించండి; ఇందులో స్పష్టమైన బూలియన్ విలువ
`false` మాత్రమే చెల్లుబాటు అయ్యే ఫ్లాగ్‌గా పరిగణించాలి, మిగతావన్నీ తిరస్కరించాలి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> మీరు లిటరల్ `false` ను మాత్రమే అంగీకరించి మిగతా అన్ని ఫాల్సీ విలువలను తిరస్కరించాల్సినప్పుడు `isFalse` ను ఉపయోగించండి;
> ఇది `value === false` అయినప్పుడే `true` ను తిరిగి ఇస్తుంది.

### ప్రయోజనాలు

- ఏ విధమైన కోర్షన్ లేకుండా బూలియన్ లిటరల్ `false` కోసం కఠినమైన తనిఖీని అందిస్తుంది.
- `0`, `""`, `null`, మరియు `undefined` వంటి ఇతర ఫాల్సీ విలువల నుండి `false` ను వేరు చేయడంలో సహాయపడుతుంది.
- తెలియని ఇన్‌పుట్‌ను ధృవీకరిస్తున్నప్పుడు ఉద్దేశాన్ని స్పష్టంగా చూపించడం ద్వారా చదవడానికి సులభతను మెరుగుపరుస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isFalse(value)`

పారామీటర్లు:

- `value`: తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isFalse } from "@type-check/guards";

const input: unknown = false;

if (isFalse(input)) {
  // ఇక్కడ input ఖచ్చితంగా false
  console.log("Got false");
} else {
  console.log("Not false");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isFalse(value)`
