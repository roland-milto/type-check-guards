# areErrors

## వివరణ

ఒక అరే ఖాళీ కాకుండా ఉందో మరియు అందులో `Error` ఆబ్జెక్ట్‌లు మాత్రమే ఉన్నాయో తనిఖీ చేసి, `true` లేదా `false` ను తిరిగి
ఇస్తుంది.

### ఉపయోగ సందర్భం

రన్‌టైమ్‌లో అందించిన `unknown[]` (ఉదా., సమీకృత వైఫల్యాలు, ధృవీకరణ ఫలితాలు, లేదా డీసీరియలైజ్ చేసిన డేటా) ను ఇటరేట్
చేయడానికి, లాగ్ చేయడానికి, లేదా మళ్లీ త్రో చేయడానికి ముందు అది `Error` ఆబ్జెక్ట్‌ల ఖాళీ కాని జాబితా అని ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `areErrors` ప్రతి అంశం `Error` అయిన నిండిన అరేకు మాత్రమే `true` ను ఇస్తుంది; ఖాళీ అరేకు లేదా ఏదైనా అంశం `Error`
> కాకపోతే `false` ను ఇస్తుంది.

### ప్రయోజనాలు

- ప్రతి అంశం `Error` ఇన్‌స్టాన్స్ అని నిర్ధారిస్తుంది, సురక్షితమైన లోప నిర్వహణ మరియు లాగింగ్‌ను సాధ్యం చేస్తుంది.
- ఖాళీ అరేలను తిరస్కరిస్తుంది, అనుకోకుండా “లోపాలు లేవు” స్థితులను చెల్లుబాటు అయ్యే లోప జాబితాలుగా పరిగణించకుండా
  నిరోధిస్తుంది.
- `unknown[]` ఇన్‌పుట్‌లతో (ఉదా., APIల నుండి లేదా `catch` బ్లాక్‌ల నుండి) వ్యవహరించేటప్పుడు రన్‌టైమ్ గార్డ్‌గా బాగా
  పనిచేస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areErrors(array)`

పారామీటర్లు:

- `array`: `Error` ఆబ్జెక్ట్‌ల కోసం తనిఖీ చేయాల్సిన అరే.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areErrors } from "@type-check/guards";

const value: unknown = [new Error("error1"), new TypeError("error2")];

if (Array.isArray(value) && areErrors(value)) {
  // విలువ Error ఆబ్జెక్టుల ఖాళీ కాని అర్రే
  for (const err of value) {
    console.error(err.name, err.message);
  }
} else {
  console.log("Not a non-empty Error[]");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.areErrors(array)`
