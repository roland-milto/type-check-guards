# isNaN

## వివరణ

స్ట్రింగ్‌లను మార్చకుండా, అందించిన `value` `number` రకానికి చెందిన `NaN` కాదా అని నిర్ణయిస్తుంది.

### ఉపయోగ సందర్భం

నమ్మలేని లేదా సడలించిన టైప్ ఉన్న ఇన్‌పుట్‌ను (ఉదా. API పేలోడ్లు, ఫారమ్ విలువలు, పార్స్ చేసిన JSON) ధృవీకరించి, ప్రత్యేక
`NaN` విలువను గుర్తించి స్పష్టంగా నిర్వహించడానికి; అలాగే సంఖ్య కాని ఇన్‌పుట్‌లను `NaN` కాదని పరిగణించడానికి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> ఇన్‌పుట్ నిజంగా `number` అని నిర్ధారించుకుంటూనే (స్ట్రింగ్-నుంచి-సంఖ్య మార్పిడి లేకుండా) ప్రత్యేక సంఖ్యా విలువు `NaN`
> ను గుర్తించాల్సినప్పుడు `isNaN` ను ఉపయోగించండి.

### ప్రయోజనాలు

- సంఖ్యలు కాని విలువలను (ఉదా. స్ట్రింగ్‌లు) సంఖ్యలుగా బలవంతంగా మార్చకుండా ఒక విలువు `NaN` కాదా అని తనిఖీ చేస్తుంది.
- `number` రకం మరియు `NaN` రెండూ అయిన విలువలకే `true` ను తిరిగి ఇస్తుంది.
- `unknown` ఇన్‌పుట్‌లకు సురక్షితం మరియు అంతర్లీన మార్పిడుల వల్ల వచ్చే తప్పుడు పాజిటివ్‌లను నివారిస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isNaN(value)`

పారామీటర్లు:

- `value`: `number` రకానికి చెందిన `NaN` కాదా అని తనిఖీ చేయాల్సిన విలువు.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // true
console.log(isNaN(b)); // false
console.log(isNaN(c)); // false

if (isNaN(a)) {
  // a ቁጽሪ እዩ እና ብፍሉይ NaN እዩ
}
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isNaN(value)`
