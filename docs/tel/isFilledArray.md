# isFilledArray

## వివరణ

`value` కనీసం ఒక అంశం ఉన్న అర్రేనా అని తనిఖీ చేసి, `true` లేదా `false` ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

ఇటరేట్ చేయడానికి ముందు, మొదటి అంశాన్ని యాక్సెస్ చేయడానికి ముందు, లేదా కనీసం ఒక అంశం అవసరమైన లాజిక్‌ను వర్తింపజేయడానికి
ముందు వచ్చే డేటాను (ఉదా., API పేలోడ్లు, ఫారమ్ విలువలు, కాన్ఫిగరేషన్) ధృవీకరించడానికి `isFilledArray` ను ఉపయోగించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `isFilledArray` ఒక రన్‌టైమ్ గార్డ్; ఇది బూలియన్‌ను తిరిగి ఇస్తుంది. అర్రే ఖాళీ కాదని నిర్ధారించడాన్ని మించి అంశాల
> టైపులను ఇది మరింతగా న్యారో చేయదు.

### ప్రయోజనాలు

- `Array.isArray` మరియు length తనిఖీని ఉపయోగించి ఖాళీ కాని అర్రేను సులభంగా, వేగంగా తనిఖీ చేయవచ్చు.
- కోడ్ ఒక అర్రేలో కనీసం ఒక అంశం ఉందని ఊహించినప్పుడు రన్‌టైమ్ లోపాలను నివారించడంలో సహాయపడుతుంది.
- స్పష్టమైన బూలియన్ ఫలితం: ఖాళీ కాని అర్రేల కోసం `true`, లేకపోతే `false` ను తిరిగి ఇస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isFilledArray(value)`

పారామీటర్లు:

- `value`: ఇది ఖాళీ కాని అర్రేనా అని తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isFilledArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && isFilledArray(input)) {
  // ఇన్‌పుట్ రన్‌టైమ్‌లో ఖాళీ కాని అర్రే
  console.log(input[0]);
} else {
  console.log("Not a non-empty array");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isFilledArray(value)`
