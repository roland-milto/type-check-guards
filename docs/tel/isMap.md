# isMap

## వివరణ

ఇచ్చిన `value` ఒక `Map` కాదా అని తనిఖీ చేస్తుంది; అది అయితే `true`, లేకపోతే `false` ను తిరిగి ఇస్తుంది.

### ఉపయోగ సందర్భం

మీకు `unknown` విలువ (ఉదా., JSON పార్సింగ్, బాహ్య APIలు, లేదా యూజర్ ఇన్‌పుట్ నుండి) వచ్చినప్పుడు, `Map` ఆపరేషన్లు
చేయడానికి ముందు అది `Map` అని నిర్ధారించుకోవడానికి `isMap` ను ఉపయోగించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> `isMap` అనేది రన్‌టైమ్ గార్డ్; విలువ `Map` అయితే `true`, లేకపోతే `false` ను తిరిగి ఇస్తుంది. `Map` APIలను పిలిచే ముందు
`unknown` ను న్యారో చేయడానికి దీన్ని ఉపయోగించండి.

### ప్రయోజనాలు

- `Map` కాదా అని ఒక విలువపై త్వరిత రన్‌టైమ్ తనిఖీని అందిస్తుంది.
- `get`, `set`, `has` వంటి `Map` పద్ధతులు అవసరమైన కోడ్ మార్గాలను గార్డ్ చేయడం ద్వారా టైప్ లోపాలను నివారించడంలో
  సహాయపడుతుంది.
- `unknown` ఇన్‌పుట్‌లను నిర్వహించేటప్పుడు తేలికపాటి ధృవీకరణ దశగా ఇది బాగా పనిచేస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isMap(value)`

పారామీటర్లు:

- `value`: తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isMap } from "@type-check/guards";

const input: unknown = new Map<string, number>([["a", 1]]);

if (isMap(input)) {
  input.set("b", 2);
  const a = input.get("a");
  console.log(a);
} else {
  console.log("Not a Map");
}

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isMap(value)`
