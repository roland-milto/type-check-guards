# isInteger

## వివరణ

ఇచ్చిన `value` ఒక సురక్షిత పూర్ణసంఖ్యా సంఖ్యా కాదో నిర్ధారిస్తుంది.

### ఉపయోగ సందర్భం

నమ్మలేని ఇన్‌పుట్‌ను (ఉదా., query params, JSON payloads, environment variables) అరే ఇండెక్సులు, పేజినేషన్, కౌంటర్లు,
లేదా డేటాబేస్ IDs కోసం పూర్ణసంఖ్యగా ఉపయోగించే ముందు ధృవీకరించండి.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> తెలియని ఇన్‌పుట్‌ను సంఖ్యా పూర్ణసంఖ్యగా పరిగణించే ముందు దాన్ని ధృవీకరించడానికి `isInteger` ను ఉపయోగించండి; ఇది
`typeof value === "number"` మరియు `Number.isSafeInteger(value)` ఉన్న విలువలకే `true` ను తిరిగి ఇస్తుంది.

### ప్రయోజనాలు

- రకం మరియు సంఖ్యా భద్రత రెండింటినీ తనిఖీ చేస్తుంది: ఇన్‌పుట్ ఒక సంఖ్యగా మరియు సురక్షిత పూర్ణసంఖ్యగా ఉన్నప్పుడు మాత్రమే
  `true` ను తిరిగి ఇస్తుంది.
- సంఖ్యా బలవంతపు మార్పిడి (numeric coercion) వల్ల వచ్చే సాధారణ పొరపాట్లను నివారిస్తుంది: "5" వంటి స్ట్రింగ్‌లు సరైన
  విధంగా `false` ను తిరిగి ఇస్తాయి.
- పూర్ణసంఖ్యలు కానివాటిని మరియు సురక్షితం కాని పూర్ణసంఖ్యలను తిరస్కరిస్తుంది, అందువల్ల ఇది IDs, కౌంటర్లు, మరియు అరే
  ఇండెక్సింగ్‌కు అనుకూలంగా ఉంటుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `isInteger(value)`

పారామీటర్లు:

- `value`: పూర్ణసంఖ్య స్థితి కోసం తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      // నిజం
const b = isInteger(-100);   // నిజం
const c = isInteger("5");    // అబద్ధం
const d = isInteger(5.5);    // అబద్ధం
const e = isInteger(null);   // అబద్ధం

```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

```ts
import "@type-check/guards/register-global-object.mjs";
```

తర్వాత క్రింది మెథడ్ గ్లోబల్‌గా అందుబాటులో ఉంటుంది:

- `Type.isInteger(value)`
