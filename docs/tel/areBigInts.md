# areBigInts

## వివరణ

`areBigInts` ఒక విలువ `bigint` విలువలనే కలిగిన ఖాళీ కాని అర్రేనా అని నిర్ణయిస్తుంది.

### ఉపయోగ సందర్భం

తెలియని ఇన్‌పుట్‌ను (ఉదా., పార్స్ చేసిన JSON-లాంటి డేటా, API పేలోడ్లు, లేదా `unknown` గా టైప్ చేసిన ఫంక్షన్ పరామితులు)
ప్రాసెస్ చేయడానికి ముందు అది `bigint` విలువలతో కూడిన ఖాళీ కాని అర్రే అని నిర్ధారించడానికి ధృవీకరించండి; అన్ని అంశాలు
`bigint` అయినప్పుడే `true`, లేకపోతే `false` ను తిరిగి ఇస్తుంది.

> **TypeScript వినియోగదారుల కోసం గమనిక:**
>
> తెలియని ఇన్‌పుట్‌పై `bigint`-మాత్రమే ఆపరేషన్లు (ఉదా., అంకగణితం, పోలికలు) చేయడానికి ముందు రన్‌టైమ్ గార్డ్‌గా
`areBigInts` ను ఉపయోగించండి.

### ప్రయోజనాలు

- ప్రతి అంశం `bigint` అని నిర్ధారిస్తుంది; మొత్తం అర్రే సరిపోతేనే `true` ను తిరిగి ఇస్తుంది.
- `isFilledArray` ద్వారా రూపకల్పన ప్రకారం అర్రే కానివాటిని మరియు ఖాళీ అర్రేలను తిరస్కరిస్తుంది; చెల్లని ఇన్‌పుట్‌లు
  పొరపాటున అంగీకరించబడకుండా నిరోధిస్తుంది.
- త్వరిత విఫలం: `bigint` కాని అంశం కనబడిన వెంటనే `false` ను తిరిగి ఇస్తుంది.

## వినియోగం

### సింటాక్స్

ఫంక్షన్:

- `areBigInts(array)`

పారామీటర్లు:

- `array`: తనిఖీ చేయాల్సిన విలువ.

### లోకల్ ఫంక్షన్ ఇంపోర్ట్

```ts
import { areBigInts } from "@type-check/guards";

const a: unknown = [10n, 20n];
const b: unknown = [10n, 20];
const c: unknown = [];

console.log(areBigInts(a)); // నిజం
console.log(areBigInts(b)); // అబద్ధం
console.log(areBigInts(c)); // అబద్ధం
```

### గ్లోబల్ ఆబ్జెక్ట్ ఇంపోర్ట్

ఫంక్షన్లను గ్లోబల్ ఆబ్జెక్ట్ మెథడ్‌లుగా ఇంపోర్ట్ చేయడానికి ఉపయోగించండి:

- `Type.areBigInts(array)`
