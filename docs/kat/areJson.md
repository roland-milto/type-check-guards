# areJson

## აღწერა

ამოწმებს, არის თუ არა მასივის ყველა ელემენტი JSON სტრიქონი და აბრუნებს `true` მხოლოდ იმ შემთხვევაში, თუ მასივი
შევსებულია და თითოეული ელემენტი ვალიდური JSON-ია; სხვა შემთხვევაში აბრუნებს `false`.

### გამოყენების შემთხვევა

შეამოწმეთ შემომავალი მონაცემები (მაგ., query params-იდან, environment variables-იდან ან გარე API-ებიდან), როცა ელით
JSON-ით კოდირებული სტრიქონების მასივს და გსურთ უარყოთ ცარიელი მასივები ან ნებისმიერი არ-JSON ჩანაწერი.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `areJson`, როცა გჭირდებათ დაადასტუროთ, რომ `unknown[]` შეიცავს მხოლოდ JSON სტრიქონებს მათ გაპარსვამდე (
> მაგ., `JSON.parse`-ით).

### უპირატესობები

- აბრუნებს `true` მხოლოდ მაშინ, როცა ყველა ელემენტი არის ვალიდური JSON სტრიქონი; სხვა შემთხვევაში აბრუნებს `false`.
- სწრაფად წყვეტს: ამოწმებას აჩერებს მაშინვე, როგორც კი არ-JSON ელემენტს იპოვის.
- დიზაინით უარყოფს ცარიელ მასივებს და არაშევსებული შეყვანისთვის აბრუნებს `false`.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areJson(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს JSON სტრიქონის ელემენტებზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // ჭეშმარიტი
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // მცდარი
const empty = areJson([]); // მცდარი

```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:

- `Type.areJson(array)`
