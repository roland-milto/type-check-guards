# isOctal

## აღწერა

ადგენს, არის თუ არა მნიშვნელობა ვალიდური ოქტალური ლიტერალის სტრიქონი (მაგ. `0o755`).

### გამოყენების შემთხვევა

დაავალიდირეთ მომხმარებლის შეყვანა ან კონფიგურაციის მნიშვნელობები, რომლებიც უნდა იყოს წარმოდგენილი როგორც ოქტალური
ლიტერალის სტრიქონი (მაგალითად, ფაილის ნებართვების რეჟიმები, როგორიცაა `0o644`), მათ დამუშავებამდე ან გარდაქმნამდე.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `isOctal` არის ტიპის დამცველი (`value is string`). `true` შედეგის შემდეგ TypeScript ამცირებს შემოწმებულ ცვლადს
`string`-მდე.

### უპირატესობები

- უზრუნველყოფს მკაცრ ტიპის დამცველს: აბრუნებს `true`-ს მხოლოდ მაშინ, როცა შეყვანა არის სტრიქონი, რომელიც ემთხვევა
  ოქტალური ლიტერალის ფორმატს.
- უარყოფს ცარიელ სტრიქონებს და სტრიქონებს წამყვანი/ბოლო გამოტოვებებით (ASCII კონტროლი/სივრცე), რაც ამცირებს შემთხვევით
  დამთხვევებს.
- მხარს უჭერს არჩევით ნიშანს და არ არის რეგისტრზე მგრძნობიარე `0o`/`0O` პრეფიქსისთვის.
- არასტრიქონულ შეყვანებზე ლმობიერია — გამონაკლისის აგდების ნაცვლად აბრუნებს `false`-ს.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isOctal(value)`

პარამეტრები:

- `value`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); // ჭეშმარიტი
console.log(isOctal(b)); // ჭეშმარიტი
console.log(isOctal(c)); // მცდარი
console.log(isOctal(d)); // მცდარი

if (isOctal(a)) {
  // აქ a არის სტრინგი
  const normalized = a.toLowerCase();
  console.log(normalized);
}

```
