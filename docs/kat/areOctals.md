# areOctals

## აღწერა

`areOctals` განსაზღვრავს, არის თუ არა მოწოდებული მნიშვნელობა ვალიდური ოქტალური სტრიქონების არაცარიელი მასივი.

### გამოყენების შემთხვევა

გამოიყენეთ `areOctals` მომხმარებლის შეყვანის, კონფიგურაციის მნიშვნელობების ან API payload-ების ვალიდაციისას, რომლებიც
უნდა შეიცავდეს ოქტალურ ლიტერალებს (მაგ., ფაილის ნებართვების რეჟიმები, როგორიცაა `0o755`), და გსურთ უარყოთ ცარიელი
მასივები ან ნებისმიერი არავალიდური ჩანაწერი `false`-ის დაბრუნებით.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `areOctals`, რათა დარწმუნდეთ, რომ გაქვთ არაცარიელი `unknown[]`, სადაც თითოეული ჩანაწერი არის ვალიდური
> ოქტალური სტრიქონი, გარდაქმნამდე (მაგ., `Number(...)`-ით ან საკუთარი პარსინგით).

### უპირატესობები

- ამოწმებს, რომ მნიშვნელობა არის არაცარიელი მასივი, სადაც ყოველი ელემენტი არის ოქტალური სტრიქონი, და აბრუნებს `true`
  მხოლოდ მაშინ, როცა ყველა ელემენტი გადის შემოწმებას.
- სწრაფად წყვეტს: აბრუნებს `false` როგორც კი აღმოჩნდება არაოქტალური ელემენტი.
- სასარგებლოა როგორც დამცავი შემოწმება პარსინგამდე ან ოქტალური სტრიქონების გარდაქმნამდე, რათა თავიდან აიცილოთ შესრულების
  დროის შეცდომები და არათანმიმდევრული შეყვანის დამუშავება.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areOctals(array)`

პარამეტრები:

- `array`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value არის არაცარიელი მასივი ოქტალური სტრიქონების
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```
