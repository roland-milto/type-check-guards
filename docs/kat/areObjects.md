# areObjects

## აღწერა

`areObjects` ამოწმებს, შეიცავს თუ არა მოწოდებული შევსებული მასივი მხოლოდ ობიექტებს.

### გამოყენების შემთხვევა

გამოიყენეთ `areObjects`, როცა იღებთ უცნობ მასივს (მაგ., JSON-ის პარსინგიდან ან გარე API-ებიდან) და გჭირდებათ დარწმუნდეთ,
რომ ის არ არის ცარიელი და რომ ყოველი ელემენტი არის ობიექტი, სანამ იტერაციას დაიწყებთ და ობიექტის თვისებებს მიმართავთ.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `areObjects` `unknown[]`-ის ვალიდაციისთვის, სანამ ელემენტებს ობიექტებად მოექცევით; ცარიელი მასივებისთვის ის
> აბრუნებს `false`-ს.

### უპირატესობები

- აბრუნებს `true` მხოლოდ მაშინ, როცა შეყვანა არის შევსებული მასივი და ყოველი ელემენტი არის ობიექტი.
- ადრეულად ჩერდება და აბრუნებს `false` როგორც კი აღმოჩნდება არაობიექტური ელემენტი.
- ეხმარება უცნობი შეყვანის ვალიდაციას ობიექტზე სპეციფიკური ოპერაციების შესრულებამდე.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areObjects(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს ობიექტური ელემენტების არსებობაზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areObjects } from "@type-check/guards";

const value: unknown = [{}, { a: 1 }, new Date()];

if (Array.isArray(value) && areObjects(value)) {
  // value objektoen beteteko array ya
  console.log("All items are objects:", value.length);
} else {
  console.log("Not a filled array of objects");
}

```
