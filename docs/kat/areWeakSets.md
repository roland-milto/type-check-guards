# areWeakSets

## აღწერა

ამოწმებს, არის თუ არა შეყვანა არაცარიელი მასივი, სადაც ყოველი ელემენტი არის `WeakSet`, და `true`-ს აბრუნებს მხოლოდ ამ
შემთხვევაში.

### გამოყენების შემთხვევა

გაშვების დროს მიღებული შეყვანის (მაგ., API-ებიდან, კონფიგურაციიდან ან მომხმარებლის მიერ მოწოდებული მონაცემებიდან)
ვალიდაცია, რათა დარწმუნდეთ, რომ გაქვთ `WeakSet` ინსტანსების არაცარიელი სია, სანამ გააგრძელებთ ლოგიკას, რომელიც `WeakSet`
-ის ქცევაზეა დამოკიდებული.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `areWeakSets` უცნობი შეყვანის ვალიდაციისთვის, სანამ მას `WeakSet[]`-ად მოექცევით. ის აბრუნებს `false`-ს
> ცარიელი მასივებისა და არამასივებისთვის.

### უპირატესობები

- უზრუნველყოფს, რომ შეყვანის მასივში ყოველი ელემენტი იყოს `WeakSet`.
- ცარიელი მასივებისთვის აბრუნებს `false`-ს, რაც თავიდან აცილებს მონაცემების არქონისას შემთხვევით „ყველა ვალიდურია“
  შედეგს.
- უსაფრთხოდ მარცხდება: აბრუნებს `false`-ს, როცა შეყვანა არ არის შევსებული მასივი (მათ შორის `null`).
- სასარგებლოა როგორც დამცავი შემოწმება იმ ოპერაციებამდე, რომლებიც `WeakSet` ინსტანსებს მოითხოვს.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areWeakSets(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს `WeakSet` ობიექტებზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areWeakSets } from "@type-check/guards";

const a: unknown = [new WeakSet<object>(), new WeakSet<object>()];
const b: unknown = [new WeakSet<object>(), {}];
const c: unknown = [];

if (areWeakSets(a)) {
  // a არის WeakSet-ის ინსტანციების არაცარიელი მასივი
}

console.log(areWeakSets(a)); // ჭეშმარიტი
console.log(areWeakSets(b)); // მცდარი
console.log(areWeakSets(c)); // მცდარი
console.log(areWeakSets(null as unknown)); // მცდარი

```
