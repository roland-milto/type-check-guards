# areHexadecimals

## აღწერა

ამოწმებს, არის თუ არა მასივში ყველა ელემენტი ჰექსადეციმალური სტრიქონი და `true`-ს აბრუნებს მხოლოდ არაცარიელი
მასივებისთვის, სადაც ყოველი ელემენტი ვალიდურია.

### გამოყენების შემთხვევა

`areHexadecimals` გამოიყენეთ მომხმარებლის შეყვანის ან გარე მონაცემების (მაგ., ID-ები, checksum-ები, ფერის კოდები
წამყვანი '#' გარეშე) ვალიდაციისთვის ჰექსადეციმალური პარსინგის ან შემდგომი დამუშავების შესრულებამდე.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `areHexadecimals` გამოიყენეთ უცნობი შეყვანის ვალიდაციისთვის მნიშვნელობების პარსინგამდე ან კონვერტაციამდე (მაგალითად,
`parseInt(value, 16)`-მდე ან BigInt კონვერტაციებამდე).

### უპირატესობები

- ყოველი ელემენტის ჰექსადეციმალურ სტრიქონად ვალიდაციას ახდენს და `true`-ს აბრუნებს მხოლოდ მაშინ, როცა ყველა ელემენტი
  ემთხვევა.
- დიზაინით უარყოფს ცარიელ მასივებს და შეყვანის მონაცემების არქონისას `false`-ს აბრუნებს.
- უზრუნველყოფს მარტივ ბულურ შედეგს (`true`/`false`), რომელიც შესაფერისია guard-ებისთვის და early-return ვალიდაციისთვის.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areHexadecimals(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს ჰექსადეციმალური სტრიქონის ელემენტებზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areHexadecimals } from "@type-check/guards";

const a = areHexadecimals(["1A", "3F", "B2"]);
const b = areHexadecimals(["1A", "3G", "B2"]);
const c = areHexadecimals([10 as unknown as string, "3F", "B2"] as unknown[]);
const d = areHexadecimals([]);

console.log(a, b, c, d);
```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:

- `Type.areHexadecimals(array)`
