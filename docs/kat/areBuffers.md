# areBuffers

## აღწერა

`areBuffers` ამოწმებს, არის თუ არა მიწოდებული მნიშვნელობა არაცარიელი, შევსებული მასივი, სადაც ყოველი ელემენტი არის
`Buffer`, და თუ ასეა აბრუნებს `true`-ს, წინააღმდეგ შემთხვევაში — `false`-ს.

### გამოყენების შემთხვევა

შეამოწმეთ შემომავალი ჩანკების მასივები (მაგ., სტრიმებიდან, ფაილების ატვირთვებიდან ან ქსელური პაკეტებიდან), რათა
დარწმუნდეთ, რომ ყველა ნაწილი არის `Buffer` ინსტანცია, სანამ მათ გააერთიანებთ, გაშიფრავთ ან გადასცემთ კრიპტოგრაფიულ ან
ბინარული დამუშავების ფუნქციებს.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `areBuffers` `unknown[]`-ის ვალიდაციისთვის `Buffer`-ზე სპეციფიკური API-ების (როგორიცაა `Buffer.concat`)
> გამოძახებამდე, რათა ფუნქციამ `true` დააბრუნოს მხოლოდ მაშინ, როცა ყოველი ელემენტი არის `Buffer`.

### უპირატესობები

- უზრუნველყოფს, რომ შეყვანაში არსებული ყოველი ელემენტი იყოს Node.js-ის `Buffer` ინსტანცია და აბრუნებს `true`-ს მხოლოდ
  მაშინ, როცა მთელი მასივი ემთხვევა ამ პირობას.
- ადრეულ ეტაპზე უარყოფს არასწორ შეყვანას არაცარიელი, შევსებული მასივის მოთხოვნით; ცარიელი მასივებისთვის ან
  არამასივებისთვის აბრუნებს `false`-ს.
- სასარგებლოა როგორც დამცავი შემოწმება ბუფერზე-მხოლოდ ოპერაციების შესრულებამდე (მაგ., გაერთიანება, ჰეშირება, ბინარული
  პროტოკოლები).

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areBuffers(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს ბუფერის ინსტანციებზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areBuffers } from "@type-check/guards";

const chunks: unknown[] = [Buffer.from("test"), Buffer.from("123")];

if (areBuffers(chunks)) {
  const combined = Buffer.concat(chunks);
  console.log(combined.toString("utf8"));
} else {
  throw new TypeError("Expected a non-empty array of Buffer instances");
}

```
