# areSets

## აღწერა

ამოწმებს, შეიცავს თუ არა მოცემული არაცარიელი მასივი მხოლოდ `Set`-ის ინსტანციებს; თუ შეიცავს, აბრუნებს `true`-ს,
წინააღმდეგ შემთხვევაში — `false`-ს.

### გამოყენების შემთხვევა

დაავალიდირეთ, რომ მნიშვნელობა (მაგ., მომხმარებლის შეყვანიდან, JSON-ის პარსინგიდან ან გარე API-ებიდან) არის `Set`
ობიექტების არაცარიელი მასივი, სანამ თითოეულ set-ს დაამუშავებთ.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `areSets` გამოიყენეთ უცნობი შეყვანის ვალიდაციისთვის, სანამ იტერაციას დაიწყებთ და თითოეულ ელემენტზე `Set` API-ებს (
> მაგ., `.size`, `.has`, `.add`) გამოიძახებთ.

### უპირატესობები

- `true`-ს აბრუნებს მხოლოდ მაშინ, როცა შეყვანა არის არაცარიელი მასივი და ყოველი ელემენტი არის `Set`-ის ინსტანცია.
- ცარიელი მასივებისთვის ცრუ დადებით შედეგებს თავიდან აცილებს: თუ მასივს ელემენტები არ აქვს, აბრუნებს `false`-ს.
- გამოსადეგია როგორც runtime-გარდი, სანამ თითოეულ ელემენტზე `Set`-ზე სპეციფიკურ ოპერაციებს შეასრულებთ.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areSets(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს `Set`-ის ინსტანციებზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  // a runtime-ya Set instance-ya array
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); // false
console.log(areSets(c)); // false

```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts

```
