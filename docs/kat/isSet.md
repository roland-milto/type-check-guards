# isSet

## აღწერა

ადგენს, არის თუ არა მოცემული მნიშვნელობა `Set`.

### გამოყენების შემთხვევა

გადაამოწმეთ გარე წყაროებიდან მიღებული შეყვანები (მაგ., JSON-ის პარსინგი, მომხმარებლის შეყვანა ან მესამე მხარის API-ები),
რათა დარწმუნდეთ, რომ მნიშვნელობა `Set`-ია, სანამ `Set` ოპერაციებს შეასრულებთ.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isSet`, რათა დაავიწროვოთ `unknown` მნიშვნელობები, სანამ `Set`-ზე სპეციფიკურ API-ებს გამოიძახებთ, როგორიცაა
`.add`, `.has` ან `.size`.

### უპირატესობები

- მნიშვნელობის `Set`-ად ყოფნის დასადასტურებლად უზრუნველყოფს მარტივ შესრულების დროის შემოწმებას.
- ეხმარება ტიპის შეცდომების თავიდან აცილებაში, რადგან საშუალებას იძლევა ადრე განშტოება, როცა მნიშვნელობა `Set` არ არის.
- მუშაობს ნებისმიერი `Set`-ის შიგთავსთან (ცარიელთანაც და შევსებულთანაც) და თანმიმდევრულად აბრუნებს `true`/`false`.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isSet(value)`

პარამეტრები:

- `value`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // a runtime-ya Set ya
  console.log(a.size);
}

console.log(isSet(b)); // false
```
