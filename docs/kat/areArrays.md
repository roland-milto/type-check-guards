# areArrays

## აღწერა

`areArrays` განსაზღვრავს, არის თუ არა მნიშვნელობა შევსებული ორზომიანი მასივი, რომლის ყველა ელემენტიც მასივია.

### გამოყენების შემთხვევა

გამოიყენეთ `areArrays` ტაბულარული ან მატრიცის მსგავსი შეყვანების (მაგ., CSV რიგები, grid მონაცემები ან დაჯგუფებული
სიები) ვალიდაციისთვის, სანამ რიგ/სვეტის ოპერაციებს შეასრულებთ; ის აბრუნებს `false`-ს, თუ შეყვანა არ არის მასივი,
ცარიელია, ან შეიცავს რომელიმე არამასივ ელემენტს.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `areArrays`, როცა გჭირდებათ დარწმუნდეთ, რომ მნიშვნელობა არის არაცარიელი 2D მასივი და რომ თითოეული რიგი
> მასივია, სანამ ჩაშენებულ მასივებში იტერაციას ან ინდექსირებას დაიწყებთ.

### უპირატესობები

- ამოწმებს, რომ შეყვანა არის არაცარიელი ორზომიანი მასივი, სადაც ყოველი ელემენტი მასივია.
- აბრუნებს მარტივ ბულურ შედეგს (`true`/`false`), რომელიც გამოდგება guard-ებისთვის და ადრეული დასრულებისთვის.
- ეხმარება runtime შეცდომების თავიდან აცილებაში, როცა შემდგომი კოდი ვარაუდობს ჩაშენებული მასივების ოპერაციებს (მაგ.,
  რიგების map-ით დამუშავება).

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areArrays(array)`

პარამეტრები:

- `array`: შესამოწმებელი შეყვანა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value არის 2D მასივი, რომლის ელემენტებიც მასივებია
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```
