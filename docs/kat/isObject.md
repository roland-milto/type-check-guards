# isObject

## აღწერა

ადგენს, არის თუ არა მოცემული `value` `object` (`null`-ის გამოკლებით).

### გამოყენების შემთხვევა

გამოიყენეთ `isObject` უცნობი შეყვანების ვალიდაციისთვის (მაგ., დამუშავებული JSON, API პასუხები, event payload-ები)
თვისებებზე წვდომამდე, რათა დარწმუნდეთ, რომ მნიშვნელობა ობიექტია და არა `null`.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `isObject` არის შესრულების დროის guard, რომელიც აბრუნებს boolean-ს; ის არ ავიწროებს ტიპს კონკრეტულ ობიექტის ფორმამდე.
> შეუთავსეთ დამატებით შემოწმებებს (მაგ., თვისების არსებობა), როცა უფრო ძლიერი ტიპიზაცია გჭირდებათ.

### უპირატესობები

- აბრუნებს `true`-ს მხოლოდ არ-`null` მნიშვნელობებისთვის, რომელთა `typeof` არის `"object"`.
- იცავს JavaScript-ის გავრცელებული შეცდომისგან, როცა `null` სხვაგვარად ობიექტად იქნებოდა მიჩნეული.
- მუშაობს როგორც ჩვეულებრივ ობიექტებზე, ისე ჩაშენებული ობიექტების ინსტანციებზე (მაგ., `Date`, `RegExp`).
- მარტივი, სწრაფი შესრულების დროის შემოწმება, რომელიც გამოდგება თავდაცვითი პროგრამირებისა და შეყვანის ვალიდაციისთვის.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isObject(value)`

პარამეტრები:

- `value`: მნიშვნელობა, რომელიც უნდა შემოწმდეს, არის თუ არა `object`.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isObject } from "@type-check/guards";

const input: unknown = { a: 1 };

if (isObject(input)) {
  // input რეალურ დროში არის არანულოვანი ობიექტი
  console.log("Object detected");
} else {
  console.log("Not an object");
}

```
