# isInteger

## აღწერა

განსაზღვრავს, არის თუ არა მოცემული `value` უსაფრთხო მთელი რიცხვი.

### გამოყენების შემთხვევა

დაავალიდირეთ არასანდო შეყვანა (მაგ., query params, JSON payloads, environment variables) სანამ მას გამოიყენებთ მთელ
რიცხვად მასივის ინდექსებისთვის, გვერდებად დაყოფისთვის (pagination), მთვლელებისთვის ან მონაცემთა ბაზის ID-ებისთვის.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isInteger` უცნობი შეყვანის ვალიდაციისთვის, სანამ მას რიცხვით მთელ რიცხვად მოექცევით; ის აბრუნებს `true`-ს
> მხოლოდ იმ მნიშვნელობებისთვის, სადაც `typeof value === "number"` და `Number.isSafeInteger(value)`.

### უპირატესობები

- ამოწმებს როგორც ტიპის, ისე რიცხვით უსაფრთხოებას: აბრუნებს `true`-ს მხოლოდ მაშინ, როცა შეყვანილი მნიშვნელობა არის
  რიცხვი და უსაფრთხო მთელი რიცხვი.
- იცავს რიცხვითი იძულებითი გარდაქმნის (coercion) გავრცელებული შეცდომებისგან: სტრიქონები, როგორიცაა "5", სწორად აბრუნებენ
  `false`-ს.
- უარყოფს არამთელ რიცხვებს და არაუსაფრთხო მთელ რიცხვებს, რაც მას შესაფერისს ხდის ID-ებისთვის, მთვლელებისთვის და მასივის
  ინდექსაციისთვის.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isInteger(value)`

პარამეტრები:

- `value`: მნიშვნელობა, რომლის მთელრიცხვოვნებაც უნდა შემოწმდეს.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      // true
const b = isInteger(-100);   // true
const c = isInteger("5");    // false
const d = isInteger(5.5);    // false
const e = isInteger(null);   // false

```

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:
