# isMap

## აღწერა

ამოწმებს, არის თუ არა მოცემული `value` ტიპის `Map`, აბრუნებს `true`-ს თუ არის და `false`-ს სხვა შემთხვევაში.

### გამოყენების შემთხვევა

გამოიყენეთ `isMap`, როცა იღებთ `unknown` მნიშვნელობას (მაგ., JSON-ის პარსინგიდან, გარე API-ებიდან ან მომხმარებლის
შეყვანიდან) და გჭირდებათ დარწმუნება, რომ ის არის `Map`, სანამ `Map` ოპერაციებს შეასრულებთ.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `isMap` არის შესრულების დროის guard, რომელიც აბრუნებს `true`-ს, როცა მნიშვნელობა არის `Map`, და `false`-ს სხვა
> შემთხვევაში; გამოიყენეთ იგი `unknown`-ის დასავიწროებლად `Map` API-ების გამოძახებამდე.

### უპირატესობები

- უზრუნველყოფს სწრაფ შესრულების დროის შემოწმებას, არის თუ არა მნიშვნელობა `Map`.
- ეხმარება ტიპის შეცდომების თავიდან აცილებაში, კოდის იმ ბილიკების დაცვით, რომლებიც საჭიროებს `Map` მეთოდებს, როგორიცაა
  `get`, `set` და `has`.
- კარგად მუშაობს როგორც მსუბუქი ვალიდაციის ნაბიჯი `unknown` შეყვანების დამუშავებისას.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isMap(value)`

პარამეტრები:

- `value`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isMap } from "@type-check/guards";

const input: unknown = new Map<string, number>([["a", 1]]);

if (isMap(input)) {
  input.set("b", 2);
  const a = input.get("a");
  console.log(a);
} else {
  console.log("Not a Map");
}

```
