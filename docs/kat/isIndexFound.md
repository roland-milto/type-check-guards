# isIndexFound

## აღწერა

`isIndexFound` განსაზღვრავს, არის თუ არა მოცემული მნიშვნელობა არაუარყოფითი მთელი რიცხვი, რაც მიუთითებს, რომ ინდექსი
ნაპოვნია.

### გამოყენების შემთხვევა

დაადასტურეთ, რომ ძიების შედეგი წარმოადგენს გამოსაყენებელ ინდექსს (მთელი რიცხვი `>= 0`) მასივში ან სტრიქონში
ინდექსირებამდე, რათა თავიდან აიცილოთ `-1`-ის ან არარიცხვითი მნიშვნელობების შემთხვევითი გამოყენება.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `isIndexFound` გამოიყენეთ ისეთი ოპერაციების შემდეგ, როგორიცაა `indexOf`, `findIndex`, ან მორგებული ძიებები, სადაც
`-1` (ან სხვა არავალიდური მნიშვნელობები) შეიძლება ნიშნავდეს „ვერ მოიძებნა“-ს. როცა ის `true`-ს აბრუნებს, მნიშვნელობა
> არის რიცხვი და უსაფრთხოა მასივის/სტრიქონის ინდექსად გამოსაყენებლად.

### უპირატესობები

- არასირთულე ტიპის დამცავი, რომელიც ამოწმებს, მოიძებნა თუ არა ინდექსი არაუარყოფითი მთელი რიცხვის შემოწმებით.
- `true`-ს აბრუნებს მხოლოდ ვალიდური ინდექსის მსგავს მნიშვნელობებზე (მთელი რიცხვები `>= 0`), უარყოფს უარყოფითებს,
  არამთელებს და არარიცხვებს.
- ეხმარება „ერთით აცდენის“ და სენტინელ-მნიშვნელობის შეცდომების თავიდან აცილებაში, როცა მუშაობთ API-ებთან, რომლებიც „ვერ
  მოიძებნა“-სთვის `-1`-ს აბრუნებენ.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isIndexFound(value)`

პარამეტრები:

- `value`: მნიშვნელობა, რომლის შემოწმებაც უნდა მოხდეს, არის თუ არა არაუარყოფითი მთელი რიცხვი.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // idx aq aris ricxvi da aris >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// tipuri gamoyeneba indexOf-it
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```
