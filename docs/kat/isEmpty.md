# isEmpty

## აღწერა

ადგენს, არის თუ არა მოცემული მნიშვნელობა ცარიელი; აბრუნებს `true`-ს `null`-ისთვის, `undefined`-ისთვის, ცარიელი/მხოლოდ
whitespace სტრიქონებისთვის, ცარიელი მასივებისთვის, ცარიელი `Map`/`Set`-ისთვის ან ობიექტებისთვის, რომლებსაც საკუთარი
enumerable თვისებები არ აქვთ.

### გამოყენების შემთხვევა

გამოიყენეთ `isEmpty` შეყვანების ვალიდაციისთვის და დაკარგული/ცარიელი მნიშვნელობების აღმოსაჩენად მრავალ მონაცემთა ტიპში (
მაგ., ფორმის ველები, API payload-ები, კონფიგურაციის ობიექტები), სადაც `null`, `undefined`, whitespace სტრიქონები,
ცარიელი კოლექციები და თვისებების არმქონე ობიექტები ცარიელად უნდა ჩაითვალოს.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `isEmpty` არის boolean-ის დამბრუნებელი უტილიტა (და არა TypeScript-ის ტიპის პრედიკატი), ამიტომ თავისთავად ტიპებს არ
> ავიწროებს; გამოიყენეთ ვალიდაციისთვის/განშტოებისთვის და არა compile-time narrowing-ისთვის.

### უპირატესობები

- `null` და `undefined` ცარიელობის შემოწმებისას `true`-ად მიიჩნევს.
- მხოლოდ გამოტოვებებისგან (whitespace) შემდგარ სტრიქონებს ცარიელად მიიჩნევს, რადგან სიგრძის შემოწმებამდე trim-ს აკეთებს.
- მხარს უჭერს გავრცელებულ კონტეინერის ტიპებს (მასივები, `Map`, `Set`) და ჩვეულებრივ ობიექტებს, რომლებსაც საკუთარი
  enumerable თვისებები არ აქვთ.
- მემკვიდრეობით მიღებული თვისებების დათვლას თავიდან იცილებს `hasOwnProperty` შემოწმებების გამოყენებით.
- აბრუნებს მარტივ boolean შედეგს (`true`/`false`), რომელიც გამოდგება guard-ებისა და ვალიდაციისთვის.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isEmpty(value)`

პარამეტრები:

- `value`: მნიშვნელობა, რომლის ცარიელობაც უნდა შემოწმდეს.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:

- `Type.isEmpty(value)`
