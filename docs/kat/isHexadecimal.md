# isHexadecimal

## აღწერა

`isHexadecimal` ამოწმებს, არის თუ არა მოცემული მნიშვნელობა თექვსმეტობითი სტრიქონული ლიტერალი სავალდებულო `0x`/`0X`
პრეფიქსით.

### გამოყენების შემთხვევა

გამოიყენეთ `isHexadecimal` კონფიგურაციის მნიშვნელობების, API payload-ის ველების ან CLI არგუმენტების ვალიდაციისთვის,
რომლებიც უნდა იყოს მოწოდებული თექვსმეტობითი სტრიქონული ლიტერალების სახით (მაგ., ID-ები, მასკები ან მისამართები) და არ
უნდა შეიცავდეს გარშემო გამოტოვებებს.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isHexadecimal`, როცა გჭირდებათ მომხმარებლის შეყვანის ან სერიალიზებული მონაცემების ვალიდაცია, როგორც მკაცრი
> თექვსმეტობითი ლიტერალის სტრიქონი (მათ შორის `0x`/`0X` პრეფიქსი) დამუშავებამდე, პარსინგამდე ან კონვერტაციამდე.

### უპირატესობები

- ამოწმებს, რომ მნიშვნელობა სტრიქონია და შეესაბამება მკაცრ თექვსმეტობითი ლიტერალის ფორმატს (სავალდებულოა `0x`/`0X`
  პრეფიქსი).
- უარყოფს სტრიქონებს საწყისი ან საბოლოო გამოტოვებით (whitespace), რაც ეხმარება თავიდან აიცილოს შემთხვევითი მიღება
  შევსებული (padded) შეყვანის.
- მხარს უჭერს არასავალდებულო ნიშანს და არ არის მგრძნობიარე რეგისტრის მიმართ პრეფიქსისა და ციფრებისთვის, პროგნოზირებადად
  აბრუნებს `true`/`false`.

