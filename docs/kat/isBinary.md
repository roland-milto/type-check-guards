# isBinary

## აღწერა

`isBinary` განსაზღვრავს, არის თუ არა მნიშვნელობა ბინარული სტრიქონი (`0b`/`0B` პრეფიქსით სურვილისამებრ) და აბრუნებს
`true` ან `false`.

### გამოყენების შემთხვევა

დაავალიდირეთ მომხმარებლის მიერ მოწოდებული სტრიქონები (მაგ., ფორმის ველები, CLI არგუმენტები, კონფიგურაციის
მნიშვნელობები), რათა დარწმუნდეთ, რომ ისინი მხოლოდ ბინარულ ციფრებს შეიცავს და სურვილისამებრ აქვს `0b`/`0B` პრეფიქსი,
შემდგომი დამუშავებამდე.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isBinary` როგორც ტიპის guard სტრიქონის `BigInt`/`Number`-ად დაპარსვამდე ან გარდაქმნამდე, რათა თავიდან
> აიცილოთ არასწორი შეყვანა.

### უპირატესობები

- `0b`/`0B` პრეფიქსით ან მის გარეშე იღებს ბინარულ სტრიქონებს.
- უარყოფს ცარიელ სტრიქონებს და სტრიქონებს, რომლებსაც აქვთ დასაწყისში/ბოლოში whitespace (ASCII ≤ 32).
- `true`/`false`-ს აბრუნებს გამონაკლისის აგდების გარეშე, რაც მას უსაფრთხოს ხდის უცნობი შეყვანებისთვის.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isBinary(value)`

პარამეტრები:

- `value`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // true
const b = isBinary("1010");   // true
const c = isBinary("0b1020"); // false
const d = isBinary(0b1010);     // false

```

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts

```
