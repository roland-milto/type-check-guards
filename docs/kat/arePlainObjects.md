# arePlainObjects

## აღწერა

ამოწმებს, არის თუ არა მასივის ყველა ელემენტი ჩვეულებრივი ობიექტი და აბრუნებს `true`-ს მხოლოდ იმ შემთხვევაში, თუ ყველა
ელემენტი აკმაყოფილებს პირობას.

### გამოყენების შემთხვევა

დაავალიდირეთ გარე ან უტიპო მონაცემები (მაგ., დამუშავებული JSON, API payload-ები, ფორმის გაგზავნები), რათა დარწმუნდეთ,
რომ მიიღეთ არაცარიელი მასივი, სადაც ყოველი ჩანაწერი არის ჩვეულებრივი ობიექტი, სანამ მასზე იტერაციას დაიწყებთ და
თვისებებს წაიკითხავთ.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `arePlainObjects`, რათა დაავალიდიროთ უცნობი შეყვანა, სანამ მას TypeScript-ში `Record<string, unknown>[]`
> -ად (ან უფრო მკაცრი ობიექტის ფორმად) მოექცევით.

### უპირატესობები

- უზრუნველყოფს, რომ შეყვანის მასივში ყოველი ელემენტი იყოს ჩვეულებრივი ობიექტი, და აბრუნებს `true`-ს მხოლოდ მაშინ, როცა
  ყველა ელემენტი ემთხვევა.
- ადრეულად უარყოფს არასწორ შეყვანებს (არამასივებს ან ცარიელ მასივებს) `false`-ის დაბრუნებით.
- ორივე ტიპის ობიექტს — ობიექტ-ლიტერალს და `Object.create(null)`-ით შექმნილ ობიექტს — მიიჩნევს ვალიდურ ჩვეულებრივ
  ობიექტებად.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `arePlainObjects(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს, შეიცავს თუ არა ჩვეულებრივი ობიექტის ელემენტებს.

### ფუნქციის ლოკალური იმპორტი

```ts
import { arePlainObjects } from "@type-check/guards";

const a = arePlainObjects([{ a: 1 }, { b: 2 }]); // ჭეშმარიტი
const b = arePlainObjects([{}, Object.create(null)]); // ჭეშმარიტი
const c = arePlainObjects([{ a: 1 }, 2 as unknown]); // მცდარი
const d = arePlainObjects([] as unknown[]); // მცდარი
```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:

- `Type.arePlainObjects(array)`
