# areValidDates

## აღწერა

ადგენს, არის თუ არა მასივი არაცარიელი და მთლიანად შედგება ვალიდური `Date` ობიექტებისგან.

### გამოყენების შემთხვევა

გამოიყენეთ `areValidDates` მომხმარებლის მიერ მოწოდებული ან API-დან მიღებული მასივების ვალიდაციისთვის, სანამ თარიღებზე
დაფუძნებულ ოპერაციებს (დალაგება, დიაპაზონის შემოწმება, ფორმატირება) შეასრულებთ; ეს უზრუნველყოფს, რომ ყველა ჩანაწერი არის
რეალური, ვალიდური `Date` ობიექტი და რომ სია ცარიელი არ არის.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `areValidDates` ცარიელი მასივისთვის აბრუნებს `false`-ს; სანამ მასზე ვალიდაციის ნაბიჯად დაეყრდნობით, დარწმუნდით, რომ
> მასივი განზრახ არაცარიელია.

### უპირატესობები

- აბრუნებს `true`-ს მხოლოდ მაშინ, როცა ყოველი ელემენტი არის ვალიდური `Date` ინსტანსი (არ შეიცავს არავალიდურ თარიღებს,
  როგორიცაა `new Date('invalid')`).
- ცარიელ შეყვანას უარყოფს `false`-ის დაბრუნებით, რაც უზრუნველყოფს, რომ მიიღოთ მხოლოდ შინაარსიანი, არაცარიელი თარიღების
  სიები.
- იძლევა მარტივ ბულურ, guard-სტილის შემოწმებას, რომლის კომბინირებაც ადვილია სხვა ვალიდაციებთან.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areValidDates(array)`

პარამეტრები:

- `array`: შესამოწმებელი მასივი, რომელიც შესაძლოა შეიცავდეს `Date` ობიექტებს.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areValidDates } from "@type-check/guards";

const a = [new Date(), new Date("2025-12-17")];
const b = [new Date(), "not a date"] as unknown[];
const c: unknown[] = [];
const d = [new Date("invalid date")] as unknown[];

console.log(areValidDates(a)); // მართალი
console.log(areValidDates(b)); // მცდარი
console.log(areValidDates(c)); // მცდარი
console.log(areValidDates(d)); // მცდარი

```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:

- `Type.areValidDates(array)`
