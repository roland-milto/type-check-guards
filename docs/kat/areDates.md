# areDates

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areDates(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს `Date` ობიექტებზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areDates } from "@type-check/guards";

const a: unknown[] = [new Date(), new Date("2021-01-01")];
const b: unknown[] = [];
const c: unknown[] = [new Date(), "not a date"];

console.log(areDates(a)); // ჭეშმარიტი
console.log(areDates(b)); // მცდარი
console.log(areDates(c)); // მცდარი

if (areDates(a)) {
  const timestamps = a.map(d => d.getTime());
  console.log(timestamps);
}

```
