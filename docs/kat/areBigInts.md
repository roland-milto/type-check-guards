# areBigInts

## აღწერა

`areBigInts` განსაზღვრავს, არის თუ არა მნიშვნელობა არაცარიელი მასივი, რომელიც შეიცავს მხოლოდ `bigint` მნიშვნელობებს.

### გამოყენების შემთხვევა

დაავალიდირეთ უცნობი შეყვანა (მაგ., დამუშავებული JSON-ის მსგავსი მონაცემები, API payload-ები, ან `unknown`-ად ტიპიზებული
ფუნქციის პარამეტრები), რათა დამუშავებამდე დარწმუნდეთ, რომ ეს არის `bigint` მნიშვნელობების არაცარიელი მასივი; `true`-ს
აბრუნებს მხოლოდ მაშინ, როცა ყველა ელემენტი `bigint`-ია, წინააღმდეგ შემთხვევაში — `false`.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `areBigInts` როგორც runtime guard, სანამ უცნობ შეყვანაზე `bigint`-მხოლოდ ოპერაციებს (მაგ., არითმეტიკა,
> შედარებები) შეასრულებთ.

### უპირატესობები

- ყოველი ელემენტის `bigint`-ად ყოფნას უზრუნველყოფს და `true`-ს აბრუნებს მხოლოდ მაშინ, როცა მთელი მასივი ემთხვევა.
- დიზაინით უარყოფს არამასივებს და ცარიელ მასივებს (`isFilledArray`-ის მეშვეობით), რაც თავიდან აცილებს არასწორი
  შეყვანების შემთხვევით მიღებას.
- სწრაფი შეწყვეტა: `false`-ს აბრუნებს როგორც კი არ-`bigint` ელემენტი აღმოჩნდება.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areBigInts(array)`

პარამეტრები:

- `array`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areBigInts } from "@type-check/guards";

const a: unknown = [10n, 20n];
const b: unknown = [10n, 20];
const c: unknown = [];

console.log(areBigInts(b)); // მცდარი
console.log(areBigInts(c)); // მცდარი
```
