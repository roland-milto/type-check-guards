# isWeakSet

## აღწერა

ᲒᲐᲜᲡᲐᲖᲦᲕᲠᲐᲕᲡ, ᲗᲣ ᲛᲘᲪᲔᲛᲣᲚᲘ `value` ᲐᲠᲘᲡ ᲝᲑᲘᲔᲥᲢᲔᲑᲘᲡ `WeakSet`.

### გამოყენების შემთხვევა

`isWeakSet` ᲒᲐᲛᲝᲘᲧᲔᲜᲔᲗ, ᲠᲝᲓᲔᲡᲐᲪ ᲘᲦᲔᲑᲗ ᲣᲢᲘᲞᲝ ᲨᲔᲧᲕᲐᲜᲘᲚᲡ (ᲛᲐᲒ., ᲒᲐᲠᲔ ᲐᲞᲘ-ᲔᲑᲘᲓᲐᲜ, ᲓᲘᲜᲐᲛᲘᲣᲠᲘ ᲙᲝᲜᲤᲘᲒᲣᲠᲐᲪᲘᲘᲓᲐᲜ ᲐᲜ `unknown`
ᲛᲜᲘᲨᲕᲜᲔᲚᲝᲑᲔᲑᲘᲓᲐᲜ) ᲓᲐ ᲒᲭᲘᲠᲓᲔᲑᲐᲗ ᲓᲐᲠᲬᲛᲣᲜᲓᲔᲗ, ᲠᲝᲛ ᲘᲡ `WeakSet`-ია, ᲡᲐᲜᲐᲛ `WeakSet`-ᲘᲡ ᲡᲞᲔᲪᲘᲤᲘᲙᲣᲠ ᲝᲞᲔᲠᲐᲪᲘᲔᲑᲡ ᲒᲐᲛᲝᲘᲧᲔᲜᲔᲑᲗ.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `isWeakSet` ᲒᲐᲛᲝᲘᲧᲔᲜᲔᲗ `unknown` ᲛᲜᲘᲨᲕᲜᲔᲚᲝᲑᲘᲡ ᲠᲣᲜᲢᲐᲘᲛᲨᲘ `WeakSet<object>`-ᲐᲓ ᲓᲐᲕᲠᲝᲕᲔᲑᲘᲡᲗᲕᲘᲡ; ᲒᲐᲘᲗᲕᲐᲚᲘᲡᲬᲘᲜᲔᲗ, ᲠᲝᲛ
`WeakSet`-ᲨᲘ ᲨᲔᲘᲫᲚᲔᲑᲐ ᲛᲮᲝᲚᲝᲓ ᲝᲑᲘᲔᲥᲢᲔᲑᲘᲡ ᲠᲔᲤᲔᲠᲔᲜᲡᲔᲑᲘ ᲘᲧᲝᲡ.

### უპირატესობები

- `WeakSet` ᲓᲐᲠᲢᲧᲛᲘᲡ ᲛᲐᲠᲢᲘᲕ ᲠᲣᲜᲢᲐᲘᲛ ᲨᲔᲛᲝᲬᲛᲔᲑᲐᲡ ᲘᲫᲚᲔᲕᲐ, ᲗᲣ ᲛᲜᲘᲨᲕᲜᲔᲚᲝᲑᲐ `WeakSet`-ია.
- ᲢᲘᲞᲘᲡ ᲨᲔᲪᲓᲝᲛᲔᲑᲘᲡ ᲗᲐᲕᲘᲓᲐᲜ ᲐᲠᲘᲓᲔᲑᲐᲨᲘ ᲔᲮᲛᲐᲠᲔᲑᲐ, ᲠᲐᲓᲒᲐᲜ ᲣᲖᲠᲣᲜᲕᲔᲚᲧᲝᲤᲡ, ᲠᲝᲛ ᲛᲮᲝᲚᲝᲓ `WeakSet`-ის ᲔᲥᲖᲔᲛᲞᲚᲐᲠᲔᲑᲘ ᲘᲥᲜᲔᲑᲐ ᲐᲡᲔ
  ᲛᲘᲩᲜᲔᲣᲚᲘ.
- ᲛᲣᲨᲐᲝᲑᲡ ᲜᲔᲑᲘᲡᲛᲘᲔᲠ `unknown` ᲨᲔᲧᲕᲐᲜᲘᲚᲖᲔ ᲓᲐ ᲐᲑᲠᲣᲜᲔᲑᲡ ᲒᲐᲜᲡᲐᲖᲦᲕᲠᲣᲚ ᲑᲣᲚᲔᲐᲜ ᲨᲔᲓᲔᲒᲡ (`true`/`false`).

### ფუნქციის ლოკალური იმპორტი

```ts

  // a არის WeakSet შესრულების დროს
}
```
