# areDecimals

## აღწერა

ამოწმებს, არის თუ არა მასივში ყველა ელემენტი ათწილადი რიცხვი და არის თუ არა მასივი შევსებული, აბრუნებს `true` ან
`false`.

### გამოყენების შემთხვევა

მომხმარებლის მიერ მოწოდებული სიების (მაგ., CSV სვეტები ან ფორმის შეყვანები) ვალიდაცია, რათა დარწმუნდეთ, რომ მასივი არ
არის ცარიელი და თითოეული ჩანაწერი არის ათწილადი მნიშვნელობა, სანამ დაიწყებთ პარსინგს ან გამოთვლებს.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `areDecimals`, როცა გჭირდებათ სწრაფი ბულური შემოწმება, რომ `unknown[]` არ არის ცარიელი და თითოეული ელემენტი
> წარმოადგენს ათწილადს.

### უპირატესობები

- უზრუნველყოფს, რომ შეყვანა იყოს შევსებული მასივი ელემენტების ვალიდაციამდე, რაც თავიდან აცილებს ცარიელი სიების
  შემთხვევით მიღებას.
- ვალიდაციას უკეთებს თითოეულ ელემენტს `isDecimal`-ით, ამიტომ შერეული ან არასწორი მნიშვნელობები დაუყოვნებლივ იწვევს
  `false` შედეგს.
- იძლევა მარტივ ბულურ შედეგს (`true`/`false`), რომელიც შესაფერისია guard-ებისთვის და early-return ვალიდაციის
  ნაკადებისთვის.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areDecimals(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // ჭეშმარიტი
console.log(areDecimals(b)); // მცდარი
console.log(areDecimals(c)); // მცდარი
```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts

```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:
