# isWeakMap

## აღწერა

განსაზღვრავს, არის თუ არა მოცემული `value` `WeakMap`-ის ინსტანცია.

### გამოყენების შემთხვევა

გამოიყენეთ `isWeakMap`, როცა იღებთ `unknown` მნიშვნელობას (მაგ., საჯარო API-დან, პლაგინების სისტემიდან ან დინამიკური
კონფიგურაციიდან) და გჭირდებათ გადაამოწმოთ, რომ ეს არის `WeakMap`, სანამ `WeakMap`-ისთვის სპეციფიკურ ქცევას გამოიყენებთ.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `isWeakMap` ასრულებს `instanceof WeakMap` შემოწმებას; ეს არის შესრულების დროის guard, რომელიც `true`-ს აბრუნებს მხოლოდ
> რეალური `WeakMap` ინსტანციებისთვის.

### უპირატესობები

- მარტივი შესრულების დროის შემოწმება იმის დასადგენად, არის თუ არა მნიშვნელობა `WeakMap`.
- ეხმარება თავიდან აიცილოს იმ API-ების არასწორი გამოყენება, რომლებიც `WeakMap`-ს მოითხოვენ, რადგან გამონაკლისის აგდების
  ნაცვლად აბრუნებს `true`/`false`.
- მუშაობს `unknown` შეყვანებთან, რაც მოსახერხებელს ხდის მოდულის საზღვრებზე (მაგ., პარსინგი, გარე მონაცემები ან უტიპო
  კოდი).

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isWeakMap(value)`

პარამეტრები:

- `value`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isWeakMap } from "@type-check/guards";

const a: unknown = new WeakMap<object, number>();
const b: unknown = new Map();

if (isWeakMap(a)) {
  // a გაშვების დროს WeakMap-ია
}

console.log(isWeakMap(a)); // ჭეშმარიტი
console.log(isWeakMap(b)); // მცდარი
```
