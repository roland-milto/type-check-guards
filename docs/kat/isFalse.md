# isFalse

## აღწერა

`isFalse` ამოწმებს, არის თუ არა მოცემული მნიშვნელობა მკაცრად ტოლი ბულური ლიტერალის `false`-ის.

### გამოყენების შემთხვევა

უცნობი მონაცემების (მაგ., JSON-იდან, query params-იდან ან მომხმარებლის შეყვანიდან) ვალიდაცია, როცა მხოლოდ აშკარა ბულური
მნიშვნელობა `false` უნდა ჩაითვალოს ვალიდურ ფლაგად, ხოლო ყველაფერი დანარჩენი უნდა უარყოფილ იქნას.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isFalse`, როცა საჭიროა მხოლოდ ლიტერალური `false`-ის მიღება და ყველა სხვა falsy მნიშვნელობის უარყოფა; ის
> აბრუნებს `true`-ს მხოლოდ `value === false` შემთხვევაში.

### უპირატესობები

- კოერციის გარეშე უზრუნველყოფს ბულური ლიტერალის `false` მკაცრ შემოწმებას.
- ეხმარება `false`-ის გარჩევაში სხვა falsy მნიშვნელობებისგან, როგორიცაა `0`, `""`, `null` და `undefined`.
- აუმჯობესებს წაკითხვადობას, რადგან უცნობი შეყვანის ვალიდაციისას განზრახვას აშკარად გამოხატავს.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isFalse(value)`

პარამეტრები:

- `value`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isFalse } from "@type-check/guards";

const input: unknown = false;

if (isFalse(input)) {
  // აქ input ზუსტად false-ია
  console.log("Got false");
} else {
  console.log("Not false");
}

```
