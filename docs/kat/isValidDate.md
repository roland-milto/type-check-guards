# isValidDate

## აღწერა

`isValidDate` ამოწმებს, არის თუ არა მოცემული მნიშვნელობა ვალიდური `Date` ობიექტი და აბრუნებს `true`-ს მხოლოდ რეალური,
არაუვარგისი თარიღებისთვის.

### გამოყენების შემთხვევა

დაავალიდირეთ მომხმარებლის შეყვანა ან API მონაცემები, რომლებიც შეიძლება შეიცავდეს თარიღებს, რათა დარწმუნდეთ, რომ
მნიშვნელობა არის რეალური `Date` ინსტანცია და არა არასწორი თარიღი, სანამ შეასრულებთ თარიღის გამოთვლებს, ფორმატირებას ან
შედარებებს.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isValidDate` `Date` მეთოდების (მაგ., `toISOString`, `getTime`) გამოძახებამდე `unknown` ტიპის
> მნიშვნელობებზე, რათა დარწმუნდეთ, რომ ისინი ვალიდური `Date` ობიექტებია.

### უპირატესობები

- უზრუნველყოფს, რომ მნიშვნელობა იყოს `Date` ინსტანცია და არა უბრალოდ თარიღის მსგავსი სტრიქონი ან რიცხვი.
- უარყოფს არასწორ თარიღებს (მაგ., `new Date("invalid")`) `NaN` დროის მნიშვნელობების შემოწმებით.
- მარტივი ბულური გუშაგი, რომელიც მარტივად გამოიყენება პირობითებში და ვალიდაციის მილსადენებში.
- ეხმარება თავიდან აიცილოს შესრულების დროის შეცდომები თარიღის მეთოდების გამოძახებისას, წინასწარ ამოწმებს შეყვანას.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isValidDate(value)`

პარამეტრები:

- `value`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isValidDate } from "@type-check/guards";

const input: unknown = new Date();

if (isValidDate(input)) {
  // input არის სწორი Date ინსტანცია
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a valid Date");
}

console.log(isValidDate(new Date("invalid"))); // მცდარი
console.log(isValidDate("2025-12-22")); // მცდარი

```
