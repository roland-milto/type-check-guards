# isNaN

## აღწერა

განსაზღვრავს, არის თუ არა მოწოდებული `value` `number` ტიპის `NaN`, სტრიქონების გარდაქმნის გარეშე.

### გამოყენების შემთხვევა

დაამოწმეთ არასანდო ან სუსტად ტიპიზებული შეყვანა (მაგ., API payload-ები, ფორმის მნიშვნელობები, დამუშავებული JSON), რათა
აღმოაჩინოთ სპეციალური `NaN` მნიშვნელობა და დაამუშავოთ ის ცალსახად, ხოლო არარიცხვითი შეყვანები ჩაითვალოს როგორც არა
`NaN`.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isNaN`, როცა გჭირდებათ სპეციალური რიცხვითი მნიშვნელობის `NaN` აღმოჩენა და ამავე დროს დარწმუნება, რომ
> შეყვანა რეალურად არის `number` (სტრიქონიდან რიცხვად გარდაქმნის გარეშე).

### უპირატესობები

- ამოწმებს, არის თუ არა მნიშვნელობა `NaN`, ისე რომ არ მოახდინოს არარიცხვითი მნიშვნელობების (მაგ., სტრიქონების) რიცხვებად
  იძულებითი გარდაქმნა.
- აბრუნებს `true`-ს მხოლოდ იმ მნიშვნელობებისთვის, რომლებიც ერთდროულად არის `number` ტიპის და `NaN`.
- უსაფრთხოა `unknown` შეყვანებისთვის და თავიდან იცილებს ცრუ დადებით შედეგებს იმპლიციტური გარდაქმნებიდან.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isNaN(value)`

პარამეტრები:

- `value`: მნიშვნელობა, რომელიც უნდა შემოწმდეს, არის თუ არა `number` ტიპის `NaN`.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // ჭეშმარიტი
console.log(isNaN(b)); // მცდარი
console.log(isNaN(c)); // მცდარი

if (isNaN(a)) {
  // a არის რიცხვი და კერძოდ NaN
}
```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:

- `Type.isNaN(value)`
