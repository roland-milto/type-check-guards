# isOneOfType

## აღწერა

`isOneOfType` განსაზღვრავს, ემთხვევა თუ არა მოცემული `value` მოწოდებული ტიპის სტრიქონებიდან მაინც ერთს; დამთხვევის
არსებობისას აბრუნებს `true`-ს, წინააღმდეგ შემთხვევაში — `false`-ს.

### გამოყენების შემთხვევა

შეამოწმეთ სუსტად-ტიპიზებული ან გარე მონაცემები (მაგ., გაპარსული JSON, query პარამეტრები) რამდენიმე მისაღები შესრულების
დროის ტიპის დაშვებით (როგორიცაა `number` ან `string`) მანამდე, სანამ გააგრძელებთ შემდგომ ლოგიკას.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isOneOfType`, როცა გსურთ შესრულების დროის შემოწმება, რომ მნიშვნელობა ემთხვევა რამდენიმე დაშვებული ტიპიდან
> რომელიმეს; ის აბრუნებს `true`-ს, თუ მაინც ერთი ტიპი ემთხვევა, წინააღმდეგ შემთხვევაში — `false`-ს.

### უპირატესობები

- ერთ გამოძახებაში ამოწმებს მნიშვნელობას რამდენიმე დაშვებულ ტიპთან, და პირველივე დამთხვევაზე აბრუნებს `true`-ს.
- მუშაობს `unknown` შეყვანებთან, რაც მას სასარგებლოს ხდის შესრულების დროის საზღვრებზე (მაგ., გარე მონაცემები,
  მომხმარებლის შეყვანა).
- აძლევს მარტივ ბულურ შედეგს (`true`/`false`), რომელიც კარგად ეწყობა პირობით ლოგიკას და ადრეულ დაბრუნებებს.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isOneOfType(value, types)`

პარამეტრები:

- `value`: მნიშვნელობა, რომელიც უნდა შემოწმდეს მითითებულ ტიპებთან მიმართებით.
- `types`: ტიპების სტრიქონების მასივი, რომლებიც წარმოადგენს მნიშვნელობის შესაძლო ტიპებს.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // input რეალურად ობიექტია შესრულების დროს
}

console.log(isOneOfType(3, ["number", "string"])); // ჭეშმარიტი
console.log(isOneOfType("hello", ["number", "boolean"])); // მცდარი

```
