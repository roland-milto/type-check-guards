# arePrimitives

## აღწერა

`arePrimitives` აფასებს, არის თუ არა მოწოდებულ, არაცარიელ მასივში ყველა ელემენტი პრიმიტიული ტიპის.

### გამოყენების შემთხვევა

დაადასტურეთ, რომ შემომავალი მონაცემები (მაგ., query პარამეტრები, CSV რიგის მნიშვნელობები, ან ID-ების/ტეგების სია)
შეიცავს მხოლოდ პრიმიტიულ მნიშვნელობებს სერიალიზაციამდე, ჰეშირებამდე, ლოგირებამდე, ან იმ API-ებში გადაცემამდე, რომლებმაც
არ უნდა მიიღონ ობიექტები.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `arePrimitives`, როცა გჭირდებათ დარწმუნდეთ, რომ `unknown[]` შეიცავს მხოლოდ პრიმიტიულ მნიშვნელობებს (string,
> number, bigint, boolean, symbol, undefined, ან null) შემდგომი დამუშავების წინ.

### უპირატესობები

- აბრუნებს `true` მხოლოდ მაშინ, როცა ყოველი ელემენტი პრიმიტიული მნიშვნელობაა, რაც მას მკაცრ დამცავად აქცევს
  „ობიექტების/ფუნქციების გარეშე“ მასივებისთვის.
- სწრაფად წყვეტს შემოწმებას: აბრუნებს `false` როგორც კი არაპრიმიტიულ ელემენტს აღმოაჩენს.
- ასევე აბრუნებს `false` არამასივებისთვის და ცარიელი მასივებისთვის (შევსებული-მასივის შემოწმების მეშვეობით), რაც თავიდან
  აცილებს არასწორი შეყვანის შემთხვევით მიღებას.

- `arePrimitives(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს პრიმიტიული ტიპის ელემენტებზე.

