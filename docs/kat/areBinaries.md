> **შენიშვნა TypeScript მომხმარებლებისთვის:**

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areBinaries(array)`

პარამეტრები:

- `array`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // true
console.log(areBinaries(b)); // false
console.log(areBinaries([])); // false
```
