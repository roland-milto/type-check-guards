# areSymbols

## აღწერა

ამოწმებს, არის თუ არა შეყვანა შევსებული მასივი, რომლის ყველა ელემენტი სიმბოლოა, და აბრუნებს `true` ან `false`.

### გამოყენების შემთხვევა

დაავალიდირეთ, რომ კონფიგურაციის ველი (მაგ., უნიკალური გასაღებების სია, რომელიც სიმბოლოებით არის წარმოდგენილი) არის
არაცარიელი მასივი, რომელიც შეიცავს მხოლოდ სიმბოლოებს, სანამ მას გამოიყენებთ API-ებში, რომლებსაც სჭირდებათ `symbol[]`.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `areSymbols` უცნობი შეყვანის ვალიდაციისთვის, სანამ მას `symbol[]`-ად მოექცევით; ის აბრუნებს `false`-ს
> არამასივებისთვის და ცარიელი მასივებისთვის.

### უპირატესობები

- აბრუნებს `true`-ს მხოლოდ მაშინ, როცა შეყვანა არის არაცარიელი მასივი და ყოველი ელემენტი არის სიმბოლო.
- თავიდან იცილებს ცრუ დადებით შედეგებს: შიდა შევსებული-მასივის შემოწმებით უარყოფს არამასივებს და ცარიელ მასივებს.
- გამოსადეგია როგორც runtime ტიპის დამცველი (type guard) სიმბოლოებისგან შემდგარი სიების ვალიდაციისთვის შემდგომ
  დამუშავებამდე.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areSymbols(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს სიმბოლო-ელემენტებზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  // a არის მხოლოდ სიმბოლოების მასივი შესრულების დროს
  const first = a[0];
  console.log(typeof first); // "symbol"
}

console.log(areSymbols(b)); // false
```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:

- `Type.areSymbols(array)`
