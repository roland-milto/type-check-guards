# areNaNs

## აღწერა

`areNaNs` ამოწმებს, არის თუ არა მასივში ყველა ელემენტი `NaN` და აბრუნებს `true`-ს მხოლოდ იმ შემთხვევაში, თუ ყოველი
ელემენტი არის `NaN`.

### გამოყენების შემთხვევა

დაამოწმეთ შემომავალი მონაცემები, სადაც `NaN` გამოიყენება როგორც სენტინელის მნიშვნელობა და აუცილებელია დარწმუნდეთ, რომ
მთელი მასივი შედგება ექსკლუზიურად `NaN`-ისგან (მაგ., სრულად გამოტოვებული რიცხვითი სერიის აღმოჩენა).

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `areNaNs`, როცა გჭირდებათ დაადასტუროთ, რომ მასივი შეიცავს მხოლოდ რიცხვით `NaN` მნიშვნელობას (სტრიქონიდან
> რიცხვად გარდაქმნის გარეშე).

### უპირატესობები

- აბრუნებს `true`-ს მხოლოდ მაშინ, როცა ყოველი ელემენტი არის `NaN` (ყველა ელემენტის მკაცრი შემოწმება).
- არ ახდენს სტრიქონების რიცხვებად გარდაქმნას; ისეთი მნიშვნელობები, როგორიცაა "NaN", რჩება არა-`NaN` და შედეგს ხდის
  `false`-ს.
- არაშევსებული მასივებისთვის აბრუნებს `false`-ს, რაც თავიდან აცილებს შემთხვევით `true`-ს ცარიელ შეყვანაზე.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areNaNs(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს `NaN` მნიშვნელობებზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // true
const b = areNaNs([NaN, 1, NaN]); // false
const c = areNaNs([NaN, "NaN", NaN]); // false
const d = areNaNs([NaN, null, NaN]); // false
const e = areNaNs([] as unknown[]); // false
```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:

- `Type.areNaNs(array)`
