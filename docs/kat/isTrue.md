# isTrue

## აღწერა

`isTrue` განსაზღვრავს, არის თუ არა მოცემული მნიშვნელობა მკაცრად ტოლი `true`-ს.

### გამოყენების შემთხვევა

გამოიყენეთ `isTrue` ფლაგების, ფუნქციის გადამრთველების (feature toggles) ან კონფიგურაციის მნიშვნელობების ვალიდაციისთვის,
სადაც უნდა მიიღებოდეს მხოლოდ ლიტერალი `true`, ხოლო ყველაფერი დანარჩენი უნდა განიხილებოდეს როგორც `false`.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isTrue`, როცა საჭიროა მხოლოდ ბულური ლიტერალის `true`-ის მიღება და არა უბრალოდ truthy მნიშვნელობების.

### უპირატესობები

- უზრუნველყოფს ბულური ლიტერალის `true`-ის მკაცრ შემოწმებას (კოერციის გარეშე).
- ეხმარება `true`-ის გარჩევაში truthy მნიშვნელობებისგან, როგორიცაა `1`, `"true"` ან `{}`.
- მარტივი, პროგნოზირებადი ქცევა, რომელიც შესაფერისია guard-ებისა და ვალიდაციის პაიპლაინებისთვის.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isTrue(value)`

პარამეტრები:

- `value`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // ჭეშმარიტი
const b = isTrue(1);         // მცდარი
const c = isTrue("true");   // მცდარი

if (isTrue(a)) {
  // აქ a ჭეშმარიტია
}
```
