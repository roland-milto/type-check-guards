# areTrue

## აღწერა

ამოწმებს, შეიცავს თუ არა არაცარიელი მასივი მხოლოდ ბულურ `true` მნიშვნელობებს.

### გამოყენების შემთხვევა

გამოიყენეთ `areTrue`, რათა დაადასტუროთ, რომ წინაპირობების ან ფუნქციის დროშების (feature flags) ნაკრები სრულად ჩართულია (
ყველა მნიშვნელობა არის `true`) გაგრძელებამდე, ხოლო ცარიელი ან არასწორად ფორმირებული შეყვანები ჩაითვალოს
დაუკმაყოფილებლად (`false`).

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `areTrue` აბრუნებს `false`-ს ცარიელი მასივისთვის და იმ მასივებისთვის, რომლებიც შეიცავს ნებისმიერ მნიშვნელობას, რომელიც
> მკაცრად `true` არ არის.

### უპირატესობები

- აბრუნებს `true`-ს მხოლოდ მაშინ, როცა ყოველი ელემენტი მკაცრად `true`-ია და მასივი არ არის ცარიელი.
- სწრაფად წყვეტს: აბრუნებს `false`-ს როგორც კი მოიძებნება არ-`true` მნიშვნელობა.
- უარყოფს არასწორ შეყვანებს (არამასივებს ან ცარიელ მასივებს) `false`-ის დაბრუნებით.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areTrue(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს ყველა `true` მნიშვნელობაზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areTrue } from "@type-check/guards";

const a = areTrue([true, true, true]);
const b = areTrue([true, false, true]);
const c = areTrue([]);
const d = areTrue([true, "string" as unknown, true]);

console.log(a, b, c, d);
```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:

- `Type.areTrue(array)`
