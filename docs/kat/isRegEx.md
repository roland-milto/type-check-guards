# isRegEx

## აღწერა

ადგენს, არის თუ არა მოწოდებული მნიშვნელობა `RegExp`-ის ინსტანსი.

### გამოყენების შემთხვევა

დაავალიდირეთ მომხმარებლის მიერ მოწოდებული ან დინამიკური მნიშვნელობები (მაგ., კონფიგურაცია, API payload-ები, პლაგინის
შეყვანები) მანამდე, სანამ მათ რეგულარულ გამოსახულებად ჩათვლით.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isRegEx`, რათა დაავიწროვოთ `unknown` (ან union) მნიშვნელობები `RegExp`-ისთვის სპეციფიკური თვისებების ან
> მეთოდების გამოყენებამდე; ის აბრუნებს `true`-ს მხოლოდ იმ მნიშვნელობებისთვის, რომლებიც `RegExp`-ის ინსტანსებია.

### უპირატესობები

- `RegExp`-ის მნიშვნელობაა თუ არა, შესამოწმებლად უზრუნველყოფს მარტივ გაშვების დროის ტიპის დამცველს (runtime type guard).
- ეხმარება შეცდომების თავიდან აცილებაში, როცა კოდი ელოდება რეგულარულ გამოსახულებას (მაგ., `test`, `exec` გამოძახებამდე
  ან `source`-ის წაკითხვამდე).
- მუშაობს როგორც regex ლიტერალებთან, ისე `new RegExp(...)`-ით შექმნილ ინსტანსებთან.
- აბრუნებს მკაფიო ბულურ შედეგს (`true`/`false`) და არ აგდებს გამონაკლისს არარეგექს-შეყვანებზე.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isRegEx(value)`

პარამეტრები:

- `value`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  // აქ input არის RegExp
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```
