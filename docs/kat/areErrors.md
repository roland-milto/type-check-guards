# areErrors

## აღწერა

ამოწმებს, არის თუ არა მასივი არაცარიელი და შეიცავს მხოლოდ `Error` ობიექტებს, აბრუნებს `true` ან `false`.

### გამოყენების შემთხვევა

დაადასტურეთ, რომ runtime-ში მოწოდებული `unknown[]` (მაგ., აგრეგირებული ჩავარდნები, ვალიდაციის შედეგები ან
დესერიალიზებული მონაცემები) არის `Error` ობიექტების არაცარიელი სია, სანამ დაიწყებთ იტერაციას, ლოგირებას ან ხელახლა
გადაგდებას (rethrow).

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `areErrors` აბრუნებს `true`-ს მხოლოდ შევსებული მასივისთვის, სადაც ყოველი ელემენტი არის `Error`; აბრუნებს `false`-ს
> ცარიელი მასივისთვის ან თუ რომელიმე ელემენტი არ არის `Error`.

### უპირატესობები

- ყოველი ელემენტი უზრუნველყოფს, რომ იყოს `Error` ინსტანცია, რაც შესაძლებელს ხდის უსაფრთხო შეცდომების დამუშავებას და
  ლოგირებას.
- უარყოფს ცარიელ მასივებს, რაც ხელს უშლის შემთხვევით „შეცდომები არ არის“ მდგომარეობების სწორ შეცდომების სიის სახით
  აღქმას.
- კარგად მუშაობს როგორც runtime guard, როცა საქმე გვაქვს `unknown[]` შეყვანებთან (მაგ., API-ებიდან ან `catch`
  ბლოკებიდან).

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areErrors(array)`

პარამეტრები:

- `array`: მასივი, რომელიც უნდა შემოწმდეს `Error` ობიექტებზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areErrors } from "@type-check/guards";

const value: unknown = [new Error("error1"), new TypeError("error2")];

if (Array.isArray(value) && areErrors(value)) {
  // value არის Error ობიექტების არაცარიელი მასივი
  for (const err of value) {
    console.error(err.name, err.message);
  }
} else {
  console.log("Not a non-empty Error[]");
}

```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:

- `Type.areErrors(array)`
