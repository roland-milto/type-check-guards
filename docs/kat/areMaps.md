# areMaps

## აღწერა

`areMaps` განსაზღვრავს, არის თუ არა მოცემული მასივი არაცარიელი და მისი ყველა ელემენტი `Map` ინსტანცია.

### გამოყენების შემთხვევა

უცნობი შეყვანის ვალიდაცია (მაგ., JSON-ის პარსინგიდან, გარე API-ებიდან, ან დინამიკური წყაროებიდან) მანამდე, სანამ მას
`Map` ობიექტების არაცარიელ სიად განიხილავთ.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> ცარიელი მასივისთვის აბრუნებს `false`-ს; `true`-ს აბრუნებს მხოლოდ მაშინ, როცა მასივი შევსებულია და ყოველი ელემენტი
`Map`-ია.

### უპირატესობები

- ყოველი ელემენტის `Map` ინსტანციად ყოფნას უზრუნველყოფს და `true`-ს აბრუნებს მხოლოდ მაშინ, როცა შემოწმებას მთელი მასივი
  გადის.
- დიზაინით უარყოფს ცარიელ მასივებს, რაც ხელს უშლის „მონაცემები არ არის“-ის შემთხვევით მიღებას ვალიდურ შეყვანად.
- გამოსადეგია როგორც დამცავი შემოწმება `Map`-ზე სპეციფიკური ოპერაციების შესრულებამდე (მაგ., `.get()`, `.set()`,
  იტერაცია) კოლექციაზე.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areMaps(array)`

პარამეტრები:

- `array`: შესამოწმებელი მასივი.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // items გაძლევთ გარანტიას, რომ შესრულების დროს არის Map-ის ინსტანციების არაცარიელი მასივი
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // false: ცარიელი მასივებისთვის, ან მასივებისთვის, რომლებიც შეიცავს რომელიმე არამაპურ მნიშვნელობას
}

```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

შემდეგი მეთოდი გლობალურად იქნება ხელმისაწვდომი:

- `Type.areMaps(array)`
