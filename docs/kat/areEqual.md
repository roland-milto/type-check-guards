# areEqual

## აღწერა

`areEqual` ამოწმებს, არის თუ არა მასივში ყველა ელემენტი ტოლი მოცემული მოსალოდნელი მნიშვნელობისა და აბრუნებს `true`-ს
მხოლოდ არაცარიელი მასივებისთვის, სადაც ყველა ელემენტი ემთხვევა.

### გამოყენების შემთხვევა

დაადასტურეთ, რომ სია შეიცავს მხოლოდ ერთ დაშვებულ მნიშვნელობას (მაგ., ყველა სტატუსის დროშა არის `true`, ყველა როლი არის
`"admin"`, ან ყველა რიცხვითი ჩანაწერი უდრის მოთხოვნილ კონსტანტას), ხოლო ცარიელი შეყვანა ჩაითვალოს არავალიდურად (
`false`).

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `areEqual`, როცა გჭირდებათ მკაცრი „ყველა ელემენტის“ შემოწმება; ის აბრუნებს `false`-ს ცარიელი მასივებისთვის
> და ნებისმიერი არამასივური ან არაშევსებული შეყვანისთვის.

### უპირატესობები

- აბრუნებს `true` მხოლოდ მაშინ, როცა ყველა ელემენტი ემთხვევა მოსალოდნელ მნიშვნელობას; სხვა შემთხვევაში აბრუნებს `false`.
- სწრაფად მარცხდება: წყვეტს შემოწმებას როგორც კი არამთხვეული ელემენტი მოიძებნება.
- იცავს არასწორი შეყვანისგან, რადგან აბრუნებს `false`-ს, როცა შეყვანა არ არის შევსებული მასივი.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `areEqual(value, expected)`

პარამეტრები:

- `value`: მასივი, რომელიც უნდა შემოწმდეს.
- `expected`: ელემენტი, რომელსაც მასივის თითოეულ ელემენტს ადარებს.

### ფუნქციის ლოკალური იმპორტი

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```
