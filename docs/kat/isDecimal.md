# isDecimal

## აღწერა

`isDecimal` ამოწმებს, არის თუ არა მნიშვნელობა ათწილადი სტრიქონის წარმოდგენა, დასაწყის/დასასრულის გამოტოვებების გარეშე და
სწორი ათწილადი ფორმატით.

### გამოყენების შემთხვევა

ფორმის ველების, API payload-ების ან კონფიგურაციის მნიშვნელობების ვალიდაცია, რომლებიც უნდა იყოს მოწოდებული როგორც
ათწილადი სტრიქონი (სურვილისამებრ ნიშნის მქონე) ყოველგვარი გარშემო არსებული გამოტოვებების გარეშე, დამუშავებამდე ან
შენახვამდე.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isDecimal` მომხმარებლის შეყვანის ვალიდაციისთვის მის გარდაქმნამდე (მაგ., `Number(value)`-ით), განსაკუთრებით
> მაშინ, როცა გამოტოვებები უნდა უარყოფილ იქნას.

### უპირატესობები

- შესაძლოა მკაცრად ამოწმებს, რომ შეყვანა არის სტრიქონი და ემთხვევა ათწილადი-ლიტერალის ნიმუშს.
- უარყოფს დასაწყისისა და დასასრულის გამოტოვებებს (მათ შორის საკონტროლო სიმბოლოებს), რათა თავიდან აიცილოს ორაზროვანი
  დამუშავება.
- სწრაფი წინასწარი შემოწმებები (ტიპის შემოწმება და პირველი/ბოლო სიმბოლო) რეგექსის გაშვებამდე.
- აბრუნებს მარტივ ბულურ შედეგს (`true`/`false`), რომელიც შესაფერისია guard-ებისთვის და შეყვანის ვალიდაციისთვის.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isDecimal(value)`

პარამეტრები:

- `value`: მნიშვნელობა, რომელიც უნდა შემოწმდეს ათწილადი სტრიქონის ფორმატზე.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v აქ სტრიქონია (გაშვების დროს დადასტურებული)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### ობიექტის გლობალური იმპორტი

ფუნქციების, როგორც გლობალური ობიექტის მეთოდების, იმპორტისთვის გამოიყენეთ:

```ts

```
