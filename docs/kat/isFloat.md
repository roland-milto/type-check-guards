# isFloat

## აღწერა

`isFloat` განსაზღვრავს, არის თუ არა მოცემული `value` საბოლოო მცურავი წერტილის რიცხვი (ანუ `number`, რომელიც არ არის
მთელი რიცხვი).

### გამოყენების შემთხვევა

მომხმარებლის მიერ მოწოდებული რიცხვითი შეყვანის ვალიდაცია, სადაც საჭიროა წილადი მნიშვნელობები (მაგ., ფასები, გაზომვები,
განაკვეთები) და მთელი რიცხვების, `NaN`-ისა და უსასრულობების უარყოფა.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isFloat`, როცა საჭიროა მხოლოდ საბოლოო, არამთელი რიცხვითი შეყვანების მიღება; ის უარყოფს მთელ რიცხვებს და
> არასაბოლოო რიცხვებს.

### უპირატესობები

- აბრუნებს `true`-ს მხოლოდ საბოლოო, არამთელ რიცხვებზე (გამორიცხავს მთელ რიცხვებს, `NaN`-ს, `Infinity`-ს და `-Infinity`
  -ს).
- მუშაობს ნებისმიერი შეყვანის ტიპთან (`unknown`) და უსაფრთხოდ ავიწროებს ტიპს `typeof value === "number"`-ის შემოწმებით.
- იყენებს ჩაშენებულ რიცხვით დამცავებს (`Number.isInteger`, `Number.isFinite`) პროგნოზირებადი ქცევისთვის.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isFloat(value)`

პარამეტრები:

- `value`: მნიშვნელობა, რომელიც უნდა შემოწმდეს, არის თუ არა მცურავი წერტილის რიცხვი.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isFloat } from "@type-check/guards";

const inputs: unknown[] = [3.14, -0.1, 1e-7, 42, "3.14", NaN, Infinity];

for (const value of inputs) {
  if (isFloat(value)) {
    // მნიშვნელობა გაშვების დროს რიცხვია; ის საბოლოოა და მთელი რიცხვი არ არის
    const rounded = value.toFixed(2);
    console.log("float:", value, "rounded:", rounded);
  } else {
    console.log("not a float:", value);
  }
}
```
