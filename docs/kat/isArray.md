# isArray

## აღწერა

`isArray` ამოწმებს, არის თუ არა მოცემული მნიშვნელობა მასივი და თუ არის, აბრუნებს `true`-ს, წინააღმდეგ შემთხვევაში
`false`-ს.

### გამოყენების შემთხვევა

დაამოწმეთ უცნობი მონაცემები (მაგ., დამუშავებული JSON ან API პასუხები), რათა დარწმუნდეთ, რომ მნიშვნელობა მასივია, სანამ
იტერაციას, ინდექსირებას ან `.length`-ზე წვდომას გააკეთებთ.

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> გამოიყენეთ `isArray`, როცა გჭირდებათ მასივების runtime შემოწმება; ის აბრუნებს ბულურ მნიშვნელობას და უსაფრთხოა
`unknown` მნიშვნელობებთან გამოსაძახებლად.

### უპირატესობები

- იყენებს ჩაშენებულ `Array.isArray`-ს მასივის საიმედო ამოცნობისთვის სხვადასხვა რეალმებში (მაგ., iframes).
- აბრუნებს მარტივ ბულურ შედეგს (`true`/`false`), რომელიც შესაფერისია guard-ებისთვის და განშტოების ლოგიკისთვის.
- მუშაობს ნებისმიერი შეყვანის ტიპთან, რადგან პარამეტრი არის `unknown`.

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isArray(value)`

პარამეტრები:

- `value`: შესამოწმებელი მნიშვნელობა.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  // input გაშლილი მასივი არის გაშვების დროს
  console.log(input.length);
} else {
  console.log("Not an array");
}

```
