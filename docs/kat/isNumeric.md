# isNumeric

## აღწერა

`isNumeric` განსაზღვრავს, მიიჩნევა თუ არა მოცემული `value` რიცხვითად, მისი დადგენილი ტიპის `NUMERIC_TYPES`-თან
შედარებით.

### გამოყენების შემთხვევა

გამოიყენეთ `isNumeric` შეყვანების (მაგ., API payload-ები, ფორმის მნიშვნელობები, კონფიგურაცია) ვალიდაციისთვის რიცხვითი
ოპერაციების შესრულებამდე და იმისთვის, რომ `NUMERIC_TYPES`-ის მიხედვით თანმიმდევრულად მიიღოთ რიცხვითის მსგავსი ტიპები (
როგორიცაა `BigInt`).

> **შენიშვნა TypeScript მომხმარებლებისთვის:**
>
> `isNumeric` არის ბულეანის დამბრუნებელი პრედიკატი; მოექეცით მას როგორც runtime შემოწმებას, ადგენს თუ არა მნიშვნელობა
> ბიბლიოთეკის მიერ განსაზღვრულ რიცხვით ტიპთა ნაკრებს.

### უპირატესობები

- `getTypeOf`-სა და `NUMERIC_TYPES`-ს იყენებს რიცხვითობის ამოცნობის ლოგიკის ცენტრალიზებისთვის და შემოწმებების
  თანმიმდევრულად შესანარჩუნებლად მთელ კოდბაზაში.
- აბრუნებს მარტივ ბულეანს (`true`/`false`) მარტივი განშტოებისთვის და guard-სტილის გამოყენებისთვის.
- `NUMERIC_TYPES`-ით განსაზღვრული მრავალ რიცხვით წარმოდგენას უჭერს მხარს (მაგ., `number`, `BigInt`).

## გამოყენება

### სინტაქსი

ფუნქცია:

- `isNumeric(value)`

პარამეტრები:

- `value`: მნიშვნელობა, რომლის რიცხვით ტიპად ყოფნაც უნდა შემოწმდეს.

### ფუნქციის ლოკალური იმპორტი

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    // v ბიბლიოთეკის ტიპის წესებით რიცხვითად ითვლება
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```
