# areWeakMaps

## Опис

`areWeakMaps` перевіряє, чи є значення непорожнім масивом, у якому кожен елемент — це `WeakMap`, повертаючи `true` лише
в цьому випадку та `false` в інших.

### Випадок використання

Перевіряти дані під час виконання (наприклад, розпарсений JSON, вхідні дані плагінів або слабо типізовану конфігурацію),
щоб упевнитися, що це непорожній масив екземплярів `WeakMap` перед ітерацією та викликом методів `WeakMap`; повертає
`false`, якщо будь-який елемент не є `WeakMap` або якщо масив порожній.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `areWeakMaps`, щоб перевіряти невідомий ввід перед тим, як трактувати його як непорожній `WeakMap[]`;
> для порожніх масивів функція повертає `false`.

### Переваги

- Гарантує, що кожен елемент у наданому масиві є екземпляром `WeakMap`.
- Повертає `false` для порожніх масивів, запобігаючи випадковому прийняттю «відсутності даних» як коректного вводу.
- Корисно як захисна перевірка перед виконанням операцій, специфічних для `WeakMap`, над усіма елементами.

## Використання

### Синтаксис

Функція:

- `areWeakMaps(array)`

Параметри:

- `array`: Масив, який потрібно перевірити на наявність екземплярів `WeakMap`.

### Локальний імпорт функції

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  // list — це непорожній масив екземплярів WeakMap
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  // не є непорожнім WeakMap[]
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.areWeakMaps(array)`
