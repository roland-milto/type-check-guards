# isEmpty

## Опис

Визначає, чи є задане значення порожнім, повертаючи `true` для `null`, `undefined`, порожніх/пробільних рядків, порожніх
масивів, порожніх `Map`/`Set` або об’єктів без власних перелічуваних властивостей.

### Випадок використання

Використовуйте `isEmpty`, щоб валідовувати введення та виявляти відсутні/порожні значення в різних типах даних (
наприклад, поля форм, payload API, об’єкти конфігурації), де `null`, `undefined`, пробільні рядки, порожні колекції та
об’єкти без властивостей мають вважатися порожніми.

> **Примітка для користувачів TypeScript:**
>
> `isEmpty` — це утиліта, що повертає булеве значення (а не предикат типу TypeScript), тому сама по собі вона не звужує
> типи; використовуйте її для валідації/розгалуження, а не для звуження на етапі компіляції.

### Переваги

- Розглядає `null` і `undefined` як `true` під час перевірок на порожнечу.
- Вважає рядки, що містять лише пробіли, порожніми, оскільки перед перевіркою довжини виконує обрізання пробілів.
- Підтримує поширені типи контейнерів (масиви, `Map`, `Set`) і звичайні об’єкти без власних перелічуваних властивостей.
- Уникає підрахунку успадкованих властивостей, використовуючи перевірки `hasOwnProperty`.
- Повертає простий булевий результат (`true`/`false`), придатний для гардiв і валідації.

## Використання

### Синтаксис

Функція:

- `isEmpty(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити на порожнечу.

### Локальний імпорт функції

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isEmpty(value)`
