# arePrimitives

## Опис

`arePrimitives` визначає, чи всі елементи в наданому непорожньому масиві є примітивними типами.

### Випадок використання

Перевіряйте, що вхідні дані (наприклад, параметри запиту, значення рядка CSV або список ID/тегів) містять лише
примітивні значення перед серіалізацією, хешуванням, логуванням або передаванням до API, які не повинні отримувати
об’єкти.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `arePrimitives`, коли потрібно переконатися, що `unknown[]` містить лише примітивні значення (string,
> number, bigint, boolean, symbol, undefined або null) перед подальшою обробкою.

### Переваги

- Повертає `true` лише тоді, коли кожен елемент є примітивним значенням, що робить це суворою перевіркою для масивів
  «без об’єктів/функцій».
- Швидко завершується: повертає `false`, щойно знаходить непримітивний елемент.
- Також повертає `false` для не-масивів і порожніх масивів (через перевірку на заповнений масив), запобігаючи
  випадковому прийняттю некоректного вводу.

## Використання

### Синтаксис

Функція:

- `arePrimitives(array)`

Параметри:

- `array`: Масив, який потрібно перевірити на наявність елементів примітивного типу.

### Локальний імпорт функції

```ts
import { arePrimitives } from "@type-check/guards";

const a: unknown[] = [1, "string", true];
const b: unknown[] = [null, undefined, Symbol("x")];
const c: unknown[] = [1, {}, false];

const r1 = arePrimitives(a); // істина
const r2 = arePrimitives(b); // істина
const r3 = arePrimitives(c); // хибність
```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.arePrimitives(array)`
