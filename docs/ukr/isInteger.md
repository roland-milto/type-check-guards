# isInteger

## Опис

Визначає, чи є задане `value` безпечним цілим числом.

### Випадок використання

Валідуйте ненадійне вхідне значення (наприклад, параметри запиту, JSON-пейлоади, змінні середовища) перед використанням
його як цілого числа для індексів масивів, пагінації, лічильників або ідентифікаторів бази даних.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `isInteger`, щоб валідувати невідоме вхідне значення перед тим, як трактувати його як числове ціле;
> воно повертає `true` лише для значень, де `typeof value === "number"` і `Number.isSafeInteger(value)`.

### Переваги

- Перевіряє і тип, і числову безпеку: повертає `true` лише тоді, коли вхідне значення є числом і безпечним цілим.
- Запобігає поширеним помилкам із числовим приведенням: рядки на кшталт "5" коректно повертають `false`.
- Відхиляє нецілі та небезпечні цілі числа, що робить його придатним для ідентифікаторів, лічильників та індексації
  масивів.

## Використання

### Синтаксис

Функція:

- `isInteger(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити на статус цілого числа.

### Локальний імпорт функції

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      // істина
const b = isInteger(-100);   // істина
const c = isInteger("5");    // хибність
const d = isInteger(5.5);    // хибність
const e = isInteger(null);   // хибність

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isInteger(value)`
