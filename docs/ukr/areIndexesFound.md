# areIndexesFound

## Опис

`areIndexesFound` перевіряє, чи є значення непорожнім масивом, елементи якого всі є коректними індексами, повертаючи
`true`, якщо це так, і `false` в іншому разі.

### Випадок використання

Перевіряйте надані користувачем або зовнішні дані (наприклад, розібраний JSON), від яких очікується список індексів,
перед тим як використовувати їх для доступу до масивів або їхнього розрізання.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `areIndexesFound`, щоб перевіряти невідомі вхідні дані перед тим, як трактувати їхні елементи як
> індекси масиву; вона повертає `false` для порожніх масивів і для масивів, що містять значення, які не є індексами.

### Переваги

- Вона повертає `true` лише тоді, коли вхідні дані — це заповнений масив і кожен елемент є коректним індексом.
- Швидко завершується: повертає `false`, щойно зустрічається елемент, що не є індексом.
- Корисно як перевірка перед використанням значень як позицій або зсувів у масиві.

## Використання

### Синтаксис

Функція:

- `areIndexesFound(array)`

Параметри:

- `array`: Масив, який потрібно перевірити на відповідність індексам.

### Локальний імпорт функції

```ts
import { areIndexesFound } from "@type-check/guards";

const a: unknown[] = [0, 1, 2];
const b: unknown[] = [0, "a", 2];
const c: unknown[] = [];

console.log(areIndexesFound(a)); // true
console.log(areIndexesFound(b)); // false
console.log(areIndexesFound(c)); // false

if (areIndexesFound(a)) {
  // Тут підтверджено, що `a` є заповненим масивом індексів.
  const firstIndex = a[0];
  console.log(firstIndex);
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.areIndexesFound(array)`
