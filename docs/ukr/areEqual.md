# areEqual

## Опис

`areEqual` перевіряє, чи всі елементи в масиві дорівнюють заданому очікуваному значенню, повертаючи `true` лише для
непорожніх масивів, у яких кожен елемент збігається.

### Випадок використання

Перевірити, що список містить лише одне дозволене значення (наприклад, усі прапорці стану — `true`, усі ролі —
`"admin"`, або всі числові значення дорівнюють потрібній константі), водночас вважаючи порожній ввід недійсним (
`false`).

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `areEqual`, коли потрібна сувора перевірка всіх елементів; вона повертає `false` для порожніх масивів і
> для будь-якого вводу, що не є масивом або не є заповненим.

### Переваги

- Повертає `true` лише тоді, коли кожен елемент відповідає очікуваному значенню; інакше повертає `false`.
- Швидко завершує перевірку: припиняє перевіряти, щойно знаходить елемент, що не збігається.
- Захищає від некоректного вводу, повертаючи `false`, коли вхідні дані не є заповненим масивом.

## Використання

### Синтаксис

Функція:

- `areEqual(value, expected)`

Параметри:

- `value`: Масив, який потрібно перевірити.
- `expected`: Елемент, з яким порівнюється кожен елемент масиву.

### Локальний імпорт функції

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.areEqual(value, expected)`
