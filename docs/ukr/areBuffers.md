# areBuffers

## Опис

`areBuffers` перевіряє, чи є надане значення непорожнім, заповненим масивом, у якому кожен елемент є `Buffer`,
повертаючи `true` у такому разі та `false` інакше.

### Випадок використання

Перевіряйте вхідні масиви чанків (наприклад, зі стрімів, завантажень файлів або мережевих пакетів), щоб упевнитися, що
всі частини є екземплярами `Buffer`, перед конкатенацією, декодуванням або передаванням їх у криптографічні чи
бінарно-обробні функції.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `areBuffers`, щоб перевіряти `unknown[]` перед викликом API, специфічних для Buffer, як-от
`Buffer.concat`, гарантуючи, що функція повертає `true` лише тоді, коли кожен елемент є `Buffer`.

### Переваги

- Гарантує, що кожен елемент у вхідних даних є екземпляром Node.js `Buffer`, повертаючи `true` лише тоді, коли весь
  масив відповідає умові.
- Рано відхиляє некоректні вхідні дані, вимагаючи непорожній, заповнений масив; повертає `false` для порожніх масивів
  або не-масивів.
- Корисно як перевірка перед виконанням операцій лише для буферів (наприклад, конкатенація, хешування, бінарні
  протоколи).

## Використання

### Синтаксис

Функція:

- `areBuffers(array)`

Параметри:

- `array`: Масив, який потрібно перевірити на наявність екземплярів буфера.

### Локальний імпорт функції

```ts
import { areBuffers } from "@type-check/guards";

const chunks: unknown[] = [Buffer.from("test"), Buffer.from("123")];

if (areBuffers(chunks)) {
  const combined = Buffer.concat(chunks);
  console.log(combined.toString("utf8"));
} else {
  throw new TypeError("Expected a non-empty array of Buffer instances");
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.areBuffers(array)`
