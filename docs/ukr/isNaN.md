# isNaN

## Опис

Визначає, чи є надане `value` значенням `NaN` типу `number` без перетворення рядків.

### Випадок використання

Валідуйте ненадійні або слабо типізовані вхідні дані (наприклад, API-пейлоади, значення форм, розпарсений JSON), щоб
виявити спеціальне значення `NaN` і явно його обробити, водночас вважаючи нечислові вхідні значення такими, що не є
`NaN`.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `isNaN`, коли потрібно виявити спеціальне числове значення `NaN`, водночас гарантуючи, що вхідне
> значення справді є `number` (без перетворення рядка на число).

### Переваги

- Перевіряє, чи є значення `NaN`, без приведення нечислових значень (наприклад, рядків) до чисел.
- Повертає `true` лише для значень, які одночасно мають тип `number` і є `NaN`.
- Безпечно для вхідних значень типу `unknown` і уникає хибнопозитивних результатів через неявні перетворення.

## Використання

### Синтаксис

Функція:

- `isNaN(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити, чи є воно `NaN` типу `number`.

### Локальний імпорт функції

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // true
console.log(isNaN(b)); // false
console.log(isNaN(c)); // false

if (isNaN(a)) {
  // a є числом і, зокрема, NaN
}
```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isNaN(value)`
