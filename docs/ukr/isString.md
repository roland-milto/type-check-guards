# isString

## Опис

`isString` визначає, чи є задане значення рядком.

### Випадок використання

Валідовуйте введення користувача, поля payload API або значення конфігурації під час виконання, щоб переконатися, що
значення є рядком, перш ніж застосовувати рядкові операції (наприклад, обрізання пробілів, розбиття, перетворення
регістру).

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `isString`, щоб валідовувати значення типу `unknown` або зі слабкою типізацією перед викликом рядкових
> методів; воно повертає `true` лише тоді, коли `typeof value === "string"`.

### Переваги

- Проста й швидка перевірка за допомогою `typeof`.
- Повертає передбачуваний булевий результат: `true` для рядків, інакше `false`.
- Працює як для порожніх, так і для непорожніх рядків.
- Корисно як легка runtime-перевірка перед виконанням операцій, специфічних для рядків.

## Використання

### Синтаксис

Функція:

- `isString(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити на рядковий тип.

### Локальний імпорт функції

```ts
import { isString } from "@type-check/guards";

const input: unknown = "Hello World";

if (isString(input)) {
  // тут input є рядком
  console.log(input.toUpperCase());
} else {
  console.log("Not a string");
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isString(value)`
