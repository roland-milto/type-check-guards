# isRegEx

## Опис

Визначає, чи є надане значення екземпляром `RegExp`.

### Випадок використання

Перевіряйте значення, надані користувачем або динамічні значення (наприклад, конфігурацію, корисне навантаження API,
вхідні дані плагінів), перш ніж трактувати їх як регулярний вираз.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `isRegEx`, щоб звузити значення типу `unknown` (або об’єднання типів) перед використанням властивостей
> чи методів, специфічних для RegExp; він повертає `true` лише для значень, які є екземплярами `RegExp`.

### Переваги

- Надає простий захисник типу під час виконання, щоб перевірити, чи є значення `RegExp`.
- Допомагає запобігти помилкам, коли код очікує регулярний вираз (наприклад, перед викликом `test`, `exec` або читанням
  `source`).
- Працює як із літералами регулярних виразів, так і з екземплярами, створеними через `new RegExp(...)`.
- Повертає чіткий булевий результат (`true`/`false`) без викидання винятків для вхідних значень, що не є регулярними
  виразами.

## Використання

### Синтаксис

Функція:

- `isRegEx(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити.

### Локальний імпорт функції

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  // input тут є RegExp
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isRegEx(value)`
