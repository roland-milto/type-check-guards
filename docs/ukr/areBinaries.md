# areBinaries

## Опис

Перевіряє, чи є надане значення непорожнім масивом коректних двійкових рядків, і повертає `true` лише якщо всі елементи
проходять валідацію.

### Випадок використання

Використовуйте `areBinaries`, коли отримуєте невідомий список (наприклад, із JSON, форм або API) і потрібно
переконатися, що це непорожній масив двійкових рядків перед його парсингом або обробкою.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `areBinaries`, щоб перевіряти невідомі вхідні дані перед перетворенням двійкових рядків на
> числа/BigInts; це гарантує, що масив непорожній і кожен елемент є коректним двійковим рядком.

### Переваги

- Перевіряє, що значення є непорожнім масивом, у якому кожен елемент є коректним двійковим рядком.
- Повертає простий булевий результат (`true`/`false`), придатний для гардiв, ранніх повернень і валідації введення.
- Запобігає подальшим помилкам парсингу, відхиляючи масиви, що містять будь-які недвійкові значення.

## Використання

### Синтаксис

Функція:

- `areBinaries(array)`

Параметри:

- `array`: Значення, яке потрібно перевірити.

### Локальний імпорт функції

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // true
console.log(areBinaries(b)); // false
console.log(areBinaries([])); // false
```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.areBinaries(array)`
