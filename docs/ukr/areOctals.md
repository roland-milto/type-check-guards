# areOctals

## Опис

`areOctals` визначає, чи є надане значення непорожнім масивом коректних вісімкових рядків.

### Випадок використання

Використовуйте `areOctals` під час валідації введення користувача, значень конфігурації або payload API, які мають
містити вісімкові літерали (наприклад, режими прав доступу до файлів на кшталт `0o755`), і ви хочете відхиляти порожні
масиви або будь-які некоректні елементи, повертаючи `false`.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `areOctals`, щоб переконатися, що у вас є непорожній `unknown[]`, де кожен елемент є коректним
> вісімковим рядком, перед перетворенням (наприклад, через `Number(...)` або власний парсинг).

### Переваги

- Перевіряє, що значення є непорожнім масивом, у якому кожен елемент є вісімковим рядком, повертаючи `true` лише тоді,
  коли всі елементи проходять перевірку.
- Швидко завершує перевірку: повертає `false`, щойно знайдено невісімковий елемент.
- Корисно як запобіжник перед парсингом або перетворенням вісімкових рядків, щоб уникнути помилок під час виконання та
  непослідовної обробки введення.

## Використання

### Синтаксис

Функція:

- `areOctals(array)`

Параметри:

- `array`: Значення, яке потрібно перевірити.

### Локальний імпорт функції

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value — непорожній масив вісімкових рядків
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.areOctals(array)`
