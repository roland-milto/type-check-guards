# isOctal

## Опис

Визначає, чи є значення коректним рядком вісімкового літерала (наприклад, `0o755`).

### Випадок використання

Перевіряйте введення користувача або значення конфігурації, які мають бути задані як рядок вісімкового літерала (
наприклад, режими прав доступу до файлів на кшталт `0o644`), перед їхнім парсингом або перетворенням.

> **Примітка для користувачів TypeScript:**
>
> `isOctal` — це захист типу (`value is string`). Після результату `true` TypeScript звужує перевірену змінну до
`string`.

### Переваги

- Забезпечує строгий захист типу: повертає `true` лише тоді, коли вхідне значення є рядком, що відповідає формату
  вісімкового літерала.
- Відхиляє порожні рядки та рядки з початковими/кінцевими пробілами (ASCII керувальні символи/пробіли), зменшуючи
  кількість випадкових збігів.
- Підтримує необов’язковий знак і не залежить від регістру для префікса `0o`/`0O`.
- Поблажливий до не-рядкових вхідних значень, повертаючи `false` замість викидання помилки.

## Використання

### Синтаксис

Функція:

- `isOctal(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити.

### Локальний імпорт функції

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); // true
console.log(isOctal(b)); // true
console.log(isOctal(c)); // false
console.log(isOctal(d)); // false

if (isOctal(a)) {
  // a тут є рядком
  const normalized = a.toLowerCase();
  console.log(normalized);
}
```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isOctal(value)`
