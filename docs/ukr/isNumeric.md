# isNumeric

## Опис

`isNumeric` визначає, чи вважається задане `value` числовим, порівнюючи його визначений тип із `NUMERIC_TYPES`.

### Випадок використання

Використовуйте `isNumeric` для валідації вхідних даних (наприклад, API payloads, значень форм, конфігурації) перед
виконанням числових операцій, а також щоб послідовно приймати числоподібні типи (такі як `BigInt`) відповідно до
`NUMERIC_TYPES`.

> **Примітка для користувачів TypeScript:**
>
> `isNumeric` — це предикат, що повертає булеве значення; розглядайте його як перевірку під час виконання, чи належить
> значення до визначеного бібліотекою набору числових типів.

### Переваги

- Використовує `getTypeOf` разом із `NUMERIC_TYPES`, щоб централізувати логіку виявлення числових типів і підтримувати
  узгоджені перевірки в межах кодової бази.
- Повертає просте булеве значення (`true`/`false`) для зручного розгалуження та використання в стилі guard.
- Підтримує кілька числових представлень (наприклад, `number`, `BigInt`), як визначено в `NUMERIC_TYPES`.

## Використання

### Синтаксис

Функція:

- `isNumeric(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити на числовий тип.

### Локальний імпорт функції

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    // v вважається числовим згідно з правилами типізації бібліотеки
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isNumeric(value)`
