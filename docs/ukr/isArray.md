# isArray

## Опис

`isArray` перевіряє, чи є задане значення масивом, і повертає `true`, якщо так, інакше `false`.

### Випадок використання

Валідувати невідомі дані (наприклад, розпарсений JSON або відповіді API), щоб переконатися, що значення є масивом, перш
ніж виконувати ітерацію, індексацію або звертатися до `.length`.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `isArray`, коли потрібна перевірка масивів під час виконання; вона повертає булеве значення і її
> безпечно викликати зі значеннями типу `unknown`.

### Переваги

- Використовує вбудований `Array.isArray` для надійного визначення масивів у різних контекстах виконання (наприклад, в
  iframe).
- Повертає простий булевий результат (`true`/`false`), придатний для гардiв і розгалуження логіки.
- Працює з будь-яким типом вхідних даних, оскільки параметр має тип `unknown`.

## Використання

### Синтаксис

Функція:

- `isArray(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити.

### Локальний імпорт функції

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  // input є масивом під час виконання
  console.log(input.length);
} else {
  console.log("Not an array");
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isArray(value)`
