# isDecimal

## Опис

`isDecimal` перевіряє, чи є значення десятковим рядковим поданням без початкових/кінцевих пробілів і з коректним
десятковим форматом.

### Випадок використання

Валідуйте поля форм, корисні навантаження API або значення конфігурації, які мають бути надані як десятковий рядок (за
потреби зі знаком) без будь-яких пробілів навколо, перед розбором або збереженням.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `isDecimal`, щоб перевіряти введення користувача перед перетворенням (наприклад, за допомогою
`Number(value)`), особливо коли пробіли потрібно відхиляти.

### Переваги

- Суворо перевіряє, що вхідне значення є рядком і відповідає шаблону десяткового літерала.
- Відхиляє початкові та кінцеві пробіли (включно з керівними символами), щоб уникнути неоднозначного розбору.
- Виконує швидкі попередні перевірки (перевірка типу та першого/останнього символу) перед запуском регулярного виразу.
- Повертає простий булевий результат (`true`/`false`), придатний для гардiв і валідації введення.

## Використання

### Синтаксис

Функція:

- `isDecimal(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити на відповідність формату десяткового рядка.

### Локальний імпорт функції

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v тут є рядком (перевірено під час виконання)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isDecimal(value)`
