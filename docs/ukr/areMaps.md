# areMaps

## Опис

`areMaps` визначає, чи є заданий масив непорожнім і чи всі його елементи є екземплярами `Map`.

### Випадок використання

Перевіряйте невідомий ввід (наприклад, після парсингу JSON, із зовнішніх API або динамічних джерел), перш ніж трактувати
його як непорожній список об’єктів `Map`.

> **Примітка для користувачів TypeScript:**
>
> Повертає `false` для порожнього масиву; повертає `true` лише тоді, коли масив заповнений і кожен елемент є `Map`.

### Переваги

- Гарантує, що кожен елемент є екземпляром `Map`, повертаючи `true` лише тоді, коли перевірку проходить увесь масив.
- Навмисно відхиляє порожні масиви, запобігаючи випадковому прийняттю «відсутності даних» як коректного вводу.
- Корисно як захисна перевірка перед виконанням операцій, специфічних для `Map` (наприклад, `.get()`, `.set()`,
  ітерація) над колекцією.

## Використання

### Синтаксис

Функція:

- `areMaps(array)`

Параметри:

- `array`: Масив для перевірки.

### Локальний імпорт функції

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // items гарантовано є непорожнім масивом екземплярів Map під час виконання
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // false для: порожніх масивів або масивів, що містять будь-яке значення, яке не є Map
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.areMaps(array)`
