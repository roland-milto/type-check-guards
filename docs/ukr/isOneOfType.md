# isOneOfType

## Опис

`isOneOfType` визначає, чи відповідає задане `value` принаймні одному з наданих рядків типів, повертаючи `true`, якщо
знайдено будь-який збіг, і `false` в іншому разі.

### Випадок використання

Валідуйте слабо типізовані або зовнішні дані (наприклад, розпарсений JSON, параметри запиту), дозволяючи кілька
прийнятних типів під час виконання (наприклад, `number` або `string`) перед продовженням подальшої логіки.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `isOneOfType`, коли вам потрібна перевірка під час виконання, що значення відповідає будь-якому з
> кількох дозволених типів; вона повертає `true`, якщо збігається принаймні один тип, інакше `false`.

### Переваги

- Перевіряє значення на відповідність кільком дозволеним типам за один виклик, повертаючи `true` при першому збігу.
- Працює з вхідними даними типу `unknown`, що робить його корисним на межах виконання (наприклад, зовнішні дані,
  введення користувача).
- Надає простий булевий результат (`true`/`false`), який добре поєднується з умовною логікою та ранніми поверненнями.

## Використання

### Синтаксис

Функція:

- `isOneOfType(value, types)`

Параметри:

- `value`: Значення, яке потрібно перевірити на відповідність зазначеним типам.
- `types`: Масив рядків типів, що представляють потенційні типи значення.

### Локальний імпорт функції

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // input є об’єктом під час виконання
}

console.log(isOneOfType(3, ["number", "string"])); // true
console.log(isOneOfType("hello", ["number", "boolean"])); // false

```

### Глобальний імпорт об’єкта

```ts

```

- `Type.isOneOfType(value, types)`
