# areSymbols

## Опис

Перевіряє, чи є вхідні дані заповненим масивом, елементи якого всі є символами, повертаючи `true` або `false`.

### Випадок використання

Перевірити, що поле конфігурації (наприклад, список унікальних ключів, представлених символами) є непорожнім масивом,
який містить лише символи, перш ніж використовувати його в API, що вимагають `symbol[]`.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `areSymbols`, щоб перевіряти невідомі вхідні дані перед тим, як трактувати їх як `symbol[]`; вона
> повертає `false` для не-масивів і порожніх масивів.

### Переваги

- Повертає `true` лише тоді, коли вхідні дані є непорожнім масивом і кожен елемент є символом.
- Запобігає хибнопозитивним результатам, відхиляючи не-масиви та порожні масиви через внутрішню перевірку заповненого
  масиву.
- Корисно як захисник типів під час виконання (runtime type guard) для валідації списків, що містять лише символи, перед
  подальшою обробкою.

## Використання

### Синтаксис

Функція:

- `areSymbols(array)`

Параметри:

- `array`: Масив, який потрібно перевірити на наявність елементів-символів.

### Локальний імпорт функції

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  // a є масивом, що містить лише символи, під час виконання
  const first = a[0];
  console.log(typeof first); // "symbol"
}

console.log(areSymbols(b)); // false
```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.areSymbols(array)`
