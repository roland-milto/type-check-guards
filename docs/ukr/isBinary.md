# isBinary

## Опис

`isBinary` визначає, чи є значення двійковим рядком (за потреби з префіксом `0b`/`0B`) і повертає `true` або `false`.

### Випадок використання

Валідуйте рядки, надані користувачем (наприклад, поля форм, аргументи CLI, значення конфігурації), щоб переконатися, що
вони містять лише двійкові цифри, за потреби з префіксом `0b`/`0B`, перед подальшою обробкою.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `isBinary` як захисник типу перед парсингом або перетворенням рядка на `BigInt`/`Number`, щоб уникнути
> некоректного вводу.

### Переваги

- Приймає двійкові рядки з префіксом `0b`/`0B` або без нього.
- Відхиляє порожні рядки та рядки з початковими/кінцевими пробільними символами (ASCII ≤ 32).
- Повертає `true`/`false` без викидання винятків, що робить функцію безпечною для невідомих вхідних даних.

## Використання

### Синтаксис

Функція:

- `isBinary(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити.

### Локальний імпорт функції

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // true
const b = isBinary("1010");   // true
const c = isBinary("0b1020"); // false
const d = isBinary(0b1010);     // false

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isBinary(value)`
