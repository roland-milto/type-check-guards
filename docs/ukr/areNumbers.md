# areNumbers

## Опис

`areNumbers` перевіряє, чи є значення непорожнім масивом, у якому всі елементи — числа.

### Випадок використання

Валідуйте дані, надані користувачем або API, щоб переконатися, що це непорожній масив чисел перед обчисленням сум,
середніх значень або інших числових агрегацій.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `areNumbers`, щоб валідовувати невідомі масиви перед виконанням числових обчислень; вона повертає
`false` для порожніх масивів і для масивів, що містять будь-яке нечислове значення.

### Переваги

- Повертає `true` лише тоді, коли вхідне значення є непорожнім масивом і кожен елемент є числом.
- Запобігає хибнопозитивним результатам, відхиляючи порожні масиви та вхідні значення, що не є масивами.
- Корисно як перевірка перед числовими операціями (наприклад, підсумовуванням, обчисленням середнього), щоб уникнути
  помилок під час виконання.

## Використання

### Синтаксис

Функція:

- `areNumbers(array)`

Параметри:

- `array`: Масив, який потрібно перевірити на наявність числових елементів.

### Локальний імпорт функції

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.areNumbers(array)`
