# isIndexFound

## Опис

`isIndexFound` визначає, чи є задане значення невід’ємним цілим числом, що означає, що індекс знайдено.

### Випадок використання

Перевірити, що результат пошуку є придатним індексом (ціле число `>= 0`) перед індексацією масиву або рядка, запобігаючи
випадковому використанню `-1` чи нечислових значень.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `isIndexFound` після операцій на кшталт `indexOf`, `findIndex` або власних пошуків, де `-1` (або інші
> некоректні значення) можуть означати «не знайдено». Коли функція повертає `true`, значення є числом і його безпечно
> використовувати як індекс масиву/рядка.

### Переваги

- Надає простий захисник типу (type guard), щоб визначити, чи було знайдено індекс, перевіряючи, що значення є
  невід’ємним цілим числом.
- Повертає `true` лише для коректних індексоподібних значень (цілі числа `>= 0`), відхиляючи від’ємні, нецілі та
  нечислові значення.
- Допомагає уникати помилок «на одиницю» та помилок із сигнальними значеннями під час роботи з API, які повертають `-1`
  для «не знайдено».

## Використання

### Синтаксис

Функція:

- `isIndexFound(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити на те, чи є воно невід’ємним цілим числом.

### Локальний імпорт функції

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // idx тут є числом і є >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// Типове використання з indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isIndexFound(value)`
