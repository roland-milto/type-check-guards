# Посилання на функції

## Функції

| Функція                                     | Опис                                                                                                                                                                                                        |
|---------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [areArrays](areArrays.md)                   | `areArrays` визначає, чи є значення заповненим двовимірним масивом, елементи якого всі є масивами.                                                                                                          |
| [areBigInts](areBigInts.md)                 | `areBigInts` визначає, чи є значення непорожнім масивом, що містить лише значення `bigint`.                                                                                                                 |
| [areBinaries](areBinaries.md)               | Перевіряє, чи є надане значення непорожнім масивом коректних двійкових рядків, і повертає `true` лише якщо всі елементи проходять валідацію.                                                                |
| [areBooleans](areBooleans.md)               | `areBooleans` перевіряє, чи містить заданий непорожній масив лише булеві значення, повертаючи `true`, якщо так, і `false` в іншому випадку.                                                                 |
| [areBuffers](areBuffers.md)                 | `areBuffers` перевіряє, чи є надане значення непорожнім, заповненим масивом, у якому кожен елемент є `Buffer`, повертаючи `true` у такому разі та `false` інакше.                                           |
| [areDates](areDates.md)                     | `areDates` визначає, чи заданий масив заповнений і містить лише об’єкти `Date`, повертаючи `true` лише тоді, коли всі елементи є коректними датами.                                                         |
| [areDecimals](areDecimals.md)               | Перевіряє, чи всі елементи масиву є десятковими числами та чи масив заповнений, повертаючи `true` або `false`.                                                                                              |
| [areEqual](areEqual.md)                     | `areEqual` перевіряє, чи всі елементи в масиві дорівнюють заданому очікуваному значенню, повертаючи `true` лише для непорожніх масивів, у яких кожен елемент збігається.                                    |
| [areErrors](areErrors.md)                   | Перевіряє, чи масив є непорожнім і містить лише об’єкти `Error`, повертаючи `true` або `false`.                                                                                                             |
| [areFalse](areFalse.md)                     | `areFalse` перевіряє, чи всі елементи в наданому масиві є строго булевим значенням `false`.                                                                                                                 |
| [areFilledArrays](areFilledArrays.md)       | `areFilledArrays` перевіряє, чи двовимірний масив не порожній і чи всі його підмасиви не порожні.                                                                                                           |
| [areFinite](areFinite.md)                   | `areFinite` перевіряє, чи є значення непорожнім масивом, елементи якого всі є скінченними числами, повертаючи `true` у такому разі та `false` в іншому.                                                     |
| [areFloats](areFloats.md)                   | `areFloats` перевіряє, чи заданий масив заповнений і чи всі його елементи є числами з плаваючою комою.                                                                                                      |
| [areHexadecimals](areHexadecimals.md)       | Перевіряє, чи всі елементи в масиві є шістнадцятковими рядками, повертаючи `true` лише для непорожніх масивів, у яких кожен елемент є валідним.                                                             |
| [areIndexesFound](areIndexesFound.md)       | `areIndexesFound` перевіряє, чи є значення непорожнім масивом, елементи якого всі є коректними індексами, повертаючи `true`, якщо це так, і `false` в іншому разі.                                          |
| [areIntegers](areIntegers.md)               | `areIntegers` визначає, чи всі елементи в заданому масиві є цілими числами, повертаючи `true`, якщо так, і `false` в іншому разі.                                                                           |
| [areJson](areJson.md)                       | Перевіряє, чи всі елементи масиву є JSON-рядками, повертаючи `true` лише якщо масив заповнений і кожен елемент є коректним JSON; інакше повертає `false`.                                                   |
| [areMaps](areMaps.md)                       | `areMaps` визначає, чи є заданий масив непорожнім і чи всі його елементи є екземплярами `Map`.                                                                                                              |
| [areNaNs](areNaNs.md)                       | `areNaNs` перевіряє, чи всі елементи в масиві є `NaN`, і повертає `true` лише якщо кожен елемент є `NaN`.                                                                                                   |
| [areNullOrUndefined](areNullOrUndefined.md) | Перевіряє, чи всі елементи в заданому масиві є `null` або `undefined`.                                                                                                                                      |
| [areNumbers](areNumbers.md)                 | `areNumbers` перевіряє, чи є значення непорожнім масивом, у якому всі елементи — числа.                                                                                                                     |
| [areNumerics](areNumerics.md)               | `areNumerics` перевіряє, чи є значення непорожнім масивом, у якому всі елементи є числовими.                                                                                                                |
| [areObjects](areObjects.md)                 | `areObjects` перевіряє, чи містить наданий заповнений масив лише об’єкти.                                                                                                                                   |
| [areOctals](areOctals.md)                   | `areOctals` визначає, чи є надане значення непорожнім масивом коректних вісімкових рядків.                                                                                                                  |
| [areOfType](areOfType.md)                   | Перевіряє, чи всі елементи в заданому `array` мають вказаний `type`.                                                                                                                                        |
| [areOneOfType](areOneOfType.md)             | `areOneOfType` перевіряє, чи всі елементи в непорожньому масиві належать до одного із зазначених типів під час виконання.                                                                                   |
| [arePlainObjects](arePlainObjects.md)       | Перевіряє, чи всі елементи масиву є простими об’єктами, повертаючи `true` лише якщо кожен елемент відповідає критерію.                                                                                      |
| [arePrimitives](arePrimitives.md)           | `arePrimitives` визначає, чи всі елементи в наданому непорожньому масиві є примітивними типами.                                                                                                             |
| [arePromises](arePromises.md)               | `arePromises` визначає, чи всі елементи в масиві є екземплярами `Promise`.                                                                                                                                  |
| [areRegExes](areRegExes.md)                 | `areRegExes` перевіряє, чи є значення заповненим масивом, що містить лише об’єкти `RegExp`.                                                                                                                 |
| [areSets](areSets.md)                       | Перевіряє, чи містить заданий непорожній масив лише екземпляри `Set`, повертаючи `true`, якщо так, і `false` в іншому разі.                                                                                 |
| [areStreams](areStreams.md)                 | `areStreams` визначає, чи є значення заповненим масивом, у якому кожен елемент є `Stream`.                                                                                                                  |
| [areStrings](areStrings.md)                 | `areStrings` перевіряє, чи масив є непорожнім і чи всі його елементи є рядками, повертаючи `true` лише в цьому випадку.                                                                                     |
| [areSymbols](areSymbols.md)                 | Перевіряє, чи є вхідні дані заповненим масивом, елементи якого всі є символами, повертаючи `true` або `false`.                                                                                              |
| [areTrue](areTrue.md)                       | Перевіряє, чи непорожній масив містить лише булеві значення `true`.                                                                                                                                         |
| [areUndefined](areUndefined.md)             | `areUndefined` перевіряє, чи кожен елемент у наданому масиві є `undefined`.                                                                                                                                 |
| [areValidDates](areValidDates.md)           | Визначає, чи є масив непорожнім і чи складається він повністю з валідних об’єктів `Date`.                                                                                                                   |
| [areWeakMaps](areWeakMaps.md)               | `areWeakMaps` перевіряє, чи є значення непорожнім масивом, у якому кожен елемент — це `WeakMap`, повертаючи `true` лише в цьому випадку та `false` в інших.                                                 |
| [areWeakSets](areWeakSets.md)               | Перевіряє, чи є вхідні дані непорожнім масивом, у якому кожен елемент є `WeakSet`, і повертає `true` лише в цьому випадку.                                                                                  |
| [getTypeOf](getTypeOf.md)                   | `getTypeOf` повертає детальну, людиночитну мітку типу для заданого значення, включно з уточненими числовими типами та конкретними видами об’єктів.                                                          |
| [isArray](isArray.md)                       | `isArray` перевіряє, чи є задане значення масивом, і повертає `true`, якщо так, інакше `false`.                                                                                                             |
| [isBigInt](isBigInt.md)                     | `isBigInt` перевіряє, чи має задане значення тип `bigint`, повертаючи `true` для примітивів BigInt і `false` в інших випадках.                                                                              |
| [isBinary](isBinary.md)                     | `isBinary` визначає, чи є значення двійковим рядком (за потреби з префіксом `0b`/`0B`) і повертає `true` або `false`.                                                                                       |
| [isBoolean](isBoolean.md)                   | Визначає, чи є задане значення типу `boolean`.                                                                                                                                                              |
| [isBuffer](isBuffer.md)                     | Перевіряє, чи є значення Node.js `Buffer`, і повертає `true` або `false`.                                                                                                                                   |
| [isDate](isDate.md)                         | `isDate` визначає, чи є надане значення `Date`, повертаючи `true` для екземплярів `Date` і `false` в інших випадках.                                                                                        |
| [isDecimal](isDecimal.md)                   | `isDecimal` перевіряє, чи є значення десятковим рядковим поданням без початкових/кінцевих пробілів і з коректним десятковим форматом.                                                                       |
| [isEmpty](isEmpty.md)                       | Визначає, чи є задане значення порожнім, повертаючи `true` для `null`, `undefined`, порожніх/пробільних рядків, порожніх масивів, порожніх `Map`/`Set` або об’єктів без власних перелічуваних властивостей. |
| [isError](isError.md)                       | Перевіряє, чи є задане `value` екземпляром `Error`.                                                                                                                                                         |
| [isFalse](isFalse.md)                       | `isFalse` перевіряє, чи є задане значення строго рівним булевому літералу `false`.                                                                                                                          |
| [isFilledArray](isFilledArray.md)           | Перевіряє, чи є `value` масивом із принаймні одним елементом, повертаючи `true` або `false`.                                                                                                                |
| [isFinite](isFinite.md)                     | Визначає, чи є задане `value` скінченним `number`.                                                                                                                                                          |
| [isFloat](isFloat.md)                       | `isFloat` визначає, чи є задане `value` скінченним числом з плаваючою комою (тобто `number`, який не є цілим числом).                                                                                       |
| [isHexadecimal](isHexadecimal.md)           | `isHexadecimal` перевіряє, чи є задане значення шістнадцятковим рядковим літералом з обов’язковим префіксом `0x`/`0X`.                                                                                      |
| [isIndexFound](isIndexFound.md)             | `isIndexFound` визначає, чи є задане значення невід’ємним цілим числом, що означає, що індекс знайдено.                                                                                                     |
| [isInteger](isInteger.md)                   | Визначає, чи є задане `value` безпечним цілим числом.                                                                                                                                                       |
| [isMap](isMap.md)                           | Перевіряє, чи є задане `value` об’єктом `Map`, повертаючи `true`, якщо так, і `false` в іншому разі.                                                                                                        |
| [isNaN](isNaN.md)                           | Визначає, чи є надане `value` значенням `NaN` типу `number` без перетворення рядків.                                                                                                                        |
| [isNull](isNull.md)                         | Визначає, чи є надане `value` значенням `null`.                                                                                                                                                             |
| [isNullOrUndefined](isNullOrUndefined.md)   | Перевіряє, чи є задане значення `null` або `undefined`.                                                                                                                                                     |
| [isNumber](isNumber.md)                     | `isNumber` перевіряє, чи є значення скінченним числом, відмінним від `NaN`.                                                                                                                                 |
| [isNumeric](isNumeric.md)                   | `isNumeric` визначає, чи вважається задане `value` числовим, порівнюючи його визначений тип із `NUMERIC_TYPES`.                                                                                             |
| [isObject](isObject.md)                     | Визначає, чи є задане `value` об’єктом (`object`) (за винятком `null`).                                                                                                                                     |
| [isOctal](isOctal.md)                       | Визначає, чи є значення коректним рядком вісімкового літерала (наприклад, `0o755`).                                                                                                                         |
| [isOfType](isOfType.md)                     | Визначає, чи відповідає задане `value` вказаному рядку типу, використовуючи `typeof` для примітивів і резервний механізм для складних типів.                                                                |
| [isOneOfType](isOneOfType.md)               | `isOneOfType` визначає, чи відповідає задане `value` принаймні одному з наданих рядків типів, повертаючи `true`, якщо знайдено будь-який збіг, і `false` в іншому разі.                                     |
| [isPlainObject](isPlainObject.md)           | Перевіряє, чи є задане `value` звичайним об’єктом, і повертає `true`, якщо так, інакше `false`.                                                                                                             |
| [isPrimitive](isPrimitive.md)               | `isPrimitive` визначає, чи є задане значення примітивом (`null`, `undefined`, `boolean`, `number`, `string`, `bigint`, `symbol`).                                                                           |
| [isPromise](isPromise.md)                   | Визначає, чи є задане значення `Promise`.                                                                                                                                                                   |
| [isRegEx](isRegEx.md)                       | Визначає, чи є надане значення екземпляром `RegExp`.                                                                                                                                                        |
| [isSet](isSet.md)                           | Визначає, чи є задане значення `Set`.                                                                                                                                                                       |
| [isStream](isStream.md)                     | `isStream` перевіряє, чи є задане значення об’єктом потоку (схожим на потік Node.js, `ReadableStream` або `WritableStream`).                                                                                |
| [isString](isString.md)                     | `isString` визначає, чи є задане значення рядком.                                                                                                                                                           |
| [isSymbol](isSymbol.md)                     | `isSymbol` визначає, чи має задане значення тип `symbol`, повертаючи `true` для символів і `false` в інших випадках.                                                                                        |
| [isTrue](isTrue.md)                         | `isTrue` визначає, чи є задане значення строго рівним `true`.                                                                                                                                               |
| [isUndefined](isUndefined.md)               | Перевіряє, чи є задане значення `undefined`.                                                                                                                                                                |
| [isValidDate](isValidDate.md)               | `isValidDate` перевіряє, чи є задане значення валідним об’єктом `Date`, і повертає `true` лише для справжніх, не невалідних дат.                                                                            |
| [isWeakMap](isWeakMap.md)                   | Визначає, чи є задане `value` екземпляром `WeakMap`.                                                                                                                                                        |
