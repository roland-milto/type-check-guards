# areArrays

## Опис

`areArrays` визначає, чи є значення заповненим двовимірним масивом, елементи якого всі є масивами.

### Випадок використання

Використовуйте `areArrays` для валідації табличних або матричних вхідних даних (наприклад, рядків CSV, даних сітки або
згрупованих списків) перед виконанням операцій із рядками/стовпцями; функція повертає `false`, якщо вхідні дані не є
масивом, є порожніми або містять будь-який елемент, що не є масивом.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `areArrays`, коли потрібно переконатися, що значення є непорожнім 2D масивом і що кожен рядок є
> масивом, перш ніж ітеруватися або звертатися за індексом у вкладених масивах.

### Переваги

- Перевіряє, що вхідні дані є непорожнім двовимірним масивом, у якому кожен елемент є масивом.
- Повертає простий булевий результат (`true`/`false`), придатний для гардiв і ранніх виходів.
- Допомагає запобігти помилкам виконання, коли подальший код припускає операції з вкладеними масивами (наприклад, мапінг
  рядків).

## Використання

### Синтаксис

Функція:

- `areArrays(array)`

Параметри:

- `array`: Вхідні дані, які потрібно перевірити.

### Локальний імпорт функції

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value — це двовимірний масив, елементами якого є масиви
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.areArrays(array)`
