# areFloats

## Опис

`areFloats` перевіряє, чи заданий масив заповнений і чи всі його елементи є числами з плаваючою комою.

### Випадок використання

Використовуйте `areFloats`, коли отримуєте `unknown[]` (наприклад, з JSON, параметрів запиту або зовнішніх API) і
потрібно переконатися, що це заповнений масив, у якому кожен елемент є числом з плаваючою комою, перш ніж запускати
числову логіку, як-от обчислення середнього, інтерполяцію або статистичні розрахунки.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `areFloats`, щоб захистити `unknown[]` перед тим, як трактувати його як `number[]`, що містить лише
> числа з плаваючою комою; функція повертає `false` для порожніх масивів і для будь-якого елемента, що не є float.

### Переваги

- Повертає `true` лише тоді, коли вхідні дані — це непорожній масив і кожен елемент є числом з плаваючою комою.
- Швидко завершує перевірку: повертає `false`, щойно знаходить елемент, що не є числом з плаваючою комою.
- Допомагає валідувати невідомі вхідні дані перед виконанням обчислень, специфічних для чисел з плаваючою комою.

## Використання

### Синтаксис

Функція:

- `areFloats(array)`

Параметри:

- `array`: Масив для перевірки на наявність елементів типу float.

### Локальний імпорт функції

```ts
import { areFloats } from "@type-check/guards";

const a: unknown[] = [3.14, 2.71, 1.0];
const b: unknown[] = [3.14, 2];
const c: unknown[] = [];

console.log(areFloats(a)); // істина
console.log(areFloats(b)); // хибність
console.log(areFloats(c)); // хибність

function sumFloats(values: unknown): number | null {
  if (!Array.isArray(values) || !areFloats(values)) return null;
  return values.reduce((acc, n) => acc + n, 0);
}

console.log(sumFloats([0.5, 1.25])); // 1.75
console.log(sumFloats([1, 2])); // null
```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.areFloats(array)`
