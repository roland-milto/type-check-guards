# arePlainObjects

## Опис

Перевіряє, чи всі елементи масиву є простими об’єктами, повертаючи `true` лише якщо кожен елемент відповідає критерію.

### Випадок використання

Валідуйте зовнішні або нетипізовані дані (наприклад, розпарсений JSON, payload-и API, надсилання форм), щоб
переконатися, що ви отримали непорожній масив, у якому кожен запис є простим об’єктом, перш ніж ітеруватися та читати
властивості.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `arePlainObjects`, щоб валідувати невідомі вхідні дані перед тим, як трактувати їх як
`Record<string, unknown>[]` (або як суворішу форму об’єкта) у TypeScript.

### Переваги

- Гарантує, що кожен елемент у вхідному масиві є простим об’єктом, повертаючи `true` лише тоді, коли всі елементи
  відповідають умові.
- Рано відхиляє некоректні вхідні дані (не масиви або порожні масиви), повертаючи `false`.
- Вважає валідними простими об’єктами як об’єкти-літерали, так і об’єкти `Object.create(null)`.

## Використання

### Синтаксис

Функція:

- `arePlainObjects(array)`

Параметри:

- `array`: Масив, який потрібно перевірити на наявність елементів, що є простими об’єктами.

### Локальний імпорт функції

```ts
import { arePlainObjects } from "@type-check/guards";

const a = arePlainObjects([{ a: 1 }, { b: 2 }]); // істина
const b = arePlainObjects([{}, Object.create(null)]); // істина
const c = arePlainObjects([{ a: 1 }, 2 as unknown]); // хибність
const d = arePlainObjects([] as unknown[]); // хибність
```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.arePlainObjects(array)`
