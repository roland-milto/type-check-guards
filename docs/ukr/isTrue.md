# isTrue

## Опис

`isTrue` визначає, чи є задане значення строго рівним `true`.

### Випадок використання

Використовуйте `isTrue` для валідації прапорців, перемикачів функцій або значень конфігурації, де має прийматися лише
літерал `true`, а все інше потрібно трактувати як `false`.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `isTrue`, коли потрібно приймати лише булевий літерал `true`, а не просто truthy-значення.

### Переваги

- Забезпечує сувору перевірку булевого літерала `true` (без приведення типів).
- Допомагає відрізняти `true` від truthy-значень на кшталт `1`, `"true"` або `{}`.
- Проста, передбачувана поведінка, придатна для гардiв і конвеєрів валідації.

## Використання

### Синтаксис

Функція:

- `isTrue(value)`

Параметри:

- `value`: Значення для перевірки.

### Локальний імпорт функції

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // істина
const b = isTrue(1);         // хибність
const c = isTrue("true");   // хибність

if (isTrue(a)) {
  // тут a є істинним
}
```

### Глобальний імпорт об’єкта
