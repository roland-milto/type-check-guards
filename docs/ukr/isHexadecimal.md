# isHexadecimal

## Опис

`isHexadecimal` перевіряє, чи є задане значення шістнадцятковим рядковим літералом з обов’язковим префіксом `0x`/`0X`.

### Випадок використання

Використовуйте `isHexadecimal` для валідації значень конфігурації, полів корисного навантаження API або аргументів CLI,
які мають бути надані як шістнадцяткові рядкові літерали (наприклад, ідентифікатори, маски або адреси) і не повинні
містити пробілів навколо.

> **Примітка для користувачів TypeScript:**
>
> Використовуйте `isHexadecimal`, коли потрібно перевірити введення користувача або серіалізовані дані як строгий
> шістнадцятковий рядковий літерал (включно з префіксом `0x`/`0X`) перед розбором або перетворенням.

### Переваги

- Перевіряє, що значення є рядком і відповідає строгому формату шістнадцяткового літерала (вимагає префікс `0x`/`0X`).
- Відхиляє рядки з початковими або кінцевими пробілами, допомагаючи уникнути випадкового прийняття введення з
  відступами.
- Підтримує необов’язковий знак і не залежить від регістру для префікса та цифр, передбачувано повертаючи `true`/
  `false`.

## Використання

### Синтаксис

Функція:

- `isHexadecimal(value)`

Параметри:

- `value`: Значення, яке потрібно перевірити.

### Локальний імпорт функції

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // true
isHexadecimal("-0Xff"); // true
isHexadecimal("1A2B"); // false (відсутній префікс)
isHexadecimal(" 0x1A2B"); // false (початкові пробіли)
isHexadecimal(0x1a2b); // false (не рядок)
```

### Глобальний імпорт об’єкта

Щоб імпортувати функції як глобальні методи об’єкта, використовуйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступний метод буде доступний глобально:

- `Type.isHexadecimal(value)`
