# isNull

## விளக்கம்

வழங்கப்பட்ட `value` என்பது `null` ஆக உள்ளதா என்பதைத் தீர்மானிக்கிறது.

### பயன்பாட்டு நிகழ்வு

`null` என்பது அர்த்தமுள்ள sentinel மதிப்பாக இருக்கும் மற்றும் `undefined` அல்லது பிற மதிப்புகளிலிருந்து வேறுபடையாக
கையாளப்பட வேண்டிய உள்ளீடுகள் அல்லது API payload புலங்களைச் சரிபார்க்க `isNull`-ஐ பயன்படுத்துங்கள்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `undefined` மற்றும் பிற falsy மதிப்புகளிலிருந்து `null`-ஐ வேறுபடுத்த வேண்டிய போது `isNull`-ஐ பயன்படுத்துங்கள்; இது
`null` க்கு மட்டும் `true` திருப்புகிறது.

### நன்மைகள்

- `undefined` உடன் குழப்பாமல், `null`-ஐ துல்லியமாகச் சரிபார்க்கிறது.
- `unknown`-ஐ ஏற்றுக்கொள்வதால், எந்த உள்ளீட்டு வகைக்கும் நம்பகமாக வேலை செய்கிறது.
- எளிமையானது, வேகமானது, பக்கவிளைவுகள் இல்லாதது; `true` அல்லது `false` மட்டுமே திருப்புகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isNull(value)`

அளவுருக்கள்:

- `value`: `null` ஆக உள்ளதா என்பதைச் சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isNull } from "@type-check/guards";

const a: unknown = null;
const b: unknown = undefined;

console.log(isNull(a)); // உண்மை
console.log(isNull(b)); // பொய்

if (isNull(a)) {
  // இங்கே a null ஆக உள்ளது
}
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isNull(value)`
