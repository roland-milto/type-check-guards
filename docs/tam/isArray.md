# isArray

## விளக்கம்

`isArray` கொடுக்கப்பட்ட மதிப்பு ஒரு வரிசையா என்பதைச் சரிபார்த்து, அது வரிசையாக இருந்தால் `true`-ஐ, இல்லையெனில் `false`-ஐ
திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

அறியப்படாத தரவை (எ.கா., parse செய்யப்பட்ட JSON அல்லது API பதில்கள்) சரிபார்த்து, மீளச்சுழற்சி (iterate) செய்வதற்கு,
index செய்வதற்கு, அல்லது `.length`-ஐ அணுகுவதற்கு முன் ஒரு மதிப்பு வரிசை என்பதை உறுதிப்படுத்துங்கள்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> வரிசைகளுக்கான runtime சரிபார்ப்பு தேவைப்படும் போது `isArray`-ஐ பயன்படுத்துங்கள்; இது boolean-ஐ திருப்புகிறது மற்றும்
`unknown` மதிப்புகளுடன் அழைப்பது பாதுகாப்பானது.

### நன்மைகள்

- வேறு ரீயலம்கள் (எ.கா., iframes) முழுவதும் நம்பகமான வரிசை கண்டறிதலுக்காக உட்பொதிந்த `Array.isArray`-ஐ பயன்படுத்துகிறது.
- காவல்கள் (guards) மற்றும் கிளைபிரிப்பு (branching) தர்க்கத்திற்கு ஏற்ற எளிய boolean முடிவை (`true`/`false`)
  திருப்புகிறது.
- அளவுரு `unknown` என்பதால் எந்த உள்ளீட்டு வகையுடனும் வேலை செய்கிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isArray(value)`

அளவுருக்கள்:

- `value`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  // input இயக்க நேரத்தில் ஒரு வரிசை ஆகும்
  console.log(input.length);
} else {
  console.log("Not an array");
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isArray(value)`
