# areBigInts

## விளக்கம்

`areBigInts` என்பது ஒரு மதிப்பு `bigint` மதிப்புகள் மட்டுமே கொண்ட காலியல்லாத வரிசையா என்பதை நிர்ணயிக்கிறது.

### பயன்பாட்டு நிகழ்வு

அறியப்படாத உள்ளீட்டை (எ.கா., parse செய்யப்பட்ட JSON போன்ற தரவு, API payloads, அல்லது `unknown` என வகைப்படுத்தப்பட்ட
function parameters) செயலாக்குவதற்கு முன் அது `bigint` மதிப்புகளின் காலியல்லாத வரிசை என்பதை உறுதிப்படுத்த
சரிபார்க்கவும்; அனைத்து கூறுகளும் `bigint` ஆக இருந்தால் மட்டுமே `true`, இல்லையெனில் `false` ஐத் திருப்பும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> அறியப்படாத உள்ளீட்டில் `bigint`-மட்டும் செயல்பாடுகள் (எ.கா., கணிதச் செயல்கள், ஒப்பீடுகள்) செய்வதற்கு முன், இயக்கநேர (
> runtime) காப்பாளராக `areBigInts` ஐப் பயன்படுத்துங்கள்.

### நன்மைகள்

- ஒவ்வொரு கூறும் `bigint` என்பதை உறுதிசெய்கிறது; முழு வரிசையும் பொருந்தும் போது மட்டுமே `true` ஐத் திருப்பும்.
- `isFilledArray` மூலம் வடிவமைப்பிலேயே (by design) வரிசையல்லாதவற்றையும் காலியான வரிசைகளையும் நிராகரிக்கிறது; தவறான
  உள்ளீடுகள் தற்செயலாக ஏற்றுக்கொள்ளப்படுவதைத் தடுக்கிறது.
- விரைவு தோல்வி: `bigint` அல்லாத ஒரு கூறு கிடைத்தவுடன் உடனே `false` ஐத் திருப்புகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areBigInts(array)`

அளவுருக்கள்:

- `array`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areBigInts } from "@type-check/guards";

const a: unknown = [10n, 20n];
const b: unknown = [10n, 20];
const c: unknown = [];

console.log(areBigInts(a)); // உண்மை
console.log(areBigInts(b)); // பொய்
console.log(areBigInts(c)); // பொய்
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areBigInts(array)`
