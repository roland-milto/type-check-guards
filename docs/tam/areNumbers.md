# areNumbers

## விளக்கம்

`areNumbers` என்பது ஒரு மதிப்பு காலியல்லாத வரிசையாகவும், அதில் உள்ள அனைத்து கூறுகளும் எண்களாகவும் உள்ளதா என்பதைச்
சரிபார்க்கிறது.

### பயன்பாட்டு நிகழ்வு

மொத்தம், சராசரி, அல்லது பிற எண் தொகுப்புகளை கணக்கிடுவதற்கு முன், பயனர் வழங்கிய அல்லது API வழங்கிய தரவு காலியல்லாத
எண்களின் வரிசையா என்பதை உறுதிப்படுத்தச் சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> எண் கணக்கீடுகளைச் செய்வதற்கு முன் தெரியாத வரிசைகளைச் சரிபார்க்க `areNumbers` ஐப் பயன்படுத்துங்கள்; இது காலி
> வரிசைகளுக்கும், எண் அல்லாத எந்த மதிப்பையும் கொண்ட வரிசைகளுக்கும் `false` ஐத் திருப்பும்.

### நன்மைகள்

- உள்ளீடு காலியல்லாத வரிசையாகவும், ஒவ்வொரு கூறும் எண்ணாகவும் இருக்கும் போது மட்டுமே `true` ஐத் திருப்பும்.
- காலி வரிசைகளையும் வரிசையல்லாத உள்ளீடுகளையும் நிராகரிப்பதன் மூலம் தவறான நேர்மறை முடிவுகளைத் தடுக்கும்.
- இயக்க நேரப் பிழைகளைத் தவிர்க்க, எண் செயல்பாடுகள் (எ.கா., கூட்டுதல், சராசரி கணக்கிடுதல்) செய்வதற்கு முன் ஒரு
  பாதுகாப்புச் சரிபார்ப்பாக பயனுள்ளது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areNumbers(array)`

அளவுருக்கள்:

- `array`: எண் கூறுகள் உள்ளதா என்பதைச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areNumbers(array)`
