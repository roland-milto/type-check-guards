# arePromises

## விளக்கம்

`arePromises` என்பது ஒரு வரிசையில் உள்ள அனைத்து உருப்படிகளும் `Promise` இன்ஸ்டன்ஸ்களா என்பதை நிர்ணயிக்கிறது.

### பயன்பாட்டு நிகழ்வு

இயக்கநேரத்தில் உருவாக்கப்பட்ட அல்லது வெளிப்புறமாக வழங்கப்பட்ட பட்டியலில் promises மட்டுமே உள்ளனவா என்பதை, அவற்றை
ஒன்றுசேர்ப்பதற்கு முன் (எ.கா., `Promise.all` மூலம்) சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `Promise.all` அல்லது பிற promise-மட்டும் செயல்பாடுகளை அழைப்பதற்கு முன் `unknown[]` ஐ சரிபார்க்க `arePromises` ஐப்
> பயன்படுத்துங்கள்; காலியான வரிசைகளுக்கு இது `false` ஐத் திருப்பி அளிக்கும்.

### நன்மைகள்

- Promise-சார்ந்த லாஜிக்குடன் தொடருவதற்கு முன், ஒவ்வொரு உருப்படியும் `Promise` என்பதை உறுதி செய்கிறது.
- காலியான (உருப்படிகள் நிரப்பப்படாத) வரிசைகளுக்கு `false` ஐத் திருப்பி அளிக்கிறது; இதனால் காலியான உள்ளீடுகளுக்கான
  குழப்பமான முடிவுகள் தவிர்க்கப்படுகின்றன.
- வெளிப்புற மூலங்களிலிருந்து வரும் `unknown[]` உடன் வேலை செய்யும்போது, இயக்கநேர (runtime) பாதுகாப்பு சரிபார்ப்பாக
  பயனுள்ளது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `arePromises(array)`

அளவுருக்கள்:

- `array`: `Promise` இன்ஸ்டன்ஸ்கள் உள்ளதா என்பதைச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { arePromises } from "@type-check/guards";

const values: unknown[] = [Promise.resolve(1), new Promise<void>(() => {})];

if (arePromises(values)) {
  // values என்பது இயக்க நேரத்தில் Promise நிகழ்வுகளின் ஒரு வரிசை
  Promise.all(values).then((results) => {
    console.log(results);
  });
} else {
  console.log("Not all items are promises");
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.arePromises(array)`
