# areSets

## விளக்கம்

கொடுக்கப்பட்ட காலியல்லாத வரிசையில் `Set` இன்ஸ்டன்ஸ்கள் மட்டுமே உள்ளனவா என்பதைச் சரிபார்த்து, இருந்தால் `true`-ஐவும்
இல்லையெனில் `false`-ஐவும் திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

ஒவ்வொரு set-ஐ செயலாக்குவதற்கு முன், ஒரு மதிப்பு (எ.கா., பயனர் உள்ளீடு, JSON parsing, அல்லது வெளிப்புற API-களிலிருந்து)
காலியல்லாத `Set` பொருட்களின் வரிசையா என்பதைச் சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> ஒவ்வொரு கூறிலும் `Set` API-களை (எ.கா., `.size`, `.has`, `.add`) அழைப்பதற்கும் மீளச்சுழற்சி செய்வதற்கும் முன் தெரியாத
> உள்ளீட்டை சரிபார்க்க `areSets`-ஐ பயன்படுத்துங்கள்.

### நன்மைகள்

- உள்ளீடு காலியல்லாத வரிசையாகவும், ஒவ்வொரு கூறும் `Set` இன்ஸ்டன்ஸாகவும் இருக்கும் போது மட்டுமே `true`-ஐ திருப்புகிறது.
- வரிசையில் கூறுகள் இல்லாத போது `false`-ஐ திருப்புவதன் மூலம் காலியான வரிசைகளுக்கான தவறான நேர்மறைகளைத் தடுக்கிறது.
- ஒவ்வொரு கூறிலும் `Set`-க்கு உரிய செயல்பாடுகளை செய்வதற்கு முன் இயக்கநேர பாதுகாப்பு சரிபார்ப்பாக பயன்படும்.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areSets(array)`

அளவுருக்கள்:

- `array`: `Set` இன்ஸ்டன்ஸ்கள் உள்ளதா என்பதைச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  // a என்பது இயக்க நேரத்தில் Set நிகழ்வுகளின் ஒரு வரிசை
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); // பொய்
console.log(areSets(c)); // பொய்

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areSets(array)`
