# areFalse

## விளக்கம்

`areFalse` என்பது வழங்கப்பட்ட ஒரு வரிசையில் உள்ள அனைத்து கூறுகளும் கண்டிப்பாக boolean `false` ஆக உள்ளனவா என்பதைச்
சரிபார்க்கிறது.

### பயன்பாட்டு நிகழ்வு

தொடர்வதற்கு முன் feature flags, checks, அல்லது guard முடிவுகளின் பட்டியல் அனைத்தும் `false` ஆக உள்ளனவா என்பதைச்
சரிபார்க்கவும் (எ.கா., தடைசெய்யும் நிலைகள் எதுவும் இல்லை என்பதை உறுதிப்படுத்த).

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> ஒரு வரிசை காலியாக இல்லாமல், அதில் boolean மதிப்பு `false` மட்டுமே உள்ளது என்பதை கண்டிப்பாகச் சரிபார்க்க வேண்டியபோது
`areFalse` ஐப் பயன்படுத்துங்கள்.

### நன்மைகள்

- ஒவ்வொரு கூறும் கண்டிப்பாக `false` என்பதைக் உறுதிசெய்கிறது (`truthy/falsey` மாற்றம் இல்லை).
- `isFilledArray` மூலம் நிரப்பப்பட்ட வரிசை அவசியம் என்பதால், வரிசையல்லாதவை அல்லது காலியான வரிசைகளுக்கு `false` ஐத்
  திருப்புகிறது.
- திறனுக்காக, முதல் `false` அல்லாத கூறிலேயே முன்கூட்டியே நிறுத்துகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areFalse(array)`

அளவுருக்கள்:

- `array`: சரிபார்க்க வேண்டிய வரிசை; எந்த வகை கூறுகளையும் கொண்டிருக்கலாம்.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areFalse } from "@type-check/guards";

const a = areFalse([false, false, false]); // உண்மை
const b = areFalse([false, true, false]);  // பொய்
const c = areFalse([false, "false", false]); // பொய்
const d = areFalse([]); // பொய்
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areFalse(array)`
