# areWeakSets

## விளக்கம்

உள்ளீடு காலியல்லாத ஒரு வரிசையா, மேலும் அதில் உள்ள ஒவ்வொரு கூறும் `WeakSet` ஆவதா என்பதைச் சரிபார்த்து, அந்த நிலையில்
மட்டும் `true` ஐத் திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

இயக்கநேர உள்ளீட்டை (எ.கா., APIகள், கட்டமைப்பு, அல்லது பயனர் வழங்கிய தரவு) சரிபார்த்து, `WeakSet` நடத்தை மீது சார்ந்த
தர்க்கத்தைத் தொடரும் முன், உங்களிடம் `WeakSet` நிகழ்வுகளின் காலியல்லாத பட்டியல் இருப்பதை உறுதிசெய்யவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `WeakSet[]` ஆகக் கருதுவதற்கு முன் தெரியாத உள்ளீட்டைச் சரிபார்க்க `areWeakSets` ஐப் பயன்படுத்துங்கள். இது காலியான
> வரிசைகளுக்கும் வரிசையல்லாதவற்றுக்கும் `false` ஐத் திருப்புகிறது.

### நன்மைகள்

- உள்ளீட்டு வரிசையில் உள்ள ஒவ்வொரு கூறும் `WeakSet` என்பதை உறுதிப்படுத்துகிறது.
- காலியான வரிசைகளுக்கு `false` ஐத் திருப்பி, தரவு இல்லாத நிலையில் தவறுதலாக “அனைத்தும் சரி” என்ற முடிவு வராமல் தடுக்கும்.
- உள்ளீடு நிரப்பப்பட்ட வரிசையாக இல்லாதபோது (`null` உட்பட) `false` ஐத் திருப்பி பாதுகாப்பாக தோல்வியடைகிறது.
- `WeakSet` நிகழ்வுகள் தேவைப்படும் செயல்பாடுகளை செய்யும் முன் ஒரு காவலாக (guard) பயன்படுத்த உதவும்.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areWeakSets(array)`

அளவுருக்கள்:

- `array`: `WeakSet` பொருட்களுக்காகச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areWeakSets } from "@type-check/guards";

const a: unknown = [new WeakSet<object>(), new WeakSet<object>()];
const b: unknown = [new WeakSet<object>(), {}];
const c: unknown = [];

if (areWeakSets(a)) {
  // a என்பது WeakSet நிகழ்வுகளின் காலியல்லாத வரிசை
}

console.log(areWeakSets(a)); // true
console.log(areWeakSets(b)); // false
console.log(areWeakSets(c)); // false
console.log(areWeakSets(null as unknown)); // false
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areWeakSets(array)`
