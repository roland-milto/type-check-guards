# isOneOfType

## விளக்கம்

`isOneOfType` என்பது கொடுக்கப்பட்ட `value` வழங்கப்பட்ட வகை சரங்களில் குறைந்தது ஒன்றுடன் பொருந்துகிறதா என்பதை
நிர்ணயித்து, ஏதேனும் பொருத்தம் கிடைத்தால் `true`-ஐவும் இல்லையெனில் `false`-ஐவும் திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

மேலும் தர்க்கத்தை தொடருவதற்கு முன் பல ஏற்றுக்கொள்ளத்தக்க இயக்கநேர வகைகளை (எ.கா., `number` அல்லது `string`) அனுமதித்து,
தளர்வான வகையிடப்பட்ட அல்லது வெளிப்புற தரவை (எ.கா., parse செய்யப்பட்ட JSON, query parameters) சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> ஒரு மதிப்பு பல அனுமதிக்கப்பட்ட வகைகளில் ஏதாவதொன்றுடன் பொருந்துகிறதா என்பதை இயக்கநேரத்தில் சரிபார்க்க விரும்பும்போது
`isOneOfType`-ஐ பயன்படுத்துங்கள்; குறைந்தது ஒரு வகை பொருந்தினால் இது `true`-ஐ, இல்லையெனில் `false`-ஐ திருப்புகிறது.

### நன்மைகள்

- ஒரே அழைப்பில் ஒரு மதிப்பை பல அனுமதிக்கப்பட்ட வகைகளுடன் ஒப்பிட்டு சரிபார்க்கிறது; முதல் பொருத்தத்தில் `true`-ஐ
  திருப்புகிறது.
- `unknown` உள்ளீடுகளுடன் வேலை செய்கிறது; இதனால் இயக்கநேர எல்லைகளில் (எ.கா., வெளிப்புற தரவு, பயனர் உள்ளீடு) இது
  பயனுள்ளதாக இருக்கும்.
- நிபந்தனைத் தர்க்கம் மற்றும் ஆரம்ப திருப்புதல்களுடன் நன்றாக இணையும் எளிய boolean முடிவை (`true`/`false`) வழங்குகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isOneOfType(value, types)`

அளவுருக்கள்:

- `value`: குறிப்பிட்ட வகைகளுக்கு எதிராக சரிபார்க்க வேண்டிய மதிப்பு.
- `types`: மதிப்பின் சாத்தியமான வகைகளை பிரதிநிதித்துவப்படுத்தும் வகை சரங்களின் வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // இயக்க நேரத்தில் input ஒரு பொருள் ஆகும்
}

console.log(isOneOfType(3, ["number", "string"])); // true
console.log(isOneOfType("hello", ["number", "boolean"])); // false

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isOneOfType(value, types)`
