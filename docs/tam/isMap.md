# isMap

## விளக்கம்

கொடுக்கப்பட்ட `value` ஒரு `Map` ஆக உள்ளதா என்பதைச் சரிபார்த்து, அது `Map` ஆக இருந்தால் `true` என்றும் இல்லையெனில்
`false` என்றும் திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

JSON parsing, வெளிப்புற API-கள், அல்லது பயனர் உள்ளீடு போன்றவற்றிலிருந்து `unknown` மதிப்பு கிடைக்கும் போது, `Map`
செயல்பாடுகளை செய்வதற்கு முன் அது `Map` என்பதை உறுதிப்படுத்த `isMap` ஐ பயன்படுத்துங்கள்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `isMap` என்பது இயக்கநேர பாதுகாவலர்; மதிப்பு `Map` ஆக இருந்தால் `true` என்றும் இல்லையெனில் `false` என்றும்
> திருப்புகிறது; `Map` API-களை அழைக்கும் முன் `unknown` ஐ குறுக்க இதைப் பயன்படுத்துங்கள்.

### நன்மைகள்

- ஒரு மதிப்பு `Map` ஆக உள்ளதா என்பதை விரைவாக இயக்கநேரத்தில் சரிபார்க்க உதவுகிறது.
- `get`, `set`, `has` போன்ற `Map` முறைகள் தேவைப்படும் குறியீட்டு பாதைகளை பாதுகாப்பதன் மூலம் வகை பிழைகளைத் தடுக்க
  உதவுகிறது.
- `unknown` உள்ளீடுகளை கையாளும் போது இலகுவான சரிபார்ப்பு படியாக இது நன்றாக செயல்படுகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isMap(value)`

அளவுருக்கள்:

- `value`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isMap } from "@type-check/guards";

const input: unknown = new Map<string, number>([["a", 1]]);

if (isMap(input)) {
  input.set("b", 2);
  const a = input.get("a");
  console.log(a);
} else {
  console.log("Not a Map");
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isMap(value)`
