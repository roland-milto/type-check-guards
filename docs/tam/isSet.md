# isSet

## விளக்கம்

கொடுக்கப்பட்ட மதிப்பு `Set` ஆக உள்ளதா என்பதை நிர்ணயிக்கிறது.

### பயன்பாட்டு நிகழ்வு

வெளிப்புற மூலங்களிலிருந்து (எ.கா., JSON parsing, பயனர் உள்ளீடு, அல்லது third-party API-கள்) வரும் உள்ளீடுகளைச்
சரிபார்த்து, `Set` செயல்பாடுகளைச் செய்வதற்கு முன் ஒரு மதிப்பு `Set` ஆக இருப்பதை உறுதி செய்யுங்கள்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `.add`, `.has`, அல்லது `.size` போன்ற `Set`-சார்ந்த API-களை அழைப்பதற்கு முன் `unknown` மதிப்புகளை குறுகலாக்க `isSet`
> ஐப் பயன்படுத்துங்கள்.

### நன்மைகள்

- ஒரு மதிப்பு `Set` ஆக உள்ளதா என்பதை உறுதிப்படுத்த ஒரு எளிய இயக்கநேரச் சரிபார்ப்பை வழங்குகிறது.
- ஒரு மதிப்பு `Set` அல்லாதபோது முன்கூட்டியே கிளைபிரிப்பைச் செய்ய அனுமதிப்பதன் மூலம் வகை பிழைகளைத் தவிர்க்க உதவுகிறது.
- எந்த `Set` உள்ளடக்கத்துடனும் (காலியானது அல்லது நிரப்பப்பட்டது) வேலை செய்து, எப்போதும் ஒரே மாதிரியாக `true`/`false` ஐத்
  திருப்புகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isSet(value)`

அளவுருக்கள்:

- `value`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // இயக்க நேரத்தில் a ஒரு Set ஆகும்
  console.log(a.size);
}

console.log(isSet(b)); // தவறு
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isSet(value)`
