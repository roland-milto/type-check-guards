# isNumber

## விளக்கம்

`isNumber` ஒரு மதிப்பு முடிவுற்ற, `NaN` அல்லாத எண் தானா என்பதைச் சரிபார்க்கிறது.

### பயன்பாட்டு நிகழ்வு

கணக்கீடுகள், சேமிப்பு, அல்லது வரம்புச் சரிபார்ப்புகளுக்கு முன் நம்பமுடியாத மூலங்களிலிருந்து (படிவங்கள், query params,
JSON payloads) வரும் எண் உள்ளீட்டைச் சரிபார்த்து, முடிவுற்ற எண்கள் மட்டுமே (`true`) செல்லவும், மற்ற அனைத்தும் `false`
திருப்பவும் உறுதி செய்யுங்கள்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> கணிதச் செயல்களை செய்வதற்கு முன் `unknown` மதிப்புகளைச் சரிபார்க்க `isNumber` ஐ பயன்படுத்துங்கள்; இது `NaN`,
`Infinity`, மற்றும் `-Infinity` ஆகியவற்றை நிராகரிக்கிறது.

### நன்மைகள்

- `true` என்பதை உண்மையான JavaScript எண்களுக்கு மட்டுமே திருப்புகிறது (வகைச் சரிபார்ப்பு + `NaN` மற்றும் முடிவிலி
  மதிப்புகளை நிராகரித்தல்).
- `NaN`, `Infinity`, அல்லது `-Infinity` தவறுதலாக எண்களாகச் செல்லும் பொதுவான சரிபார்ப்பு பிழைகளைத் தடுக்கிறது.
- அறியப்படாத உள்ளீட்டிற்கு (எ.கா., JSON, பயனர் உள்ளீடு, வெளிப்புற APIகள்) இயக்கநேர பாதுகாப்பாக நன்றாக செயல்படுகிறது.
- எளிமையானது, வேகமானது, மற்றும் பக்கவிளைவுகள் இல்லாதது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isNumber(value)`

அளவுருக்கள்:

- `value`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isNumber } from "@type-check/guards";

const input: unknown = 42;

if (isNumber(input)) {
  // input ஒரு செல்லுபடியான முடிவுடைய எண்
  const doubled = input * 2;
  console.log(doubled);
} else {
  console.log("Not a valid number");
}

console.log(isNumber(NaN));
console.log(isNumber(Infinity));
console.log(isNumber("42"));
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isNumber(value)`
