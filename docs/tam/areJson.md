# areJson

## விளக்கம்

ஒரு வரிசையின் அனைத்து உறுப்புகளும் JSON சரங்களா என்பதைச் சரிபார்க்கிறது; வரிசை நிரப்பப்பட்டு ஒவ்வொரு உருப்படியும்
செல்லுபடியான JSON ஆக இருந்தால் மட்டுமே `true`-ஐ திருப்பும்; இல்லையெனில் `false`-ஐ திருப்பும்.

### பயன்பாட்டு நிகழ்வு

வரவிருக்கும் தரவை (எ.கா., query params, environment variables, அல்லது வெளிப்புற APIs இலிருந்து) சரிபார்க்கவும்;
JSON-குறியாக்கப்பட்ட சரங்களின் வரிசை என எதிர்பார்க்கும் இடங்களில் காலியான வரிசைகளையோ அல்லது JSON அல்லாத எந்த
உள்ளீடுகளையோ நிராகரிக்க விரும்பும் போது.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `unknown[]`-ல் JSON சரங்கள் மட்டுமே உள்ளனவா என்பதை அவற்றை parse செய்வதற்கு முன் (எ.கா., `JSON.parse` மூலம்) சரிபார்க்க
> வேண்டிய போது `areJson`-ஐ பயன்படுத்தவும்.

### நன்மைகள்

- ஒவ்வொரு உறுப்பும் செல்லுபடியான JSON சரமாக இருக்கும் போது மட்டுமே `true`-ஐ திருப்பும்; இல்லையெனில் `false`-ஐ
  திருப்பும்.
- விரைவாக தோல்வியடையும்: JSON அல்லாத ஒரு உறுப்பை கண்டவுடன் சரிபார்ப்பதை நிறுத்தும்.
- வடிவமைப்பிலேயே காலியான வரிசைகளை நிராகரிக்கும்; நிரப்பப்படாத உள்ளீட்டிற்கு `false`-ஐ திருப்பும்.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areJson(array)`

அளவுருக்கள்:

- `array`: JSON சர உறுப்புகளுக்காக சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // சரி
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // தவறு
const empty = areJson([]); // தவறு

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areJson(array)`
