# areEqual

## விளக்கம்

`areEqual` என்பது ஒரு வரிசையில் உள்ள அனைத்து கூறுகளும் கொடுக்கப்பட்ட எதிர்பார்க்கப்படும் மதிப்புக்கு சமமா என்பதைச்
சரிபார்க்கிறது; ஒவ்வொரு உருப்படியும் பொருந்தும் காலியானதல்லாத வரிசைகளுக்கு மட்டுமே `true` ஐத் திருப்பும்.

### பயன்பாட்டு நிகழ்வு

ஒரு பட்டியலில் ஒரே அனுமதிக்கப்பட்ட மதிப்பு மட்டுமே உள்ளதா என்பதைச் சரிபார்க்கவும் (எ.கா., அனைத்து நிலை கொடிகளும் `true`,
அனைத்து பாத்திரங்களும் `"admin"`, அல்லது அனைத்து எண் பதிவுகளும் தேவையான மாறிலிக்கு சமம்) மேலும் காலியான உள்ளீட்டை
செல்லாததாக (`false`) கருதவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> கடுமையான அனைத்து-உருப்படிகள் சரிபார்ப்பு தேவைப்படும் போது `areEqual` ஐப் பயன்படுத்துங்கள்; இது காலியான வரிசைகளுக்கும்,
> வரிசையல்லாத அல்லது நிரப்பப்படாத எந்த உள்ளீட்டிற்கும் `false` ஐத் திருப்பும்.

### நன்மைகள்

- ஒவ்வொரு கூறும் எதிர்பார்க்கப்படும் மதிப்புடன் பொருந்தும் போது மட்டுமே `true` ஐத் திருப்பும்; இல்லையெனில் `false` ஐத்
  திருப்பும்.
- விரைவாகத் தோல்வியடையும்: பொருந்தாத ஒரு கூறு கிடைத்தவுடன் சரிபார்ப்பதை நிறுத்தும்.
- உள்ளீடு நிரப்பப்பட்ட வரிசையாக இல்லாதபோது `false` ஐத் திருப்புவதன் மூலம் தவறான உள்ளீட்டிலிருந்து பாதுகாக்கிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areEqual(value, expected)`

அளவுருக்கள்:

- `value`: சரிபார்க்க வேண்டிய வரிசை.
- `expected`: ஒவ்வொரு வரிசை உருப்படியுடனும் ஒப்பிட வேண்டிய கூறு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areEqual(value, expected)`
