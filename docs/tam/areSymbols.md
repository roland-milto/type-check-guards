# areSymbols

## விளக்கம்

ஒரு உள்ளீடு கூறுகள் அனைத்தும் சின்னங்கள் (symbols) ஆக உள்ள, நிரப்பப்பட்ட (filled) வரிசையா என்பதைச் சரிபார்த்து, `true`
அல்லது `false`-ஐ திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

ஒரு கட்டமைப்பு (configuration) புலம் (எ.கா., symbols ஆக பிரதிநிதித்துவப்படுத்தப்பட்ட தனித்துவமான விசைகளின் பட்டியல்)
`symbol[]` தேவைப்படும் API-களில் பயன்படுத்துவதற்கு முன், அது சின்னங்கள் (symbols) மட்டுமே கொண்ட காலியல்லாத வரிசையா
என்பதைச் சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `symbol[]` எனக் கருதுவதற்கு முன் தெரியாத (unknown) உள்ளீட்டை சரிபார்க்க `areSymbols`-ஐ பயன்படுத்துங்கள்; இது
> வரிசையல்லாதவற்றுக்கும் காலி வரிசைகளுக்கும் `false`-ஐ திருப்பும்.

### நன்மைகள்

- உள்ளீடு காலியல்லாத ஒரு வரிசையாகவும், ஒவ்வொரு கூறும் ஒரு சின்னமாகவும் (symbol) இருக்கும் போது மட்டுமே `true`-ஐ
  திருப்பும்.
- உள் filled-array சரிபார்ப்பின் மூலம் வரிசையல்லாதவற்றையும் காலி வரிசைகளையும் நிராகரித்து தவறான நேர்மறை முடிவுகளைத்
  தடுக்கிறது.
- மேலும் செயலாக்கத்திற்கு முன் symbol-மட்டுமே உள்ள பட்டியல்களை சரிபார்க்கும் runtime வகை காவலராக (type guard) பயனுள்ளது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areSymbols(array)`

அளவுருக்கள்:

- `array`: சின்ன (symbol) கூறுகள் உள்ளதா எனச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  // இயக்க நேரத்தில் a என்பது சின்னங்கள் மட்டுமே கொண்ட வரிசை
  const first = a[0];
  console.log(typeof first); // "symbol"
}

console.log(areSymbols(b)); // false
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areSymbols(array)`
