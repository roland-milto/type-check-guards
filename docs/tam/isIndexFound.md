# isIndexFound

## விளக்கம்

`isIndexFound` கொடுக்கப்பட்ட மதிப்பு எதிர்மறையல்லாத முழு எண் தானா என்பதை நிர்ணயித்து, ஒரு குறியீடு (index)
கண்டுபிடிக்கப்பட்டுள்ளது என்பதைச் சுட்டுகிறது.

### பயன்பாட்டு நிகழ்வு

ஒரு தேடல் முடிவு பயன்படுத்தக்கூடிய குறியீடாக (முழு எண் `>= 0`) உள்ளதா என்பதை, array அல்லது string-இல் index செய்வதற்கு
முன் சரிபார்த்து, தவறுதலாக `-1` அல்லது எண் அல்லாத மதிப்புகளைப் பயன்படுத்துவதைத் தடுப்பது.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `indexOf`, `findIndex`, அல்லது தனிப்பயன் தேடல்கள் போன்ற செயல்பாடுகளுக்குப் பிறகு `isIndexFound`-ஐ பயன்படுத்துங்கள்;
> அங்கு `-1` (அல்லது பிற செல்லாத மதிப்புகள்) “கண்டுபிடிக்கப்படவில்லை” என்பதைக் குறிக்கலாம். இது `true` திருப்பினால், அந்த
> மதிப்பு ஒரு எண் ஆகும் மற்றும் array/string index ஆகப் பயன்படுத்த பாதுகாப்பானது.

### நன்மைகள்

- எதிர்மறையல்லாத முழு எண் உள்ளதா என்பதைச் சரிபார்த்து, ஒரு குறியீடு (index) கண்டுபிடிக்கப்பட்டதா என்பதை கண்டறிய ஒரு எளிய
  வகை-காவலை (type guard) வழங்குகிறது.
- செல்லுபடியாகும் குறியீடு போன்ற மதிப்புகளுக்கு (முழு எண்கள் `>= 0`) மட்டுமே `true` திருப்புகிறது; எதிர்மறைகள், முழு எண்
  அல்லாதவை, மற்றும் எண் அல்லாதவை ஆகியவற்றை நிராகரிக்கிறது.
- `-1`-ஐ “கண்டுபிடிக்கப்படவில்லை” என்பதற்காகத் திருப்பும் API-களுடன் வேலை செய்யும்போது, off-by-one மற்றும்
  sentinel-value பிழைகளைத் தவிர்க்க உதவுகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isIndexFound(value)`

அளவுருக்கள்:

- `value`: எதிர்மறையல்லாத முழு எண் ஆக உள்ளதா என்பதைச் சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // இங்கே idx ஒரு எண் மற்றும் அது >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// indexOf உடன் வழக்கமான பயன்பாடு
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isIndexFound(value)`
