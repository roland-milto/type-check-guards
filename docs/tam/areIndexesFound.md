# areIndexesFound

## விளக்கம்

`areIndexesFound` என்பது ஒரு மதிப்பு காலியல்லாத வரிசையா, அதன் கூறுகள் அனைத்தும் செல்லுபடியான குறியீடுகளா என்பதைச்
சரிபார்த்து, அவ்வாறு இருந்தால் `true` ஐயும் இல்லையெனில் `false` ஐயும் திருப்பும்.

### பயன்பாட்டு நிகழ்வு

பயனர் வழங்கிய அல்லது வெளிப்புற தரவை (எ.கா., parse செய்யப்பட்ட JSON) வரிசைகளை அணுக அல்லது துண்டிக்க (slice)
பயன்படுத்துவதற்கு முன், அது குறியீடுகளின் பட்டியலாக இருக்க வேண்டும் என்பதைச் சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> அறியப்படாத உள்ளீட்டை அதன் கூறுகளை வரிசை குறியீடுகளாகக் கருதுவதற்கு முன் சரிபார்க்க `areIndexesFound` ஐ
> பயன்படுத்துங்கள்; காலியான வரிசைகளுக்கும், குறியீடு அல்லாத மதிப்புகள் உள்ள வரிசைகளுக்கும் இது `false` ஐத் திருப்பும்.

### நன்மைகள்

- உள்ளீடு நிரப்பப்பட்ட வரிசையாகவும், ஒவ்வொரு கூறும் செல்லுபடியான குறியீடாகவும் இருக்கும் போது மட்டுமே இது `true` ஐத்
  திருப்பும்.
- விரைவாக தோல்வியடையும்: குறியீடு அல்லாத கூறு ஒன்று கிடைத்தவுடன் உடனே `false` ஐத் திருப்பும்.
- மதிப்புகளை வரிசை இடங்கள் அல்லது இடமாற்றங்கள் (offsets) ஆக பயன்படுத்துவதற்கு முன் பாதுகாப்புச் சோதனையாக பயனுள்ளது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areIndexesFound(array)`

அளவுருக்கள்:

- `array`: குறியீடு இணக்கத்திற்காக சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areIndexesFound } from "@type-check/guards";

const a: unknown[] = [0, 1, 2];
const b: unknown[] = [0, "a", 2];
const c: unknown[] = [];

console.log(areIndexesFound(a)); // true
console.log(areIndexesFound(b)); // false
console.log(areIndexesFound(c)); // false

if (areIndexesFound(a)) {
  // இங்கே, `a` என்பது குறியீடுகளால் நிரப்பப்பட்ட வரிசை என்று உறுதிப்படுத்தப்படுகிறது.
  const firstIndex = a[0];
  console.log(firstIndex);
}
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areIndexesFound(array)`
