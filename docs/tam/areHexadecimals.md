# areHexadecimals

## விளக்கம்

ஒரு வரிசையில் உள்ள அனைத்து கூறுகளும் ஹெக்ஸாடெசிமல் சரங்களா என்பதைச் சரிபார்த்து, காலியல்லாத வரிசைகளில் ஒவ்வொரு
உருப்படியும் செல்லுபடியாக இருக்கும் போது மட்டுமே `true` ஐத் திருப்பும்.

### பயன்பாட்டு நிகழ்வு

ஹெக்ஸாடெசிமல் பகுப்பாய்வு அல்லது மேலதிக செயலாக்கம் செய்வதற்கு முன், பயனர் உள்ளீடு அல்லது வெளித் தரவை (எ.கா., IDs,
checksums, முன்னிலை '#' இல்லாத color codes) சரிபார்க்க `areHexadecimals` ஐப் பயன்படுத்துங்கள்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `parseInt(value, 16)` அல்லது BigInt மாற்றங்கள் செய்வதற்கு முன் போன்றவற்றில், அறியப்படாத உள்ளீட்டை பகுப்பாய்வு அல்லது
> மாற்றம் செய்வதற்கு முன் சரிபார்க்க `areHexadecimals` ஐப் பயன்படுத்துங்கள்.

### நன்மைகள்

- ஒவ்வொரு கூறும் ஹெக்ஸாடெசிமல் சரமாக உள்ளதா என்பதைச் சரிபார்த்து, அனைத்து உருப்படிகளும் பொருந்தும் போது மட்டுமே `true`
  ஐத் திருப்பும்.
- வடிவமைப்பிலேயே காலியான வரிசைகளை நிராகரித்து, உள்ளீட்டு தரவு இல்லாதபோது `false` ஐத் திருப்பும்.
- காவல்கள் மற்றும் முன்கூட்டிய-திரும்பல் சரிபார்ப்புக்கு ஏற்ற எளிய பூலியன் முடிவை (`true`/`false`) வழங்கும்.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areHexadecimals(array)`

அளவுருக்கள்:

- `array`: ஹெக்ஸாடெசிமல் சரக் கூறுகளுக்காகச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areHexadecimals } from "@type-check/guards";

const a = areHexadecimals(["1A", "3F", "B2"]);
const b = areHexadecimals(["1A", "3G", "B2"]);
const c = areHexadecimals([10 as unknown as string, "3F", "B2"] as unknown[]);
const d = areHexadecimals([]);

console.log(a, b, c, d);
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areHexadecimals(array)`
