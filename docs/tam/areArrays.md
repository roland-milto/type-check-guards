# areArrays

## விளக்கம்

`areArrays` என்பது ஒரு மதிப்பு நிரப்பப்பட்ட இரு-பரிமாண வரிசையா, மேலும் அதன் உருப்படிகள் அனைத்தும் வரிசைகளா என்பதை
தீர்மானிக்கிறது.

### பயன்பாட்டு நிகழ்வு

வரிசை/நெடுவரிசை செயல்பாடுகளைச் செய்வதற்கு முன் அட்டவணை அல்லது மேட்ரிக்ஸ் போன்ற உள்ளீடுகளை (எ.கா., CSV வரிசைகள், grid
தரவு, அல்லது குழுவாக்கப்பட்ட பட்டியல்கள்) சரிபார்க்க `areArrays`-ஐ பயன்படுத்துங்கள்; உள்ளீடு ஒரு வரிசை அல்ல, காலியாக
உள்ளது, அல்லது வரிசையல்லாத எந்த உருப்படியையும் கொண்டுள்ளது என்றால் இது `false`-ஐ திருப்பும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> ஒரு மதிப்பு காலியல்லாத 2D வரிசை என்றும், உட்பொதிந்த வரிசைகளில் மீளச்சுழற்சி (iterate) செய்ய அல்லது குறியீடு (index)
> செய்ய முன் ஒவ்வொரு வரிசையும் ஒரு வரிசை (array) என்றும் உறுதி செய்ய வேண்டிய போது `areArrays`-ஐ பயன்படுத்துங்கள்.

### நன்மைகள்

- உள்ளீடு காலியல்லாத இரு-பரிமாண வரிசை (2D array) என்றும், அதில் உள்ள ஒவ்வொரு உறுப்பும் ஒரு வரிசை (array) என்றும்
  சரிபார்க்கிறது.
- காவலர்கள் (guards) மற்றும் ஆரம்ப வெளியேற்றங்களுக்கு (early exits) ஏற்ற எளிய boolean முடிவை (`true`/`false`)
  திருப்புகிறது.
- பின்னர் வரும் குறியீடு உட்பொதிந்த வரிசை செயல்பாடுகளை (எ.கா., வரிசைகளை map செய்வது) கருதும் போது ஏற்படும் runtime
  பிழைகளைத் தடுக்க உதவுகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areArrays(array)`

அளவுருக்கள்:

- `array`: சரிபார்க்க வேண்டிய உள்ளீடு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value என்பது கூறுகளாக வரிசைகள் கொண்ட 2D வரிசை
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areArrays(array)`
