# isTrue

## விளக்கம்

`isTrue` என்பது கொடுக்கப்பட்ட மதிப்பு `true`-க்கு கடுமையாக சமமா என்பதை நிர்ணயிக்கிறது.

### பயன்பாட்டு நிகழ்வு

`isTrue`-ஐ கொடிகள் (flags), அம்ச மாற்றிகள் (feature toggles), அல்லது கட்டமைப்பு (configuration) மதிப்புகளை சரிபார்க்க
பயன்படுத்துங்கள்; அங்கு லிட்டரல் `true` மட்டுமே ஏற்கப்பட வேண்டும், மற்ற அனைத்தும் `false` எனக் கருதப்பட வேண்டும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> பூலியன் லிட்டரல் `true`-ஐ மட்டும் ஏற்க வேண்டியபோது `isTrue`-ஐ பயன்படுத்துங்கள்; வெறும் truthy மதிப்புகளை அல்ல.

### நன்மைகள்

- பூலியன் லிட்டரல் `true`-க்கு கடுமையான சரிபார்ப்பை வழங்குகிறது (coercion இல்லை).
- `1`, `"true"`, அல்லது `{}` போன்ற truthy மதிப்புகளிலிருந்து `true`-ஐ வேறுபடுத்த உதவுகிறது.
- காவல்கள் (guards) மற்றும் சரிபார்ப்பு (validation) பைப்லைன்களுக்கு ஏற்ற எளிய, கணிக்கக்கூடிய நடத்தை.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isTrue(value)`

அளவுருக்கள்:

- `value`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // உண்மை
const b = isTrue(1);         // பொய்
const c = isTrue("true");   // பொய்

if (isTrue(a)) {
  // இங்கே a உண்மை
}
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isTrue(value)`
