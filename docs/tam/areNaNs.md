# areNaNs

## விளக்கம்

`areNaNs` என்பது ஒரு வரிசையில் உள்ள அனைத்து உருப்படிகளும் `NaN` ஆக உள்ளனவா என்பதைச் சரிபார்த்து, ஒவ்வொரு உருப்படியும்
`NaN` ஆக இருந்தால் மட்டுமே `true` ஐத் திருப்பும்.

### பயன்பாட்டு நிகழ்வு

`NaN` ஒரு sentinel மதிப்பாகப் பயன்படுத்தப்படும் வரும் தரவைச் சரிபார்த்து, முழு வரிசையும் `NaN` மட்டுமே கொண்டுள்ளது
என்பதை உறுதி செய்ய வேண்டிய சூழல் (எ.கா., முழுவதும் காணாமல் போன எண் தொடர் என்பதை கண்டறிதல்).

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> ஒரு வரிசையில் எண் `NaN` மதிப்பு மட்டுமே உள்ளது என்பதை (சரம்-இருந்து-எண் மாற்றம் இன்றி) சரிபார்க்க வேண்டிய போது
`areNaNs` ஐப் பயன்படுத்துங்கள்.

### நன்மைகள்

- ஒவ்வொரு உருப்படியும் `NaN` ஆக இருக்கும் போது மட்டுமே `true` ஐத் திருப்பும் (கடுமையான அனைத்து-உருப்படிகள் சரிபார்ப்பு).
- சரங்களை எண்களாக மாற்றாது; "NaN" போன்ற மதிப்புகள் `NaN` அல்லாதவையாகவே இருந்து முடிவை `false` ஆக்கும்.
- நிரப்பப்படாத வரிசைகளுக்கு `false` ஐத் திருப்புகிறது; காலியான உள்ளீட்டில் தவறுதலாக `true` ஆகிவிடுவதைத் தடுக்கிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areNaNs(array)`

அளவுருக்கள்:

- `array`: `NaN` மதிப்புகளுக்காகச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // சரி
const b = areNaNs([NaN, 1, NaN]); // தவறு
const c = areNaNs([NaN, "NaN", NaN]); // தவறு
const d = areNaNs([NaN, null, NaN]); // தவறு
const e = areNaNs([] as unknown[]); // தவறு
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areNaNs(array)`
