# isNaN

## விளக்கம்

சரங்களை மாற்றாமல், வழங்கப்பட்ட `value` என்பது `number` வகையின் `NaN` ஆக உள்ளதா என்பதை நிர்ணயிக்கிறது.

### பயன்பாட்டு நிகழ்வு

நம்பகமற்ற அல்லது தளர்வான வகையிடப்பட்ட உள்ளீடுகளை (எ.கா. API payloads, படிவ மதிப்புகள், parse செய்யப்பட்ட JSON)
சரிபார்த்து, சிறப்பு `NaN` மதிப்பை கண்டறிந்து வெளிப்படையாக கையாளவும்; அதே நேரத்தில் எண் அல்லாத உள்ளீடுகளை `NaN` அல்ல
எனக் கருதவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> உள்ளீடு உண்மையில் `number` என்பதையும் (சரம்-இலிருந்து-எண் மாற்றம் இல்லாமல்) உறுதி செய்து கொண்டே, சிறப்பு எண் மதிப்பு
`NaN` ஐ கண்டறிய வேண்டியபோது `isNaN` ஐப் பயன்படுத்துங்கள்.

### நன்மைகள்

- எண் அல்லாத மதிப்புகளை (எ.கா. சரங்கள்) எண்களாக கட்டாய மாற்றம் செய்யாமல் ஒரு மதிப்பு `NaN` ஆக உள்ளதா என்பதைச்
  சரிபார்க்கிறது.
- `number` வகையாகவும் `NaN` ஆகவும் இருக்கும் மதிப்புகளுக்கு மட்டுமே `true` ஐத் திருப்புகிறது.
- `unknown` உள்ளீடுகளுக்கு பாதுகாப்பானது; மறைமுக மாற்றங்களால் ஏற்படும் தவறான நேர்மறை முடிவுகளைத் தவிர்க்கிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isNaN(value)`

அளவுருக்கள்:

- `value`: `number` வகையின் `NaN` ஆக உள்ளதா என்பதைச் சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // சரி
console.log(isNaN(b)); // தவறு
console.log(isNaN(c)); // தவறு

if (isNaN(a)) {
  // a ஒரு எண்; குறிப்பாக NaN
}
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isNaN(value)`
