# isWeakMap

## விளக்கம்

கொடுக்கப்பட்ட `value` ஒரு `WeakMap` இன்ஸ்டன்ஸ் தானா என்பதை நிர்ணயிக்கிறது.

### பயன்பாட்டு நிகழ்வு

நீங்கள் ஒரு `unknown` மதிப்பை (எ.கா., ஒரு பொது API, பிளகின் சிஸ்டம், அல்லது டைனமிக் கான்ஃபிகரேஷன்) ஏற்கும் போது,
`WeakMap`-க்கு உரிய நடத்தை பயன்படுத்துவதற்கு முன் அது `WeakMap` என்பதைச் சரிபார்க்க `isWeakMap` ஐ பயன்படுத்துங்கள்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `isWeakMap` ஒரு `instanceof WeakMap` சரிபார்ப்பை செய்கிறது; இது ஒரு ரன்டைம் கார்டு, உண்மையான `WeakMap`
> இன்ஸ்டன்ஸ்களுக்கு மட்டுமே `true` ஐத் திருப்புகிறது.

### நன்மைகள்

- ஒரு மதிப்பு `WeakMap` ஆக உள்ளதா என்பதை எளிய ரன்டைம் சரிபார்ப்பாக வழங்குகிறது.
- `WeakMap` தேவைப்படும் API-களை தவறாகப் பயன்படுத்துவதைத் தடுப்பதில் உதவுகிறது; எறிவதற்குப் பதிலாக `true`/`false` ஐத்
  திருப்புகிறது.
- `unknown` உள்ளீடுகளுடன் வேலை செய்கிறது; இதனால் மாட்யூல் எல்லைகளில் (எ.கா., பார்சிங், வெளிப்புற தரவு, அல்லது டைப்
  செய்யப்படாத கோடு) பயன்படுத்த வசதியாகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isWeakMap(value)`

அளவுருக்கள்:

- `value`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isWeakMap } from "@type-check/guards";

const a: unknown = new WeakMap<object, number>();
const b: unknown = new Map();

if (isWeakMap(a)) {
  // இயக்க நேரத்தில் a ஒரு WeakMap ஆகும்
}

console.log(isWeakMap(a)); // true
console.log(isWeakMap(b)); // false
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isWeakMap(value)`
