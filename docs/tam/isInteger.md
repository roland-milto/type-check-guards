# isInteger

## விளக்கம்

கொடுக்கப்பட்ட `value` ஒரு பாதுகாப்பான முழு எண் (safe integer) எண்ணா என்பதை நிர்ணயிக்கிறது.

### பயன்பாட்டு நிகழ்வு

நம்பமுடியாத உள்ளீட்டை (எ.கா., query params, JSON payloads, environment variables) வரிசை குறியீடுகள், பக்கமிடல் (
pagination), கவுண்டர்கள், அல்லது தரவுத்தள IDகளுக்கான முழு எண்ணாக பயன்படுத்துவதற்கு முன் சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> அறியப்படாத உள்ளீட்டை எண் முழு எண் எனக் கருதுவதற்கு முன் சரிபார்க்க `isInteger` ஐப் பயன்படுத்துங்கள்;
`typeof value === "number"` மற்றும் `Number.isSafeInteger(value)` ஆகியவை பூர்த்தி செய்யும் மதிப்புகளுக்கு மட்டுமே இது
`true` ஐத் திருப்பும்.

### நன்மைகள்

- வகை மற்றும் எண் பாதுகாப்பு இரண்டையும் சரிபார்க்கிறது: உள்ளீடு ஒரு எண் மற்றும் பாதுகாப்பான முழு எண் ஆக இருக்கும் போது
  மட்டுமே `true` ஐத் திருப்பும்.
- எண் கட்டாய மாற்றம் (numeric coercion) தொடர்பான பொதுவான சிக்கல்களைத் தவிர்க்கிறது: "5" போன்ற சரங்கள் சரியாக `false` ஐத்
  திருப்பும்.
- முழு எண்கள் அல்லாதவற்றையும் பாதுகாப்பற்ற முழு எண்களையும் நிராகரிக்கிறது; இதனால் இது IDகள், கவுண்டர்கள், மற்றும்
  வரிசை (array) குறியிடலுக்கு பொருத்தமானது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isInteger(value)`

அளவுருக்கள்:

- `value`: முழு எண் நிலையைச் சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      // சரி
const b = isInteger(-100);   // சரி
const c = isInteger("5");    // தவறு
const d = isInteger(5.5);    // தவறு
const e = isInteger(null);   // தவறு

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isInteger(value)`
