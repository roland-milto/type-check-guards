# isBinary

## விளக்கம்

`isBinary` ஒரு மதிப்பு இரும சரமா (விருப்பமாக `0b`/`0B` முன்னொட்டுடன்) என்பதை நிர்ணயித்து `true` அல்லது `false` ஐத்
திருப்பி அளிக்கிறது.

### பயன்பாட்டு நிகழ்வு

மேலும் செயலாக்கத்திற்கு முன், பயனர் வழங்கும் சரங்கள் (எ.கா., படிவப் புலங்கள், CLI args, config values) இரும இலக்கங்கள்
மட்டுமே கொண்டுள்ளனவா, விருப்பமாக `0b`/`0B` முன்னொட்டுடன் உள்ளனவா என்பதைச் சரிபார்த்து உறுதிப்படுத்தவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> தவறான உள்ளீட்டைத் தவிர்க்க, ஒரு சரத்தை `BigInt`/`Number` ஆகப் பார்ஸ் அல்லது மாற்றுவதற்கு முன் `isBinary` ஐ type guard
> ஆகப் பயன்படுத்தவும்.

### நன்மைகள்

- `0b`/`0B` முன்னொட்டுடன் அல்லது இல்லாமல் இரும (binary) சரங்களை ஏற்கிறது.
- காலி சரங்களையும், தொடக்க/முடிவு வெற்றிடங்கள் (ASCII ≤ 32) உள்ள சரங்களையும் நிராகரிக்கிறது.
- எறியாமல் `true`/`false` ஐத் திருப்பி அளிக்கிறது; தெரியாத உள்ளீடுகளுக்கும் பாதுகாப்பானது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isBinary(value)`

அளவுருக்கள்:

- `value`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // சரி
const b = isBinary("1010");   // சரி
const c = isBinary("0b1020"); // தவறு
const d = isBinary(0b1010);     // தவறு

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isBinary(value)`
