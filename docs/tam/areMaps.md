# areMaps

## விளக்கம்

`areMaps` என்பது கொடுக்கப்பட்ட வரிசை காலியாக இல்லையா மற்றும் அதன் அனைத்து கூறுகளும் `Map` இன்ஸ்டன்ஸ்களா என்பதை
நிர்ணயிக்கிறது.

### பயன்பாட்டு நிகழ்வு

அறியப்படாத உள்ளீட்டை (எ.கா., JSON parsing, வெளிப்புற APIகள், அல்லது இயக்கநிலை மூலங்கள்) `Map` பொருட்களின் காலியல்லாத
பட்டியலாகக் கருதுவதற்கு முன் சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> காலியான வரிசைக்கு `false` ஐத் திருப்பும்; வரிசை நிரம்பியிருக்கவும் ஒவ்வொரு கூறும் `Map` ஆகவும் இருந்தால் மட்டுமே
`true` ஐத் திருப்பும்.

### நன்மைகள்

- ஒவ்வொரு கூறும் `Map` இன்ஸ்டன்ஸ் என்பதை உறுதிசெய்கிறது; முழு வரிசையும் சரிபார்ப்பைத் தாண்டினால் மட்டுமே `true` ஐத்
  திருப்பும்.
- வடிவமைப்பிலேயே காலியான வரிசைகளை நிராகரிக்கிறது; “தரவு இல்லை” என்பதைக் தவறுதலாக செல்லுபடியான உள்ளீடாக ஏற்றுக்கொள்வதைத்
  தடுக்கிறது.
- ஒரு தொகுப்பில் `Map`-சார்ந்த செயல்பாடுகள் (எ.கா., `.get()`, `.set()`, iteration) செய்வதற்கு முன் பாதுகாப்புச்
  சரிபார்ப்பாக பயன்படும்.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areMaps(array)`

அளவுருக்கள்:

- `array`: சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // இயக்க நேரத்தில் items என்பது காலியல்லாத Map நிகழ்வுகளின் வரிசை என்று உறுதி செய்யப்படுகிறது
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // இதற்கு false: காலியான வரிசைகள், அல்லது Map அல்லாத எந்த மதிப்பையும் கொண்ட வரிசைகள்
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areMaps(array)`
