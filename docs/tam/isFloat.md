# isFloat

## விளக்கம்

`isFloat` என்பது கொடுக்கப்பட்ட `value` ஒரு முடிவுற்ற மிதவை-புள்ளி எண் (முழு எண் அல்லாத `number`) தானா என்பதை
நிர்ணயிக்கிறது.

### பயன்பாட்டு நிகழ்வு

பகுதி மதிப்புகள் (fractional values) தேவைப்படும் இடங்களில் (எ.கா., விலைகள், அளவீடுகள், விகிதங்கள்) பயனர் வழங்கும் எண்
உள்ளீட்டை சரிபார்த்து, முழு எண்கள், `NaN`, மற்றும் முடிவற்ற மதிப்புகளை நிராகரிக்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> முடிவுற்ற, முழு எண் அல்லாத எண் உள்ளீடுகளை மட்டுமே ஏற்க வேண்டியபோது `isFloat` ஐப் பயன்படுத்துங்கள்; இது முழு எண்களையும்
> முடிவற்ற (non-finite) எண்களையும் நிராகரிக்கும்.

### நன்மைகள்

- முடிவுற்ற, முழு எண் அல்லாத எண்களுக்கு மட்டுமே `true` ஐத் திருப்பும் (முழு எண்கள், `NaN`, `Infinity`, மற்றும்
  `-Infinity` ஆகியவற்றை விலக்கும்).
- எந்த உள்ளீட்டு வகையுடனும் (`unknown`) வேலை செய்து, `typeof value === "number"` என்பதைச் சரிபார்ப்பதன் மூலம்
  பாதுகாப்பாக குறுகிய வகைப்படுத்தலை (narrowing) செய்கிறது.
- முன்கூட்டியே கணிக்கக்கூடிய நடத்தைக்காக உட்பொதிக்கப்பட்ட எண் பாதுகாப்பு சரிபார்ப்புகளை (`Number.isInteger`,
  `Number.isFinite`) பயன்படுத்துகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isFloat(value)`

அளவுருக்கள்:

- `value`: இது மிதவை-புள்ளி எண் (floating-point number) தானா என்பதைச் சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isFloat } from "@type-check/guards";

const inputs: unknown[] = [3.14, -0.1, 1e-7, 42, "3.14", NaN, Infinity];

for (const value of inputs) {
  if (isFloat(value)) {
    // மதிப்பு இயக்க நேரத்தில் ஒரு எண்; அது முடிவுடையது மற்றும் முழு எண் அல்ல
    const rounded = value.toFixed(2);
    console.log("float:", value, "rounded:", rounded);
  } else {
    console.log("not a float:", value);
  }
}
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isFloat(value)`
