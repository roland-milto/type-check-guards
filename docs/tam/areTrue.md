# areTrue

## விளக்கம்

காலியாக இல்லாத ஒரு வரிசையில் boolean `true` மதிப்புகள் மட்டுமே உள்ளனவா என்பதைச் சரிபார்க்கிறது.

### பயன்பாட்டு நிகழ்வு

தொடர்வதற்கு முன் முன்நிபந்தனைகள் அல்லது அம்சக் கொடிகள் அனைத்தும் இயக்கப்பட்டுள்ளனவா (அனைத்து மதிப்புகளும் `true`)
என்பதைச் சரிபார்க்க `areTrue` ஐப் பயன்படுத்துங்கள்; காலி அல்லது தவறான வடிவிலான உள்ளீடுகளை நிறைவேறாததாக (`false`)
கருதும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `areTrue` காலி வரிசைக்கும், கண்டிப்பாக `true` அல்லாத எந்த மதிப்பையும் கொண்ட வரிசைகளுக்கும் `false` ஐத் திருப்பும்.

### நன்மைகள்

- ஒவ்வொரு கூறும் கண்டிப்பாக `true` ஆகவும், வரிசை காலியாக இல்லாமலும் இருக்கும் போது மட்டுமே `true` ஐத் திருப்பும்.
- விரைவாகத் தோல்வியடையும்: `true` அல்லாத மதிப்பு கிடைத்தவுடன் உடனே `false` ஐத் திருப்பும்.
- செல்லாத உள்ளீடுகளை (வரிசை அல்லாதவை அல்லது காலி வரிசைகள்) `false` ஐத் திருப்புவதன் மூலம் நிராகரிக்கும்.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areTrue(array)`

அளவுருக்கள்:

- `array`: அனைத்து `true` மதிப்புகளும் உள்ளதா என்பதைச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areTrue } from "@type-check/guards";

const a = areTrue([true, true, true]);
const b = areTrue([true, false, true]);
const c = areTrue([]);
const d = areTrue([true, "string" as unknown, true]);

console.log(a, b, c, d);
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areTrue(array)`
