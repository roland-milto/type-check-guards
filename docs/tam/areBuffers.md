# areBuffers

## விளக்கம்

`areBuffers` என்பது வழங்கப்பட்ட மதிப்பு காலியானதல்ல, கூறுகள் நிரப்பப்பட்ட வரிசையாகவும், அதில் உள்ள ஒவ்வொரு கூறும்
`Buffer` ஆகவும் உள்ளதா என்பதைச் சரிபார்க்கிறது; அப்படியானால் `true`, இல்லையெனில் `false` திருப்பும்.

### பயன்பாட்டு நிகழ்வு

வரும் chunk வரிசைகள் (எ.கா., ஸ்ட்ரீம்கள், கோப்பு பதிவேற்றங்கள், அல்லது நெட்வொர்க் பாக்கெட்டுகள்) அனைத்துப் பகுதிகளும்
`Buffer` இன்ஸ்டன்ஸ்கள் என்பதை உறுதிசெய்ய சரிபார்த்து, பின்னர் அவற்றை இணைத்தல், டிகோடு செய்தல், அல்லது
குறியாக்க/பைனரி-செயலாக்க செயல்பாடுகளுக்கு அனுப்புதல்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `Buffer.concat` போன்ற Buffer-சார்ந்த API-களை அழைப்பதற்கு முன் `unknown[]` ஐ சரிபார்க்க `areBuffers` ஐ
> பயன்படுத்துங்கள்; ஒவ்வொரு கூறும் `Buffer` ஆக இருக்கும் போது மட்டுமே இந்த செயல்பாடு `true` திருப்புவதை இது
> உறுதிசெய்கிறது.

### நன்மைகள்

- உள்ளீட்டிலுள்ள ஒவ்வொரு கூறும் Node.js `Buffer` இன்ஸ்டன்ஸ் என்பதை உறுதிசெய்கிறது; முழு வரிசையும் பொருந்தும் போது
  மட்டுமே `true` திருப்பும்.
- காலியானதல்ல, கூறுகள் நிரப்பப்பட்ட வரிசை வேண்டும் என்பதன் மூலம் தவறான உள்ளீடுகளை ஆரம்பத்திலேயே நிராகரிக்கிறது; காலியான
  வரிசைகள் அல்லது வரிசையல்லாதவற்றிற்கு `false` திருப்பும்.
- பஃபர்-மட்டும் செயல்பாடுகளை (எ.கா., இணைத்தல், ஹாஷிங், பைனரி நெறிமுறைகள்) செய்வதற்கு முன் பாதுகாப்பு சரிபார்ப்பாக
  பயனுள்ளது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areBuffers(array)`

அளவுருக்கள்:

- `array`: பஃபர் இன்ஸ்டன்ஸ்கள் உள்ளதா எனச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areBuffers } from "@type-check/guards";

const chunks: unknown[] = [Buffer.from("test"), Buffer.from("123")];

if (areBuffers(chunks)) {
  const combined = Buffer.concat(chunks);
  console.log(combined.toString("utf8"));
} else {
  throw new TypeError("Expected a non-empty array of Buffer instances");
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areBuffers(array)`
