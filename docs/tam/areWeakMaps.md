# areWeakMaps

## விளக்கம்

`areWeakMaps` என்பது ஒரு மதிப்பு காலியல்லாத வரிசையா, மேலும் அதில் உள்ள ஒவ்வொரு கூறும் `WeakMap` ஆவதா என்பதைச்
சரிபார்க்கிறது; அந்த நிலையில் மட்டும் `true` ஐத் திருப்பி, இல்லையெனில் `false` ஐத் திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

இயக்கநேர தரவை (எ.கா., பார்ஸ் செய்யப்பட்ட JSON, பிளகின் உள்ளீடுகள், அல்லது தளர்வாக வகைப்படுத்தப்பட்ட கட்டமைப்பு)
சரிபார்த்து, அது `WeakMap` இன்ஸ்டன்ஸ்கள் கொண்ட காலியல்லாத வரிசை என்பதை உறுதிப்படுத்தி, பின்னர் மீளச்சுழற்சி செய்து
`WeakMap` முறைகளை அழைக்க பயன்படுத்துங்கள்; எந்த கூறும் `WeakMap` அல்லாதபோது அல்லது வரிசை காலியாக இருந்தால் `false` ஐத்
திருப்புகிறது.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> அறியப்படாத உள்ளீட்டை காலியல்லாத `WeakMap[]` ஆகக் கருதுவதற்கு முன் அதைச் சரிபார்க்க `areWeakMaps` ஐப் பயன்படுத்துங்கள்;
> காலி வரிசைகளுக்கு இது `false` ஐத் திருப்புகிறது.

### நன்மைகள்

- வழங்கப்பட்ட வரிசையில் உள்ள ஒவ்வொரு கூறும் `WeakMap` இன்ஸ்டன்ஸ் என்பதை உறுதிப்படுத்துகிறது.
- காலி வரிசைகளுக்கு `false` ஐத் திருப்புகிறது; இதனால் “தரவு இல்லை” என்பதைக் தவறுதலாக செல்லுபடியான உள்ளீடாக
  ஏற்றுக்கொள்வதைத் தடுக்கிறது.
- அனைத்து உருப்படிகளிலும் `WeakMap`-சார்ந்த செயல்பாடுகளைச் செய்வதற்கு முன் ஒரு பாதுகாப்பு சரிபார்ப்பாக (guard)
  பயனுள்ளது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areWeakMaps(array)`

அளவுருக்கள்:

- `array`: `WeakMap` இன்ஸ்டன்ஸ்கள் உள்ளதா என்பதைச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  // list என்பது WeakMap நிகழ்வுகளின் காலியல்லாத வரிசை
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  // காலியல்லாத WeakMap[] அல்ல
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areWeakMaps(array)`
