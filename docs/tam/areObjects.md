# areObjects

## விளக்கம்

`areObjects` வழங்கப்பட்ட நிரப்பப்பட்ட வரிசையில் பொருட்கள் மட்டுமே உள்ளனவா என்பதைச் சரிபார்க்கிறது.

### பயன்பாட்டு நிகழ்வு

நீங்கள் தெரியாத ஒரு வரிசையை (எ.கா., JSON parsing அல்லது வெளிப்புற APIகளிலிருந்து) பெறும் போது, அதை மீளச்சுழற்றி பொருள்
பண்புகளை அணுகுவதற்கு முன் அது காலியல்லாததையும் ஒவ்வொரு கூறும் ஒரு பொருளாக இருப்பதையும் உறுதிப்படுத்த `areObjects` ஐப்
பயன்படுத்துங்கள்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `unknown[]` ஐ பொருட்களாகக் கருதுவதற்கு முன் அதைச் சரிபார்க்க `areObjects` ஐப் பயன்படுத்துங்கள்; காலியான வரிசைகளுக்கு
> இது `false` ஐத் திருப்பும்.

### நன்மைகள்

- உள்ளீடு நிரப்பப்பட்ட வரிசையாகவும் ஒவ்வொரு கூறும் ஒரு பொருளாகவும் இருக்கும் போது மட்டுமே `true` ஐத் திருப்பும்.
- பொருளல்லாத கூறு கண்டுபிடிக்கப்பட்டவுடன் உடனே நிறுத்தி `false` ஐத் திருப்பும்.
- பொருள்-சார்ந்த செயல்பாடுகளை செய்வதற்கு முன் தெரியாத உள்ளீட்டை சரிபார்க்க உதவும்.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areObjects(array)`

அளவுருக்கள்:

- `array`: பொருள் கூறுகள் உள்ளதா என்பதைச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areObjects } from "@type-check/guards";

const value: unknown = [{}, { a: 1 }, new Date()];

if (Array.isArray(value) && areObjects(value)) {
  // value என்பது பொருட்களின் நிரப்பப்பட்ட வரிசை
  console.log("All items are objects:", value.length);
} else {
  console.log("Not a filled array of objects");
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areObjects(array)`
