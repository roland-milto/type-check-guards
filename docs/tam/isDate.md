# isDate

## விளக்கம்

`isDate` வழங்கப்பட்ட மதிப்பு `Date` ஆக உள்ளதா என்பதைத் தீர்மானித்து, `Date` இன்ஸ்டன்ஸ்களுக்கு `true` மற்றும் இல்லையெனில்
`false` என்பதைத் திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

`toISOString()` ஐ அழைப்பது போன்ற வடிவமைத்தல், ஒப்பீடுகள், அல்லது `Date` செயல்பாடுகளைச் செய்வதற்கு முன் தெரியாத
மதிப்புகளை (எ.கா., request data, config values, அல்லது parsed JSON) சரிபார்த்து குறுக்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> ரன்டைமில் `unknown` ஐ `Date` ஆக குறுக்க `isDate` ஐப் பயன்படுத்துங்கள்; இது உண்மையான `Date` இன்ஸ்டன்ஸ்களுக்கு மட்டுமே
`true` திருப்பும் (date strings க்கு அல்ல).

### நன்மைகள்

- ஒரு மதிப்பு `Date` ஆக உள்ளதா என்பதைச் சரிபார்க்க ஒரு எளிய ரன்டைம் காவலை இது வழங்குகிறது.
- சரிபார்ப்பை `Date` இன்ஸ்டன்ஸ்கள் மட்டுமே கடக்குமாறு உறுதி செய்வதன் மூலம் வகை பிழைகளைத் தவிர்க்க இது உதவுகிறது.
- தேதி-சார்ந்த முறைகளைப் பயன்படுத்துவதற்கு முன் தெரியாத உள்ளீடுகளை (எ.கா., API payloads) சரிபார்ப்பதற்கு இது பயனுள்ளது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isDate(value)`

அளவுருக்கள்:

- `value`: `Date` வகைக்காகச் சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isDate } from "@type-check/guards";

const input: unknown = new Date();

if (isDate(input)) {
  // இங்கே input ஒரு Date ஆகும்
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a Date");
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isDate(value)`
