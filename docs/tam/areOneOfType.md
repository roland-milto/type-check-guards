# areOneOfType

## விளக்கம்

`areOneOfType` என்பது காலியல்லாத ஒரு வரிசையில் உள்ள அனைத்து உருப்படிகளும் குறிப்பிடப்பட்ட இயக்கநேர வகைகளில் ஒன்றாக
உள்ளனவா என்பதைச் சரிபார்க்கிறது.

### பயன்பாட்டு நிகழ்வு

வரும் தரவை (எ.கா., parse செய்யப்பட்ட JSON) சரிபார்க்கவும்; ஒரு புலம் காலியல்லாத வரிசையாக இருக்க வேண்டும், மேலும் அதன்
உருப்படிகள் அறியப்பட்ட அடிப்படை வகைகளின் தொகுப்பிற்குள் மட்டுமே இருக்க வேண்டும்; வரிசை காலியாக இருந்தாலோ அல்லது
அனுமதிக்கப்படாத எந்த வகையும் இருந்தாலோ `false` ஐத் திருப்பவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> இந்த செயல்பாடு boolean ஐத் திருப்பும்; தொகுப்புநேரத்தில் வரிசை உருப்படி வகைகளை குறுக்காது. மேலதிக செயலாக்கத்திற்கு
> முன் இயக்கநேர சரிபார்ப்பு படியாக இதைப் பயன்படுத்தவும்.

### நன்மைகள்

- ஒரு வரிசையில் உள்ள ஒவ்வொரு உருப்படியும் அனுமதிக்கப்பட்ட இயக்கநேர வகைகளில் குறைந்தது ஒன்றுடன் பொருந்துவதை உறுதி
  செய்கிறது; முழு வரிசையும் தகுதி பெற்றால் மட்டுமே `true` ஐத் திருப்பும்.
- தவறான உள்ளீடுகளை ஆரம்பத்திலேயே நிராகரிக்கிறது: `array` அல்லது `types` காலியாக இருந்தால் அல்லது நிரப்பப்பட்ட வரிசையாக
  இல்லாவிட்டால் `false` ஐத் திருப்பும்.
- `areOneOfType`-க்கு ஒரே அழைப்பில் கலப்பு-வகை தொகுப்புகளை (எ.கா., எண்கள் மற்றும் சரங்கள்) சரிபார்க்க பயனுள்ளது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areOneOfType(array, types)`

அளவுருக்கள்:

- `array`: வழங்கப்பட்ட வகைகளுடன் ஒப்பிட்டு சரிபார்க்க வேண்டிய உருப்படிகளின் வரிசை.
- `types`: சரிபார்க்க வேண்டிய தரவு வகைகளை குறிக்கும் சரங்களின் வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areOneOfType } from "@type-check/guards";

const values1: unknown[] = [1, "a", true];
const ok1 = areOneOfType(values1, ["number", "string", "boolean"]);

const values2: unknown[] = [1, "a", {}];
const ok2 = areOneOfType(values2, ["number", "string"]);

const values3: unknown[] = [];
const ok3 = areOneOfType(values3, ["number"]);

console.log({ ok1, ok2, ok3 });
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areOneOfType(array, types)`
