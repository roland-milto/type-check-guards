# isDecimal

## விளக்கம்

`isDecimal` என்பது ஒரு மதிப்பு முன்னும் பின்னும் வெற்றிடங்கள் இல்லாமல், செல்லுபடியான தசம வடிவத்துடன் கூடிய தசம சரம்
பிரதிநிதித்துவமா என்பதைச் சரிபார்க்கிறது.

### பயன்பாட்டு நிகழ்வு

படிவப் புலங்கள், API payloads, அல்லது கட்டமைப்பு மதிப்புகள் போன்றவை எந்தச் சுற்றியுள்ள வெற்றிடங்களும் இல்லாமல் (
விருப்பமாக குறியுடன்) தசம சரமாக வழங்கப்பட வேண்டும் என்றால், அவற்றை parse செய்வதற்கு அல்லது சேமிப்பதற்கு முன்
சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `isDecimal`-ஐ பயனர் உள்ளீட்டை மாற்றுவதற்கு முன் (எ.கா., `Number(value)` மூலம்) சரிபார்க்கப் பயன்படுத்துங்கள்,
> குறிப்பாக வெற்றிடங்களை நிராகரிக்க வேண்டியபோது.

### நன்மைகள்

- உள்ளீடு ஒரு சரம் (string) என்பதையும் அது தசம-எழுத்துமுறை (decimal-literal) வடிவத்துடன் பொருந்துகிறதையும் கடுமையாகச்
  சரிபார்க்கிறது.
- தெளிவற்ற பகுப்பாய்வைத் தவிர்க்க, முன்னும் பின்னும் உள்ள வெற்றிடங்களை (கட்டுப்பாட்டு எழுத்துகள் உட்பட) நிராகரிக்கிறது.
- regex இயக்குவதற்கு முன் வேகமான முன்-சரிபார்ப்புகளை (வகைச் சரிபார்ப்பு மற்றும் முதல்/கடைசி எழுத்து) செய்கிறது.
- guards மற்றும் உள்ளீடு சரிபார்ப்புக்கு ஏற்ற எளிய boolean முடிவை (`true`/`false`) திருப்புகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isDecimal(value)`

அளவுருக்கள்:

- `value`: தசம சரம் வடிவமா என்பதைச் சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v இங்கே ஒரு சரம் (இயக்கநேரத்தில் சரிபார்க்கப்பட்டது)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isDecimal(value)`
