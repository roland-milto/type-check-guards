# isUndefined

## விளக்கம்

கொடுக்கப்பட்ட மதிப்பு `undefined` ஆக உள்ளதா என்பதைச் சரிபார்க்கிறது.

### பயன்பாட்டு நிகழ்வு

விருப்பமான உள்ளீடுகளை பாதுகாக்க, காணாமல் போன பண்புகளை கண்டறிய, அல்லது “வழங்கப்படவில்லை” (`undefined`) மற்றும்
“வெளிப்படையாக காலி” (`null`) என்பவற்றை வேறுபடுத்த `isUndefined` ஐ பயன்படுத்துங்கள்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `undefined` ( `null` அல்ல) என்பதை குறிப்பாக கண்டறிய வேண்டிய போது `isUndefined` ஐ பயன்படுத்துங்கள். இது
`typeof value === "undefined"` மீது சார்ந்திருப்பதால் பாதுகாப்பானது.

### நன்மைகள்

- `typeof` ஐ பயன்படுத்தி `undefined` என்பதை தெளிவாகவும் வெளிப்படையாகவும் சரிபார்க்கிறது; அறிவிக்கப்படாத மாறிகளால்
  ஏற்படும் விளிம்பு நிலைகளைத் தவிர்க்கிறது.
- காவல்கள், கிளை பிரிப்புகள், மற்றும் சரிபார்ப்பு தர்க்கத்திற்கு ஏற்ற எளிய boolean முடிவை (`true`/`false`)
  திருப்புகிறது.
- `undefined` ஐ `null`, `0`, `""`, அல்லது `NaN` போன்ற பிற “காலி” மதிப்புகளிலிருந்து வேறுபடுத்த உதவுகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isUndefined(value)`

அளவுருக்கள்:

- `value`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isUndefined } from "@type-check/guards";

let x: unknown;

if (isUndefined(x)) {
  // இங்கே x வரையறுக்கப்படாதது
} else {
  // இங்கே x வரையறுக்கப்படாதது அல்ல
}

const a = isUndefined(undefined); // உண்மை
const b = isUndefined(null);      // பொய்
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isUndefined(value)`
