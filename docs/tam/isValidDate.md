# isValidDate

## விளக்கம்

`isValidDate` கொடுக்கப்பட்ட மதிப்பு செல்லுபடியான `Date` பொருளா என்பதைச் சரிபார்த்து, உண்மையான, செல்லாததல்லாத தேதிகளுக்கு
மட்டும் `true` ஐத் திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

பயனர் உள்ளீடு அல்லது API தரவில் தேதிகள் இருக்கக்கூடிய சூழலில், தேதி கணக்கீடுகள், வடிவமைப்பு, அல்லது ஒப்பீடுகளைச்
செய்வதற்கு முன் அந்த மதிப்பு உண்மையான `Date` இன்ஸ்டன்ஸ் தானா மற்றும் அது செல்லாத தேதி அல்லதா என்பதை உறுதிப்படுத்த
சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `unknown` என வகைப்படுத்தப்பட்ட மதிப்புகளில் `Date` முறைகள் (எ.கா., `toISOString`, `getTime`) அழைக்கும் முன், அவை
> செல்லுபடியான `Date` பொருள்கள் என்பதை உறுதிசெய்ய `isValidDate` ஐ பயன்படுத்துங்கள்.

### நன்மைகள்

- ஒரு மதிப்பு வெறும் தேதி போன்ற சரம் அல்லது எண் அல்லாமல், அது `Date` இன்ஸ்டன்ஸ் என்பதை உறுதிசெய்கிறது.
- `NaN` நேர மதிப்புகளைச் சரிபார்த்து, செல்லாத தேதிகளை (எ.கா., `new Date("invalid")`) நிராகரிக்கிறது.
- நிபந்தனைகள் மற்றும் சரிபார்ப்பு (validation) பைப்லைன்களில் பயன்படுத்த எளிதான எளிய boolean guard.
- உள்ளீட்டை முதலில் சரிபார்ப்பதன் மூலம் தேதி முறைகளை அழைக்கும் போது ஏற்படும் runtime பிழைகளைத் தவிர்க்க உதவுகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isValidDate(value)`

அளவுருக்கள்:

- `value`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isValidDate } from "@type-check/guards";

const input: unknown = new Date();

if (isValidDate(input)) {
  // input ஒரு செல்லுபடியான Date நிகழ்வு
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a valid Date");
}

console.log(isValidDate(new Date("invalid"))); // false
console.log(isValidDate("2025-12-22")); // false

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isValidDate(value)`
