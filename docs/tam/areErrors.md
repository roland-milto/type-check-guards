# areErrors

## விளக்கம்

ஒரு வரிசை காலியாக இல்லாமல் `Error` பொருட்களையே கொண்டுள்ளதா என்பதைச் சரிபார்த்து, `true` அல்லது `false` ஐத்
திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

ரன்டைமில் வழங்கப்படும் `unknown[]` (எ.கா., ஒருங்கிணைக்கப்பட்ட தோல்விகள், சரிபார்ப்பு முடிவுகள், அல்லது டிசீரியலைஸ்
செய்யப்பட்ட தரவு) மீது மீளச்சுழற்சி செய்யும் முன், பதிவு செய்யும் முன், அல்லது மீண்டும் எறியும் முன், அது காலியாக இல்லாத
`Error` பொருட்களின் பட்டியலா என்பதைச் சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `areErrors` என்பது ஒவ்வொரு உருப்படியும் `Error` ஆக இருக்கும் நிரம்பிய வரிசைக்கு மட்டுமே `true` ஐத் திருப்பும்; காலியான
> வரிசைக்கு அல்லது எந்த உருப்படியும் `Error` அல்லாதிருந்தால் `false` ஐத் திருப்பும்.

### நன்மைகள்

- ஒவ்வொரு உருப்படியும் `Error` இன்ஸ்டன்ஸ் என்பதை உறுதி செய்கிறது; இதனால் பாதுகாப்பான பிழை கையாளுதல் மற்றும் பதிவு
  செய்தல் சாத்தியமாகிறது.
- காலியான வரிசைகளை நிராகரிக்கிறது; இதனால் தவறுதலாக “பிழைகள் இல்லை” என்ற நிலைகள் செல்லுபடியாகும் பிழை பட்டியல்களாக
  கருதப்படுவதைத் தடுக்கிறது.
- `unknown[]` உள்ளீடுகளுடன் (எ.கா., APIகளிலிருந்து அல்லது `catch` பிளாக்குகளிலிருந்து) பணிபுரியும் போது ரன்டைம் காவலராக
  நன்றாக செயல்படுகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areErrors(array)`

அளவுருக்கள்:

- `array`: `Error` பொருட்கள் உள்ளதா என்பதைச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areErrors } from "@type-check/guards";

const value: unknown = [new Error("error1"), new TypeError("error2")];

if (Array.isArray(value) && areErrors(value)) {
  // value என்பது Error பொருட்களின் காலியல்லாத வரிசை
  for (const err of value) {
    console.error(err.name, err.message);
  }
} else {
  console.log("Not a non-empty Error[]");
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areErrors(array)`
