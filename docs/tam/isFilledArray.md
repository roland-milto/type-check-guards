# isFilledArray

## விளக்கம்

`value` குறைந்தது ஒரு உருப்படியைக் கொண்ட வரிசையா என்பதைச் சரிபார்த்து, `true` அல்லது `false` திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

மீளச்சுழற்சி செய்வதற்கு முன், முதல் உருப்படியை அணுகுவதற்கு முன், அல்லது குறைந்தது ஒரு உருப்படி தேவைப்படும் தர்க்கத்தைப்
பயன்படுத்துவதற்கு முன், வரும் தரவை (எ.கா., API payloads, படிவ மதிப்புகள், கட்டமைப்பு) சரிபார்க்க `isFilledArray`-ஐ
பயன்படுத்தவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `isFilledArray` என்பது boolean-ஐத் திருப்பும் ஒரு runtime guard; வரிசை காலியல்லாதது என்பதை உறுதிப்படுத்துவதைக்
> கடந்தும் உருப்படிகளின் வகைகளை இது மேலும் குறுக்காது.

### நன்மைகள்

- `Array.isArray` மற்றும் நீளச் சரிபார்ப்பைப் பயன்படுத்தி காலியல்லாத வரிசையை எளிமையாகவும் வேகமாகவும் சரிபார்க்கலாம்.
- குறியீடு ஒரு வரிசையில் குறைந்தது ஒரு உருப்படி உள்ளது என்று கருதும் போது ஏற்படும் இயக்கநேரப் பிழைகளைத் தவிர்க்க
  உதவுகிறது.
- தெளிவான boolean முடிவு: காலியல்லாத வரிசைகளுக்கு `true` மற்றும் இல்லையெனில் `false` திருப்புகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `isFilledArray(value)`

அளவுருக்கள்:

- `value`: இது காலியல்லாத வரிசையா என்பதைச் சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { isFilledArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && isFilledArray(input)) {
  // input இயக்க நேரத்தில் காலியல்லாத வரிசை ஆகும்
  console.log(input[0]);
} else {
  console.log("Not a non-empty array");
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.isFilledArray(value)`
