# areDates

## விளக்கம்

`areDates` கொடுக்கப்பட்ட வரிசை நிரம்பியதா மற்றும் அதில் `Date` பொருட்களே உள்ளனவா என்பதை நிர்ணயித்து, அனைத்து கூறுகளும்
செல்லுபடியான தேதிகளாக இருக்கும் போது மட்டுமே `true` திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

தேதி-சார்ந்த தர்க்கங்களை (உதா., நேரத்தின் அடிப்படையில் வரிசைப்படுத்துதல், வடிவமைத்தல், அல்லது வரம்புகளை கணக்கிடுதல்)
இயக்குவதற்கு முன், தெரியாத உள்ளீடுகளை (எ.கா., parse செய்யப்பட்ட JSON, படிவத் தரவு, API payloads) சரிபார்க்க `areDates` ஐ
பயன்படுத்துங்கள்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> ஒவ்வொரு கூறும் `Date` ஆக இருக்கும் காலியாக இல்லாத வரிசைகளுக்கு மட்டுமே `true` திருப்புகிறது; காலியான வரிசைகள் `false`
> தரும்.

### நன்மைகள்

- ஒரு வரிசையின் உள்ளடக்கத்தை சரிபார்ப்பதற்கு முன் அது காலியாக இல்லையென உறுதி செய்கிறது; காலியான உள்ளீடுகளுக்கு `true`
  திரும்புவதைத் தடுக்கிறது.
- ஒவ்வொரு கூறும் `Date` இன்ஸ்டன்ஸ் என்பதை உறுதிப்படுத்துகிறது; முதல் பொருந்தாமை ஏற்பட்டவுடன் உடனடியாக `false`
  திருப்புகிறது.
- வரிசை உருப்படிகளில் தேதி-சார்ந்த செயல்பாடுகளை செய்யும் முன் guard-பாணி சரிபார்ப்பாக பயனுள்ளது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areDates(array)`

அளவுருக்கள்:

- `array`: `Date` பொருட்கள் உள்ளதா எனச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areDates } from "@type-check/guards";

const a: unknown[] = [new Date(), new Date("2021-01-01")];
const b: unknown[] = [];
const c: unknown[] = [new Date(), "not a date"];

console.log(areDates(a)); // சரி
console.log(areDates(b)); // தவறு
console.log(areDates(c)); // தவறு

if (areDates(a)) {
  const timestamps = a.map(d => d.getTime());
  console.log(timestamps);
}
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areDates(array)`
