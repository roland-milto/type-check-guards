# areDecimals

## விளக்கம்

ஒரு வரிசையில் உள்ள அனைத்து கூறுகளும் தசம எண்களா மற்றும் அந்த வரிசை நிரப்பப்பட்டதா என்பதைச் சரிபார்த்து, `true` அல்லது
`false` ஐத் திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

பயனர் வழங்கும் பட்டியல்கள் (எ.கா., CSV நெடுவரிசைகள் அல்லது படிவ உள்ளீடுகள்) காலியாக இல்லாமல், ஒவ்வொரு பதிவும் தசம
மதிப்பாக இருப்பதைப் பாகுபடுத்தல் (parsing) அல்லது கணக்கீடுகளுக்கு முன் உறுதி செய்ய சரிபார்க்கவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `unknown[]` காலியாக இல்லாமல், ஒவ்வொரு கூறும் தசம பிரதிநிதித்துவமாக இருப்பதை விரைவாக boolean ஆகச் சரிபார்க்க வேண்டிய
> போது `areDecimals` ஐப் பயன்படுத்துங்கள்.

### நன்மைகள்

- உருப்படிகளை சரிபார்ப்பதற்கு முன் உள்ளீடு நிரப்பப்பட்ட வரிசை (array) என்பதை உறுதி செய்கிறது; இதனால் காலியான பட்டியல்கள்
  தவறுதலாக ஏற்றுக்கொள்ளப்படுவது தடுக்கப்படுகிறது.
- ஒவ்வொரு கூறையும் `isDecimal` மூலம் சரிபார்க்கிறது; ஆகவே கலந்த அல்லது செல்லாத மதிப்புகள் உடனடியாக `false` முடிவை
  ஏற்படுத்தும்.
- காவலர்கள் (guards) மற்றும் முன்கூட்டிய-திரும்பல் (early-return) சரிபார்ப்பு ஓட்டங்களுக்கு ஏற்ற எளிய boolean முடிவை (
  `true`/`false`) வழங்குகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areDecimals(array)`

அளவுருக்கள்:

- `array`: சரிபார்க்க வேண்டிய வரிசை (array).

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // உண்மை
console.log(areDecimals(b)); // பொய்
console.log(areDecimals(c)); // பொய்
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areDecimals(array)`
