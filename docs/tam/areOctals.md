# areOctals

## விளக்கம்

`areOctals` வழங்கப்பட்ட மதிப்பு செல்லுபடியான எட்டுமுறை சரங்களின் காலியல்லாத வரிசையா என்பதை நிர்ணயிக்கிறது.

### பயன்பாட்டு நிகழ்வு

பயனர் உள்ளீடு, கட்டமைப்பு மதிப்புகள், அல்லது API payloads ஆகியவற்றைச் சரிபார்க்கும்போது `areOctals` ஐப்
பயன்படுத்துங்கள்; அவை எட்டுமுறை literals (எ.கா., `0o755` போன்ற கோப்பு அனுமதி முறைகள்) கொண்டிருக்க வேண்டும், மேலும்
காலியான வரிசைகள் அல்லது எந்தச் செல்லாத பதிவுகளையும் `false` திருப்பி நிராகரிக்க விரும்பும்போது இது உதவும்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> `Number(...)` அல்லது தனிப்பயன் பகுப்பாய்வு மூலம் மாற்றுவதற்கு முன், ஒவ்வொரு பதிவும் செல்லுபடியான எட்டுமுறை சரமாக
> இருக்கும் காலியல்லாத `unknown[]` உங்களிடம் இருப்பதை உறுதிப்படுத்த `areOctals` ஐப் பயன்படுத்துங்கள்.

### நன்மைகள்

- ஒரு மதிப்பு காலியல்லாத வரிசையாக (array) இருப்பதையும், அதில் உள்ள ஒவ்வொரு உறுப்பும் எட்டுமுறை (octal) சரமாக (string)
  இருப்பதையும் சரிபார்த்து, அனைத்து உருப்படிகளும் தேர்ச்சி பெறும் போது மட்டுமே `true` ஐத் திருப்புகிறது.
- விரைவாக தோல்வியடையும்: எட்டுமுறை அல்லாத ஒரு உருப்பு கண்டுபிடிக்கப்பட்டவுடன் உடனே `false` ஐத் திருப்புகிறது.
- இயக்கநேரப் பிழைகள் மற்றும் ஒற்றுமையற்ற உள்ளீடு கையாளுதலைத் தவிர்க்க, எட்டுமுறை சரங்களைப் பகுப்பாய்வு (parse) அல்லது
  மாற்றுவதற்கு முன் ஒரு பாதுகாப்பு (guard) ஆகப் பயன்படுத்த உதவும்.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areOctals(array)`

அளவுருக்கள்:

- `array`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value என்பது எண்ம எண் (octal) சரங்களின் காலியல்லாத வரிசை
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areOctals(array)`
