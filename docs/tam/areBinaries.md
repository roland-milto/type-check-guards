# areBinaries

## விளக்கம்

வழங்கப்பட்ட மதிப்பு செல்லுபடியான பைனரி சரங்களின் காலியல்லாத வரிசையா என்பதைச் சரிபார்த்து, அனைத்து உருப்படிகளும்
சரிபார்ப்பைத் தாண்டினால் மட்டுமே `true` என்பதைத் திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

தெரியாத பட்டியலை (எ.கா., JSON, படிவங்கள், அல்லது APIs இலிருந்து) பெறும் போது, அதை பார்ச் அல்லது செயலாக்குவதற்கு முன் அது
பைனரி சரங்களின் காலியல்லாத வரிசை என்பதை உறுதி செய்ய வேண்டியிருந்தால் `areBinaries` ஐ பயன்படுத்துங்கள்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> பைனரி சரங்களை numbers/BigInts ஆக மாற்றுவதற்கு முன் தெரியாத உள்ளீட்டை சரிபார்க்க `areBinaries` ஐ பயன்படுத்துங்கள்; இது
> வரிசை காலியல்லாததையும் ஒவ்வொரு கூறும் செல்லுபடியான பைனரி சரமென்பதையும் உறுதி செய்கிறது.

### நன்மைகள்

- ஒவ்வொரு கூறும் செல்லுபடியான பைனரி சரமாக உள்ள, காலியல்லாத வரிசையாக ஒரு மதிப்பு இருப்பதை சரிபார்க்கிறது.
- காவல்கள், ஆரம்ப திருப்பல்கள், மற்றும் உள்ளீடு சரிபார்ப்புக்கு ஏற்ற எளிய boolean முடிவை (`true`/`false`) திருப்புகிறது.
- பைனரி அல்லாத எந்தப் பதிவும் உள்ள வரிசைகளை நிராகரிப்பதன் மூலம் பின்னர் ஏற்படும் பார்சிங் பிழைகளைத் தடுக்கிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areBinaries(array)`

அளவுருக்கள்:

- `array`: சரிபார்க்க வேண்டிய மதிப்பு.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // சரி
console.log(areBinaries(b)); // தவறு
console.log(areBinaries([])); // தவறு
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areBinaries(array)`
