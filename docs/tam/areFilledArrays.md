# areFilledArrays

## விளக்கம்

`areFilledArrays` ஒரு இரு-பரிமாண வரிசை காலியாக இல்லையா மற்றும் அதன் அனைத்து உள் வரிசைகளும் காலியாக இல்லையா என்பதைச்
சரிபார்க்கிறது.

### பயன்பாட்டு நிகழ்வு

அட்டவணை அல்லது மேட்ரிக்ஸ் போன்ற உள்ளீடுகளை (எ.கா., CSV வரிசைகள், கிரிட் தரவு, குழுவாக்கப்பட்ட முடிவுகள்) சரிபார்க்க
`areFilledArrays` ஐப் பயன்படுத்துங்கள்; இதனால் குறைந்தது ஒரு உள் வரிசை உள்ளது மற்றும் எந்த உள் வரிசையும் காலியாக இல்லை
என்று பாதுகாப்பாகக் கருதலாம்.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> 2D வரிசையில் குறைந்தது ஒரு வரிசை இருக்கிறது மற்றும் ஒவ்வொரு வரிசையிலும் குறைந்தது ஒரு உருப்படி இருக்கிறது என்பதை
> உறுதிப்படுத்தி, அதில் மீளச்சுழற்சி செய்ய அல்லது குறியீட்டால் அணுகுவதற்கு முன் `areFilledArrays` ஐப் பயன்படுத்துங்கள்.

### நன்மைகள்

- வெளிப்புற வரிசை காலியாக இல்லையெனவும், ஒவ்வொரு உள் வரிசையும் காலியாக இல்லையெனவும் சரிபார்க்கிறது; இரு நிபந்தனைகளும்
  பூர்த்தியானால் மட்டுமே `true` ஐத் திருப்புகிறது.
- உள் வரிசைகளுக்குள் உள்ள எந்த உருப்படி வகைகளுடனும் (எ.கா., எண்கள், சரங்கள், பொருட்கள், உட்பொதிந்த வரிசைகள்) வேலை
  செய்கிறது; ஏனெனில் இது உருப்படி உள்ளடக்கத்தை அல்ல, வரிசை “நிரம்பிய” நிலையையே மட்டும் சரிபார்க்கிறது.
- இரு-பரிமாண தரவை செயலாக்குவதற்கு முன் பாதுகாப்புச் சரிபார்ப்பாகப் பயன்படுத்த ஏற்ற எளிய பூலியன் முடிவை (`true`/`false`)
  வழங்குகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `areFilledArrays(array)`

அளவுருக்கள்:

- `array`: சரிபார்க்க வேண்டிய இரு-பரிமாண வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { areFilledArrays } from "@type-check/guards";

const a: unknown[][] = [[1]];
const b: unknown[][] = [["a", "b"], [1, 2, 3]];
const c: unknown[][] = [[{}, []], ["string"]];
const d: unknown[][] = [[]];
const e: unknown[][] = [[], [1, 2, 3]];
const f: unknown[][] = [];

console.log(areFilledArrays(a)); // சரி
console.log(areFilledArrays(b)); // சரி
console.log(areFilledArrays(c)); // சரி
console.log(areFilledArrays(d)); // தவறு
console.log(areFilledArrays(e)); // தவறு
console.log(areFilledArrays(f)); // தவறு

```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.areFilledArrays(array)`
