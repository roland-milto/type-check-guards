# arePlainObjects

## விளக்கம்

ஒரு வரிசையிலுள்ள அனைத்து கூறுகளும் சாதாரண (plain) பொருள்களா என்பதைச் சரிபார்த்து, ஒவ்வொரு கூறும் தகுதி பெற்றால் மட்டுமே
`true` ஐத் திருப்புகிறது.

### பயன்பாட்டு நிகழ்வு

வெளிப்புற அல்லது வகையிடப்படாத தரவை (எ.கா., parse செய்யப்பட்ட JSON, API payloads, படிவ சமர்ப்பிப்புகள்) சரிபார்த்து,
நீங்கள் காலியல்லாத ஒரு வரிசையைப் பெற்றுள்ளீர்கள் என்றும் அதிலுள்ள ஒவ்வொரு பதிவும் ஒரு சாதாரண (plain) பொருள் என்றும்
உறுதிசெய்த பிறகு, அதில் மீளச்சுழற்றி (iterate) பண்புகளை வாசிக்க.

> **TypeScript பயனர்களுக்கான குறிப்பு:**
>
> TypeScript-இல் தெரியாத உள்ளீட்டை `Record<string, unknown>[]` (அல்லது இன்னும் கடுமையான பொருள் வடிவம்) எனக் கருதுவதற்கு
> முன் அதைச் சரிபார்க்க `arePlainObjects` ஐப் பயன்படுத்துங்கள்.

### நன்மைகள்

- உள்ளீட்டு வரிசையிலுள்ள ஒவ்வொரு கூறும் ஒரு சாதாரண (plain) பொருளா என்பதை உறுதிசெய்கிறது; அனைத்து உருப்படிகளும்
  பொருந்தினால் மட்டுமே `true` ஐத் திருப்புகிறது.
- செல்லாத உள்ளீடுகளை (வரிசையல்லாதவை அல்லது காலியான வரிசைகள்) `false` ஐத் திருப்பி ஆரம்பத்திலேயே நிராகரிக்கிறது.
- object-literal பொருள்களையும் `Object.create(null)` மூலம் உருவாக்கப்பட்ட பொருள்களையும் செல்லுபடியான சாதாரண (plain)
  பொருள்களாகக் கருதுகிறது.

## பயன்பாடு

### சிண்டாக்ஸ்

செயல்பாடு:

- `arePlainObjects(array)`

அளவுருக்கள்:

- `array`: சாதாரண (plain) பொருள் கூறுகளுக்காகச் சரிபார்க்க வேண்டிய வரிசை.

### உள்ளூர் செயல்பாடு இறக்குமதி

```ts
import { arePlainObjects } from "@type-check/guards";

const a = arePlainObjects([{ a: 1 }, { b: 2 }]); // சரி
const b = arePlainObjects([{}, Object.create(null)]); // சரி
const c = arePlainObjects([{ a: 1 }, 2 as unknown]); // தவறு
const d = arePlainObjects([] as unknown[]); // தவறு
```

### உலகளாவிய பொருள் இறக்குமதி

செயல்பாடுகளை உலகளாவிய பொருள் முறைகளாக இறக்குமதி செய்ய பயன்படுத்தவும்:

```ts
import "@type-check/guards/register-global-object.mjs";
```

பின்னர் கீழ்க்காணும் முறை உலகளாவியமாக கிடைக்கும்:

- `Type.arePlainObjects(array)`
