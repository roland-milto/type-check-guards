# areWeakMaps

## چۈشەندۈرۈش

`areWeakMaps` بىر قىممەتنىڭ بوش بولمىغان سانلار قاتارى بولۇپ، ئۇنىڭدىكى ھەر بىر ئېلېمېنت `WeakMap` ئىكەنلىكىنى
تەكشۈرىدۇ؛ پەقەت شۇ ھالەتتە `true` قايتۇرىدۇ، باشقا بارلىق ھالەتلەردە `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

ئىجرا ۋاقتىدىكى سانلىق مەلۇماتنى (مەسىلەن، پارس قىلىنغان JSON، قىستۇرما كىرگۈزۈشلىرى ياكى بوش تىپلانغان سەپلىمە)
دەلىللەپ، ئۇنىڭ `WeakMap` نۇسخىلىرىدىن تەركىب تاپقان بوش بولمىغان سانلار قاتارى ئىكەنلىكىنى جەزملەشتۈرۈپ، ئاندىن
ئايلىنىپ چىقىپ `WeakMap` مېتودلىرىنى چاقىرىش؛ ھەر قانداق ئېلېمېنت `WeakMap` بولمىسا ياكى سانلار قاتارى بوش بولسا `false`
قايتۇرىدۇ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> نامەلۇم كىرگۈزۈشنى بوش بولمىغان `WeakMap[]` دەپ قاراشتىن بۇرۇن دەلىللەش ئۈچۈن `areWeakMaps` نى ئىشلىتىڭ؛ ئۇ بوش سانلار
> قاتارى ئۈچۈن `false` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- تەمىنلەيدۇكى، تەمىنلەنگەن سانلار قاتارىدىكى ھەر بىر ئېلېمېنت `WeakMap` نۇسخىسى بولسۇن.
- بوش سانلار قاتارى ئۈچۈن `false` قايتۇرىدۇ، بۇ «سانلىق مەلۇمات يوق» نى توغرا كىرگۈزۈش دەپ خاتا قوبۇل قىلىپ قويۇشنىڭ
  ئالدىنى ئالىدۇ.
- بارلىق تۈرلەرگە `WeakMap` غا خاس مەشغۇلاتلارنى ئىجرا قىلىشتىن بۇرۇن قوغدىغۇچ (guard) سۈپىتىدە پايدىلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areWeakMaps(array)`

پارامېتىرلار:

- `array`: `WeakMap` نۇسخىلىرى بار-يوقلۇقىنى تەكشۈرىدىغان سانلار قاتارى.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  //‎‎ list WeakMap نۇسخىلىرىدىن تەركىب تاپقان بوش بولمىغان تىزىم
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  //‎‎ بوش بولمىغان WeakMap[] ئەمەس
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areWeakMaps(array)`
