# areValidDates

## چۈشەندۈرۈش

بىر ئاراي بوش ئەمەسلىكىنى ۋە پۈتۈنلەي ئىناۋەتلىك `Date` ئوبيېكتلىرىدىن تەركىب تاپقانلىقىنى بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

چېسلا-ئاساسلىق مەشغۇلاتلارنى (تەرتىپلەش، دائىرە تەكشۈرۈش، فورماتلاش) ئىجرا قىلىشتىن بۇرۇن، ئىشلەتكۈچى تەمىنلىگەن ياكى
API تەمىنلىگەن ئارايلىرىنى دەلىللەش ئۈچۈن `areValidDates` نى ئىشلىتىڭ؛ بۇ ئارقىلىق بارلىق كىرگۈزۈشلەرنىڭ ھەقىقىي،
ئىناۋەتلىك `Date` ئوبيېكتلىرى ئىكەنلىكى ۋە تىزىملىكنىڭ بوش ئەمەسلىكىگە كاپالەتلىك قىلىسىز.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areValidDates` بوش ئاراي ئۈچۈن `false` قايتۇرىدۇ؛ ئۇنى دەلىللەش قەدىمى سۈپىتىدە ئىشلىتىشكە تايىنىشتىن بۇرۇن، ئاراي
> ھەقىقەتەن بوش بولماسلىقى كېرەكلىكىنى جەزملەشتۈرۈڭ.

### ئەۋزەللىكلەر

- پەقەت ھەر بىر ئېلېمېنت ئىناۋەتلىك `Date` ئىنستانسى بولغاندا (`new Date('invalid')` غا ئوخشاش ئىناۋەتسىز چېسلا
  بولمىغاندا)لا `true` قايتۇرىدۇ.
- `false` قايتۇرۇش ئارقىلىق بوش كىرگۈزۈشنى رەت قىلىدۇ، شۇنىڭ بىلەن پەقەت مەنىلىك، بوش بولمىغان چېسلا تىزىملىكىنىلا قوبۇل
  قىلىشىڭىزغا كاپالەتلىك قىلىدۇ.
- باشقا دەلىللەشلىرى بىلەن ئاسان بىرلەشتۈرگىلى بولىدىغان ئاددىي بولېن قوغدىغۇچ-ئۇسلۇبىدىكى تەكشۈرۈشنى تەمىنلەيدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areValidDates(array)`

پارامېتىرلار:

- `array`: تەكشۈرۈلىدىغان ئاراي، ئىچىدە `Date` ئوبيېكتلىرى بولۇشى مۇمكىن.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areValidDates } from "@type-check/guards";

const a = [new Date(), new Date("2025-12-17")];
const b = [new Date(), "not a date"] as unknown[];
const c: unknown[] = [];
const d = [new Date("invalid date")] as unknown[];

console.log(areValidDates(a)); //‎ راست
console.log(areValidDates(b)); //‎ يالغان
console.log(areValidDates(c)); //‎ يالغان
console.log(areValidDates(d)); //‎ يالغان

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areValidDates(array)`
