# isBigInt

## چۈشەندۈرۈش

`isBigInt` بېرىلگەن قىممەتنىڭ تىپى `bigint` ئىكەنلىكىنى تەكشۈرىدۇ؛ BigInt ئەسلى قىممەتلىرى ئۈچۈن `true`، بولمىسا `false`
قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

تىپى بەلگىلەنمىگەن مەنبەلەردىن (مەسىلەن، JSON پارسلاش، ئىشلەتكۈچى كىرگۈزۈشى، سىرتقى API لار) كەلگەن قىممەتلەرنى
BigInt-غا خاس ھېسابلاشلارنى قىلىش ياكى ئۇلارنى پەقەت BigInt قوبۇل قىلىدىغان مەيدانلارغا ساقلاشتىن بۇرۇن دەلىللەش ۋە
تارايتىش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> BigInt ھېسابلاشلىرىنى (مەسىلەن، `+`, `*`) قىلىشتىن بۇرۇن `unknown` نى `bigint` كە تارايتىش ئۈچۈن `isBigInt` نى
> ئىشلىتىڭ؛ بۇ مەشغۇلاتلار BigInt ئوپېراندلىرىنى تەلەپ قىلىدۇ.

### ئەۋزەللىكلەر

- `bigint` ئەسلى تىپى ئۈچۈن ئاددىي ۋە ئىشەنچلىك ئىجرا ۋاقتى تەكشۈرۈشىنى تەمىنلەيدۇ.
- BigInt-لا مەشغۇلاتلارنى قىلىشتىن بۇرۇن `unknown` قىممەتلەرنى تارايتىشقا ياردەم بېرىدۇ.
- يالغان مۇسبەت نەتىجىلەرنىڭ ئالدىنى ئالىدۇ: ئادەتتىكى سانلار، تېكىستلەر ۋە باشقا تىپلەر `false` قايتۇرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isBigInt(value)`

پارامېتىرلار:

- `value`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isBigInt } from "@type-check/guards";

const input: unknown = 10n;

if (isBigInt(input)) {
  const doubled = input * 2n;
  console.log(doubled);
} else {
  console.log("Not a bigint");
}

console.log(isBigInt(10n)); //‎ راست
console.log(isBigInt(10));  //‎ يالغان
console.log(isBigInt("10")); //‎ يالغان
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isBigInt(value)`
