# isBinary

## چۈشەندۈرۈش

`isBinary` بىر قىممەتنىڭ ئىككىلىك تىزىم (ئىختىيارىي ھالدا `0b`/`0B` ئالدى قوشۇلغۇچىسى بىلەن) ئىكەنلىكىنى بەلگىلەپ،
`true` ياكى `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

ئىشلەتكۈچى تەمىنلىگەن تىزىملارنى (مەسىلەن، فورما مەيدانلىرى، CLI args، config قىممەتلىرى) دەلىللەپ، كېيىنكى بىر تەرەپ
قىلىشتىن بۇرۇن ئۇلارنىڭ پەقەت ئىككىلىك رەقەملەرنىلا ئىپادىلەيدىغانلىقىنى ۋە ئىختىيارىي ھالدا `0b`/`0B` ئالدى قوشۇلغۇچىسى
بارلىقىنى جەزملەشتۈرۈڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> تىزىمنى `BigInt`/`Number` غا پارس قىلىش ياكى ئايلاندۇرۇشتىن بۇرۇن، ناتوغرا كىرگۈزۈشتىن ساقلىنىش ئۈچۈن `isBinary` نى
> تىپ قوغدىغۇچى (type guard) سۈپىتىدە ئىشلىتىڭ.

### ئەۋزەللىكلەر

- `0b`/`0B` ئالدى قوشۇلغۇچىسى بار ياكى يوق بولغان ئىككىلىك تىزىم (binary string) نى قوبۇل قىلىدۇ.
- بوش تىزىملارنى ۋە ئالدى/ئاخىرىدا بوشلۇق (ASCII ≤ 32) بار تىزىملارنى رەت قىلىدۇ.
- خاتالىق تاشلىماي `true`/`false` قايتۇرىدۇ، شۇڭا نامەلۇم كىرگۈزۈشلەر ئۈچۈن بىخەتەر.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isBinary(value)`

پارامېتىرلار:

- `value`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); //‎ راست
const b = isBinary("1010");   //‎ راست
const c = isBinary("0b1020"); //‎ يالغان
const d = isBinary(0b1010);     //‎ يالغان

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isBinary(value)`
