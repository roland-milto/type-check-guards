# areSets

## چۈشەندۈرۈش

بېرىلگەن بوش بولمىغان تىزىمنىڭ پەقەت `Set` ئىنستانسلىرىنىلا ئۆز ئىچىگە ئالغان-ئالمىغانلىقىنى تەكشۈرىدۇ؛ شۇنداق بولسا
`true` قايتۇرىدۇ، بولمىسا `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

بىر قىممەتنىڭ (مەسىلەن، ئىشلەتكۈچى كىرگۈزۈشى، JSON پارسلاش ياكى سىرتقى API لاردىن) بىر تەرەپ قىلىشتىن بۇرۇن بوش بولمىغان
`Set` ئوبيېكتلىرى تىزىمى ئىكەنلىكىنى دەلىللەش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areSets` نى ئىشلىتىپ نامەلۇم كىرگۈزۈشنى تەكشۈرۈپ بولغاندىن كېيىن، ھەر بىر ئېلېمېنتقا `Set` API لىرىنى (مەسىلەن،
`.size`, `.has`, `.add`) چاقىرىش ۋە ئايلىنىپ چىقىشنى بىخەتەر قىلىڭ.

### ئەۋزەللىكلەر

- كىرگۈزۈلگەن قىممەت بوش بولمىغان سانلار تىزىمى بولۇپ، ھەر بىر ئېلېمېنتى `Set` نىڭ ئىنستانسى بولغاندا ئاندىن `true`
  قايتۇرىدۇ.
- تىزىمدە ئېلېمېنت بولمىغاندا `false` قايتۇرۇش ئارقىلىق بوش تىزىملارغا بولغان خاتا مۇۋاپىقلىشىشنى ئالدىنى ئالىدۇ.
- ھەر بىر ئېلېمېنتقا `Set` غا خاس مەشغۇلاتلارنى ئىجرا قىلىشتىن بۇرۇن runtime قوغدىغۇچ سۈپىتىدە پايدىلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areSets(array)`

پارامېتىرلار:

- `array`: `Set` ئىنستانسلىرى بار-يوقلۇقى تەكشۈرۈلىدىغان تىزىم.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  //‎‎ a ئىجرا ۋاقتىدا Set ئۈلگىلىرىدىن تۈزۈلگەن بىر تىزىم
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); //‎ false
console.log(areSets(c)); //‎ false
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areSets(array)`
