# areBuffers

## چۈشەندۈرۈش

`areBuffers` تەمىنلەنگەن قىممەتنىڭ بوش بولمىغان، تولدۇرۇلغان تىزىملىك بولۇپ، ئۇنىڭدىكى ھەر بىر ئېلېمېنت `Buffer`
ئىكەنلىكىنى تەكشۈرىدۇ؛ شۇنداق بولسا `true` قايتۇرىدۇ، بولمىسا `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

كىرىدىغان chunk تىزىملىكلەرنى (مەسىلەن، stream لاردىن، ھۆججەت يۈكلەشتىن ياكى تور پەكەتلىرىدىن) دەلىللەپ، بارلىق بۆلەكلەر
`Buffer` ئىنستانسى ئىكەنلىكىنى كاپالەتلەندۈرۈپ ئاندىن بىرلەشتۈرۈش، decode قىلىش ياكى ئۇلارنى كرىپتوگرافىيەلىك ياكى
ئىككىلىك-ئىشلىتىش فۇنكسىيەلەرگە يوللاش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areBuffers` نى `unknown[]` نى دەلىللەش ئۈچۈن ئىشلىتىپ، `Buffer.concat` كە ئوخشاش Buffer-غا خاس API لارنى چاقىرىشتىن
> بۇرۇن تەكشۈرۈڭ؛ بۇ فۇنكسىيە پەقەت ھەر بىر ئېلېمېنت `Buffer` بولغاندا `true` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- كىرگۈزۈلگەن قىممەتتىكى ھەر بىر ئېلېمېنتنىڭ Node.js `Buffer` ئىنستانسى ئىكەنلىكىنى كاپالەتلەندۈرىدۇ؛ پۈتۈن سانلار
  تىزىملىكى ماس كەلگەندەلا `true` قايتۇرىدۇ.
- بوش بولمىغان، تولدۇرۇلغان تىزىملىك تەلەپ قىلىش ئارقىلىق ناتوغرا كىرگۈزۈشلەرنى بالدۇر رەت قىلىدۇ؛ بوش تىزىملىكلەر ياكى
  تىزىملىك بولمىغان قىممەتلەر ئۈچۈن `false` قايتۇرىدۇ.
- Buffer-لا ئىشلىتىلىدىغان مەشغۇلاتلارنى (مەسىلەن، بىرلەشتۈرۈش، hash قىلىش، ئىككىلىك پروتوكوللار) ئىجرا قىلىشتىن بۇرۇن
  قوغدىغۇچ سۈپىتىدە پايدىلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areBuffers(array)`

پارامېتىرلار:

- `array`: Buffer ئىنستانسلىرى بار-يوقلۇقىنى تەكشۈرىدىغان تىزىملىك.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areBuffers } from "@type-check/guards";

const chunks: unknown[] = [Buffer.from("test"), Buffer.from("123")];

if (areBuffers(chunks)) {
  const combined = Buffer.concat(chunks);
  console.log(combined.toString("utf8"));
} else {
  throw new TypeError("Expected a non-empty array of Buffer instances");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areBuffers(array)`
