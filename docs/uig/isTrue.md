# isTrue

## چۈشەندۈرۈش

`isTrue` بېرىلگەن قىممەتنىڭ `true` غا قاتتىق تەڭ ئىكەن-ئەمەسلىكىنى بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

`isTrue` نى بايراقلار، ئىقتىدار ئالماشتۇرغۇچىلار (feature toggles) ياكى تەڭشەك قىممەتلىرىنى دەلىللەشتە ئىشلىتىڭ؛ بۇ
يەردە پەقەت لىتىرال `true` لا قوبۇل قىلىنىشى، قالغان ھەممىسى `false` دەپ قارىلىشى كېرەك.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> پەقەت بولېن لىتىرال `true` نىلا قوبۇل قىلىش كېرەك بولغاندا، پەقەت truthy قىممەتلەرنى ئەمەس، `isTrue` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- بولېن لىتىرال `true` ئۈچۈن قاتتىق تەكشۈرۈشنى تەمىنلەيدۇ (مەجبۇرىي ئايلاندۇرۇش يوق).
- `true` نى `1`, `"true"` ياكى `{}` قاتارلىق truthy قىممەتلەردىن پەرقلىشىشكە ياردەم بېرىدۇ.
- قوغدىغۇچىلار ۋە دەلىللەش تۇرۇبا لىنىيەلىرىگە ماس كېلىدىغان ئاددىي، ئالدىن پەرەز قىلغىلى بولىدىغان ھەرىكەت.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isTrue(value)`

پارامېتىرلار:

- `value`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      //‎ راست
const b = isTrue(1);         //‎ يالغان
const c = isTrue("true");   //‎ يالغان

if (isTrue(a)) {
  //‎‎ بۇ يەردە a راست
}
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isTrue(value)`
