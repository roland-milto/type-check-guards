# areIntegers

## چۈشەندۈرۈش

`areIntegers` بېرىلگەن تىزىمدىكى بارلىق ئېلېمېنتلارنىڭ پۈتۈن سان ئىكەنلىكىنى بەلگىلەيدۇ؛ ئەگەر شۇنداق بولسا `true`
قايتۇرىدۇ، بولمىسا `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

لوگىكىڭىز ID لار، ساناقلار، بەتلەش (pagination) ئوففسېتلىرى ياكى تىزىم ئىندېكسلىرىغا ئوخشاش پۈتۈن سان قىممەتلىرىدىن
تۈزۈلگەن تولدۇرۇلغان تىزىم تەلەپ قىلغاندا، `areIntegers` نى ئىشلەتكۈچى تەمىنلىگەن ياكى سىرتقى سانلىق مەلۇماتلارنى (
مەسىلەن، query پارامېتىرلىرى، JSON payload لار، CSV قۇرلىرى) دەلىللەش ئۈچۈن ئىشلىتىڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areIntegers` نى `unknown[]` كىرگۈزۈشلىرى ئۈچۈن ئىجرا ۋاقتىدىكى قوغدىغۇچ (runtime guard) سۈپىتىدە ئىشلىتىپ، ئۇلارنى
> پەقەت پۈتۈن سانلاردىن تۈزۈلگەن `number[]` دەپ قاراشتىن بۇرۇن تەكشۈرۈڭ. ئەگەر ئۇ `false` قايتۇرسا، كىرگۈزۈش يا
> تولدۇرۇلغان تىزىم ئەمەس ياكى ئاز دېگەندە بىر پۈتۈن سان بولمىغان قىممەتنى ئۆز ئىچىگە ئالىدۇ.

### ئەۋزەللىكلەر

- پەقەت ھەر بىر ئېلېمېنت پۈتۈن سان بولغاندا `true` قايتۇرىدۇ؛ بولمىسا `false` قايتۇرىدۇ.
- پۈتۈن سانلا ئىشلىتىدىغان مەشغۇلاتلارنى (مەسىلەن، ئىندېكسلاش، ساناق، ID لار) ئىجرا قىلىشتىن بۇرۇن نامەلۇم كىرگۈزۈشنى
  دەلىللەشكە ياردەم بېرىدۇ.
- تېز مەغلۇپ بولىدۇ: پۈتۈن سان بولمىغان بىر ئېلېمېنت تېپىلغان ھامان تەكشۈرۈشنى توختىتىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areIntegers(array)`

پارامېتىرلار:

- `array`: پۈتۈن سان ئېلېمېنتلىرى بار-يوقلۇقىنى تەكشۈرىدىغان سانلار تىزىمى.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areIntegers } from "@type-check/guards";

const a: unknown[] = [1, 2, 3];
const b: unknown[] = [0, -10, 42];
const c: unknown[] = [1, 2, "3"];

console.log(areIntegers(a)); //‎ راست
console.log(areIntegers(b)); //‎ راست
console.log(areIntegers(c)); //‎ يالغان

function sumIntegers(values: unknown[]): number {
  if (!areIntegers(values)) {
    throw new TypeError("Expected a filled array of integers");
  }
  return (values as number[]).reduce((acc, n) => acc + n, 0);
}

console.log(sumIntegers([10, 20, 30]));

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areIntegers(array)`
