# isInteger

## چۈشەندۈرۈش

بېرىلگەن `value` نىڭ بىخەتەر پۈتۈن سان (safe integer) سان ئىكەنلىكىنى بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

ئىشەنچسىز كىرگۈزۈشنى (مەسىلەن، query params، JSON payloads، environment variables) پۈتۈن سان سۈپىتىدە ئىشلىتىشتىن بۇرۇن
دەلىللەڭ؛ array ئىندېكسلىرى، بەتلەش (pagination)، ساناق (counters) ياكى سانلىق مەلۇمات ئامبىرى ID لىرى ئۈچۈن ئىشلىتىشتىن
بۇرۇن.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> نامەلۇم كىرگۈزۈشنى سانلىق پۈتۈن سان دەپ ئىشلىتىشتىن بۇرۇن دەلىللەش ئۈچۈن `isInteger` نى ئىشلىتىڭ؛ ئۇ پەقەت
`typeof value === "number"` ۋە `Number.isSafeInteger(value)` بولغان قىممەتلەر ئۈچۈنلا `true` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- تىپ ۋە سانلىق بىخەتەرلىكنى بىرلا ۋاقىتتا تەكشۈرىدۇ: كىرگۈزۈش سان بولۇپ، بىخەتەر پۈتۈن سان بولغاندا ئاندىن `true`
  قايتۇرىدۇ.
- سانغا مەجبۇرىي ئايلاندۇرۇشتىكى كۆپ ئۇچرايدىغان خاتالىقلارنىڭ ئالدىنى ئالىدۇ: "5" غا ئوخشاش تىزىملىك (string) قىممەتلەر
  توغرا ھالدا `false` قايتۇرىدۇ.
- پۈتۈن سان بولمىغان ۋە بىخەتەر بولمىغان پۈتۈن سانلارنى رەت قىلىدۇ، شۇڭا ID، ساناق (counter) ۋە array ئىندېكسلاشقا ماس
  كېلىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isInteger(value)`

پارامېتىرلار:

- `value`: پۈتۈن سان ھالىتىنى تەكشۈرىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      //‎ راست
const b = isInteger(-100);   //‎ راست
const c = isInteger("5");    //‎ يالغان
const d = isInteger(5.5);    //‎ يالغان
const e = isInteger(null);   //‎ يالغان

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isInteger(value)`
