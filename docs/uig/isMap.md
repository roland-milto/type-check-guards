# isMap

## چۈشەندۈرۈش

بېرىلگەن `value` نىڭ `Map` ئىكەنلىكىنى تەكشۈرىدۇ؛ ئەگەر شۇنداق بولسا `true` قايتۇرىدۇ، بولمىسا `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

JSON پارسلاش، سىرتقى API لار ياكى ئىشلەتكۈچى كىرگۈزۈشىدىن كەلگەن `unknown` قىممەتنى قوبۇل قىلغاندا، `Map` مەشغۇلاتلىرىنى
قىلىشتىن بۇرۇن ئۇنىڭ `Map` ئىكەنلىكىنى كاپالەتلەندۈرۈش ئۈچۈن `isMap` نى ئىشلىتىڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `isMap` ئىجرا ۋاقتىدىكى قوغدىغۇچ بولۇپ، قىممەت `Map` بولغاندا `true` قايتۇرىدۇ، بولمىسا `false` قايتۇرىدۇ؛ `Map` API
> لىرىنى چاقىرىشتىن بۇرۇن `unknown` نى تارايىتىش ئۈچۈن ئىشلىتىڭ.

### ئەۋزەللىكلەر

- بىر قىممەتنىڭ `Map` ئىكەنلىكىنى تېز سۈرئەتتە ئىجرا ۋاقتىدا تەكشۈرۈپ بېرىدۇ.
- `get`, `set`, ۋە `has` قاتارلىق `Map` ئۇسۇللىرىنى تەلەپ قىلىدىغان كود يوللىرىنى قوغداش ئارقىلىق تىپ خاتالىقلىرىنىڭ
  ئالدىنى ئېلىشقا ياردەم بېرىدۇ.
- `unknown` كىرگۈزۈلمىلەرنى بىر تەرەپ قىلغاندا يېنىك دەرىجىدىكى دەلىللەش قەدىمى سۈپىتىدە ياخشى ئىشلەيدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isMap(value)`

پارامېتىرلار:

- `value`: تەكشۈرىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isMap } from "@type-check/guards";

const input: unknown = new Map<string, number>([["a", 1]]);

if (isMap(input)) {
  input.set("b", 2);
  const a = input.get("a");
  console.log(a);
} else {
  console.log("Not a Map");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isMap(value)`
