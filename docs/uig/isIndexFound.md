# isIndexFound

## چۈشەندۈرۈش

`isIndexFound` بېرىلگەن قىممەتنىڭ مەنپىي بولمىغان پۈتۈن سان ئىكەنلىكىنى بەلگىلەپ، ئىندېكس تېپىلغانلىقىنى كۆرسىتىدۇ.

### ئىشلىتىش ھالىتى

ئىزدەش نەتىجىسىنىڭ ئىشلىتىشكە بولىدىغان ئىندېكس (پۈتۈن سان `>= 0`) ئىكەنلىكىنى ئىندېكسلاشتىن بۇرۇن دەلىللەپ، `-1` ياكى
سان بولمىغان قىممەتلەرنى خاتا ئىشلىتىپ قويۇشنىڭ ئالدىنى ئالىدۇ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `indexOf`, `findIndex` ياكى ئۆزىڭىز يازغان ئىزدەشلەردىن كېيىن `isIndexFound` نى ئىشلىتىڭ؛ بۇ يەردە `-1` (ياكى باشقا
> ئىناۋەتسىز قىممەتلەر) «تېپىلمىدى» نى بىلدۈرۈشى مۇمكىن. ئۇ `true` قايتۇرغاندا، قىممەت سان بولۇپ، سانلار
> گۇرۇپپىسى/تېكىست
> ئىندېكسى سۈپىتىدە بىخەتەر ئىشلىتىشكە بولىدۇ.

### ئەۋزەللىكلەر

- مەنپىي بولمىغان پۈتۈن ساننى تەكشۈرۈش ئارقىلىق بىر ئىندېكس تېپىلغان-تېپىلمايدىغانلىقىنى بايقاش ئۈچۈن ئاددىي تىپ
  قوغدىغۇچنى تەمىنلەيدۇ.
- پەقەت ئىندېكسقا ئوخشاش توغرا قىممەتلەر (پۈتۈن سانلار `>= 0`) ئۈچۈنلا `true` قايتۇرىدۇ؛ مەنپىي قىممەتلەرنى، پۈتۈن سان
  بولمىغانلارنى ۋە سان بولمىغانلارنى رەت قىلىدۇ.
- `-1` نى «تېپىلمىدى» دەپ قايتۇرىدىغان API لار بىلەن ئىشلىگەندە off-by-one ۋە sentinel-قىممەت خاتالىقلىرىدىن ساقلىنىشقا
  ياردەم بېرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isIndexFound(value)`

پارامېتىرلار:

- `value`: مەنپىي بولمىغان پۈتۈن سان ئىكەنلىكىنى تەكشۈرىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  //‎‎ idx بۇ يەردە سان بولۇپ، 0 دىن چوڭ ياكى تەڭ
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

//‎‎ indexOf بىلەن ئادەتتىكى ئىشلىتىش
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isIndexFound(value)`
