# arePrimitives

## چۈشەندۈرۈش

`arePrimitives` تەمىنلەنگەن، بوش بولمىغان تىزىملىكتىكى بارلىق ئېلېمېنتلارنىڭ ئەسلى (primitive) تىپلار ئىكەنلىكىنى
باھالايدۇ.

### ئىشلىتىش ھالىتى

كىرىدىغان سانلىق مەلۇمات (مەسىلەن، query پارامېتىرلىرى، CSV قۇر قىممەتلىرى ياكى ID/tag تىزىملىكى) نىڭ پەقەت ئەسلى
قىممەتلەرنىلا ئۆز ئىچىگە ئالىدىغانلىقىنى تەكشۈرۈپ، ئاندىن ئۇنى سېرئىياللاشتۇرۇش، ھاشلاش، خاتىرىلەش ياكى ئوبيېكت قوبۇل
قىلماسلىقى كېرەك بولغان API لارغا يوللاش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> كېيىنكى بىر تەرەپ قىلىشتىن بۇرۇن `unknown[]` نىڭ پەقەت ئەسلى قىممەتلەرنىلا (string, number, bigint, boolean, symbol,
> undefined ياكى null) ئۆز ئىچىگە ئالىدىغانلىقىنى كاپالەتلەندۈرۈش كېرەك بولغاندا `arePrimitives` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- پەقەت ھەر بىر ئېلېمېنت ئەسلى (primitive) قىممەت بولغاندا `true` قايتۇرىدۇ، بۇ ئۇنى «ئوبيېكت/فۇنكسىيە يوق» تىزىملىكلەر
  ئۈچۈن قاتتىق قوغدىغۇچ قىلىدۇ.
- تېز مەغلۇپ بولىدۇ: ئەسلى بولمىغان ئېلېمېنت تېپىلغان ھامان `false` قايتۇرىدۇ.
- تىزىملىك بولمىغان قىممەتلەر ۋە بوش تىزىملىكلەر ئۈچۈنمۇ (تولدۇرۇلغان-تىزىملىك تەكشۈرۈشى ئارقىلىق) `false` قايتۇرىدۇ، بۇ
  ئىناۋەتسىز كىرگۈزۈشنىڭ خاتا قوبۇل قىلىنىشىنىڭ ئالدىنى ئالىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `arePrimitives(array)`

پارامېتىرلار:

- `array`: ئەسلى تىپتىكى ئېلېمېنتلار بار-يوقلۇقى تەكشۈرۈلىدىغان تىزىملىك.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { arePrimitives } from "@type-check/guards";

const a: unknown[] = [1, "string", true];
const b: unknown[] = [null, undefined, Symbol("x")];
const c: unknown[] = [1, {}, false];

const r1 = arePrimitives(a); //‎ true
const r2 = arePrimitives(b); //‎ true
const r3 = arePrimitives(c); //‎ false
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.arePrimitives(array)`
