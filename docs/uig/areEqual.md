# areEqual

## چۈشەندۈرۈش

`areEqual` ماسسىۋدىكى بارلىق ئېلېمېنتلارنىڭ بېرىلگەن كۈتۈلگەن قىممەتكە تەڭ-تەڭ ئەمەسلىكىنى تەكشۈرىدۇ؛ پەقەت بوش بولمىغان
ماسسىۋدا ھەر بىر تۈر ماس كەلگەندەلا `true` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

تىزىملىكتە پەقەت بىرلا رۇخسەت قىلىنغان قىممەت بارلىقىنى دەلىللەش (مەسىلەن، بارلىق ھالەت بايراقلىرى `true`، بارلىق روللار
`"admin"`، ياكى بارلىق سانلىق كىرگۈزۈشلەر تەلەپ قىلىنغان تۇراقلىق قىممەتكە تەڭ) ۋە بوش كىرگۈزۈشنى ئىناۋەتسىز (`false`)
دەپ قاراش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> قاتتىق «ھەممە تۈر» تەكشۈرۈشى لازىم بولغاندا `areEqual` نى ئىشلىتىڭ؛ ئۇ بوش ماسسىۋلارغا ۋە ھەر قانداق ماسسىۋ ئەمەس ياكى
> توشقان ئەمەس كىرگۈزۈشلەرگە `false` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- پەقەت ھەر بىر ئېلېمېنت كۈتۈلگەن قىممەتكە ماس كەلگەندەلا `true` قايتۇرىدۇ؛ بولمىسا `false` قايتۇرىدۇ.
- تېز مەغلۇپ بولىدۇ: ماس كەلمەيدىغان ئېلېمېنت تېپىلغان ھامان تەكشۈرۈشنى توختىتىدۇ.
- كىرگۈزۈش توشقان ماسسىۋى بولمىغاندا `false` قايتۇرۇش ئارقىلىق ئىناۋەتسىز كىرگۈزۈشتىن ساقلايدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areEqual(value, expected)`

پارامېتىرلار:

- `value`: تەكشۈرۈلىدىغان ماسسىۋ.
- `expected`: ھەر بىر ماسسىۋ تۈرى بىلەن سېلىشتۇرۇلىدىغان ئېلېمېنت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areEqual(value, expected)`
