# isOctal

## چۈشەندۈرۈش

بىر قىممەتنىڭ ئىناۋەتلىك سەككىزلىك لىتېرال string (مەسىلەن `0o755`) ئىكەنلىكىنى بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

پارسىلاش ياكى ئايلاندۇرۇشتىن بۇرۇن، ئىشلەتكۈچى كىرگۈزۈشى ياكى سەپلىمە قىممەتلىرىنىڭ سەككىزلىك لىتېرال string شەكلىدە
بولۇشى زۆرۈر بولغان ئەھۋاللاردا (مەسىلەن، `0o644` غا ئوخشاش ھۆججەت ئىجازەت ھالىتى) دەلىللەش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `isOctal` بىر تىپ قوغدىغۇچى (`value is string`). `true` نەتىجىسىدىن كېيىن، TypeScript تەكشۈرۈلگەن ئۆزگەرگۈچىنى
`string` غا تارايتىدۇ.

### ئەۋزەللىكلەر

- قاتتىق تىپ قوغدىغۇچىنى تەمىنلەيدۇ: كىرگۈزۈش پەقەت سەككىزلىك لىتېرال فورماتىغا ماس كېلىدىغان بىر string بولغاندا ئاندىن
  `true` قايتۇرىدۇ.
- بوش string لارنى ۋە ئالدى/ئارقىسىدا بوشلۇق (ASCII كونترول/بوشلۇق) بار string لارنى رەت قىلىدۇ، بۇ تاسادىپىي ماسلىشىشنى
  ئازايتىدۇ.
- ئىختىيارىي بەلگە (+/−) نى قوللايدۇ ۋە `0o`/`0O` ئالدى قوشۇمچىسىغا نىسبەتەن چوڭ-كىچىك ھەرپ پەرقىنى قىلمايدۇ.
- string بولمىغان كىرگۈزۈشلەرگە كەڭچىلىك قىلىپ، خاتالىق چىقارماستىن `false` قايتۇرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isOctal(value)`

پارامېتىرلار:

- `value`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); //‎ راست
console.log(isOctal(b)); //‎ راست
console.log(isOctal(c)); //‎ يالغان
console.log(isOctal(d)); //‎ يالغان

if (isOctal(a)) {
  //‎‎ بۇ يەردە a تىپى string
  const normalized = a.toLowerCase();
  console.log(normalized);
}
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isOctal(value)`
