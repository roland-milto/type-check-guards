# isValidDate

## چۈشەندۈرۈش

`isValidDate` بېرىلگەن قىممەتنىڭ ئىناۋەتلىك `Date` ئوبيېكتى ئىكەنلىكىنى تەكشۈرىدۇ ۋە پەقەت ھەقىقىي، ئىناۋەتسىز بولمىغان
چېسلالار ئۈچۈنلا `true` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

ئىشلەتكۈچى كىرگۈزۈشى ياكى API سانلىق مەلۇماتىدا چېسلا بولۇشى مۇمكىن بولغان قىممەتلەرنى دەلىللەش؛ چېسلا ھېسابلاش،
فورماتلاش ياكى سېلىشتۇرۇشنى ئىجرا قىلىشتىن بۇرۇن، قىممەتنىڭ ئىناۋەتسىز چېسلا ئەمەس بەلكى ھەقىقىي `Date` نۇسخىسى
ئىكەنلىكىنى كاپالەتلەندۈرۈش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `unknown` تىپلىق قىممەتلەردە `Date` مېتودلىرىنى (مەسىلەن، `toISOString`, `getTime`) چاقىرىشتىن بۇرۇن، ئۇلارنىڭ
> ئىناۋەتلىك `Date` ئوبيېكتلىرى ئىكەنلىكىنى كاپالەتلەندۈرۈش ئۈچۈن `isValidDate` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- قىممەتنىڭ پەقەتلا چېسلا-ئوخشاش تېكىست ياكى سان ئەمەس، بەلكى `Date` نۇسخىسى ئىكەنلىكىنى كاپالەتلەندۈرىدۇ.
- `NaN` ۋاقىت قىممەتلىرىنى تەكشۈرۈش ئارقىلىق ئىناۋەتسىز چېسلالارنى (مەسىلەن، `new Date("invalid")`) رەت قىلىدۇ.
- شەرت جۈملىلىرى ۋە دەلىللەش تۇرۇبا يوللىرىدا ئىشلىتىش ئاسان بولغان ئاددىي boolean قوغدىغۇچ.
- كىرگۈزۈشنى ئالدى بىلەن دەلىللەش ئارقىلىق چېسلا مېتودلىرىنى چاقىرغاندا ئىجرا ۋاقتى خاتالىقلىرىنىڭ ئالدىنى ئېلىشقا
  ياردەم بېرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isValidDate(value)`

پارامېتىرلار:

- `value`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isValidDate } from "@type-check/guards";

const input: unknown = new Date();

if (isValidDate(input)) {
  //‎‎ input ئىناۋەتلىك Date نۇسخىسى
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a valid Date");
}

console.log(isValidDate(new Date("invalid"))); //‎ false
console.log(isValidDate("2025-12-22")); //‎ false
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isValidDate(value)`
