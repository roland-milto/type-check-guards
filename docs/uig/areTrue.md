# areTrue

## چۈشەندۈرۈش

بوش بولمىغان ماسسىۋادا پەقەت بولېن `true` قىممەتلىرىلا بار-يوقلۇقىنى تەكشۈرىدۇ.

### ئىشلىتىش ھالىتى

داۋاملاشتۇرۇشتىن بۇرۇن ئالدىنقى شەرتلەر ياكى ئىقتىدار بايراقلىرىنىڭ ھەممىسى قوزغىتىلغانلىقىنى (ھەممىسى `true`) دەلىللەش
ئۈچۈن `areTrue` نى ئىشلىتىڭ؛ بوش ياكى خاتا شەكىلدىكى كىرگۈزۈشلەرنى قاندۇرۇلمىغان (`false`) دەپ قارىيدۇ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areTrue` بوش ماسسىۋا ئۈچۈن ۋە قاتتىق ھالدا `true` بولمىغان ھەر قانداق قىممەتنى ئۆز ئىچىگە ئالغان ماسسىۋىلار ئۈچۈن
`false` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- پەقەت ھەر بىر ئېلېمېنت قاتتىق ھالدا `true` بولۇپ، ماسسىۋا بوش بولمىغاندا `true` قايتۇرىدۇ.
- تېز مەغلۇپ بولىدۇ: `true` بولمىغان قىممەت بايقالغان ھامان `false` قايتۇرىدۇ.
- ئىناۋەتسىز كىرگۈزۈشلەرنى (مسىۋا بولمىغان ياكى بوش ماسسىۋا) `false` قايتۇرۇش ئارقىلىق رەت قىلىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areTrue(array)`

پارامېتىرلار:

- `array`: بارلىق `true` قىممەتلەر بار-يوقلۇقىنى تەكشۈرىدىغان ماسسىۋا.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areTrue } from "@type-check/guards";

const a = areTrue([true, true, true]);
const b = areTrue([true, false, true]);
const c = areTrue([]);
const d = areTrue([true, "string" as unknown, true]);

console.log(a, b, c, d);
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areTrue(array)`
