# areArrays

## چۈشەندۈرۈش

`areArrays` بىر قىممەتنىڭ ئىچى تولدۇرۇلغان ئىككى ئۆلچەملىك سانلار قاتارى بولۇپ، ئۇنىڭ ئىچىدىكى تۈرلەرنىڭ ھەممىسى سانلار
قاتارى ئىكەنلىكىنى بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

قۇر/ستون مەشغۇلاتلىرىنى ئىجرا قىلىشتىن بۇرۇن، جەدۋەل ياكى ماترىتسا شەكلىدىكى كىرگۈزۈشلەرنى (مەسىلەن، CSV قۇرلىرى، تور (
grid) سانلىق مەلۇماتلىرى ياكى گۇرۇپپىلانغان تىزىملىكلەر) دەلىللەش ئۈچۈن `areArrays` نى ئىشلىتىڭ؛ كىرگۈزۈش سانلار قاتارى
بولمىسا، بوش بولسا ياكى ئىچىدە سانلار قاتارى بولمىغان ھەر قانداق ئېلېمېنت بولسا `false` قايتۇرىدۇ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> قاتلاملىق سانلار قاتارىغا ئايلىنىپ ئايلىنىش ياكى ئىندېكسلاشتىن بۇرۇن، بىر قىممەتنىڭ بوش بولمىغان 2D سانلار قاتارى
> ئىكەنلىكىنى ۋە ھەر بىر قۇرىنىڭ سانلار قاتارى ئىكەنلىكىنى كاپالەتلەندۈرۈش كېرەك بولغاندا `areArrays` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- كىرگۈزۈلگەن قىممەتنىڭ بوش بولمىغان ئىككى ئۆلچەملىك سانلار قاتارى (2D array) ئىكەنلىكىنى، ھەمدە ھەر بىر ئېلېمېنتىنىڭ
  ئۆزى بىر سانلار قاتارى ئىكەنلىكىنى دەلىللەيدۇ.
- قوغدىغۇچ (guard) ۋە بالدۇر چىقىش (early exit) ئۈچۈن ماس كېلىدىغان ئاددىي boolean نەتىجە (`true`/`false`) قايتۇرىدۇ.
- كېيىنكى كود قاتلاملىق سانلار قاتارى مەشغۇلاتلىرىنى (مەسىلەن، قۇرلارنى map قىلىش) پەرەز قىلغاندا يۈز بېرىدىغان runtime
  خاتالىقلارنىڭ ئالدىنى ئېلىشقا ياردەم بېرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areArrays(array)`

پارامېتىرلار:

- `array`: تەكشۈرۈلىدىغان كىرگۈزۈش.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  //‎‎ value بولسا ئېلېمېنتلىرى سانلار بولغان 2D ماسسىپ
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areArrays(array)`
