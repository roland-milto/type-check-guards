# areHexadecimals

## چۈشەندۈرۈش

Array ئىچىدىكى بارلىق ئېلېمېنتلارنىڭ ئون ئالتىلىك سان سىستېمىسىدىكى تېكىست ئىكەنلىكىنى تەكشۈرىدۇ؛ پەقەت بوش بولمىغان ۋە
ھەر بىر تۈرى توغرا بولغان array لار ئۈچۈنلا `true` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

`areHexadecimals` نى ئىشلىتىپ ئىشلەتكۈچى كىرگۈزۈشى ياكى سىرتقى سانلىق مەلۇماتلارنى (مەسىلەن، ID لار، checksum لار،
ئالدىدا '#' بولمىغان رەڭ كودلىرى) ئون ئالتىلىك پارسلاش ياكى كېيىنكى بىر تەرەپ قىلىشتىن بۇرۇن دەلىللەڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areHexadecimals` نى ئىشلىتىپ نامەلۇم كىرگۈزۈشنى پارسلاش ياكى قىممەتلەرنى ئايلاندۇرۇشتىن بۇرۇن دەلىللەڭ (مەسىلەن،
`parseInt(value, 16)` دىن بۇرۇن ياكى BigInt ئايلاندۇرۇشلىرىدىن بۇرۇن).

### ئەۋزەللىكلەر

- ھەر بىر ئېلېمېنتنىڭ ئون ئالتىلىك سان سىستېمىسىدىكى (hexadecimal) تېكىست ئىكەنلىكىنى دەلىللەيدۇ ۋە پەقەت بارلىق تۈرلەر
  ماس كەلگەندەلا `true` قايتۇرىدۇ.
- لايىھە بويىچە بوش array لارنى رەت قىلىدۇ، كىرگۈزۈش سانلىق مەلۇماتى يوق بولغاندا `false` قايتۇرىدۇ.
- قوغدىغۇچ (guard) ۋە بالدۇر قايتىش (early-return) دەلىللەش ئۈچۈن ماس كېلىدىغان ئاددىي boolean نەتىجە (`true`/`false`)
  تەمىنلەيدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areHexadecimals(array)`

پارامېتىرلار:

- `array`: ئون ئالتىلىك سان سىستېمىسىدىكى تېكىست ئېلېمېنتلىرى بار-يوقلۇقى تەكشۈرۈلىدىغان array.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areHexadecimals } from "@type-check/guards";

const a = areHexadecimals(["1A", "3F", "B2"]);
const b = areHexadecimals(["1A", "3G", "B2"]);
const c = areHexadecimals([10 as unknown as string, "3F", "B2"] as unknown[]);
const d = areHexadecimals([]);

console.log(a, b, c, d);
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areHexadecimals(array)`
