# isRegEx

## چۈشەندۈرۈش

بېرىلگەن قىممەتنىڭ `RegExp` ئىنستانسىسى ئىكەنلىكىنى بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

ئىشلەتكۈچى تەمىنلىگەن ياكى دىنامىك قىممەتلەرنى (مەسىلەن، سەپلىمە، API payloadلىرى، پلاگىن كىرگۈزۈشلەر) دائىملىق ئىپادە
دەپ قاراشتىن بۇرۇن دەلىللەش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `RegExp` غا خاس خۇسۇسىيەت ياكى مېتودلارنى ئىشلىتىشتىن بۇرۇن `unknown` (ياكى union) قىممەتلەرنى تارايتىش ئۈچۈن
`isRegEx` نى ئىشلىتىڭ؛ ئۇ پەقەت `RegExp` نىڭ ئىنستانسىسى بولغان قىممەتلەر ئۈچۈنلا `true` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- بىر قىممەتنىڭ `RegExp` ئىكەنلىكىنى تەكشۈرۈش ئۈچۈن ئاددىي runtime تىپ قوغدىغۇچ بىلەن تەمىنلەيدۇ.
- كود دائىملىق ئىپادە كۈتۈۋاتقاندا (مەسىلەن، `test`، `exec` نى چاقىرىشتىن ياكى `source` نى ئوقۇشتىن بۇرۇن) خاتالىقلارنىڭ
  ئالدىنى ئېلىشقا ياردەم بېرىدۇ.
- `/regex/` لىتىراللىرى ۋە `new RegExp(...)` ئارقىلىق قۇرۇلغان ئىنستانسىلار بىلەن ھەر ئىككىسىدە ئىشلەيدۇ.
- regex بولمىغان كىرگۈزۈشلەر ئۈچۈن خاتالىق تاشلىماي، ئېنىق بولغان boolean نەتىجە (`true`/`false`) قايتۇرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isRegEx(value)`

پارامېتىرلار:

- `value`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  //‎‎ بۇ يەردە input بىر RegExp
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isRegEx(value)`
