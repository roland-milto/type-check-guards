# areErrors

## چۈشەندۈرۈش

مېسىۋنىڭ بوش ئەمەسلىكى ۋە پەقەت `Error` ئوبيېكتلىرىنىلا ئۆز ئىچىگە ئالغانلىقىنى تەكشۈرۈپ، `true` ياكى `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

runtime تەمىنلىگەن `unknown[]` (مەسىلەن توپلانغان مەغلۇبىيەتلەر، دەلىللەش نەتىجىلىرى ياكى deserialized سانلىق مەلۇمات)
نىڭ ئۈستىدە ئايلىنىش، خاتىرىلەش ياكى قايتا تاشلاشتىن بۇرۇن، ئۇنىڭ بوش ئەمەس `Error` ئوبيېكتلىرى تىزىملىكى ئىكەنلىكىنى
دەلىللەش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areErrors` پەقەت ھەر بىر تۈرى `Error` بولغان تولدۇرۇلغان ماسسىۋ ئۈچۈنلا `true` قايتۇرىدۇ؛ بوش ماسسىۋ ئۈچۈن ياكى ھەر
> قانداق بىر ئېلېمېنت `Error` بولمىسا `false` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- ھەر بىر ئېلېمېنتنىڭ `Error` ئىنستانسى ئىكەنلىكىنى كاپالەتلەندۈرۈپ، خاتالىقلارنى بىخەتەر بىر تەرەپ قىلىش ۋە خاتىرىلەشنى
  مۇمكىن قىلىدۇ.
- بوش ماسسىۋلارنى رەت قىلىپ، تاسادىپىي «خاتالىق يوق» ھالەتلىرىنىڭ توغرا خاتالىق تىزىملىكى دەپ قارىلىشىنىڭ ئالدىنى
  ئالىدۇ.
- `unknown[]` كىرگۈزۈلمىلىرى (مەسىلەن API لاردىن ياكى `catch` بلوكلىرىدىن) بىلەن ئىشلىگەندە runtime guard سۈپىتىدە ياخشى
  ئىشلەيدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areErrors(array)`

پارامېتىرلار:

- `array`: `Error` ئوبيېكتلىرى بار-يوقلۇقىنى تەكشۈرىدىغان ماسسىۋ.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areErrors } from "@type-check/guards";

const value: unknown = [new Error("error1"), new TypeError("error2")];

if (Array.isArray(value) && areErrors(value)) {
  //‎‎ value بولسا Error ئوبيېكتلىرىنىڭ بوش بولمىغان تىزىمى
  for (const err of value) {
    console.error(err.name, err.message);
  }
} else {
  console.log("Not a non-empty Error[]");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areErrors(array)`
