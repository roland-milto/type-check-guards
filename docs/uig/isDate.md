# isDate

## چۈشەندۈرۈش

`isDate` بېرىلگەن قىممەتنىڭ `Date` ئىكەنلىكىنى بەلگىلەيدۇ؛ `Date` نۇسخىلىرى ئۈچۈن `true` قايتۇرىدۇ، باشقا ھاللاردا
`false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

`Date` مەشغۇلاتلىرىنى (مەسىلەن، فورماتلاش، سېلىشتۇرۇش ياكى `toISOString()` نى چاقىرىش) ئىجرا قىلىشتىن بۇرۇن نامەلۇم
قىممەتلەرنى (مەسىلەن، ئىلتىماس سانلىق مەلۇماتى، سەپلىمە قىممەتلىرى ياكى پارس قىلىنغان JSON) دەلىللەش ۋە تارايتىش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `isDate` نى ئىشلىتىپ runtime دا `unknown` نى `Date` غا تارايتىڭ؛ ئۇ پەقەت ھەقىقىي `Date` نۇسخىلىرى ئۈچۈنلا `true`
> قايتۇرىدۇ (date string لار ئۈچۈن ئەمەس).

### ئەۋزەللىكلەر

- ئۇ بىر قىممەتنىڭ `Date` ئىكەنلىكىنى دەلىللەش ئۈچۈن ئاددىي runtime قوغدىغۇچ بىلەن تەمىنلەيدۇ.
- پەقەت `Date` نۇسخىلىرىلا دەلىللەشتىن ئۆتۈشىگە كاپالەتلىك قىلىپ، تىپ خاتالىقلىرىنىڭ ئالدىنى ئېلىشقا ياردەم بېرىدۇ.
- نامەلۇم كىرگۈزۈشلەرنى (مەسىلەن، API payloads) ۋاقىتقا خاس ئۇسۇللارنى ئىشلىتىشتىن بۇرۇن دەلىللەشتە پايدىلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isDate(value)`

پارامېتىرلار:

- `value`: `Date` تىپى ئۈچۈن تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isDate } from "@type-check/guards";

const input: unknown = new Date();

if (isDate(input)) {
  //‎‎ بۇ يەردە input بىر Date
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a Date");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isDate(value)`
