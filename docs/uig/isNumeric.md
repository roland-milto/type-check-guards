# isNumeric

## چۈشەندۈرۈش

`isNumeric` بېرىلگەن `value` نىڭ يېشىلگەن تۈرىنى `NUMERIC_TYPES` بىلەن سېلىشتۇرۇپ تەكشۈرۈش ئارقىلىق ئۇنىڭ سانلىق دەپ
قارىلىدىغان-قارىلمايدىغانلىقىنى بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

سانلىق مەشغۇلاتلارنى ئىجرا قىلىشتىن بۇرۇن كىرگۈزۈشلەرنى (مەسىلەن، API payloads، فورما قىممەتلىرى، سەپلىمە) دەلىللەش
ئۈچۈن `isNumeric` نى ئىشلىتىڭ، ۋە `NUMERIC_TYPES` غا ئاساسەن `BigInt` كە ئوخشاش سانلىق-سىمان تۈرلەرنى بىردەك قوبۇل
قىلىڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `isNumeric` بولېن قايتۇرىدىغان پەيشانە؛ ئۇنى قىممەتنىڭ كۈتۈپخانا بەلگىلىگەن سانلىق تۈر توپلىمىغا تەۋە-تەۋە ئەمەسلىكىنى
> ئىجرا ۋاقتىدا تەكشۈرۈش دەپ قارىڭ.

### ئەۋزەللىكلەر

- `getTypeOf` ۋە `NUMERIC_TYPES` نى ئىشلىتىپ سانلىق تۈرنى بايقاش لوگىكىسىنى مەركەزلەشتۈرىدۇ ۋە كود بازىسى بويىچە
  تەكشۈرۈشلەرنىڭ بىردەك بولۇشىنى ساقلايدۇ.
- ئاسان شاخلىنىش ۋە قوغداش-ئۇسلۇبىدىكى ئىشلىتىش ئۈچۈن ئاددىي بولېن (`true`/`false`) قايتۇرىدۇ.
- `NUMERIC_TYPES` تەرىپىدىن بەلگىلەنگەن كۆپ خىل سانلىق ئىپادىلەش شەكىللىرىنى (مەسىلەن، `number`, `BigInt`) قوللايدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isNumeric(value)`

پارامېتىرلار:

- `value`: سانلىق تۈر ئىكەنلىكىنى تەكشۈرىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    //‎‎ v بۇ ئامبارنىڭ تىپ قائىدىلىرى بويىچە سانلىق دەپ قارىلىدۇ
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isNumeric(value)`
