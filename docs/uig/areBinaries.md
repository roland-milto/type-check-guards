# areBinaries

## چۈشەندۈرۈش

تەمىنلەنگەن قىممەتنىڭ ئىناۋەتلىك ئىككىلىك تىزىمەكلەردىن تۈزۈلگەن بوش بولمىغان سانلار گۇرۇپپىسى ئىكەنلىكىنى تەكشۈرۈپ،
پەقەت بارلىق تۈرلەر دەلىللەشتىن ئۆتسەلا `true` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

JSON، فورما ياكى API لاردىن كەلگەن نامەلۇم تىزىملىك (مەسىلەن) نى قوبۇل قىلغاندا، ئۇنى پارسلاش ياكى بىر تەرەپ قىلىشتىن
بۇرۇن ئۇنىڭ ئىككىلىك تىزىمەكلەردىن تۈزۈلگەن بوش بولمىغان سانلار گۇرۇپپىسى ئىكەنلىكىنى جەزملەشتۈرۈش ئۈچۈن `areBinaries`
نى ئىشلىتىڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> نامەلۇم كىرگۈزۈشنى ئىككىلىك تىزىمەكلەرنى سان/BigInts قا ئايلاندۇرۇشتىن بۇرۇن دەلىللەش ئۈچۈن `areBinaries` نى ئىشلىتىڭ؛
> ئۇ سانلار گۇرۇپپىسىنىڭ بوش ئەمەسلىكىنى ۋە ھەر بىر ئېلېمېنتنىڭ ئىناۋەتلىك ئىككىلىك تىزىمەك ئىكەنلىكىنى كاپالەتلەيدۇ.

### ئەۋزەللىكلەر

- بىر قىممەتنىڭ ھەر بىر ئېلېمېنتى ئىناۋەتلىك ئىككىلىك (binary) تىزىمەك بولغان، بوش بولمىغان سانلار گۇرۇپپىسى (array)
  ئىكەنلىكىنى دەلىللەيدۇ.
- قوغدىغۇچلار (guards)، بالدۇر قايتىش (early returns) ۋە كىرگۈزۈش دەلىللەش (input validation) ئۈچۈن ماس كېلىدىغان ئاددىي
  boolean نەتىجە (`true`/`false`) قايتۇرىدۇ.
- ئىچىدە ئىككىلىك بولمىغان ھەر قانداق كىرگۈزۈش بار سانلار گۇرۇپپىسىنى رەت قىلىش ئارقىلىق كېيىنكى باسقۇچتىكى پارسلاش
  خاتالىقلىرىنىڭ ئالدىنى ئالىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areBinaries(array)`

پارامېتىرلار:

- `array`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); //‎ راست
console.log(areBinaries(b)); //‎ يالغان
console.log(areBinaries([])); //‎ يالغان
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areBinaries(array)`
