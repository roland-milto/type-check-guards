# areObjects

## چۈشەندۈرۈش

`areObjects` تەمىنلەنگەن تولدۇرۇلغان ماسسىپنىڭ پەقەت ئوبيېكتلاردىنلا تەركىب تاپقان-تاپمىغانلىقىنى تەكشۈرىدۇ.

### ئىشلىتىش ھالىتى

`areObjects` نى نامەلۇم ماسسىپ (مەسىلەن، JSON پارسلاش ياكى سىرتقى API لاردىن كەلگەن) قوبۇل قىلغاندا، ئۇنىڭ بوش
ئەمەسلىكىنى ۋە ھەر بىر ئېلېمېنتى ئوبيېكت ئىكەنلىكىنى تەكرارلاش ۋە ئوبيېكت خاسلىقىغا كىرىشتىن بۇرۇن كاپالەتلەندۈرۈش ئۈچۈن
ئىشلىتىڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areObjects` نى `unknown[]` نى ئېلېمېنتلارنى ئوبيېكت دەپ قاراشتىن بۇرۇن دەلىللەش ئۈچۈن ئىشلىتىڭ؛ ئۇ بوش ماسسىپلاردىكى
> ھالەتتە `false` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- كىرگۈزۈلگەن قىممەت تولدۇرۇلغان ماسسىپ بولۇپ، ھەر بىر ئېلېمېنتى ئوبيېكت بولغاندا ئاندىنلا `true` قايتۇرىدۇ.
- ئوبيېكت بولمىغان ئېلېمېنت بايقالغان ھامان بالدۇر توختاپ `false` قايتۇرىدۇ.
- ئوبيېكتقا خاس مەشغۇلاتلارنى ئىجرا قىلىشتىن بۇرۇن نامەلۇم كىرگۈزۈلمىنى دەلىللەشكە ياردەم بېرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areObjects(array)`

پارامېتىرلار:

- `array`: ئوبيېكت ئېلېمېنتلىرى بار-يوقلۇقى تەكشۈرۈلىدىغان ماسسىپ.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areObjects } from "@type-check/guards";

const value: unknown = [{}, { a: 1 }, new Date()];

if (Array.isArray(value) && areObjects(value)) {
  //‎‎ value بولسا ئوبيېكتلاردىن تۈزۈلگەن تولدۇرۇلغان سانلار گۇرۇپپىسى
  console.log("All items are objects:", value.length);
} else {
  console.log("Not a filled array of objects");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areObjects(array)`
