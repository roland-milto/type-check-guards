# areIndexesFound

## چۈشەندۈرۈش

`areIndexesFound` بىر قىممەتنىڭ بوش بولمىغان تىزىم (array) ئىكەنلىكىنى ۋە ئۇنىڭ ئېلېمېنتلىرىنىڭ ھەممىسى ئىناۋەتلىك
ئىندېكس ئىكەنلىكىنى تەكشۈرىدۇ؛ شۇنداق بولسا `true` قايتۇرىدۇ، بولمىسا `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

ئىشلەتكۈچى تەمىنلىگەن ياكى سىرتقى سانلىق مەلۇمات (مەسىلەن، پارس قىلىنغان JSON) نىڭ ئىندېكسلار تىزىمى بولۇشى كۈتۈلگەندە،
ئۇنى تىزىملارغا كىرىش ياكى تىزىمنى كېسىش (slice) ئۈچۈن ئىشلىتىشتىن بۇرۇن دەلىللەش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areIndexesFound` نى نامەلۇم كىرگۈزۈشنى ئۇنىڭ ئېلېمېنتلىرىنى تىزىم ئىندېكسلىرى دەپ قاراشتىن بۇرۇن دەلىللەش ئۈچۈن
> ئىشلىتىڭ؛ ئۇ بوش تىزىملار (array) ۋە ئىندېكس بولمىغان قىممەتلەرنى ئۆز ئىچىگە ئالغان تىزىملار ئۈچۈن `false` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- كىرگۈزۈلگەن قىممەت تولدۇرۇلغان بىر تىزىم (array) بولۇپ، ھەر بىر ئېلېمېنتى ئىناۋەتلىك ئىندېكس بولغاندا ئاندىن `true`
  قايتۇرىدۇ.
- تېز مەغلۇپ بولىدۇ: ئىندېكس بولمىغان ئېلېمېنت ئۇچرىغان ھامان `false` قايتۇرىدۇ.
- قىممەتلەرنى تىزىم ئورنى ياكى ئوفسېت سۈپىتىدە ئىشلىتىشتىن بۇرۇن قوغدىغۇچ (guard) قىلىپ ئىشلىتىشكە پايدىلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areIndexesFound(array)`

پارامېتىرلار:

- `array`: ئىندېكسقا ماس كېلىدىغان-كەلمەيدىغانلىقى تەكشۈرۈلىدىغان تىزىم (array).

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areIndexesFound } from "@type-check/guards";

const a: unknown[] = [0, 1, 2];
const b: unknown[] = [0, "a", 2];
const c: unknown[] = [];

console.log(areIndexesFound(a)); //‎ true
console.log(areIndexesFound(b)); //‎ false
console.log(areIndexesFound(c)); //‎ false

if (areIndexesFound(a)) {
  //‎‎ بۇ يەردە، `a` ئىندېكسلار بىلەن تولدۇرۇلغان بىر سانلار گۇرۇپپىسى ئىكەنلىكى دەلىللەندى.
  const firstIndex = a[0];
  console.log(firstIndex);
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areIndexesFound(array)`
