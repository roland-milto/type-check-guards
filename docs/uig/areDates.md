# areDates

## چۈشەندۈرۈش

`areDates` بېرىلگەن تىزىمنىڭ تولدۇرۇلغانلىقىنى ۋە پەقەت `Date` ئوبيېكتلىرىنىلا ئۆز ئىچىگە ئالغانلىقىنى بەلگىلەپ، بارلىق
ئېلېمېنتلار ئىناۋەتلىك ۋاقىت بولغاندا ئاندىن `true` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

ۋاقىتقا خاس لوگىكىنى (مەسىلەن ۋاقىت بويىچە تەرتىپلەش، فورماتلاش ياكى دائىرە ھېسابلاش) ئىجرا قىلىشتىن بۇرۇن، نامەلۇم
كىرگۈزۈشنى (مەسىلەن پارس قىلىنغان JSON، فورما سانلىق مەلۇماتى، API payloads) دەلىللەش ئۈچۈن `areDates` نى ئىشلىتىڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> پەقەت بوش بولمىغان تىزىملاردا ھەر بىر ئېلېمېنت `Date` بولغاندا `true` قايتۇرىدۇ؛ بوش تىزىملار `false` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- سانلار تىزىملىكىنىڭ مەزمۇنىنى دەلىللەشتىن بۇرۇن ئۇنىڭ بوش ئەمەسلىكىنى كاپالەتلەندۈرىدۇ، بوش كىرگۈزۈشلەر ئۈچۈن `true`
  قايتۇرۇپ قويۇشنىڭ ئالدىنى ئالىدۇ.
- ھەر بىر ئېلېمېنتنىڭ `Date` نۇسخىسى ئىكەنلىكىنى تەكشۈرىدۇ، تۇنجى ماس كەلمەسلىك كۆرۈلگەن ھامان دەرھال `false` قايتۇرىدۇ.
- تىزىمدىكى تۈرلەرگە ۋاقىتقا خاس مەشغۇلاتلارنى ئىجرا قىلىشتىن بۇرۇن قوغداش-ئۇسلۇبىدىكى تەكشۈرۈش سۈپىتىدە پايدىلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areDates(array)`

پارامېتىرلار:

- `array`: `Date` ئوبيېكتلىرى بار-يوقلۇقى تەكشۈرۈلىدىغان تىزىم.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areDates } from "@type-check/guards";

const a: unknown[] = [new Date(), new Date("2021-01-01")];
const b: unknown[] = [];
const c: unknown[] = [new Date(), "not a date"];

console.log(areDates(a)); //‎ راست
console.log(areDates(b)); //‎ يالغان
console.log(areDates(c)); //‎ يالغان

if (areDates(a)) {
  const timestamps = a.map(d => d.getTime());
  console.log(timestamps);
}
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:
