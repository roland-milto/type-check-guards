# areWeakSets

## چۈشەندۈرۈش

كىرگۈزۈشنىڭ بوش بولمىغان سانلار گۇرۇپپىسى بولۇپ، ئۇنىڭدىكى ھەر بىر ئېلېمېنت `WeakSet` بولسا شۇنداقلا پەقەت شۇ ھالەتتە
`true` قايتۇرىدىغانلىقىنى تەكشۈرىدۇ.

### ئىشلىتىش ھالىتى

ئىجرا ۋاقتىدىكى كىرگۈزۈشنى (مەسىلەن، API لاردىن، سەپلىمەدىن ياكى ئىشلەتكۈچى تەمىنلىگەن سانلىق مەلۇماتتىن) دەلىللەپ،
`WeakSet` خاسلىقىغا تايىنىدىغان لوگىكىنى داۋاملاشتۇرۇشتىن بۇرۇن بوش بولمىغان `WeakSet` ئەنسەتلىرى تىزىملىكىڭىز بارلىقىنى
كاپالەتلەندۈرۈش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areWeakSets` نى نامەلۇم كىرگۈزۈشنى `WeakSet[]` دەپ قاراشتىن بۇرۇن دەلىللەش ئۈچۈن ئىشلىتىڭ. ئۇ بوش سانلار گۇرۇپپىسى ۋە
> سانلار گۇرۇپپىسى بولمىغان قىممەتلەر ئۈچۈن `false` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- كىرگۈزۈش سانلار گۇرۇپپىسىدىكى ھەر بىر ئېلېمېنتنىڭ `WeakSet` ئىكەنلىكىنى كاپالەتلەندۈرىدۇ.
- بوش سانلار گۇرۇپپىسىغا `false` قايتۇرىدۇ، بۇ سانلىق مەلۇمات يوق بولغاندا خاتالىق بىلەن «ھەممىسى توغرا» دېگەن نەتىجە
  چىقىپ كېتىشىنىڭ ئالدىنى ئالىدۇ.
- كىرگۈزۈش تولدۇرۇلغان سانلار گۇرۇپپىسى بولمىغاندا (جۈملىدىن `null`) بىخەتەر ھالدا `false` قايتۇرۇپ مەغلۇپ بولىدۇ.
- `WeakSet` ئەنسەتلىرىنى تەلەپ قىلىدىغان مەشغۇلاتلارنى ئىجرا قىلىشتىن بۇرۇن قوغدىغۇچ (guard) سۈپىتىدە پايدىلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areWeakSets(array)`

پارامېتىرلار:

- `array`: `WeakSet` ئوبيېكتلىرى بار-يوقلۇقى تەكشۈرۈلىدىغان سانلار گۇرۇپپىسى.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areWeakSets } from "@type-check/guards";

const a: unknown = [new WeakSet<object>(), new WeakSet<object>()];
const b: unknown = [new WeakSet<object>(), {}];
const c: unknown = [];

if (areWeakSets(a)) {
  //‎‎ a بولسا WeakSet ئەمەلىي نۇسخىلىرىدىن تۈزۈلگەن بوش بولمىغان سانلار تىزىقى
}

console.log(areWeakSets(a)); //‎ راست
console.log(areWeakSets(b)); //‎ يالغان
console.log(areWeakSets(c)); //‎ يالغان
console.log(areWeakSets(null as unknown)); //‎ يالغان
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areWeakSets(array)`
