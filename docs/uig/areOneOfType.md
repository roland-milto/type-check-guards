# areOneOfType

## چۈشەندۈرۈش

`areOneOfType` بوش بولمىغان تىزىملىكتەكى بارلىق ئېلېمېنتلارنىڭ كۆرسىتىلگەن runtime تىپلاردىن بىرىگە تەۋە-تەۋە
ئەمەسلىكىنى تەكشۈرىدۇ.

### ئىشلىتىش ھالىتى

كىرىدىغان سانلىق مەلۇماتنى (مەسىلەن، پارس قىلىنغان JSON) دەلىللەش: بىر مەيدان بوش بولمىغان تىزىملىك بولۇشى ۋە ئۇنىڭ
ئىچىدىكى تۈرلەر مەلۇم بىر primitive تىپلەر توپلىمى بىلەن چەكلىنىشى كېرەك؛ تىزىملىك بوش بولسا ياكى رۇخسەت قىلىنمىغان تىپ
بار بولسا `false` قايتۇرۇڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> بۇ فۇنكسىيە boolean قايتۇرىدۇ ۋە compile time دا تىزىملىك ئېلېمېنت تىپلىرىنى تارايتمايدۇ؛ كېيىنكى بىر تەرەپ قىلىشتىن
> بۇرۇن runtime دەلىللەش قەدىمى سۈپىتىدە ئىشلىتىڭ.

### ئەۋزەللىكلەر

- سانلار تىزىملىكىدىكى ھەر بىر ئېلېمېنتنىڭ كەم دېگەندە بىر رۇخسەت قىلىنغان runtime تىپىغا ماس كېلىشىنى كاپالەتلەندۈرىدۇ؛
  پۈتۈن تىزىملىك ئۆتكىنىدىلا `true` قايتۇرىدۇ.
- نامۇۋاپىق كىرگۈزۈشلەرنى بالدۇر رەت قىلىدۇ: `array` ياكى `types` بوش بولسا ياكى تولدۇرۇلغان تىزىملىك بولمىسا `false`
  قايتۇرىدۇ.
- ئارىلاش تىپلىق توپلاملارنى (مەسىلەن، سان ۋە تېكىست) بىرلا `areOneOfType` چاقىرىشى بىلەن دەلىللەشكە پايدىلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areOneOfType(array, types)`

پارامېتىرلار:

- `array`: تەمىنلەنگەن تىپلەرگە سېلىشتۇرۇپ دەلىللەيدىغان ئېلېمېنتلار تىزىملىكى.
- `types`: تەكشۈرۈلىدىغان سانلىق مەلۇمات تىپلىرىنى بىلدۈرىدىغان تېكىست (string) تىزىملىكى.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areOneOfType } from "@type-check/guards";

const values1: unknown[] = [1, "a", true];
const ok1 = areOneOfType(values1, ["number", "string", "boolean"]);

const values2: unknown[] = [1, "a", {}];
const ok2 = areOneOfType(values2, ["number", "string"]);

const values3: unknown[] = [];
const ok3 = areOneOfType(values3, ["number"]);

console.log({ ok1, ok2, ok3 });
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areOneOfType(array, types)`
