# areFilledArrays

## چۈشەندۈرۈش

`areFilledArrays` ئىككى ئۆلچەملىك ماسسىپنىڭ بوش ئەمەسلىكىنى ۋە ئۇنىڭ بارلىق ئىچكى ماسسىپلىرىنىڭمۇ بوش ئەمەسلىكىنى
تەكشۈرىدۇ.

### ئىشلىتىش ھالىتى

`areFilledArrays` نى جەدۋەل ياكى ماترىتسا شەكىللىك كىرگۈزۈشنى (مەسىلەن، CSV قۇرلىرى، تور (grid) سانلىق مەلۇماتى،
گۇرۇپپىلانغان نەتىجىلەر) دەلىللەش ئۈچۈن ئىشلىتىڭ؛ شۇنداق قىلغاندا ئەڭ ئاز دېگەندە بىر ئىچكى ماسسىپ بارلىقىنى ۋە ھېچقايسى
ئىچكى ماسسىپنىڭ بوش ئەمەسلىكىنى بىخەتەر پەرەز قىلالايسىز.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> ئىككى ئۆلچەملىك ماسسىپتا ئەڭ ئاز دېگەندە بىر قۇر بارلىقىنى ۋە ھەر بىر قۇردا ئەڭ ئاز دېگەندە بىر ئېلېمېنت بارلىقىنى
> كاپالەتلەندۈرۈپ، ئۇنىڭ ئۈستىدە ئايلىنىش ياكى ئىندېكسلاشتىن بۇرۇن `areFilledArrays` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- سىرتقى ماسسىپنىڭ بوش ئەمەسلىكىنى ۋە ھەر بىر ئىچكى ماسسىپنىڭمۇ بوش ئەمەسلىكىنى دەلىللەيدۇ؛ پەقەت ئىككى شەرت ھەممىسى
  قاندۇرۇلغاندا `true` قايتۇرىدۇ.
- ئىچكى ماسسىپلاردىكى ھەر قانداق ئېلېمېنت تىپلىرى بىلەن ئىشلەيدۇ (مەسىلەن، سانلار، تېكىستلەر، ئوبيېكتلار، ئىچىگە
  قاپلانغان ماسسىپلەر)، چۈنكى ئۇ پەقەت ماسسىپنىڭ «تولۇق/بوش ئەمەس» ھالىتىنىلا تەكشۈرىدۇ، ئېلېمېنت مەزمۇنىنى ئەمەس.
- ئىككى ئۆلچەملىك سانلىق مەلۇماتنى بىر تەرەپ قىلىشتىن بۇرۇن قوغدىغۇچ سۈپىتىدە ئىشلىتىشكە ماس كېلىدىغان ئاددىي بولېن
  نەتىجە (`true`/`false`) تەمىنلەيدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areFilledArrays(array)`

پارامېتىرلار:

- `array`: تەكشۈرۈلىدىغان ئىككى ئۆلچەملىك ماسسىپ.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areFilledArrays } from "@type-check/guards";

const a: unknown[][] = [[1]];
const b: unknown[][] = [["a", "b"], [1, 2, 3]];
const c: unknown[][] = [[{}, []], ["string"]];
const d: unknown[][] = [[]];
const e: unknown[][] = [[], [1, 2, 3]];
const f: unknown[][] = [];

console.log(areFilledArrays(a)); //‎ راست
console.log(areFilledArrays(b)); //‎ راست
console.log(areFilledArrays(c)); //‎ راست
console.log(areFilledArrays(d)); //‎ يالغان
console.log(areFilledArrays(e)); //‎ يالغان
console.log(areFilledArrays(f)); //‎ يالغان

```
