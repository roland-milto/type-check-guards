# areBooleans

## چۈشەندۈرۈش

`areBooleans` بېرىلگەن بوش بولمىغان سانلار گۇرۇپپىسىنىڭ پەقەت بولېن قىممەتلەرنىلا ئۆز ئىچىگە ئالغان-ئالمىغانلىقىنى
تەكشۈرىدۇ؛ ئەگەر شۇنداق بولسا `true` قايتۇرىدۇ، بولمىسا `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

ئىشلەتكۈچى تەمىنلىگەن ياكى سىرتقى سانلىق مەلۇماتلارنى (مەسىلەن، JSON payloads، query params، config arrays) دەلىللەپ،
بوش بولمىغان تىزىملىكنىڭ پەقەت بولېنلارنىلا ئۆز ئىچىگە ئالغانلىقىغا كاپالەتلىك قىلىڭ؛ ئاندىن بولېن لوگىكىسىنى قوللىنىش
ياكى `boolean[]` كۈتىدىغان API لارغا يوللاش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `unknown[]` نى `boolean[]` دەپ قاراشتىن بۇرۇن `areBooleans` نى ئىشلىتىپ دەلىللەڭ؛ ئۇ بوش سانلار گۇرۇپپىسى ئۈچۈن
`false` قايتۇرىدۇ، شۇڭا ئەگەر بوش تىزىملىككە رۇخسەت قىلىنىشى كېرەك بولسا، ئۇ ھالەتنى ئايرىم بىر تەرەپ قىلىڭ.

### ئەۋزەللىكلەر

- پەقەت ھەر بىر ئېلېمېنت بولېن بولۇپ، كىرگۈزۈش بوش بولمىغان سانلار گۇرۇپپىسى بولغاندا `true` قايتۇرىدۇ.
- بوش سانلار گۇرۇپپىسىنى رەت قىلىش ( `false` قايتۇرىدۇ) ئارقىلىق يالغان مۇۋاپىق كېلىپ قېلىشنىڭ ئالدىنى ئالىدۇ.
- بولېنلا ئىشلىتىدىغان مەشغۇلاتلاردىن بۇرۇن ئىجرا ۋاقتىدىكى قوغدىغۇچ سۈپىتىدە ياخشى ئىشلەيدۇ (مەسىلەن، `every`, `some`,
  لوگىكىلىق قىسقارتىشلار).

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areBooleans(array)`

پارامېتىرلار:

- `array`: بولېن ئېلېمېنتلىرى بار-يوقلۇقى تەكشۈرۈلىدىغان سانلار گۇرۇپپىسى.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areBooleans } from "@type-check/guards";

const values1: unknown[] = [true, false, true];
if (areBooleans(values1)) {
  const allTrue = values1.every(v => v);
  console.log(allTrue);
}

const values2: unknown[] = [];
console.log(areBooleans(values2));

const values3: unknown[] = [true, 1, false];
console.log(areBooleans(values3));
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areBooleans(array)`
