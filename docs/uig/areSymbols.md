# areSymbols

## چۈشەندۈرۈش

كىرگۈزۈش قىممىتىنىڭ ئېلېمېنتلىرىنىڭ ھەممىسى symbol بولغان بوش بولمىغان ماسسىۋ ئىكەنلىكىنى تەكشۈرۈپ، `true` ياكى `false`
قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

بىر سەپلىمە (configuration) مەيدانىنىڭ (مەسىلەن، symbol ئارقىلىق ئىپادىلەنگەن ئۆزگىچە ئاچقۇچلار تىزىملىكى) بوش بولمىغان
ۋە پەقەت symbol لاردىن تۈزۈلگەن ماسسىۋ ئىكەنلىكىنى، `symbol[]` تەلەپ قىلىدىغان API لاردا ئىشلىتىشتىن بۇرۇن دەلىللەڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areSymbols` نى `symbol[]` دەپ قاراشتىن بۇرۇن نامەلۇم كىرگۈزۈشنى دەلىللەش ئۈچۈن ئىشلىتىڭ؛ ئۇ ماسسىۋ بولمىغانلار ۋە بوش
> ماسسىۋلار ئۈچۈن `false` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- كىرگۈزۈش قىممىتى بوش بولمىغان ماسسىۋ بولۇپ، ھەر بىر ئېلېمېنتى symbol بولغاندا ئاندىنلا `true` قايتۇرىدۇ.
- ئىچكى filled-array تەكشۈرۈشى ئارقىلىق ماسسىۋ بولمىغانلارنى ۋە بوش ماسسىۋلارنى رەت قىلىپ، يالغان مۇۋەپپەقىيەتلەرنىڭ
  ئالدىنى ئالىدۇ.
- كېيىنكى بىر تەرەپ قىلىشتىن بۇرۇن پەقەت symbol دىن تۈزۈلگەن تىزىملىكلەرنى دەلىللەشتە runtime type guard سۈپىتىدە
  پايدىلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areSymbols(array)`

پارامېتىرلار:

- `array`: symbol ئېلېمېنتلىرى بار-يوقلۇقى تەكشۈرۈلىدىغان ماسسىۋ.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  //‎‎ a ئىجرا ۋاقتىدا پەقەت symbol دىن تۈزۈلگەن سانلار قاتارى
  const first = a[0];
  console.log(typeof first); // "symbol"
}

console.log(areSymbols(b)); // false
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areSymbols(array)`
