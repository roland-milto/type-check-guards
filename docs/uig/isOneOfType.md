# isOneOfType

## چۈشەندۈرۈش

`isOneOfType` بېرىلگەن `value` نىڭ تەمىنلەنگەن تىپ تېكىستلىرىدىن ئاز دېگەندە بىرىگە ماس كېلىدىغان-كەلمەيدىغانلىقىنى
بەلگىلەيدۇ؛ ئەگەر ھەر قانداق ماسلىشىش تېپىلسا `true` قايتۇرىدۇ، بولمىسا `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

كېڭ تىپلىق ياكى سىرتتىن كەلگەن سانلىق مەلۇماتنى (مەسىلەن، پارس قىلىنغان JSON، سوئال پارامېتىرلىرى) تەكشۈرۈپ دەلىللەش؛
داۋاملىق لوگىكىغا ئۆتۈشتىن بۇرۇن كۆپ خىل قوبۇل قىلىنىدىغان ئىجرا ۋاقتى تىپلىرىغا (مەسىلەن `number` ياكى `string`) رۇخسەت
قىلىش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> بىر قىممەتنىڭ بىر قانچە رۇخسەت قىلىنغان تىپنىڭ خالىغان بىرىگە ماس كېلىدىغانلىقىنى ئىجرا ۋاقتىدا تەكشۈرمەكچى بولغاندا
`isOneOfType` نى ئىشلىتىڭ؛ ئاز دېگەندە بىر تىپ ماس كەلسە `true` قايتۇرىدۇ، بولمىسا `false` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- بىرلا چاقىرىشتا قىممەتنى كۆپ خىل رۇخسەت قىلىنغان تىپلارغا سېلىشتۇرۇپ تەكشۈرىدۇ، تۇنجى ماس كەلگەندە `true` قايتۇرىدۇ.
- `unknown` كىرگۈزۈلمىلەر بىلەن ئىشلەيدۇ، شۇڭا ئۇ ئىجرا ۋاقتى چېگرا نۇقتىلىرىدا (مەسىلەن، سىرتقى سانلىق مەلۇمات،
  ئىشلەتكۈچى كىرگۈزۈشى) پايدىلىق.
- شەرتلىك لوگىكا ۋە بالدۇر قايتۇرۇشلار بىلەن ياخشى بىرلەشتۈرۈلىدىغان ئاددىي بولېن نەتىجە (`true`/`false`) تەمىنلەيدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isOneOfType(value, types)`

پارامېتىرلار:

- `value`: بەلگىلەنگەن تىپلارغا سېلىشتۇرۇپ تەكشۈرۈلىدىغان قىممەت.
- `types`: قىممەتنىڭ مۇمكىن بولغان تىپلىرىنى ئىپادىلەيدىغان تىپ تېكىستلىرىدىن تۈزۈلگەن سانلار گۇرۇپپىسى.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  //‎‎ ئىجرا ۋاقتىدا input بىر ئوبيېكت
}

console.log(isOneOfType(3, ["number", "string"])); //‎ راست
console.log(isOneOfType("hello", ["number", "boolean"])); //‎ يالغان

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isOneOfType(value, types)`
