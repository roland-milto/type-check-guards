# isNaN

## چۈشەندۈرۈش

تېكىستنى ئايلاندۇرماستىن، تەمىنلەنگەن `value` نىڭ `number` تىپىدىكى `NaN` ئىكەنلىكىنى بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

ئىشەنچسىز ياكى بوش تىپلانغان كىرگۈزۈشنى (مەسىلەن، API payloads، فورما قىممەتلىرى، پارس قىلىنغان JSON) دەلىللەپ، ئالاھىدە
`NaN` قىممىتىنى بايقاپ ئۇنى ئېنىق بىر تەرەپ قىلىش؛ شۇنىڭ بىلەن بىر ۋاقىتتا سان بولمىغان كىرگۈزۈشلەرنى `NaN` ئەمەس دەپ
قاراش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> كىرگۈزۈشنىڭ راستىنلا `number` ئىكەنلىكىگە كاپالەتلىك قىلىپ (تېكىستتىن سانغا ئايلاندۇرۇش يوق)، ئالاھىدە سان قىممىتى
`NaN` نى بايقاشقا توغرا كەلگەندە `isNaN` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- سان بولمىغان قىممەتلەرنى (مەسىلەن، تېكىست/سټرېڭ) سانغا زورلاپ ئايلاندۇرماي تۇرۇپ بىر قىممەتنىڭ `NaN` ئىكەنلىكىنى
  تەكشۈرىدۇ.
- `number` تىپىدىكى ۋە شۇنىڭ بىلەن بىر ۋاقىتتا `NaN` بولغان قىممەتلەر ئۈچۈنلا `true` قايتۇرىدۇ.
- `unknown` كىرگۈزۈشلەر ئۈچۈن بىخەتەر بولۇپ، يوشۇرۇن ئايلاندۇرۇشتىن كېلىدىغان يالغان مۇسبەت نەتىجىلەرنىڭ ئالدىنى ئالىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isNaN(value)`

پارامېتىرلار:

- `value`: `number` تىپىدىكى `NaN` ئىكەنلىكى تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); //‎ true
console.log(isNaN(b)); //‎ false
console.log(isNaN(c)); //‎ false

if (isNaN(a)) {
  //‎‎ a بىر سان بولۇپ، ئالاھىدە ھالدا NaN
}
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isNaN(value)`
