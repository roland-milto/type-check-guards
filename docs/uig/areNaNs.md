# areNaNs

## چۈشەندۈرۈش

`areNaNs` ئارايىدىكى بارلىق ئېلېمېنتلارنىڭ `NaN` ئىكەنلىكىنى تەكشۈرىدۇ ۋە پەقەت ھەر بىر ئېلېمېنت `NaN` بولغاندا ئاندىن
`true` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

`NaN` سىگنال (sentinel) قىممەت سۈپىتىدە ئىشلىتىلىدىغان كىرگەن سانلىق مەلۇماتنى دەلىللەش، ھەمدە پۈتۈن ئارايىنىڭ پەقەتلا
`NaN` دىن تەركىب تاپقانلىقىغا كاپالەتلىك قىلىش (مەسىلەن، پۈتۈنلەي يوقاپ كەتكەن سانلىق قاتارنى بايقاش).

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> ئارايىنىڭ پەقەت سانلىق `NaN` قىممىتىدىنلا تەركىب تاپقانلىقىنى دەلىللەش كېرەك بولغاندا (تېكىستنى سانغا زورلاپ
> ئايلاندۇرماي) `areNaNs` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- پەقەت ھەر بىر ئېلېمېنت `NaN` بولغاندا ئاندىن `true` قايتۇرىدۇ (قاتتىق ھەممە-ئېلېمېنت تەكشۈرۈشى).
- تېكىستلەرنى سانغا ئايلاندۇرمايدۇ؛ "NaN" غا ئوخشاش قىممەتلەر `NaN` بولماي قالىدۇ ۋە نەتىجىنى `false` قىلىدۇ.
- تولدۇرۇلمىغان ئارايىلار ئۈچۈن `false` قايتۇرىدۇ، بۇ بوش كىرگۈزۈشتە خاتالىق بىلەن `true` بولۇپ كېتىشنىڭ ئالدىنى ئالىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areNaNs(array)`

پارامېتىرلار:

- `array`: `NaN` قىممەتلىرى بار-يوقلۇقىنى تەكشۈرىدىغان ئارايى.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); //‎ true
const b = areNaNs([NaN, 1, NaN]); //‎ false
const c = areNaNs([NaN, "NaN", NaN]); //‎ false
const d = areNaNs([NaN, null, NaN]); //‎ false
const e = areNaNs([] as unknown[]); //‎ false

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areNaNs(array)`
