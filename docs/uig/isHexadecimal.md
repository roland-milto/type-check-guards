# isHexadecimal

## چۈشەندۈرۈش

`isHexadecimal` بېرىلگەن قىممەتنىڭ مەجبۇرىي `0x`/`0X` ئالدى قوشۇلغۇچىسى بار ئون ئالتىلىك تىزىم لىتېرالى ئىكەنلىكىنى
تەكشۈرىدۇ.

### ئىشلىتىش ھالىتى

`isHexadecimal` نى، سەپلىمە قىممەتلىرى، API يۈكى (payload) مەيدانلىرى ياكى CLI ئارگۇمېنتلىرى قاتارلىقلاردا ئون ئالتىلىك
تىزىم لىتېرالى شەكلىدە تەمىنلىنىشى زۆرۈر (مەسىلەن، ID لار، ماسكا (mask) لار ياكى ئادرېسلار) ۋە ئەتراپىدا بوشلۇق
بولماسلىقى كېرەك بولغان قىممەتلەرنى دەلىللەش ئۈچۈن ئىشلىتىڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `isHexadecimal` نى، ئىشلەتكۈچى كىرگۈزۈشى ياكى سېرئىياللاشتۇرۇلغان سانلىق مەلۇماتنى پارسلاش ياكى ئايلاندۇرۇشتىن بۇرۇن
> قاتتىق ئون ئالتىلىك لىتېرال تىزىم (مەجبۇرىي `0x`/`0X` ئالدى قوشۇلغۇچىسىنى ئۆز ئىچىگە ئالىدۇ) سۈپىتىدە دەلىللەش كېرەك
> بولغاندا ئىشلىتىڭ.

### ئەۋزەللىكلەر

- بىر قىممەتنىڭ تىزىم (string) ئىكەنلىكىنى ۋە قاتتىق ئون ئالتىلىك (hexadecimal) لىتېرال فورماتىغا ماس كېلىدىغانلىقىنى
  دەلىللەيدۇ (`0x`/`0X` ئالدى قوشۇلغۇچىسى زۆرۈر).
- باشى ياكى ئاخىرىدا بوشلۇق بار تىزىملارنى رەت قىلىدۇ، بۇ ئارقىلىق تولدۇرۇلغان كىرگۈزۈشنىڭ خاتا قوبۇل قىلىنىشىدىن
  ساقلايدۇ.
- ئىختىيارىي بەلگە (sign) نى قوللايدۇ ۋە ئالدى قوشۇلغۇچى بىلەن رەقەملەرگە نىسبەتەن چوڭ-كىچىك ھەرپ پەرقىنى قىلمايدۇ،
  `true`/`false` نى ئالدىن پەرەز قىلغىلى بولىدىغان شەكىلدە قايتۇرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isHexadecimal(value)`

پارامېتىرلار:

- `value`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); //‎ true
isHexadecimal("-0Xff"); //‎ true
isHexadecimal("1A2B"); //‎ false (ئالدى قوشۇمچىسى يوق)
isHexadecimal(" 0x1A2B"); //‎ false (باشتىكى بوشلۇق)
isHexadecimal(0x1a2b); //‎ false (تېكىست ئەمەس)
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isHexadecimal(value)`
