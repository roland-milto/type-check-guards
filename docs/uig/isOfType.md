# isOfType

## چۈشەندۈرۈش

بېرىلگەن `value` نىڭ بەلگىلەنگەن تىپ تېكىستىگە ماس كېلىدىغان-كەلمەيدىغانلىقىنى بەلگىلەيدۇ؛ پىرىمىتىۋلار ئۈچۈن `typeof`
نى، مۇرەككەپ تىپلەر ئۈچۈن زاپاس ئۇسۇلنى ئىشلىتىدۇ.

### ئىشلىتىش ھالىتى

تىپقا خاس مەشغۇلاتلارنى قىلىشتىن بۇرۇن قىممەتنىڭ كۈتۈلگەن تىپ تېكىستىدە ئىكەنلىكىنى تەكشۈرۈش ئارقىلىق `unknown`
كىرگۈزۈشلەرنى (مەسىلەن، API جاۋابلىرى، ئىشلەتكۈچى كىرگۈزۈشى، پارس قىلىنغان JSON) دەلىللەش ۋە تارايتىش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `unknown` قىممەتلەر بىلەن ئىشلىگەندە ئىجرا ۋاقتىدىكى تىپلەر بويىچە شاخلىنىش ئۈچۈن `isOfType` نى ئىشلىتىڭ؛ ئۇ `true`/
`false` قايتۇرىدۇ ۋە `null` بىلەن `undefined` نى ئېنىق بىر تەرەپ قىلىدۇ.

### ئەۋزەللىكلەر

- سۈرئەت ۋە ئېنىقلىق ئۈچۈن بىۋاسىتە `typeof` ئارقىلىق پىرىمىتىۋ تىپلەرنى تەكشۈرىدۇ.
- `typeof` يالغۇز ئۆزى كۆڭۈلدىكىدەك ئايرىپ بېرەلمەيدىغان `null` ۋە `undefined` نى توغرا بىر تەرەپ قىلىدۇ.
- `getTypeOf` نى ئىشلىتىدىغان زاپاس سېلىشتۇرۇش ئارقىلىق مۇرەككەپ ياكى خاس تىپ تېكىستلىرىنى قوللايدۇ.
- قوغدىغۇچ ۋە شاخلىنىشقا ماس كېلىدىغان ئاددىي بولېن نەتىجە (`true`/`false`) قايتۇرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isOfType(value, type)`

پارامېتىرلار:

- `value`: `type` بىلەن سېلىشتۇرۇپ سىنايدىغان قىممەت.
- `type`: تەكشۈرۈلىدىغان تىپنىڭ تېكىستلىك ئىپادىسى.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isOfType } from "@type-check/guards";

const input: unknown = Math.random() > 0.5 ? 123 : "hello";

if (isOfType(input, "number")) {
  //‎‎ بۇ يەردە input سان
  const doubled = input * 2;
  console.log(doubled);
} else if (isOfType(input, "string")) {
  //‎‎ بۇ يەردە input تېكىست
  console.log(input.toUpperCase());
}

console.log(isOfType(null, "null"));
console.log(isOfType(undefined, "undefined"));
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isOfType(value, type)`
