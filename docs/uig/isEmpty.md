# isEmpty

## چۈشەندۈرۈش

بېرىلگەن قىممەتنىڭ بوش ياكى ئەمەسلىكىنى بەلگىلەيدۇ؛ `null`, `undefined`, بوش/پەقەت بوشلۇق تىزىملىكى، بوش ئاراي، بوش
`Map`/`Set` ياكى ئۆزىگە تەۋە ساناقلىق خاسلىقى يوق ئوبيېكت ئۈچۈن `true` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

`isEmpty` نى كىرگۈزۈشلەرنى دەلىللەش ۋە كۆپ خىل سانلىق مەلۇمات تۈرلىرىدە يوق/بوش قىممەتلەرنى بايقاش ئۈچۈن ئىشلىتىڭ (
مەسىلەن، فورما مەيدانلىرى، API payload لىرى، سەپلىمە ئوبيېكتلار)؛ بۇ يەردە `null`, `undefined`, پەقەت بوشلۇق تىزىملىكى،
بوش توپلاملار ۋە خاسلىقى يوق ئوبيېكتلار بوش دەپ قارىلىشى كېرەك.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `isEmpty` بولسا boolean قايتۇرىدىغان قورال (TypeScript type predicate ئەمەس)، شۇڭا ئۆزىلا تۈرلەرنى تارايتمەيدۇ؛ ئۇنى
> compile-time تارايىتىشتىن كۆرە دەلىللەش/شاخلىنىش ئۈچۈن ئىشلىتىڭ.

### ئەۋزەللىكلەر

- بوش قالدۇرۇش تەكشۈرۈشىدە `null` ۋە `undefined` نى `true` دەپ قارىيدۇ.
- ئۇزۇنلۇقنى تەكشۈرۈشتىن بۇرۇن `trim` قىلىپ، پەقەت بوشلۇقتىن ئىبارەت بولغان تىزىملىكلەرنى بوش دەپ قارىيدۇ.
- ئادەتتىكى قاچا تۈرلىرىنى (ئاراي، `Map`, `Set`) ۋە ئۆزىگە تەۋە ساناقلىق (enumerable) خاسلىقى يوق ئاددىي ئوبيېكتلارنى
  قوللايدۇ.
- `hasOwnProperty` تەكشۈرۈشىنى ئىشلىتىپ، ۋارىسلىق قىلىنغان خاسلىقلارنى ساناشتىن ساقلىنىدۇ.
- قوغداش (guard) ۋە دەلىللەش (validation) ئۈچۈن ماس كېلىدىغان ئاددىي boolean نەتىجە (`true`/`false`) قايتۇرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isEmpty(value)`

پارامېتىرلار:

- `value`: بوش ياكى ئەمەسلىكى تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isEmpty(value)`
