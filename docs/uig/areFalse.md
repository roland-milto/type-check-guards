# areFalse

## چۈشەندۈرۈش

`areFalse` بېرىلگەن سانلار گۇرۇپپىسىدىكى بارلىق ئېلېمېنتلارنىڭ قاتتىق ھالدا بولېن `false` ئىكەن-ئەمەسلىكىنى تەكشۈرىدۇ.

### ئىشلىتىش ھالىتى

داۋاملاشتۇرۇشتىن بۇرۇن ئىقتىدار بايراقلىرى، تەكشۈرۈشلەر ياكى قوغدىغۇچ نەتىجىلىرى تىزىملىكىنىڭ ھەممىسى `false`
ئىكەنلىكىنى دەلىللەش (مەسىلەن، توسالغۇ بولىدىغان شەرتلەر يوقلۇقىنى جەزملەشتۈرۈش).

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> سانلار گۇرۇپپىسىنىڭ بوش ئەمەسلىكى ۋە پەقەت بولېن قىممەت `false` نىلا ئۆز ئىچىگە ئالىدىغانلىقىنى قاتتىق دەلىللەش كېرەك
> بولغاندا `areFalse` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- ھەر بىر ئېلېمېنتنىڭ قاتتىق ھالدا `false` ئىكەنلىكىنى كاپالەتلەندۈرىدۇ (truthy/falsey مەجبۇرىي ئايلاندۇرۇش يوق).
- `isFilledArray` ئارقىلىق تولدۇرۇلغان سانلار گۇرۇپپىسىنى تەلەپ قىلىدىغانلىقى ئۈچۈن، سانلار گۇرۇپپىسى بولمىغان ياكى بوش
  سانلار گۇرۇپپىسىغا `false` قايتۇرىدۇ.
- ئۈنۈمدارلىق ئۈچۈن تۇنجى `false` بولمىغان ئېلېمېنتتا بالدۇر توختايدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areFalse(array)`

پارامېتىرلار:

- `array`: تەكشۈرۈلىدىغان سانلار گۇرۇپپىسى؛ ھەر قانداق تىپتىكى ئېلېمېنتلارنى ئۆز ئىچىگە ئالالايدۇ.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areFalse } from "@type-check/guards";

const a = areFalse([false, false, false]); //‎ راست
const b = areFalse([false, true, false]);  //‎ يالغان
const c = areFalse([false, "false", false]); //‎ يالغان
const d = areFalse([]); //‎ يالغان
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areFalse(array)`
