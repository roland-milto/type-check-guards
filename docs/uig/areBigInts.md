# areBigInts

## چۈشەندۈرۈش

`areBigInts` بىر قىممەتنىڭ پەقەت `bigint` قىممەتلىرىنى ئۆز ئىچىگە ئالغان بوش بولمىغان تىزىملىك ئىكەن-ئەمەسلىكىنى
بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

نامەلۇم كىرگۈزۈشنى (مەسىلەن، پارس قىلىنغان JSON-غا ئوخشاش سانلىق مەلۇمات، API payloadلىرى ياكى `unknown` دەپ تىپلانغان
فۇنكسىيە پارامېتىرلىرى) بىر تەرەپ قىلىشتىن بۇرۇن، ئۇنىڭ `bigint` قىممەتلىرىدىن تەركىب تاپقان بوش بولمىغان تىزىملىك
ئىكەنلىكىنى دەلىللەش؛ پەقەت بارلىق ئېلېمېنتلار `bigint` بولغاندا `true` قايتۇرىدۇ، بولمىسا `false`.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> نامەلۇم كىرگۈزۈش ئۈستىدە `bigint`-لا مەشغۇلاتلارنى (مەسىلەن، ھېسابلاش، سېلىشتۇرۇش) ئىجرا قىلىشتىن بۇرۇن، ئىجرا
> ۋاقتىدىكى قوغدىغۇچ سۈپىتىدە `areBigInts` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- ھەر بىر ئېلېمېنتنىڭ `bigint` ئىكەنلىكىنى كاپالەتلەندۈرىدۇ؛ پەقەت پۈتۈن سانلار تىزىملىكى تولۇق ماس كەلگەندەلا `true`
  قايتۇرىدۇ.
- لايىھە بويىچە تىزىملىك بولمىغان قىممەتلەرنى ۋە بوش تىزىملىكلەرنى رەت قىلىدۇ (`isFilledArray` ئارقىلىق)، بۇ ئارقىلىق
  ئىناۋەتسىز كىرگۈزۈشلەرنىڭ خاتا قوبۇل قىلىنىشىنىڭ ئالدىنى ئالىدۇ.
- تېز مەغلۇپ بولۇش: `bigint` بولمىغان بىر ئېلېمېنت بايقالغان ھامان `false` قايتۇرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areBigInts(array)`

پارامېتىرلار:

- `array`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areBigInts } from "@type-check/guards";

const a: unknown = [10n, 20n];
const b: unknown = [10n, 20];
const c: unknown = [];

console.log(areBigInts(a)); // ‎true
console.log(areBigInts(b)); // ‎false
console.log(areBigInts(c)); // ‎false
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areBigInts(array)`
