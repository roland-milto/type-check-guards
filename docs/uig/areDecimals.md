# areDecimals

## چۈشەندۈرۈش

تىزىمدىكى بارلىق ئېلېمېنتلارنىڭ ئونلۇق سان ئىكەنلىكىنى ۋە تىزىملىكنىڭ تولدۇرۇلغانلىقىنى تەكشۈرۈپ، `true` ياكى `false`
قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

ئىشلەتكۈچى تەمىنلىگەن تىزىملىكلەرنى (مەسىلەن، CSV ئىستونلىرى ياكى فورما كىرگۈزۈشلەر) دەلىللەپ، پارسلاش ياكى ھېسابلاشتىن
بۇرۇن تىزىملىكنىڭ بوش ئەمەسلىكى ۋە ھەر بىر كىرگۈزۈشنىڭ ئونلۇق قىممەت ئىكەنلىكىنى كاپالەتلەندۈرۈش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `unknown[]` نىڭ بوش ئەمەسلىكى ۋە ھەر بىر ئېلېمېنتىنىڭ ئونلۇق سان ئىپادىسى ئىكەنلىكىنى تېزلا بولېن شەكىلدە تەكشۈرۈش
> كېرەك بولغاندا `areDecimals` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- تۈرلەرنى دەلىللەشتىن بۇرۇن كىرگۈزۈلگەن سانلار تىزىملىكىنىڭ تولدۇرۇلغانلىقىنى كاپالەتلەندۈرىدۇ، بۇ ئارقىلىق بوش
  تىزىملىكلەرنىڭ خاتالىق بىلەن قوبۇل قىلىنىشىنىڭ ئالدىنى ئالىدۇ.
- ھەر بىر ئېلېمېنتنى `isDecimal` بىلەن دەلىللەيدۇ، شۇڭا ئارىلاش ياكى ئىناۋەتسىز قىممەتلەر دەرھال `false` نەتىجىسىنى
  كەلتۈرۈپ چىقىرىدۇ.
- قوغدىغۇچىلار ۋە بالدۇر قايتۇرۇش (early-return) دەلىللەش ئېقىملىرىغا ماس كېلىدىغان ئاددىي بولېن نەتىجە (`true`/`false`)
  بىلەن تەمىنلەيدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areDecimals(array)`

پارامېتىرلار:

- `array`: تەكشۈرۈلىدىغان تىزىملىك.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); //‎ راست
console.log(areDecimals(b)); //‎ يالغان
console.log(areDecimals(c)); //‎ يالغان
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areDecimals(array)`
