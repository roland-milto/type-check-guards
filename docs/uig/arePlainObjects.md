# arePlainObjects

## چۈشەندۈرۈش

سانلار گۇرۇپپىسىدىكى بارلىق ئېلېمېنتلارنىڭ ئاددىي ئوبيېكت ئىكەنلىكىنى تەكشۈرىدۇ؛ پەقەت ھەر بىر ئېلېمېنت شەرتكە ئۇيغۇن
بولغاندا `true` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

سىرتقى ياكى تىپسىز سانلىق مەلۇماتلارنى (مەسىلەن، پارس قىلىنغان JSON، API payloadلىرى، فورما يوللاشلىرى) دەلىللەپ،
خاسلىقلىرىنى ئوقۇش ۋە ئايلاندۇرۇشتىن بۇرۇن، سىزگە بوش بولمىغان ۋە ھەر بىر كىرىش تۈرى ئاددىي ئوبيېكت بولغان سانلار
گۇرۇپپىسى كەلگەنلىكىنى كاپالەتلەندۈرۈڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> TypeScript تا نامەلۇم كىرگۈزۈشنى `Record<string, unknown>[]` (ياكى تېخىمۇ قاتتىق ئوبيېكت شەكلى) دەپ قاراشتىن بۇرۇن
`arePlainObjects` نى ئىشلىتىپ دەلىللەڭ.

### ئەۋزەللىكلەر

- كىرگۈزۈلگەن سانلار گۇرۇپپىسىدىكى ھەر بىر ئېلېمېنتنىڭ ئاددىي ئوبيېكت ئىكەنلىكىنى كاپالەتلەندۈرىدۇ؛ پەقەت بارلىق تۈرلەر
  ماس كەلگەندەلا `true` قايتۇرىدۇ.
- `false` قايتۇرۇش ئارقىلىق ئىناۋەتسىز كىرگۈزۈشلەرنى (سانلار گۇرۇپپىسى بولمىغان ياكى بوش سانلار گۇرۇپپىسى) بالدۇر رەت
  قىلىدۇ.
- ئوبيېكت-لىتېرال ئوبيېكتلارنىمۇ، `Object.create(null)` ئارقىلىق ياسالغان ئوبيېكتلارنىمۇ ئىناۋەتلىك ئاددىي ئوبيېكت دەپ
  قارىيدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `arePlainObjects(array)`

پارامېتىرلار:

- `array`: ئاددىي ئوبيېكت ئېلېمېنتلىرى بار-يوقلۇقى تەكشۈرۈلىدىغان سانلار گۇرۇپپىسى.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { arePlainObjects } from "@type-check/guards";

const a = arePlainObjects([{ a: 1 }, { b: 2 }]); //‎ راست
const b = arePlainObjects([{}, Object.create(null)]); //‎ راست
const c = arePlainObjects([{ a: 1 }, 2 as unknown]); //‎ يالغان
const d = arePlainObjects([] as unknown[]); //‎ يالغان
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.arePlainObjects(array)`
