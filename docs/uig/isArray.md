# isArray

## چۈشەندۈرۈش

`isArray` بېرىلگەن قىممەتنىڭ تىزىملىك (array) ئىكەنلىكىنى تەكشۈرىدۇ ۋە ئەگەر شۇنداق بولسا `true` نى، بولمىسا `false` نى
قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

نامەلۇم سانلىق مەلۇماتنى (مەسىلەن، پارس قىلىنغان JSON ياكى API جاۋابلىرى) دەلىللەپ، ئايلاندۇرۇش (iterate)، ئىندېكسلاش (
indexing) ياكى `.length` غا كىرىشتىن بۇرۇن قىممەتنىڭ تىزىملىك (array) ئىكەنلىكىنى جەزملەشتۈرۈش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> تىزىملىكلەر (array) ئۈچۈن runtime تەكشۈرۈش كېرەك بولغاندا `isArray` نى ئىشلىتىڭ؛ ئۇ boolean قايتۇرىدۇ ۋە `unknown`
> قىممەتلەر بىلەن بىخەتەر چاقىرىلىدۇ.

### ئەۋزەللىكلەر

- ئوخشىمىغان realm لار (مەسىلەن، iframe لار) ئارىسىدا ئىشەنچلىك تىزىملىك (array) بايقاش ئۈچۈن ئىچىگە قۇرۇلغان
  `Array.isArray` نى ئىشلىتىدۇ.
- قوغداش (guard) ۋە شاخلىنىش لوگىكىسىغا ماس كېلىدىغان ئاددىي boolean نەتىجە (`true`/`false`) نى قايتۇرىدۇ.
- پارامېتىر `unknown` بولغانلىقى ئۈچۈن ھەر قانداق كىرگۈزۈش تىپى بىلەن ئىشلەيدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isArray(value)`

پارامېتىرلار:

- `value`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  //‎‎ input ئىجرا ۋاقتىدا بىر سانلار تىزىملىكى
  console.log(input.length);
} else {
  console.log("Not an array");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isArray(value)`
