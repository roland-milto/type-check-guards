# areOctals

## چۈشەندۈرۈش

`areOctals` تەمىنلەنگەن قىممەتنىڭ ئىناۋەتلىك سەككىزلىك تىزىملاردىن تەركىب تاپقان بوش بولمىغان تىزىملىك (array)
ئىكەنلىكىنى بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

`areOctals` نى ئىشلەتكۈچى كىرگۈزۈشى، سەپلىمە قىممەتلىرى ياكى API payload لىرىنى دەلىللەشتە ئىشلىتىڭ؛ بۇلار سەككىزلىك
لىتېراللارنى (مەسىلەن ھۆججەت ئىجازەت ھالىتى `0o755` غا ئوخشاش) ئۆز ئىچىگە ئېلىشى كېرەك بولغاندا، بوش تىزىملىكلەرنى ياكى
ھەر قانداق ئىناۋەتسىز كىرگۈزۈلمىلەرنى `false` قايتۇرۇش ئارقىلىق رەت قىلىشنى خالايسىز.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areOctals` نى ئىشلىتىپ، ئايلاندۇرۇشتىن (مەسىلەن `Number(...)` ئارقىلىق ياكى ئۆزىڭىز يازغان پارسلاش بىلەن) بۇرۇن، ھەر
> بىر كىرگۈزۈلمىسى ئىناۋەتلىك سەككىزلىك تىزىم بولغان بوش بولمىغان `unknown[]` بارلىقىڭىزنى كاپالەتلەندۈرۈڭ.

### ئەۋزەللىكلەر

- قىممەتنىڭ بوش بولمىغان بىر تىزىملىك (array) ئىكەنلىكىنى تەكشۈرىدۇ؛ ھەر بىر ئېلېمېنتى سەككىزلىك (octal) تىزىم (string)
  بولغاندا ۋە بارلىق تۈرلەر ئۆتكەندەلا `true` قايتۇرىدۇ.
- تېز مەغلۇپ بولىدۇ: سەككىزلىك بولمىغان ئېلېمېنت بايقالغان ھامان `false` قايتۇرىدۇ.
- ئىجرا ۋاقتى خاتالىقى ۋە كىرگۈزۈشنى بىردەك بىر تەرەپ قىلماسلىقنىڭ ئالدىنى ئېلىش ئۈچۈن، سەككىزلىك تىزىملارنى پارسلاش
  ياكى ئايلاندۇرۇشتىن بۇرۇن قوغدىغۇچ (guard) سۈپىتىدە پايدىلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areOctals(array)`

پارامېتىرلار:

- `array`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  //‎‎ value سەككىزلىك سان تىزىملىرىدىن تۈزۈلگەن بوش بولمىغان بىر تىزىم
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areOctals(array)`
