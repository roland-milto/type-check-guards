# isObject

## چۈشەندۈرۈش

بېرىلگەن `value` نىڭ `object` ئىكەنلىكىنى ( `null` نى چىقىرىۋېتىپ) بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

خاسلىقلىرىغا كىرىشتىن بۇرۇن نامەلۇم كىرگۈزۈشلەرنى (مەسىلەن، پارس قىلىنغان JSON، API جاۋابلىرى، ھادىسە payload لىرى)
دەلىللەش ئۈچۈن `isObject` نى ئىشلىتىڭ؛ بۇ قىممەتنىڭ ئوبيېكت ئىكەنلىكىنى ۋە `null` ئەمەسلىكىنى كاپالەتلەيدۇ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `isObject` بولسا رانتەيم گارد بولۇپ، boolean قايتۇرىدۇ؛ ئۇ مەلۇم بىر ئوبيېكت شەكلىگە تارايتمەيدۇ. تېخىمۇ كۈچلۈك
> تايپلاشتۇرۇشقا ئېھتىياج بولغاندا، قوشۇمچە تەكشۈرۈشلەر (مەسىلەن، خاسلىقنىڭ مەۋجۇتلۇقى) بىلەن بىرلەشتۈرۈڭ.

### ئەۋزەللىكلەر

- `typeof` ئى `"object"` بولغان، پەقەت `null` بولمىغان قىممەتلەر ئۈچۈنلا `true` قايتۇرىدۇ.
- `null` نىڭ ئادەتتە ئوبيېكت دەپ قارىلىپ كېتىدىغان كۆپ ئۇچرايدىغان JavaScript خاتالىقىنىڭ ئالدىنى ئالىدۇ.
- ئاددىي ئوبيېكتلار ۋە ئىچىگە قۇرۇلغان ئوبيېكت ئىنستانسلىرى (مەسىلەن، `Date`, `RegExp`) ئۈچۈن ئىشلىيدۇ.
- مۇداپىئە خاراكتېرلىك پروگراممىلاش ۋە كىرگۈزۈش دەلىللەش ئۈچۈن ماس كېلىدىغان ئاددىي، تېز رانتەيم تەكشۈرۈش.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isObject(value)`

پارامېتىرلار:

- `value`: `object` ئىكەنلىكى تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isObject } from "@type-check/guards";

const input: unknown = { a: 1 };

if (isObject(input)) {
  //‎‎ input ئىجرا ۋاقتىدا null بولمىغان ئوبيېكت
  console.log("Object detected");
} else {
  console.log("Not an object");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isObject(value)`
