# isFalse

## چۈشەندۈرۈش

`isFalse` بېرىلگەن قىممەتنىڭ بولېن لىتېرالى `false` بىلەن قاتتىق تەڭ ئىكەنلىكىنى تەكشۈرىدۇ.

### ئىشلىتىش ھالىتى

نامەلۇم سانلىق مەلۇماتنى (مەسىلەن، JSON دىن، query params دىن ياكى ئىشلەتكۈچى كىرگۈزۈشىدىن) دەلىللەشتە، پەقەت ئاشكارا
بولېن قىممىتى `false` نىلا ئىناۋەتلىك بايراق دەپ قاراپ، باشقىلىرىنىڭ ھەممىسىنى رەت قىلىش كېرەك بولغاندا ئىشلىتىلىدۇ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> پەقەت لىتېرال `false` نىلا قوبۇل قىلىپ، باشقا بارلىق falsy قىممەتلەرنى رەت قىلىشىڭىز كېرەك بولغاندا `isFalse` نى
> ئىشلىتىڭ؛ ئۇ پەقەت `value === false` بولغاندا `true` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- مەجبۇرىي ئۆزگەرتىش (coercion) قىلماي تۇرۇپ، بولېن لىتېرالى `false` نى قاتتىق تەكشۈرۈشنى تەمىنلەيدۇ.
- `false` نى `0`, `""`, `null`, ۋە `undefined` قاتارلىق باشقا falsy قىممەتلەردىن پەرق قىلىشقا ياردەم بېرىدۇ.
- نامەلۇم كىرگۈزۈشنى دەلىللەشتە نىيەتنى ئاشكارا قىلىپ، ئوقۇشچانلىقنى ياخشىلايدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isFalse(value)`

پارامېتىرلار:

- `value`: تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isFalse } from "@type-check/guards";

const input: unknown = false;

if (isFalse(input)) {
  //‎‎ بۇ يەردە input دەل false
  console.log("Got false");
} else {
  console.log("Not false");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isFalse(value)`
