# areNumbers

## چۈشەندۈرۈش

`areNumbers` بىر قىممەتنىڭ بوش بولمىغان ماسسىپ ئىكەنلىكىنى ۋە ئۇنىڭدىكى بارلىق ئېلېمېنتلارنىڭ سان ئىكەنلىكىنى تەكشۈرىدۇ.

### ئىشلىتىش ھالىتى

ئىشلەتكۈچى تەمىنلىگەن ياكى API تەمىنلىگەن سانلىق مەلۇماتلارنى جەم، ئوتتۇرىچە ياكى باشقا سانلىق توپلاشلارنى ھېسابلاشتىن
بۇرۇن، ئۇنىڭ بوش بولمىغان سان ماسسىپى ئىكەنلىكىنى دەلىللەش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> سانلىق ھېسابلاشلارنى ئىجرا قىلىشتىن بۇرۇن نامەلۇم ماسسىپلارنى دەلىللەش ئۈچۈن `areNumbers` نى ئىشلىتىڭ؛ ئۇ بوش
> ماسسىپلارغا ۋە ئىچىدە ھەر قانداق سان بولمىغان قىممەت بار ماسسىپلارغا `false` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- كىرگۈزۈلگەن قىممەت بوش بولمىغان ماسسىپ بولۇپ، ھەر بىر ئېلېمېنتى سان بولغاندا ئاندىن `true` قايتۇرىدۇ.
- بوش ماسسىپلار ۋە ماسسىپ بولمىغان كىرگۈزۈشلەرنى رەت قىلىش ئارقىلىق خاتا مۇۋاپىق دەپ قاراشنىڭ ئالدىنى ئالىدۇ.
- ئىجرا ۋاقتى خاتالىقلىرىدىن ساقلىنىش ئۈچۈن سانلىق مەشغۇلاتلاردىن (مەسىلەن، يىغىش، ئوتتۇرىچە ئېلىش) بۇرۇن قوغدىغۇچ
  سۈپىتىدە پايدىلىنىشقا قولايلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areNumbers(array)`

پارامېتىرلار:

- `array`: سان ئېلېمېنتلىرى بار-يوقلۇقى تەكشۈرۈلىدىغان ماسسىپ.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areNumbers(array)`
