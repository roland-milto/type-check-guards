# isFilledArray

## چۈشەندۈرۈش

`value` نىڭ ئەڭ ئاز دېگەندە بىر ئېلېمېنتى بار سانلار گۇرۇپپىسى ئىكەنلىكىنى تەكشۈرۈپ، `true` ياكى `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

ئايلاندۇرۇش، بىرىنچى ئېلېمېنتقا كىرىش ياكى ئەڭ ئاز دېگەندە بىر تۈر بولۇشنى تەلەپ قىلىدىغان لوگىكىنى قوللىنىشتىن بۇرۇن،
كىرىپ كەلگەن سانلىق مەلۇماتلارنى (مەسىلەن، API payloadلىرى، فورما قىممەتلىرى، سەپلىمە) دەلىللەش ئۈچۈن `isFilledArray` نى
ئىشلىتىڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `isFilledArray` ئىجرا ۋاقتىدىكى قوغدىغۇچ بولۇپ، بولىيان قىممەت قايتۇرىدۇ؛ سانلار گۇرۇپپىسىنىڭ بوش ئەمەسلىكىنى
> دەلىللەشتىن باشقا، ئېلېمېنت تىپلىرىنى تېخىمۇ تارايتمەيدۇ.

### ئەۋزەللىكلەر

- `Array.isArray` ۋە ئۇزۇنلۇق تەكشۈرۈشى ئارقىلىق بوش بولمىغان سانلار گۇرۇپپىسىنى ئاددىي ۋە تېز تەكشۈرۈش.
- كود بىر سانلار گۇرۇپپىسىدا ئەڭ ئاز دېگەندە بىر ئېلېمېنت بار دەپ پەرەز قىلغاندا، ئىجرا ۋاقتىدىكى خاتالىقلاردىن
  ساقلىنىشقا ياردەم بېرىدۇ.
- ئېنىق بولىيان نەتىجە: بوش بولمىغان سانلار گۇرۇپپىسى ئۈچۈن `true` قايتۇرىدۇ، بولمىسا `false`.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isFilledArray(value)`

پارامېتىرلار:

- `value`: ئۇنىڭ بوش بولمىغان سانلار گۇرۇپپىسى ئىكەنلىكىنى تەكشۈرىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isFilledArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && isFilledArray(input)) {
  //‎‎ input ئىجرا ۋاقتىدا بوش بولمىغان سانلار تىزىمى
  console.log(input[0]);
} else {
  console.log("Not a non-empty array");
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isFilledArray(value)`
