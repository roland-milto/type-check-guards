# isSet

## چۈشەندۈرۈش

بېرىلگەن قىممەتنىڭ `Set` ئىكەنلىكىنى بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

سىرتقى مەنبەلەردىن كەلگەن كىرگۈزۈشلەرنى (مەسىلەن، JSON پارسلاش، ئىشلەتكۈچى كىرگۈزۈشى ياكى ئۈچىنچى تەرەپ API لىرى)
دەلىللەپ، `Set` مەشغۇلاتلىرىنى ئىجرا قىلىشتىن بۇرۇن قىممەتنىڭ `Set` ئىكەنلىكىگە كاپالەتلىك قىلىڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `unknown` قىممەتلەرنى تارايتىش ئۈچۈن `isSet` نى ئىشلىتىپ، ئاندىن `.add`, `.has` ياكى `.size` غا ئوخشاش `Set`-غا خاس
> API لارنى چاقىرىڭ.

### ئەۋزەللىكلەر

- قىممەتنىڭ `Set` ئىكەنلىكىنى دەلىللەش ئۈچۈن ئاددىي runtime تەكشۈرۈش بىلەن تەمىنلەيدۇ.
- قىممەت `Set` بولمىغاندا بالدۇر شاخلىنىشقا يول قويۇپ، تىپ خاتالىقلىرىنىڭ ئالدىنى ئېلىشقا ياردەم بېرىدۇ.
- ھەر قانداق `Set` مەزمۇنى (بوش ياكى تولدۇرۇلغان) بىلەن ئىشلەيدۇ ۋە ئىزچىل ھالدا `true`/`false` قايتۇرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isSet(value)`

پارامېتىرلار:

- `value`: تەكشۈرىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  //‎‎ a ئىجرا ۋاقتىدا Set
  console.log(a.size);
}

console.log(isSet(b)); //‎ false
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isSet(value)`
