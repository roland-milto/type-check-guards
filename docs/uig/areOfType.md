# areOfType

## چۈشەندۈرۈش

بېرىلگەن `array` ئىچىدىكى بارلىق ئېلېمېنتلارنىڭ بەلگىلەنگەن `type` تىپىدا ئىكەنلىكىنى تەكشۈرىدۇ.

### ئىشلىتىش ھالىتى

سانلار گۇرۇپپىسىدىكى ھەر بىر ئېلېمېنتقا تىپقا خاس مەشغۇلاتلارنى قىلىشتىن بۇرۇن، نامەلۇم كىرگۈزۈلمىنى (مەسىلەن، پارس
قىلىنغان JSON، API payloadلىرى، ئىشلەتكۈچى كىرگۈزۈشى) دەلىللەش ئۈچۈن `areOfType` نى ئىشلىتىڭ.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `areOfType` تىپ قوغدىغۇچى بولغاچقا، TypeScript `if (areOfType(...)) {}` بلوكى ئىچىدە سانلار گۇرۇپپىسىنى
`Array<DataTypeOf<T>>` غا تارايتىدۇ.

### ئەۋزەللىكلەر

- TypeScript تىپ قوغدىغۇچىسىنى تەمىنلەيدۇ: ئۇ `true` قايتۇرغاندا، كىرگۈزۈلمە `Array<DataTypeOf<T>>` غا تارايتىلىدۇ.
- ھەر بىر ئېلېمېنتنى تەلەپ قىلىنغان runtime تىپىغا سېلىشتۇرۇپ دەلىللەيدۇ، ئارىلاش تىپلىق سانلار گۇرۇپپىسىنىڭ ئۆتۈپ
  كېتىشىنىڭ ئالدىنى ئالىدۇ.
- تېز مەغلۇپ بولىدۇ: ماس كەلمەيدىغان ئېلېمېنت بايقالغان ھامان `false` قايتۇرىدۇ.
- لايىھە بويىچە سانلار گۇرۇپپىسى بولمىغانلارنى ۋە بوش سانلار گۇرۇپپىسىنى رەت قىلىدۇ (`isFilledArray` غا باغلىق).

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areOfType(array, type)`

پارامېتىرلار:

- `array`: تەكشۈرۈلىدىغان سانلار گۇرۇپپىسى.
- `type`: سانلار گۇرۇپپىسىدىكى ھەر بىر ئېلېمېنتقا سېلىشتۇرۇپ تەكشۈرىدىغان تىپ.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areOfType } from "@type-check/guards";

const values: unknown[] = [1, 2, 3];

if (areOfType(values, "number")) {
  //‎‎ values ھازىر number[]
  const sum = values.reduce((a, b) => a + b, 0);
  console.log(sum);
}

const mixed: unknown[] = [1, "2", 3];
const allNumbers = areOfType(mixed, "number"); //‎ false

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areOfType(array, type)`
