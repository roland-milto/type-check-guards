# areMaps

## چۈشەندۈرۈش

`areMaps` بېرىلگەن سانلار تىزىملىكىنىڭ بوش ئەمەسلىكىنى ۋە ئۇنىڭدىكى بارلىق ئېلېمېنتلارنىڭ `Map` ئىنستانسلىرى ئىكەنلىكىنى
بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

نامەلۇم كىرگۈزۈشنى (مەسىلەن، JSON پارسلاشتىن، سىرتقى API لاردىن ياكى دىنامىك مەنبەلەردىن) `Map` ئوبيېكتلىرىنىڭ بوش ئەمەس
تىزىملىكى دەپ قاراشتىن بۇرۇن دەلىللەش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> بوش سانلار تىزىملىكى ئۈچۈن `false` قايتۇرىدۇ؛ پەقەت سانلار تىزىملىكى تولۇق بولۇپ، ھەر بىر ئېلېمېنت `Map` بولغاندا
`true` قايتۇرىدۇ.

### ئەۋزەللىكلەر

- ھەر بىر ئېلېمېنتنىڭ `Map` ئىنستانسى ئىكەنلىكىنى كاپالەتلەندۈرىدۇ؛ پۈتۈن سانلار تىزىملىكى تەكشۈرۈشتىن ئۆتكەندەلا `true`
  قايتۇرىدۇ.
- لايىھە بويىچە بوش سانلار تىزىملىكىنى رەت قىلىدۇ، «سانلىق مەلۇمات يوق» نى توغرا كىرگۈزۈش دەپ خاتا قوبۇل قىلىشنىڭ
  ئالدىنى ئالىدۇ.
- توپلام بويىچە `Map` غا خاس مەشغۇلاتلارنى (مەسىلەن، `.get()`, `.set()`, ئايلىنىپ چىقىش) ئىجرا قىلىشتىن بۇرۇن قوغدىغۇچ
  سۈپىتىدە پايدىلىق.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areMaps(array)`

پارامېتىرلار:

- `array`: تەكشۈرۈلىدىغان سانلار تىزىملىكى.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  //‎‎ items ئىجرا ۋاقتىدا Map ئۈلگىلىرىدىن تەركىب تاپقان بوش بولمىغان تىزىم ئىكەنلىكى كاپالەتلەندۈرۈلىدۇ
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  //‎‎ تۆۋەندىكىلەر ئۈچۈن false: بوش تىزىملار، ياكى ئىچىدە Map بولمىغان ھەر قانداق قىممەت بار تىزىملار
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areMaps(array)`
