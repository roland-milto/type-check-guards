# isFloat

## چۈشەندۈرۈش

`isFloat` بېرىلگەن `value` نىڭ چەكلىك لەيلىمە نۇقتىلىق سان (پۈتۈن سان بولمىغان `number`) ئىكەنلىكىنى بەلگىلەيدۇ.

### ئىشلىتىش ھالىتى

پارچە قىممەتلەر تەلەپ قىلىنىدىغان (مەسىلەن، باھا، ئۆلچەم، نىسبەت) ئىشلەتكۈچى تەمىنلىگەن سانلىق كىرگۈزۈشنى دەلىللەش ۋە
پۈتۈن سانلارنى، `NaN` نى ۋە چەكسىزلىكلەرنى رەت قىلىش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> پەقەت چەكلىك، پۈتۈن سان بولمىغان سانلىق كىرگۈزۈشلەرنى قوبۇل قىلىشىڭىز كېرەك بولغاندا `isFloat` نى ئىشلىتىڭ؛ ئۇ پۈتۈن
> سانلار ۋە چەكلىك بولمىغان سانلارنى رەت قىلىدۇ.

### ئەۋزەللىكلەر

- `true` نى پەقەت چەكلىك، پۈتۈن سان بولمىغان سانلار ئۈچۈنلا قايتۇرىدۇ (پۈتۈن سانلار، `NaN`، `Infinity` ۋە `-Infinity` نى
  ئۆز ئىچىگە ئالمايدۇ).
- ھەر قانداق كىرگۈزۈش تىپى (`unknown`) بىلەن ئىشلەيدۇ ۋە `typeof value === "number"` نى تەكشۈرۈش ئارقىلىق بىخەتەر
  تارايتىدۇ.
- ئالدىنقى قۇرۇلغان سانلىق قوغدىغۇچىلار (`Number.isInteger`, `Number.isFinite`) نى ئىشلىتىپ، ئالدىن پەرەز قىلىشقا
  بولىدىغان ھەرىكەتنى تەمىنلەيدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isFloat(value)`

پارامېتىرلار:

- `value`: ئۇنىڭ لەيلىمە نۇقتىلىق سان ئىكەنلىكى تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isFloat } from "@type-check/guards";

const inputs: unknown[] = [3.14, -0.1, 1e-7, 42, "3.14", NaN, Infinity];

for (const value of inputs) {
  if (isFloat(value)) {
    //‎‎ value ئىجرا ۋاقتىدا سان؛ ئۇ چەكلىك بولۇپ پۈتۈن سان ئەمەس
    const rounded = value.toFixed(2);
    console.log("float:", value, "rounded:", rounded);
  } else {
    console.log("not a float:", value);
  }
}
```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isFloat(value)`
