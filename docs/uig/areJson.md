# areJson

## چۈشەندۈرۈش

سانلار قاتارىدىكى بارلىق ئېلېمېنتلارنىڭ JSON تېكىستلىرى ئىكەنلىكىنى تەكشۈرىدۇ؛ سانلار قاتارى تولدۇرۇلغان ۋە ھەر بىر تۈر
ئىناۋەتلىك JSON بولغاندىلا `true` قايتۇرىدۇ، بولمىسا `false` قايتۇرىدۇ.

### ئىشلىتىش ھالىتى

كىرىدىغان سانلىق مەلۇماتنى (مەسىلەن query params، environment variables ياكى سىرتقى API لاردىن) دەلىللەش؛ سىز
JSON-كودلانغان تېكىستلەرنىڭ سانلار قاتارىنى كۈتىسىز ۋە بوش سانلار قاتارىنى ياكى JSON بولمىغان ھەر قانداق كىرگۈزۈشنى رەت
قىلماقچى بولىسىز.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> `unknown[]` نىڭ پەقەت JSON تېكىستلىرىنىلا ئۆز ئىچىگە ئالغانلىقىنى پارسلاشتىن بۇرۇن (مەسىلەن `JSON.parse` بىلەن)
> دەلىللەش كېرەك بولغاندا `areJson` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- پەقەت ھەر بىر ئېلېمېنت ئىناۋەتلىك JSON تېكىستى بولغاندا `true` قايتۇرىدۇ؛ بولمىسا `false` قايتۇرىدۇ.
- تېز مەغلۇپ بولىدۇ: JSON بولمىغان ئېلېمېنت بايقالغان ھامان تەكشۈرۈشنى توختىتىدۇ.
- لايىھە بويىچە بوش سانلار قاتارىنى رەت قىلىدۇ، تولدۇرۇلمىغان كىرگۈزۈش ئۈچۈن `false` قايتۇرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `areJson(array)`

پارامېتىرلار:

- `array`: JSON تېكىست ئېلېمېنتلىرى بار-يوقلۇقى تەكشۈرۈلىدىغان سانلار قاتارى.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); //‎ راست
const mixed = areJson(["{\"a\":1}", 123 as unknown]); //‎ يالغان
const empty = areJson([]); //‎ يالغان

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.areJson(array)`
