# isDecimal

## چۈشەندۈرۈش

`isDecimal` بىر قىممەتنىڭ ئالدى/كەينىدە بوشلۇق بولمىغان ۋە ئۈنۈملۈك ئونلۇق فورماتقا ئىگە بولغان ئونلۇق تىزىم
ئىپادىلىنىشى ئىكەنلىكىنى تەكشۈرىدۇ.

### ئىشلىتىش ھالىتى

پارسلاش ياكى ساقلاشتىن بۇرۇن، ھېچقانداق ئەتراپ بوشلۇقى بولمىغان ھالدا ئونلۇق تىزىم (ئىختىيارىي ئىمزا بىلەن) سۈپىتىدە
تەمىنلىنىشى كېرەك بولغان فورما مەيدانلىرى، API payloadلىرى ياكى سەپلىمە قىممەتلىرىنى دەلىللەش.

> **TypeScript ئىشلەتكۈچىلەرگە ئەسكەرتىش:**
>
> بوشلۇقنى رەت قىلىش زۆرۈر بولغاندا، ئۇنى ئايلاندۇرۇشتىن بۇرۇن (مەسىلەن `Number(value)` بىلەن) ئىشلەتكۈچى كىرگۈزۈشىنى
> دەلىللەش ئۈچۈن `isDecimal` نى ئىشلىتىڭ.

### ئەۋزەللىكلەر

- كىرگۈزۈلگەن قىممەتنىڭ قاتتىق ھالدا تىزىم (string) ئىكەنلىكىنى ۋە ئونلۇق-لىتېرال (decimal-literal) ئەندىزىسىگە ماس
  كېلىدىغانلىقىنى دەلىللەيدۇ.
- ئامبىگۇس پارسلاشتىن ساقلىنىش ئۈچۈن ئالدى-كەينىدىكى بوشلۇق (كونترول ھەرپلەرنىمۇ ئۆز ئىچىگە ئالىدۇ) نى رەت قىلىدۇ.
- regex نى ئىجرا قىلىشتىن بۇرۇن تېز ئالدىن تەكشۈرۈشلەرنى (تىپ تەكشۈرۈش ۋە بىرىنچى/ئاخىرقى ھەرپ) قىلىدۇ.
- قوغدىغۇچىلار ۋە كىرگۈزۈش دەلىللەش ئۈچۈن ماس كېلىدىغان ئاددىي boolean نەتىجە (`true`/`false`) نى قايتۇرىدۇ.

## ئىشلىتىش

### سىنتاكس

فۇنكسىيە:

- `isDecimal(value)`

پارامېتىرلار:

- `value`: ئونلۇق تىزىم (decimal string) فورماتى ئۈچۈن تەكشۈرۈلىدىغان قىممەت.

### فۇنكسىيەنى يەرلىك ئىمپورت قىلىش

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    //‎‎ v بۇ يەردە بىر تىزىملىك (ئىجرا ۋاقتىدا دەلىللەنگەن)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### گلوبال ئوبيېكت ئىمپورت قىلىش

فۇنكسىيەلەرنى گلوبال ئوبيېكت مېتودلىرى سۈپىتىدە ئىمپورت قىلىش ئۈچۈن مۇنداق ئىشلىتىڭ:

```ts
import "@type-check/guards/register-global-object.mjs";
```

شۇنداقتا تۆۋەندىكى مېتود گلوبال ئىشلىتىشكە بولىدۇ:

- `Type.isDecimal(value)`
