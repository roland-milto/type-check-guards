# isDate

## विवरण

`isDate` यह निर्धारित करता है कि दिया गया मान `Date` है या नहीं; `Date` इंस्टेंस के लिए `true` और अन्यथा `false` लौटाता
है।

### उपयोग का मामला

`Date` ऑपरेशन्स जैसे फ़ॉर्मैटिंग, तुलना, या `toISOString()` कॉल करने से पहले अज्ञात मानों (जैसे, रिक्वेस्ट डेटा,
कॉन्फ़िग वैल्यूज़, या पार्स किया हुआ JSON) को वैलिडेट और नैरो करें।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> रनटाइम पर `unknown` को `Date` तक नैरो करने के लिए `isDate` का उपयोग करें; यह केवल वास्तविक `Date` इंस्टेंस के लिए
`true` लौटाता है (डेट स्ट्रिंग्स के लिए नहीं)।

### फायदे

- यह सत्यापित करने के लिए एक सरल रनटाइम गार्ड प्रदान करता है कि कोई मान `Date` है या नहीं।
- यह सुनिश्चित करके टाइप त्रुटियों को रोकने में मदद करता है कि केवल `Date` इंस्टेंस ही वैलिडेशन पास करें।
- तिथि-विशिष्ट मेथड्स का उपयोग करने से पहले अज्ञात इनपुट (जैसे, API पेलोड) को वैलिडेट करने के लिए उपयोगी।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `isDate(value)`

पैरामीटर:

- `value`: `Date` टाइप के लिए जाँचा जाने वाला मान।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { isDate } from "@type-check/guards";

const input: unknown = new Date();

if (isDate(input)) {
  // input यहाँ एक Date है
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a Date");
}

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.isDate(value)`
