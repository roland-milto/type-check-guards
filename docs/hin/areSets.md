# areSets

## विवरण

जाँचता है कि दिया गया गैर-खाली ऐरे केवल `Set` इंस्टेंस ही रखता है या नहीं; यदि रखता है तो `true` और अन्यथा `false`
लौटाता है।

### उपयोग का मामला

प्रत्येक सेट को प्रोसेस करने से पहले यह वैलिडेट करें कि कोई मान (जैसे, उपयोगकर्ता इनपुट, JSON पार्सिंग, या बाहरी APIs
से) `Set` ऑब्जेक्ट्स का एक गैर-खाली ऐरे है।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> प्रत्येक तत्व पर `Set` APIs (जैसे, `.size`, `.has`, `.add`) को इटरेट करके कॉल करने से पहले अज्ञात इनपुट को वैलिडेट
> करने के लिए `areSets` का उपयोग करें।

### फायदे

- `true` केवल तब लौटाता है जब इनपुट एक गैर-खाली ऐरे हो और हर तत्व `Set` का एक इंस्टेंस हो।
- खाली ऐरे के लिए `false` लौटाकर गलत-सकारात्मक परिणामों को रोकता है, जब ऐरे में कोई तत्व नहीं होता।
- प्रत्येक तत्व पर `Set`-विशिष्ट ऑपरेशन्स करने से पहले रनटाइम गार्ड के रूप में उपयोगी।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `areSets(array)`

पैरामीटर:

- `array`: `Set` इंस्टेंस के लिए जाँचा जाने वाला ऐरे।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  // a रनटाइम पर Set इंस्टेंसों की एक ऐरे है
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); // false
console.log(areSets(c)); // false
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.areSets(array)`
