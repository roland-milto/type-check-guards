# areBinaries

## विवरण

जाँचता है कि प्रदान किया गया मान मान्य बाइनरी स्ट्रिंग्स का एक गैर-खाली ऐरे है या नहीं, और केवल तभी `true` लौटाता है जब
सभी आइटम वैलिडेशन पास करें।

### उपयोग का मामला

जब आपको कोई अज्ञात सूची (जैसे JSON, फॉर्म्स, या APIs से) मिलती है और उसे पार्स या प्रोसेस करने से पहले यह सुनिश्चित करना
होता है कि वह बाइनरी स्ट्रिंग्स का एक गैर-खाली ऐरे है, तब `areBinaries` का उपयोग करें।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> अज्ञात इनपुट को संख्याओं/BigInts में बाइनरी स्ट्रिंग्स में बदलने से पहले वैलिडेट करने के लिए `areBinaries` का उपयोग
> करें; यह सुनिश्चित करता है कि ऐरे गैर-खाली है और हर तत्व एक मान्य बाइनरी स्ट्रिंग है।

### फायदे

- यह सत्यापित करता है कि कोई मान एक गैर-खाली ऐरे है जिसमें हर तत्व एक मान्य बाइनरी स्ट्रिंग है।
- एक सरल बूलियन परिणाम (`true`/`false`) लौटाता है जो गार्ड्स, शुरुआती रिटर्न, और इनपुट वैलिडेशन के लिए उपयुक्त है।
- किसी भी गैर-बाइनरी प्रविष्टि वाले ऐरे को अस्वीकार करके आगे होने वाली पार्सिंग त्रुटियों को रोकता है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `areBinaries(array)`

पैरामीटर:

- `array`: जाँचा जाने वाला मान।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // सही
console.log(areBinaries(b)); // गलत
console.log(areBinaries([])); // गलत
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.areBinaries(array)`
