# isTrue

## विवरण

`isTrue` यह निर्धारित करता है कि दिया गया मान `true` के सख्त रूप से बराबर है या नहीं।

### उपयोग का मामला

`isTrue` का उपयोग फ्लैग्स, फीचर टॉगल्स, या कॉन्फ़िगरेशन मानों को वैलिडेट करने के लिए करें, जहाँ केवल लिटरल `true` ही
स्वीकार किया जाना चाहिए और बाकी सबको `false` माना जाना चाहिए।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> जब आपको केवल बूलियन लिटरल `true` स्वीकार करना हो, केवल truthy मान नहीं, तब `isTrue` का उपयोग करें।

### फायदे

- बूलियन लिटरल `true` के लिए सख्त जाँच प्रदान करता है (कोई coercion नहीं)।
- `true` को `1`, `"true"`, या `{}` जैसे truthy मानों से अलग पहचानने में मदद करता है।
- गार्ड्स और वैलिडेशन पाइपलाइनों के लिए उपयुक्त सरल, पूर्वानुमेय व्यवहार।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `isTrue(value)`

पैरामीटर:

- `value`: जाँचने के लिए मान।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // सत्य
const b = isTrue(1);         // असत्य
const c = isTrue("true");   // असत्य

if (isTrue(a)) {
  // यहाँ a सत्य है
}
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.isTrue(value)`
