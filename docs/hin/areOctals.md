# areOctals

## विवरण

`areOctals` यह निर्धारित करता है कि दिया गया मान वैध ऑक्टल स्ट्रिंग्स का एक गैर-खाली ऐरे है या नहीं।

### उपयोग का मामला

जब आप उपयोगकर्ता इनपुट, कॉन्फ़िगरेशन मान, या API पेलोड्स को वैलिडेट कर रहे हों जिनमें ऑक्टल लिटरल्स (जैसे फ़ाइल परमिशन
मोड `0o755`) होना आवश्यक है, और आप खाली ऐरे या किसी भी अमान्य एंट्री को `false` लौटाकर अस्वीकार करना चाहते हों, तब
`areOctals` का उपयोग करें।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> कन्वर्ट करने से पहले (जैसे `Number(...)` या कस्टम पार्सिंग के जरिए) यह सुनिश्चित करने के लिए `areOctals` का उपयोग करें
> कि आपके पास एक गैर-खाली `unknown[]` है जिसमें हर एंट्री एक वैध ऑक्टल स्ट्रिंग है।

### फायदे

- यह सत्यापित करता है कि कोई मान एक गैर-खाली ऐरे है जिसमें हर तत्व एक ऑक्टल स्ट्रिंग है, और केवल तब `true` लौटाता है जब
  सभी आइटम पास हों।
- तेज़ी से विफल होता है: जैसे ही कोई गैर-ऑक्टल तत्व मिलता है, तुरंत `false` लौटाता है।
- ऑक्टल स्ट्रिंग्स को पार्स या कन्वर्ट करने से पहले गार्ड के रूप में उपयोगी, ताकि रनटाइम त्रुटियों और असंगत इनपुट
  हैंडलिंग से बचा जा सके।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `areOctals(array)`

पैरामीटर:

- `array`: जाँचा जाने वाला मान।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value ऑक्टल स्ट्रिंगों की एक गैर-खाली ऐरे है
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.areOctals(array)`
