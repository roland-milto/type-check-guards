# isNaN

## विवरण

स्ट्रिंग्स को बदले बिना यह निर्धारित करता है कि दिया गया `value` `number` प्रकार का `NaN` है या नहीं।

### उपयोग का मामला

अविश्वसनीय या ढीले-ढाले टाइप किए गए इनपुट (जैसे API payloads, form values, parsed JSON) को सत्यापित करें ताकि विशेष
`NaN` मान का पता लगाकर उसे स्पष्ट रूप से संभाला जा सके, जबकि गैर-संख्या इनपुट को `NaN` न माना जाए।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> `isNaN` का उपयोग तब करें जब आपको विशेष संख्यात्मक मान `NaN` का पता लगाना हो और साथ ही यह सुनिश्चित करना हो कि इनपुट
> वास्तव में `number` है (कोई string-to-number conversion नहीं)।

### फायदे

- गैर-संख्यात्मक मानों (जैसे स्ट्रिंग्स) को संख्या में बदले बिना यह जांचता है कि कोई मान `NaN` है या नहीं।
- केवल उन्हीं मानों के लिए `true` लौटाता है जो `number` प्रकार के भी हों और `NaN` भी हों।
- `unknown` इनपुट के लिए सुरक्षित है और अप्रत्यक्ष रूपांतरणों से होने वाले गलत सकारात्मक परिणामों से बचाता है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `isNaN(value)`

पैरामीटर:

- `value`: वह मान जिसे यह जांचने के लिए परखा जाना है कि क्या वह `number` प्रकार का `NaN` है।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // सही
console.log(isNaN(b)); // गलत
console.log(isNaN(c)); // गलत

if (isNaN(a)) {
  // a एक संख्या है और विशेष रूप से NaN है
}
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.isNaN(value)`
