# isHexadecimal

## विवरण

`isHexadecimal` जाँचता है कि दिया गया मान अनिवार्य `0x`/`0X` प्रीफ़िक्स के साथ एक हेक्साडेसिमल स्ट्रिंग लिटरल है या
नहीं।

### उपयोग का मामला

`isHexadecimal` का उपयोग कॉन्फ़िगरेशन मानों, API पेलोड फ़ील्ड्स, या CLI आर्ग्युमेंट्स को सत्यापित करने के लिए करें
जिन्हें हेक्साडेसिमल स्ट्रिंग लिटरल्स (जैसे IDs, masks, या addresses) के रूप में प्रदान करना अनिवार्य हो और जिनमें आसपास
का व्हाइटस्पेस नहीं होना चाहिए।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> `isHexadecimal` का उपयोग तब करें जब आपको पार्स या कन्वर्ट करने से पहले उपयोगकर्ता इनपुट या सीरियलाइज़्ड डेटा को एक
> सख्त हेक्साडेसिमल लिटरल स्ट्रिंग (जिसमें `0x`/`0X` प्रीफ़िक्स शामिल हो) के रूप में सत्यापित करना हो।

### फायदे

- यह सत्यापित करता है कि कोई मान एक स्ट्रिंग है और एक सख्त हेक्साडेसिमल लिटरल फ़ॉर्मैट से मेल खाता है (इसके लिए `0x`/
  `0X` प्रीफ़िक्स आवश्यक है)।
- आगे या पीछे के व्हाइटस्पेस वाली स्ट्रिंग्स को अस्वीकार करता है, जिससे पैड किए गए इनपुट को गलती से स्वीकार करने से बचाव
  होता है।
- वैकल्पिक साइन का समर्थन करता है और प्रीफ़िक्स व अंकों के लिए केस-इन्सेंसिटिव है, तथा पूर्वानुमेय रूप से `true`/`false`
  लौटाता है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `isHexadecimal(value)`

पैरामीटर:

- `value`: जाँचा जाने वाला मान।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // सही
isHexadecimal("-0Xff"); // सही
isHexadecimal("1A2B"); // गलत (प्रिफिक्स गायब)
isHexadecimal(" 0x1A2B"); // गलत (शुरुआती व्हाइटस्पेस)
isHexadecimal(0x1a2b); // गलत (स्ट्रिंग नहीं)

```
