# isBinary

## विवरण

`isBinary` यह निर्धारित करता है कि कोई मान बाइनरी स्ट्रिंग है या नहीं (वैकल्पिक रूप से `0b`/`0B` प्रीफ़िक्स के साथ) और
`true` या `false` लौटाता है।

### उपयोग का मामला

उपयोगकर्ता द्वारा प्रदान की गई स्ट्रिंग्स (जैसे, फ़ॉर्म फ़ील्ड्स, CLI args, कॉन्फ़िग मान) को वैलिडेट करें ताकि आगे की
प्रोसेसिंग से पहले यह सुनिश्चित हो सके कि वे केवल बाइनरी अंकों का प्रतिनिधित्व करती हैं, वैकल्पिक रूप से `0b`/`0B`
प्रीफ़िक्स के साथ।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> अमान्य इनपुट से बचने के लिए किसी स्ट्रिंग को `BigInt`/`Number` में पार्स या कन्वर्ट करने से पहले `isBinary` को टाइप
> गार्ड के रूप में उपयोग करें।

### फायदे

- `0b`/`0B` प्रीफ़िक्स के साथ या बिना बाइनरी स्ट्रिंग्स स्वीकार करता है।
- खाली स्ट्रिंग्स और आगे/पीछे व्हाइटस्पेस (ASCII ≤ 32) वाली स्ट्रिंग्स को अस्वीकार करता है।
- बिना थ्रो किए `true`/`false` लौटाता है, जिससे यह अज्ञात इनपुट्स के लिए सुरक्षित रहता है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `isBinary(value)`

पैरामीटर:

- `value`: जाँचा जाने वाला मान।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // सही
const b = isBinary("1010");   // सही
const c = isBinary("0b1020"); // गलत
const d = isBinary(0b1010);     // गलत

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.isBinary(value)`
