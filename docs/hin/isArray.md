# isArray

## विवरण

`isArray` जाँचता है कि दिया गया मान एक ऐरे है या नहीं और यदि है तो `true` लौटाता है, अन्यथा `false`।

### उपयोग का मामला

अज्ञात डेटा (जैसे पार्स किया हुआ JSON या API प्रतिक्रियाएँ) को वैलिडेट करें ताकि इटरेट करने, इंडेक्स करने, या `.length`
एक्सेस करने से पहले यह सुनिश्चित हो सके कि मान एक ऐरे है।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> जब आपको ऐरे के लिए रनटाइम जाँच की आवश्यकता हो तब `isArray` का उपयोग करें; यह एक बूलियन लौटाता है और `unknown` मानों के
> साथ कॉल करना सुरक्षित है।

### फायदे

- विभिन्न रियल्म्स (जैसे iframes) में भरोसेमंद ऐरे पहचान के लिए बिल्ट-इन `Array.isArray` का उपयोग करता है।
- गार्ड्स और ब्रांचिंग लॉजिक के लिए उपयुक्त एक सरल बूलियन परिणाम (`true`/`false`) लौटाता है।
- किसी भी इनपुट प्रकार के साथ काम करता है क्योंकि पैरामीटर `unknown` है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `isArray(value)`

पैरामीटर:

- `value`: जाँचा जाने वाला मान।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  // input रनटाइम पर एक ऐरे है
  console.log(input.length);
} else {
  console.log("Not an array");
}

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.isArray(value)`
