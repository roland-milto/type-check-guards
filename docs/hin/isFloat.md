# isFloat

## विवरण

`isFloat` निर्धारित करता है कि दिया गया `value` एक सीमित फ्लोटिंग-पॉइंट संख्या है या नहीं (एक `number` जो पूर्णांक नहीं
है)।

### उपयोग का मामला

उपयोगकर्ता द्वारा प्रदान किए गए संख्यात्मक इनपुट को मान्य करें जहाँ भिन्नात्मक मान आवश्यक हों (जैसे, कीमतें, माप, दरें)
और पूर्णांकों, `NaN`, तथा अनंत मानों को अस्वीकार करें।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> जब आपको केवल सीमित, गैर-पूर्णांक संख्यात्मक इनपुट स्वीकार करने हों, तब `isFloat` का उपयोग करें; यह पूर्णांकों और
> गैर-सीमित संख्याओं को अस्वीकार करता है।

### फायदे

- `true` केवल सीमित, गैर-पूर्णांक संख्याओं के लिए लौटाता है (पूर्णांक, `NaN`, `Infinity`, और `-Infinity` को बाहर करता
  है)।
- किसी भी इनपुट प्रकार (`unknown`) के साथ काम करता है और `typeof value === "number"` की जाँच करके सुरक्षित रूप से टाइप
  को संकीर्ण करता है।
- पूर्वानुमेय व्यवहार के लिए अंतर्निर्मित संख्यात्मक गार्ड्स (`Number.isInteger`, `Number.isFinite`) का उपयोग करता है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `isFloat(value)`

पैरामीटर:

- `value`: यह जाँचने के लिए मान कि क्या यह एक फ्लोटिंग-पॉइंट संख्या है।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { isFloat } from "@type-check/guards";

const inputs: unknown[] = [3.14, -0.1, 1e-7, 42, "3.14", NaN, Infinity];

for (const value of inputs) {
  if (isFloat(value)) {
    // मान रनटाइम पर एक संख्या है; यह सीमित है और पूर्णांक नहीं है
    const rounded = value.toFixed(2);
    console.log("float:", value, "rounded:", rounded);
  } else {
    console.log("not a float:", value);
  }
}
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.isFloat(value)`
