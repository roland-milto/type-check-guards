# isIndexFound

## विवरण

`isIndexFound` यह निर्धारित करता है कि दिया गया मान गैर-ऋणात्मक पूर्णांक है या नहीं, जो यह संकेत देता है कि एक इंडेक्स
मिला है।

### उपयोग का मामला

किसी array या string में इंडेक्सिंग करने से पहले यह सत्यापित करें कि खोज परिणाम एक उपयोगी इंडेक्स (पूर्णांक `>= 0`) का
प्रतिनिधित्व करता है, ताकि गलती से `-1` या गैर-संख्या मानों का उपयोग न हो।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> `indexOf`, `findIndex`, या कस्टम खोज जैसी ऑपरेशनों के बाद `isIndexFound` का उपयोग करें, जहाँ `-1` (या अन्य अमान्य मान)
> “नहीं मिला” को दर्शा सकते हैं। जब यह `true` लौटाता है, तो मान एक संख्या होता है और array/string इंडेक्स के रूप में
> उपयोग
> करने के लिए सुरक्षित होता है।

### फायदे

- गैर-ऋणात्मक पूर्णांक की जाँच करके यह पता लगाने के लिए एक सरल टाइप गार्ड प्रदान करता है कि कोई इंडेक्स मिला है या नहीं।
- केवल वैध इंडेक्स-जैसे मानों (पूर्णांक `>= 0`) के लिए `true` लौटाता है, और ऋणात्मक, गैर-पूर्णांक, तथा गैर-संख्या मानों
  को अस्वीकार करता है।
- उन API के साथ काम करते समय off-by-one और sentinel-value जैसी गलतियों से बचने में मदद करता है जो “नहीं मिला” के लिए
  `-1` लौटाते हैं।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `isIndexFound(value)`

पैरामीटर:

- `value`: जाँचने के लिए मान कि क्या वह गैर-ऋणात्मक पूर्णांक है।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // idx यहाँ एक संख्या है और >= 0 है
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// indexOf के साथ सामान्य उपयोग
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.isIndexFound(value)`
