# areEqual

## विवरण

`areEqual` जाँचता है कि क्या किसी ऐरे के सभी तत्व दिए गए अपेक्षित मान के बराबर हैं, और `true` केवल उन गैर-खाली ऐरे के
लिए लौटाता है जिनमें हर आइटम मेल खाता है।

### उपयोग का मामला

यह सत्यापित करें कि किसी सूची में केवल एक ही अनुमत मान मौजूद है (जैसे, सभी स्टेटस फ़्लैग `true` हैं, सभी भूमिकाएँ
`"admin"` हैं, या सभी संख्यात्मक प्रविष्टियाँ किसी आवश्यक स्थिरांक के बराबर हैं), और खाली इनपुट को अमान्य (`false`)
मानें।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> जब आपको सभी आइटमों की सख्त जाँच चाहिए, तब `areEqual` का उपयोग करें; यह खाली ऐरे और किसी भी गैर-ऐरे या गैर-भरे हुए
> इनपुट के लिए `false` लौटाता है।

### फायदे

- `true` केवल तब लौटाता है जब हर तत्व अपेक्षित मान से मेल खाता हो; अन्यथा `false` लौटाता है।
- तेज़ी से विफल होता है: जैसे ही कोई गैर-मेल खाने वाला तत्व मिलता है, जाँच रोक देता है।
- इनपुट भरा हुआ ऐरे न होने पर `false` लौटाकर अमान्य इनपुट से सुरक्षा करता है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `areEqual(value, expected)`

पैरामीटर:

- `value`: जाँचा जाने वाला ऐरे।
- `expected`: वह तत्व जिसके साथ प्रत्येक ऐरे आइटम की तुलना की जाती है।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.areEqual(value, expected)`
