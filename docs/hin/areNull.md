# areNull

## विवरण

जाँचता है कि दिए गए `array` के सभी तत्व `null` हैं या नहीं।

### उपयोग का मामला

यह सत्यापित करें कि कोई डेटासेट कॉलम, API फ़ील्ड सूची, या प्लेसहोल्डर ऐरे केवल `null` मानों से बना है, इससे पहले कि आप
ऐसा लॉजिक लागू करें जो मानता है कि सभी प्रविष्टियाँ जानबूझकर खाली हैं।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> `areNull` का उपयोग तब करें जब आपको सख्त जाँच चाहिए कि इनपुट एक गैर-खाली ऐरे है और हर तत्व ठीक-ठीक `null` है (
`undefined` नहीं, न ही falsy मान)।

### फायदे

- केवल तब `true` लौटाता है जब हर तत्व `null` हो, जिससे यह एक सख्त “सभी मेल खाते हैं” गार्ड बनता है।
- `false` लौटाकर गैर-ऐरे और खाली ऐरे को अस्वीकार करता है, जिससे अमान्य इनपुट पर गलती से truthy परिणाम आने से बचाव होता
  है।
- ऐसे डेटा को प्रोसेस करने से पहले प्रीकंडीशन जाँच के रूप में अच्छी तरह काम करता है जिसे पूरी तरह `null` होना आवश्यक है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `areNull(array)`

पैरामीटर:

- `array`: `null` तत्वों के लिए जाँचने हेतु इनपुट ऐरे।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { areNull } from "@type-check/guards";

const a = [null, null];
const b = [null, 1, null];

const allNullA = areNull(a); // सत्य
const allNullB = areNull(b); // असत्य

const notAnArray = areNull(123 as unknown as unknown[]); // असत्य
const empty = areNull([]); // असत्य

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.areNull(array)`
