# areMaps

## विवरण

`areMaps` यह निर्धारित करता है कि दी गई ऐरे खाली नहीं है और उसके सभी तत्व `Map` इंस्टेंस हैं।

### उपयोग का मामला

अज्ञात इनपुट (जैसे JSON पार्सिंग, बाहरी APIs, या डायनेमिक स्रोतों से) को `Map` ऑब्जेक्ट्स की गैर-खाली सूची मानने से पहले
वैलिडेट करें।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> खाली ऐरे के लिए `false` लौटाता है; यह केवल तब `true` लौटाता है जब ऐरे भरी हुई हो और हर तत्व एक `Map` हो।

### फायदे

- यह सुनिश्चित करता है कि हर तत्व एक `Map` इंस्टेंस है, और केवल तब `true` लौटाता है जब पूरी ऐरे जाँच में पास हो जाती है।
- डिज़ाइन के अनुसार खाली ऐरे को अस्वीकार करता है, जिससे “कोई डेटा नहीं” को वैध इनपुट के रूप में गलती से स्वीकार होने से
  बचाता है।
- किसी संग्रह पर `Map`-विशिष्ट ऑपरेशन्स (जैसे, `.get()`, `.set()`, इटरेशन) करने से पहले एक गार्ड के रूप में उपयोगी।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `areMaps(array)`

पैरामीटर:

- `array`: जाँचने के लिए ऐरे।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // items को रनटाइम पर Map इंस्टेंसों की एक गैर-खाली ऐरे होने की गारंटी है
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // इनके लिए false: खाली ऐरे, या ऐसी ऐरे जिनमें कोई भी गैर-Map मान शामिल हो
}

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.areMaps(array)`
