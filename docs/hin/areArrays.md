# areArrays

## विवरण

`areArrays` यह निर्धारित करता है कि कोई मान एक भरा हुआ द्वि-आयामी ऐरे है या नहीं, जिसके सभी आइटम ऐरे हैं।

### उपयोग का मामला

पंक्ति/स्तंभ ऑपरेशन्स करने से पहले सारणीबद्ध या मैट्रिक्स-जैसे इनपुट (जैसे, CSV पंक्तियाँ, ग्रिड डेटा, या समूहित
सूचियाँ) को सत्यापित करने के लिए `areArrays` का उपयोग करें; यदि इनपुट ऐरे नहीं है, खाली है, या किसी भी गैर-ऐरे तत्व को
शामिल करता है, तो यह `false` लौटाता है।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> जब आपको यह सुनिश्चित करना हो कि कोई मान गैर-खाली 2D ऐरे है और नेस्टेड ऐरे पर इटरेट करने या इंडेक्सिंग से पहले प्रत्येक
> पंक्ति एक ऐरे है, तब `areArrays` का उपयोग करें।

### फायदे

- यह सत्यापित करता है कि इनपुट एक गैर-खाली द्वि-आयामी ऐरे है, जहाँ हर तत्व स्वयं एक ऐरे है।
- गार्ड्स और शुरुआती निकास के लिए उपयुक्त एक सरल बूलियन परिणाम (`true`/`false`) लौटाता है।
- जब बाद का कोड नेस्टेड ऐरे ऑपरेशन्स (जैसे, पंक्तियों पर मैपिंग) मानकर चलता है, तब रनटाइम त्रुटियों को रोकने में मदद
  करता है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `areArrays(array)`

पैरामीटर:

- `array`: जाँच के लिए इनपुट।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value एक 2D ऐरे है जिसमें तत्वों के रूप में ऐरे हैं
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.areArrays(array)`
