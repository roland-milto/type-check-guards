# areNaNs

## विवरण

`areNaNs` जाँचता है कि क्या किसी ऐरे के सभी तत्व `NaN` हैं और केवल तभी `true` लौटाता है जब हर तत्व `NaN` हो।

### उपयोग का मामला

आने वाले डेटा को सत्यापित करें जहाँ `NaN` को सेंटिनल मान के रूप में उपयोग किया जाता है और आपको यह सुनिश्चित करना हो कि
पूरा ऐरे केवल `NaN` से ही बना है (उदा., पूरी तरह गायब संख्यात्मक श्रृंखला का पता लगाना)।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> जब आपको यह सत्यापित करना हो कि किसी ऐरे में केवल संख्यात्मक `NaN` मान ही हैं (स्ट्रिंग-से-नंबर कोएर्शन के बिना), तब
`areNaNs` का उपयोग करें।

### फायदे

- केवल तब `true` लौटाता है जब हर तत्व `NaN` हो (सख्त सभी-तत्व जाँच)।
- स्ट्रिंग्स को संख्याओं में कोएर्स नहीं करता; "NaN" जैसे मान non-`NaN` बने रहते हैं और परिणाम `false` कर देते हैं।
- भरे न गए/खाली ऐरे के लिए `false` लौटाता है, जिससे खाली इनपुट पर गलती से `true` होने से बचाव होता है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `areNaNs(array)`

पैरामीटर:

- `array`: `NaN` मानों के लिए जाँचने वाला ऐरे।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // सही
const b = areNaNs([NaN, 1, NaN]); // गलत
const c = areNaNs([NaN, "NaN", NaN]); // गलत
const d = areNaNs([NaN, null, NaN]); // गलत
const e = areNaNs([] as unknown[]); // गलत

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.areNaNs(array)`
