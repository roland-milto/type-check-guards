# isDecimal

## विवरण

`isDecimal` जाँचता है कि कोई मान बिना अग्र/पश्च व्हाइटस्पेस के और वैध दशमलव फ़ॉर्मैट के साथ एक दशमलव स्ट्रिंग
प्रतिनिधित्व है या नहीं।

### उपयोग का मामला

फ़ॉर्म फ़ील्ड्स, API पेलोड्स, या कॉन्फ़िगरेशन मानों को वैलिडेट करें जिन्हें पार्स या स्टोर करने से पहले बिना किसी आसपास
के व्हाइटस्पेस के एक दशमलव स्ट्रिंग (वैकल्पिक रूप से साइन सहित) के रूप में प्रदान किया जाना चाहिए।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> `isDecimal` का उपयोग इसे कन्वर्ट करने से पहले (जैसे `Number(value)` के साथ) उपयोगकर्ता इनपुट को वैलिडेट करने के लिए
> करें, खासकर जब व्हाइटस्पेस को अस्वीकार करना आवश्यक हो।

### फायदे

- सख्ती से सत्यापित करता है कि इनपुट एक स्ट्रिंग है और एक दशमलव-लिटरल पैटर्न से मेल खाता है।
- अस्पष्ट पार्सिंग से बचने के लिए अग्र और पश्च व्हाइटस्पेस (कंट्रोल कैरेक्टर्स सहित) को अस्वीकार करता है।
- रेगेक्स चलाने से पहले तेज़ प्री-चेक (टाइप चेक और पहला/आख़िरी कैरेक्टर) करता है।
- गार्ड्स और इनपुट वैलिडेशन के लिए उपयुक्त एक सरल बूलियन परिणाम (`true`/`false`) लौटाता है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `isDecimal(value)`

पैरामीटर:

- `value`: दशमलव स्ट्रिंग फ़ॉर्मैट के लिए जाँचने वाला मान।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v यहाँ एक स्ट्रिंग है (रनटाइम पर सत्यापित)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.isDecimal(value)`
