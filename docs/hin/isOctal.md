# isOctal

## विवरण

निर्धारित करता है कि कोई मान एक वैध ऑक्टल लिटरल स्ट्रिंग है या नहीं (उदा. `0o755`)।

### उपयोग का मामला

यूज़र इनपुट या कॉन्फ़िगरेशन मानों को वैलिडेट करें जिन्हें ऑक्टल लिटरल स्ट्रिंग के रूप में व्यक्त किया जाना आवश्यक है (
उदाहरण के लिए, फ़ाइल परमिशन मोड जैसे `0o644`), उन्हें पार्स या कन्वर्ट करने से पहले।

> **TypeScript उपयोगकर्ताओं के लिए संकेत:**
>
> `isOctal` एक टाइप गार्ड है (`value is string`)। `true` परिणाम के बाद, TypeScript जाँचे गए वेरिएबल को `string` तक
> संकीर्ण कर देता है।

### फायदे

- एक सख्त टाइप गार्ड प्रदान करता है: `true` केवल तब लौटाता है जब इनपुट एक स्ट्रिंग हो जो ऑक्टल लिटरल फ़ॉर्मैट से मेल
  खाती हो।
- खाली स्ट्रिंग्स और आगे/पीछे व्हाइटस्पेस (ASCII नियंत्रण/स्पेस) वाली स्ट्रिंग्स को अस्वीकार करता है, जिससे अनजाने में
  होने वाले मैच कम होते हैं।
- `0o`/`0O` प्रीफ़िक्स के लिए वैकल्पिक साइन का समर्थन करता है और केस-इन्सेंसिटिव है।
- नॉन-स्ट्रिंग इनपुट के लिए `false` लौटाकर (throw करने के बजाय) लचीला व्यवहार करता है।

## उपयोग

### सिंटैक्स

फ़ंक्शन:

- `isOctal(value)`

पैरामीटर:

- `value`: जाँचा जाने वाला मान।

### लोकल फ़ंक्शन इम्पोर्ट

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); // सही
console.log(isOctal(b)); // सही
console.log(isOctal(c)); // गलत
console.log(isOctal(d)); // गलत

if (isOctal(a)) {
  // यहाँ a स्ट्रिंग है
  const normalized = a.toLowerCase();
  console.log(normalized);
}
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फ़ंक्शन्स को ग्लोबल ऑब्जेक्ट मेथड्स के रूप में इम्पोर्ट करने के लिए उपयोग करें:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबली उपलब्ध होगा:

- `Type.isOctal(value)`
