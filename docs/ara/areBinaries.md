# areBinaries

## الوصف

يتحقق مما إذا كانت القيمة المقدمة مصفوفة غير فارغة من سلاسل ثنائية صالحة ويعيد `true` فقط إذا اجتازت جميع العناصر
التحقق.

### حالة الاستخدام

استخدم `areBinaries` عندما تتلقى قائمة غير معروفة (مثلًا من JSON أو النماذج أو واجهات برمجة التطبيقات) وتحتاج إلى التأكد
من أنها مصفوفة غير فارغة من سلاسل ثنائية قبل تحليلها أو معالجتها.

> **ملاحظة لمستخدمي TypeScript:**
>
> استخدم `areBinaries` للتحقق من مدخلات غير معروفة قبل تحويل السلاسل الثنائية إلى أرقام/BigInts؛ فهو يضمن أن المصفوفة
> غير فارغة وأن كل عنصر عبارة عن سلسلة ثنائية صالحة.

### المزايا

- يتحقق من أن القيمة مصفوفة غير فارغة وأن كل عنصر فيها سلسلة ثنائية صالحة.
- يعيد نتيجة منطقية بسيطة (`true`/`false`) مناسبة للحراس، وعمليات الإرجاع المبكر، والتحقق من صحة المدخلات.
- يمنع أخطاء التحليل اللاحقة عبر رفض المصفوفات التي تحتوي على أي إدخال غير ثنائي.

## الاستخدام

### الصياغة

الدالة:

- `areBinaries(array)`

المعاملات:

- `array`: القيمة المراد التحقق منها.

### استيراد الدالة محليًا

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); //‎ صحيح
console.log(areBinaries(b)); //‎ خطأ
console.log(areBinaries([])); //‎ خطأ
```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.areBinaries(array)`
