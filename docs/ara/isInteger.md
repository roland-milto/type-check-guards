# isInteger

## الوصف

يحدد ما إذا كانت `value` المعطاة عددًا صحيحًا آمنًا.

### حالة الاستخدام

تحقق من صحة المُدخلات غير الموثوقة (مثل معاملات الاستعلام، وحمولات JSON، ومتغيرات البيئة) قبل استخدامها كعدد صحيح لفهارس
المصفوفات أو ترقيم الصفحات أو العدادات أو معرّفات قاعدة البيانات.

> **ملاحظة لمستخدمي TypeScript:**
>
> استخدم `isInteger` للتحقق من صحة المُدخلات غير المعروفة قبل التعامل معها كعدد صحيح؛ فهو يُرجع `true` فقط للقيم التي
> يكون فيها `typeof value === "number"` و `Number.isSafeInteger(value)`.

### المزايا

- يتحقق من كلٍّ من سلامة النوع والسلامة العددية: يُرجع `true` فقط عندما تكون المُدخلات رقمًا وعددًا صحيحًا آمنًا.
- يمنع المزالق الشائعة مع الإكراه العددي: السلاسل النصية مثل "5" تُرجع بشكل صحيح `false`.
- يرفض الأعداد غير الصحيحة والأعداد الصحيحة غير الآمنة، مما يجعله مناسبًا للمعرّفات (IDs) والعدادات وفهرسة المصفوفات.

## الاستخدام

### الصياغة

الدالة:

- `isInteger(value)`

المعاملات:

- `value`: القيمة المراد التحقق من كونها عددًا صحيحًا.

### استيراد الدالة محليًا

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      //‎ صحيح
const b = isInteger(-100);   //‎ صحيح
const c = isInteger("5");    //‎ خطأ
const d = isInteger(5.5);    //‎ خطأ
const e = isInteger(null);   //‎ خطأ

```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.isInteger(value)`
