# isEmpty

## الوصف

يحدد ما إذا كانت قيمة معيّنة فارغة، ويعيد `true` لـ `null` و`undefined` والسلاسل النصية الفارغة/المكوّنة من مسافات فقط،
والمصفوفات الفارغة، و`Map`/`Set` الفارغة، أو الكائنات التي لا تحتوي على خصائص قابلة للتعداد مملوكة لها.

### حالة الاستخدام

استخدم `isEmpty` للتحقق من صحة المدخلات واكتشاف القيم المفقودة/الفارغة عبر أنواع بيانات متعددة (مثل حقول النماذج،
وحمولات API، وكائنات الإعدادات) حيث ينبغي التعامل مع `null` و`undefined` والسلاسل النصية المكوّنة من مسافات فقط،
والمجموعات الفارغة، والكائنات بلا خصائص على أنها فارغة.

> **ملاحظة لمستخدمي TypeScript:**
>
> `isEmpty` هي أداة تُرجع قيمة منطقية (وليست TypeScript type predicate)، لذا فهي لا تُضيّق الأنواع (narrow types)
> بذاتها؛ استخدمها للتحقق/التفريع بدلًا من التضييق وقت الترجمة (compile-time).

### المزايا

- يتعامل مع `null` و`undefined` على أنهما `true` عند فحص الفراغ.
- يعتبر السلاسل النصية التي تحتوي على مسافات فقط فارغة عبر إجراء trim قبل التحقق من الطول.
- يدعم أنواع الحاويات الشائعة (المصفوفات، `Map`، `Set`) والكائنات العادية التي لا تحتوي على خصائص قابلة للتعداد مملوكة
  لها.
- يتجنب احتساب الخصائص الموروثة عبر استخدام فحوصات `hasOwnProperty`.
- يعيد نتيجة منطقية بسيطة (`true`/`false`) مناسبة للحراس (guards) والتحقق من الصحة.

## الاستخدام

### الصياغة

الدالة:

- `isEmpty(value)`

المعاملات:

- `value`: القيمة المراد التحقق من كونها فارغة.

### استيراد الدالة محليًا

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.isEmpty(value)`
