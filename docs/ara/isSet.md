# isSet

## الوصف

يحدّد ما إذا كانت قيمة معيّنة هي `Set`.

### حالة الاستخدام

تحقّق من صحة المدخلات القادمة من مصادر خارجية (مثل تحليل JSON، أو إدخال المستخدم، أو واجهات برمجة تطبيقات لجهات خارجية)
لضمان أن القيمة هي `Set` قبل تنفيذ عمليات `Set`.

> **ملاحظة لمستخدمي TypeScript:**
>
> استخدم `isSet` لتضييق قيم `unknown` قبل استدعاء واجهات برمجة التطبيقات الخاصة بـ `Set` مثل `.add` أو `.has` أو
`.size`.

### المزايا

- يوفّر فحصًا بسيطًا وقت التشغيل للتأكد مما إذا كانت القيمة `Set`.
- يساعد على منع أخطاء الأنواع عبر إتاحة التفريع المبكر عندما لا تكون القيمة `Set`.
- يعمل مع أي محتويات داخل `Set` (فارغة أو ممتلئة) ويُرجع `true`/`false` بشكل متّسق.

## الاستخدام

### الصياغة

الدالة:

- `isSet(value)`

المعاملات:

- `value`: القيمة المراد التحقق منها.

### استيراد الدالة محليًا

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  //‎‎ a هي Set أثناء وقت التشغيل
  console.log(a.size);
}

console.log(isSet(b)); //‎ خطأ
```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.isSet(value)`
