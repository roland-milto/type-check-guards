# isHexadecimal

## الوصف

تتحقق `isHexadecimal` مما إذا كانت قيمة معيّنة تمثل سلسلة نصية حرفية سداسية عشرية مع بادئة إلزامية `0x`/`0X`.

### حالة الاستخدام

استخدم `isHexadecimal` للتحقق من قيم الإعدادات، أو حقول حمولة واجهة برمجة التطبيقات (API)، أو وسائط سطر الأوامر (CLI)
التي يجب تقديمها كسلاسل نصية حرفية سداسية عشرية (مثل المعرّفات، أو الأقنعة، أو العناوين) ويجب ألا تحتوي على مسافات بيضاء
محيطة.

> **ملاحظة لمستخدمي TypeScript:**
>
> استخدم `isHexadecimal` عندما تحتاج إلى التحقق من إدخال المستخدم أو البيانات المُسلسلة على أنها سلسلة نصية حرفية سداسية
> عشرية صارمة (بما في ذلك بادئة `0x`/`0X`) قبل تحليلها أو تحويلها.

### المزايا

- يتحقق من أن القيمة سلسلة نصية وتطابق تنسيقًا صارمًا لتمثيل سداسي عشري حرفي (يتطلب بادئة `0x`/`0X`).
- يرفض السلاسل النصية التي تحتوي على مسافات بيضاء في البداية أو النهاية، مما يساعد على تجنب القبول غير المقصود لإدخال
  مُضاف إليه حشو.
- يدعم إشارة اختيارية ولا يتأثر بحالة الأحرف للبادئة والأرقام، ويُرجع `true`/`false` بشكل متوقع.

## الاستخدام

### الصياغة

الدالة:

- `isHexadecimal(value)`

المعاملات:

- `value`: القيمة المراد التحقق منها.

### استيراد الدالة محليًا

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); //‎ صحيح
isHexadecimal("-0Xff"); //‎ صحيح
isHexadecimal("1A2B"); //‎ خطأ (بادئة مفقودة)
isHexadecimal(" 0x1A2B"); //‎ خطأ (مسافة بادئة في البداية)
isHexadecimal(0x1a2b); //‎ خطأ (ليس سلسلة نصية)
```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.isHexadecimal(value)`
