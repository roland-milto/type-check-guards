# isBinary

## الوصف

تحدد `isBinary` ما إذا كانت القيمة سلسلة ثنائية (مع إمكانية وجود بادئة `0b`/`0B`) وتعيد `true` أو `false`.

### حالة الاستخدام

تحقق من السلاسل التي يوفرها المستخدم (مثل حقول النماذج، وسيطات CLI، قيم الإعدادات) لضمان أنها تمثل أرقامًا ثنائية فقط،
مع إمكانية وجود بادئة `0b`/`0B`، قبل المعالجة اللاحقة.

> **ملاحظة لمستخدمي TypeScript:**
>
> استخدم `isBinary` كحارس نوع قبل تحليل سلسلة أو تحويلها إلى `BigInt`/`Number` لتجنب إدخال غير صالح.

### المزايا

- يقبل السلاسل الثنائية مع بادئة `0b`/`0B` أو بدونها.
- يرفض السلاسل الفارغة والسلاسل التي تحتوي على مسافات بادئة/لاحقة (ASCII ≤ 32).
- يعيد `true`/`false` دون رمي استثناءات، مما يجعله آمنًا للمدخلات غير المعروفة.

## الاستخدام

### الصياغة

الدالة:

- `isBinary(value)`

المعاملات:

- `value`: القيمة المراد التحقق منها.

### استيراد الدالة محليًا

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); //‎ صحيح
const b = isBinary("1010");   //‎ صحيح
const c = isBinary("0b1020"); //‎ خطأ
const d = isBinary(0b1010);     //‎ خطأ

```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.isBinary(value)`
