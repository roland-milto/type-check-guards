# areArrays

## الوصف

تحدد `areArrays` ما إذا كانت القيمة مصفوفة ثنائية الأبعاد ممتلئة تكون جميع عناصرها مصفوفات.

### حالة الاستخدام

استخدم `areArrays` للتحقق من صحة المدخلات الجدولية أو الشبيهة بالمصفوفات (مثل صفوف CSV أو بيانات الشبكة أو القوائم
المجمعة) قبل تنفيذ عمليات الصف/العمود؛ إذ تعيد `false` إذا لم يكن الإدخال مصفوفة، أو كان فارغًا، أو احتوى على أي عنصر
ليس مصفوفة.

> **ملاحظة لمستخدمي TypeScript:**
>
> استخدم `areArrays` عندما تحتاج إلى التأكد من أن القيمة مصفوفة ثنائية الأبعاد غير فارغة وأن كل صف عبارة عن مصفوفة قبل
> التكرار أو الفهرسة داخل المصفوفات المتداخلة.

### المزايا

- يتحقق من أن الإدخال عبارة عن مصفوفة ثنائية الأبعاد غير فارغة حيث يكون كل عنصر مصفوفة.
- يعيد نتيجة منطقية بسيطة (`true`/`false`) مناسبة للحراس والخروج المبكر.
- يساعد على منع أخطاء وقت التشغيل عندما يفترض الكود اللاحق عمليات على مصفوفات متداخلة (مثل إجراء map على الصفوف).

## الاستخدام

### الصياغة

الدالة:

- `areArrays(array)`

المعاملات:

- `array`: الإدخال المراد التحقق منه.

### استيراد الدالة محليًا

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  //‎‎ القيمة هي مصفوفة ثنائية الأبعاد تحتوي على مصفوفات كعناصر
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.areArrays(array)`
