# areSets

## الوصف

يتحقق مما إذا كانت مصفوفة غير فارغة معيّنة تحتوي فقط على مثيلات `Set`، ويعيد `true` إذا كان الأمر كذلك و`false` خلاف
ذلك.

### حالة الاستخدام

تحقق من أن قيمة ما (مثلًا من إدخال المستخدم، أو تحليل JSON، أو واجهات برمجة تطبيقات خارجية) هي مصفوفة غير فارغة من
كائنات `Set` قبل معالجة كل مجموعة.

> **ملاحظة لمستخدمي TypeScript:**
>
> استخدم `areSets` للتحقق من صحة الإدخال غير المعروف قبل التكرار واستدعاء واجهات برمجة تطبيقات `Set` (مثل `.size` و
`.has` و`.add`) على كل عنصر.

### المزايا

- يعيد `true` فقط عندما يكون الإدخال مصفوفة غير فارغة وكل عنصر فيها مثيلاً من `Set`.
- يمنع النتائج الإيجابية الخاطئة للمصفوفات الفارغة عبر إرجاع `false` عندما لا تحتوي المصفوفة على أي عناصر.
- مفيد كحارس وقت التشغيل قبل تنفيذ عمليات خاصة بـ `Set` على كل عنصر.

## الاستخدام

### الصياغة

الدالة:

- `areSets(array)`

المعاملات:

- `array`: المصفوفة المراد التحقق مما إذا كانت تحتوي على مثيلات `Set`.

### استيراد الدالة محليًا

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  //‎‎ a هي مصفوفة من مثيلات Set أثناء وقت التشغيل
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); //‎ خطأ
console.log(areSets(c)); //‎ خطأ
```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.areSets(array)`
