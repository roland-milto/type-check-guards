# areOctals

## الوصف

تحدد `areOctals` ما إذا كانت القيمة المقدمة مصفوفة غير فارغة من سلاسل ثُمانية صالحة.

### حالة الاستخدام

استخدم `areOctals` عند التحقق من مدخلات المستخدم أو قيم الإعدادات أو حمولة API التي يجب أن تحتوي على صيغ ثُمانية (مثل
أوضاع أذونات الملفات مثل `0o755`) وعندما تريد رفض المصفوفات الفارغة أو أي إدخالات غير صالحة عبر إرجاع `false`.

> **ملاحظة لمستخدمي TypeScript:**
>
> استخدم `areOctals` للتأكد من أن لديك `unknown[]` غير فارغة حيث يكون كل إدخال سلسلة ثُمانية صالحة قبل التحويل (مثلًا
> عبر `Number(...)` أو تحليل مخصص).

### المزايا

- يتحقق من أن القيمة مصفوفة غير فارغة حيث يكون كل عنصر سلسلة ثُمانية، ويُرجع `true` فقط عندما تجتاز جميع العناصر التحقق.
- يفشل بسرعة: يُرجع `false` بمجرد العثور على عنصر غير ثُماني.
- مفيد كحارس قبل تحليل أو تحويل السلاسل الثُمانية لتجنب أخطاء وقت التشغيل وعدم اتساق التعامل مع المدخلات.

## الاستخدام

### الصياغة

الدالة:

- `areOctals(array)`

المعاملات:

- `array`: القيمة المراد التحقق منها.

### استيراد الدالة محليًا

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  //‎‎ القيمة عبارة عن مصفوفة غير فارغة من سلاسل ثُمانية
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.areOctals(array)`
