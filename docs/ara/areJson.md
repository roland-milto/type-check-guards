# areJson

## الوصف

يتحقق مما إذا كانت جميع عناصر المصفوفة سلاسل JSON، ويعيد `true` فقط إذا كانت المصفوفة غير فارغة وكل عنصر JSON صالح؛ وإلا
يعيد `false`.

### حالة الاستخدام

التحقق من صحة البيانات الواردة (مثلًا من معاملات الاستعلام، أو متغيرات البيئة، أو واجهات برمجة التطبيقات الخارجية) عندما
تتوقع مصفوفة من السلاسل المرمّزة بصيغة JSON وتريد رفض المصفوفات الفارغة أو أي إدخالات غير JSON.

> **ملاحظة لمستخدمي TypeScript:**
>
> استخدم `areJson` عندما تحتاج إلى التحقق من أن `unknown[]` يحتوي فقط على سلاسل JSON قبل تحليلها (مثلًا باستخدام
`JSON.parse`).

### المزايا

- يعيد `true` فقط عندما يكون كل عنصر سلسلة JSON صالحة؛ وإلا يعيد `false`.
- يفشل بسرعة: يتوقف عن التحقق بمجرد العثور على عنصر غير JSON.
- يرفض المصفوفات الفارغة حسب التصميم، ويعيد `false` للإدخال غير المعبّأ.

## الاستخدام

### الصياغة

الدالة:

- `areJson(array)`

المعاملات:

- `array`: المصفوفة المراد التحقق من احتوائها على عناصر من سلاسل JSON.

### استيراد الدالة محليًا

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); //‎ صحيح
const mixed = areJson(["{\"a\":1}", 123 as unknown]); //‎ خطأ
const empty = areJson([]); //‎ خطأ

```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.areJson(array)`
