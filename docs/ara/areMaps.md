# areMaps

## الوصف

تحدد `areMaps` ما إذا كانت المصفوفة المعطاة غير فارغة وأن جميع عناصرها هي مثيلات `Map`.

### حالة الاستخدام

تحقق من صحة الإدخال غير المعروف (مثل الناتج عن تحليل JSON، أو واجهات برمجة التطبيقات الخارجية، أو المصادر الديناميكية)
قبل التعامل معه كقائمة غير فارغة من كائنات `Map`.

> **ملاحظة لمستخدمي TypeScript:**
>
> تُرجع `false` للمصفوفة الفارغة؛ ولا تُرجع `true` إلا عندما تكون المصفوفة ممتلئة وكل عنصر فيها هو `Map`.

### المزايا

- يضمن أن كل عنصر هو مثيل `Map`، ويُرجع `true` فقط عندما تجتاز المصفوفة بأكملها الفحص.
- يرفض المصفوفات الفارغة حسب التصميم، مما يمنع القبول غير المقصود لـ "عدم وجود بيانات" كمدخل صالح.
- مفيد كحارس قبل تنفيذ عمليات خاصة بـ `Map` (مثل `.get()` و`.set()` والتكرار) عبر مجموعة.

## الاستخدام

### الصياغة

الدالة:

- `areMaps(array)`

المعاملات:

- `array`: المصفوفة المراد التحقق منها.

### استيراد الدالة محليًا

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  //‎‎ يُضمن أن items مصفوفة غير فارغة من مثيلات Map أثناء وقت التشغيل
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  //‎‎ تكون false لـ: المصفوفات الفارغة، أو المصفوفات التي تحتوي على أي قيمة ليست من نوع Map
}

```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.areMaps(array)`
