# isIndexFound

## الوصف

تحدّد `isIndexFound` ما إذا كانت قيمة معيّنة عددًا صحيحًا غير سالب، بما يشير إلى أنه تم العثور على فهرس.

### حالة الاستخدام

تحقّق من أن نتيجة البحث تمثّل فهرسًا قابلًا للاستخدام (عدد صحيح `>= 0`) قبل الفهرسة داخل مصفوفة أو سلسلة، لمنع الاستخدام
غير المقصود لـ `-1` أو القيم غير الرقمية.

> **ملاحظة لمستخدمي TypeScript:**
>
> استخدم `isIndexFound` بعد عمليات مثل `indexOf` و`findIndex` أو عمليات بحث مخصّصة حيث يمكن أن تشير `-1` (أو قيم غير
> صالحة أخرى) إلى "غير موجود". عندما تُرجع `true` تكون القيمة رقمًا وآمنة للاستخدام كفهرس لمصفوفة/سلسلة.

### المزايا

- يوفّر حارس نوع بسيطًا لاكتشاف ما إذا كان قد تم العثور على فهرس عبر التحقق من كونه عددًا صحيحًا غير سالب.
- يعيد `true` فقط للقيم الصالحة الشبيهة بالفهرس (أعداد صحيحة `>= 0`)، مع رفض القيم السالبة، وغير الصحيحة (غير الأعداد
  الصحيحة)، وغير الرقمية.
- يساعد على تجنّب أخطاء زيادة/نقصان واحد وأخطاء قيم الحارس (sentinel) عند العمل مع واجهات برمجة تطبيقات تُرجع `-1`
  للدلالة على "غير موجود".

## الاستخدام

### الصياغة

الدالة:

- `isIndexFound(value)`

المعاملات:

- `value`: القيمة المراد التحقق من كونها عددًا صحيحًا غير سالب.

### استيراد الدالة محليًا

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  //‎‎ idx هو رقم هنا وهو >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

//‎‎ الاستخدام المعتاد مع indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### استيراد كائن عام

استخدم الاستيراد التالي لاستيراد الدوال كطرائق للكائن بشكل عام:

```ts
import "@type-check/guards/register-global-object.mjs";
```

ستتوفر عندها الطريقة التالية بشكل عام:

- `Type.isIndexFound(value)`
