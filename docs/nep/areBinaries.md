# areBinaries

## विवरण

प्रदान गरिएको मान मान्य बाइनरी स्ट्रिङहरूको गैर-खाली एरे हो कि होइन जाँच्छ र सबै वस्तुहरूले प्रमाणीकरण पास गरेमा मात्र
`true` फर्काउँछ।

### प्रयोगको केस

तपाईंले अज्ञात सूची (जस्तै JSON, फारमहरू, वा APIs बाट) प्राप्त गर्दा र यसलाई पार्स वा प्रोसेस गर्नु अघि यो बाइनरी
स्ट्रिङहरूको गैर-खाली एरे हो भन्ने सुनिश्चित गर्नुपर्ने अवस्थामा `areBinaries` प्रयोग गर्नुहोस्।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> बाइनरी स्ट्रिङहरूलाई numbers/BigInts मा रूपान्तरण गर्नु अघि अज्ञात इनपुट प्रमाणीकरण गर्न `areBinaries` प्रयोग
> गर्नुहोस्; यसले एरे गैर-खाली छ र प्रत्येक तत्व मान्य बाइनरी स्ट्रिङ हो भन्ने सुनिश्चित गर्छ।

### फाइदाहरू

- कुनै मान गैर-खाली एरे हो र त्यसका प्रत्येक तत्व मान्य बाइनरी स्ट्रिङ हो भन्ने कुरा प्रमाणीकरण गर्छ।
- गार्डहरू, प्रारम्भिक रिटर्नहरू, र इनपुट प्रमाणीकरणका लागि उपयुक्त सरल बूलियन परिणाम (`true`/`false`) फर्काउँछ।
- कुनै पनि गैर-बाइनरी प्रविष्टि समावेश भएका एरेहरू अस्वीकार गरेर पछिल्लो चरणका पार्सिङ त्रुटिहरू रोक्छ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `areBinaries(array)`

प्यारामिटरहरू:

- `array`: जाँच गर्नुपर्ने मान।

### स्थानीय फङ्सन आयात

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // सत्य
console.log(areBinaries(b)); // असत्य
console.log(areBinaries([])); // असत्य
```

### ग्लोबल अब्जेक्ट आयात

फङ्सनहरूलाई ग्लोबल अब्जेक्ट मेथडका रूपमा आयात गर्न प्रयोग गर्नुहोस्:

```ts

```

त्यसपछि निम्न मेथड ग्लोबली उपलब्ध हुनेछ:

- `Type.areBinaries(array)`
