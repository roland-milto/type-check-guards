# areJson

## विवरण

एरेका सबै तत्वहरू JSON स्ट्रिङ हुन् कि होइनन् भनेर जाँच गर्छ, एरे भरिएको छ र हरेक आइटम मान्य JSON भएमा मात्र `true`
फर्काउँछ; अन्यथा `false` फर्काउँछ।

### प्रयोगको केस

आगमन डेटा (जस्तै query params, environment variables, वा external APIs बाट) प्रमाणीकरण गर्नुहोस् जहाँ तपाईं JSON-encoded
स्ट्रिङहरूको एरे अपेक्षा गर्नुहुन्छ र खाली एरेहरू वा कुनै पनि गैर-JSON प्रविष्टिहरू अस्वीकार गर्न चाहनुहुन्छ।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> `areJson` प्रयोग गर्नुहोस् जब तपाईंले `unknown[]` मा पार्स गर्नु अघि (जस्तै `JSON.parse` सँग) केवल JSON स्ट्रिङहरू
> मात्र छन् भनेर प्रमाणीकरण गर्न आवश्यक हुन्छ।

### फाइदाहरू

- हरेक तत्व मान्य JSON स्ट्रिङ हुँदा मात्र `true` फर्काउँछ; अन्यथा `false` फर्काउँछ।
- छिटो असफल हुन्छ: गैर-JSON तत्व भेटिने बित्तिकै जाँच रोक्छ।
- डिजाइनअनुसार खाली एरेहरू अस्वीकार गर्छ, भरिएको नभएको इनपुटका लागि `false` फर्काउँछ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `areJson(array)`

प्यारामिटरहरू:

- `array`: JSON स्ट्रिङ तत्वहरूका लागि जाँच गर्नुपर्ने एरे।

### स्थानीय फङ्सन आयात

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // सत्य
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // असत्य
const empty = areJson([]); // असत्य

```

### ग्लोबल अब्जेक्ट आयात

फङ्सनहरूलाई ग्लोबल अब्जेक्ट मेथडका रूपमा आयात गर्न प्रयोग गर्नुहोस्:

```ts
import "@type-check/guards/register-global-object.mjs";
```

त्यसपछि निम्न मेथड ग्लोबली उपलब्ध हुनेछ:

- `Type.areJson(array)`
