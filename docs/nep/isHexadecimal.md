# isHexadecimal

## विवरण

`isHexadecimal` ले दिइएको मान अनिवार्य `0x`/`0X` उपसर्ग भएको हेक्साडेसिमल स्ट्रिङ लिटरल हो कि होइन भनेर जाँच गर्छ।

### प्रयोगको केस

कन्फिगरेसन मानहरू, API payload का फिल्डहरू, वा CLI arguments जसलाई हेक्साडेसिमल स्ट्रिङ लिटरल (जस्तै IDs, masks, वा
addresses) का रूपमा उपलब्ध गराउनैपर्ने हुन्छ र वरिपरि whitespace हुन नहुने हुन्छ, तिनलाई प्रमाणीकरण गर्न `isHexadecimal`
प्रयोग गर्नुहोस्।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> पार्स वा रूपान्तरण गर्नु अघि प्रयोगकर्ता इनपुट वा सिरियलाइज्ड डाटालाई कडा हेक्साडेसिमल लिटरल स्ट्रिङ ( `0x`/`0X`
> उपसर्ग सहित) का रूपमा प्रमाणीकरण गर्न आवश्यक हुँदा `isHexadecimal` प्रयोग गर्नुहोस्।

### फाइदाहरू

- कुनै मान स्ट्रिङ हो र कडा हेक्साडेसिमल लिटरल ढाँचासँग मेल खान्छ (अनिवार्य रूपमा `0x`/`0X` उपसर्ग चाहिन्छ) भन्ने कुरा
  प्रमाणीकरण गर्छ।
- अगाडि वा पछाडि खाली ठाउँ (whitespace) भएका स्ट्रिङहरू अस्वीकार गर्छ, जसले प्याड गरिएको इनपुट गल्तीले स्वीकारिने जोखिम
  घटाउँछ।
- वैकल्पिक चिन्ह (sign) समर्थन गर्छ र उपसर्ग तथा अंकहरूका लागि केस-इन्सेन्सिटिभ हुन्छ, `true`/`false` पूर्वानुमेय रूपमा
  फर्काउँछ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `isHexadecimal(value)`

प्यारामिटरहरू:

- `value`: जाँच गर्नुपर्ने मान।

### स्थानीय फङ्सन आयात

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // true
isHexadecimal("-0Xff"); // true
isHexadecimal("1A2B"); // false (उपसर्ग हराइरहेको)
isHexadecimal(" 0x1A2B"); // false (अगाडि खाली ठाउँ)
isHexadecimal(0x1a2b); // false (स्ट्रिङ होइन)
```
