# isOneOfType

## विवरण

`isOneOfType` ले दिइएको `value` ले प्रदान गरिएका प्रकार स्ट्रिङहरूमध्ये कम्तीमा एउटा सँग मेल खान्छ कि छैन भनेर निर्धारण
गर्छ; कुनै मिलान भेटिएमा `true` र नभेटिएमा `false` फर्काउँछ।

### प्रयोगको केस

थप तर्क अघि बढाउनु अघि धेरै स्वीकार्य रनटाइम प्रकारहरू (जस्तै `number` वा `string`) अनुमति दिएर ढिलो-टाइप गरिएको वा
बाह्य डेटा (जस्तै पार्स गरिएको JSON, क्वेरी प्यारामिटरहरू) प्रमाणीकरण गर्नुहोस्।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> रनटाइममा कुनै मानले धेरैमध्ये कुनै एक अनुमति प्राप्त प्रकारसँग मेल खान्छ कि भनेर जाँच गर्न चाहँदा `isOneOfType` प्रयोग
> गर्नुहोस्; कम्तीमा एउटा प्रकार मिलेमा `true`, नत्र `false` फर्काउँछ।

### फाइदाहरू

- एकै पटकको कलमा मानलाई धेरै अनुमति प्राप्त प्रकारहरूसँग जाँच गर्छ, पहिलो मिलानमै `true` फर्काउँछ।
- `unknown` इनपुटहरूसँग काम गर्छ, जसले यसलाई रनटाइम सीमाहरूमा (जस्तै बाह्य डेटा, प्रयोगकर्ता इनपुट) उपयोगी बनाउँछ।
- यसले सरल बूलियन नतिजा (`true`/`false`) प्रदान गर्छ, जुन सर्तीय तर्क र छिटो रिटर्नहरूसँग राम्रोसँग संयोजन हुन्छ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `isOneOfType(value, types)`

प्यारामिटरहरू:

- `value`: निर्दिष्ट प्रकारहरूसँग जाँच गर्नुपर्ने मान।
- `types`: मानका सम्भावित प्रकारहरू प्रतिनिधित्व गर्ने प्रकार स्ट्रिङहरूको एरे।

### स्थानीय फङ्सन आयात

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // input रनटाइममा एउटा वस्तु हो
}

console.log(isOneOfType(3, ["number", "string"])); // true
console.log(isOneOfType("hello", ["number", "boolean"])); // false

```
