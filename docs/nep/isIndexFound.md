# isIndexFound

## विवरण

`isIndexFound` ले दिइएको मान गैर-ऋणात्मक पूर्णांक हो कि होइन निर्धारण गर्छ, जसले इन्डेक्स फेला परेको संकेत गर्छ।

### प्रयोगको केस

एरे वा स्ट्रिङमा इन्डेक्सिङ गर्नु अघि खोज परिणाम प्रयोगयोग्य इन्डेक्स (पूर्णांक `>= 0`) हो भनेर प्रमाणीकरण गर्नुहोस्,
ताकि `-1` वा गैर-संख्यात्मक मानहरू अनायास प्रयोग हुन नदिन सकियोस्।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> `indexOf`, `findIndex`, वा `-1` (वा अन्य अमान्य मानहरू) ले “फेला परेन” जनाउन सक्ने कस्टम खोजहरू जस्ता अपरेसनपछि
`isIndexFound` प्रयोग गर्नुहोस्। यसले `true` फर्काउँदा, त्यो मान संख्या हुन्छ र array/string इन्डेक्सका रूपमा प्रयोग
> गर्न सुरक्षित हुन्छ।

### फाइदाहरू

- गैर-ऋणात्मक पूर्णांक छ कि छैन जाँच गरेर कुनै इन्डेक्स फेला परेको हो कि होइन पत्ता लगाउन सरल टाइप गार्ड प्रदान गर्छ।
- मान्य इन्डेक्स-जस्ता मानहरू (पूर्णांक `>= 0`) का लागि मात्र `true` फर्काउँछ, ऋणात्मक, गैर-पूर्णांक, र गैर-संख्यात्मक
  मानहरू अस्वीकार गर्छ।
- “फेला परेन” का लागि `-1` फर्काउने API हरूसँग काम गर्दा off-by-one र sentinel-value सम्बन्धी गल्तीहरूबाट बच्न मद्दत
  गर्छ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `isIndexFound(value)`

प्यारामिटरहरू:

- `value`: गैर-ऋणात्मक पूर्णांक हो कि होइन भनेर जाँच गर्ने मान।

### स्थानीय फङ्सन आयात

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // idx यहाँ एउटा संख्या हो र >= 0 छ
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// indexOf सँग सामान्य प्रयोग
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```
