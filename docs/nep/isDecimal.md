# isDecimal

## विवरण

`isDecimal` ले कुनै मान अग्र/पछाडिको खालीस्थान बिना र मान्य दशमलव ढाँचासहितको दशमलव स्ट्रिङ प्रतिनिधित्व हो कि होइन
जाँच्छ।

### प्रयोगको केस

पार्स वा भण्डारण गर्नु अघि, वरिपरि कुनै पनि खालीस्थान बिना दशमलव स्ट्रिङ (वैकल्पिक रूपमा साइन सहित) का रूपमा उपलब्ध
गरिनुपर्ने फर्म फिल्डहरू, API पेलोडहरू, वा कन्फिगरेसन मानहरू प्रमाणीकरण गर्नुहोस्।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> `isDecimal` प्रयोग गरेर प्रयोगकर्ता इनपुटलाई रूपान्तरण गर्नु अघि (जस्तै `Number(value)` सँग) प्रमाणीकरण गर्नुहोस्,
> विशेष गरी जब खालीस्थान अस्वीकार गर्नुपर्छ।

### फाइदाहरू

- इनपुट स्ट्रिङ हो भन्ने कुरा कडाइका साथ प्रमाणीकरण गर्छ र दशमलव-लिटरल ढाँचासँग मिल्छ कि मिल्दैन जाँच्छ।
- अस्पष्ट पार्सिङबाट बच्न अग्र/पछाडिको खालीस्थान (कन्ट्रोल क्यारेक्टरहरू सहित) अस्वीकार गर्छ।
- रेगेक्स चलाउनु अघि छिटो पूर्व-जाँचहरू (टाइप जाँच र पहिलो/अन्तिम क्यारेक्टर) गर्छ।
- गार्ड र इनपुट प्रमाणीकरणका लागि उपयुक्त सरल बूलियन परिणाम (`true`/`false`) फर्काउँछ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `isDecimal(value)`

प्यारामिटरहरू:

- `value`: दशमलव स्ट्रिङ ढाँचाका लागि जाँच गर्नुपर्ने मान।

### स्थानीय फङ्सन आयात

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v यहाँ स्ट्रिङ हो (रनटाइममा प्रमाणीकरण गरिएको)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```
