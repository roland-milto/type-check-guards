# areNumbers

## विवरण

`areNumbers` ले कुनै मान गैर-खाली एरे हो र सबै तत्वहरू संख्या हुन् कि होइनन् भनेर जाँच गर्छ।

### प्रयोगको केस

योग, औसत, वा अन्य संख्यात्मक समष्टि निकाल्नु अघि प्रयोगकर्ता-प्रदान गरिएको वा API-प्रदान गरिएको डेटा गैर-खाली
संख्याहरूको एरे हो भन्ने सुनिश्चित गर्न मान्य गर्नुहोस्।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> संख्यात्मक गणनाहरू गर्नु अघि अज्ञात एरेहरू मान्य गर्न `areNumbers` प्रयोग गर्नुहोस्; यसले खाली एरेहरूका लागि र कुनै
> पनि गैर-संख्या मान भएको एरेका लागि `false` फर्काउँछ।

### फाइदाहरू

- इनपुट गैर-खाली एरे भएको र प्रत्येक तत्व संख्या भएको अवस्थामा मात्र `true` फर्काउँछ।
- खाली एरे र एरे नभएका इनपुटहरू अस्वीकार गरेर गलत सकारात्मक परिणामहरू रोक्छ।
- रनटाइम त्रुटिहरूबाट बच्न संख्यात्मक अपरेसनहरू (जस्तै, जोड्ने, औसत निकाल्ने) अघि गार्डको रूपमा उपयोगी।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `areNumbers(array)`

प्यारामिटरहरू:

- `array`: संख्या तत्वहरू छन् कि छैनन् भनेर जाँच गर्नुपर्ने एरे।

### स्थानीय फङ्सन आयात

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```
