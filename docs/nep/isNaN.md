# isNaN

## विवरण

स्ट्रिङहरू रूपान्तरण नगरी प्रदान गरिएको `value` `number` प्रकारको `NaN` हो कि होइन निर्धारण गर्छ।

### प्रयोगको केस

अविश्वसनीय वा ढिलो टाइप गरिएको इनपुट (जस्तै API payloads, form values, parsed JSON) लाई मान्यकरण गरेर विशेष `NaN` मान
पत्ता लगाउने र त्यसलाई स्पष्ट रूपमा ह्यान्डल गर्ने, जबकि गैर-सङ्ख्यात्मक इनपुटलाई `NaN` नभएको रूपमा व्यवहार गर्ने।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> इनपुट वास्तवमै `number` हो भन्ने सुनिश्चित गर्दै (स्ट्रिङ-देखि-सङ्ख्या रूपान्तरण बिना) विशेष सङ्ख्यात्मक मान `NaN`
> पत्ता लगाउनुपर्ने बेला `isNaN` प्रयोग गर्नुहोस्।

### फाइदाहरू

- गैर-सङ्ख्यात्मक मानहरू (जस्तै स्ट्रिङ) लाई सङ्ख्यामा जबर्जस्ती रूपान्तरण नगरी कुनै मान `NaN` हो कि होइन जाँच्छ।
- `number` प्रकारका र `NaN` दुवै भएका मानहरूका लागि मात्र `true` फर्काउँछ।
- `unknown` इनपुटका लागि सुरक्षित छ र अप्रत्यक्ष रूपान्तरणबाट हुने गलत सकारात्मक नतिजाबाट बचाउँछ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `isNaN(value)`

प्यारामिटरहरू:

- `value`: `number` प्रकारको `NaN` हो कि होइन भनेर जाँच गर्नुपर्ने मान।

### स्थानीय फङ्सन आयात

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // सत्य
console.log(isNaN(b)); // असत्य
console.log(isNaN(c)); // असत्य

if (isNaN(a)) {
  // a एउटा संख्या हो र विशेष रूपमा NaN हो
}
```

### ग्लोबल अब्जेक्ट आयात

फङ्सनहरूलाई ग्लोबल अब्जेक्ट मेथडका रूपमा आयात गर्न प्रयोग गर्नुहोस्:


- `Type.isNaN(value)`
