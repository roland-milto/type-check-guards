# areArrays

## विवरण

`areArrays` ले कुनै मान सबै आइटमहरू एरे भएका, भरिएको दुई-आयामिक एरे हो कि होइन भनेर निर्धारण गर्छ।

### प्रयोगको केस

पङ्क्ति/स्तम्भ अपरेसनहरू गर्नु अघि तालिकात्मक वा म्याट्रिक्स-जस्तो इनपुटहरू (जस्तै, CSV पङ्क्तिहरू, ग्रिड डेटा, वा
समूहबद्ध सूचीहरू) प्रमाणीकरण गर्न `areArrays` प्रयोग गर्नुहोस्; यदि इनपुट एरे होइन, खाली छ, वा कुनै पनि गैर-एरे तत्व
समावेश गर्छ भने यसले `false` फर्काउँछ।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> नेस्टेड एरेहरूमा इटरेट वा इन्डेक्सिङ गर्नु अघि कुनै मान खाली नभएको 2D एरे हो र प्रत्येक पङ्क्ति एरे हो भन्ने सुनिश्चित
> गर्न आवश्यक हुँदा `areArrays` प्रयोग गर्नुहोस्।

### फाइदाहरू

- इनपुट खाली नभएको दुई-आयामिक एरे हो र प्रत्येक तत्व स्वयं एरे हो भन्ने कुरा प्रमाणीकरण गर्छ।
- गार्डहरू र छिटो निकासका लागि उपयुक्त सरल बूलियन परिणाम (`true`/`false`) फर्काउँछ।
- पछि कोडले नेस्टेड एरे अपरेसनहरू (जस्तै, पङ्क्तिहरू म्याप गर्ने) मान्छ भन्ने अवस्थामा रनटाइम त्रुटिहरू रोक्न मद्दत
  गर्छ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `areArrays(array)`

प्यारामिटरहरू:

- `array`: जाँच गर्नुपर्ने इनपुट।

### स्थानीय फङ्सन आयात

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value एरेहरूलाई तत्वका रूपमा भएको 2D एरे हो
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```
