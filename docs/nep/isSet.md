# isSet

## विवरण

दिइएको मान `Set` हो कि होइन भनेर निर्धारण गर्छ।

### प्रयोगको केस

बाह्य स्रोतहरू (जस्तै, JSON parsing, प्रयोगकर्ता इनपुट, वा third-party APIs) बाट आएका इनपुटहरू मान्यकरण गर्नुहोस् ताकि
`Set` अपरेसनहरू गर्नु अघि मान `Set` हो भन्ने सुनिश्चित गर्न सकियोस्।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> `.add`, `.has`, वा `.size` जस्ता `Set`-विशेष API हरू कल गर्नु अघि `unknown` मानहरूलाई साँघुरो बनाउन `isSet` प्रयोग
> गर्नुहोस्।

### फाइदाहरू

- कुनै मान `Set` हो कि होइन भन्ने पुष्टि गर्न सरल रनटाइम जाँच प्रदान गर्छ।
- मान `Set` नभएको अवस्थामा प्रारम्भमै शाखाकरण गर्न अनुमति दिएर टाइप त्रुटिहरू रोक्न मद्दत गर्छ।
- कुनै पनि `Set` सामग्री (खाली वा भरिएको) सँग काम गर्छ र निरन्तर रूपमा `true`/`false` फर्काउँछ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `isSet(value)`

प्यारामिटरहरू:

- `value`: जाँच गर्नुपर्ने मान।

### स्थानीय फङ्सन आयात

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // a रनटाइममा Set हो
  console.log(a.size);
}

console.log(isSet(b)); // false
```

- `Type.isSet(value)`
