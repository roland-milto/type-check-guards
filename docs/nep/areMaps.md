# areMaps

## विवरण

`areMaps` ले दिइएको एरे खाली छैन र यसको सबै तत्वहरू `Map` का इन्स्ट्यान्स हुन् कि होइनन् भन्ने निर्धारण गर्छ।

### प्रयोगको केस

अज्ञात इनपुट (जस्तै, JSON parsing, external APIs, वा dynamic sources बाट) लाई `Map` वस्तुहरूको खाली नभएको सूचीका रूपमा
व्यवहार गर्नु अघि प्रमाणीकरण गर्नु।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> खाली एरेका लागि `false` फर्काउँछ; एरे भरिएको र हरेक तत्व `Map` भएमा मात्र `true` फर्काउँछ।

### फाइदाहरू

- हरेक तत्व `Map` को इन्स्ट्यान्स हो भन्ने सुनिश्चित गर्छ, र सम्पूर्ण एरेले जाँच पास गरेमा मात्र `true` फर्काउँछ।
- डिजाइनमै खाली एरेहरू अस्वीकार गर्छ, जसले “डाटा छैन” लाई वैध इनपुटका रूपमा गल्तीले स्वीकारिनबाट रोक्छ।
- सङ्ग्रहभरि `Map`-विशेष अपरेसनहरू (जस्तै, `.get()`, `.set()`, iteration) गर्ने अघि गार्डका रूपमा उपयोगी हुन्छ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `areMaps(array)`

प्यारामिटरहरू:

- `array`: जाँच गर्नुपर्ने एरे।

### स्थानीय फङ्सन आयात

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // items रनटाइममा Map इन्स्टेन्सहरूको गैर-खाली एरे भएको सुनिश्चित हुन्छ
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // यसका लागि false: खाली एरेहरू, वा कुनै पनि गैर-Map मान समावेश गर्ने एरेहरू
}

```
