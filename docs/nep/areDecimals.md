# areDecimals

## विवरण

एरेका सबै तत्वहरू दशमलव संख्या हुन् कि होइनन् र एरे भरिएको छ कि छैन जाँच्छ, र `true` वा `false` फर्काउँछ।

### प्रयोगको केस

प्रयोगकर्ताले उपलब्ध गराएका सूचीहरू (जस्तै, CSV स्तम्भहरू वा फारम इनपुटहरू) प्रमाणीकरण गरेर एरे खाली छैन र प्रत्येक
प्रविष्टि दशमलव मान हो भन्ने सुनिश्चित गर्नुहोस्, त्यसपछि मात्र पार्सिङ वा गणना गर्नुहोस्।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> `unknown[]` खाली नभएको र प्रत्येक तत्व दशमलव प्रतिनिधित्व हो भन्ने छिटो बूलियन जाँच चाहिँदा `areDecimals` प्रयोग
> गर्नुहोस्।

### फाइदाहरू

- आइटमहरू प्रमाणीकरण गर्नु अघि इनपुट भरिएको एरे हो भन्ने सुनिश्चित गर्छ, जसले खाली सूचीहरू गल्तीले स्वीकारिनबाट रोक्छ।
- `isDecimal` प्रयोग गरेर प्रत्येक तत्व प्रमाणीकरण गर्छ, त्यसैले मिश्रित वा अवैध मानहरूले तुरुन्तै `false` परिणाम
  दिन्छन्।
- गार्डहरू र छिटो-फर्किने (early-return) प्रमाणीकरण प्रवाहका लागि उपयुक्त सरल बूलियन नतिजा (`true`/`false`) प्रदान गर्छ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `areDecimals(array)`

प्यारामिटरहरू:

- `array`: जाँच गर्नुपर्ने एरे।

### स्थानीय फङ्सन आयात

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // सत्य
console.log(areDecimals(b)); // असत्य
console.log(areDecimals(c)); // असत्य
```
