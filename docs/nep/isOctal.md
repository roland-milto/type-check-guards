# isOctal

## विवरण

कुनै मान मान्य अष्टाधारी लिटरल स्ट्रिङ (जस्तै `0o755`) हो कि होइन निर्धारण गर्छ।

### प्रयोगको केस

पार्स वा रूपान्तरण गर्नु अघि अष्टाधारी लिटरल स्ट्रिङका रूपमा व्यक्त हुनैपर्ने प्रयोगकर्ता इनपुट वा कन्फिगरेसन मानहरू (
उदाहरणका लागि, `0o644` जस्ता फाइल अनुमति मोडहरू) प्रमाणीकरण गर्नु।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> `isOctal` एउटा प्रकार गार्ड हो (`value is string`)। `true` परिणामपछि, TypeScript ले जाँच गरिएको भेरिएबललाई `string` मा
> सीमित (narrow) गर्छ।

### फाइदाहरू

- कडा प्रकार गार्ड प्रदान गर्छ: इनपुट अष्टाधारी लिटरल ढाँचासँग मिल्ने स्ट्रिङ हुँदा मात्र `true` फर्काउँछ।
- खाली स्ट्रिङ र अगाडि/पछाडि ह्वाइटस्पेस (ASCII नियन्त्रण/स्पेस) भएका स्ट्रिङहरू अस्वीकार गर्छ, जसले अनायास मिलान हुने
  सम्भावना घटाउँछ।
- `0o`/`0O` उपसर्गका लागि वैकल्पिक चिन्हलाई समर्थन गर्छ र केस-इन्सेन्सिटिभ छ।
- स्ट्रिङ नभएका इनपुटहरूमा त्रुटि फ्याँक्नुको सट्टा `false` फर्काएर लचिलो व्यवहार गर्छ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `isOctal(value)`

प्यारामिटरहरू:

- `value`: जाँच गर्नुपर्ने मान।

### स्थानीय फङ्सन आयात

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); // सत्य
console.log(isOctal(b)); // सत्य
console.log(isOctal(c)); // असत्य
console.log(isOctal(d)); // असत्य

if (isOctal(a)) {
  // यहाँ a स्ट्रिङ हो
  const normalized = a.toLowerCase();
  console.log(normalized);
}

```
