# isTrue

## विवरण

`isTrue` ले दिइएको मान `true` सँग कडाइका साथ बराबर छ कि छैन भनेर निर्धारण गर्छ।

### प्रयोगको केस

फ्ल्यागहरू, फिचर टगलहरू, वा कन्फिगरेसन मानहरू भ्यालिडेट गर्न `isTrue` प्रयोग गर्नुहोस्, जहाँ केवल लिटरल `true` मात्र
स्वीकारिनुपर्छ र बाँकी सबैलाई `false` को रूपमा व्यवहार गर्नुपर्छ।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> केवल बुलियन लिटरल `true` मात्र स्वीकार गर्नुपर्दा `isTrue` प्रयोग गर्नुहोस्, केवल truthy मानहरू होइन।

### फाइदाहरू

- बुलियन लिटरल `true` का लागि कडा जाँच प्रदान गर्छ (coercion बिना)।
- `true` लाई `1`, `"true"`, वा `{}` जस्ता truthy मानहरूबाट छुट्याउन मद्दत गर्छ।
- गार्डहरू र भ्यालिडेसन पाइपलाइनहरूका लागि उपयुक्त सरल, पूर्वानुमेय व्यवहार।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `isTrue(value)`

प्यारामिटरहरू:

- `value`: जाँच गर्नुपर्ने मान।

### स्थानीय फङ्सन आयात

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // सत्य
const b = isTrue(1);         // असत्य
const c = isTrue("true");   // असत्य

if (isTrue(a)) {
  // यहाँ a सत्य छ
}
```
