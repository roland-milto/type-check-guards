# areOctals

## विवरण

`areOctals` ले प्रदान गरिएको मान मान्य अष्टाधारी स्ट्रिङहरूको गैर-खाली एरे हो कि होइन भनेर निर्धारण गर्छ।

### प्रयोगको केस

प्रयोगकर्ता इनपुट, कन्फिगरेसन मानहरू, वा API payloads प्रमाणीकरण गर्दा `areOctals` प्रयोग गर्नुहोस्, जहाँ अष्टाधारी
लिटरलहरू (जस्तै `0o755` जस्ता फाइल अनुमति मोडहरू) समावेश हुनैपर्छ, र तपाईं खाली एरे वा कुनै पनि अमान्य प्रविष्टि भए
`false` फर्काएर अस्वीकार गर्न चाहनुहुन्छ।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> `areOctals` प्रयोग गरेर रूपान्तरण गर्नु अघि (जस्तै `Number(...)` वा कस्टम पार्सिङमार्फत) प्रत्येक प्रविष्टि मान्य
> अष्टाधारी स्ट्रिङ भएको गैर-खाली `unknown[]` छ भन्ने सुनिश्चित गर्नुहोस्।

### फाइदाहरू

- कुनै मान गैर-खाली एरे हो र त्यसका प्रत्येक तत्व अष्टाधारी (octal) स्ट्रिङ हो भन्ने कुरा प्रमाणीकरण गर्छ, सबै आइटम पास
  हुँदा मात्र `true` फर्काउँछ।
- छिट्टै असफल हुन्छ: कुनै गैर-अष्टाधारी तत्व भेटिने बित्तिकै `false` फर्काउँछ।
- अष्टाधारी स्ट्रिङहरू पार्स वा रूपान्तरण गर्नु अघि गार्डको रूपमा उपयोगी हुन्छ, जसले रनटाइम त्रुटि र असंगत इनपुट
  ह्यान्डलिङबाट बचाउँछ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `areOctals(array)`

प्यारामिटरहरू:

- `array`: जाँच गर्नुपर्ने मान।

### स्थानीय फङ्सन आयात

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value अष्टाधारी स्ट्रिङहरूको खाली नभएको एरे हो
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```
