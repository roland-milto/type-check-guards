# areNaNs

## विवरण

`areNaNs` ले एरेका सबै तत्वहरू `NaN` छन् कि छैनन् भनेर जाँच गर्छ र हरेक तत्व `NaN` भएमा मात्र `true` फर्काउँछ।

### प्रयोगको केस

`NaN` लाई sentinel मानका रूपमा प्रयोग गरिएको आउने डेटा प्रमाणीकरण गर्नुहोस्, जहाँ तपाईंले सम्पूर्ण एरे पूर्ण रूपमा `NaN`
मात्रबाट बनेको छ भन्ने सुनिश्चित गर्नुपर्छ (जस्तै, सबै मान हराएको संख्यात्मक शृङ्खला पत्ता लगाउने)।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> स्ट्रिङ-देखि-सङ्ख्या रूपान्तरण (coercion) बिना एरेमा केवल संख्यात्मक `NaN` मान मात्र छ भनेर प्रमाणीकरण गर्नुपर्ने बेला
`areNaNs` प्रयोग गर्नुहोस्।

### फाइदाहरू

- हरेक तत्व `NaN` हुँदा मात्र `true` फर्काउँछ (कडाइका साथ सबै-तत्व जाँच)।
- स्ट्रिङलाई सङ्ख्यामा रूपान्तरण (coerce) गर्दैन; "NaN" जस्ता मानहरू non-`NaN` नै रहन्छन् र नतिजा `false` बनाउँछन्।
- भरिएका नभएका (non-filled) एरेहरूका लागि `false` फर्काउँछ, जसले खाली इनपुटमा अनायासै `true` हुने अवस्थालाई रोक्छ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `areNaNs(array)`

प्यारामिटरहरू:

- `array`: `NaN` मानहरूका लागि जाँच गर्नुपर्ने एरे।

### स्थानीय फङ्सन आयात

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // सत्य
const b = areNaNs([NaN, 1, NaN]); // असत्य
const c = areNaNs([NaN, "NaN", NaN]); // असत्य
const d = areNaNs([NaN, null, NaN]); // असत्य
const e = areNaNs([] as unknown[]); // असत्य

```
