# isBinary

## विवरण

`isBinary` ले कुनै मान बाइनरी स्ट्रिङ हो कि होइन (वैकल्पिक रूपमा `0b`/`0B` उपसर्गसहित) निर्धारण गर्छ र `true` वा `false`
फर्काउँछ।

### प्रयोगको केस

थप प्रशोधन गर्नु अघि प्रयोगकर्ताले उपलब्ध गराएका स्ट्रिङहरू (जस्तै, form fields, CLI args, config values) ले केवल बाइनरी
अंकहरू मात्र प्रतिनिधित्व गर्छन् कि छैनन्, र वैकल्पिक रूपमा `0b`/`0B` उपसर्गसहित छन् कि छैनन् भन्ने सुनिश्चित गर्न
मान्यकरण गर्नुहोस्।

> **TypeScript प्रयोगकर्ताहरूका लागि संकेत:**
>
> अवैध इनपुटबाट बच्न स्ट्रिङलाई `BigInt`/`Number` मा parse वा convert गर्नु अघि type guard को रूपमा `isBinary` प्रयोग
> गर्नुहोस्।

### फाइदाहरू

- `0b`/`0B` उपसर्गसहित वा उपसर्गबिना बाइनरी स्ट्रिङहरू स्वीकार गर्छ।
- खाली स्ट्रिङहरू र अगाडि/पछाडि whitespace (ASCII ≤ 32) भएको स्ट्रिङहरू अस्वीकार गर्छ।
- throw नगरी `true`/`false` फर्काउँछ, जसले अज्ञात इनपुटहरूका लागि यसलाई सुरक्षित बनाउँछ।

## प्रयोग

### सिन्ट्याक्स

फङ्सन:

- `isBinary(value)`

प्यारामिटरहरू:

- `value`: जाँच गर्नुपर्ने मान।

### स्थानीय फङ्सन आयात

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // सत्य
const b = isBinary("1010");   // सत्य
const c = isBinary("0b1020"); // असत्य
const d = isBinary(0b1010);     // असत्य

```

### ग्लोबल अब्जेक्ट आयात

फङ्सनहरूलाई ग्लोबल अब्जेक्ट मेथडका रूपमा आयात गर्न प्रयोग गर्नुहोस्:

```ts

```

त्यसपछि निम्न मेथड ग्लोबली उपलब्ध हुनेछ:

- `Type.isBinary(value)`
