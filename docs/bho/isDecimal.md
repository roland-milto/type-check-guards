# isDecimal

## विवरण

`isDecimal` जाँचेला कि कवनो मान दशमलव स्ट्रिंग रिप्रेजेंटेशन बा कि ना, जेकरा में आगे/पीछे व्हाइटस्पेस ना होखे आ दशमलव
फॉर्मेट वैध होखे।

### उपयोग

फॉर्म फील्ड, API पेलोड, भा कॉन्फिगरेशन वैल्यू के वैलिडेट करीं जेकरा के दशमलव स्ट्रिंग (वैकल्पिक साइन सहित) के रूप में,
बिना कवनो आसपास के व्हाइटस्पेस के, पार्स भा स्टोर करे से पहिले देहल जरूरी होखे।

> **TypeScript उपयोगकर्ता खातिर संकेत:**
>
> `isDecimal` के इस्तेमाल यूजर इनपुट के कन्वर्ट करे से पहिले वैलिडेट करे खातिर करीं (जइसे `Number(value)` से), खासकर तब
> जब व्हाइटस्पेस के अस्वीकार कइल जरूरी होखे।

### फायदे

- सख्ती से जाँचेला कि इनपुट एगो स्ट्रिंग बा आ दशमलव-लिटरल पैटर्न से मेल खाला।
- अस्पष्ट पार्सिंग से बचे खातिर आगे आ पीछे के व्हाइटस्पेस (कंट्रोल कैरेक्टर समेत) के अस्वीकार करेला।
- रेगेक्स चलावे से पहिले तेज प्री-चेक (टाइप चेक आ पहिला/आखिरी कैरेक्टर) करेला।
- गार्ड आ इनपुट वैलिडेशन खातिर उपयुक्त एगो सरल बूलियन नतीजा (`true`/`false`) लौटावेला।

## उपयोग

### सिंटैक्स

फंक्शन:

- `isDecimal(value)`

पैरामीटर:

- `value`: दशमलव स्ट्रिंग फॉर्मेट खातिर जाँच करे वाला मान।

### लोकल फंक्शन इम्पोर्ट

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // इहाँ v एगो स्ट्रिंग बा (रनटाइम पर जाँचल गइल)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन सभ के ग्लोबल ऑब्जेक्ट मेथड के रूप में इम्पोर्ट करे खातिर उपयोग करीं:

```ts
import "@type-check/guards/register-global-object.mjs";
```

तब निम्नलिखित मेथड ग्लोबल रूप से उपलब्ध होई:

- `Type.isDecimal(value)`
