# isHexadecimal

## विवरण

`isHexadecimal` जाँचेला कि दिहल मान अनिवार्य `0x`/`0X` प्रीफिक्स वाला हेक्साडेसिमल स्ट्रिंग लिटरल ह कि ना।

### उपयोग

कॉन्फिगरेशन मान, API पेलोड फील्ड, भा CLI आर्ग्युमेंट के वैलिडेट करे खातिर `isHexadecimal` के इस्तेमाल करीं, जहाँ मान
हेक्साडेसिमल स्ट्रिंग लिटरल (जइसे IDs, masks, भा addresses) के रूप में दिहल जरूरी होखे आ ओकरा चारो ओर व्हाइटस्पेस ना
होखे।

> **TypeScript उपयोगकर्ता खातिर संकेत:**
>
> जब रउआँ के यूजर इनपुट भा सीरियलाइज़्ड डेटा के सख्त हेक्साडेसिमल लिटरल स्ट्रिंग ( `0x`/`0X` प्रीफिक्स समेत) के रूप में
> पार्स भा कन्वर्ट करे से पहिले वैलिडेट करे के होखे, तब `isHexadecimal` के इस्तेमाल करीं।

### फायदे

- जाँचेला कि कउनो मान स्ट्रिंग हवे आ सख्त हेक्साडेसिमल लिटरल फॉर्मेट से मेल खाला ( `0x`/`0X` प्रीफिक्स जरूरी बा)।
- आगे भा पीछे के व्हाइटस्पेस वाला स्ट्रिंग के खारिज करेला, जेकरा से पैड कइल इनपुट गलती से स्वीकार होखे से बचाव होला।
- वैकल्पिक साइन के सपोर्ट करेला आ प्रीफिक्स आ अंक खातिर केस-इन्सेंसिटिव बा, आ अनुमानित रूप से `true`/`false` लौटावेला।

## उपयोग

### सिंटैक्स

फंक्शन:

- `isHexadecimal(value)`

पैरामीटर:

- `value`: जवन मान के जाँचल जाई।

### लोकल फंक्शन इम्पोर्ट

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // सही
isHexadecimal("-0Xff"); // सही
isHexadecimal("1A2B"); // गलत (उपसर्ग नइखे)
isHexadecimal(" 0x1A2B"); // गलत (आगे के खाली जगह)
isHexadecimal(0x1a2b); // गलत (स्ट्रिंग नइखे)
```
