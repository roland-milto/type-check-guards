# isRegEx

## विवरण

तय करेला कि दिहल गइल वैल्यू `RegExp` के इंस्टेंस बा कि ना।

### उपयोग

यूजर से दिहल भा डायनामिक वैल्यू (जइसे कॉन्फिगरेशन, API पेलोड, प्लगइन इनपुट) के रेगुलर एक्सप्रेशन मान के इस्तेमाल करे से
पहिले वैलिडेट करीं।

> **TypeScript उपयोगकर्ता खातिर संकेत:**
>
> `isRegEx` के इस्तेमाल `unknown` (भा यूनियन) वैल्यू के नैरो करे खातिर करीं, RegExp-विशेष प्रॉपर्टी भा मेथड इस्तेमाल करे
> से पहिले; ई `true` खाली ओही वैल्यू खातिर लौटावेला जे `RegExp` के इंस्टेंस होखे।

### फायदे

- ई एगो सरल रनटाइम टाइप गार्ड देला जे जांचेला कि कउनो वैल्यू `RegExp` बा कि ना।
- जब कोड के रेगुलर एक्सप्रेशन के उम्मीद होखे (जइसे `test`, `exec` कॉल करे से पहिले, भा `source` पढ़े से पहिले) त गलती से
  बचावे में मदद करेला।
- रेगेक्स लिटरल आ `new RegExp(...)` से बनावल इंस्टेंस दुनो के साथ काम करेला।
- नॉन-रेगेक्स इनपुट खातिर थ्रो कइले बिना साफ बूलियन रिजल्ट (`true`/`false`) लौटावेला।

## उपयोग

### सिंटैक्स

फंक्शन:

- `isRegEx(value)`

पैरामीटर:

- `value`: जवन वैल्यू के जांचल जाई।

### लोकल फंक्शन इम्पोर्ट

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  // input इहाँ RegExp बा
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन सभ के ग्लोबल ऑब्जेक्ट मेथड के रूप में इम्पोर्ट करे खातिर उपयोग करीं:


तब निम्नलिखित मेथड ग्लोबल रूप से उपलब्ध होई:

- `Type.isRegEx(value)`
