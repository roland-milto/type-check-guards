# areArrays

## विवरण

`areArrays` तय करेला कि कवनो मान एगो भरल दू-आयामी ऐरे बा कि ना, जेकर आइटम सभे ऐरे हउवें।

### उपयोग

पंक्ति/स्तंभ ऑपरेशन करे से पहिले टेबुलर भा मैट्रिक्स-जइसन इनपुट (जइसे, CSV पंक्ति, ग्रिड डेटा, भा समूहबद्ध सूची) के
वैलिडेट करे खातिर `areArrays` के इस्तेमाल करीं; अगर इनपुट ऐरे ना होखे, खाली होखे, भा एको गैर-ऐरे तत्व रखे, त ई `false`
लौटावेला।

> **TypeScript उपयोगकर्ता खातिर संकेत:**
>
> जब रउआ के ई पक्का करे के होखे कि कवनो मान एगो खाली ना होखे वाला 2D ऐरे बा आ हर पंक्ति एगो ऐरे बा, तब नेस्टेड ऐरे में
> इटरेट करे भा इंडेक्स करे से पहिले `areArrays` के इस्तेमाल करीं।

### फायदे

- ई जाँचेला कि इनपुट एगो खाली ना होखे वाला दू-आयामी ऐरे बा, जहाँ हर तत्व खुद एगो ऐरे बा।
- गार्ड आ जल्दी निकास खातिर उपयुक्त एगो सादा बूलियन नतीजा (`true`/`false`) लौटावेला।
- बाद के कोड जब नेस्टेड ऐरे ऑपरेशन (जइसे, पंक्ति के मैपिंग) मान के चलेला, तब रनटाइम त्रुटि से बचावे में मदद करेला।

## उपयोग

### सिंटैक्स

फंक्शन:

- `areArrays(array)`

पैरामीटर:

- `array`: जाँचल जाए वाला इनपुट।

### लोकल फंक्शन इम्पोर्ट

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value एगो 2D array हवे जवना में elements के रूप में arrays बा
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन सभ के ग्लोबल ऑब्जेक्ट मेथड के रूप में इम्पोर्ट करे खातिर उपयोग करीं:

```ts

```

तब निम्नलिखित मेथड ग्लोबल रूप से उपलब्ध होई:

- `Type.areArrays(array)`
