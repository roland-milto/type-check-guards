# isBinary

## विवरण

`isBinary` तय करेला कि कउनो मान बाइनरी स्ट्रिंग बा कि ना (वैकल्पिक रूप से `0b`/`0B` प्रीफिक्स सहित) आ `true` भा `false`
लौटावेला।

### उपयोग

यूजर द्वारा दिहल स्ट्रिंग (जइसे, फॉर्म फील्ड, CLI args, config values) के वैलिडेट करीं, ताकि आगे के प्रोसेसिंग से पहिले
ई पक्का हो सके कि ऊ खाली बाइनरी अंक ही दर्शावत बा, आ वैकल्पिक रूप से `0b`/`0B` प्रीफिक्स के साथ।

> **TypeScript उपयोगकर्ता खातिर संकेत:**
>
> `BigInt`/`Number` में पार्स भा कन्वर्ट करे से पहिले `isBinary` के टाइप गार्ड के रूप में इस्तेमाल करीं, ताकि अमान्य
> इनपुट से बचल जा सके।

### फायदे

- `0b`/`0B` प्रीफिक्स के साथ भा बिना, बाइनरी स्ट्रिंग स्वीकार करेला।
- खाली स्ट्रिंग आ अगिला/पाछिला व्हाइटस्पेस (ASCII ≤ 32) वाला स्ट्रिंग के अस्वीकार करेला।
- कउनो exception फेंके बिना `true`/`false` लौटावेला, एहसे अनजान इनपुट खातिर सुरक्षित बा।

## उपयोग

### सिंटैक्स

फंक्शन:

- `isBinary(value)`

पैरामीटर:

- `value`: जवन मान के जांचल जाई।

### लोकल फंक्शन इम्पोर्ट

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // सही
const b = isBinary("1010");   // सही
const c = isBinary("0b1020"); // गलत
const d = isBinary(0b1010);     // गलत

```
