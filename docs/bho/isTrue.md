# isTrue

## विवरण

`isTrue` तय करेला कि दिहल गइल मान सख्ती से `true` के बराबर बा कि नाहीं.

### उपयोग

फ्लैग, फीचर टॉगल, भा कॉन्फिगरेशन मान के वैलिडेट करे खातिर `isTrue` के इस्तेमाल करीं, जहाँ खाली लिटरल `true` के स्वीकार
कइल जाव आ बाकी सभ के `false` मानल जाव.

> **TypeScript उपयोगकर्ता खातिर संकेत:**
>
> `isTrue` के तब इस्तेमाल करीं जब रउआ के खाली बूलियन लिटरल `true` स्वीकार करे के होखे, खाली truthy मान नाहीं.

### फायदे

- बूलियन लिटरल `true` खातिर सख्त जाँच देला (कोई कोएर्शन नाहीं).
- `true` के `1`, `"true"`, भा `{}` जइसन truthy मान से अलग पहिचाने में मदद करेला.
- सरल, अनुमान लगावे लायक व्यवहार, जे गार्ड आ वैलिडेशन पाइपलाइन खातिर उपयुक्त बा.

## उपयोग

### सिंटैक्स

फंक्शन:

- `isTrue(value)`

पैरामीटर:

- `value`: जवन मान के जाँचल जाई.

### लोकल फंक्शन इम्पोर्ट

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // सही
const b = isTrue(1);         // गलत
const c = isTrue("true");   // गलत

if (isTrue(a)) {
  // इहाँ a सही बा
}
```
