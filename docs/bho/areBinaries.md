# areBinaries

## विवरण

जाँचेला कि दिहल मान एगो गैर-खाली वैध बाइनरी स्ट्रिंगन के सरणी बा कि ना, आ `true` खाली तबे लौटावेला जब सभे आइटम वैलिडेशन
पास करेला।

### उपयोग

`areBinaries` के इस्तेमाल तब करीं जब रउआँ के कवनो अज्ञात सूची (जइसे JSON, फॉर्म, भा API से) मिले आ रउआँ के पार्स भा
प्रोसेस करे से पहिले ई पक्का करे के होखे कि ई बाइनरी स्ट्रिंगन के एगो गैर-खाली सरणी बा।

> **TypeScript उपयोगकर्ता खातिर संकेत:**
>
> `areBinaries` के इस्तेमाल अज्ञात इनपुट के वैलिडेट करे खातिर करीं, बाइनरी स्ट्रिंगन के नंबर/BigInts में बदले से पहिले;
> ई पक्का करेला कि सरणी गैर-खाली बा आ हर तत्व एगो वैध बाइनरी स्ट्रिंग बा।

### फायदे

- ई जाँचेला कि कवनो मान एगो गैर-खाली सरणी (array) बा जवना में हर तत्व एगो वैध बाइनरी स्ट्रिंग बा।
- एगो सादा बूलियन नतीजा (`true`/`false`) लौटावेला, जे गार्ड, जल्दी रिटर्न, आ इनपुट वैलिडेशन खातिर उपयुक्त बा।
- जवन सरणी में कवनो गैर-बाइनरी प्रविष्टि होखे, ओहके खारिज क के आगे होखे वाला पार्सिंग गलती से बचावेला।

## उपयोग

### सिंटैक्स

फंक्शन:

- `areBinaries(array)`

पैरामीटर:

- `array`: जवन मान के जाँचल जाई।

### लोकल फंक्शन इम्पोर्ट

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // सही
console.log(areBinaries(b)); // गलत
console.log(areBinaries([])); // गलत
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट


तब निम्नलिखित मेथड ग्लोबल रूप से उपलब्ध होई:
