# isObject

## Описание

Определя дали дадена `value` е `object` (с изключение на `null`).

### Случай на употреба

Използвайте `isObject`, за да валидирате неизвестни входни данни (напр. парснат JSON, отговори от API, payload-и на
събития) преди достъп до свойства, като гарантирате, че стойността е обект, а не `null`.

> **Бележка за потребителите на TypeScript:**
>
> `isObject` е runtime guard, който връща boolean; той не стеснява типа до конкретна форма на обект. Комбинирайте го с
> допълнителни проверки (напр. наличие на свойства), когато ви е нужно по-строго типизиране.

### Предимства

- Връща `true` само за не-`null` стойности, чийто `typeof` е `"object"`.
- Предотвратява често срещания капан в JavaScript, при който `null` иначе би бил третиран като обект.
- Работи за обикновени обекти и вградени инстанции на обекти (напр. `Date`, `RegExp`).
- Проста и бърза проверка по време на изпълнение, подходяща за защитно програмиране и валидиране на входни данни.

## Използване

### Синтаксис

Функция:

- `isObject(value)`

Параметри:

- `value`: Стойността, която трябва да бъде проверена дали е `object`.

### Локален импорт на функция

```ts
import { isObject } from "@type-check/guards";

const input: unknown = { a: 1 };

if (isObject(input)) {
  // input е ненулев обект по време на изпълнение
  console.log("Object detected");
} else {
  console.log("Not an object");
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isObject(value)`
