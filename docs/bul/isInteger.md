# isInteger

## Описание

Определя дали дадена `value` е безопасно цяло число.

### Случай на употреба

Валидирайте недоверен вход (напр. параметри на заявка, JSON payload-и, променливи на средата), преди да го използвате
като цяло число за индекси на масиви, странициране, броячи или идентификатори в база данни.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isInteger`, за да валидирате неизвестен вход, преди да го третирате като числово цяло число; връща `true`
> само за стойности, при които `typeof value === "number"` и `Number.isSafeInteger(value)`.

### Предимства

- Проверява както типа, така и числовата безопасност: връща `true` само когато входът е число и безопасно цяло число.
- Предотвратява често срещани капани при числовото преобразуване: низове като "5" правилно връщат `false`.
- Отхвърля нецели и небезопасни цели числа, което го прави подходящо за идентификатори, броячи и индексиране на масиви.

## Използване

### Синтаксис

Функция:

- `isInteger(value)`

Параметри:

- `value`: Стойността, която да се провери дали е цяло число.

### Локален импорт на функция

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      // вярно
const b = isInteger(-100);   // вярно
const c = isInteger("5");    // невярно
const d = isInteger(5.5);    // невярно
const e = isInteger(null);   // невярно

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isInteger(value)`
