# isSet

## Описание

Определя дали дадена стойност е `Set`.

### Случай на употреба

Валидирайте входни данни от външни източници (напр. парсване на JSON, потребителски вход или API-та на трети страни), за
да се уверите, че стойността е `Set`, преди да извършвате операции със `Set`.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isSet`, за да стесните стойности от тип `unknown`, преди да извиквате API-та, специфични за `Set`, като
`.add`, `.has` или `.size`.

### Предимства

- Предоставя проста проверка по време на изпълнение, за да потвърди дали дадена стойност е `Set`.
- Помага да се предотвратят грешки от типове, като позволява ранно разклоняване, когато стойността не е `Set`.
- Работи с всякакво съдържание на `Set` (празно или попълнено) и последователно връща `true`/`false`.

## Използване

### Синтаксис

Функция:

- `isSet(value)`

Параметри:

- `value`: Стойността за проверка.

### Локален импорт на функция

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // a е Set по време на изпълнение
  console.log(a.size);
}

console.log(isSet(b)); // false
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isSet(value)`
