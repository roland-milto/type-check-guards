# areOneOfType

## Описание

`areOneOfType` проверява дали всички елементи в непразен масив са от един от посочените runtime типове.

### Случай на употреба

Валидирайте входящи данни (напр. парсиран JSON), при които дадено поле трябва да е непразен масив, чиито елементи са
ограничени до известен набор от примитивни типове; върнете `false`, когато масивът е празен или съдържа какъвто и да е
неразрешен тип.

> **Бележка за потребителите на TypeScript:**
>
> Тази функция връща boolean и не стеснява типовете на елементите на масива по време на компилация; използвайте я като
> стъпка за runtime валидиране преди по-нататъшна обработка.

### Предимства

- Гарантира, че всеки елемент в масив съвпада поне с един разрешен runtime тип, като връща `true` само когато целият
  масив премине проверката.
- Отхвърля невалидни входни данни рано: връща `false`, когато `array` или `types` е празен или не е запълнен масив.
- Полезно за валидиране на колекции със смесени типове (напр. числа и низове) с едно извикване на `areOneOfType`.

## Използване

### Синтаксис

Функция:

- `areOneOfType(array, types)`

Параметри:

- `array`: Масив от елементи, които да бъдат проверени спрямо предоставените типове.
- `types`: Масив от низове, представящи типовете данни, спрямо които да се проверява.

### Локален импорт на функция

```ts
import { areOneOfType } from "@type-check/guards";

const values1: unknown[] = [1, "a", true];
const ok1 = areOneOfType(values1, ["number", "string", "boolean"]);

const values2: unknown[] = [1, "a", {}];
const ok2 = areOneOfType(values2, ["number", "string"]);

const values3: unknown[] = [];
const ok3 = areOneOfType(values3, ["number"]);

console.log({ ok1, ok2, ok3 });
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areOneOfType(array, types)`
