# areSets

## Описание

Проверява дали даден непразен масив съдържа само инстанции на `Set`, като връща `true`, ако е така, и `false` в противен
случай.

### Случай на употреба

Валидирайте, че стойност (напр. от потребителски вход, парсване на JSON или външни API-та) е непразен масив от обекти
`Set` преди обработване на всеки set.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areSets`, за да валидирате неизвестен вход преди обхождане и извикване на API-та на `Set` (напр. `.size`,
`.has`, `.add`) върху всеки елемент.

### Предимства

- Връща `true` само когато входът е непразен масив и всеки елемент е инстанция на `Set`.
- Предотвратява фалшиви положителни резултати за празни масиви, като връща `false`, когато масивът няма елементи.
- Полезно като проверка по време на изпълнение преди извършване на операции, специфични за `Set`, върху всеки елемент.

## Използване

### Синтаксис

Функция:

- `areSets(array)`

Параметри:

- `array`: Масивът, който трябва да бъде проверен за инстанции на `Set`.

### Локален импорт на функция

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  // a е масив от инстанции на Set по време на изпълнение
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); // невярно
console.log(areSets(c)); // невярно
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areSets(array)`
