# areSymbols

## Описание

Проверява дали входът е запълнен масив, чиито елементи са всички символи, като връща `true` или `false`.

### Случай на употреба

Валидирайте, че поле от конфигурация (напр. списък от уникални ключове, представени като символи) е непразен масив,
съдържащ само символи, преди да го използвате в API, които изискват `symbol[]`.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areSymbols`, за да валидирате неизвестен вход, преди да го третирате като `symbol[]`; функцията връща
`false` за немасиви и празни масиви.

### Предимства

- Връща `true` само когато входът е непразен масив и всеки елемент е символ.
- Предотвратява фалшиви положителни резултати, като отхвърля немасиви и празни масиви чрез вътрешната проверка за
  запълнен масив.
- Полезно като runtime type guard за валидиране на списъци, съдържащи само символи, преди по-нататъшна обработка.

## Използване

### Синтаксис

Функция:

- `areSymbols(array)`

Параметри:

- `array`: Масивът, който трябва да бъде проверен за елементи от тип символ.

### Локален импорт на функция

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  // a е масив само от символи по време на изпълнение
  const first = a[0];
  console.log(typeof first); // "symbol"
}

console.log(areSymbols(b)); // false
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areSymbols(array)`
