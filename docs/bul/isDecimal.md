# isDecimal

## Описание

`isDecimal` проверява дали дадена стойност е десетично низово представяне без водещи/завършващи интервали и с валиден
десетичен формат.

### Случай на употреба

Валидирайте полета във формуляри, API payload-и или конфигурационни стойности, които трябва да бъдат предоставени като
десетичен низ (по избор със знак) без каквито и да било околни интервали, преди да ги парснете или съхраните.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isDecimal`, за да валидирате потребителския вход преди да го конвертирате (напр. с `Number(value)`),
> особено когато интервалите трябва да бъдат отхвърлени.

### Предимства

- Строго валидира, че входът е низ и съответства на шаблон за десетичен литерал.
- Отхвърля водещи и завършващи интервали (включително контролни знаци), за да се избегне двусмислено парсване.
- Бързи предварителни проверки (проверка на типа и първи/последен знак) преди изпълнение на регулярния израз.
- Връща прост булев резултат (`true`/`false`), подходящ за гардове и валидиране на вход.

## Използване

### Синтаксис

Функция:

- `isDecimal(value)`

Параметри:

- `value`: Стойността, която да се провери за формат на десетичен низ.

### Локален импорт на функция

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v е низ тук (валидирано по време на изпълнение)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isDecimal(value)`
