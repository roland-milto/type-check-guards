# isFalse

## Описание

`isFalse` проверява дали дадена стойност е строго равна на булевия литерал `false`.

### Случай на употреба

Валидирайте неизвестни данни (напр. от JSON, параметри на заявка или потребителски вход), при които само изричната
булева стойност `false` трябва да се счита за валиден флаг, а всичко останало да бъде отхвърлено.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isFalse`, когато трябва да приемате само литерала `false` и да отхвърляте всички други „falsy“ стойности;
> функцията връща `true` само при `value === false`.

### Предимства

- Осигурява строгa проверка за булевия литерал `false` без преобразуване на типове.
- Помага да се разграничи `false` от други „falsy“ стойности като `0`, `""`, `null` и `undefined`.
- Подобрява четимостта, като прави намерението изрично при валидиране на неизвестен вход.

## Използване

### Синтаксис

Функция:

- `isFalse(value)`

Параметри:

- `value`: Стойността, която трябва да бъде проверена.

### Локален импорт на функция

```ts
import { isFalse } from "@type-check/guards";

const input: unknown = false;

if (isFalse(input)) {
  // input тук е точно false
  console.log("Got false");
} else {
  console.log("Not false");
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isFalse(value)`
