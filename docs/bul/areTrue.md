# areTrue

## Описание

Проверява дали непразен масив съдържа само булеви стойности `true`.

### Случай на употреба

Използвайте `areTrue`, за да валидирате, че набор от предварителни условия или флагове за функционалности са всички
активирани (всички стойности са `true`) преди да продължите, като третирате празни или неправилно подадени входни данни
като неудовлетворени (`false`).

> **Бележка за потребителите на TypeScript:**
>
> `areTrue` връща `false` за празен масив и за масиви, съдържащи каквато и да е стойност, която не е строго `true`.

### Предимства

- Връща `true` само когато всеки елемент е строго `true` и масивът не е празен.
- Прекратява рано: връща `false` веднага щом бъде намерена стойност, която не е `true`.
- Отхвърля невалидни входни данни (не-масиви или празни масиви), като връща `false`.

## Използване

### Синтаксис

Функция:

- `areTrue(array)`

Параметри:

- `array`: Масивът, който да се провери дали съдържа само стойности `true`.

### Локален импорт на функция

```ts
import { areTrue } from "@type-check/guards";

const a = areTrue([true, true, true]);
const b = areTrue([true, false, true]);
const c = areTrue([]);
const d = areTrue([true, "string" as unknown, true]);

console.log(a, b, c, d);
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areTrue(array)`
