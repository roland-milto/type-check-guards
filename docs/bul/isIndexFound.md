# isIndexFound

## Описание

`isIndexFound` определя дали дадена стойност е неотрицателно цяло число, което означава, че е намерен индекс.

### Случай на употреба

Проверете дали резултатът от търсене представлява използваем индекс (цяло число `>= 0`) преди индексиране в масив или
низ, като предотвратявате случайно използване на `-1` или нечислови стойности.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isIndexFound` след операции като `indexOf`, `findIndex` или персонализирани търсения, при които `-1` (или
> други невалидни стойности) може да означава „не е намерено“. Когато връща `true`, стойността е число и е безопасно да
> се
> използва като индекс за масив/низ.

### Предимства

- Предоставя прост тип-пазач за откриване дали е намерен индекс чрез проверка за неотрицателно цяло число.
- Връща `true` само за валидни стойности, подобни на индекс (цели числа `>= 0`), като отхвърля отрицателни, нецели и
  нечислови стойности.
- Помага да се избегнат грешки тип „off-by-one“ и грешки със стойности-сентинели при работа с API, които връщат `-1` за
  „не е намерено“.

## Използване

### Синтаксис

Функция:

- `isIndexFound(value)`

Параметри:

- `value`: Стойността, която да се провери дали е неотрицателно цяло число.

### Локален импорт на функция

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // idx тук е число и е >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// Типична употреба с indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isIndexFound(value)`
