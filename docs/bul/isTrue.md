# isTrue

## Описание

`isTrue` определя дали дадена стойност е строго равна на `true`.

### Случай на употреба

Използвайте `isTrue`, за да валидирате флагове, feature toggles или конфигурационни стойности, при които трябва да се
приема само литералът `true`, а всичко останало да се третира като `false`.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isTrue`, когато трябва да приемате само булевия литерал `true`, а не просто truthy стойности.

### Предимства

- Осигурява строго проверяване за булевия литерал `true` (без преобразуване).
- Помага да се разграничи `true` от truthy стойности като `1`, `"true"` или `{}`.
- Просто, предвидимо поведение, подходящо за гардове и валидационни пайплайни.

## Използване

### Синтаксис

Функция:

- `isTrue(value)`

Параметри:

- `value`: Стойността за проверка.

### Локален импорт на функция

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // вярно
const b = isTrue(1);         // невярно
const c = isTrue("true");   // невярно

if (isTrue(a)) {
  // a е вярно тук
}
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isTrue(value)`
