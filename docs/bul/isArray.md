# isArray

## Описание

`isArray` проверява дали дадена стойност е масив и връща `true`, ако е така, в противен случай `false`.

### Случай на употреба

Валидирайте неизвестни данни (напр. парснат JSON или отговори от API), за да се уверите, че дадена стойност е масив,
преди да обхождате, индексирате или достъпвате `.length`.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isArray`, когато ви е нужна проверка по време на изпълнение за масиви; тя връща булева стойност и е
> безопасно да се извиква с `unknown` стойности.

### Предимства

- Използва вградената `Array.isArray` за надеждно откриване на масиви в различни контексти (напр. iframes).
- Връща прост булев резултат (`true`/`false`), подходящ за гардове и разклоняваща логика.
- Работи с всякакъв тип вход, защото параметърът е `unknown`.

## Използване

### Синтаксис

Функция:

- `isArray(value)`

Параметри:

- `value`: Стойността, която трябва да бъде проверена.

### Локален импорт на функция

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  // input е масив по време на изпълнение
  console.log(input.length);
} else {
  console.log("Not an array");
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isArray(value)`
