# isBinary

## Описание

`isBinary` определя дали дадена стойност е двоичен низ (по избор с префикс `0b`/`0B`) и връща `true` или `false`.

### Случай на употреба

Валидирайте предоставени от потребителя низове (напр. полета във формуляр, CLI аргументи, конфигурационни стойности), за
да се уверите, че съдържат само двоични цифри, по избор с префикс `0b`/`0B`, преди по-нататъшна обработка.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isBinary` като type guard преди парсване или конвертиране на низ към `BigInt`/`Number`, за да избегнете
> невалиден вход.

### Предимства

- Приема двоични низове със или без префикса `0b`/`0B`.
- Отхвърля празни низове и низове с водещи/завършващи празни знаци (ASCII ≤ 32).
- Връща `true`/`false` без да хвърля изключение, което го прави безопасен при неизвестни входни данни.

## Използване

### Синтаксис

Функция:

- `isBinary(value)`

Параметри:

- `value`: Стойността, която трябва да бъде проверена.

### Локален импорт на функция

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // вярно
const b = isBinary("1010");   // вярно
const c = isBinary("0b1020"); // невярно
const d = isBinary(0b1010);     // невярно

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isBinary(value)`
