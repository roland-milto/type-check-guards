# areBuffers

## Описание

`areBuffers` проверява дали предоставената стойност е непразен, запълнен масив, в който всеки елемент е `Buffer`, като
връща `true`, ако е така, и `false` в противен случай.

### Случай на употреба

Валидирайте входящи масиви от части (напр. от потоци, качвания на файлове или мрежови пакети), за да се уверите, че
всички части са инстанции на `Buffer`, преди да ги конкатенирате, декодирате или подадете към криптографски или функции
за двоична обработка.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areBuffers`, за да валидирате `unknown[]` преди извикване на API-та, специфични за Buffer, като
`Buffer.concat`, като гарантирате, че функцията връща `true` само когато всеки елемент е `Buffer`.

### Предимства

- Гарантира, че всеки елемент във входа е инстанция на Node.js `Buffer`, като връща `true` само когато целият масив
  съвпада.
- Отхвърля невалидни входни данни рано, като изисква непразен, запълнен масив; връща `false` за празни масиви или за
  стойности, които не са масиви.
- Полезно като защитна проверка преди извършване на операции само с буфери (напр. конкатенация, хеширане, двоични
  протоколи).

## Използване

### Синтаксис

Функция:

- `areBuffers(array)`

Параметри:

- `array`: Масивът, който трябва да бъде проверен за инстанции на буфер.

### Локален импорт на функция

```ts
import { areBuffers } from "@type-check/guards";

const chunks: unknown[] = [Buffer.from("test"), Buffer.from("123")];

if (areBuffers(chunks)) {
  const combined = Buffer.concat(chunks);
  console.log(combined.toString("utf8"));
} else {
  throw new TypeError("Expected a non-empty array of Buffer instances");
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areBuffers(array)`
