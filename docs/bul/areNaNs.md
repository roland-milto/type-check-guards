# areNaNs

## Описание

`areNaNs` проверява дали всички елементи в масив са `NaN` и връща `true` само ако всеки елемент е `NaN`.

### Случай на употреба

Валидирайте входящи данни, при които `NaN` се използва като стойност-сентинел, и трябва да гарантирате, че целият масив
се състои изключително от `NaN` (напр. откриване на изцяло липсваща числова серия).

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areNaNs`, когато трябва да валидирате, че масив съдържа само числовата стойност `NaN` (без преобразуване
> от низ към число).

### Предимства

- Връща `true` само когато всеки елемент е `NaN` (строга проверка за всички елементи).
- Не преобразува низове в числа; стойности като "NaN" остават не-`NaN` и правят резултата `false`.
- Връща `false` за непопълнени масиви, предотвратявайки случайно `true` при празен вход.

## Използване

### Синтаксис

Функция:

- `areNaNs(array)`

Параметри:

- `array`: Масивът, който да се провери за стойности `NaN`.

### Локален импорт на функция

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // вярно
const b = areNaNs([NaN, 1, NaN]); // невярно
const c = areNaNs([NaN, "NaN", NaN]); // невярно
const d = areNaNs([NaN, null, NaN]); // невярно
const e = areNaNs([] as unknown[]); // невярно

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areNaNs(array)`
