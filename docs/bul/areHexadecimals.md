# areHexadecimals

## Описание

Проверява дали всички елементи в масив са шестнадесетични низове, като връща `true` само за непразни масиви, в които
всеки елемент е валиден.

### Случай на употреба

Използвайте `areHexadecimals`, за да валидирате потребителски вход или външни данни (напр. идентификатори, контролни
суми, цветови кодове без водещ '#') преди шестнадесетично парсване или по-нататъшна обработка.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areHexadecimals`, за да валидирате неизвестен вход преди парсване или конвертиране на стойности (например
> преди `parseInt(value, 16)` или конверсии към BigInt).

### Предимства

- Проверява дали всеки елемент е шестнадесетичен низ и връща `true` само когато всички елементи съвпадат.
- По замисъл отхвърля празни масиви, като връща `false` при липсващи входни данни.
- Предоставя прост булев резултат (`true`/`false`), подходящ за гардове и валидация с ранно връщане.

## Използване

### Синтаксис

Функция:

- `areHexadecimals(array)`

Параметри:

- `array`: Масивът, който трябва да бъде проверен за елементи, представляващи шестнадесетични низове.

### Локален импорт на функция

```ts
import { areHexadecimals } from "@type-check/guards";

const a = areHexadecimals(["1A", "3F", "B2"]);
const b = areHexadecimals(["1A", "3G", "B2"]);
const c = areHexadecimals([10 as unknown as string, "3F", "B2"] as unknown[]);
const d = areHexadecimals([]);

console.log(a, b, c, d);
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areHexadecimals(array)`
