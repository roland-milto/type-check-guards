# areWeakMaps

## Описание

`areWeakMaps` проверява дали дадена стойност е непразен масив, в който всеки елемент е `WeakMap`, като връща `true` само
в този случай и `false` в противен.

### Случай на употреба

Валидирайте данни по време на изпълнение (напр. парсиран JSON, входове от плъгини или слабо типизирана конфигурация), за
да се уверите, че представляват непразен масив от инстанции на `WeakMap`, преди да итерирате и да извиквате методи на
`WeakMap`; връща `false`, когато някой елемент не е `WeakMap` или когато масивът е празен.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areWeakMaps`, за да валидирате неизвестен вход, преди да го третирате като непразен `WeakMap[]`;
> функцията връща `false` за празни масиви.

### Предимства

- Гарантира, че всеки елемент в предоставения масив е инстанция на `WeakMap`.
- Връща `false` за празни масиви, предотвратявайки случайното приемане на „няма данни“ като валиден вход.
- Полезно като защитна проверка преди извършване на операции, специфични за `WeakMap`, върху всички елементи.

## Използване

### Синтаксис

Функция:

- `areWeakMaps(array)`

Параметри:

- `array`: Масивът, който да се провери за инстанции на `WeakMap`.

### Локален импорт на функция

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  // list е непразен масив от инстанции на WeakMap
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  // не е непразен WeakMap[]
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areWeakMaps(array)`
