# arePlainObjects

## Описание

Проверява дали всички елементи на масив са обикновени обекти, като връща `true` само ако всеки елемент отговаря на
условията.

### Случай на употреба

Валидирайте външни или нетипизирани данни (напр. парсиран JSON, payload-и от API, изпращания от форми), за да се
уверите, че сте получили непразен масив, в който всеки запис е обикновен обект, преди да обхождате и да четете свойства.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `arePlainObjects`, за да валидирате входни данни с неизвестен тип, преди да ги третирате като
`Record<string, unknown>[]` (или по-строга форма на обект) в TypeScript.

### Предимства

- Гарантира, че всеки елемент във входния масив е обикновен обект, като връща `true` само когато всички елементи
  съвпадат.
- Отхвърля невалидни входни данни рано (немасиви или празни масиви), като връща `false`.
- Счита както обекти, създадени с обектен литерал, така и обекти `Object.create(null)` за валидни обикновени обекти.

## Използване

### Синтаксис

Функция:

- `arePlainObjects(array)`

Параметри:

- `array`: Масивът, който трябва да бъде проверен за елементи, които са обикновени обекти.

### Локален импорт на функция

```ts
import { arePlainObjects } from "@type-check/guards";

const a = arePlainObjects([{ a: 1 }, { b: 2 }]); // вярно
const b = arePlainObjects([{}, Object.create(null)]); // вярно
const c = arePlainObjects([{ a: 1 }, 2 as unknown]); // невярно
const d = arePlainObjects([] as unknown[]); // невярно
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.arePlainObjects(array)`
