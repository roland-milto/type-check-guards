# isSymbol

## Описание

`isSymbol` определя дали дадена стойност е от тип `symbol`, като връща `true` за символи и `false` в противен случай.

### Случай на употреба

Валидирайте, че стойност от тип `unknown` е `symbol`, преди да я използвате като уникален идентификатор, ключ в регистър
или изчисляем ключ на свойство в обекти и map-ове.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isSymbol`, за да стесните `unknown` до `symbol` преди извикване на функции, свързани със символи, или
> преди използването му като изчисляем ключ на свойство.

### Предимства

- Осигурява проста и надеждна проверка по време на изпълнение за примитивния тип `symbol` в JavaScript.
- Помага за стесняване на стойности от тип `unknown` преди използване на API-та, специфични за символи, или преди
  съхраняването им като ключове.
- Избягва фалшиви положителни резултати чрез използване на `typeof`, което е каноничният начин за откриване на стойности
  от тип `symbol`.

## Използване

### Синтаксис

Функция:

- `isSymbol(value)`

Параметри:

- `value`: Стойността, която трябва да бъде проверена.

### Локален импорт на функция

```ts
import { isSymbol } from "@type-check/guards";

const input: unknown = Symbol("key");

if (isSymbol(input)) {
  // input тук е символ
  const registryKey = Symbol.keyFor(input);
  console.log(registryKey);
} else {
  console.log("Not a symbol");
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isSymbol(value)`
