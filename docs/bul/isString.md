# isString

## Описание

`isString` определя дали дадена стойност е низ.

### Случай на употреба

Валидирайте потребителски вход, полета от payload на API или конфигурационни стойности по време на изпълнение, за да се
уверите, че стойността е низ, преди да приложите операции с низове (напр. подрязване, разделяне, преобразуване на
регистъра).

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isString`, за да валидирате стойности от тип `unknown` или с нестрога типизация, преди да извикате методи
> за низове; връща `true` само когато `typeof value === "string"`.

### Предимства

- Проста и бърза проверка с `typeof`.
- Връща предвидим булев резултат: `true` за низове, иначе `false`.
- Работи както за празни, така и за непразни низове.
- Полезно като лек runtime guard преди изпълнение на операции, специфични за низове.

## Използване

### Синтаксис

Функция:

- `isString(value)`

Параметри:

- `value`: Стойността, която да бъде тествана дали е от тип низ.

### Локален импорт на функция

```ts
import { isString } from "@type-check/guards";

const input: unknown = "Hello World";

if (isString(input)) {
  // входът тук е низ
  console.log(input.toUpperCase());
} else {
  console.log("Not a string");
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isString(value)`
