# Препратки към функции

## Функции

| Функция                                     | Описание                                                                                                                                                                                       |
|---------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [areArrays](areArrays.md)                   | `areArrays` определя дали дадена стойност е запълнен двуизмерен масив, чиито елементи са изцяло масиви.                                                                                        |
| [areBigInts](areBigInts.md)                 | `areBigInts` определя дали дадена стойност е непразен масив, съдържащ само стойности от тип `bigint`.                                                                                          |
| [areBinaries](areBinaries.md)               | Проверява дали предоставената стойност е непразен масив от валидни двоични низове и връща `true` само ако всички елементи преминат валидацията.                                                |
| [areBooleans](areBooleans.md)               | `areBooleans` проверява дали даден непразен масив съдържа само булеви стойности, като връща `true`, ако е така, и `false` в противен случай.                                                   |
| [areBuffers](areBuffers.md)                 | `areBuffers` проверява дали предоставената стойност е непразен, запълнен масив, в който всеки елемент е `Buffer`, като връща `true`, ако е така, и `false` в противен случай.                  |
| [areDates](areDates.md)                     | `areDates` определя дали даден масив е запълнен и съдържа само обекти `Date`, като връща `true` само когато всички елементи са валидни дати.                                                   |
| [areDecimals](areDecimals.md)               | Проверява дали всички елементи в масив са десетични числа и дали масивът е запълнен, като връща `true` или `false`.                                                                            |
| [areEqual](areEqual.md)                     | `areEqual` проверява дали всички елементи в масив са равни на дадена очаквана стойност, като връща `true` само за непразни масиви, в които всеки елемент съвпада.                              |
| [areErrors](areErrors.md)                   | Проверява дали масивът е непразен и съдържа само обекти `Error`, връщайки `true` или `false`.                                                                                                  |
| [areFalse](areFalse.md)                     | `areFalse` проверява дали всички елементи в предоставен масив са строго булевата стойност `false`.                                                                                             |
| [areFilledArrays](areFilledArrays.md)       | `areFilledArrays` проверява дали двумерен масив не е празен и всички негови подмасиви не са празни.                                                                                            |
| [areFinite](areFinite.md)                   | `areFinite` проверява дали дадена стойност е непразен масив, чиито елементи са всички крайни числа, като връща `true` ако е така и `false` в противен случай.                                  |
| [areFloats](areFloats.md)                   | `areFloats` проверява дали даден масив е запълнен и всички негови елементи са числа с плаваща запетая.                                                                                         |
| [areHexadecimals](areHexadecimals.md)       | Проверява дали всички елементи в масив са шестнадесетични низове, като връща `true` само за непразни масиви, в които всеки елемент е валиден.                                                  |
| [areIndexesFound](areIndexesFound.md)       | `areIndexesFound` проверява дали дадена стойност е непразен масив, чиито елементи са всички валидни индекси, като връща `true`, ако са, и `false` в противен случай.                           |
| [areIntegers](areIntegers.md)               | `areIntegers` определя дали всички елементи в даден масив са цели числа, като връща `true`, ако са, и `false` в противен случай.                                                               |
| [areJson](areJson.md)                       | Проверява дали всички елементи на масив са JSON низове, като връща `true` само ако масивът е попълнен и всеки елемент е валиден JSON; в противен случай връща `false`.                         |
| [areMaps](areMaps.md)                       | `areMaps` определя дали даден масив е непразен и дали всички негови елементи са инстанции на `Map`.                                                                                            |
| [areNaNs](areNaNs.md)                       | `areNaNs` проверява дали всички елементи в масив са `NaN` и връща `true` само ако всеки елемент е `NaN`.                                                                                       |
| [areNullOrUndefined](areNullOrUndefined.md) | Проверява дали всички елементи в дадения масив са `null` или `undefined`.                                                                                                                      |
| [areNumbers](areNumbers.md)                 | `areNumbers` проверява дали дадена стойност е непразен масив, в който всички елементи са числа.                                                                                                |
| [areNumerics](areNumerics.md)               | `areNumerics` проверява дали дадена стойност е непразен масив, в който всички елементи са числови.                                                                                             |
| [areObjects](areObjects.md)                 | `areObjects` проверява дали предоставен запълнен масив съдържа само обекти.                                                                                                                    |
| [areOctals](areOctals.md)                   | `areOctals` определя дали предоставената стойност е непразен масив от валидни осмични низове.                                                                                                  |
| [areOfType](areOfType.md)                   | Проверява дали всички елементи в дадения `array` са от посочения `type`.                                                                                                                       |
| [areOneOfType](areOneOfType.md)             | `areOneOfType` проверява дали всички елементи в непразен масив са от един от посочените runtime типове.                                                                                        |
| [arePlainObjects](arePlainObjects.md)       | Проверява дали всички елементи на масив са обикновени обекти, като връща `true` само ако всеки елемент отговаря на условията.                                                                  |
| [arePrimitives](arePrimitives.md)           | `arePrimitives` оценява дали всички елементи в предоставен, непразен масив са примитивни типове.                                                                                               |
| [arePromises](arePromises.md)               | `arePromises` определя дали всички елементи в масив са инстанции на `Promise`.                                                                                                                 |
| [areRegExes](areRegExes.md)                 | `areRegExes` проверява дали дадена стойност е запълнен масив, съдържащ само обекти `RegExp`.                                                                                                   |
| [areSets](areSets.md)                       | Проверява дали даден непразен масив съдържа само инстанции на `Set`, като връща `true`, ако е така, и `false` в противен случай.                                                               |
| [areStreams](areStreams.md)                 | `areStreams` определя дали дадена стойност е непразен масив, в който всеки елемент е `Stream`.                                                                                                 |
| [areStrings](areStrings.md)                 | `areStrings` проверява дали масивът е непразен и дали всички негови елементи са низове, като връща `true` само в този случай.                                                                  |
| [areSymbols](areSymbols.md)                 | Проверява дали входът е запълнен масив, чиито елементи са всички символи, като връща `true` или `false`.                                                                                       |
| [areTrue](areTrue.md)                       | Проверява дали непразен масив съдържа само булеви стойности `true`.                                                                                                                            |
| [areUndefined](areUndefined.md)             | `areUndefined` проверява дали всеки елемент в предоставен масив е `undefined`.                                                                                                                 |
| [areValidDates](areValidDates.md)           | Определя дали даден масив е непразен и се състои изцяло от валидни обекти `Date`.                                                                                                              |
| [areWeakMaps](areWeakMaps.md)               | `areWeakMaps` проверява дали дадена стойност е непразен масив, в който всеки елемент е `WeakMap`, като връща `true` само в този случай и `false` в противен.                                   |
| [areWeakSets](areWeakSets.md)               | Проверява дали входът е непразен масив, в който всеки елемент е `WeakSet`, като връща `true` само в този случай.                                                                               |
| [getTypeOf](getTypeOf.md)                   | `getTypeOf` връща подробен, четим за хора етикет за тип за дадена стойност, включително прецизирани числови типове и конкретни видове обекти.                                                  |
| [isArray](isArray.md)                       | `isArray` проверява дали дадена стойност е масив и връща `true`, ако е така, в противен случай `false`.                                                                                        |
| [isBigInt](isBigInt.md)                     | `isBigInt` проверява дали дадена стойност е от тип `bigint`, като връща `true` за BigInt примитиви и `false` в противен случай.                                                                |
| [isBinary](isBinary.md)                     | `isBinary` определя дали дадена стойност е двоичен низ (по избор с префикс `0b`/`0B`) и връща `true` или `false`.                                                                              |
| [isBoolean](isBoolean.md)                   | Определя дали дадена стойност е `boolean`.                                                                                                                                                     |
| [isBuffer](isBuffer.md)                     | Проверява дали дадена стойност е Node.js `Buffer` и връща `true` или `false`.                                                                                                                  |
| [isDate](isDate.md)                         | `isDate` определя дали предоставена стойност е `Date`, като връща `true` за инстанции на `Date` и `false` в противен случай.                                                                   |
| [isDecimal](isDecimal.md)                   | `isDecimal` проверява дали дадена стойност е десетично низово представяне без водещи/завършващи интервали и с валиден десетичен формат.                                                        |
| [isEmpty](isEmpty.md)                       | Определя дали дадена стойност е празна, като връща `true` за `null`, `undefined`, празни/само-интервални низове, празни масиви, празни `Map`/`Set` или обекти без собствени изброими свойства. |
| [isError](isError.md)                       | Проверява дали дадена `value` е инстанция на `Error`.                                                                                                                                          |
| [isFalse](isFalse.md)                       | `isFalse` проверява дали дадена стойност е строго равна на булевия литерал `false`.                                                                                                            |
| [isFilledArray](isFilledArray.md)           | Проверява дали `value` е масив с поне един елемент, като връща `true` или `false`.                                                                                                             |
| [isFinite](isFinite.md)                     | Определя дали дадена `value` е крайно `number`.                                                                                                                                                |
| [isFloat](isFloat.md)                       | `isFloat` определя дали дадена `value` е крайно число с плаваща запетая (тип `number`, което не е цяло число).                                                                                 |
| [isHexadecimal](isHexadecimal.md)           | `isHexadecimal` проверява дали дадена стойност е шестнадесетичен низов литерал със задължителен префикс `0x`/`0X`.                                                                             |
| [isIndexFound](isIndexFound.md)             | `isIndexFound` определя дали дадена стойност е неотрицателно цяло число, което означава, че е намерен индекс.                                                                                  |
| [isInteger](isInteger.md)                   | Определя дали дадена `value` е безопасно цяло число.                                                                                                                                           |
| [isMap](isMap.md)                           | Проверява дали дадената `value` е `Map`, като връща `true`, ако е, и `false` в противен случай.                                                                                                |
| [isNaN](isNaN.md)                           | Определя дали предоставената `value` е `NaN` от тип `number`, без да преобразува низове.                                                                                                       |
| [isNull](isNull.md)                         | Определя дали предоставената `value` е `null`.                                                                                                                                                 |
| [isNullOrUndefined](isNullOrUndefined.md)   | Проверява дали дадена стойност е `null` или `undefined`.                                                                                                                                       |
| [isNumber](isNumber.md)                     | `isNumber` проверява дали дадена стойност е крайно число, различно от `NaN`.                                                                                                                   |
| [isNumeric](isNumeric.md)                   | `isNumeric` определя дали дадена `value` се счита за числова, като проверява нейния определен тип спрямо `NUMERIC_TYPES`.                                                                      |
| [isObject](isObject.md)                     | Определя дали дадена `value` е `object` (с изключение на `null`).                                                                                                                              |
| [isOctal](isOctal.md)                       | Определя дали дадена стойност е валиден низ за осмичен литерал (напр. `0o755`).                                                                                                                |
| [isOfType](isOfType.md)                     | Определя дали дадена `value` съвпада с указан низ за тип, използвайки `typeof` за примитиви и резервен механизъм за сложни типове.                                                             |
| [isOneOfType](isOneOfType.md)               | `isOneOfType` определя дали дадена `value` съвпада поне с един от предоставените низове за тип, като връща `true`, ако бъде намерено съвпадение, и `false` в противен случай.                  |
| [isPlainObject](isPlainObject.md)           | Проверява дали дадена `value` е обикновен обект и връща `true`, ако е така, в противен случай `false`.                                                                                         |
| [isPrimitive](isPrimitive.md)               | `isPrimitive` определя дали дадена стойност е примитив (`null`, `undefined`, `boolean`, `number`, `string`, `bigint`, `symbol`).                                                               |
| [isPromise](isPromise.md)                   | Определя дали дадена стойност е `Promise`.                                                                                                                                                     |
| [isRegEx](isRegEx.md)                       | Определя дали предоставена стойност е инстанция на `RegExp`.                                                                                                                                   |
| [isSet](isSet.md)                           | Определя дали дадена стойност е `Set`.                                                                                                                                                         |
| [isStream](isStream.md)                     | `isStream` проверява дали дадена стойност е обект поток (подобен на Node.js поток, `ReadableStream` или `WritableStream`).                                                                     |
| [isString](isString.md)                     | `isString` определя дали дадена стойност е низ.                                                                                                                                                |
| [isSymbol](isSymbol.md)                     | `isSymbol` определя дали дадена стойност е от тип `symbol`, като връща `true` за символи и `false` в противен случай.                                                                          |
| [isTrue](isTrue.md)                         | `isTrue` определя дали дадена стойност е строго равна на `true`.                                                                                                                               |
| [isUndefined](isUndefined.md)               | Проверява дали дадена стойност е `undefined`.                                                                                                                                                  |
| [isValidDate](isValidDate.md)               | `isValidDate` проверява дали дадена стойност е валиден обект `Date` и връща `true` само за реални, не-невалидни дати.                                                                          |
| [isWeakMap](isWeakMap.md)                   | Определя дали дадената `value` е инстанция на `WeakMap`.                                                                                                                                       |
| [isWeakSet](isWeakSet.md)                   | Определя дали дадената `value` е `WeakSet` от обекти.                                                                                                                                          |
