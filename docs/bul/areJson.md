# areJson

## Описание

Проверява дали всички елементи на масив са JSON низове, като връща `true` само ако масивът е попълнен и всеки елемент е
валиден JSON; в противен случай връща `false`.

### Случай на употреба

Валидирайте входящи данни (напр. от query параметри, променливи на средата или външни API), когато очаквате масив от
низове, кодирани като JSON, и искате да отхвърлите празни масиви или каквито и да е записи, които не са JSON.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areJson`, когато трябва да валидирате, че `unknown[]` съдържа само JSON низове, преди да ги парснете (
> напр. с `JSON.parse`).

### Предимства

- Връща `true` само когато всеки елемент е валиден JSON низ; в противен случай връща `false`.
- Прекратява проверката при първата грешка: спира веднага щом бъде открит елемент, който не е JSON.
- По замисъл отхвърля празни масиви, като връща `false` при непопълнен вход.

## Използване

### Синтаксис

Функция:

- `areJson(array)`

Параметри:

- `array`: Масивът, който трябва да бъде проверен за елементи, които са JSON низове.

### Локален импорт на функция

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // вярно
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // невярно
const empty = areJson([]); // невярно

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areJson(array)`
