# isRegEx

## Описание

Определя дали предоставена стойност е инстанция на `RegExp`.

### Случай на употреба

Валидирайте предоставени от потребителя или динамични стойности (напр. конфигурация, API payload-и, входове от плъгини),
преди да ги третирате като регулярен израз.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isRegEx`, за да стесните стойности от тип `unknown` (или обединение) преди използване на свойства или
> методи, специфични за RegExp; функцията връща `true` само за стойности, които са инстанции на `RegExp`.

### Предимства

- Предоставя проста проверка на типа по време на изпълнение, за да се установи дали дадена стойност е `RegExp`.
- Помага да се предотвратят грешки, когато кодът очаква регулярен израз (напр. преди извикване на `test`, `exec` или
  четене на `source`).
- Работи както с литерали за регулярен израз, така и с инстанции, създадени чрез `new RegExp(...)`.
- Връща ясен булев резултат (`true`/`false`) без да хвърля изключение при входове, които не са регулярен израз.

## Използване

### Синтаксис

Функция:

- `isRegEx(value)`

Параметри:

- `value`: Стойността, която трябва да бъде проверена.

### Локален импорт на функция

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  // input е RegExp тук
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isRegEx(value)`
