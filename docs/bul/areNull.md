# areNull

## Описание

Проверява дали всички елементи в дадения `array` са `null`.

### Случай на употреба

Валидирайте, че колона в набор от данни, списък с полета от API или масив-плейсхолдър съдържа само стойности `null`,
преди да приложите логика, която предполага, че всички записи са умишлено празни.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areNull`, когато ви е нужна строга проверка, че входът е непразен масив и всеки елемент е точно `null` (
> не `undefined`, не falsy стойности).

### Предимства

- Връща `true` само когато всеки елемент е `null`, което го прави строг защитен механизъм тип „всички съвпадат“.
- Отхвърля не-масиви и празни масиви, като връща `false`, предотвратявайки случайни truthy резултати при невалиден вход.
- Работи добре като предварителна проверка (precondition) преди обработка на данни, които трябва да са изцяло `null`.

## Използване

### Синтаксис

Функция:

- `areNull(array)`

Параметри:

- `array`: Входният масив, който да се провери за елементи `null`.

### Локален импорт на функция

```ts
import { areNull } from "@type-check/guards";

const a = [null, null];
const b = [null, 1, null];

const allNullA = areNull(a); // вярно
const allNullB = areNull(b); // невярно

const notAnArray = areNull(123 as unknown as unknown[]); // невярно
const empty = areNull([]); // невярно

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areNull(array)`
