# isHexadecimal

## Описание

`isHexadecimal` проверява дали дадена стойност е шестнадесетичен низов литерал със задължителен префикс `0x`/`0X`.

### Случай на употреба

Използвайте `isHexadecimal`, за да валидирате конфигурационни стойности, полета в API payload или аргументи на CLI,
които трябва да бъдат подадени като шестнадесетични низови литерали (напр. идентификатори, маски или адреси) и не трябва
да съдържат околни интервали.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isHexadecimal`, когато трябва да валидирате потребителски вход или сериализирани данни като строг
> шестнадесетичен литерален низ (включително префикса `0x`/`0X`) преди парсване или преобразуване.

### Предимства

- Проверява дали дадена стойност е низ и съответства на строг формат на шестнадесетичен литерал (изисква префикса `0x`/
  `0X`).
- Отхвърля низове с водещи или завършващи интервали, което помага да се избегне случайно приемане на вход с добавени
  празни символи.
- Поддържа незадължителен знак и не е чувствителна към регистъра за префикса и цифрите, като предсказуемо връща `true`/
  `false`.

## Използване

### Синтаксис

Функция:

- `isHexadecimal(value)`

Параметри:

- `value`: Стойността, която трябва да бъде проверена.

### Локален импорт на функция

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // вярно
isHexadecimal("-0Xff"); // вярно
isHexadecimal("1A2B"); // невярно (липсва префикс)
isHexadecimal(" 0x1A2B"); // невярно (водещи интервали)
isHexadecimal(0x1a2b); // невярно (не е низ)
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isHexadecimal(value)`
