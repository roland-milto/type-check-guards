# isEmpty

## Описание

Определя дали дадена стойност е празна, като връща `true` за `null`, `undefined`, празни/само-интервални низове, празни
масиви, празни `Map`/`Set` или обекти без собствени изброими свойства.

### Случай на употреба

Използвайте `isEmpty`, за да валидирате входни данни и да откривате липсващи/празни стойности в множество типове данни (
напр. полета във формуляри, API payload-и, конфигурационни обекти), където `null`, `undefined`, низове само с интервали,
празни колекции и обекти без свойства трябва да се третират като празни.

> **Бележка за потребителите на TypeScript:**
>
> `isEmpty` е помощна функция, която връща булева стойност (не е TypeScript type predicate), така че сама по себе си не
> стеснява типовете; използвайте я за валидация/разклоняване, а не за стесняване по време на компилация.

### Предимства

- Третира `null` и `undefined` като `true` при проверки за празнота.
- Счита низовете, съдържащи само интервали, за празни, като ги подрязва (trim) преди проверка на дължината.
- Поддържа често срещани контейнерни типове (масиви, `Map`, `Set`) и обикновени обекти без собствени изброими свойства.
- Избягва броенето на наследени свойства чрез проверки с `hasOwnProperty`.
- Връща прост булев резултат (`true`/`false`), подходящ за гардове и валидация.

## Използване

### Синтаксис

Функция:

- `isEmpty(value)`

Параметри:

- `value`: Стойността, която да се провери за празнота.

### Локален импорт на функция

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isEmpty(value)`
