# areDates

## Описание

`areDates` определя дали даден масив е запълнен и съдържа само обекти `Date`, като връща `true` само когато всички
елементи са валидни дати.

### Случай на употреба

Използвайте `areDates`, за да валидирате входни данни с неизвестен тип (напр. парсиран JSON, данни от формуляр,
payload-и от API) преди изпълнение на логика, специфична за дати, като сортиране по време, форматиране или изчисляване
на диапазони.

> **Бележка за потребителите на TypeScript:**
>
> Връща `true` само за непразни масиви, в които всеки елемент е `Date`; празните масиви дават `false`.

### Предимства

- Гарантира, че масивът не е празен преди валидирането на съдържанието му, предотвратявайки `true` при празни входни
  данни.
- Проверява дали всеки елемент е инстанция на `Date`, като връща `false` незабавно при първото несъответствие.
- Полезно като проверка тип „guard“ преди изпълнение на операции, специфични за дати, върху елементите на масива.

## Използване

### Синтаксис

Функция:

- `areDates(array)`

Параметри:

- `array`: Масивът, който трябва да бъде проверен за обекти `Date`.

### Локален импорт на функция

```ts
import { areDates } from "@type-check/guards";

const a: unknown[] = [new Date(), new Date("2021-01-01")];
const b: unknown[] = [];
const c: unknown[] = [new Date(), "not a date"];

console.log(areDates(a)); // вярно
console.log(areDates(b)); // невярно
console.log(areDates(c)); // невярно

if (areDates(a)) {
  const timestamps = a.map(d => d.getTime());
  console.log(timestamps);
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areDates(array)`
