# areOctals

## Описание

`areOctals` определя дали предоставената стойност е непразен масив от валидни осмични низове.

### Случай на употреба

Използвайте `areOctals` при валидиране на потребителски вход, конфигурационни стойности или API payload-и, които трябва
да съдържат осмични литерали (напр. режими за права на файлове като `0o755`), и искате да отхвърлите празни масиви или
невалидни записи, като върнете `false`.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areOctals`, за да се уверите, че разполагате с непразен `unknown[]`, в който всеки елемент е валиден
> осмичен низ, преди да конвертирате (напр. чрез `Number(...)` или чрез собствено парсване).

### Предимства

- Проверява дали дадена стойност е непразен масив, в който всеки елемент е осмичен низ, като връща `true` само когато
  всички елементи преминат проверката.
- Прекратява рано: връща `false` веднага щом бъде открит неосмичен елемент.
- Полезно като защита преди парсване или конвертиране на осмични низове, за да се избегнат runtime грешки и
  непоследователна обработка на входа.

## Използване

### Синтаксис

Функция:

- `areOctals(array)`

Параметри:

- `array`: Стойността, която трябва да бъде проверена.

### Локален импорт на функция

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value е непразен масив от осмични низове
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areOctals(array)`
