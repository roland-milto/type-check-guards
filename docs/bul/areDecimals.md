# areDecimals

## Описание

Проверява дали всички елементи в масив са десетични числа и дали масивът е запълнен, като връща `true` или `false`.

### Случай на употреба

Валидирайте предоставени от потребителя списъци (напр. CSV колони или входове от формуляр), за да се уверите, че масивът
не е празен и всеки запис е десетична стойност преди парсване или изчисления.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areDecimals`, когато ви трябва бърза булева проверка дали `unknown[]` е непразен и всеки елемент е
> десетично представяне.

### Предимства

- Гарантира, че входът е запълнен масив преди валидирането на елементите, предотвратявайки случайно приемане на празни
  списъци.
- Валидира всеки елемент с `isDecimal`, така че смесени или невалидни стойности водят до незабавен резултат `false`.
- Предоставя прост булев резултат (`true`/`false`), подходящ за guard-и и потоци за валидация с ранно връщане.

## Използване

### Синтаксис

Функция:

- `areDecimals(array)`

Параметри:

- `array`: Масивът, който трябва да бъде проверен.

### Локален импорт на функция

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // вярно
console.log(areDecimals(b)); // невярно
console.log(areDecimals(c)); // невярно
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areDecimals(array)`
