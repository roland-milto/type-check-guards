# areNumbers

## Описание

`areNumbers` проверява дали дадена стойност е непразен масив, в който всички елементи са числа.

### Случай на употреба

Валидирайте данни, предоставени от потребител или API, за да се уверите, че представляват непразен масив от числа, преди
да изчислявате суми, средни стойности или други числови агрегации.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areNumbers`, за да валидирате неизвестни масиви преди извършване на числови изчисления; връща `false` за
> празни масиви и за масиви, съдържащи каквато и да е нечислова стойност.

### Предимства

- Връща `true` само когато входът е непразен масив и всеки елемент е число.
- Предотвратява фалшиви положителни резултати, като отхвърля празни масиви и входове, които не са масиви.
- Полезно като защита преди числови операции (напр. сумиране, осредняване), за да се избегнат грешки по време на
  изпълнение.

## Използване

### Синтаксис

Функция:

- `areNumbers(array)`

Параметри:

- `array`: Масивът, който трябва да бъде проверен за числови елементи.

### Локален импорт на функция

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areNumbers(array)`
