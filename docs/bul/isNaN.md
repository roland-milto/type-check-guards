# isNaN

## Описание

Определя дали предоставената `value` е `NaN` от тип `number`, без да преобразува низове.

### Случай на употреба

Валидирайте недоверен или слабо типизиран вход (напр. payload-и от API, стойности от форми, парснат JSON), за да
откриете специалната стойност `NaN` и да я обработите изрично, като третирате входовете, които не са числа, като не-
`NaN`.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isNaN`, когато трябва да засечете специалната числова стойност `NaN`, като същевременно гарантирате, че
> входът действително е `number` (без преобразуване от низ към число).

### Предимства

- Проверява дали дадена стойност е `NaN`, без да преобразува не-числа (напр. низове) в числа.
- Връща `true` само за стойности, които са едновременно от тип `number` и `NaN`.
- Безопасно за входове от тип `unknown` и избягва фалшиви положителни резултати от неявни преобразувания.

## Използване

### Синтаксис

Функция:

- `isNaN(value)`

Параметри:

- `value`: Стойността, която да бъде проверена дали е `NaN` от тип `number`.

### Локален импорт на функция

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // вярно
console.log(isNaN(b)); // невярно
console.log(isNaN(c)); // невярно

if (isNaN(a)) {
  // a е число и по-специално NaN
}
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isNaN(value)`
