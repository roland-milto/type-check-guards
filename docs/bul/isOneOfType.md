# isOneOfType

## Описание

`isOneOfType` определя дали дадена `value` съвпада поне с един от предоставените низове за тип, като връща `true`, ако
бъде намерено съвпадение, и `false` в противен случай.

### Случай на употреба

Валидирайте слабо типизирани или външни данни (напр. парсиран JSON, параметри на заявка), като позволите множество
приемливи типове по време на изпълнение (като `number` или `string`), преди да продължите с по-нататъшна логика.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isOneOfType`, когато искате проверка по време на изпълнение дали дадена стойност съвпада с някой от
> няколко позволени типа; връща `true`, ако поне един тип съвпада, иначе `false`.

### Предимства

- Проверява стойност спрямо множество позволени типове с едно извикване, като връща `true` при първото съвпадение.
- Работи с входове от тип `unknown`, което го прави полезен на границите на изпълнение (напр. външни данни,
  потребителски вход).
- Прост булев резултат (`true`/`false`), който се комбинира добре с условна логика и ранни връщания.

## Използване

### Синтаксис

Функция:

- `isOneOfType(value, types)`

Параметри:

- `value`: Стойността, която да бъде проверена спрямо зададените типове.
- `types`: Масив от низове за типове, представляващи потенциалните типове на стойността.

### Локален импорт на функция

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // input е обект по време на изпълнение
}

console.log(isOneOfType(3, ["number", "string"])); // вярно
console.log(isOneOfType("hello", ["number", "boolean"])); // невярно

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isOneOfType(value, types)`
