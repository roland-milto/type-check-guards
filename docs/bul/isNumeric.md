# isNumeric

## Описание

`isNumeric` определя дали дадена `value` се счита за числова, като проверява нейния определен тип спрямо
`NUMERIC_TYPES`.

### Случай на употреба

Използвайте `isNumeric`, за да валидирате входни данни (напр. API payloads, стойности от форми, конфигурация) преди
извършване на числови операции и за последователно приемане на числоподобни типове (като `BigInt`) според
`NUMERIC_TYPES`.

> **Бележка за потребителите на TypeScript:**
>
> `isNumeric` е предикат, който връща булева стойност; третирайте го като runtime проверка дали дадена стойност
> принадлежи към дефинирания от библиотеката набор от числови типове.

### Предимства

- Използва `getTypeOf` плюс `NUMERIC_TYPES`, за да централизира логиката за откриване на числови типове и да поддържа
  проверките последователни в целия кодов базис.
- Връща прост булев резултат (`true`/`false`) за лесно разклоняване и използване в стил guard.
- Поддържа множество числови представяния (напр. `number`, `BigInt`), както са дефинирани от `NUMERIC_TYPES`.

## Използване

### Синтаксис

Функция:

- `isNumeric(value)`

Параметри:

- `value`: Стойността, която да се провери за числов тип.

### Локален импорт на функция

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    // v се счита за числова стойност според правилата за типове на библиотеката
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isNumeric(value)`
