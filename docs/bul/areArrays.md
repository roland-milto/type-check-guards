# areArrays

## Описание

`areArrays` определя дали дадена стойност е запълнен двуизмерен масив, чиито елементи са изцяло масиви.

### Случай на употреба

Използвайте `areArrays`, за да валидирате таблични или матрични входове (напр. CSV редове, данни за решетка или
групирани списъци), преди да извършвате операции по редове/колони; функцията връща `false`, ако входът не е масив, е
празен или съдържа елемент, който не е масив.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areArrays`, когато трябва да се уверите, че дадена стойност е непразен 2D масив и че всеки ред е масив,
> преди да итерирате или да индексирате във вложени масиви.

### Предимства

- Проверява дали входът е непразен двуизмерен масив, в който всеки елемент е масив.
- Връща прост булев резултат (`true`/`false`), подходящ за гардове и ранно прекратяване.
- Помага да се предотвратят грешки по време на изпълнение, когато по-късен код предполага операции с вложени масиви (
  напр. мапване на редове).

## Използване

### Синтаксис

Функция:

- `areArrays(array)`

Параметри:

- `array`: Входът, който трябва да бъде проверен.

### Локален импорт на функция

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value е двумерен масив с масиви като елементи
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areArrays(array)`
