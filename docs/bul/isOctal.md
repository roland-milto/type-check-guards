# isOctal

## Описание

Определя дали дадена стойност е валиден низ за осмичен литерал (напр. `0o755`).

### Случай на употреба

Валидирайте потребителски вход или стойности от конфигурация, които трябва да бъдат изразени като низ за осмичен
литерал (например режими за права на файлове като `0o644`), преди да ги парснете или преобразувате.

> **Бележка за потребителите на TypeScript:**
>
> `isOctal` е тип гард (`value is string`). След резултат `true` TypeScript стеснява проверената променлива до `string`.

### Предимства

- Осигурява строг тип гард: връща `true` само когато входът е низ, който съвпада с формат на осмичен литерал.
- Отхвърля празни низове и низове с водещи/завършващи интервали (ASCII контролни символи/интервал), като намалява
  случайните съвпадения.
- Поддържа незадължителен знак и не е чувствителен към регистъра за префикса `0o`/`0O`.
- По-толерантен към входове, които не са низ: връща `false` вместо да хвърля изключение.

## Използване

### Синтаксис

Функция:

- `isOctal(value)`

Параметри:

- `value`: Стойността, която трябва да бъде проверена.

### Локален импорт на функция

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); // вярно
console.log(isOctal(b)); // вярно
console.log(isOctal(c)); // невярно
console.log(isOctal(d)); // невярно

if (isOctal(a)) {
  // a е низ тук
  const normalized = a.toLowerCase();
  console.log(normalized);
}
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isOctal(value)`
