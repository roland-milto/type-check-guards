# areEqual

## Описание

`areEqual` проверява дали всички елементи в масив са равни на дадена очаквана стойност, като връща `true` само за
непразни масиви, в които всеки елемент съвпада.

### Случай на употреба

Валидирайте, че списък съдържа само една позволена стойност (напр. всички флагове за статус са `true`, всички роли са
`"admin"` или всички числови записи са равни на изисквана константа), като третирате празния вход като невалиден (
`false`).

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areEqual`, когато ви е нужна строга проверка „всички елементи“; връща `false` за празни масиви и за всеки
> вход, който не е масив или не е запълнен.

### Предимства

- Връща `true` само когато всеки елемент съвпада с очакваната стойност; в противен случай връща `false`.
- Прекратява рано: спира проверката веднага щом бъде намерен елемент, който не съвпада.
- Предпазва от невалиден вход, като връща `false`, когато входът не е запълнен масив.

## Използване

### Синтаксис

Функция:

- `areEqual(value, expected)`

Параметри:

- `value`: Масивът, който трябва да бъде проверен.
- `expected`: Елементът, с който да се сравнява всеки елемент от масива.

### Локален импорт на функция

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areEqual(value, expected)`
