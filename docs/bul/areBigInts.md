# areBigInts

## Описание

`areBigInts` определя дали дадена стойност е непразен масив, съдържащ само стойности от тип `bigint`.

### Случай на употреба

Валидирайте неизвестен вход (напр. парснати JSON-подобни данни, API payload-и или параметри на функции, типизирани като
`unknown`), за да се уверите, че представлява непразен масив от стойности `bigint` преди обработка; връща `true` само
когато всички елементи са `bigint`, в противен случай `false`.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areBigInts` като runtime guard, преди да извършвате операции само с `bigint` (напр. аритметика,
> сравнения) върху входни данни с неизвестен тип.

### Предимства

- Гарантира, че всеки елемент е `bigint`, като връща `true` само когато целият масив съвпада.
- По замисъл отхвърля стойности, които не са масиви, както и празни масиви (чрез `isFilledArray`), предотвратявайки
  случайно приемане на невалидни входни данни.
- Бързо прекратяване: връща `false` веднага щом бъде открит елемент, който не е `bigint`.

## Използване

### Синтаксис

Функция:

- `areBigInts(array)`

Параметри:

- `array`: Стойността за проверка.

### Локален импорт на функция

```ts
import { areBigInts } from "@type-check/guards";

const a: unknown = [10n, 20n];
const b: unknown = [10n, 20];
const c: unknown = [];

console.log(areBigInts(a)); // вярно
console.log(areBigInts(b)); // невярно
console.log(areBigInts(c)); // невярно
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areBigInts(array)`
