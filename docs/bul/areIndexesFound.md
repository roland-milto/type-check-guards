# areIndexesFound

## Описание

`areIndexesFound` проверява дали дадена стойност е непразен масив, чиито елементи са всички валидни индекси, като връща
`true`, ако са, и `false` в противен случай.

### Случай на употреба

Валидирайте предоставени от потребителя или външни данни (напр. парсиран JSON), за които се очаква да са списък от
индекси, преди да ги използвате за достъп или изрязване на масиви.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areIndexesFound`, за да валидирате неизвестен вход, преди да третирате елементите му като индекси на
> масив; връща `false` за празни масиви и за масиви, съдържащи стойности, които не са индекси.

### Предимства

- Връща `true` само когато входът е непразен масив и всеки елемент е валиден индекс.
- Прекратява рано: връща `false` веднага щом бъде срещнат елемент, който не е индекс.
- Полезно като защита преди използване на стойности като позиции или отмествания в масив.

## Използване

### Синтаксис

Функция:

- `areIndexesFound(array)`

Параметри:

- `array`: Масивът, който трябва да бъде проверен за съответствие с индексите.

### Локален импорт на функция

```ts
import { areIndexesFound } from "@type-check/guards";

const a: unknown[] = [0, 1, 2];
const b: unknown[] = [0, "a", 2];
const c: unknown[] = [];

console.log(areIndexesFound(a)); // вярно
console.log(areIndexesFound(b)); // невярно
console.log(areIndexesFound(c)); // невярно

if (areIndexesFound(a)) {
  // Тук `a` е потвърдено като запълнен масив от индекси.
  const firstIndex = a[0];
  console.log(firstIndex);
}
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areIndexesFound(array)`
