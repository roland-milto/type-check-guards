# areBinaries

## Описание

Проверява дали предоставената стойност е непразен масив от валидни двоични низове и връща `true` само ако всички
елементи преминат валидацията.

### Случай на употреба

Използвайте `areBinaries`, когато получавате неизвестен списък (напр. от JSON, формуляри или API) и трябва да се
уверите, че това е непразен масив от двоични низове преди парсване или обработка.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `areBinaries`, за да валидирате неизвестен вход преди преобразуване на двоични низове в числа/BigInts; то
> гарантира, че масивът е непразен и всеки елемент е валиден двоичен низ.

### Предимства

- Проверява дали дадена стойност е непразен масив, в който всеки елемент е валиден двоичен низ.
- Връща прост булев резултат (`true`/`false`), подходящ за гардове, ранни изходи и валидиране на входни данни.
- Предотвратява последващи грешки при парсване, като отхвърля масиви, които съдържат какъвто и да е недвоичен елемент.

## Използване

### Синтаксис

Функция:

- `areBinaries(array)`

Параметри:

- `array`: Стойността, която трябва да бъде проверена.

### Локален импорт на функция

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // вярно
console.log(areBinaries(b)); // невярно
console.log(areBinaries([])); // невярно
```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areBinaries(array)`
