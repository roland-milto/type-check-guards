# areMaps

## Описание

`areMaps` определя дали даден масив е непразен и дали всички негови елементи са инстанции на `Map`.

### Случай на употреба

Валидирайте неизвестен вход (напр. от парсване на JSON, външни API или динамични източници), преди да го третирате като
непразен списък от обекти `Map`.

> **Бележка за потребителите на TypeScript:**
>
> Връща `false` за празен масив; връща `true` само когато масивът е запълнен и всеки елемент е `Map`.

### Предимства

- Гарантира, че всеки елемент е инстанция на `Map`, като връща `true` само когато целият масив премине проверката.
- По замисъл отхвърля празни масиви, предотвратявайки случайното приемане на „няма данни“ като валиден вход.
- Полезно като предпазна проверка преди изпълнение на операции, специфични за `Map` (напр. `.get()`, `.set()`,
  обхождане) върху колекция.

## Използване

### Синтаксис

Функция:

- `areMaps(array)`

Параметри:

- `array`: Масивът за проверка.

### Локален импорт на функция

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // items е гарантирано да е непразен масив от инстанции на Map по време на изпълнение
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // false за: празни масиви или масиви, съдържащи каквато и да е стойност, която не е Map
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.areMaps(array)`
