# isDate

## Описание

`isDate` определя дали предоставена стойност е `Date`, като връща `true` за инстанции на `Date` и `false` в противен
случай.

### Случай на употреба

Валидирайте и стеснете неизвестни стойности (напр. данни от заявка, конфигурационни стойности или парснат JSON), преди
да извършвате операции с `Date`, като форматиране, сравнения или извикване на `toISOString()`.

> **Бележка за потребителите на TypeScript:**
>
> Използвайте `isDate`, за да стесните `unknown` до `Date` по време на изпълнение; връща `true` само за реални инстанции
> на `Date` (не за низове с дати).

### Предимства

- Предоставя проста защита по време на изпълнение, за да се провери дали дадена стойност е `Date`.
- Помага да се предотвратят грешки в типовете, като гарантира, че само инстанции на `Date` преминават валидирането.
- Полезно е за валидиране на неизвестни входни данни (напр. payload-и от API), преди да се използват методи, специфични
  за дати.

## Използване

### Синтаксис

Функция:

- `isDate(value)`

Параметри:

- `value`: Стойността, която трябва да бъде проверена за тип `Date`.

### Локален импорт на функция

```ts
import { isDate } from "@type-check/guards";

const input: unknown = new Date();

if (isDate(input)) {
  // тук input е Date
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a Date");
}

```

### Глобален импорт на обект

За импорт на функциите като глобални методи на обект използвайте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следният метод ще бъде наличен глобално:

- `Type.isDate(value)`
