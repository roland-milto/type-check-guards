# areBinaries

## Описание

Проверяет, является ли переданное значение непустым массивом корректных двоичных строк, и возвращает `true` только если
все элементы проходят проверку.

### Сценарий использования

Используйте `areBinaries`, когда получаете неизвестный список (например, из JSON, форм или API) и нужно убедиться, что
это непустой массив двоичных строк перед разбором или обработкой.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areBinaries` для проверки неизвестного ввода перед преобразованием двоичных строк в числа/BigInt; это
> гарантирует, что массив непустой и каждый элемент является корректной двоичной строкой.

### Преимущества

- Проверяет, что значение является непустым массивом, где каждый элемент — корректная двоичная строка.
- Возвращает простой булев результат (`true`/`false`), подходящий для защитных проверок, ранних выходов и валидации
  ввода.
- Предотвращает ошибки последующего парсинга, отклоняя массивы, содержащие любые недвоичные значения.

## Использование

### Синтаксис

Функция:

- `areBinaries(array)`

Параметры:

- `array`: Значение, которое нужно проверить.

### Локальный импорт функции

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // истина
console.log(areBinaries(b)); // ложь
console.log(areBinaries([])); // ложь
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areBinaries(array)`
