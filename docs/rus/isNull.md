# isNull

## Описание

Определяет, является ли предоставленное `value` значением `null`.

### Сценарий использования

Используйте `isNull` для валидации входных данных или полей полезной нагрузки API, где `null` является значимым
значением-сентинелом и должно обрабатываться иначе, чем `undefined` или другие значения.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isNull`, когда нужно отличать `null` от `undefined` и других ложных значений; функция возвращает `true`
> только для `null`.

### Преимущества

- Обеспечивает точную проверку на `null`, не смешивая его с `undefined`.
- Надёжно работает для любого типа входных данных, поскольку принимает `unknown`.
- Простая, быстрая и без побочных эффектов; возвращает только `true` или `false`.

## Использование

### Синтаксис

Функция:

- `isNull(value)`

Параметры:

- `value`: Значение, которое нужно проверить на `null`.

### Локальный импорт функции

```ts
import { isNull } from "@type-check/guards";

const a: unknown = null;
const b: unknown = undefined;

console.log(isNull(a)); // true
console.log(isNull(b)); // false

if (isNull(a)) {
  // a здесь равно null
}
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isNull(value)`
