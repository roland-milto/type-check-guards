# areBooleans

## Описание

`areBooleans` проверяет, содержит ли заданный непустой массив только булевы значения, возвращая `true`, если это так, и
`false` в противном случае.

### Сценарий использования

Проверяйте предоставленные пользователем или внешние данные (например, JSON-полезные нагрузки, параметры запроса,
массивы конфигурации), чтобы убедиться, что непустой список содержит только булевы значения, прежде чем применять булеву
логику или передавать его в API, которые ожидают `boolean[]`.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areBooleans`, чтобы валидировать `unknown[]` перед тем, как трактовать его как `boolean[]`; функция
> возвращает `false` для пустых массивов, поэтому обработайте этот случай явно, если пустой список должен быть допустим.

### Преимущества

- Возвращает `true` только тогда, когда каждый элемент является булевым значением, а входные данные — непустой массив.
- Предотвращает ложные срабатывания, отклоняя пустые массивы (возвращает `false`).
- Хорошо подходит в качестве проверки во время выполнения перед операциями, рассчитанными только на булевы значения (
  например, `every`, `some`, логические свёртки).

## Использование

### Синтаксис

Функция:

- `areBooleans(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие булевых элементов.

### Локальный импорт функции

```ts
import { areBooleans } from "@type-check/guards";

const values1: unknown[] = [true, false, true];
if (areBooleans(values1)) {
  const allTrue = values1.every(v => v);
  console.log(allTrue);
}

const values2: unknown[] = [];
console.log(areBooleans(values2));

const values3: unknown[] = [true, 1, false];
console.log(areBooleans(values3));
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areBooleans(array)`
