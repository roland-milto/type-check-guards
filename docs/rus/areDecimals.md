# areDecimals

## Описание

Проверяет, что все элементы массива являются десятичными числами и массив заполнен, возвращая `true` или `false`.

### Сценарий использования

Проверять предоставленные пользователем списки (например, столбцы CSV или поля формы), чтобы убедиться, что массив не
пуст и каждая запись является десятичным значением перед разбором или вычислениями.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areDecimals`, когда нужна быстрая булева проверка того, что `unknown[]` не пуст и каждый элемент является
> десятичным представлением.

### Преимущества

- Гарантирует, что входные данные — это заполненный массив перед проверкой элементов, предотвращая случайное принятие
  пустых списков.
- Проверяет каждый элемент с помощью `isDecimal`, поэтому смешанные или некорректные значения сразу дают результат
  `false`.
- Предоставляет простой булев результат (`true`/`false`), подходящий для гардов и потоков валидации с ранним выходом.

## Использование

### Синтаксис

Функция:

- `areDecimals(array)`

Параметры:

- `array`: Массив, который нужно проверить.

### Локальный импорт функции

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // истина
console.log(areDecimals(b)); // ложь
console.log(areDecimals(c)); // ложь
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areDecimals(array)`
