# areFalse

## Описание

`areFalse` проверяет, что все элементы в переданном массиве строго являются логическим значением `false`.

### Сценарий использования

Проверьте, что список флагов функций, проверок или результатов guard-функций весь состоит из `false` перед
продолжением (например, подтвердите, что нет блокирующих условий).

> **Примечание для пользователей TypeScript:**
>
> Используйте `areFalse`, когда нужна строгая валидация, что массив не пуст и содержит только логическое значение
`false`.

### Преимущества

- Гарантирует, что каждый элемент строго равен `false` (без приведения truthy/falsey).
- Возвращает `false` для не-массивов или пустых массивов, требуя заполненный массив через `isFilledArray`.
- Для эффективности завершает проверку при первом элементе, не равном `false`.

## Использование

### Синтаксис

Функция:

- `areFalse(array)`

Параметры:

- `array`: Массив для проверки, содержащий элементы любого типа.

### Локальный импорт функции

```ts
import { areFalse } from "@type-check/guards";

const a = areFalse([false, false, false]); // истина
const b = areFalse([false, true, false]);  // ложь
const c = areFalse([false, "false", false]); // ложь
const d = areFalse([]); // ложь

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areFalse(array)`
