# isFalse

## Описание

`isFalse` проверяет, является ли заданное значение строго равным булевому литералу `false`.

### Сценарий использования

Валидируйте неизвестные данные (например, из JSON, параметров запроса или пользовательского ввода), где только явное
булево значение `false` должно считаться допустимым флагом, а всё остальное должно быть отклонено.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isFalse`, когда нужно принимать только литерал `false` и отклонять все остальные ложные значения; функция
> возвращает `true` только для `value === false`.

### Преимущества

- Обеспечивает строгую проверку булевого литерала `false` без приведения типов.
- Помогает отличать `false` от других ложных (falsy) значений, таких как `0`, `""`, `null` и `undefined`.
- Улучшает читаемость, делая намерение явным при валидации неизвестного ввода.

## Использование

### Синтаксис

Функция:

- `isFalse(value)`

Параметры:

- `value`: Значение, которое нужно проверить.

### Локальный импорт функции

```ts
import { isFalse } from "@type-check/guards";

const input: unknown = false;

if (isFalse(input)) {
  // здесь input точно равен false
  console.log("Got false");
} else {
  console.log("Not false");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isFalse(value)`
