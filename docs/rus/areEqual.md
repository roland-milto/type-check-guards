# areEqual

## Описание

`areEqual` проверяет, равны ли все элементы массива заданному ожидаемому значению, возвращая `true` только для непустых
массивов, где каждый элемент совпадает.

### Сценарий использования

Проверить, что список содержит только одно допустимое значение (например, все флаги статуса равны `true`, все роли —
`"admin"`, или все числовые значения равны требуемой константе), при этом считать пустой ввод недопустимым (`false`).

> **Примечание для пользователей TypeScript:**
>
> Используйте `areEqual`, когда нужна строгая проверка «все элементы»; она возвращает `false` для пустых массивов и для
> любого ввода, который не является массивом или не является заполненным.

### Преимущества

- Возвращает `true` только когда каждый элемент соответствует ожидаемому значению; иначе возвращает `false`.
- Быстро завершает проверку: прекращает проверять, как только найден несовпадающий элемент.
- Защищает от некорректного ввода, возвращая `false`, когда входные данные не являются заполненным массивом.

## Использование

### Синтаксис

Функция:

- `areEqual(value, expected)`

Параметры:

- `value`: Массив, который нужно проверить.
- `expected`: Элемент, с которым сравнивается каждый элемент массива.

### Локальный импорт функции

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areEqual(value, expected)`
