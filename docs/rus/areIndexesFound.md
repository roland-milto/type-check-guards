# areIndexesFound

## Описание

`areIndexesFound` проверяет, является ли значение непустым массивом, элементы которого все являются допустимыми
индексами; возвращает `true`, если это так, и `false` в противном случае.

### Сценарий использования

Проверять предоставленные пользователем или внешние данные (например, распарсенный JSON), которые ожидаются как список
индексов, прежде чем использовать их для доступа к массивам или их разрезания (slice).

> **Примечание для пользователей TypeScript:**
>
> Используйте `areIndexesFound`, чтобы валидировать неизвестный ввод перед тем, как трактовать его элементы как индексы
> массива; функция возвращает `false` для пустых массивов и для массивов, содержащих значения, не являющиеся индексами.

### Преимущества

- Возвращает `true` только когда входное значение — заполненный массив и каждый элемент является допустимым индексом.
- Быстро завершает проверку: возвращает `false`, как только встречается элемент, не являющийся индексом.
- Полезно как защитная проверка перед использованием значений в качестве позиций или смещений в массиве.

## Использование

### Синтаксис

Функция:

- `areIndexesFound(array)`

Параметры:

- `array`: Массив, который нужно проверить на соответствие требованиям к индексам.

### Локальный импорт функции

```ts
import { areIndexesFound } from "@type-check/guards";

const a: unknown[] = [0, 1, 2];
const b: unknown[] = [0, "a", 2];
const c: unknown[] = [];

console.log(areIndexesFound(a)); // true
console.log(areIndexesFound(b)); // false
console.log(areIndexesFound(c)); // false

if (areIndexesFound(a)) {
  // Здесь подтверждается, что `a` — заполненный массив индексов.
  const firstIndex = a[0];
  console.log(firstIndex);
}
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areIndexesFound(array)`
