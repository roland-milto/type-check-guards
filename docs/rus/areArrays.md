# areArrays

## Описание

`areArrays` определяет, является ли значение заполненным двумерным массивом, элементы которого все являются массивами.

### Сценарий использования

Используйте `areArrays` для проверки табличных или матричных входных данных (например, строк CSV, данных сетки или
сгруппированных списков) перед выполнением операций со строками/столбцами; функция возвращает `false`, если входное
значение не является массивом, пустое или содержит хотя бы один элемент, который не является массивом.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areArrays`, когда нужно убедиться, что значение является непустым двумерным массивом и что каждая
> строка — массив, прежде чем выполнять итерацию или индексирование во вложенных массивах.

### Преимущества

- Проверяет, что входное значение — непустой двумерный массив, где каждый элемент является массивом.
- Возвращает простой булев результат (`true`/`false`), подходящий для защитных проверок и раннего выхода.
- Помогает предотвратить ошибки во время выполнения, когда последующий код предполагает операции с вложенными
  массивами (например, отображение строк).

## Использование

### Синтаксис

Функция:

- `areArrays(array)`

Параметры:

- `array`: Входное значение, которое нужно проверить.

### Локальный импорт функции

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value — это двумерный массив с массивами в качестве элементов
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areArrays(array)`
