# arePrimitives

## Описание

`arePrimitives` определяет, являются ли все элементы в предоставленном непустом массиве примитивными типами.

### Сценарий использования

Проверяйте, что входящие данные (например, параметры запроса, значения строк CSV или список ID/тегов) содержат только
примитивные значения перед сериализацией, хешированием, логированием или передачей в API, которые не должны получать
объекты.

> **Примечание для пользователей TypeScript:**
>
> Используйте `arePrimitives`, когда нужно убедиться, что `unknown[]` содержит только примитивные значения (string,
> number, bigint, boolean, symbol, undefined или null) перед дальнейшей обработкой.

### Преимущества

- Возвращает `true` только тогда, когда каждый элемент является примитивным значением, что делает её строгой проверкой
  для массивов «без объектов/функций».
- Быстро завершает проверку: возвращает `false`, как только обнаруживается непримитивный элемент.
- Также возвращает `false` для не-массивов и пустых массивов (через проверку на заполненный массив), предотвращая
  случайное принятие некорректного ввода.

## Использование

### Синтаксис

Функция:

- `arePrimitives(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие элементов примитивного типа.

### Локальный импорт функции

```ts
import { arePrimitives } from "@type-check/guards";

const a: unknown[] = [1, "string", true];
const b: unknown[] = [null, undefined, Symbol("x")];
const c: unknown[] = [1, {}, false];

const r1 = arePrimitives(a); // true
const r2 = arePrimitives(b); // true
const r3 = arePrimitives(c); // false
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.arePrimitives(array)`
