# areMaps

## Описание

`areMaps` определяет, является ли заданный массив непустым и состоят ли все его элементы из экземпляров `Map`.

### Сценарий использования

Проверяйте неизвестный ввод (например, после парсинга JSON, из внешних API или динамических источников) перед тем, как
трактовать его как непустой список объектов `Map`.

> **Примечание для пользователей TypeScript:**
>
> Возвращает `false` для пустого массива; `true` возвращается только тогда, когда массив заполнен и каждый элемент
> является `Map`.

### Преимущества

- Гарантирует, что каждый элемент является экземпляром `Map`, возвращая `true` только тогда, когда проверку проходит
  весь массив.
- По замыслу отклоняет пустые массивы, предотвращая случайное принятие «нет данных» за корректный ввод.
- Полезно как защитная проверка перед выполнением операций, специфичных для `Map` (например, `.get()`, `.set()`,
  итерация) по всей коллекции.

## Использование

### Синтаксис

Функция:

- `areMaps(array)`

Параметры:

- `array`: Массив для проверки.

### Локальный импорт функции

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // гарантируется, что items является непустым массивом экземпляров Map во время выполнения
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // false для: пустых массивов или массивов, содержащих любое значение, не являющееся Map
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areMaps(array)`
