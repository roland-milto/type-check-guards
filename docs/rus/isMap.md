# isMap

## Описание

Проверяет, является ли заданное `value` объектом `Map`, возвращая `true`, если это так, и `false` в противном случае.

### Сценарий использования

Используйте `isMap`, когда вы получаете значение типа `unknown` (например, из парсинга JSON, внешних API или
пользовательского ввода) и вам нужно убедиться, что это `Map`, прежде чем выполнять операции `Map`.

> **Примечание для пользователей TypeScript:**
>
> `isMap` — это runtime-guard, который возвращает `true`, когда значение является `Map`, и `false` в противном случае;
> используйте его, чтобы сузить `unknown` перед вызовом API `Map`.

### Преимущества

- Обеспечивает быструю проверку во время выполнения, является ли значение `Map`.
- Помогает предотвратить ошибки типов, защищая ветви кода, которым требуются методы `Map`, такие как `get`, `set` и
  `has`.
- Хорошо подходит как лёгкий шаг валидации при обработке входных данных типа `unknown`.

## Использование

### Синтаксис

Функция:

- `isMap(value)`

Параметры:

- `value`: Значение для проверки.

### Локальный импорт функции

```ts
import { isMap } from "@type-check/guards";

const input: unknown = new Map<string, number>([["a", 1]]);

if (isMap(input)) {
  input.set("b", 2);
  const a = input.get("a");
  console.log(a);
} else {
  console.log("Not a Map");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isMap(value)`
