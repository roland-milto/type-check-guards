# areErrors

## Описание

Проверяет, что массив непустой и содержит только объекты `Error`, возвращая `true` или `false`.

### Сценарий использования

Проверить, что предоставленный во время выполнения `unknown[]` (например, агрегированные сбои, результаты валидации или
десериализованные данные) является непустым списком объектов `Error` перед итерацией, логированием или повторным
выбрасыванием.

> **Примечание для пользователей TypeScript:**
>
> `areErrors` возвращает `true` только для заполненного массива, где каждый элемент — это `Error`; он возвращает `false`
> для пустого массива или если какой-либо элемент не является `Error`.

### Преимущества

- Гарантирует, что каждый элемент является экземпляром `Error`, обеспечивая безопасную обработку ошибок и логирование.
- Отклоняет пустые массивы, предотвращая случайные состояния «нет ошибок», которые могут быть ошибочно приняты за
  корректные списки ошибок.
- Хорошо подходит как runtime-проверка при работе с входными данными типа `unknown[]` (например, из API или блоков
  `catch`).

## Использование

### Синтаксис

Функция:

- `areErrors(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие объектов `Error`.

### Локальный импорт функции

```ts
import { areErrors } from "@type-check/guards";

const value: unknown = [new Error("error1"), new TypeError("error2")];

if (Array.isArray(value) && areErrors(value)) {
  // value — непустой массив объектов Error
  for (const err of value) {
    console.error(err.name, err.message);
  }
} else {
  console.log("Not a non-empty Error[]");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areErrors(array)`
