# areBuffers

## Описание

`areBuffers` проверяет, является ли предоставленное значение непустым, заполненным массивом, где каждый элемент — это
`Buffer`, возвращая `true` в этом случае и `false` в противном.

### Сценарий использования

Проверяйте входящие массивы чанков (например, из потоков, загрузок файлов или сетевых пакетов), чтобы убедиться, что все
части являются экземплярами `Buffer`, прежде чем конкатенировать, декодировать или передавать их в криптографические или
бинарные функции обработки.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areBuffers` для валидации `unknown[]` перед вызовом API, специфичных для Buffer, таких как
`Buffer.concat`, чтобы функция возвращала `true` только когда каждый элемент является `Buffer`.

### Преимущества

- Гарантирует, что каждый элемент во входных данных является экземпляром Node.js `Buffer`, возвращая `true` только когда
  совпадает весь массив целиком.
- Рано отклоняет некорректные входные данные, требуя непустой, заполненный массив; возвращает `false` для пустых
  массивов или не-массивов.
- Полезно как защитная проверка перед выполнением операций только для буферов (например, конкатенация, хеширование,
  бинарные протоколы).

## Использование

### Синтаксис

Функция:

- `areBuffers(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие экземпляров буфера.

### Локальный импорт функции

```ts
import { areBuffers } from "@type-check/guards";

const chunks: unknown[] = [Buffer.from("test"), Buffer.from("123")];

if (areBuffers(chunks)) {
  const combined = Buffer.concat(chunks);
  console.log(combined.toString("utf8"));
} else {
  throw new TypeError("Expected a non-empty array of Buffer instances");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areBuffers(array)`
