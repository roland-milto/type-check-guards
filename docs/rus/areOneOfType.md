# areOneOfType

## Описание

`areOneOfType` проверяет, что все элементы непустого массива относятся к одному из указанных типов во время выполнения.

### Сценарий использования

Проверять входящие данные (например, распарсенный JSON), где поле должно быть непустым массивом, элементы которого
ограничены известным набором примитивных типов; возвращать `false`, если массив пуст или содержит любой недопустимый
тип.

> **Примечание для пользователей TypeScript:**
>
> Эта функция возвращает boolean и не сужает типы элементов массива на этапе компиляции; используйте её как шаг
> валидации во время выполнения перед дальнейшей обработкой.

### Преимущества

- Гарантирует, что каждый элемент массива соответствует как минимум одному разрешённому типу во время выполнения,
  возвращая `true` только когда проверку проходит весь массив.
- Рано отклоняет некорректные входные данные: возвращает `false`, когда `array` или `types` пусты либо не являются
  заполненным массивом.
- Полезно для валидации коллекций со смешанными типами (например, числа и строки) одним вызовом `areOneOfType`.

## Использование

### Синтаксис

Функция:

- `areOneOfType(array, types)`

Параметры:

- `array`: Массив элементов, которые нужно проверить на соответствие предоставленным типам.
- `types`: Массив строк, представляющих типы данных, по которым выполняется проверка.

### Локальный импорт функции

```ts
import { areOneOfType } from "@type-check/guards";

const values1: unknown[] = [1, "a", true];
const ok1 = areOneOfType(values1, ["number", "string", "boolean"]);

const values2: unknown[] = [1, "a", {}];
const ok2 = areOneOfType(values2, ["number", "string"]);

const values3: unknown[] = [];
const ok3 = areOneOfType(values3, ["number"]);

console.log({ ok1, ok2, ok3 });
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areOneOfType(array, types)`
