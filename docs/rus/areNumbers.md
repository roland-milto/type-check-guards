# areNumbers

## Описание

`areNumbers` проверяет, является ли значение непустым массивом, в котором все элементы — числа.

### Сценарий использования

Проверяйте данные, предоставленные пользователем или API, чтобы убедиться, что это непустой массив чисел, прежде чем
вычислять суммы, средние значения или другие числовые агрегаты.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areNumbers`, чтобы валидировать неизвестные массивы перед выполнением числовых вычислений; функция
> возвращает `false` для пустых массивов и для массивов, содержащих любое нечисловое значение.

### Преимущества

- Возвращает `true` только тогда, когда входное значение — непустой массив и каждый элемент является числом.
- Предотвращает ложные срабатывания, отклоняя пустые массивы и значения, не являющиеся массивами.
- Полезно как защитная проверка перед числовыми операциями (например, суммированием, вычислением среднего), чтобы
  избежать ошибок во время выполнения.

## Использование

### Синтаксис

Функция:

- `areNumbers(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие числовых элементов.

### Локальный импорт функции

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areNumbers(array)`
