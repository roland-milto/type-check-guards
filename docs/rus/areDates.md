# areDates

## Описание

`areDates` определяет, заполнен ли заданный массив и содержит ли он только объекты `Date`, возвращая `true` только когда
все элементы являются корректными датами.

### Сценарий использования

Используйте `areDates` для проверки неизвестного ввода (например, разобранного JSON, данных формы, payload’ов API) перед
запуском логики, специфичной для дат, такой как сортировка по времени, форматирование или вычисление диапазонов.

> **Примечание для пользователей TypeScript:**
>
> Возвращает `true` только для непустых массивов, где каждый элемент — `Date`; пустые массивы дают `false`.

### Преимущества

- Гарантирует, что массив не пуст перед проверкой его содержимого, предотвращая `true` для пустых входных данных.
- Проверяет, что каждый элемент является экземпляром `Date`, немедленно возвращая `false` при первом несоответствии.
- Полезно как проверка в стиле guard перед выполнением операций, специфичных для дат, над элементами массива.

## Использование

### Синтаксис

Функция:

- `areDates(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие объектов `Date`.

### Локальный импорт функции

```ts
import { areDates } from "@type-check/guards";

const a: unknown[] = [new Date(), new Date("2021-01-01")];
const b: unknown[] = [];
const c: unknown[] = [new Date(), "not a date"];

console.log(areDates(a)); // истина
console.log(areDates(b)); // ложь
console.log(areDates(c)); // ложь

if (areDates(a)) {
  const timestamps = a.map(d => d.getTime());
  console.log(timestamps);
}
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areDates(array)`
