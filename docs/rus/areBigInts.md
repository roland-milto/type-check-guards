# areBigInts

## Описание

`areBigInts` определяет, является ли значение непустым массивом, содержащим только значения `bigint`.

### Сценарий использования

Проверяйте неизвестный ввод (например, разобранные JSON-подобные данные, полезные нагрузки API или параметры функций,
типизированные как `unknown`), чтобы убедиться, что это непустой массив значений `bigint` перед обработкой; возвращает
`true` только когда все элементы — `bigint`, иначе `false`.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areBigInts` как runtime-проверку (guard) перед выполнением операций, допустимых только для `bigint` (
> например, арифметики, сравнений), над неизвестным вводом.

### Преимущества

- Гарантирует, что каждый элемент является `bigint`, возвращая `true` только когда соответствует весь массив целиком.
- По замыслу отклоняет не-массивы и пустые массивы (через `isFilledArray`), предотвращая случайное принятие недопустимых
  входных данных.
- Быстрый отказ: возвращает `false`, как только обнаруживается элемент, не являющийся `bigint`.

## Использование

### Синтаксис

Функция:

- `areBigInts(array)`

Параметры:

- `array`: Значение для проверки.

### Локальный импорт функции

```ts
import { areBigInts } from "@type-check/guards";

const a: unknown = [10n, 20n];
const b: unknown = [10n, 20];
const c: unknown = [];

console.log(areBigInts(a)); // истина
console.log(areBigInts(b)); // ложь
console.log(areBigInts(c)); // ложь
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areBigInts(array)`
