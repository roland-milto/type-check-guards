# areSymbols

## Описание

Проверяет, является ли входное значение заполненным массивом, элементы которого все являются символами, возвращая `true`
или `false`.

### Сценарий использования

Проверить, что поле конфигурации (например, список уникальных ключей, представленных символами) является непустым
массивом, содержащим только символы, прежде чем использовать его в API, которым требуется `symbol[]`.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areSymbols`, чтобы проверять неизвестный ввод перед тем, как трактовать его как `symbol[]`; функция
> возвращает `false` для не-массивов и пустых массивов.

### Преимущества

- Возвращает `true` только тогда, когда входное значение — непустой массив и каждый элемент является символом.
- Предотвращает ложные срабатывания, отклоняя не-массивы и пустые массивы с помощью внутренней проверки заполненного
  массива.
- Полезно как runtime type guard для проверки списков, содержащих только символы, перед дальнейшей обработкой.

## Использование

### Синтаксис

Функция:

- `areSymbols(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие элементов-символов.

### Локальный импорт функции

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  // a — это массив, содержащий только символы, во время выполнения
  const first = a[0];
  console.log(typeof first); // "symbol"
}

console.log(areSymbols(b)); // false
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areSymbols(array)`
