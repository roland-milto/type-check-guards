# arePlainObjects

## Описание

Проверяет, являются ли все элементы массива простыми объектами, возвращая `true` только если каждый элемент подходит.

### Сценарий использования

Проверяйте внешние или нетипизированные данные (например, распарсенный JSON, payload’ы API, отправки форм), чтобы
убедиться, что вы получили непустой массив, где каждая запись — простой объект, прежде чем итерироваться и читать
свойства.

> **Примечание для пользователей TypeScript:**
>
> Используйте `arePlainObjects`, чтобы валидировать неизвестный ввод перед тем, как трактовать его как
`Record<string, unknown>[]` (или более строгую форму объекта) в TypeScript.

### Преимущества

- Гарантирует, что каждый элемент входного массива является простым объектом, возвращая `true` только когда все элементы
  соответствуют.
- Рано отклоняет некорректные входные данные (не массивы или пустые массивы), возвращая `false`.
- Считает валидными простыми объектами как объектные литералы, так и объекты `Object.create(null)`.

## Использование

### Синтаксис

Функция:

- `arePlainObjects(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие элементов — простых объектов.

### Локальный импорт функции

```ts
import { arePlainObjects } from "@type-check/guards";

const a = arePlainObjects([{ a: 1 }, { b: 2 }]); // истина
const b = arePlainObjects([{}, Object.create(null)]); // истина
const c = arePlainObjects([{ a: 1 }, 2 as unknown]); // ложь
const d = arePlainObjects([] as unknown[]); // ложь
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.arePlainObjects(array)`
