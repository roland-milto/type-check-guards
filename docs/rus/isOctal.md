# isOctal

## Описание

Определяет, является ли значение корректной строкой восьмеричного литерала (например, `0o755`).

### Сценарий использования

Проверять пользовательский ввод или значения конфигурации, которые должны быть выражены строкой восьмеричного литерала (
например, режимы прав доступа к файлам вроде `0o644`), перед разбором или преобразованием.

> **Примечание для пользователей TypeScript:**
>
> `isOctal` — это защитник типов (`value is string`). После результата `true` TypeScript сужает проверяемую переменную
> до `string`.

### Преимущества

- Предоставляет строгий защитник типов: возвращает `true` только когда входное значение — строка, соответствующая
  формату восьмеричного литерала.
- Отклоняет пустые строки и строки с ведущими/замыкающими пробельными символами (ASCII управляющие/пробел), снижая
  вероятность случайных совпадений.
- Поддерживает необязательный знак и не чувствителен к регистру для префикса `0o`/`0O`.
- Лоялен к нестроковым входным значениям: возвращает `false` вместо выбрасывания исключения.

## Использование

### Синтаксис

Функция:

- `isOctal(value)`

Параметры:

- `value`: Значение, которое нужно проверить.

### Локальный импорт функции

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); // истина
console.log(isOctal(b)); // истина
console.log(isOctal(c)); // ложь
console.log(isOctal(d)); // ложь

if (isOctal(a)) {
  // здесь a является строкой
  const normalized = a.toLowerCase();
  console.log(normalized);
}
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isOctal(value)`
