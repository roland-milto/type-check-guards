# isEmpty

## Описание

Определяет, является ли заданное значение пустым, возвращая `true` для `null`, `undefined`, пустых/пробельных строк,
пустых массивов, пустых `Map`/`Set` или объектов без собственных перечислимых свойств.

### Сценарий использования

Используйте `isEmpty` для валидации входных данных и обнаружения отсутствующих/пустых значений в разных типах данных (
например, поля форм, payload API, объекты конфигурации), где `null`, `undefined`, пробельные строки, пустые коллекции и
объекты без свойств должны считаться пустыми.

> **Примечание для пользователей TypeScript:**
>
> `isEmpty` — это утилита, возвращающая boolean (а не предикат типа TypeScript), поэтому сама по себе она не сужает
> типы; используйте её для валидации/ветвления, а не для сужения на этапе компиляции.

### Преимущества

- Считает `null` и `undefined` пустыми (возвращает `true`) при проверках на пустоту.
- Считает строки, состоящие только из пробельных символов, пустыми, предварительно выполняя `trim` перед проверкой
  длины.
- Поддерживает распространённые контейнеры (массивы, `Map`, `Set`) и обычные объекты без собственных перечислимых
  свойств.
- Избегает подсчёта унаследованных свойств, используя проверки `hasOwnProperty`.
- Возвращает простой булев результат (`true`/`false`), подходящий для гардов и валидации.

## Использование

### Синтаксис

Функция:

- `isEmpty(value)`

Параметры:

- `value`: Значение, которое нужно проверить на пустоту.

### Локальный импорт функции

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isEmpty(value)`
