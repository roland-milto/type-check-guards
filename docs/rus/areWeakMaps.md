# areWeakMaps

## Описание

`areWeakMaps` проверяет, является ли значение непустым массивом, где каждый элемент — `WeakMap`, возвращая `true` только
в этом случае и `false` в противном.

### Сценарий использования

Проверять данные во время выполнения (например, распарсенный JSON, входные данные плагинов или слабо типизированную
конфигурацию), чтобы убедиться, что это непустой массив экземпляров `WeakMap`, прежде чем итерироваться по нему и
вызывать методы `WeakMap`; возвращает `false`, если какой-либо элемент не является `WeakMap` или если массив пуст.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areWeakMaps`, чтобы валидировать неизвестный ввод перед тем, как трактовать его как непустой `WeakMap[]`;
> для пустых массивов функция возвращает `false`.

### Преимущества

- Гарантирует, что каждый элемент в предоставленном массиве является экземпляром `WeakMap`.
- Возвращает `false` для пустых массивов, предотвращая случайное принятие «отсутствия данных» за корректный ввод.
- Полезно как защитная проверка перед выполнением операций, специфичных для `WeakMap`, над всеми элементами.

## Использование

### Синтаксис

Функция:

- `areWeakMaps(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие экземпляров `WeakMap`.

### Локальный импорт функции

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  // list — непустой массив экземпляров WeakMap
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  // не непустой WeakMap[]
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areWeakMaps(array)`
