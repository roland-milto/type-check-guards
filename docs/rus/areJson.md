# areJson

## Описание

Проверяет, являются ли все элементы массива JSON-строками, возвращая `true` только если массив заполнен и каждый
элемент — корректный JSON; иначе возвращает `false`.

### Сценарий использования

Проверка входящих данных (например, из параметров запроса, переменных окружения или внешних API), когда ожидается массив
строк, закодированных в JSON, и нужно отклонять пустые массивы или любые элементы, не являющиеся JSON.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areJson`, когда нужно проверить, что `unknown[]` содержит только JSON-строки перед их разбором (например,
> с помощью `JSON.parse`).

### Преимущества

- Возвращает `true` только тогда, когда каждый элемент является корректной JSON-строкой; в противном случае возвращает
  `false`.
- Быстро завершает проверку: прекращает проверять, как только найден элемент, не являющийся JSON.
- По задумке отклоняет пустые массивы, возвращая `false` для незаполненного ввода.

## Использование

### Синтаксис

Функция:

- `areJson(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие элементов, являющихся JSON-строками.

### Локальный импорт функции

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // истина
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // ложь
const empty = areJson([]); // ложь

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areJson(array)`
