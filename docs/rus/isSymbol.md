# isSymbol

## Описание

`isSymbol` определяет, является ли заданное значение типом `symbol`, возвращая `true` для symbol и `false` в противном
случае.

### Сценарий использования

Проверяйте, что значение типа `unknown` является `symbol`, прежде чем использовать его как уникальный идентификатор,
ключ реестра или вычисляемый ключ свойства в объектах и картах.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isSymbol`, чтобы сузить `unknown` до `symbol` перед вызовом функций, связанных с symbol, или
> использованием его в качестве вычисляемого ключа свойства.

### Преимущества

- Обеспечивает простую и надёжную проверку во время выполнения для примитивного типа JavaScript `symbol`.
- Помогает сузить значения типа `unknown` перед использованием API, специфичных для symbol, или перед сохранением их в
  качестве ключей.
- Избегает ложных срабатываний благодаря использованию `typeof`, который является каноническим способом определения
  значений `symbol`.

## Использование

### Синтаксис

Функция:

- `isSymbol(value)`

Параметры:

- `value`: Значение, которое нужно проверить.

### Локальный импорт функции

```ts
import { isSymbol } from "@type-check/guards";

const input: unknown = Symbol("key");

if (isSymbol(input)) {
  // здесь input является символом
  const registryKey = Symbol.keyFor(input);
  console.log(registryKey);
} else {
  console.log("Not a symbol");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isSymbol(value)`
