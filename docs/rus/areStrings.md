# areStrings

## Описание

`areStrings` проверяет, что массив непустой и все его элементы — строки, возвращая `true` только в этом случае.

### Сценарий использования

Проверяйте внешние или предоставленные пользователем данные (например, параметры запроса, JSON-полезные нагрузки, поля
CSV), чтобы убедиться, что у вас есть непустой список строк перед обработкой.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areStrings` для проверки неизвестных массивов перед применением логики только для строк; для пустых
> массивов она возвращает `false`.

### Преимущества

- Гарантирует, что каждый элемент является строкой, и отклоняет массивы со смешанными типами, возвращая `false`.
- Отклоняет пустые массивы, поэтому `true` означает только непустой список строк.
- Полезно как быстрая проверка во время выполнения перед выполнением операций только со строками (например, `trim`,
  `toLowerCase`).

## Использование

### Синтаксис

Функция:

- `areStrings(value)`

Параметры:

- `value`: Expected type `string[]`.

### Локальный импорт функции

```ts
import { areStrings } from "@type-check/guards";

const input: unknown = ["hello", "world"];

if (Array.isArray(input) && areStrings(input)) {
  // input является непустым string[] во время выполнения
  const upper = input.map((s) => s.toUpperCase());
  console.log(upper);
} else {
  console.log("Not a non-empty array of strings");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areStrings(value)`
