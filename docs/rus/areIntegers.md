# areIntegers

## Описание

`areIntegers` определяет, являются ли все элементы в заданном массиве целыми числами, возвращая `true`, если это так, и
`false` в противном случае.

### Сценарий использования

Используйте `areIntegers` для валидации данных, предоставленных пользователем или полученных извне (например, параметры
запроса, JSON-полезная нагрузка, строки CSV), когда вашей логике требуется заполненный список целочисленных значений,
таких как ID, счётчики, смещения пагинации или индексы массива.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areIntegers` как runtime-guard для входных данных типа `unknown[]` перед тем, как трактовать их как
`number[]`, содержащий только целые числа. Если функция возвращает `false`, входные данные либо не являются заполненным
> массивом, либо содержат как минимум одно нецелое значение.

### Преимущества

- Возвращает `true` только тогда, когда каждый элемент является целым числом; в противном случае возвращает `false`.
- Помогает валидировать неизвестный ввод перед выполнением операций, допустимых только для целых чисел (например,
  индексация, счётчики, ID).
- Быстро завершает проверку: прекращает проверять, как только найден нецелочисленный элемент.

## Использование

### Синтаксис

Функция:

- `areIntegers(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие только целочисленных элементов.

### Локальный импорт функции

```ts
import { areIntegers } from "@type-check/guards";

const a: unknown[] = [1, 2, 3];
const b: unknown[] = [0, -10, 42];
const c: unknown[] = [1, 2, "3"];

console.log(areIntegers(a)); // true
console.log(areIntegers(b)); // true
console.log(areIntegers(c)); // false

function sumIntegers(values: unknown[]): number {
  if (!areIntegers(values)) {
    throw new TypeError("Expected a filled array of integers");
  }
  return (values as number[]).reduce((acc, n) => acc + n, 0);
}

console.log(sumIntegers([10, 20, 30]));

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areIntegers(array)`
