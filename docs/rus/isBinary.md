# isBinary

## Описание

`isBinary` определяет, является ли значение двоичной строкой (опционально с префиксом `0b`/`0B`), и возвращает `true`
или `false`.

### Сценарий использования

Проверяйте строки, предоставленные пользователем (например, поля форм, аргументы CLI, значения конфигурации), чтобы
убедиться, что они содержат только двоичные цифры, опционально с префиксом `0b`/`0B`, перед дальнейшей обработкой.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isBinary` как защиту типов (type guard) перед разбором или преобразованием строки в `BigInt`/`Number`,
> чтобы избежать некорректного ввода.

### Преимущества

- Принимает двоичные строки с префиксом `0b`/`0B` или без него.
- Отклоняет пустые строки и строки с ведущими/замыкающими пробельными символами (ASCII ≤ 32).
- Возвращает `true`/`false` без выбрасывания исключений, что делает функцию безопасной для неизвестных входных данных.

## Использование

### Синтаксис

Функция:

- `isBinary(value)`

Параметры:

- `value`: Проверяемое значение.

### Локальный импорт функции

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // истина
const b = isBinary("1010");   // истина
const c = isBinary("0b1020"); // ложь
const d = isBinary(0b1010);     // ложь

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isBinary(value)`
