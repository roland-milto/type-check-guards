# isOneOfType

## Описание

`isOneOfType` определяет, соответствует ли заданное `value` хотя бы одной из предоставленных строк типов, возвращая
`true`, если найдено любое совпадение, и `false` в противном случае.

### Сценарий использования

Проверяйте слаботипизированные или внешние данные (например, разобранный JSON, параметры запроса), разрешая несколько
приемлемых типов во время выполнения (таких как `number` или `string`) перед продолжением дальнейшей логики.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isOneOfType`, когда вам нужна проверка во время выполнения, что значение соответствует любому из
> нескольких допустимых типов; она возвращает `true`, если совпадает хотя бы один тип, иначе `false`.

### Преимущества

- Проверяет значение на соответствие нескольким допустимым типам за один вызов, возвращая `true` при первом совпадении.
- Работает с входными данными типа `unknown`, что делает его полезным на границах выполнения (например, внешние данные,
  ввод пользователя).
- Возвращает простой булев результат (`true`/`false`), который хорошо сочетается с условной логикой и ранними
  возвратами.

## Использование

### Синтаксис

Функция:

- `isOneOfType(value, types)`

Параметры:

- `value`: Значение, которое нужно проверить на соответствие указанным типам.
- `types`: Массив строк типов, представляющих возможные типы значения.

### Локальный импорт функции

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // input является объектом во время выполнения
}

console.log(isOneOfType(3, ["number", "string"])); // true
console.log(isOneOfType("hello", ["number", "boolean"])); // false

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isOneOfType(value, types)`
