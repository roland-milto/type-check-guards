# isObject

## Описание

Определяет, является ли заданное `value` объектом (`object`) (исключая `null`).

### Сценарий использования

Используйте `isObject` для валидации неизвестных входных данных (например, распарсенного JSON, ответов API, полезной
нагрузки событий) перед обращением к свойствам, чтобы убедиться, что значение является объектом, а не `null`.

> **Примечание для пользователей TypeScript:**
>
> `isObject` — это runtime-guard, который возвращает boolean; он не сужает тип до конкретной формы объекта. Комбинируйте
> его с дополнительными проверками (например, наличия свойств), когда нужна более строгая типизация.

### Преимущества

- Возвращает `true` только для не-`null` значений, у которых `typeof` равен `"object"`.
- Предотвращает распространённую ловушку JavaScript, когда `null` иначе считался бы объектом.
- Работает для обычных объектов и экземпляров встроенных объектов (например, `Date`, `RegExp`).
- Простая и быстрая проверка во время выполнения, подходящая для защитного программирования и валидации входных данных.

## Использование

### Синтаксис

Функция:

- `isObject(value)`

Параметры:

- `value`: Значение, которое нужно проверить на то, является ли оно `object`.

### Локальный импорт функции

```ts
import { isObject } from "@type-check/guards";

const input: unknown = { a: 1 };

if (isObject(input)) {
  // input является ненулевым объектом во время выполнения
  console.log("Object detected");
} else {
  console.log("Not an object");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isObject(value)`
