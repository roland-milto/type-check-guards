# isSet

## Описание

Определяет, является ли заданное значение `Set`.

### Сценарий использования

Проверяйте входные данные из внешних источников (например, при разборе JSON, вводе пользователя или из сторонних API),
чтобы убедиться, что значение является `Set`, прежде чем выполнять операции с `Set`.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isSet`, чтобы сузить значения типа `unknown` перед вызовом API, специфичных для `Set`, таких как `.add`,
`.has` или `.size`.

### Преимущества

- Предоставляет простую проверку во время выполнения, чтобы подтвердить, является ли значение `Set`.
- Помогает предотвратить ошибки типов, позволяя рано разветвлять логику, когда значение не является `Set`.
- Работает с любым содержимым `Set` (пустым или заполненным) и последовательно возвращает `true`/`false`.

## Использование

### Синтаксис

Функция:

- `isSet(value)`

Параметры:

- `value`: Значение для проверки.

### Локальный импорт функции

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // a является Set во время выполнения
  console.log(a.size);
}

console.log(isSet(b)); // false
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isSet(value)`
