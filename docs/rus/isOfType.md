# isOfType

## Описание

Определяет, соответствует ли заданное `value` указанной строке типа, используя `typeof` для примитивов и резервный
вариант для сложных типов.

### Сценарий использования

Проверяйте и сужайте `unknown`-входные данные (например, ответы API, пользовательский ввод, распарсенный JSON),
проверяя, соответствует ли значение ожидаемой строке типа, прежде чем выполнять операции, зависящие от типа.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isOfType` для ветвления по типам во время выполнения при работе со значениями `unknown`; функция
> возвращает `true`/`false` и явно обрабатывает `null` и `undefined`.

### Преимущества

- Проверяет примитивы через прямой `typeof` для скорости и ясности.
- Корректно обрабатывает `null` и `undefined`, которые один лишь `typeof` не может различить должным образом.
- Поддерживает сложные или пользовательские строки типов через резервное сравнение с использованием `getTypeOf`.
- Возвращает простой булев результат (`true`/`false`), подходящий для защитных проверок и ветвления.

## Использование

### Синтаксис

Функция:

- `isOfType(value, type)`

Параметры:

- `value`: Значение, которое нужно проверить на соответствие `type`.
- `type`: Строковое представление типа, с которым нужно сравнить.

### Локальный импорт функции

```ts
import { isOfType } from "@type-check/guards";

const input: unknown = Math.random() > 0.5 ? 123 : "hello";

if (isOfType(input, "number")) {
  // здесь input является числом
  const doubled = input * 2;
  console.log(doubled);
} else if (isOfType(input, "string")) {
  // здесь input является строкой
  console.log(input.toUpperCase());
}

console.log(isOfType(null, "null"));
console.log(isOfType(undefined, "undefined"));
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isOfType(value, type)`
