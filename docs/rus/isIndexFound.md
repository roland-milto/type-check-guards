# isIndexFound

## Описание

`isIndexFound` определяет, является ли заданное значение неотрицательным целым числом, указывая, что индекс найден.

### Сценарий использования

Проверять, что результат поиска представляет собой пригодный к использованию индекс (целое число `>= 0`) перед
обращением по индексу в массиве или строке, предотвращая случайное использование `-1` или нечисловых значений.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isIndexFound` после операций вроде `indexOf`, `findIndex` или пользовательских поисков, где `-1` (или
> другие некорректные значения) могут означать «не найдено». Когда функция возвращает `true`, значение является числом и
> его безопасно использовать как индекс массива/строки.

### Преимущества

- Предоставляет простой защитник типа (type guard), чтобы определить, был ли найден индекс, проверяя, что значение
  является неотрицательным целым числом.
- Возвращает `true` только для корректных индексоподобных значений (целые числа `>= 0`), отклоняя отрицательные, нецелые
  и нечисловые значения.
- Помогает избежать ошибок «на единицу» и ошибок со значениями-сентинелами при работе с API, которые возвращают `-1` для
  «не найдено».

## Использование

### Синтаксис

Функция:

- `isIndexFound(value)`

Параметры:

- `value`: Значение, которое нужно проверить на то, является ли оно неотрицательным целым числом.

### Локальный импорт функции

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // здесь idx — число и оно >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// Типичное использование с indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isIndexFound(value)`
