# isFilledArray

## Описание

Проверяет, является ли `value` массивом с хотя бы одним элементом, возвращая `true` или `false`.

### Сценарий использования

Используйте `isFilledArray` для валидации входящих данных (например, полезной нагрузки API, значений форм, конфигурации)
перед итерацией, доступом к первому элементу или применением логики, требующей хотя бы одного элемента.

> **Примечание для пользователей TypeScript:**
>
> `isFilledArray` — это рантайм-предикат, который возвращает boolean; он не уточняет типы элементов, кроме
> подтверждения, что массив непустой.

### Преимущества

- Простая и быстрая проверка непустого массива с использованием `Array.isArray` и проверки длины.
- Помогает избежать ошибок во время выполнения, когда код предполагает, что в массиве есть хотя бы один элемент.
- Понятный булев результат: возвращает `true` для непустых массивов и `false` в противном случае.

## Использование

### Синтаксис

Функция:

- `isFilledArray(value)`

Параметры:

- `value`: Значение, которое нужно проверить на то, является ли оно непустым массивом.

### Локальный импорт функции

```ts
import { isFilledArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && isFilledArray(input)) {
  // input является непустым массивом во время выполнения
  console.log(input[0]);
} else {
  console.log("Not a non-empty array");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isFilledArray(value)`
