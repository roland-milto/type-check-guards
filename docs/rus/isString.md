# isString

## Описание

`isString` определяет, является ли заданное значение строкой.

### Сценарий использования

Проверяйте пользовательский ввод, поля полезной нагрузки API или значения конфигурации во время выполнения, чтобы
убедиться, что значение является строкой, прежде чем применять строковые операции (например, обрезку пробелов,
разбиение, преобразование регистра).

> **Примечание для пользователей TypeScript:**
>
> Используйте `isString` для валидации значений типа `unknown` или со слабой типизацией перед вызовом строковых методов;
> функция возвращает `true` только когда `typeof value === "string"`.

### Преимущества

- Простая и быстрая проверка с помощью `typeof`.
- Возвращает предсказуемый булев результат: `true` для строк, иначе `false`.
- Работает как для пустых, так и для непустых строк.
- Полезно как лёгкая проверка во время выполнения перед выполнением операций, специфичных для строк.

## Использование

### Синтаксис

Функция:

- `isString(value)`

Параметры:

- `value`: Значение, которое нужно проверить на строковый тип.

### Локальный импорт функции

```ts
import { isString } from "@type-check/guards";

const input: unknown = "Hello World";

if (isString(input)) {
  // здесь input является строкой
  console.log(input.toUpperCase());
} else {
  console.log("Not a string");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isString(value)`
