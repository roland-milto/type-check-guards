# isDecimal

## Описание

`isDecimal` проверяет, является ли значение десятичным строковым представлением без начальных/конечных пробельных
символов и с корректным десятичным форматом.

### Сценарий использования

Валидировать поля форм, полезные нагрузки API или значения конфигурации, которые должны быть предоставлены как
десятичная строка (возможно, со знаком) без каких-либо пробельных символов по краям, перед разбором или сохранением.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isDecimal`, чтобы валидировать пользовательский ввод перед преобразованием (например, с помощью
`Number(value)`), особенно когда пробельные символы должны отклоняться.

### Преимущества

- Строго проверяет, что входное значение является строкой и соответствует шаблону десятичного литерала.
- Отклоняет начальные и конечные пробельные символы (включая управляющие символы), чтобы избежать неоднозначного
  разбора.
- Выполняет быстрые предварительные проверки (проверка типа и первого/последнего символа) перед запуском регулярного
  выражения.
- Возвращает простой булев результат (`true`/`false`), подходящий для гардов и валидации ввода.

## Использование

### Синтаксис

Функция:

- `isDecimal(value)`

Параметры:

- `value`: Значение, которое нужно проверить на соответствие формату десятичной строки.

### Локальный импорт функции

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v здесь является строкой (проверено во время выполнения)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isDecimal(value)`
