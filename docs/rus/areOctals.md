# areOctals

## Описание

`areOctals` определяет, является ли предоставленное значение непустым массивом корректных восьмеричных строк.

### Сценарий использования

Используйте `areOctals` при валидации пользовательского ввода, значений конфигурации или полезной нагрузки API, которые
должны содержать восьмеричные литералы (например, режимы прав доступа к файлам вроде `0o755`), и вы хотите отклонять
пустые массивы или любые некорректные элементы, возвращая `false`.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areOctals`, чтобы убедиться, что у вас есть непустой `unknown[]`, где каждая запись является корректной
> восьмеричной строкой, перед преобразованием (например, через `Number(...)` или пользовательский разбор).

### Преимущества

- Проверяет, что значение является непустым массивом, где каждый элемент — восьмеричная строка, возвращая `true` только
  когда все элементы проходят проверку.
- Быстро завершает проверку: возвращает `false`, как только обнаруживается не-восьмеричный элемент.
- Полезно использовать как защитную проверку перед разбором или преобразованием восьмеричных строк, чтобы избежать
  ошибок во время выполнения и непоследовательной обработки входных данных.

## Использование

### Синтаксис

Функция:

- `areOctals(array)`

Параметры:

- `array`: Значение, которое нужно проверить.

### Локальный импорт функции

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value — непустой массив восьмеричных строк
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areOctals(array)`
