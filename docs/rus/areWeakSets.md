# areWeakSets

## Описание

Проверяет, является ли входное значение непустым массивом, где каждый элемент — `WeakSet`, и возвращает `true` только в
этом случае.

### Сценарий использования

Проверять входные данные во время выполнения (например, из API, конфигурации или пользовательских данных), чтобы
убедиться, что у вас есть непустой список экземпляров `WeakSet`, прежде чем продолжать логику, зависящую от поведения
`WeakSet`.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areWeakSets`, чтобы валидировать неизвестный ввод перед тем, как трактовать его как `WeakSet[]`. Функция
> возвращает `false` для пустых массивов и значений, не являющихся массивами.

### Преимущества

- Гарантирует, что каждый элемент входного массива является `WeakSet`.
- Возвращает `false` для пустых массивов, предотвращая случайные результаты «всё валидно» при отсутствии данных.
- Безопасно завершается, возвращая `false`, когда входное значение не является заполненным массивом (включая `null`).
- Полезно как защитная проверка перед выполнением операций, требующих экземпляры `WeakSet`.

## Использование

### Синтаксис

Функция:

- `areWeakSets(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие объектов `WeakSet`.

### Локальный импорт функции

```ts
import { areWeakSets } from "@type-check/guards";

const a: unknown = [new WeakSet<object>(), new WeakSet<object>()];
const b: unknown = [new WeakSet<object>(), {}];
const c: unknown = [];

if (areWeakSets(a)) {
  // a — непустой массив экземпляров WeakSet
}

console.log(areWeakSets(a)); // true
console.log(areWeakSets(b)); // false
console.log(areWeakSets(c)); // false
console.log(areWeakSets(null as unknown)); // false
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areWeakSets(array)`
