# areFilledArrays

## Описание

`areFilledArrays` проверяет, что двумерный массив не пуст и все его подмассивы не пусты.

### Сценарий использования

Используйте `areFilledArrays` для валидации табличного или матричного ввода (например, строк CSV, данных сетки,
сгруппированных результатов), чтобы можно было безопасно предполагать, что существует хотя бы один подмассив и ни один
из подмассивов не пуст.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areFilledArrays`, когда нужно убедиться, что 2D-массив содержит хотя бы одну строку и в каждой строке
> есть хотя бы один элемент, прежде чем выполнять итерацию или обращаться по индексу.

### Преимущества

- Проверяет, что внешний массив не пуст и что каждый внутренний массив также не пуст, возвращая `true` только при
  выполнении обоих условий.
- Работает с любыми типами элементов внутри подмассивов (например, числами, строками, объектами, вложенными массивами),
  потому что проверяет только «заполненность» массива, а не содержимое элементов.
- Предоставляет простой булев результат (`true`/`false`), подходящий для проверок-охранников перед обработкой двумерных
  данных.

## Использование

### Синтаксис

Функция:

- `areFilledArrays(array)`

Параметры:

- `array`: Двумерный массив для проверки.

### Локальный импорт функции

```ts
import { areFilledArrays } from "@type-check/guards";

const a: unknown[][] = [[1]];
const b: unknown[][] = [["a", "b"], [1, 2, 3]];
const c: unknown[][] = [[{}, []], ["string"]];
const d: unknown[][] = [[]];
const e: unknown[][] = [[], [1, 2, 3]];
const f: unknown[][] = [];

console.log(areFilledArrays(a)); // истина
console.log(areFilledArrays(b)); // истина
console.log(areFilledArrays(c)); // истина
console.log(areFilledArrays(d)); // ложь
console.log(areFilledArrays(e)); // ложь
console.log(areFilledArrays(f)); // ложь

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areFilledArrays(array)`
