# isDate

## Описание

`isDate` определяет, является ли переданное значение `Date`, возвращая `true` для экземпляров `Date` и `false` в
противном случае.

### Сценарий использования

Проверяйте и сужайте неизвестные значения (например, данные запроса, значения конфигурации или разобранный JSON) перед
выполнением операций с `Date`, таких как форматирование, сравнения или вызов `toISOString()`.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isDate`, чтобы сузить тип `unknown` до `Date` во время выполнения; функция возвращает `true` только для
> реальных экземпляров `Date` (а не для строк с датой).

### Преимущества

- Предоставляет простую проверку во время выполнения, чтобы определить, является ли значение `Date`.
- Помогает предотвратить ошибки типов, гарантируя, что проверку проходят только экземпляры `Date`.
- Полезно для валидации неизвестных входных данных (например, полезных нагрузок API) перед использованием методов,
  специфичных для дат.

## Использование

### Синтаксис

Функция:

- `isDate(value)`

Параметры:

- `value`: Значение, которое нужно проверить на тип `Date`.

### Локальный импорт функции

```ts
import { isDate } from "@type-check/guards";

const input: unknown = new Date();

if (isDate(input)) {
  // здесь input является Date
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a Date");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isDate(value)`
