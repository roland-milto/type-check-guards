# areSets

## Описание

Проверяет, содержит ли заданный непустой массив только экземпляры `Set`, возвращая `true`, если это так, и `false` в
противном случае.

### Сценарий использования

Проверить, что значение (например, из пользовательского ввода, парсинга JSON или внешних API) является непустым массивом
объектов `Set` перед обработкой каждого множества.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areSets`, чтобы валидировать неизвестный ввод перед итерацией и вызовом API `Set` (например, `.size`,
`.has`, `.add`) для каждого элемента.

### Преимущества

- Возвращает `true` только тогда, когда входное значение — непустой массив и каждый элемент является экземпляром `Set`.
- Предотвращает ложноположительные результаты для пустых массивов, возвращая `false`, когда в массиве нет элементов.
- Полезно как проверка во время выполнения перед выполнением операций, специфичных для `Set`, над каждым элементом.

## Использование

### Синтаксис

Функция:

- `areSets(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие экземпляров `Set`.

### Локальный импорт функции

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  // a — это массив экземпляров Set во время выполнения
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); // ложь
console.log(areSets(c)); // ложь
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areSets(array)`
