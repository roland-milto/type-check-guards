# areRegExes

## Описание

`areRegExes` проверяет, является ли значение заполненным массивом, содержащим только объекты `RegExp`.

### Сценарий использования

Проверьте, что параметр конфигурации (например, список шаблонов разрешения/запрета) является непустым массивом
регулярных выражений, прежде чем использовать его для сопоставления.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areRegExes`, чтобы сузить тип `unknown` до `RegExp[]` перед итерацией или компоновкой шаблонов.

### Преимущества

- Гарантирует, что значение является непустым массивом, где каждый элемент — экземпляр `RegExp`.
- Предоставляет простой булевый предикат (`true`/`false`) для валидации пользовательского ввода или конфигурации.
- Помогает предотвратить ошибки во время выполнения, когда последующий код предполагает, что все элементы поддерживают
  операции с регулярными выражениями.

## Использование

### Синтаксис

Функция:

- `areRegExes(array)`

Параметры:

- `array`: Значение, которое нужно проверить.

### Локальный импорт функции

```ts
import { areRegExes } from "@type-check/guards";

const patterns: unknown = [/[a-z]/, /[0-9]/];

if (areRegExes(patterns)) {
  // patterns здесь является массивом RegExp
  const combined = new RegExp(patterns.map(r => r.source).join("|"));
  console.log(combined.test("abc123"));
} else {
  throw new TypeError("Expected a non-empty array of RegExp");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areRegExes(array)`
