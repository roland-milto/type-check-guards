# isArray

## Описание

`isArray` проверяет, является ли заданное значение массивом, и возвращает `true`, если это так, иначе `false`.

### Сценарий использования

Проверять неизвестные данные (например, разобранный JSON или ответы API), чтобы убедиться, что значение является
массивом, прежде чем выполнять итерацию, индексирование или обращаться к `.length`.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isArray`, когда нужна проверка массивов во время выполнения; она возвращает boolean и ее безопасно
> вызывать со значениями типа `unknown`.

### Преимущества

- Использует встроенный `Array.isArray` для надежного определения массивов между разными контекстами выполнения (
  например, в iframe).
- Возвращает простой булев результат (`true`/`false`), подходящий для защитных проверок и ветвления логики.
- Работает с любым типом входных данных, поскольку параметр имеет тип `unknown`.

## Использование

### Синтаксис

Функция:

- `isArray(value)`

Параметры:

- `value`: Значение, которое нужно проверить.

### Локальный импорт функции

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  // input является массивом во время выполнения
  console.log(input.length);
} else {
  console.log("Not an array");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isArray(value)`
