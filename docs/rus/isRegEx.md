# isRegEx

## Описание

Определяет, является ли переданное значение экземпляром `RegExp`.

### Сценарий использования

Проверяйте значения, предоставленные пользователем или полученные динамически (например, конфигурацию, полезную нагрузку
API, входные данные плагинов), прежде чем трактовать их как регулярное выражение.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isRegEx`, чтобы сузить значения типа `unknown` (или объединения) перед использованием свойств или
> методов, специфичных для RegExp; функция возвращает `true` только для значений, являющихся экземплярами `RegExp`.

### Преимущества

- Предоставляет простой защитник типа во время выполнения, чтобы проверить, является ли значение `RegExp`.
- Помогает предотвращать ошибки, когда код ожидает регулярное выражение (например, перед вызовом `test`, `exec` или
  чтением `source`).
- Работает как с литералами регулярных выражений, так и с экземплярами, созданными через `new RegExp(...)`.
- Возвращает понятный булев результат (`true`/`false`), не выбрасывая исключений для входных данных, не являющихся
  регулярным выражением.

## Использование

### Синтаксис

Функция:

- `isRegEx(value)`

Параметры:

- `value`: Проверяемое значение.

### Локальный импорт функции

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  // input здесь является RegExp
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isRegEx(value)`
