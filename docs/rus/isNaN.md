# isNaN

## Описание

Определяет, является ли предоставленное `value` значением `NaN` типа `number`, не преобразуя строки.

### Сценарий использования

Проверяйте недоверенные или слабо типизированные входные данные (например, полезные нагрузки API, значения форм,
разобранный JSON), чтобы обнаружить специальное значение `NaN` и обработать его явно, при этом считая нечисловые входные
данные не `NaN`.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isNaN`, когда нужно обнаружить специальное числовое значение `NaN`, при этом гарантируя, что входное
> значение действительно является `number` (без преобразования строки в число).

### Преимущества

- Проверяет, является ли значение `NaN`, не приводя нечисловые значения (например, строки) к числам.
- Возвращает `true` только для значений, которые одновременно имеют тип `number` и равны `NaN`.
- Безопасно для входных данных типа `unknown` и избегает ложных срабатываний из-за неявных преобразований.

## Использование

### Синтаксис

Функция:

- `isNaN(value)`

Параметры:

- `value`: Значение, которое нужно проверить, является ли оно `NaN` типа `number`.

### Локальный импорт функции

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // true
console.log(isNaN(b)); // false
console.log(isNaN(c)); // false

if (isNaN(a)) {
  // a — это число, и конкретно NaN
}
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isNaN(value)`
