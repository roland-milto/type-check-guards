# isTrue

## Описание

`isTrue` определяет, является ли заданное значение строго равным `true`.

### Сценарий использования

Используйте `isTrue` для валидации флагов, переключателей функций (feature toggles) или значений конфигурации, где
должно приниматься только буквальное `true`, а всё остальное должно трактоваться как `false`.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isTrue`, когда нужно принимать только булев литерал `true`, а не просто truthy-значения.

### Преимущества

- Обеспечивает строгую проверку булевого литерала `true` (без приведения типов).
- Помогает отличать `true` от truthy-значений, таких как `1`, `"true"` или `{}`.
- Простое, предсказуемое поведение, подходящее для гардов и конвейеров валидации.

## Использование

### Синтаксис

Функция:

- `isTrue(value)`

Параметры:

- `value`: Значение для проверки.

### Локальный импорт функции

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // истина
const b = isTrue(1);         // ложь
const c = isTrue("true");   // ложь

if (isTrue(a)) {
  // здесь a равно true
}
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isTrue(value)`
