# areFloats

## Описание

`areFloats` проверяет, что заданный массив заполнен и все его элементы — числа с плавающей точкой.

### Сценарий использования

Используйте `areFloats`, когда вы получаете `unknown[]` (например, из JSON, параметров запроса или внешних API) и вам
нужно убедиться, что это заполненный массив, где каждый элемент — число с плавающей точкой, прежде чем выполнять
числовую логику, такую как усреднение, интерполяция или статистические вычисления.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areFloats` для защиты `unknown[]` перед тем, как трактовать его как `number[]`, содержащий только числа с
> плавающей точкой; функция возвращает `false` для пустых массивов и для любого элемента, который не является числом с
> плавающей точкой.

### Преимущества

- Возвращает `true` только тогда, когда входное значение — непустой массив и каждый элемент является числом с плавающей
  точкой.
- Быстро завершает проверку: возвращает `false`, как только найден элемент, не являющийся числом с плавающей точкой.
- Помогает валидировать неизвестный ввод перед выполнением вычислений, специфичных для чисел с плавающей точкой.

## Использование

### Синтаксис

Функция:

- `areFloats(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие элементов с плавающей точкой.

### Локальный импорт функции

```ts
import { areFloats } from "@type-check/guards";

const a: unknown[] = [3.14, 2.71, 1.0];
const b: unknown[] = [3.14, 2];
const c: unknown[] = [];

console.log(areFloats(a)); // true
console.log(areFloats(b)); // false
console.log(areFloats(c)); // false

function sumFloats(values: unknown): number | null {
  if (!Array.isArray(values) || !areFloats(values)) return null;
  return values.reduce((acc, n) => acc + n, 0);
}

console.log(sumFloats([0.5, 1.25])); // 1.75
console.log(sumFloats([1, 2])); // null

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areFloats(array)`
