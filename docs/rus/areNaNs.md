# areNaNs

## Описание

`areNaNs` проверяет, являются ли все элементы массива `NaN`, и возвращает `true` только если каждый элемент — `NaN`.

### Сценарий использования

Проверка входящих данных, где `NaN` используется как сигнальное значение, и необходимо убедиться, что весь массив
состоит исключительно из `NaN` (например, для обнаружения полностью отсутствующего числового ряда).

> **Примечание для пользователей TypeScript:**
>
> Используйте `areNaNs`, когда нужно проверить, что массив содержит только числовое значение `NaN` (без приведения строк
> к числам).

### Преимущества

- Возвращает `true` только когда каждый элемент равен `NaN` (строгая проверка всех элементов).
- Не приводит строки к числам; значения вроде "NaN" остаются не-`NaN` и делают результат `false`.
- Возвращает `false` для незаполненных массивов, предотвращая случайный `true` на пустом вводе.

## Использование

### Синтаксис

Функция:

- `areNaNs(array)`

Параметры:

- `array`: Массив для проверки на значения `NaN`.

### Локальный импорт функции

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // true
const b = areNaNs([NaN, 1, NaN]); // false
const c = areNaNs([NaN, "NaN", NaN]); // false
const d = areNaNs([NaN, null, NaN]); // false
const e = areNaNs([] as unknown[]); // false
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areNaNs(array)`
