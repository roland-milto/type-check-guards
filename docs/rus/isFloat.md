# isFloat

## Описание

`isFloat` определяет, является ли заданное `value` конечным числом с плавающей запятой (тип `number`, которое не
является целым).

### Сценарий использования

Проверка введённых пользователем числовых данных, где требуются дробные значения (например, цены, измерения, ставки), и
отклонение целых чисел, `NaN` и бесконечностей.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isFloat`, когда нужно принимать только конечные, нецелые числовые значения; он отклоняет целые числа и
> неконечные числа.

### Преимущества

- Возвращает `true` только для конечных, нецелых чисел (исключает целые числа, `NaN`, `Infinity` и `-Infinity`).
- Работает с любым типом входных данных (`unknown`) и безопасно сужает тип, проверяя `typeof value === "number"`.
- Использует встроенные числовые проверки (`Number.isInteger`, `Number.isFinite`) для предсказуемого поведения.

## Использование

### Синтаксис

Функция:

- `isFloat(value)`

Параметры:

- `value`: Значение, которое нужно проверить на то, является ли оно числом с плавающей запятой.

### Локальный импорт функции

```ts
import { isFloat } from "@type-check/guards";

const inputs: unknown[] = [3.14, -0.1, 1e-7, 42, "3.14", NaN, Infinity];

for (const value of inputs) {
  if (isFloat(value)) {
    // value — это число во время выполнения; оно конечно и не является целым
    const rounded = value.toFixed(2);
    console.log("float:", value, "rounded:", rounded);
  } else {
    console.log("not a float:", value);
  }
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isFloat(value)`
