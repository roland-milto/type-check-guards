# isNumeric

## Описание

`isNumeric` определяет, считается ли заданное `value` числовым, сравнивая его определённый тип с `NUMERIC_TYPES`.

### Сценарий использования

Используйте `isNumeric` для валидации входных данных (например, payload API, значений форм, конфигурации) перед
выполнением числовых операций, а также чтобы последовательно принимать числоподобные типы (такие как `BigInt`) в
соответствии с `NUMERIC_TYPES`.

> **Примечание для пользователей TypeScript:**
>
> `isNumeric` — это предикат, возвращающий boolean; рассматривайте его как проверку во время выполнения того,
> принадлежит ли значение к определённому библиотекой набору числовых типов.

### Преимущества

- Использует `getTypeOf` вместе с `NUMERIC_TYPES`, чтобы централизовать логику определения числовых типов и поддерживать
  единообразие проверок по всей кодовой базе.
- Возвращает простой boolean (`true`/`false`) для удобного ветвления и использования в стиле guard-проверок.
- Поддерживает несколько представлений чисел (например, `number`, `BigInt`), как определено в `NUMERIC_TYPES`.

## Использование

### Синтаксис

Функция:

- `isNumeric(value)`

Параметры:

- `value`: Значение, которое нужно проверить на числовой тип.

### Локальный импорт функции

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    // v считается числовым согласно правилам типов библиотеки
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isNumeric(value)`
