# isInteger

## Описание

Определяет, является ли заданное `value` безопасным целым числом.

### Сценарий использования

Проверяйте недоверенный ввод (например, параметры запроса, JSON-полезные нагрузки, переменные окружения) перед
использованием его как целого числа для индексов массивов, пагинации, счётчиков или ID в базе данных.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isInteger`, чтобы валидировать неизвестный ввод перед тем, как трактовать его как числовое целое; он
> возвращает `true` только для значений, где `typeof value === "number"` и `Number.isSafeInteger(value)`.

### Преимущества

- Проверяет и тип, и числовую безопасность: возвращает `true` только когда входное значение — число и безопасное целое.
- Предотвращает распространённые ошибки, связанные с числовым приведением типов: строки вроде "5" корректно возвращают
  `false`.
- Отклоняет нецелые и небезопасные целые числа, что делает его подходящим для ID, счётчиков и индексации массивов.

## Использование

### Синтаксис

Функция:

- `isInteger(value)`

Параметры:

- `value`: Значение, которое нужно проверить на целочисленность.

### Локальный импорт функции

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      // истина
const b = isInteger(-100);   // истина
const c = isInteger("5");    // ложь
const d = isInteger(5.5);    // ложь
const e = isInteger(null);   // ложь

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isInteger(value)`
