# areHexadecimals

## Описание

Проверяет, являются ли все элементы массива шестнадцатеричными строками, возвращая `true` только для непустых массивов,
где каждый элемент корректен.

### Сценарий использования

Используйте `areHexadecimals` для валидации пользовательского ввода или внешних данных (например, идентификаторов,
контрольных сумм, цветовых кодов без ведущего '#') перед выполнением шестнадцатеричного разбора или дальнейшей
обработкой.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areHexadecimals`, чтобы валидировать неизвестный ввод перед разбором или преобразованием значений (
> например, перед `parseInt(value, 16)` или преобразованиями в BigInt).

### Преимущества

- Проверяет, что каждый элемент является шестнадцатеричной строкой, и возвращает `true` только когда все элементы
  соответствуют.
- По замыслу отклоняет пустые массивы, возвращая `false` при отсутствии входных данных.
- Предоставляет простой булев результат (`true`/`false`), подходящий для защитных проверок и валидации с ранним выходом.

## Использование

### Синтаксис

Функция:

- `areHexadecimals(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие элементов в виде шестнадцатеричных строк.

### Локальный импорт функции

```ts
import { areHexadecimals } from "@type-check/guards";

const a = areHexadecimals(["1A", "3F", "B2"]);
const b = areHexadecimals(["1A", "3G", "B2"]);
const c = areHexadecimals([10 as unknown as string, "3F", "B2"] as unknown[]);
const d = areHexadecimals([]);

console.log(a, b, c, d);
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areHexadecimals(array)`
