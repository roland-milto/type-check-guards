# isValidDate

## Описание

`isValidDate` проверяет, является ли заданное значение корректным объектом `Date`, и возвращает `true` только для
реальных, не недопустимых дат.

### Сценарий использования

Проверяйте пользовательский ввод или данные API, которые могут содержать даты, чтобы убедиться, что значение является
реальным экземпляром `Date`, а не недопустимой датой, прежде чем выполнять вычисления с датами, форматирование или
сравнения.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isValidDate` перед вызовом методов `Date` (например, `toISOString`, `getTime`) для значений с типом
`unknown`, чтобы убедиться, что это корректные объекты `Date`.

### Преимущества

- Гарантирует, что значение является экземпляром `Date`, а не просто строкой или числом, похожими на дату.
- Отклоняет недопустимые даты (например, `new Date("invalid")`), проверяя значения времени на `NaN`.
- Простой булевый защитный предикат, который легко использовать в условных операторах и конвейерах валидации.
- Помогает предотвратить ошибки во время выполнения при вызове методов даты, предварительно проверяя входное значение.

## Использование

### Синтаксис

Функция:

- `isValidDate(value)`

Параметры:

- `value`: Значение, которое нужно проверить.

### Локальный импорт функции

```ts
import { isValidDate } from "@type-check/guards";

const input: unknown = new Date();

if (isValidDate(input)) {
  // input является корректным экземпляром Date
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a valid Date");
}

console.log(isValidDate(new Date("invalid"))); // false
console.log(isValidDate("2025-12-22")); // false

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isValidDate(value)`
