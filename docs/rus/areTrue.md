# areTrue

## Описание

Проверяет, содержит ли непустой массив только булевы значения `true`.

### Сценарий использования

Используйте `areTrue`, чтобы проверить, что набор предварительных условий или флагов функций полностью включён (все
значения равны `true`) перед продолжением, при этом пустые или некорректно сформированные входные данные считаются
неудовлетворёнными (`false`).

> **Примечание для пользователей TypeScript:**
>
> `areTrue` возвращает `false` для пустого массива и для массивов, содержащих любое значение, которое не является строго
`true`.

### Преимущества

- Возвращает `true` только тогда, когда каждый элемент строго равен `true`, и массив не пуст.
- Быстро завершает проверку: возвращает `false`, как только найдено значение, не равное `true`.
- Отклоняет некорректные входные данные (не массивы или пустые массивы), возвращая `false`.

## Использование

### Синтаксис

Функция:

- `areTrue(array)`

Параметры:

- `array`: Массив, который нужно проверить на то, что все значения строго равны `true`.

### Локальный импорт функции

```ts
import { areTrue } from "@type-check/guards";

const a = areTrue([true, true, true]);
const b = areTrue([true, false, true]);
const c = areTrue([]);
const d = areTrue([true, "string" as unknown, true]);

console.log(a, b, c, d);
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areTrue(array)`
