# areObjects

## Описание

`areObjects` проверяет, содержит ли предоставленный заполненный массив только объекты.

### Сценарий использования

Используйте `areObjects`, когда вы получаете неизвестный массив (например, из парсинга JSON или внешних API) и нужно
убедиться, что он не пустой и что каждый элемент является объектом, прежде чем выполнять итерацию и обращаться к
свойствам объектов.

> **Примечание для пользователей TypeScript:**
>
> Используйте `areObjects`, чтобы валидировать `unknown[]` перед тем, как считать элементы объектами; для пустых
> массивов функция возвращает `false`.

### Преимущества

- Возвращает `true` только тогда, когда входное значение — заполненный массив и каждый элемент является объектом.
- Завершает проверку раньше и возвращает `false`, как только найден элемент, который не является объектом.
- Помогает валидировать неизвестный ввод перед выполнением операций, специфичных для объектов.

## Использование

### Синтаксис

Функция:

- `areObjects(array)`

Параметры:

- `array`: Массив, который нужно проверить на наличие элементов-объектов.

### Локальный импорт функции

```ts
import { areObjects } from "@type-check/guards";

const value: unknown = [{}, { a: 1 }, new Date()];

if (Array.isArray(value) && areObjects(value)) {
  // value — заполненный массив объектов
  console.log("All items are objects:", value.length);
} else {
  console.log("Not a filled array of objects");
}

```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.areObjects(array)`
