# isHexadecimal

## Описание

`isHexadecimal` проверяет, является ли заданное значение шестнадцатеричным строковым литералом с обязательным префиксом
`0x`/`0X`.

### Сценарий использования

Используйте `isHexadecimal` для проверки значений конфигурации, полей полезной нагрузки API или аргументов CLI, которые
должны быть переданы как шестнадцатеричные строковые литералы (например, ID, маски или адреса) и не должны содержать
пробелы по краям.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isHexadecimal`, когда нужно проверить пользовательский ввод или сериализованные данные как строгую строку
> шестнадцатеричного литерала (включая префикс `0x`/`0X`) перед разбором или преобразованием.

### Преимущества

- Проверяет, что значение является строкой и соответствует строгому формату шестнадцатеричного строкового литерала (
  требуется префикс `0x`/`0X`).
- Отклоняет строки с ведущими или завершающими пробелами, помогая избежать случайного принятия ввода с добавленными
  пробелами.
- Поддерживает необязательный знак и не зависит от регистра для префикса и цифр, предсказуемо возвращая `true`/`false`.

## Использование

### Синтаксис

Функция:

- `isHexadecimal(value)`

Параметры:

- `value`: Проверяемое значение.

### Локальный импорт функции

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // true
isHexadecimal("-0Xff"); // true
isHexadecimal("1A2B"); // false (отсутствует префикс)
isHexadecimal(" 0x1A2B"); // false (начальные пробелы)
isHexadecimal(0x1a2b); // false (не строка)
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isHexadecimal(value)`
