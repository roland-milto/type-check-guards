# isWeakSet

## Описание

Определяет, является ли заданное `value` объектным `WeakSet`.

### Сценарий использования

Используйте `isWeakSet`, когда принимаете нетипизированный ввод (например, из внешних API, динамической конфигурации или
значения типа `unknown`) и вам нужно проверить, что это `WeakSet`, прежде чем использовать операции, специфичные для
`WeakSet`.

> **Примечание для пользователей TypeScript:**
>
> Используйте `isWeakSet`, чтобы сузить значение типа `unknown` до `WeakSet<object>` во время выполнения; учтите, что
`WeakSet` может содержать только ссылки на объекты.

### Преимущества

- Предоставляет простую проверку во время выполнения, является ли значение `WeakSet`.
- Помогает предотвращать ошибки типов, гарантируя, что только экземпляры `WeakSet` рассматриваются как таковые.
- Работает с любым входным значением типа `unknown` и возвращает понятный булев результат (`true`/`false`).

## Использование

### Синтаксис

Функция:

- `isWeakSet(value)`

Параметры:

- `value`: Значение, которое нужно проверить.

### Локальный импорт функции

```ts
import { isWeakSet } from "@type-check/guards";

const a: unknown = new WeakSet<object>();
const b: unknown = new Set();

console.log(isWeakSet(a)); // true
console.log(isWeakSet(b)); // false

if (isWeakSet(a)) {
  // a является WeakSet во время выполнения
}
```

### Глобальный импорт объекта

Чтобы импортировать функции как глобальные методы объекта, используйте:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следующий метод будет затем доступен глобально:

- `Type.isWeakSet(value)`
