# isDecimal

## תיאור

`isDecimal` בודק האם ערך הוא ייצוג של מחרוזת עשרונית ללא רווחים לבנים בתחילה/בסוף ובפורמט עשרוני תקין.

### מקרה שימוש

אמתו שדות טופס, מטעני API או ערכי תצורה שחייבים להינתן כמחרוזת עשרונית (עם סימן אופציונלי) ללא כל רווחים לבנים מסביב,
לפני פענוח או אחסון שלהם.

> **הערה למשתמשי TypeScript:**
>
> השתמשו ב-`isDecimal` כדי לאמת קלט משתמש לפני המרה שלו (למשל, עם `Number(value)`), במיוחד כאשר יש לדחות רווחים לבנים.

### יתרונות

- מאמת בקפדנות שהקלט הוא מחרוזת ותואם לתבנית של ליטרל עשרוני.
- דוחה רווחים לבנים בתחילה ובסוף (כולל תווי בקרה) כדי להימנע מפענוח דו-משמעי.
- בדיקות מקדימות מהירות (בדיקת טיפוס ותו ראשון/אחרון) לפני הרצת ה-regex.
- מחזיר תוצאת בוליאן פשוטה (`true`/`false`) המתאימה ל-guards ולאימות קלט.

## שימוש

### תחביר

פונקציה:

- `isDecimal(value)`

פרמטרים:

- `value`: הערך שיש לבדוק עבור פורמט של מחרוזת עשרונית.

### ייבוא מקומי של פונקציה

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    //‎‎ v הוא מחרוזת כאן (מאומת בזמן ריצה)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### ייבוא גלובלי של אובייקט

כדי לייבא את הפונקציות כמתודות גלובליות של אובייקט, השתמשו ב:

```ts
import "@type-check/guards/register-global-object.mjs";
```

לאחר מכן המתודה הבאה תהיה זמינה באופן גלובלי:

- `Type.isDecimal(value)`
