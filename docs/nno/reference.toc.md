# Funksjonsreferansar

## Funksjonar

| Funksjon                                    | Skildring                                                                                                                                                                                    |
|---------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [areArrays](areArrays.md)                   | `areArrays` avgjer om ein verdi er ein fylt todimensjonal matrise der alle elementa er matriser.                                                                                             |
| [areBigInts](areBigInts.md)                 | `areBigInts` avgjer om ein verdi er eit ikkje-tomt array som berre inneheld `bigint`-verdiar.                                                                                                |
| [areBinaries](areBinaries.md)               | Sjekkar om den oppgjevne verdien er ein ikkje-tom tabell av gyldige binærstrengar og returnerer `true` berre dersom alle elementa består valideringa.                                        |
| [areBooleans](areBooleans.md)               | `areBooleans` sjekkar om ein gitt ikkje-tom array berre inneheld boolske verdiar, og returnerer `true` dersom han gjer det og `false` elles.                                                 |
| [areBuffers](areBuffers.md)                 | `areBuffers` sjekkar om den oppgjevne verdien er eit ikkje-tomt, utfylt array der kvart element er ein `Buffer`, og returnerer `true` i så fall og `false` elles.                            |
| [areDates](areDates.md)                     | `areDates` avgjer om ein gitt tabell er utfylt og berre inneheld `Date`-objekt, og returnerer `true` berre når alle element er gyldige datoar.                                               |
| [areDecimals](areDecimals.md)               | Sjekkar om alle element i ein tabell er desimaltal og at tabellen er fylt, og returnerer `true` eller `false`.                                                                               |
| [areEqual](areEqual.md)                     | `areEqual` sjekkar om alle element i ein array er like ein gitt forventa verdi, og returnerer `true` berre for ikkje-tomme arrayar der kvart element samsvarar.                              |
| [areErrors](areErrors.md)                   | Sjekkar om eit array er ikkje-tomt og berre inneheld `Error`-objekt, og returnerer `true` eller `false`.                                                                                     |
| [areFalse](areFalse.md)                     | `areFalse` sjekkar om alle elementa i ein gitt array er strengt den boolske verdien `false`.                                                                                                 |
| [areFilledArrays](areFilledArrays.md)       | `areFilledArrays` sjekkar om ein todimensjonal matrise ikkje er tom og at alle undermatrisene hennar ikkje er tomme.                                                                         |
| [areFinite](areFinite.md)                   | `areFinite` sjekkar om ein verdi er ei ikkje-tom matrise der elementa alle er endelege tal, og returnerer `true` i så fall og `false` elles.                                                 |
| [areFloats](areFloats.md)                   | `areFloats` sjekkar om ei gitt matrise er fylt og om alle elementa hennar er flyttal.                                                                                                        |
| [areHexadecimals](areHexadecimals.md)       | Sjekkar om alle element i ein array er heksadesimale strengar, og returnerer `true` berre for ikkje-tomme arrayar der kvart element er gyldig.                                               |
| [areIndexesFound](areIndexesFound.md)       | `areIndexesFound` sjekkar om ein verdi er ei ikkje-tom matrise der alle elementa er gyldige indeksar, og returnerer `true` dersom dei er det og `false` elles.                               |
| [areIntegers](areIntegers.md)               | `areIntegers` avgjer om alle elementa i ein gitt array er heiltal, og returnerer `true` dersom dei er det og `false` elles.                                                                  |
| [areJson](areJson.md)                       | Sjekkar om alle elementa i ein array er JSON-strengar, og returnerer `true` berre dersom arrayen er fylt og kvart element er gyldig JSON; elles returnerer han `false`.                      |
| [areMaps](areMaps.md)                       | `areMaps` avgjer om eit gitt array er ikkje-tomt og om alle elementa er `Map`-instansar.                                                                                                     |
| [areNaNs](areNaNs.md)                       | `areNaNs` sjekkar om alle element i eit array er `NaN` og returnerer `true` berre dersom kvart element er `NaN`.                                                                             |
| [areNullOrUndefined](areNullOrUndefined.md) | Sjekkar om alle element i det gjevne arrayet er `null` eller `undefined`.                                                                                                                    |
| [areNumbers](areNumbers.md)                 | `areNumbers` sjekkar om ein verdi er ei ikkje-tom matrise der alle element er tal.                                                                                                           |
| [areNumerics](areNumerics.md)               | `areNumerics` sjekkar om ein verdi er ei ikkje-tom matrise der alle element er numeriske.                                                                                                    |
| [areObjects](areObjects.md)                 | `areObjects` sjekkar om ei oppgitt fylt matrise berre inneheld objekt.                                                                                                                       |
| [areOctals](areOctals.md)                   | `areOctals` avgjer om den oppgitte verdien er ein ikkje-tom array av gyldige oktalstrengar.                                                                                                  |
| [areOfType](areOfType.md)                   | Sjekkar om alle element i den gjevne `array` er av den spesifiserte `type`.                                                                                                                  |
| [areOneOfType](areOneOfType.md)             | `areOneOfType` sjekkar om alle element i ein ikkje-tom array er av ein av dei spesifiserte runtime-typane.                                                                                   |
| [arePlainObjects](arePlainObjects.md)       | Sjekkar om alle element i eit array er vanlege objekt, og returnerer `true` berre dersom kvart element kvalifiserer.                                                                         |
| [arePrimitives](arePrimitives.md)           | `arePrimitives` vurderer om alle element i ein oppgjeven, ikkje-tom array er primitive typar.                                                                                                |
| [arePromises](arePromises.md)               | `arePromises` avgjer om alle element i eit array er `Promise`-instansar.                                                                                                                     |
| [areRegExes](areRegExes.md)                 | `areRegExes` sjekkar om ein verdi er ein fylt matrise som berre inneheld `RegExp`-objekt.                                                                                                    |
| [areSets](areSets.md)                       | Sjekkar om ei gitt ikkje-tom matrise berre inneheld `Set`-instansar, og returnerer `true` dersom ho gjer det og `false` elles.                                                               |
| [areStreams](areStreams.md)                 | `areStreams` avgjer om ein verdi er ein utfylt array der kvart element er ein `Stream`.                                                                                                      |
| [areStrings](areStrings.md)                 | `areStrings` sjekkar om ein tabell er ikkje-tom og om alle elementa er strengar, og returnerer `true` berre i det tilfellet.                                                                 |
| [areSymbols](areSymbols.md)                 | Sjekkar om ei inndata er ei fylt matrise der elementa alle er symbol, og returnerer `true` eller `false`.                                                                                    |
| [areTrue](areTrue.md)                       | Sjekkar om eit ikkje-tomt array berre inneheld dei boolske `true`-verdiane.                                                                                                                  |
| [areUndefined](areUndefined.md)             | `areUndefined` sjekkar om kvart element i eit gjeve array er `undefined`.                                                                                                                    |
| [areValidDates](areValidDates.md)           | Avgjer om ein array er ikkje-tom og berre består av gyldige `Date`-objekt.                                                                                                                   |
| [areWeakMaps](areWeakMaps.md)               | `areWeakMaps` sjekkar om ein verdi er ein ikkje-tom array der kvart element er ein `WeakMap`, og returnerer berre `true` i det tilfellet og `false` elles.                                   |
| [areWeakSets](areWeakSets.md)               | Sjekkar om ei inndata er ein ikkje-tom array der kvart element er ein `WeakSet`, og returnerer `true` berre i det tilfellet.                                                                 |
| [getTypeOf](getTypeOf.md)                   | `getTypeOf` returnerer ei detaljert, menneskeleg typeetikett for ein gitt verdi, inkludert meir presise numeriske typar og spesifikke objektslag.                                            |
| [isArray](isArray.md)                       | `isArray` sjekkar om ein gitt verdi er ein array og returnerer `true` dersom han er det, elles `false`.                                                                                      |
| [isBigInt](isBigInt.md)                     | `isBigInt` sjekkar om ein gitt verdi er av typen `bigint`, og returnerer `true` for BigInt-primitive verdiar og `false` elles.                                                               |
| [isBinary](isBinary.md)                     | `isBinary` avgjer om ein verdi er ein binærstreng (valfritt med prefiks `0b`/`0B`) og returnerer `true` eller `false`.                                                                       |
| [isBoolean](isBoolean.md)                   | Avgjer om ein gitt verdi er ein `boolean`.                                                                                                                                                   |
| [isBuffer](isBuffer.md)                     | Sjekkar om ein verdi er ein Node.js-`Buffer` og returnerer `true` eller `false`.                                                                                                             |
| [isDate](isDate.md)                         | `isDate` avgjer om ein oppgitt verdi er ein `Date`, og returnerer `true` for `Date`-instansar og `false` elles.                                                                              |
| [isDecimal](isDecimal.md)                   | `isDecimal` sjekkar om ein verdi er ei desimalstreng-representasjon utan innleiande/avsluttande blankteikn og med eit gyldig desimalformat.                                                  |
| [isEmpty](isEmpty.md)                       | Avgjer om ein gitt verdi er tom, og returnerer `true` for `null`, `undefined`, tomme/blankteikn-strengjer, tomme tabellar, tom `Map`/`Set`, eller objekt utan eigne oppramsbare eigenskapar. |
| [isError](isError.md)                       | Sjekkar om ein gitt `value` er ein instans av `Error`.                                                                                                                                       |
| [isFalse](isFalse.md)                       | `isFalse` sjekkar om ein gitt verdi er strengt lik den boolske litteralen `false`.                                                                                                           |
| [isFilledArray](isFilledArray.md)           | Sjekkar om `value` er ein tabell med minst eitt element, og returnerer `true` eller `false`.                                                                                                 |
| [isFinite](isFinite.md)                     | Avgjer om ein gitt `value` er eit endeleg `number`.                                                                                                                                          |
| [isFloat](isFloat.md)                       | `isFloat` avgjer om ein gitt `value` er eit endeleg flyttal (eit `number` som ikkje er eit heiltal).                                                                                         |
| [isHexadecimal](isHexadecimal.md)           | `isHexadecimal` sjekkar om ein gitt verdi er ein heksadesimal strengliteral med obligatorisk `0x`/`0X`-prefiks.                                                                              |
| [isIndexFound](isIndexFound.md)             | `isIndexFound` avgjer om ein gitt verdi er eit ikkje-negativt heiltal, som indikerer at ein indeks er funnen.                                                                                |
| [isInteger](isInteger.md)                   | Avgjer om ein gitt `value` er eit trygt heiltalstal.                                                                                                                                         |
| [isMap](isMap.md)                           | Kontrollerer om den gjevne `value` er ein `Map`, og returnerer `true` viss han er det og `false` elles.                                                                                      |
| [isNaN](isNaN.md)                           | Avgjer om den oppgjevne `value` er ein `NaN` av typen `number` utan å konvertere strengar.                                                                                                   |
| [isNull](isNull.md)                         | Avgjer om den oppgjevne `value` er `null`.                                                                                                                                                   |
| [isNullOrUndefined](isNullOrUndefined.md)   | Sjekkar om ein gitt verdi er `null` eller `undefined`.                                                                                                                                       |
| [isNumber](isNumber.md)                     | `isNumber` sjekkar om ein verdi er eit endeleg tal som ikkje er `NaN`.                                                                                                                       |
| [isNumeric](isNumeric.md)                   | `isNumeric` avgjer om ein gitt `value` blir rekna som numerisk ved å sjekka den oppløyste typen opp mot `NUMERIC_TYPES`.                                                                     |
| [isObject](isObject.md)                     | Avgjer om ein gitt `value` er eit `object` (utanom `null`).                                                                                                                                  |
| [isOctal](isOctal.md)                       | Avgjer om ein verdi er ein gyldig oktal literal-streng (t.d. `0o755`).                                                                                                                       |
| [isOfType](isOfType.md)                     | Avgjer om ein gitt `value` samsvarar med ein spesifisert typestreng, ved å bruke `typeof` for primitive typar og ein reserve for komplekse typar.                                            |
| [isOneOfType](isOneOfType.md)               | `isOneOfType` avgjer om ein gitt `value` samsvarar med minst éin av dei oppgjevne typestrengane, og returnerer `true` dersom det finst eit treff og `false` elles.                           |
| [isPlainObject](isPlainObject.md)           | Sjekkar om ein gitt `value` er eit vanleg objekt og returnerer `true` viss det er det, elles `false`.                                                                                        |
| [isPrimitive](isPrimitive.md)               | `isPrimitive` avgjer om ein gitt verdi er ein primitive (`null`, `undefined`, `boolean`, `number`, `string`, `bigint`, `symbol`).                                                            |
| [isPromise](isPromise.md)                   | Avgjer om ein gitt verdi er ein `Promise`.                                                                                                                                                   |
| [isRegEx](isRegEx.md)                       | Avgjer om ein oppgjeven verdi er ein `RegExp`-instans.                                                                                                                                       |
| [isSet](isSet.md)                           | Avgjer om ein gitt verdi er ein `Set`.                                                                                                                                                       |
| [isStream](isStream.md)                     | `isStream` sjekkar om ein gitt verdi er eit straumobjekt (Node.js-straumliknande, `ReadableStream` eller `WritableStream`).                                                                  |
| [isString](isString.md)                     | `isString` avgjer om ein gitt verdi er ein streng.                                                                                                                                           |
| [isSymbol](isSymbol.md)                     | `isSymbol` avgjer om ein gitt verdi er av typen `symbol`, og returnerer `true` for symbol og `false` elles.                                                                                  |
| [isTrue](isTrue.md)                         | `isTrue` avgjer om ein gitt verdi er strengt lik `true`.                                                                                                                                     |
| [isUndefined](isUndefined.md)               | Sjekkar om ein gitt verdi er `undefined`.                                                                                                                                                    |
| [isValidDate](isValidDate.md)               | `isValidDate` sjekkar om ein gitt verdi er eit gyldig `Date`-objekt og returnerer `true` berre for ekte, ikkje-ugyldige datoar.                                                              |
| [isWeakMap](isWeakMap.md)                   | Avgjer om ein gitt `value` er ein `WeakMap`-instans.                                                                                                                                         |
| [isWeakSet](isWeakSet.md)                   | Avgjer om den gjevne `value` er ein `WeakSet` av objekt.                                                                                                                                     |
