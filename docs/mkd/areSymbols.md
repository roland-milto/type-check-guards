# areSymbols

## Опис

Проверува дали влезот е пополнета низа чии елементи се сите симболи, враќајќи `true` или `false`.

### Случај на употреба

Валидирајте дека поле во конфигурација (на пр., листа од уникатни клучеви претставени како симболи) е непразна низа што
содржи само симболи пред да ја користите во API-и што бараат `symbol[]`.

> **Белешка за корисници на TypeScript:**
>
> Користете `areSymbols` за да валидирате непознат влез пред да го третирате како `symbol[]`; враќа `false` за не-низи и
> празни низи.

### Предности

- Враќа `true` само кога влезот е непразна низа и секој елемент е симбол.
- Спречува лажни позитиви со отфрлање на не-низи и празни низи преку внатрешната проверка за пополнета низа.
- Корисно како runtime заштитник на тип (type guard) за валидација на листи што содржат само симболи пред понатамошна
  обработка.

## Употреба

### Синтакса

Функција:

- `areSymbols(array)`

Параметри:

- `array`: Низата што треба да се провери дали содржи елементи од тип симбол.

### Локален импорт на функција

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  // a е низа само од симболи во време на извршување
  const first = a[0];
  console.log(typeof first); // "симбол"
}

console.log(areSymbols(b)); // неточно
```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areSymbols(array)`
