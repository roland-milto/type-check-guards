# arePlainObjects

## Опис

Проверува дали сите елементи на една низа се обични објекти, враќајќи `true` само ако секој елемент ги исполнува
условите.

### Случај на употреба

Валидирајте надворешни или нетипизирани податоци (на пр., парсиран JSON, API payloads, поднесоци од формулари) за да се
осигурате дека сте добиле непразна низа каде што секој запис е обичен објект пред да итерирате и да читате својства.

> **Белешка за корисници на TypeScript:**
>
> Користете `arePlainObjects` за да валидирате непознат влез пред да го третирате како `Record<string, unknown>[]` (или
> построга форма на објект) во TypeScript.

### Предности

- Осигурува дека секој елемент во влезната низа е обичен објект, враќајќи `true` само кога сите ставки се совпаѓаат.
- Рано ги отфрла невалидните влезови (не-низи или празни низи) со враќање `false`.
- Ги третира и објектите создадени со објект-литерал и објектите `Object.create(null)` како валидни обични објекти.

## Употреба

### Синтакса

Функција:

- `arePlainObjects(array)`

Параметри:

- `array`: Низата што треба да се провери дали содржи елементи што се обични објекти.

### Локален импорт на функција

```ts
import { arePlainObjects } from "@type-check/guards";

const a = arePlainObjects([{ a: 1 }, { b: 2 }]); // точно
const b = arePlainObjects([{}, Object.create(null)]); // точно
const c = arePlainObjects([{ a: 1 }, 2 as unknown]); // неточно
const d = arePlainObjects([] as unknown[]); // неточно
```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.arePlainObjects(array)`
