# isNaN

## Опис

Утврдува дали дадената `value` е `NaN` од тип `number` без конвертирање на стрингови.

### Случај на употреба

Валидирајте недоверлив или лабаво типизиран влез (на пр. API payloads, вредности од формулар, парсиран JSON) за да ја
детектирате специјалната вредност `NaN` и експлицитно да ја обработите, додека влезовите што не се броеви се третираат
како да не се `NaN`.

> **Белешка за корисници на TypeScript:**
>
> Користете `isNaN` кога треба да ја детектирате специјалната нумеричка вредност `NaN` додека осигурувате дека влезот
> навистина е `number` (без конверзија од стринг во број).

### Предности

- Проверува дали вредноста е `NaN` без да ги присилува невредностите што не се броеви (на пр. стрингови) во броеви.
- Враќа `true` само за вредности што се и од тип `number` и `NaN`.
- Безбедно за влезови од тип `unknown` и избегнува лажни позитиви од имплицитни конверзии.

## Употреба

### Синтакса

Функција:

- `isNaN(value)`

Параметри:

- `value`: Вредноста што треба да се провери дали е `NaN` од тип `number`.

### Локален импорт на функција

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // точно
console.log(isNaN(b)); // неточно
console.log(isNaN(c)); // неточно

if (isNaN(a)) {
  // a е број и конкретно NaN
}
```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isNaN(value)`
