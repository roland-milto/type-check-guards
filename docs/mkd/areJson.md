# areJson

## Опис

Проверува дали сите елементи на една низа се JSON-низи, враќајќи `true` само ако низата е пополнета и секоја ставка е
валиден JSON; во спротивно враќа `false`.

### Случај на употреба

Валидирајте влезни податоци (на пр., од query params, променливи на околината или надворешни API-и) кога очекувате низа
од JSON-кодирани низи и сакате да одбиете празни низи или какви било ставки што не се JSON.

> **Белешка за корисници на TypeScript:**
>
> Користете `areJson` кога треба да потврдите дека `unknown[]` содржи само JSON-низи пред да ги парсирате (на пр., со
`JSON.parse`).

### Предности

- Враќа `true` само кога секој елемент е валидна JSON-низа; во спротивно враќа `false`.
- Брзо откажување: престанува со проверка штом ќе се пронајде елемент што не е JSON.
- По дизајн одбива празни низи, враќајќи `false` за непополнет влез.

## Употреба

### Синтакса

Функција:

- `areJson(array)`

Параметри:

- `array`: Низата што треба да се провери дали содржи JSON-низи како елементи.

### Локален импорт на функција

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // точно
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // неточно
const empty = areJson([]); // неточно

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areJson(array)`
