# areNaNs

## Опис

`areNaNs` проверува дали сите елементи во низа се `NaN` и враќа `true` само ако секој елемент е `NaN`.

### Случај на употреба

Валидирајте влезни податоци каде `NaN` се користи како сентинел вредност и мора да се осигурате дека целата низа се
состои исклучиво од `NaN` (на пр., детектирање целосно недостасувачка нумеричка серија).

> **Белешка за корисници на TypeScript:**
>
> Користете `areNaNs` кога треба да потврдите дека низа содржи само нумеричка вредност `NaN` (без присилување од стринг
> во број).

### Предности

- Враќа `true` само кога секој елемент е `NaN` (строга проверка за сите елементи).
- Не ги присилува стринговите во броеви; вредности како "NaN" остануваат не-`NaN` и го прават резултатот `false`.
- Враќа `false` за непополнети низи, спречувајќи случајно `true` при празен влез.

## Употреба

### Синтакса

Функција:

- `areNaNs(array)`

Параметри:

- `array`: Низата што треба да се провери за `NaN` вредности.

### Локален импорт на функција

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // точно
const b = areNaNs([NaN, 1, NaN]); // неточно
const c = areNaNs([NaN, "NaN", NaN]); // неточно
const d = areNaNs([NaN, null, NaN]); // неточно
const e = areNaNs([] as unknown[]); // неточно
```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areNaNs(array)`
