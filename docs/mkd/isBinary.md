# isBinary

## Опис

`isBinary` одредува дали некоја вредност е бинарна низа (опционално со префикс `0b`/`0B`) и враќа `true` или `false`.

### Случај на употреба

Валидирајте низи внесени од корисник (на пр., полиња во формулар, CLI аргументи, конфигурациски вредности) за да се
осигурате дека претставуваат само бинарни цифри, опционално со префикс `0b`/`0B`, пред понатамошна обработка.

> **Белешка за корисници на TypeScript:**
>
> Користете `isBinary` како чувар на тип (type guard) пред парсирање или конвертирање на низа во `BigInt`/`Number` за да
> избегнете невалиден влез.

### Предности

- Прифаќа бинарни низи со или без префиксот `0b`/`0B`.
- Отфрла празни низи и низи со водечки/завршни празни места (ASCII ≤ 32).
- Враќа `true`/`false` без да фрла исклучок, што го прави безбедно за непознати влезови.

## Употреба

### Синтакса

Функција:

- `isBinary(value)`

Параметри:

- `value`: Вредноста што треба да се провери.

### Локален импорт на функција

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // точно
const b = isBinary("1010");   // точно
const c = isBinary("0b1020"); // неточно
const d = isBinary(0b1010);     // неточно

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isBinary(value)`
