# areNumbers

## Опис

`areNumbers` проверува дали вредноста е непразна низа во која сите елементи се броеви.

### Случај на употреба

Валидирајте податоци доставени од корисник или од API за да се осигурате дека се непразна низа од броеви пред да
пресметувате збир, просек или други нумерички агрегации.

> **Белешка за корисници на TypeScript:**
>
> Користете `areNumbers` за да валидирате непознати низи пред да извршувате нумерички пресметки; враќа `false` за празни
> низи и за низи што содржат било која вредност што не е број.

### Предности

- Враќа `true` само кога влезот е непразна низа и секој елемент е број.
- Спречува лажни позитивни резултати со отфрлање на празни низи и влезови што не се низи.
- Корисно како заштитна проверка пред нумерички операции (на пр., собирање, пресметување просек) за да се избегнат
  грешки при извршување.

## Употреба

### Синтакса

Функција:

- `areNumbers(array)`

Параметри:

- `array`: Низата што треба да се провери дали содржи бројчени елементи.

### Локален импорт на функција

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areNumbers(array)`
