# areSets

## Опис

Проверува дали дадена непразна низа содржи само инстанци на `Set`, враќајќи `true` ако е така и `false` во спротивно.

### Случај на употреба

Валидирајте дека вредност (на пр., од кориснички влез, парсирање JSON или надворешни API-ја) е непразна низа од `Set`
објекти пред да го обработувате секој сет.

> **Белешка за корисници на TypeScript:**
>
> Користете `areSets` за да валидирате непознат влез пред да итерирате и да повикувате `Set` API-ја (на пр., `.size`,
`.has`, `.add`) на секој елемент.

### Предности

- Враќа `true` само кога влезот е непразна низа и секој елемент е инстанца на `Set`.
- Спречува лажно позитивни резултати за празни низи со тоа што враќа `false` кога низата нема елементи.
- Корисно како runtime заштита пред извршување операции специфични за `Set` врз секој елемент.

## Употреба

### Синтакса

Функција:

- `areSets(array)`

Параметри:

- `array`: Низата што треба да се провери за инстанци на `Set`.

### Локален импорт на функција

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  // a е низа од инстанци на Set во време на извршување
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); // неточно
console.log(areSets(c)); // неточно
```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areSets(array)`
