# areDecimals

## Опис

Проверува дали сите елементи во низа се децимални броеви и дали низата е пополнета, враќајќи `true` или `false`.

### Случај на употреба

Валидирајте листи обезбедени од корисник (на пр., CSV колони или внесови од формулар) за да се осигурате дека низата не
е празна и дека секој запис е децимална вредност пред парсирање или пресметки.

> **Белешка за корисници на TypeScript:**
>
> Користете `areDecimals` кога ви треба брза булова проверка дека `unknown[]` не е празна и дека секој елемент е
> децимална репрезентација.

### Предности

- Осигурува влезот да биде пополнета низа пред да се валидираат елементите, спречувајќи случајно прифаќање на празни
  листи.
- Го валидира секој елемент со `isDecimal`, па мешани или невалидни вредности веднаш даваат резултат `false`.
- Обезбедува едноставен булов исход (`true`/`false`) погоден за guard-и и текови на валидација со рано враќање.

## Употреба

### Синтакса

Функција:

- `areDecimals(array)`

Параметри:

- `array`: Низата што треба да се провери.

### Локален импорт на функција

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // точно
console.log(areDecimals(b)); // неточно
console.log(areDecimals(c)); // неточно
```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areDecimals(array)`
