| [areErrors](areErrors.md)                   | Проверува дали низата е непразна и содржи само `Error` објекти, враќајќи `true` или `false`.                                                                                                      |

| [areFilledArrays](areFilledArrays.md)       | `areFilledArrays` проверува дали дводимензионална низа не е празна и дали сите нејзини поднизи не се празни.                                                                                      |
| [areFinite](areFinite.md)                   | `areFinite` проверува дали вредноста е непразна низа чии елементи се сите конечни броеви, враќајќи `true` ако е така и `false` во спротивно.                                                      |
| [areFloats](areFloats.md)                   | `areFloats` проверува дали дадена низа е пополнета и дали сите нејзини елементи се децимални броеви (float).                                                                                      |
| [areHexadecimals](areHexadecimals.md)       | Проверува дали сите елементи во низа се хексадецимални низи, враќајќи `true` само за непразни низи каде што секоја ставка е валидна.                                                              |
| [areIndexesFound](areIndexesFound.md)       | `areIndexesFound` проверува дали вредноста е непразна низа чии елементи се сите валидни индекси, враќајќи `true` ако се и `false` во спротивно.                                                   |
| [areIntegers](areIntegers.md)               | `areIntegers` утврдува дали сите елементи во дадена низа се цели броеви, враќајќи `true` ако се и `false` во спротивно.                                                                           |
| [areJson](areJson.md)                       | Проверува дали сите елементи на една низа се JSON-низи, враќајќи `true` само ако низата е пополнета и секоја ставка е валиден JSON; во спротивно враќа `false`.                                   |
| [areMaps](areMaps.md)                       | `areMaps` утврдува дали дадена низа е непразна и дали сите нејзини елементи се инстанци на `Map`.                                                                                                 |
| [areNaNs](areNaNs.md)                       | `areNaNs` проверува дали сите елементи во низа се `NaN` и враќа `true` само ако секој елемент е `NaN`.                                                                                            |
| [areNullOrUndefined](areNullOrUndefined.md) | Проверува дали сите елементи во дадената низа се `null` или `undefined`.                                                                                                                          |
| [areNumbers](areNumbers.md)                 | `areNumbers` проверува дали вредноста е непразна низа во која сите елементи се броеви.                                                                                                            |
| [areNumerics](areNumerics.md)               | `areNumerics` проверува дали вредноста е непразна низа во која сите елементи се нумерички.                                                                                                        |
| [areObjects](areObjects.md)                 | `areObjects` проверува дали дадена пополнета низа содржи само објекти.                                                                                                                            |
| [areOctals](areOctals.md)                   | `areOctals` утврдува дали дадената вредност е непразна низа од валидни октални низи.                                                                                                              |
| [areOfType](areOfType.md)                   | Проверува дали сите елементи во дадената `array` се од наведениот `type`.                                                                                                                         |
| [areOneOfType](areOneOfType.md)             | `areOneOfType` проверува дали сите елементи во непразна низа се од еден од наведените runtime типови.                                                                                             |
| [arePlainObjects](arePlainObjects.md)       | Проверува дали сите елементи на една низа се обични објекти, враќајќи `true` само ако секој елемент ги исполнува условите.                                                                        |
| [arePrimitives](arePrimitives.md)           | `arePrimitives` оценува дали сите елементи во дадена, непразна низа се примитивни типови.                                                                                                         |
| [arePromises](arePromises.md)               | `arePromises` утврдува дали сите елементи во низа се инстанци на `Promise`.                                                                                                                       |
| [areRegExes](areRegExes.md)                 | `areRegExes` проверува дали вредноста е пополнета низа што содржи само `RegExp` објекти.                                                                                                          |
| [areSets](areSets.md)                       | Проверува дали дадена непразна низа содржи само инстанци на `Set`, враќајќи `true` ако е така и `false` во спротивно.                                                                             |

| [areSymbols](areSymbols.md)                 | Проверува дали влезот е пополнета низа чии елементи се сите симболи, враќајќи `true` или `false`.                                                                                                 |
| [areTrue](areTrue.md)                       | Проверува дали непразна низа содржи само булови вредности `true`.                                                                                                                                 |
| [areUndefined](areUndefined.md)             | `areUndefined` проверува дали секој елемент во дадена низа е `undefined`.                                                                                                                         |

| [areWeakMaps](areWeakMaps.md)               | `areWeakMaps` проверува дали вредноста е непразна низа каде што секој елемент е `WeakMap`, враќајќи `true` само во тој случај и `false` во спротивно.                                             |
| [areWeakSets](areWeakSets.md)               | Проверува дали влезот е непразна низа каде што секој елемент е `WeakSet`, враќајќи `true` само во тој случај.                                                                                     |

| [isBinary](isBinary.md)                     | `isBinary` одредува дали некоја вредност е бинарна низа (опционално со префикс `0b`/`0B`) и враќа `true` или `false`.                                                                             |

| [isDecimal](isDecimal.md)                   | `isDecimal` проверува дали некоја вредност е децимална низа без водечки/завршни празни места и со валиден децимален формат.                                                                       |
| [isEmpty](isEmpty.md)                       | Утврдува дали дадена вредност е празна, враќајќи `true` за `null`, `undefined`, празни/стрингови со празни места, празни низи, празни `Map`/`Set`, или објекти без сопствени набројливи својства. |

| [isFilledArray](isFilledArray.md)           | Проверува дали `value` е низа со барем еден елемент, враќајќи `true` или `false`.                                                                                                                 |

| [isHexadecimal](isHexadecimal.md)           | `isHexadecimal` проверува дали дадена вредност е хексадецимален литерал како низа со задолжителен префикс `0x`/`0X`.                                                                              |
| [isIndexFound](isIndexFound.md)             | `isIndexFound` утврдува дали дадена вредност е ненегативен цел број, што укажува дека е пронајден индекс.                                                                                         |

| [isOneOfType](isOneOfType.md)               | `isOneOfType` утврдува дали дадената `value` се совпаѓа со барем еден од обезбедените стрингови за тип, враќајќи `true` ако се најде било какво совпаѓање и `false` во спротивно.                 |
| [isPlainObject](isPlainObject.md)           | Проверува дали дадената `value` е обичен објект и враќа `true` ако е, во спротивно `false`.                                                                                                       |
| [isPrimitive](isPrimitive.md)               | `isPrimitive` одредува дали дадена вредност е примитив (`null`, `undefined`, `boolean`, `number`, `string`, `bigint`, `symbol`).                                                                  |
