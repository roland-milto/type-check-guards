# areMaps

## Опис

`areMaps` утврдува дали дадена низа е непразна и дали сите нејзини елементи се инстанци на `Map`.

### Случај на употреба

Валидирај непознат влез (на пр., од парсирање JSON, надворешни API-и или динамични извори) пред да го третираш како
непразна листа од `Map` објекти.

> **Белешка за корисници на TypeScript:**
>
> Враќа `false` за празна низа; враќа `true` само кога низата е пополнета и секој елемент е `Map`.

### Предности

- Осигурува дека секој елемент е инстанца на `Map`, враќајќи `true` само кога целата низа ја поминува проверката.
- По дизајн ги отфрла празните низи, спречувајќи случајно прифаќање на „нема податоци“ како валиден влез.
- Корисно како заштитна проверка пред извршување операции специфични за `Map` (на пр., `.get()`, `.set()`, итерирање)
  низ колекција.

## Употреба

### Синтакса

Функција:

- `areMaps(array)`

Параметри:

- `array`: Низата што треба да се провери.

### Локален импорт на функција

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // items е гарантирано дека е непразна низа од инстанци на Map во време на извршување
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // false за: празни низи или низи што содржат било која вредност што не е Map
}

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areMaps(array)`
