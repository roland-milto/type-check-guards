# isEmpty

## Опис

Утврдува дали дадена вредност е празна, враќајќи `true` за `null`, `undefined`, празни/стрингови со празни места, празни
низи, празни `Map`/`Set`, или објекти без сопствени набројливи својства.

### Случај на употреба

Користете `isEmpty` за да валидирате влезови и да откривате недостасувачки/празни вредности низ повеќе типови податоци (
на пр., полиња во форми, API payload-и, конфигурациски објекти) каде што `null`, `undefined`, стрингови со празни места,
празни колекции и објекти без својства треба да се третираат како празни.

> **Белешка за корисници на TypeScript:**
>
> `isEmpty` е алатка што враќа булова вредност (не е TypeScript type predicate), па затоа самостојно не ги стеснува
> типовите; користете ја за валидација/разгранување наместо за стеснување во време на компајлирање.

### Предности

- Ги третира `null` и `undefined` како `true` при проверки за празнина.
- Ги смета стринговите што содржат само празни места за празни, со отсекување (trim) пред проверка на должината.
- Поддржува вообичаени типови контејнери (низи, `Map`, `Set`) и обични објекти без сопствени набројливи својства.
- Избегнува броење наследени својства со користење проверки `hasOwnProperty`.
- Враќа едноставен булов резултат (`true`/`false`) погоден за guard-и и валидација.

## Употреба

### Синтакса

Функција:

- `isEmpty(value)`

Параметри:

- `value`: Вредноста што треба да се провери за празнина.

### Локален импорт на функција

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isEmpty(value)`
