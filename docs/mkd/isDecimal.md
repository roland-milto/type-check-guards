# isDecimal

## Опис

`isDecimal` проверува дали некоја вредност е децимална низа без водечки/завршни празни места и со валиден децимален
формат.

### Случај на употреба

Валидирајте полиња во формулари, API payload-и или конфигурациски вредности што мора да бидат дадени како децимална
низа (опционално со знак) без никакви празни места околу нив, пред парсирање или складирање.

> **Белешка за корисници на TypeScript:**
>
> Користете `isDecimal` за да валидирате кориснички влез пред да го конвертирате (на пр., со `Number(value)`), особено
> кога празните места мора да се отфрлат.

### Предности

- Строго проверува дека влезот е низа и дека се совпаѓа со шема за децимален литерал.
- Отфрла водечки и завршни празни места (вклучувајќи контролни знаци) за да се избегне двосмислено парсирање.
- Брзи пред-проверки (проверка на тип и прв/последен знак) пред да се изврши regex-от.
- Враќа едноставен булов резултат (`true`/`false`) погоден за guard-и и валидација на влез.

## Употреба

### Синтакса

Функција:

- `isDecimal(value)`

Параметри:

- `value`: Вредноста што треба да се провери за формат на децимална низа.

### Локален импорт на функција

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v е низа тука (проверено при извршување)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isDecimal(value)`
