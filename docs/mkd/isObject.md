# isObject

## Опис

Утврдува дали дадена `value` е `object` (исклучувајќи `null`).

### Случај на употреба

Користете `isObject` за да валидирате непознати влезови (на пр., парсиран JSON, API одговори, payload-и од настани) пред
да пристапите до својства, осигурувајќи дека вредноста е објект, а не `null`.

> **Белешка за корисници на TypeScript:**
>
> `isObject` е runtime guard што враќа boolean; не го стеснува типот на конкретна форма на објект. Комбинирајте го со
> дополнителни проверки (на пр., постоење на својства) кога ви треба посилно типизирање.

### Предности

- Враќа `true` само за не-`null` вредности чиј `typeof` е `"object"`.
- Ја спречува вообичаената JavaScript замка каде `null` инаку би се третирал како објект.
- Работи за обични објекти и вградени инстанци на објекти (на пр., `Date`, `RegExp`).
- Едноставна, брза проверка во runtime, соодветна за дефанзивно програмирање и валидација на влезни податоци.

## Употреба

### Синтакса

Функција:

- `isObject(value)`

Параметри:

- `value`: Вредноста што треба да се провери дали е `object`.

### Локален импорт на функција

```ts
import { isObject } from "@type-check/guards";

const input: unknown = { a: 1 };

if (isObject(input)) {
  // input е ненул објект при извршување
  console.log("Object detected");
} else {
  console.log("Not an object");
}

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isObject(value)`
