# areWeakMaps

## Опис

`areWeakMaps` проверува дали вредноста е непразна низа каде што секој елемент е `WeakMap`, враќајќи `true` само во тој
случај и `false` во спротивно.

### Случај на употреба

Валидирајте податоци во извршување (на пр., парсиран JSON, влезови од приклучоци или лабаво типизирана конфигурација) за
да се осигурате дека станува збор за непразна низа од инстанци на `WeakMap` пред да итерирате и да повикувате методи на
`WeakMap`; враќа `false` кога кој било елемент не е `WeakMap` или кога низата е празна.

> **Белешка за корисници на TypeScript:**
>
> Користете `areWeakMaps` за да валидирате непознат влез пред да го третирате како непразна `WeakMap[]`; враќа `false`
> за празни низи.

### Предности

- Осигурува дека секој елемент во дадената низа е инстанца на `WeakMap`.
- Враќа `false` за празни низи, спречувајќи случајно прифаќање на „нема податоци“ како валиден влез.
- Корисно како заштитна проверка пред извршување операции специфични за `WeakMap` врз сите ставки.

## Употреба

### Синтакса

Функција:

- `areWeakMaps(array)`

Параметри:

- `array`: Низата што треба да се провери за инстанци на `WeakMap`.

### Локален импорт на функција

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  // list е непразна низа од инстанци на WeakMap
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  // не е непразна WeakMap[]
}

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areWeakMaps(array)`
