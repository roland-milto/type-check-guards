# areEqual

## Опис

`areEqual` проверува дали сите елементи во низа се еднакви на дадена очекувана вредност, враќајќи `true` само за
непразни низи каде што секоја ставка се совпаѓа.

### Случај на употреба

Потврдете дека листа содржи само една дозволена вредност (на пр., сите статусни знаменца се `true`, сите улоги се
`"admin"`, или сите нумерички внесови се еднакви на потребна константа) при што празниот влез се смета за невалиден (
`false`).

> **Белешка за корисници на TypeScript:**
>
> Користете `areEqual` кога ви треба строга проверка за сите ставки; враќа `false` за празни низи и за секој влез што не
> е низа или не е пополнет.

### Предности

- Враќа `true` само кога секој елемент се совпаѓа со очекуваната вредност; во спротивно враќа `false`.
- Брзо откажување: престанува со проверка штом ќе се пронајде елемент што не се совпаѓа.
- Штити од невалиден влез со тоа што враќа `false` кога влезот не е пополнета низа.

## Употреба

### Синтакса

Функција:

- `areEqual(value, expected)`

Параметри:

- `value`: Низата што треба да се провери.
- `expected`: Елементот со кој се споредува секоја ставка од низата.

### Локален импорт на функција

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areEqual(value, expected)`
