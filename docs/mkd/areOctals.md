# areOctals

## Опис

`areOctals` утврдува дали дадената вредност е непразна низа од валидни октални низи.

### Случај на употреба

Користете `areOctals` при валидација на кориснички внес, конфигурациски вредности или API payload-и што мора да содржат
октални литерали (на пр., режими за дозволи на датотеки како `0o755`) и сакате да отфрлите празни низи или какви било
невалидни записи со враќање `false`.

> **Белешка за корисници на TypeScript:**
>
> Користете `areOctals` за да се уверите дека имате непразна `unknown[]` каде што секој запис е валидна октална низа
> пред конвертирање (на пр., преку `Number(...)` или сопствено парсирање).

### Предности

- Потврдува дека вредноста е непразна низа каде што секој елемент е октална низа, враќајќи `true` само кога сите ставки
  ќе поминат.
- Брзо откажување: враќа `false` веднаш штом ќе се пронајде не-октален елемент.
- Корисно како заштитна проверка пред парсирање или конвертирање на октални низи за да се избегнат runtime грешки и
  неконзистентно ракување со влезни податоци.

## Употреба

### Синтакса

Функција:

- `areOctals(array)`

Параметри:

- `array`: Вредноста што треба да се провери.

### Локален импорт на функција

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value е непразна низа од октални стрингови
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areOctals(array)`
