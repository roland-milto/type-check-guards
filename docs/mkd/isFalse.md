# isFalse

## Опис

`isFalse` проверува дали дадена вредност е строго еднаква на буловиот литерал `false`.

### Случај на употреба

Валидирајте непознати податоци (на пр., од JSON, параметри од query или кориснички внес) каде што само експлицитната
булова вредност `false` треба да се третира како валиден флаг, а сè друго треба да се одбие.

> **Белешка за корисници на TypeScript:**
>
> Користете `isFalse` кога треба да го прифатите само литералот `false` и да ги одбиете сите други „falsy“ вредности;
> враќа `true` само за `value === false`.

### Предности

- Обезбедува строго проверување за буловиот литерал `false` без присилна конверзија.
- Помага да се разликува `false` од други „falsy“ вредности како `0`, `""`, `null` и `undefined`.
- Ја подобрува читливоста со тоа што ја прави намерата експлицитна при валидација на непознат влез.

## Употреба

### Синтакса

Функција:

- `isFalse(value)`

Параметри:

- `value`: Вредноста што треба да се провери.

### Локален импорт на функција

```ts
import { isFalse } from "@type-check/guards";

const input: unknown = false;

if (isFalse(input)) {
  // input е точно false тука
  console.log("Got false");
} else {
  console.log("Not false");
}

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isFalse(value)`
