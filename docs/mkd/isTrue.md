# isTrue

## Опис

`isTrue` одредува дали дадена вредност е строго еднаква на `true`.

### Случај на употреба

Користете `isTrue` за валидација на знаменца, прекинувачи за функционалности или конфигурациски вредности каде што треба
да се прифати само литералот `true`, а сè друго мора да се третира како `false`.

> **Белешка за корисници на TypeScript:**
>
> Користете `isTrue` кога треба да прифатите само буловиот литерал `true`, а не само „truthy“ вредности.

### Предности

- Обезбедува строга проверка за буловиот литерал `true` (без присилна конверзија).
- Помага да се разликува `true` од „truthy“ вредности како `1`, `"true"` или `{}`.
- Едноставно, предвидливо однесување, соодветно за гардови и валидациски цевководи.

## Употреба

### Синтакса

Функција:

- `isTrue(value)`

Параметри:

- `value`: Вредноста што треба да се провери.

### Локален импорт на функција

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // точно
const b = isTrue(1);         // неточно
const c = isTrue("true");   // неточно

if (isTrue(a)) {
  // a е точно тука
}
```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isTrue(value)`
