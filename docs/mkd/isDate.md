# isDate

## Опис

`isDate` утврдува дали дадена вредност е `Date`, враќајќи `true` за инстанци од `Date` и `false` во спротивно.

### Случај на употреба

Валидирајте и стеснете непознати вредности (на пр., податоци од барање, конфигурациски вредности или парсиран JSON) пред
да извршувате `Date` операции како форматирање, споредби или повикување `toISOString()`.

> **Белешка за корисници на TypeScript:**
>
> Користете `isDate` за да го стесните `unknown` на `Date` во runtime; враќа `true` само за вистински инстанци од
`Date` (не и за стрингови што претставуваат датум).

### Предности

- Обезбедува едноставна runtime заштита за да се провери дали некоја вредност е `Date`.
- Помага да се спречат типски грешки со тоа што осигурува дека само инстанци од `Date` ја поминуваат валидацијата.
- Корисно е за валидација на непознати влезови (на пр., API payloads) пред користење методи специфични за датуми.

## Употреба

### Синтакса

Функција:

- `isDate(value)`

Параметри:

- `value`: Вредноста што треба да се провери за тип `Date`.

### Локален импорт на функција

```ts
import { isDate } from "@type-check/guards";

const input: unknown = new Date();

if (isDate(input)) {
  // input е Date тука
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a Date");
}

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isDate(value)`
