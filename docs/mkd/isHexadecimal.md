# isHexadecimal

## Опис

`isHexadecimal` проверува дали дадена вредност е хексадецимален литерал како низа со задолжителен префикс `0x`/`0X`.

### Случај на употреба

Користете `isHexadecimal` за да валидирате конфигурациски вредности, полиња во API payload, или CLI аргументи што мора
да бидат зададени како хексадецимални литерали во низа (на пр., ID-ја, маски или адреси) и не смеат да содржат празни
места околу нив.

> **Белешка за корисници на TypeScript:**
>
> Користете `isHexadecimal` кога треба да валидирате кориснички внес или серијализирани податоци како строг
> хексадецимален литерал во низа (вклучувајќи го префиксот `0x`/`0X`) пред парсирање или конверзија.

### Предности

- Потврдува дека вредноста е низа (string) и се совпаѓа со строг формат на хексадецимален литерал (бара префикс `0x`/
  `0X`).
- Отфрла низи со водечки или завршни празни места, помагајќи да се избегне случајно прифаќање на внес со додадени
  празнини.
- Поддржува опционален знак и не е чувствителен на големина на букви за префиксот и цифрите, враќајќи `true`/`false`
  предвидливо.

## Употреба

### Синтакса

Функција:

- `isHexadecimal(value)`

Параметри:

- `value`: Вредноста што треба да се провери.

### Локален импорт на функција

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // точно
isHexadecimal("-0Xff"); // точно
isHexadecimal("1A2B"); // неточно (недостасува префикс)
isHexadecimal(" 0x1A2B"); // неточно (водечка празнина)
isHexadecimal(0x1a2b); // неточно (не е низа)

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isHexadecimal(value)`
