# isNumeric

## Опис

`isNumeric` утврдува дали дадена `value` се смета за нумеричка така што го проверува нејзиниот разрешен тип во однос на
`NUMERIC_TYPES`.

### Случај на употреба

Користете `isNumeric` за да ги валидирате влезовите (на пр., API payload-и, вредности од форми, конфигурација) пред да
извршувате нумерички операции, и за конзистентно прифаќање на нумерички-слични типови (како `BigInt`) согласно
`NUMERIC_TYPES`.

> **Белешка за корисници на TypeScript:**
>
> `isNumeric` е предикат што враќа boolean; третирајте го како runtime проверка дали некоја вредност припаѓа на
> библиотечно-дефинираниот сет на нумерички типови.

### Предности

- Ги користи `getTypeOf` плус `NUMERIC_TYPES` за да ја централизира логиката за детекција на нумерички типови и да ги
  одржи проверките конзистентни низ целата кодна база.
- Враќа едноставен boolean (`true`/`false`) за лесно разгранување и употреба во стил на guard.
- Поддржува повеќе нумерички претставувања (на пр., `number`, `BigInt`) како што е дефинирано со `NUMERIC_TYPES`.

## Употреба

### Синтакса

Функција:

- `isNumeric(value)`

Параметри:

- `value`: Вредноста што треба да се провери дали е од нумерички тип.

### Локален импорт на функција

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    // v се смета за нумеричка според правилата за типови на библиотеката
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isNumeric(value)`
