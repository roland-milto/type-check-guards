# areBinaries

## Опис

Проверува дали дадената вредност е непразна низа од валидни бинарни низи и враќа `true` само ако сите ставки ја поминат
валидацијата.

### Случај на употреба

Користете `areBinaries` кога добивате непозната листа (на пр., од JSON, формулари или API-ја) и треба да осигурате дека
е непразна низа од бинарни низи пред да ја парсирате или обработите.

> **Белешка за корисници на TypeScript:**
>
> Користете `areBinaries` за да валидирате непознат влез пред да ги конвертирате бинарните низи во броеви/BigInts; тоа
> осигурува дека низата е непразна и дека секој елемент е валидна бинарна низа.

### Предности

- Потврдува дека вредноста е непразна низа каде што секој елемент е валидна бинарна низа.
- Враќа едноставен булов резултат (`true`/`false`) погоден за гардови, рани враќања и валидација на влез.
- Спречува последователни грешки при парсирање со отфрлање на низи што содржат каков било небинарен внес.

## Употреба

### Синтакса

Функција:

- `areBinaries(array)`

Параметри:

- `array`: Вредноста што треба да се провери.

### Локален импорт на функција

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // точно
console.log(areBinaries(b)); // неточно
console.log(areBinaries([])); // неточно
```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areBinaries(array)`
