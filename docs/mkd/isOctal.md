# isOctal

## Опис

Утврдува дали вредноста е валидна низа со октален литерал (на пр. `0o755`).

### Случај на употреба

Валидирајте кориснички внес или конфигурациски вредности што мора да бидат изразени како низа со октален литерал (на
пример, режими на дозволи за датотеки како `0o644`) пред парсирање или конвертирање.

> **Белешка за корисници на TypeScript:**
>
> `isOctal` е чувар на тип (`value is string`). По резултат `true`, TypeScript ја стеснува проверената променлива на
`string`.

### Предности

- Обезбедува строг чувар на тип: враќа `true` само кога влезот е низа што одговара на формат на октален литерал.
- Ги отфрла празните низи и низите со водечки/завршни празни места (ASCII контрола/празно место), намалувајќи случајни
  совпаѓања.
- Поддржува опционален знак и не е чувствителен на големина на букви за префиксот `0o`/`0O`.
- Поблаг за влезови што не се низа со тоа што враќа `false` наместо да фрли исклучок.

## Употреба

### Синтакса

Функција:

- `isOctal(value)`

Параметри:

- `value`: Вредноста што треба да се провери.

### Локален импорт на функција

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); // точно
console.log(isOctal(b)); // точно
console.log(isOctal(c)); // неточно
console.log(isOctal(d)); // неточно

if (isOctal(a)) {
  // a е стринг тука
  const normalized = a.toLowerCase();
  console.log(normalized);
}
```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isOctal(value)`
