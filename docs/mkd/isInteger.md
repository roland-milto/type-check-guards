# isInteger

## Опис

Одредува дали дадена `value` е безбеден цел број.

### Случај на употреба

Валидирајте недоверлив влез (на пр., параметри од query, JSON payload-и, променливи на околината) пред да го користите
како цел број за индекси на низи, пагинација, бројачи или ID-иња во база на податоци.

> **Белешка за корисници на TypeScript:**
>
> Користете `isInteger` за да валидирате непознат влез пред да го третирате како нумерички цел број; враќа `true` само
> за вредности каде `typeof value === "number"` и `Number.isSafeInteger(value)`.

### Предности

- Ја проверува и типската и нумеричката безбедност: враќа `true` само кога влезот е број и безбеден цел број.
- Спречува вообичаени замки со нумеричка коерција: низи како "5" правилно враќаат `false`.
- Ги отфрла нецелите броеви и небезбедните цели броеви, што го прави соодветно за ID-иња, бројачи и индексирање на низи.

## Употреба

### Синтакса

Функција:

- `isInteger(value)`

Параметри:

- `value`: Вредноста што треба да се провери за статус на цел број.

### Локален импорт на функција

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      // точно
const b = isInteger(-100);   // точно
const c = isInteger("5");    // неточно
const d = isInteger(5.5);    // неточно
const e = isInteger(null);   // неточно

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isInteger(value)`
