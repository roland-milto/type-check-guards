# areArrays

## Опис

`areArrays` утврдува дали некоја вредност е пополнета дводимензионална низа чии елементи сите се низи.

### Случај на употреба

Користете `areArrays` за да валидирате табеларни или матрични влезови (на пр., CSV редови, податоци за мрежа или
групирани листи) пред да извршувате операции по редови/колони; враќа `false` ако влезот не е низа, е празен или содржи
било кој елемент што не е низа.

> **Белешка за корисници на TypeScript:**
>
> Користете `areArrays` кога треба да се осигурате дека вредноста е непразна 2D низа и дека секој ред е низа пред да
> итерирате или да индексирате во вгнездени низи.

### Предности

- Потврдува дека влезот е непразна дводимензионална низа каде што секој елемент е низа.
- Враќа едноставен булов резултат (`true`/`false`) погоден за гардови и рани излези.
- Помага да се спречат грешки при извршување кога подоцнежниот код претпоставува операции со вгнездени низи (на пр.,
  мапирање редови).

## Употреба

### Синтакса

Функција:

- `areArrays(array)`

Параметри:

- `array`: Влезот што треба да се провери.

### Локален импорт на функција

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value е 2D низа со низи како елементи
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.areArrays(array)`
