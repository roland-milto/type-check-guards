# isIndexFound

## Опис

`isIndexFound` утврдува дали дадена вредност е ненегативен цел број, што укажува дека е пронајден индекс.

### Случај на употреба

Потврдете дека резултатот од пребарување претставува употреблив индекс (цел број `>= 0`) пред индексирање во низа или
стринг, спречувајќи случајна употреба на `-1` или ненумерички вредности.

> **Белешка за корисници на TypeScript:**
>
> Користете `isIndexFound` по операции како `indexOf`, `findIndex` или сопствени пребарувања каде што `-1` (или други
> невалидни вредности) може да означува „не е пронајдено“. Кога враќа `true`, вредноста е број и безбедна за користење
> како индекс за низа/стринг.

### Предности

- Обезбедува едноставен type guard за да открие дали е пронајден индекс со проверка за ненегативен цел број.
- Враќа `true` само за валидни вредности слични на индекс (цели броеви `>= 0`), отфрлајќи негативни, нецелобројни и
  небројчени вредности.
- Помага да се избегнат грешки од типот off-by-one и грешки со sentinel-вредности при работа со API-и што враќаат `-1`
  за „не е пронајдено“.

## Употреба

### Синтакса

Функција:

- `isIndexFound(value)`

Параметри:

- `value`: Вредноста што треба да се провери дали е ненегативен цел број.

### Локален импорт на функција

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // idx е број тука и е >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// Типична употреба со indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isIndexFound(value)`
