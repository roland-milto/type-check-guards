# isSet

## Опис

Утврдува дали дадена вредност е `Set`.

### Случај на употреба

Валидирајте влезови од надворешни извори (на пр., парсирање JSON, кориснички внес или API-ја од трети страни) за да се
осигурате дека вредноста е `Set` пред да извршувате `Set` операции.

> **Белешка за корисници на TypeScript:**
>
> Користете `isSet` за да ги стесните `unknown` вредностите пред да повикувате API-ја специфични за `Set`, како `.add`,
`.has` или `.size`.

### Предности

- Обезбедува едноставна проверка во време на извршување за да потврди дали вредноста е `Set`.
- Помага да се спречат грешки со типови со тоа што овозможува рано разгранување кога вредноста не е `Set`.
- Работи со каква било содржина на `Set` (празен или пополнет) и доследно враќа `true`/`false`.

## Употреба

### Синтакса

Функција:

- `isSet(value)`

Параметри:

- `value`: Вредноста што треба да се провери.

### Локален импорт на функција

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // a е Set при извршување
  console.log(a.size);
}

console.log(isSet(b)); // неточно

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isSet(value)`
