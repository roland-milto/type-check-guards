# isOneOfType

## Опис

`isOneOfType` утврдува дали дадената `value` се совпаѓа со барем еден од обезбедените стрингови за тип, враќајќи `true`
ако се најде било какво совпаѓање и `false` во спротивно.

### Случај на употреба

Валидирајте лабаво-типизирани или надворешни податоци (на пр., парсиран JSON, параметри од query) со дозволување повеќе
прифатливи типови во извршување (како `number` или `string`) пред да продолжите со понатамошна логика.

> **Белешка за корисници на TypeScript:**
>
> Користете `isOneOfType` кога сакате проверка во извршување дека вредноста се совпаѓа со било кој од неколкуте
> дозволени типови; враќа `true` ако се совпаѓа барем еден тип, инаку `false`.

### Предности

- Проверува вредност според повеќе дозволени типови во еден повик, враќајќи `true` при првото совпаѓање.
- Работи со влезови од тип `unknown`, што го прави корисно на граници во извршување (на пр., надворешни податоци,
  кориснички внес).
- Обезбедува едноставен булов резултат (`true`/`false`) што добро се комбинира со условна логика и рани враќања.

## Употреба

### Синтакса

Функција:

- `isOneOfType(value, types)`

Параметри:

- `value`: Вредноста што треба да се провери според наведените типови.
- `types`: Низа од стрингови за тип што ги претставуваат потенцијалните типови на вредноста.

### Локален импорт на функција

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // input е објект во време на извршување
}

console.log(isOneOfType(3, ["number", "string"])); // точно
console.log(isOneOfType("hello", ["number", "boolean"])); // неточно

```

### Глобален импорт на објект

За импорт на функциите како глобални методи на објект користете:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следниот метод потоа ќе биде достапен глобално:

- `Type.isOneOfType(value, types)`
