# isBinary

## تفصیل

`isBinary` یہ طے کرتا ہے کہ آیا کوئی قدر بائنری سٹرنگ ہے (اختیاری طور پر `0b`/`0B` کے سابقے کے ساتھ) اور `true` یا
`false` واپس کرتا ہے۔

### استعمال کا معاملہ

صارف کی فراہم کردہ سٹرنگز (مثلاً فارم فیلڈز، CLI args، config values) کی توثیق کریں تاکہ یہ یقینی ہو سکے کہ وہ صرف
بائنری ہندسوں کی نمائندگی کرتی ہیں، اختیاری طور پر `0b`/`0B` سابقے کے ساتھ، مزید پروسیسنگ سے پہلے۔

> **TypeScript صارفین کے لیے نوٹ:**
>
> `isBinary` کو سٹرنگ کو `BigInt`/`Number` میں پارس یا کنورٹ کرنے سے پہلے بطور ٹائپ گارڈ استعمال کریں تاکہ غلط اِن پٹ سے
> بچا جا سکے۔

### فوائد

- `0b`/`0B` سابقے کے ساتھ یا اس کے بغیر بائنری سٹرنگز قبول کرتا ہے۔
- خالی سٹرنگز اور وہ سٹرنگز مسترد کرتا ہے جن کے شروع/آخر میں وائٹ اسپیس ہو (ASCII ≤ 32)۔
- بغیر کوئی استثنا پھینکے `true`/`false` واپس کرتا ہے، جس سے یہ نامعلوم اِن پٹس کے لیے محفوظ رہتا ہے۔

## استعمال

### نحو

فنکشن:

- `isBinary(value)`

پیرامیٹرز:

- `value`: وہ قدر جس کی جانچ کی جائے۔

### لوکل فنکشن امپورٹ

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); //‎ درست
const b = isBinary("1010");   //‎ درست
const c = isBinary("0b1020"); //‎ غلط
const d = isBinary(0b1010);     //‎ غلط

```

### گلوبل آبجیکٹ امپورٹ

فنکشنز کو گلوبل آبجیکٹ میتھڈز کے طور پر امپورٹ کرنے کے لیے استعمال کریں:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پھر درج ذیل میتھڈ گلوبلی دستیاب ہوگا:

- `Type.isBinary(value)`
