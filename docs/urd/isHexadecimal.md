# isHexadecimal

## تفصیل

`isHexadecimal` یہ چیک کرتا ہے کہ آیا دی گئی قدر لازمی `0x`/`0X` پری فکس کے ساتھ ہیکساڈیسیمل سٹرنگ لِٹرل ہے یا نہیں۔

### استعمال کا معاملہ

کنفیگریشن ویلیوز، API پے لوڈ فیلڈز، یا CLI آرگیومنٹس کی توثیق کے لیے `isHexadecimal` استعمال کریں جنہیں ہیکساڈیسیمل
سٹرنگ لِٹرلز (مثلاً IDs، masks، یا addresses) کے طور پر فراہم کرنا لازمی ہو اور جن میں اردگرد کی خالی جگہ شامل نہ ہو۔

> **TypeScript صارفین کے لیے نوٹ:**
>
> جب آپ کو پارس یا کنورٹ کرنے سے پہلے صارف کے اِن پٹ یا سیریلائزڈ ڈیٹا کو سخت ہیکساڈیسیمل لِٹرل سٹرنگ (بشمول `0x`/`0X`
> پری فکس) کے طور پر ویلیڈیٹ کرنے کی ضرورت ہو تو `isHexadecimal` استعمال کریں۔

### فوائد

- یہ تصدیق کرتا ہے کہ کوئی قدر ایک سٹرنگ ہے اور سخت ہیکساڈیسیمل لِٹرل فارمیٹ سے مطابقت رکھتی ہے (جس کے لیے `0x`/`0X` پری
  فکس لازمی ہے)۔
- ابتدائی یا آخری خالی جگہ (whitespace) والی سٹرنگز کو مسترد کرتا ہے، جس سے پیڈڈ اِن پٹ کے غلطی سے قبول ہونے سے بچاؤ
  ہوتا ہے۔
- اختیاری سائن کی حمایت کرتا ہے اور پری فکس اور ہندسوں کے لیے کیس اِن سینسِٹو ہے، اور قابلِ پیش گوئی طور پر `true`/
  `false` واپس کرتا ہے۔

## استعمال

### نحو

فنکشن:

- `isHexadecimal(value)`

پیرامیٹرز:

- `value`: جس قدر کی جانچ کی جائے گی۔

### لوکل فنکشن امپورٹ

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); //‎ درست
isHexadecimal("-0Xff"); //‎ درست
isHexadecimal("1A2B"); //‎ غلط (پیشوند موجود نہیں)
isHexadecimal(" 0x1A2B"); //‎ غلط (ابتدائی خالی جگہ)
isHexadecimal(0x1a2b); //‎ غلط (سٹرنگ نہیں)
```

### گلوبل آبجیکٹ امپورٹ

فنکشنز کو گلوبل آبجیکٹ میتھڈز کے طور پر امپورٹ کرنے کے لیے استعمال کریں:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پھر درج ذیل میتھڈ گلوبلی دستیاب ہوگا:

- `Type.isHexadecimal(value)`
