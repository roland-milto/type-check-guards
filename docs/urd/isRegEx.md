# isRegEx

## تفصیل

یہ تعین کرتا ہے کہ فراہم کردہ قدر `RegExp` کی ایک انسٹینس ہے یا نہیں۔

### استعمال کا معاملہ

صارف کی فراہم کردہ یا ڈائنامک قدروں (مثلاً کنفیگریشن، API پے لوڈز، پلگ اِن اِن پٹس) کی توثیق کریں، اس سے پہلے کہ انہیں
ریگولر ایکسپریشن کے طور پر استعمال کیا جائے۔

> **TypeScript صارفین کے لیے نوٹ:**
>
> `isRegEx` کو `unknown` (یا یونین) قدروں کو محدود کرنے کے لیے استعمال کریں، اس سے پہلے کہ آپ RegExp سے مخصوص پراپرٹیز
> یا میتھڈز استعمال کریں؛ یہ صرف اُن قدروں کے لیے `true` واپس کرتا ہے جو `RegExp` کی انسٹینس ہوں۔

### فوائد

- یہ جانچنے کے لیے ایک سادہ رن ٹائم ٹائپ گارڈ فراہم کرتا ہے کہ آیا کوئی قدر `RegExp` ہے۔
- جب کوڈ کو ریگولر ایکسپریشن درکار ہو تو غلطیوں سے بچانے میں مدد کرتا ہے (مثلاً `test`، `exec` کال کرنے یا `source`
  پڑھنے سے پہلے)۔
- `new RegExp(...)` کے ذریعے بنائے گئے ریجیکس لِٹرلز اور انسٹینسز دونوں کے ساتھ کام کرتا ہے۔
- غیر ریجیکس اِن پٹس کے لیے ایرر پھینکے بغیر ایک واضح بولین نتیجہ (`true`/`false`) واپس کرتا ہے۔

## استعمال

### نحو

فنکشن:

- `isRegEx(value)`

پیرامیٹرز:

- `value`: جس قدر کی جانچ کی جانی ہے۔

### لوکل فنکشن امپورٹ

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  //‎‎ input یہاں ایک RegExp ہے
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### گلوبل آبجیکٹ امپورٹ

فنکشنز کو گلوبل آبجیکٹ میتھڈز کے طور پر امپورٹ کرنے کے لیے استعمال کریں:

```ts
import "@type-check/guards/register-global-object.mjs";
```

پھر درج ذیل میتھڈ گلوبلی دستیاب ہوگا:

- `Type.isRegEx(value)`
