# isInteger

## توضیحات

مشخص می‌کند آیا `value` داده‌شده یک عدد صحیحِ امن است یا نه.

### مورد استفاده

پیش از استفاده از ورودی غیرقابل‌اعتماد (مثلاً پارامترهای کوئری، payloadهای JSON، متغیرهای محیطی) به‌عنوان عدد صحیح برای
اندیس‌های آرایه، صفحه‌بندی، شمارنده‌ها یا شناسه‌های پایگاه‌داده، آن را اعتبارسنجی کنید.

> **نکته برای کاربران TypeScript:**
>
> از `isInteger` برای اعتبارسنجی ورودی ناشناخته پیش از برخورد با آن به‌عنوان یک عدد صحیح استفاده کنید؛ این تابع فقط برای
> مقادیری `true` برمی‌گرداند که `typeof value === "number"` و `Number.isSafeInteger(value)` برقرار باشد.

### مزایا

- هم ایمنی نوع و هم ایمنی عددی را بررسی می‌کند: فقط زمانی `true` برمی‌گرداند که ورودی یک عدد و یک عدد صحیحِ امن باشد.
- از دام‌های رایجِ تبدیل ضمنی عددی جلوگیری می‌کند: رشته‌هایی مثل "5" به‌درستی `false` برمی‌گردانند.
- اعداد غیرصحیح و اعداد صحیحِ ناامن را رد می‌کند و آن را برای شناسه‌ها، شمارنده‌ها و اندیس‌گذاری آرایه مناسب می‌سازد.

## نحوه استفاده

### نحو

تابع:

- `isInteger(value)`

پارامترها:

- `value`: مقداری که باید از نظر صحیح بودن بررسی شود.

### وارد کردن محلی تابع

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      //‎ درست
const b = isInteger(-100);   //‎ درست
const c = isInteger("5");    //‎ نادرست
const d = isInteger(5.5);    //‎ نادرست
const e = isInteger(null);   //‎ نادرست

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isInteger(value)`
