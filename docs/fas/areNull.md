# areNull

## توضیحات

بررسی می‌کند آیا همهٔ عناصر در `array` داده‌شده `null` هستند یا نه.

### مورد استفاده

پیش از اعمال منطقی که فرض می‌کند همهٔ ورودی‌ها عمداً خالی هستند، بررسی کنید که یک ستون مجموعه‌داده، فهرست فیلدهای API،
یا آرایهٔ جایگزین فقط شامل مقادیر `null` باشد.

> **نکته برای کاربران TypeScript:**
>
> وقتی به یک بررسی سخت‌گیرانه نیاز دارید که ورودی یک آرایهٔ غیرخالی است و هر عنصر دقیقاً `null` است (نه `undefined` و نه
> مقادیر falsy)، از `areNull` استفاده کنید.

### مزایا

- فقط زمانی `true` برمی‌گرداند که هر عنصر `null` باشد، و آن را به یک نگهبان سخت‌گیرانهٔ «همه مطابقت دارند» تبدیل می‌کند.
- با برگرداندن `false`، آرایه‌نبودن و آرایه‌های خالی را رد می‌کند و از نتایج truthy تصادفی روی ورودی نامعتبر جلوگیری
  می‌کند.
- به‌عنوان بررسی پیش‌شرط قبل از پردازش داده‌هایی که باید کاملاً `null` باشند، به‌خوبی عمل می‌کند.

## نحوه استفاده

### نحو

تابع:

- `areNull(array)`

پارامترها:

- `array`: آرایهٔ ورودی برای بررسی عناصر `null`.

### وارد کردن محلی تابع

```ts
import { areNull } from "@type-check/guards";

const a = [null, null];
const b = [null, 1, null];

const allNullA = areNull(a); //‎ درست
const allNullB = areNull(b); //‎ نادرست

const notAnArray = areNull(123 as unknown as unknown[]); //‎ نادرست
const empty = areNull([]); //‎ نادرست

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areNull(array)`
