# areSets

## توضیحات

بررسی می‌کند آیا یک آرایهٔ غیرخالیِ داده‌شده فقط شامل نمونه‌های `Set` است یا نه؛ اگر باشد `true` و در غیر این صورت
`false` برمی‌گرداند.

### مورد استفاده

اعتبارسنجی کنید که یک مقدار (مثلاً از ورودی کاربر، تجزیهٔ JSON، یا APIهای خارجی) یک آرایهٔ غیرخالی از اشیای `Set` است،
پیش از آن‌که هر مجموعه را پردازش کنید.

> **نکته برای کاربران TypeScript:**
>
> از `areSets` برای اعتبارسنجی ورودی ناشناخته پیش از پیمایش و فراخوانی APIهای `Set` (مثلاً `.size`، `.has`، `.add`) روی
> هر عنصر استفاده کنید.

### مزایا

- فقط زمانی `true` برمی‌گرداند که ورودی یک آرایهٔ غیرخالی باشد و هر عنصر یک نمونهٔ `Set` باشد.
- با برگرداندن `false` وقتی آرایه هیچ عنصری ندارد، از مثبتِ کاذب برای آرایه‌های خالی جلوگیری می‌کند.
- به‌عنوان یک نگهبان زمان اجرا پیش از انجام عملیات مخصوص `Set` روی هر عنصر مفید است.

## نحوه استفاده

### نحو

تابع:

- `areSets(array)`

پارامترها:

- `array`: آرایه‌ای که باید از نظر نمونه‌های `Set` بودن بررسی شود.

### وارد کردن محلی تابع

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  //‎‎ a در زمان اجرا آرایه‌ای از نمونه‌های Set است
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); //‎ نادرست
console.log(areSets(c)); //‎ نادرست
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areSets(array)`
