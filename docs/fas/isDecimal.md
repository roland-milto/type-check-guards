# isDecimal

## توضیحات

`isDecimal` بررسی می‌کند که آیا یک مقدار، نمایشِ رشته‌ایِ عدد اعشاری است که هیچ فاصلهٔ سفیدِ ابتدا/انتها ندارد و قالب
اعشاریِ معتبری دارد یا نه.

### مورد استفاده

اعتبارسنجی فیلدهای فرم، payloadهای API، یا مقادیر پیکربندی که باید به‌صورت یک رشتهٔ اعشاری (با علامت اختیاری) و بدون هیچ
فاصلهٔ سفیدِ پیرامونی ارائه شوند، پیش از تجزیه یا ذخیره‌سازی.

> **نکته برای کاربران TypeScript:**
>
> از `isDecimal` برای اعتبارسنجی ورودی کاربر پیش از تبدیل آن استفاده کنید (مثلاً با `Number(value)`)، به‌ویژه وقتی باید
> فاصلهٔ سفید رد شود.

### مزایا

- به‌طور سخت‌گیرانه اعتبارسنجی می‌کند که ورودی یک رشته است و با الگوی «لیترالِ اعشاری» مطابقت دارد.
- فاصلهٔ سفیدِ ابتدا و انتها (از جمله نویسه‌های کنترلی) را رد می‌کند تا از تجزیهٔ مبهم جلوگیری شود.
- پیش‌بررسی‌های سریع (بررسی نوع و نویسهٔ اول/آخر) را پیش از اجرای عبارت باقاعده انجام می‌دهد.
- یک نتیجهٔ بولی ساده (`true`/`false`) برمی‌گرداند که برای گاردها و اعتبارسنجی ورودی مناسب است.

## نحوه استفاده

### نحو

تابع:

- `isDecimal(value)`

پارامترها:

- `value`: مقداری که باید از نظر قالبِ رشتهٔ اعشاری بررسی شود.

### وارد کردن محلی تابع

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    //‎‎ v در اینجا یک رشته است (در زمان اجرا اعتبارسنجی شده)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isDecimal(value)`
