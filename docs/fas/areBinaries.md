# areBinaries

## توضیحات

بررسی می‌کند آیا مقدار ارائه‌شده یک آرایهٔ غیرخالی از رشته‌های دودویی معتبر است و فقط در صورتی `true` برمی‌گرداند که
همهٔ آیتم‌ها از اعتبارسنجی عبور کنند.

### مورد استفاده

وقتی یک فهرست ناشناخته (مثلاً از JSON، فرم‌ها یا APIها) دریافت می‌کنید و لازم است پیش از تجزیه یا پردازش، مطمئن شوید که
یک آرایهٔ غیرخالی از رشته‌های دودویی است، از `areBinaries` استفاده کنید.

> **نکته برای کاربران TypeScript:**
>
> از `areBinaries` برای اعتبارسنجی ورودی ناشناخته پیش از تبدیل رشته‌های دودویی به number/BigInt استفاده کنید؛ این تابع
> تضمین می‌کند آرایه غیرخالی است و هر عنصر یک رشتهٔ دودویی معتبر است.

### مزایا

- اعتبارسنجی می‌کند که یک مقدار، آرایه‌ای غیرخالی است که در آن هر عنصر یک رشتهٔ دودویی معتبر است.
- یک نتیجهٔ بولی ساده (`true`/`false`) برمی‌گرداند که برای گاردها، بازگشت‌های زودهنگام و اعتبارسنجی ورودی مناسب است.
- با رد کردن آرایه‌هایی که شامل هر ورودیِ غیردودویی باشند، از خطاهای تجزیه در مراحل بعدی جلوگیری می‌کند.

## نحوه استفاده

### نحو

تابع:

- `areBinaries(array)`

پارامترها:

- `array`: مقداری که باید بررسی شود.

### وارد کردن محلی تابع

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); //‎ درست
console.log(areBinaries(b)); //‎ نادرست
console.log(areBinaries([])); //‎ نادرست
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areBinaries(array)`
