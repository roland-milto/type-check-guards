# areEqual

## توضیحات

`areEqual` بررسی می‌کند آیا همهٔ عناصر یک آرایه با یک مقدار مورد انتظار مشخص برابر هستند یا نه، و فقط برای آرایه‌های
غیرخالی که هر آیتم مطابقت دارد `true` برمی‌گرداند.

### مورد استفاده

اعتبارسنجی اینکه یک فهرست فقط شامل یک مقدار مجاز واحد است (مثلاً همهٔ پرچم‌های وضعیت `true` هستند، همهٔ نقش‌ها `"admin"`
هستند، یا همهٔ ورودی‌های عددی برابر یک ثابتِ الزامی‌اند) و در عین حال ورودی خالی را نامعتبر (`false`) در نظر می‌گیرد.

> **نکته برای کاربران TypeScript:**
>
> وقتی به یک بررسی سخت‌گیرانهٔ «همهٔ آیتم‌ها» نیاز دارید از `areEqual` استفاده کنید؛ برای آرایه‌های خالی و برای هر
> ورودیِ غیرآرایه یا غیرپر (non-filled) مقدار `false` برمی‌گرداند.

### مزایا

- فقط زمانی `true` برمی‌گرداند که هر عنصر با مقدار مورد انتظار مطابقت داشته باشد؛ در غیر این صورت `false` برمی‌گرداند.
- شکست سریع: به محض یافتن یک عنصر نامطابق، بررسی را متوقف می‌کند.
- با برگرداندن `false` وقتی ورودی یک آرایهٔ پر (filled) نیست، در برابر ورودی نامعتبر محافظت می‌کند.

## نحوه استفاده

### نحو

تابع:

- `areEqual(value, expected)`

پارامترها:

- `value`: آرایه‌ای که باید بررسی شود.
- `expected`: عنصری که هر آیتم آرایه با آن مقایسه می‌شود.

### وارد کردن محلی تابع

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areEqual(value, expected)`
