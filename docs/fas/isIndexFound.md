# isIndexFound

## توضیحات

`isIndexFound` تعیین می‌کند آیا مقدار داده‌شده یک عدد صحیحِ نامنفی است و نشان می‌دهد که یک اندیس پیدا شده است.

### مورد استفاده

پیش از اندیس‌گذاری در یک آرایه یا رشته، اعتبارسنجی کنید که نتیجهٔ جست‌وجو یک اندیس قابل استفاده (عدد صحیحِ `>= 0`) را
نشان می‌دهد تا از استفادهٔ تصادفی از `-1` یا مقادیر غیرعددی جلوگیری شود.

> **نکته برای کاربران TypeScript:**
>
> `isIndexFound` را پس از عملیات‌هایی مانند `indexOf`، `findIndex` یا جست‌وجوهای سفارشی که در آن‌ها `-1` (یا سایر مقادیر
> نامعتبر) می‌تواند نشان‌دهنده «پیدا نشد» باشد، استفاده کنید. وقتی `true` برمی‌گرداند، مقدار یک عدد است و استفاده از آن
> به‌عنوان اندیس آرایه/رشته امن است.

### مزایا

- یک نگهبان نوع (type guard) ساده فراهم می‌کند تا با بررسی یک عدد صحیحِ نامنفی تشخیص دهد آیا یک اندیس پیدا شده است یا
  نه.
- `true` را فقط برای مقادیر معتبرِ شبیه اندیس (اعداد صحیحِ `>= 0`) برمی‌گرداند و مقادیر منفی، غیرصحیح و غیرعددی را رد
  می‌کند.
- هنگام کار با APIهایی که برای «پیدا نشد» مقدار `-1` را برمی‌گردانند، به جلوگیری از خطاهای off-by-one و اشتباهات مربوط
  به مقدار نگهبان (sentinel value) کمک می‌کند.

## نحوه استفاده

### نحو

تابع:

- `isIndexFound(value)`

پارامترها:

- `value`: مقداری که باید بررسی شود آیا یک عدد صحیحِ نامنفی است یا نه.

### وارد کردن محلی تابع

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  //‎‎ idx در اینجا یک عدد است و >= 0 است
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

//‎‎ کاربرد معمول با indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isIndexFound(value)`
