# areArrays

## توضیحات

`areArrays` تعیین می‌کند آیا یک مقدار، یک آرایهٔ دوبعدیِ پر است که همهٔ آیتم‌های آن آرایه هستند یا نه.

### مورد استفاده

از `areArrays` برای اعتبارسنجی ورودی‌های جدولی یا شبیه ماتریس (مثلاً سطرهای CSV، داده‌های شبکه‌ای، یا فهرست‌های
گروه‌بندی‌شده) پیش از انجام عملیات سطر/ستون استفاده کنید؛ اگر ورودی آرایه نباشد، خالی باشد، یا شامل هر عنصرِ غیرآرایه‌ای
باشد، `false` برمی‌گرداند.

> **نکته برای کاربران TypeScript:**
>
> وقتی لازم دارید مطمئن شوید یک مقدار یک آرایهٔ دوبعدیِ غیرخالی است و پیش از پیمایش یا اندیس‌گذاری در آرایه‌های
> تو‌در‌تو، هر سطر یک آرایه است، از `areArrays` استفاده کنید.

### مزایا

- اعتبارسنجی می‌کند که ورودی یک آرایهٔ دوبعدیِ غیرخالی است که در آن هر عنصر یک آرایه است.
- یک نتیجهٔ بولی ساده (`true`/`false`) برمی‌گرداند که برای گاردها و خروج زودهنگام مناسب است.
- کمک می‌کند از خطاهای زمان اجرا جلوگیری شود وقتی کدهای بعدی عملیات روی آرایه‌های تو‌در‌تو را فرض می‌کنند (مثلاً map
  کردن سطرها).

## نحوه استفاده

### نحو

تابع:

- `areArrays(array)`

پارامترها:

- `array`: ورودی‌ای که باید بررسی شود.

### وارد کردن محلی تابع

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  //‎‎ value یک آرایهٔ دوبعدی است که عناصر آن آرایه‌ها هستند
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areArrays(array)`
