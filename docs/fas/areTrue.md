# areTrue

## توضیحات

بررسی می‌کند آیا یک آرایهٔ غیرخالی فقط شامل مقادیر بولیِ `true` است یا خیر.

### مورد استفاده

از `areTrue` استفاده کنید تا اعتبارسنجی کنید که مجموعه‌ای از پیش‌شرط‌ها یا پرچم‌های ویژگی همگی فعال هستند (همهٔ مقادیر
`true` هستند) پیش از ادامه دادن، در حالی که ورودی‌های خالی یا بدشکل را به‌عنوان برآورده‌نشده (`false`) در نظر می‌گیرد.

> **نکته برای کاربران TypeScript:**
>
> `areTrue` برای آرایهٔ خالی و برای آرایه‌هایی که شامل هر مقداری هستند که به‌طور دقیق `true` نیست، `false` برمی‌گرداند.

### مزایا

- تنها زمانی `true` برمی‌گرداند که هر عنصر به‌طور دقیق `true` باشد و آرایه خالی نباشد.
- سریع متوقف می‌شود: به‌محض یافتن یک مقدار غیرِ `true`، `false` برمی‌گرداند.
- ورودی‌های نامعتبر (غیرآرایه‌ها یا آرایه‌های خالی) را با برگرداندن `false` رد می‌کند.

## نحوه استفاده

### نحو

تابع:

- `areTrue(array)`

پارامترها:

- `array`: آرایه‌ای که باید بررسی شود آیا همهٔ مقادیر آن `true` هستند یا نه.

### وارد کردن محلی تابع

```ts
import { areTrue } from "@type-check/guards";

const a = areTrue([true, true, true]);
const b = areTrue([true, false, true]);
const c = areTrue([]);
const d = areTrue([true, "string" as unknown, true]);

console.log(a, b, c, d);
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areTrue(array)`
