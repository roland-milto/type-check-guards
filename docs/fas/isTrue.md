# isTrue

## توضیحات

`isTrue` تعیین می‌کند آیا یک مقدار داده‌شده به‌صورت سخت‌گیرانه با `true` برابر است یا نه.

### مورد استفاده

از `isTrue` برای اعتبارسنجی فلگ‌ها، سوییچ‌های ویژگی (feature toggles) یا مقادیر پیکربندی استفاده کنید؛ جایی که فقط مقدار
ثابت `true` باید پذیرفته شود و هر چیز دیگری باید به‌عنوان `false` در نظر گرفته شود.

> **نکته برای کاربران TypeScript:**
>
> وقتی لازم دارید فقط مقدار بولیِ ثابت `true` را بپذیرید (نه صرفاً مقادیر truthy)، از `isTrue` استفاده کنید.

### مزایا

- یک بررسی سخت‌گیرانه برای مقدار بولیِ ثابت `true` فراهم می‌کند (بدون تبدیل نوع).
- کمک می‌کند `true` را از مقادیر truthy مانند `1`، `"true"` یا `{}` متمایز کنید.
- رفتاری ساده و قابل‌پیش‌بینی دارد که برای گاردها و خط لوله‌های اعتبارسنجی مناسب است.

## نحوه استفاده

### نحو

تابع:

- `isTrue(value)`

پارامترها:

- `value`: مقداری که باید بررسی شود.

### وارد کردن محلی تابع

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      //‎ درست
const b = isTrue(1);         //‎ نادرست
const c = isTrue("true");   //‎ نادرست

if (isTrue(a)) {
  //‎‎ a اینجا درست است
}
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isTrue(value)`
