# isBinary

## توضیحات

`isBinary` تعیین می‌کند آیا یک مقدار، رشتهٔ دودویی (با پیشوند اختیاری `0b`/`0B`) است یا نه و `true` یا `false`
برمی‌گرداند.

### مورد استفاده

اعتبارسنجی رشته‌های ارائه‌شده توسط کاربر (مثلاً فیلدهای فرم، آرگومان‌های CLI، مقادیر پیکربندی) برای اطمینان از اینکه فقط
رقم‌های دودویی را (با پیشوند اختیاری `0b`/`0B`) نمایش می‌دهند، پیش از پردازش بیشتر.

> **نکته برای کاربران TypeScript:**
>
> برای جلوگیری از ورودی نامعتبر، پیش از تجزیه یا تبدیل یک رشته به `BigInt`/`Number` از `isBinary` به‌عنوان نگهبان نوع (
> type guard) استفاده کنید.

### مزایا

- رشته‌های دودویی را با یا بدون پیشوند `0b`/`0B` می‌پذیرد.
- رشته‌های خالی و رشته‌هایی با فاصلهٔ سفیدِ ابتدایی/انتهایی (ASCII ≤ 32) را رد می‌کند.
- بدون پرتاب خطا `true`/`false` برمی‌گرداند و بنابراین برای ورودی‌های ناشناخته امن است.

## نحوه استفاده

### نحو

تابع:

- `isBinary(value)`

پارامترها:

- `value`: مقداری که باید بررسی شود.

### وارد کردن محلی تابع

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); //‎ درست
const b = isBinary("1010");   //‎ درست
const c = isBinary("0b1020"); //‎ نادرست
const d = isBinary(0b1010);     //‎ نادرست

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isBinary(value)`
