# areMaps

## Опис

`areMaps` утврђује да ли је дати низ непразан и да ли су сви његови елементи инстанце `Map`.

### Случај употребе

Проверите непознат улаз (нпр. из парсирања JSON-а, спољних API-ја или динамичких извора) пре него што га третирате као
непразну листу објеката `Map`.

> **Напомена за TypeScript кориснике:**
>
> Враћа `false` за празан низ; `true` враћа само када је низ попуњен и када је сваки елемент `Map`.

### Предности

- Обезбеђује да је сваки елемент инстанца `Map`, враћајући `true` само када целокупан низ прође проверу.
- Намерно одбацује празне низове, спречавајући случајно прихватање „без података“ као важећег улаза.
- Корисно као заштитна провера пре извршавања операција специфичних за `Map` (нпр. `.get()`, `.set()`, итерација) над
  колекцијом.

## Употреба

### Синтакса

Функција:

- `areMaps(array)`

Параметри:

- `array`: Низ који треба проверити.

### Локални увоз функције

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // items је гарантовано непразан низ инстанци Map у време извршавања
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // false за: празне низове, или низове који садрже било коју вредност која није Map
}

```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.areMaps(array)`
