# isIndexFound

## Опис

`isIndexFound` утврђује да ли је дата вредност ненегативан цео број, што указује да је индекс пронађен.

### Случај употребе

Проверите да ли резултат претраге представља употребљив индекс (цео број `>= 0`) пре индексирања у низ или стринг,
спречавајући случајну употребу `-1` или ненумеричких вредности.

> **Напомена за TypeScript кориснике:**
>
> Користите `isIndexFound` након операција као што су `indexOf`, `findIndex` или прилагођених претрага где `-1` (или
> друге неважеће вредности) могу да означе „није пронађено“. Када врати `true`, вредност је број и безбедна је за
> употребу
> као индекс низа/стринга.

### Предности

- Пружа једноставан чувар типа за откривање да ли је индекс пронађен проверавајући да ли је у питању ненегативан цео
  број.
- Враћа `true` само за важеће вредности налик индексу (цели бројеви `>= 0`), одбацујући негативне, нецелобројне и
  ненумеричке вредности.
- Помаже да се избегну грешке типа „за један“ и грешке са сентинел-вредностима при раду са API-јима који враћају `-1` за
  „није пронађено“.

## Употреба

### Синтакса

Функција:

- `isIndexFound(value)`

Параметри:

- `value`: Вредност коју треба проверити да ли је ненегативан цео број.

### Локални увоз функције

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // idx je ovde broj i >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// Tipična upotreba sa indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.isIndexFound(value)`
