# areNumbers

## Опис

`areNumbers` проверава да ли је вредност непразан низ у ком су сви елементи бројеви.

### Случај употребе

Валидирајте податке које је доставио корисник или API да бисте осигурали да су непразан низ бројева пре израчунавања
укупних вредности, просека или других нумеричких агрегација.

> **Напомена за TypeScript кориснике:**
>
> Користите `areNumbers` да валидирате непознате низове пре извођења нумеричких прорачуна; враћа `false` за празне
> низове и за низове који садрже било коју вредност која није број.

### Предности

- Враћа `true` само када је улаз непразан низ и сваки елемент је број.
- Спречава лажно позитивне резултате тако што одбацује празне низове и улазе који нису низови.
- Корисно као заштитна провера пре нумеричких операција (нпр. сабирање, израчунавање просека) како би се избегле грешке
  током извршавања.

## Употреба

### Синтакса

Функција:

- `areNumbers(array)`

Параметри:

- `array`: Низ који треба проверити да ли садржи бројевне елементе.

### Локални увоз функције

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.areNumbers(array)`
