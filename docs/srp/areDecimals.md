# areDecimals

## Опис

Проверава да ли су сви елементи у низу децимални бројеви и да ли је низ попуњен, враћајући `true` или `false`.

### Случај употребе

Валидирајте листе које обезбеђују корисници (нпр. CSV колоне или уносе у формама) како бисте осигурали да низ није
празан и да је сваки унос децимална вредност пре парсирања или прорачуна.

> **Напомена за TypeScript кориснике:**
>
> Користите `areDecimals` када вам је потребна брза булова провера да је `unknown[]` непразан и да је сваки елемент
> децимална репрезентација.

### Предности

- Обезбеђује да је улаз попуњен низ пре валидације ставки, спречавајући случајно прихватање празних листа.
- Валидира сваки елемент помоћу `isDecimal`, тако да мешовите или неважеће вредности одмах дају резултат `false`.
- Пружа једноставан булов исход (`true`/`false`) погодан за гардове и токове валидације са раним повратком.

## Употреба

### Синтакса

Функција:

- `areDecimals(array)`

Параметри:

- `array`: Низ који треба проверити.

### Локални увоз функције

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // tačno
console.log(areDecimals(b)); // netačno
console.log(areDecimals(c)); // netačno
```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.areDecimals(array)`
