# areOctals

## Опис

`areOctals` утврђује да ли је дата вредност непразан низ важећих окталних стрингова.

### Случај употребе

Користите `areOctals` при валидацији корисничког уноса, конфигурационих вредности или API payload-а који морају да
садрже окталне литерале (нпр. модове дозвола за фајлове као `0o755`) и када желите да одбаците празне низове или било
које неважеће уносе враћањем `false`.

> **Напомена за TypeScript кориснике:**
>
> Користите `areOctals` да бисте осигурали да имате непразан `unknown[]` у ком је сваки унос важећи октални стринг пре
> конвертовања (нпр. преко `Number(...)` или прилагођеног парсирања).

### Предности

- Проверава да ли је вредност непразан низ у ком је сваки елемент октални стринг, враћајући `true` само када све ставке
  прођу проверу.
- Брзо отказује: враћа `false` чим се пронађе неоктални елемент.
- Корисно као заштитна провера пре парсирања или конвертовања окталних стрингова како би се избегле грешке у извршавању
  и недоследно руковање улазом.

## Употреба

### Синтакса

Функција:

- `areOctals(array)`

Параметри:

- `array`: Вредност коју треба проверити.

### Локални увоз функције

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value je neprazan niz oktalnih stringova
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.areOctals(array)`
