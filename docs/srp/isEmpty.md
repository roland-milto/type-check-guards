# isEmpty

## Опис

Одређује да ли је дата вредност празна, враћајући `true` за `null`, `undefined`, празне/стрингове са размацима, празне
низове, празан `Map`/`Set`, или објекте без сопствених набројивих својстава.

### Случај употребе

Користите `isEmpty` за валидацију улаза и откривање недостајућих/празних вредности кроз више типова података (нпр. поља
формулара, API payload-ови, конфигурациони објекти) где `null`, `undefined`, стрингови са размацима, празне колекције и
објекти без својстава треба да се третирају као празни.

> **Напомена за TypeScript кориснике:**
>
> `isEmpty` је помоћна функција која враћа булову вредност (није TypeScript предикат типа), па сама по себи не сузава
> типове; користите је за валидацију/гранање, а не за сузавање у време компајлирања.

### Предности

- Третира `null` и `undefined` као `true` при проверама празнине.
- Сматра стрингове који садрже само размаке празним тако што их скраћује (trim) пре провере дужине.
- Подржава уобичајене типове контејнера (низове, `Map`, `Set`) и обичне објекте без сопствених набројивих својстава.
- Избегава бројање наслеђених својстава коришћењем `hasOwnProperty` провера.
- Враћа једноставан булов резултат (`true`/`false`) погодан за гардове и валидацију.

## Употреба

### Синтакса

Функција:

- `isEmpty(value)`

Параметри:

- `value`: Вредност коју треба проверити на празнину.

### Локални увоз функције

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.isEmpty(value)`
