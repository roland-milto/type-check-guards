# isRegEx

## Опис

Одређује да ли је дата вредност инстанца `RegExp`.

### Случај употребе

Валидирајте вредности које је обезбедио корисник или динамичке вредности (нпр. конфигурација, API payload-ови, улази
додатака) пре него што их третирате као регуларни израз.

> **Напомена за TypeScript кориснике:**
>
> Користите `isRegEx` да сузите вредности типа `unknown` (или уније) пре коришћења својстава или метода специфичних за
> RegExp; враћа `true` само за вредности које су инстанце `RegExp`.

### Предности

- Пружа једноставан чувар типа у извршавању (runtime) за проверу да ли је вредност `RegExp`.
- Помаже у спречавању грешака када код очекује регуларни израз (нпр. пре позивања `test`, `exec` или читања `source`).
- Ради и са литералима регуларних израза и са инстанцама креираним преко `new RegExp(...)`.
- Враћа јасан булов резултат (`true`/`false`) без бацања изузетка за улазе који нису регуларни израз.

## Употреба

### Синтакса

Функција:

- `isRegEx(value)`

Параметри:

- `value`: Вредност коју треба проверити.

### Локални увоз функције

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  // input je ovde RegExp
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.isRegEx(value)`
