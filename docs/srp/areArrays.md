# areArrays

## Опис

`areArrays` одређује да ли је вредност попуњен дводимензионални низ чије су ставке све низови.

### Случај употребе

Користите `areArrays` за валидацију табеларних или матричних улаза (нпр. CSV редови, подаци мреже или груписане листе)
пре извођења операција над редовима/колонама; враћа `false` ако улаз није низ, ако је празан или ако садржи било који
елемент који није низ.

> **Напомена за TypeScript кориснике:**
>
> Користите `areArrays` када треба да обезбедите да је вредност непразан 2D низ и да је сваки ред низ пре итерације или
> индексирања у угнежђене низове.

### Предности

- Проверава да је улаз непразан дводимензионални низ у ком је сваки елемент низ.
- Враћа једноставан булов резултат (`true`/`false`) погодан за гардове и ране излазе.
- Помаже у спречавању грешака у извршавању када каснији код подразумева операције над угнежђеним низовима (нпр. мапирање
  редова).

## Употреба

### Синтакса

Функција:

- `areArrays(array)`

Параметри:

- `array`: Улаз који треба проверити.

### Локални увоз функције

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value je 2D niz sa nizovima kao elementima
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.areArrays(array)`
