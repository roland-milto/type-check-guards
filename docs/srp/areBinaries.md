# areBinaries

## Опис

Проверава да ли је дата вредност непразан низ важећих бинарних стрингова и враћа `true` само ако све ставке прођу
валидацију.

### Случај употребе

Користите `areBinaries` када добијете непознату листу (нпр. из JSON-а, форми или API-ја) и треба да обезбедите да је то
непразан низ бинарних стрингова пре парсирања или обраде.

> **Напомена за TypeScript кориснике:**
>
> Користите `areBinaries` да валидирате непознат унос пре претварања бинарних стрингова у бројеве/BigInts; обезбеђује да
> је низ непразан и да је сваки елемент важећи бинарни стринг.

### Предности

- Проверава да ли је вредност непразан низ у којем је сваки елемент важећи бинарни стринг.
- Враћа једноставан булов резултат (`true`/`false`) погодан за гардове, ране повратке и валидацију улаза.
- Спречава касније грешке при парсирању тако што одбацује низове који садрже било који небинарни унос.

## Употреба

### Синтакса

Функција:

- `areBinaries(array)`

Параметри:

- `array`: Вредност коју треба проверити.

### Локални увоз функције

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // tačno
console.log(areBinaries(b)); // netačno
console.log(areBinaries([])); // netačno
```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.areBinaries(array)`
