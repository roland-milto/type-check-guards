# isOneOfType

## Опис

`isOneOfType` одређује да ли дати `value` одговара бар једном од наведених стрингова типова, враћајући `true` ако је
пронађено било какво поклапање, а `false` у супротном.

### Случај употребе

Валидирајте лабаво типизиране или спољне податке (нпр. парсирани JSON, параметри упита) тако што ћете дозволити више
прихватљивих типова у време извршавања (као што су `number` или `string`) пре наставка са даљом логиком.

> **Напомена за TypeScript кориснике:**
>
> Користите `isOneOfType` када желите проверу у време извршавања да вредност одговара било ком од неколико дозвољених
> типова; враћа `true` ако се бар један тип поклапа, иначе `false`.

### Предности

- Проверава вредност у односу на више дозвољених типова у једном позиву, враћајући `true` на првом поклапању.
- Ради са улазима типа `unknown`, што га чини корисним на границама извршавања (нпр. спољни подаци, кориснички унос).
- Пружа једноставан булов резултат (`true`/`false`) који се добро уклапа са условном логиком и раним повратком.

## Употреба

### Синтакса

Функција:

- `isOneOfType(value, types)`

Параметри:

- `value`: Вредност која се проверава у односу на наведене типове.
- `types`: Низ стрингова типова који представљају потенцијалне типове вредности.

### Локални увоз функције

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // input je objekat u vreme izvršavanja
}

console.log(isOneOfType(3, ["number", "string"])); // tačno
console.log(isOneOfType("hello", ["number", "boolean"])); // netačno

```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.isOneOfType(value, types)`
