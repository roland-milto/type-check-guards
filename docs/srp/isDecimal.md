# isDecimal

## Опис

`isDecimal` проверава да ли је вредност децимална стринг-репрезентација без водећих/завршних размака и са важећим
децималним форматом.

### Случај употребе

Валидирајте поља формулара, API payload-ове или конфигурационе вредности које морају бити наведене као децимални
стринг (опционо са знаком) без икаквих околних размака, пре парсирања или складиштења.

> **Напомена за TypeScript кориснике:**
>
> Користите `isDecimal` да валидирате кориснички унос пре него што га конвертујете (нпр. помоћу `Number(value)`),
> посебно када размаке треба одбацити.

### Предности

- Строго проверава да је улаз стринг и да одговара обрасцу децималног литерала.
- Одбацује водеће и завршне размаке (укључујући контролне знакове) како би се избегло двосмислено парсирање.
- Брзе претпровере (провера типа и првог/последњег карактера) пре покретања regex-а.
- Враћа једноставан булов резултат (`true`/`false`) погодан за гардове и валидацију уноса.

## Употреба

### Синтакса

Функција:

- `isDecimal(value)`

Параметри:

- `value`: Вредност коју треба проверити за формат децималног стринга.

### Локални увоз функције

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v је овде стринг (проверено у време извршавања)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.isDecimal(value)`
