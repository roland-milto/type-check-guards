# isHexadecimal

## Опис

`isHexadecimal` проверава да ли је дата вредност хексадецимални стринг литерал са обавезним префиксом `0x`/`0X`.

### Случај употребе

Користите `isHexadecimal` за валидацију конфигурационих вредности, поља у API payload-у или CLI аргумената који морају
бити наведени као хексадецимални стринг литерали (нпр. ID-еви, маске или адресе) и не смеју да садрже околне празнине.

> **Напомена за TypeScript кориснике:**
>
> Користите `isHexadecimal` када треба да валидирате кориснички унос или серијализоване податке као строг хексадецимални
> литерални стринг (укључујући префикс `0x`/`0X`) пре парсирања или конверзије.

### Предности

- Проверава да ли је вредност стринг и да ли одговара строгом формату хексадецималног литерала (захтева префикс `0x`/
  `0X`).
- Одбацује стрингове са водећим или завршним празнинама, што помаже да се избегне случајно прихватање уноса са додатим
  размацима.
- Подржава опциони знак и не разликује велика и мала слова за префикс и цифре, враћајући `true`/`false` предвидљиво.

## Употреба

### Синтакса

Функција:

- `isHexadecimal(value)`

Параметри:

- `value`: Вредност која се проверава.

### Локални увоз функције

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // tačno
isHexadecimal("-0Xff"); // tačno
isHexadecimal("1A2B"); // netačno (nedostaje prefiks)
isHexadecimal(" 0x1A2B"); // netačno (vodeći razmak)
isHexadecimal(0x1a2b); // netačno (nije string)
```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.isHexadecimal(value)`
