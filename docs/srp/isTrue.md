# isTrue

## Опис

`isTrue` утврђује да ли је дата вредност строго једнака `true`.

### Случај употребе

Користите `isTrue` за валидацију флагова, прекидача функционалности или конфигурационих вредности где треба прихватити
само литерал `true`, а све остало мора бити третирано као `false`.

> **Напомена за TypeScript кориснике:**
>
> Користите `isTrue` када треба да прихватите само буловски литерал `true`, а не само „truthy“ вредности.

### Предности

- Пружа строгу проверу за буловски литерал `true` (без коерције).
- Помаже да се разликује `true` од „truthy“ вредности као што су `1`, `"true"` или `{}`.
- Једноставно, предвидљиво понашање погодно за гардове и валидационе токове.

## Употреба

### Синтакса

Функција:

- `isTrue(value)`

Параметри:

- `value`: Вредност коју треба проверити.

### Локални увоз функције

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // tačno
const b = isTrue(1);         // netačno
const c = isTrue("true");   // netačno

if (isTrue(a)) {
  // a je ovde tačno
}
```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.isTrue(value)`
