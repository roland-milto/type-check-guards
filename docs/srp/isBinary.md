# isBinary

## Опис

`isBinary` одређује да ли је вредност бинарна ниска (опционо са префиксом `0b`/`0B`) и враћа `true` или `false`.

### Случај употребе

Валидирајте ниске које корисник доставља (нпр. поља формулара, CLI аргументе, вредности конфигурације) да бисте
осигурали да представљају искључиво бинарне цифре, опционално са префиксом `0b`/`0B`, пре даље обраде.

> **Напомена за TypeScript кориснике:**
>
> Користите `isBinary` као чувар типа пре парсирања или конвертовања ниске у `BigInt`/`Number` како бисте избегли
> неважећи улаз.

### Предности

- Прихвата бинарне ниске са или без префикса `0b`/`0B`.
- Одбацује празне ниске и ниске са водећим/завршним белинама (ASCII ≤ 32).
- Враћа `true`/`false` без бацања изузетка, што га чини безбедним за непознате улазе.

## Употреба

### Синтакса

Функција:

- `isBinary(value)`

Параметри:

- `value`: Вредност која се проверава.

### Локални увоз функције

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // tačno
const b = isBinary("1010");   // tačno
const c = isBinary("0b1020"); // netačno
const d = isBinary(0b1010);     // netačno

```

### Глобални увоз објекта

За увоз функција као глобалних метода објекта користите:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Следећи метод ће затим бити доступан глобално:

- `Type.isBinary(value)`
