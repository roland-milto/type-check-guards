## Funktsioonid

| Funktsioon                                  | Kirjeldus                                                                                                                                                                                                                                 |
|---------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [areArrays](areArrays.md)                   | `areArrays` määrab, kas väärtus on täidetud kahemõõtmeline massiiv, mille kõik elemendid on massiivid.                                                                                                                                    |

| [areBinaries](areBinaries.md)               | Kontrollib, kas antud väärtus on mittetühi kehtivate binaarsete stringide massiiv, ja tagastab `true` ainult siis, kui kõik elemendid läbivad valideerimise.                                                                              |
| [areBooleans](areBooleans.md)               | `areBooleans` kontrollib, kas antud mittetühi massiiv sisaldab ainult tõeväärtusi, tagastades `true`, kui sisaldab, ja `false` muul juhul.                                                                                                |
| [areBuffers](areBuffers.md)                 | `areBuffers` kontrollib, kas antud väärtus on mitte-tühi, täidetud massiiv, mille iga element on `Buffer`, tagastades sel juhul `true` ja muul juhul `false`.                                                                             |
| [areDates](areDates.md)                     | `areDates` määrab, kas antud massiiv on täidetud ja sisaldab ainult `Date` objekte, tagastades `true` ainult siis, kui kõik elemendid on kehtivad kuupäevad.                                                                              |
| [areDecimals](areDecimals.md)               | Kontrollib, kas kõik massiivi elemendid on kümnendarvud ja massiiv on täidetud, tagastades `true` või `false`.                                                                                                                            |
| [areEqual](areEqual.md)                     | `areEqual` kontrollib, kas kõik massiivi elemendid on võrdsed etteantud oodatud väärtusega, tagastades `true` ainult mitte-tühjade massiivide korral, kus iga üksus vastab.                                                               |
| [areErrors](areErrors.md)                   | Kontrollib, kas massiiv on mittetühi ja sisaldab ainult `Error`-objekte, tagastades `true` või `false`.                                                                                                                                   |
| [areFalse](areFalse.md)                     | `areFalse` kontrollib, kas kõik etteantud massiivi elemendid on rangelt boole'i väärtus `false`.                                                                                                                                          |
| [areFilledArrays](areFilledArrays.md)       | `areFilledArrays` kontrollib, kas kahemõõtmeline massiiv ei ole tühi ja kõik selle alam-massiivid on mittetühjad.                                                                                                                         |
| [areFinite](areFinite.md)                   | `areFinite` kontrollib, kas väärtus on mittetühi massiiv, mille elemendid on kõik lõplikud arvud, tagastades sel juhul `true` ja muul juhul `false`.                                                                                      |
| [areFloats](areFloats.md)                   | `areFloats` kontrollib, kas antud massiiv on täidetud ja kõik selle elemendid on ujukomaarvud.                                                                                                                                            |
| [areHexadecimals](areHexadecimals.md)       | Kontrollib, kas kõik massiivi elemendid on kuueteistkümnendsüsteemi stringid, tagastades `true` ainult mittetühjade massiivide korral, kus iga element on kehtiv.                                                                         |
| [areIndexesFound](areIndexesFound.md)       | `areIndexesFound` kontrollib, kas väärtus on mittetühi massiiv, mille kõik elemendid on kehtivad indeksid, tagastades `true`, kui nii on, ja `false` muul juhul.                                                                          |
| [areIntegers](areIntegers.md)               | `areIntegers` määrab, kas kõik antud massiivi elemendid on täisarvud, tagastades `true`, kui nad on, ja `false` muul juhul.                                                                                                               |
| [areJson](areJson.md)                       | Kontrollib, kas massiivi kõik elemendid on JSON-stringid, tagastades `true` ainult siis, kui massiiv on täidetud ja iga kirje on kehtiv JSON; vastasel juhul tagastab `false`.                                                            |
| [areMaps](areMaps.md)                       | `areMaps` määrab, kas antud massiiv on mittetühi ja kõik selle elemendid on `Map`-i eksemplarid.                                                                                                                                          |
| [areNaNs](areNaNs.md)                       | `areNaNs` kontrollib, kas kõik massiivi elemendid on `NaN`, ja tagastab `true` ainult siis, kui iga element on `NaN`.                                                                                                                     |
| [areNullOrUndefined](areNullOrUndefined.md) | Kontrollib, kas kõik antud massiivi elemendid on `null` või `undefined`.                                                                                                                                                                  |
| [areNumbers](areNumbers.md)                 | `areNumbers` kontrollib, kas väärtus on mittetühi massiiv, mille kõik elemendid on arvud.                                                                                                                                                 |
| [areNumerics](areNumerics.md)               | `areNumerics` kontrollib, kas väärtus on mittetühi massiiv, mille kõik elemendid on arvulised.                                                                                                                                            |
| [areObjects](areObjects.md)                 | `areObjects` kontrollib, kas etteantud täidetud massiiv sisaldab ainult objekte.                                                                                                                                                          |
| [areOctals](areOctals.md)                   | `areOctals` määrab, kas antud väärtus on mittetühi kehtivate kaheksandsüsteemi stringide massiiv.                                                                                                                                         |
| [areOfType](areOfType.md)                   | Kontrollib, kas kõik antud `array` elemendid on määratud `type` tüüpi.                                                                                                                                                                    |
| [areOneOfType](areOneOfType.md)             | `areOneOfType` kontrollib, kas kõik mittetühja massiivi elemendid on ühte määratud käitusaja tüüpidest.                                                                                                                                   |
| [arePlainObjects](arePlainObjects.md)       | Kontrollib, kas massiivi kõik elemendid on tavalised objektid, tagastades `true` ainult siis, kui iga element kvalifitseerub.                                                                                                             |
| [arePrimitives](arePrimitives.md)           | `arePrimitives` hindab, kas kõik antud mittetühja massiivi elemendid on primitiivsed tüübid.                                                                                                                                              |
| [arePromises](arePromises.md)               | `arePromises` määrab, kas kõik massiivi elemendid on `Promise`-i eksemplarid.                                                                                                                                                             |
| [areRegExes](areRegExes.md)                 | `areRegExes` kontrollib, kas väärtus on täidetud massiiv, mis sisaldab ainult `RegExp`-objekte.                                                                                                                                           |
| [areSets](areSets.md)                       | Kontrollib, kas antud mittetühi massiiv sisaldab ainult `Set`-i eksemplare, tagastades `true`, kui sisaldab, ja `false` muul juhul.                                                                                                       |
| [areStreams](areStreams.md)                 | `areStreams` määrab, kas väärtus on täidetud massiiv, milles iga element on `Stream`.                                                                                                                                                     |
| [areStrings](areStrings.md)                 | `areStrings` kontrollib, kas massiiv on mittetühi ja kõik selle elemendid on stringid, tagastades `true` ainult sel juhul.                                                                                                                |
| [areSymbols](areSymbols.md)                 | Kontrollib, kas sisend on täidetud massiiv, mille elemendid on kõik sümbolid, tagastades `true` või `false`.                                                                                                                              |
| [areTrue](areTrue.md)                       | Kontrollib, kas mittetühi massiiv sisaldab ainult tõeväärtusi `true`.                                                                                                                                                                     |

| [areWeakMaps](areWeakMaps.md)               | `areWeakMaps` kontrollib, kas väärtus on mittetühi massiiv, mille iga element on `WeakMap`, tagastades `true` ainult sel juhul ja muul juhul `false`.                                                                                     |
| [areWeakSets](areWeakSets.md)               | Kontrollib, kas sisend on mittetühi massiiv, mille iga element on `WeakSet`, tagastades `true` ainult sel juhul.                                                                                                                          |
| [getTypeOf](getTypeOf.md)                   | `getTypeOf` tagastab antud väärtuse jaoks detailse, inimesele loetava tüübisildi, sh täpsustatud numbritüübid ja konkreetsed objektiklassid.                                                                                              |

| [isDecimal](isDecimal.md)                   | `isDecimal` kontrollib, kas väärtus on kümnendstringi esitus ilma alguse/lõpu tühikuteta ja kehtiva kümnendvorminguga.                                                                                                                    |
| [isEmpty](isEmpty.md)                       | Määrab, kas antud väärtus on tühi, tagastades `true` väärtuste `null`, `undefined`, tühjade/ainult tühikutest koosnevate stringide, tühjade massiivide, tühja `Map`/`Set` või objektide puhul, millel puuduvad enda loendatavad omadused. |
