# areEqual

## Апісанне

`areEqual` правярае, ці ўсе элементы ў масіве роўныя зададзенаму чаканаму значэнню, вяртаючы `true` толькі для непустых
масіваў, дзе кожны элемент супадае.

### Выкарыстанне

Праверыць, што спіс утрымлівае толькі адно дазволенае значэнне (напрыклад, усе сцяжкі статусу — `true`, усе ролі —
`"admin"`, або ўсе лікавыя значэнні роўныя патрабаванай канстанце), пры гэтым лічыць пусты ўвод невалідным (`false`).

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areEqual`, калі патрэбна строгая праверка ўсіх элементаў; яна вяртае `false` для пустых масіваў і для
> любога ўводу, які не з'яўляецца масівам або не з'яўляецца запоўненым.

### Перавагі

- Вяртае `true` толькі тады, калі кожны элемент адпавядае чаканаму значэнню; у адваротным выпадку вяртае `false`.
- Хутка спыняецца: перастае правяраць адразу, як толькі знойдзены элемент, які не супадае.
- Абараняе ад некарэктнага ўводу, вяртаючы `false`, калі ўвод не з'яўляецца запоўненым масівам.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areEqual(value, expected)`

Параметры:

- `value`: Масіў, які трэба праверыць.
- `expected`: Элемент, з якім параўноўваецца кожны элемент масіва.

### Лакальны імпарт функцыі

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areEqual(value, expected)`
