# areOneOfType

## Апісанне

`areOneOfType` правярае, ці ўсе элементы ў непустым масіве належаць да аднаго з указаных тыпаў падчас выканання.

### Выкарыстанне

Правяраць уваходныя даныя (напрыклад, распарсены JSON), дзе поле павінна быць непустым масівам, элементы якога
абмежаваныя вядомым наборам прымітыўных тыпаў; вяртаць `false`, калі масіў пусты або змяшчае любы недазволены тып.

> **Падказка для карыстальнікаў TypeScript:**
>
> Гэтая функцыя вяртае boolean і не звужае тыпы элементаў масіва падчас кампіляцыі; выкарыстоўвайце яе як крок валідацыі
> падчас выканання перад далейшай апрацоўкай.

### Перавагі

- Гарантуе, што кожны элемент у масіве адпавядае хаця б аднаму дазволенаму тыпу падчас выканання, вяртаючы `true` толькі
  калі ўвесь масіў праходзіць праверку.
- Рана адхіляе некарэктныя ўводныя даныя: вяртае `false`, калі `array` або `types` пусты або не з'яўляецца запоўненым
  масівам.
- Карысна для валідацыі калекцый са змешанымі тыпамі (напрыклад, лікі і радкі) адным выклікам `areOneOfType`.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areOneOfType(array, types)`

Параметры:

- `array`: Масіў элементаў, якія трэба праверыць адносна пададзеных тыпаў.
- `types`: Масіў радкоў, якія прадстаўляюць тыпы даных для праверкі.

### Лакальны імпарт функцыі

```ts
import { areOneOfType } from "@type-check/guards";

const values1: unknown[] = [1, "a", true];
const ok1 = areOneOfType(values1, ["number", "string", "boolean"]);

const values2: unknown[] = [1, "a", {}];
const ok2 = areOneOfType(values2, ["number", "string"]);

const values3: unknown[] = [];
const ok3 = areOneOfType(values3, ["number"]);

console.log({ ok1, ok2, ok3 });
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areOneOfType(array, types)`
