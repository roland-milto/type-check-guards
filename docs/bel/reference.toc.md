# Спасылкі на функцыі

| Функцыя                                     | Апісанне                                                                                                                                                                                                       |
|---------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [areArrays](areArrays.md)                   | `areArrays` вызначае, ці з’яўляецца значэнне запоўненым двухмерным масівам, элементы якога ўсе з’яўляюцца масівамі.                                                                                            |
| [areBigInts](areBigInts.md)                 | `areBigInts` вызначае, ці з’яўляецца значэнне непустым масівам, які змяшчае толькі значэнні `bigint`.                                                                                                          |
| [areBinaries](areBinaries.md)               | Правярае, ці з'яўляецца перададзенае значэнне непустым масівам карэктных бінарных радкоў, і вяртае `true` толькі калі ўсе элементы прайшлі валідацыю.                                                          |
| [areBooleans](areBooleans.md)               | `areBooleans` правярае, ці змяшчае зададзены непусты масіў толькі булевыя значэнні, вяртаючы `true`, калі так, і `false` у адваротным выпадку.                                                                 |
| [areBuffers](areBuffers.md)                 | `areBuffers` правярае, ці з'яўляецца пададзенае значэнне непустым, запоўненым масівам, дзе кожны элемент — гэта `Buffer`, вяртаючы `true`, калі так, і `false` у адваротным выпадку.                           |
| [areDates](areDates.md)                     | `areDates` вызначае, ці запоўнены дадзены масіў і ці змяшчае ён толькі аб’екты `Date`, вяртаючы `true` толькі тады, калі ўсе элементы — карэктныя даты.                                                        |
| [areDecimals](areDecimals.md)               | Правярае, ці ўсе элементы ў масіве з'яўляюцца дзесятковымі лікамі і ці масіў запоўнены, вяртаючы `true` або `false`.                                                                                           |
| [areEqual](areEqual.md)                     | `areEqual` правярае, ці ўсе элементы ў масіве роўныя зададзенаму чаканаму значэнню, вяртаючы `true` толькі для непустых масіваў, дзе кожны элемент супадае.                                                    |
| [areErrors](areErrors.md)                   | Правярае, ці з’яўляецца масіў непустым і ці змяшчае ён толькі аб’екты `Error`, вяртаючы `true` або `false`.                                                                                                    |
| [areFalse](areFalse.md)                     | `areFalse` правярае, ці ўсе элементы ў перададзеным масіве строга з'яўляюцца булевым значэннем `false`.                                                                                                        |
| [areFilledArrays](areFilledArrays.md)       | `areFilledArrays` правярае, ці не пусты двухмерны масіў і ці не пустыя ўсе яго падмасівы.                                                                                                                      |
| [areFinite](areFinite.md)                   | `areFinite` правярае, ці з’яўляецца значэнне непустым масівам, элементы якога ўсе з’яўляюцца канечнымі лікамі, вяртаючы `true` ў такім выпадку і `false` у адваротным.                                         |
| [areFloats](areFloats.md)                   | `areFloats` правярае, ці з’яўляецца зададзены масіў запоўненым і ці ўсе яго элементы — лікі з плаваючай кропкай.                                                                                               |
| [areHexadecimals](areHexadecimals.md)       | Правярае, ці ўсе элементы ў масіве з’яўляюцца шаснаццатковымі радкамі, вяртаючы `true` толькі для непустых масіваў, дзе кожны элемент карэктны.                                                                |
| [areIndexesFound](areIndexesFound.md)       | `areIndexesFound` правярае, ці з’яўляецца значэнне непустым масівам, элементы якога ўсе з’яўляюцца карэктнымі індэксамі, і вяртае `true`, калі гэта так, і `false` у адваротным выпадку.                       |
| [areIntegers](areIntegers.md)               | `areIntegers` вызначае, ці ўсе элементы ў зададзеным масіве з'яўляюцца цэлымі лікамі, вяртаючы `true`, калі так, і `false` у адваротным выпадку.                                                               |
| [areJson](areJson.md)                       | Правярае, ці ўсе элементы масіва з’яўляюцца JSON-радкамі, вяртаючы `true` толькі калі масіў запоўнены і кожны элемент — карэктны JSON; інакш вяртае `false`.                                                   |
| [areMaps](areMaps.md)                       | `areMaps` вызначае, ці з’яўляецца зададзены масіў непустым і ці ўсе яго элементы — асобнікі `Map`.                                                                                                             |
| [areNaNs](areNaNs.md)                       | `areNaNs` правярае, ці ўсе элементы ў масіве з'яўляюцца `NaN`, і вяртае `true` толькі калі кожны элемент — `NaN`.                                                                                              |
| [areNullOrUndefined](areNullOrUndefined.md) | Правярае, ці ўсе элементы ў зададзеным масіве — `null` або `undefined`.                                                                                                                                        |
| [areNumbers](areNumbers.md)                 | `areNumbers` правярае, ці з’яўляецца значэнне непустым масівам, у якім усе элементы — лікі.                                                                                                                    |
| [areNumerics](areNumerics.md)               | `areNumerics` правярае, ці з’яўляецца значэнне непустым масівам, у якім усе элементы — лікавыя.                                                                                                                |
| [areObjects](areObjects.md)                 | `areObjects` правярае, ці змяшчае перададзены запоўнены масіў толькі аб'екты.                                                                                                                                  |
| [areOctals](areOctals.md)                   | `areOctals` вызначае, ці з’яўляецца пададзенае значэнне непустым масівам карэктных васьмярковых радкоў.                                                                                                        |
| [areOfType](areOfType.md)                   | Правярае, ці ўсе элементы ў зададзеным `array` маюць указаны `type`.                                                                                                                                           |

| [arePlainObjects](arePlainObjects.md)       | Правярае, ці ўсе элементы масіва з’яўляюцца простымі аб’ектамі, вяртаючы `true` толькі калі кожны элемент адпавядае.                                                                                           |
| [arePrimitives](arePrimitives.md)           | `arePrimitives` ацэньвае, ці ўсе элементы ў перададзеным непустым масіве з’яўляюцца прымітыўнымі тыпамі.                                                                                                       |
| [arePromises](arePromises.md)               | `arePromises` вызначае, ці з'яўляюцца ўсе элементы ў масіве асобнікамі `Promise`.                                                                                                                              |
| [areRegExes](areRegExes.md)                 | `areRegExes` правярае, ці з’яўляецца значэнне запоўненым масівам, які змяшчае толькі аб’екты `RegExp`.                                                                                                         |
| [areSets](areSets.md)                       | Правярае, ці змяшчае зададзены непусты масіў толькі асобнікі `Set`, вяртаючы `true`, калі так, і `false` у адваротным выпадку.                                                                                 |
| [areStreams](areStreams.md)                 | `areStreams` вызначае, ці з'яўляецца значэнне запоўненым масівам, у якім кожны элемент — гэта `Stream`.                                                                                                        |
| [areStrings](areStrings.md)                 | `areStrings` правярае, ці з'яўляецца масіў непустым і ці ўсе яго элементы — радкі, вяртаючы `true` толькі ў гэтым выпадку.                                                                                     |
| [areSymbols](areSymbols.md)                 | Правярае, ці з’яўляецца ўваход запоўненым масівам, элементы якога ўсе з’яўляюцца сімваламі, вяртаючы `true` або `false`.                                                                                       |
| [areTrue](areTrue.md)                       | Правярае, ці змяшчае непусты масіў толькі булевыя значэнні `true`.                                                                                                                                             |
| [areUndefined](areUndefined.md)             | `areUndefined` правярае, ці з'яўляецца кожны элемент у перададзеным масіве значэннем `undefined`.                                                                                                              |
| [areValidDates](areValidDates.md)           | Вызначае, ці з’яўляецца масіў непустым і ці складаецца ён цалкам з карэктных аб’ектаў `Date`.                                                                                                                  |
