# areBigInts

## Апісанне

`areBigInts` вызначае, ці з’яўляецца значэнне непустым масівам, які змяшчае толькі значэнні `bigint`.

### Выкарыстанне

Правярайце невядомы ўвод (напрыклад, распарсеныя JSON-падобныя даныя, payload’ы API або параметры функцый з тыпам
`unknown`), каб пераканацца, што гэта непусты масіў значэнняў `bigint` перад апрацоўкай; вяртае `true` толькі калі ўсе
элементы — `bigint`, інакш `false`.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areBigInts` як runtime-ахоўнік перад выкананнем аперацый толькі для `bigint` (напрыклад, арыфметыкі,
> параўнанняў) над невядомым уваходам.

### Перавагі

- Гарантуе, што кожны элемент — гэта `bigint`, вяртаючы `true` толькі тады, калі ўвесь масіў адпавядае ўмове.
- Па задуме адхіляе значэнні, якія не з’яўляюцца масівамі, а таксама пустыя масівы (праз `isFilledArray`), прадухіляючы
  выпадковае прыняцце некарэктных уваходных даных.
- Хуткае спыненне: вяртае `false`, як толькі знаходзіцца элемент, які не з’яўляецца `bigint`.

- `areBigInts(array)`

Параметры:
