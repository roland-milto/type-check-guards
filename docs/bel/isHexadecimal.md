# isHexadecimal

## Апісанне

`isHexadecimal` правярае, ці з’яўляецца зададзенае значэнне шаснаццатковым радковым літаралам з абавязковым прэфіксам
`0x`/`0X`.

### Выкарыстанне

Выкарыстоўвайце `isHexadecimal` для праверкі значэнняў канфігурацыі, палёў нагрузкі API або аргументаў CLI, якія павінны
быць зададзены як шаснаццатковыя радковыя літэралы (напрыклад, ID, маскі або адрасы) і не павінны ўтрымліваць прабелы па
краях.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isHexadecimal`, калі трэба праверыць карыстальніцкі ўвод або серыялізаваныя даныя як строгі радок
> шаснаццатковага літарала (уключаючы прэфікс `0x`/`0X`) перад разборкай або пераўтварэннем.

### Перавагі

- Правярае, што значэнне з’яўляецца радком і адпавядае строгаму фармату шаснаццатковага літарала (патрабуе прэфікс `0x`/
  `0X`).
- Адхіляе радкі з пачатковымі або канчатковымі прабеламі, дапамагаючы пазбегнуць выпадковага прыняцця ўводу з
  падкладкай.
- Падтрымлівае неабавязковы знак і не адрознівае рэгістр для прэфікса і лічбаў, прадказальна вяртаючы `true`/`false`.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isHexadecimal(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць.

### Лакальны імпарт функцыі

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // праўда
isHexadecimal("-0Xff"); // праўда
isHexadecimal("1A2B"); // няпраўда (адсутнічае прэфікс)
isHexadecimal(" 0x1A2B"); // няпраўда (пачатковы прабел)
isHexadecimal(0x1a2b); // няпраўда (не радок)
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isHexadecimal(value)`
