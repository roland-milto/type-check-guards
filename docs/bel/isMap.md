# isMap

## Апісанне

Правярае, ці з’яўляецца зададзенае `value` аб’ектам `Map`, вяртаючы `true`, калі так, і `false` у адваротным выпадку.

### Выкарыстанне

Выкарыстоўвайце `isMap`, калі атрымліваеце значэнне тыпу `unknown` (напрыклад, з разбору JSON, знешніх API або ўводу
карыстальніка) і трэба пераканацца, што гэта `Map`, перад выкананнем аперацый `Map`.

> **Падказка для карыстальнікаў TypeScript:**
>
> `isMap` — гэта ахоўнік падчас выканання, які вяртае `true`, калі значэнне з’яўляецца `Map`, і `false` у адваротным
> выпадку; выкарыстоўвайце яго, каб звузіць `unknown` перад выклікам API `Map`.

### Перавагі

- Забяспечвае хуткую праверку падчас выканання, ці з’яўляецца значэнне `Map`.
- Дапамагае прадухіляць памылкі тыпаў, абараняючы шляхі кода, якім патрэбныя метады `Map`, такія як `get`, `set` і
  `has`.
- Добра працуе як лёгкі крок валідацыі пры апрацоўцы ўваходных значэнняў тыпу `unknown`.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isMap(value)`

Параметры:

- `value`: Значэнне для праверкі.

### Лакальны імпарт функцыі

```ts
import { isMap } from "@type-check/guards";

const input: unknown = new Map<string, number>([["a", 1]]);

if (isMap(input)) {
  input.set("b", 2);
  const a = input.get("a");
  console.log(a);
} else {
  console.log("Not a Map");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isMap(value)`
