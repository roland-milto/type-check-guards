# isDate

## Апісанне

`isDate` вызначае, ці з'яўляецца перададзенае значэнне `Date`, вяртаючы `true` для асобнікаў `Date` і `false` у іншых
выпадках.

### Выкарыстанне

Правярайце і звужайце невядомыя значэнні (напрыклад, даныя запыту, значэнні канфігурацыі або распарсены JSON) перад
выкананнем аперацый з `Date`, такіх як фарматаванне, параўнанні або выклік `toISOString()`.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isDate`, каб звузіць `unknown` да `Date` падчас выканання; ён вяртае `true` толькі для сапраўдных
> асобнікаў `Date` (а не для радкоў з датай).

### Перавагі

- Забяспечвае простую праверку падчас выканання, каб вызначыць, ці з'яўляецца значэнне `Date`.
- Дапамагае прадухіляць памылкі тыпаў, гарантуючы, што праверку праходзяць толькі асобнікі `Date`.
- Карысна для валідацыі невядомых уваходных даных (напрыклад, payload API) перад выкарыстаннем метадаў, спецыфічных для
  дат.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isDate(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць на тып `Date`.

### Лакальны імпарт функцыі

```ts
import { isDate } from "@type-check/guards";

const input: unknown = new Date();

if (isDate(input)) {
  // тут input — гэта Date
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a Date");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isDate(value)`
