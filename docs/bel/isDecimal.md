# isDecimal

## Апісанне

`isDecimal` правярае, ці з’яўляецца значэнне дзесятковым радковым прадстаўленнем без пачатковых/канчатковых прабелаў і з
карэктным дзесятковым фарматам.

### Выкарыстанне

Валідаваць палі формы, payload API або значэнні канфігурацыі, якія павінны быць пададзены як дзесятковы радок (з
магчымым знакам) без якіх-небудзь прабелаў вакол, перад разборкай або захаваннем.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isDecimal`, каб правяраць увод карыстальніка перад пераўтварэннем (напрыклад, з `Number(value)`),
> асабліва калі прабелы павінны адхіляцца.

### Перавагі

- Строга правярае, што ўваходнае значэнне з’яўляецца радком і адпавядае шаблону дзесятковага літарала.
- Адхіляе пачатковыя і канчатковыя прабелы (уключаючы кіруючыя сімвалы), каб пазбегнуць неадназначнага разбору.
- Хуткія папярэднія праверкі (праверка тыпу і першага/апошняга сімвала) перад запускам regex.
- Вяртае просты булеў вынік (`true`/`false`), прыдатны для ахоўнікаў і валідацыі ўводу.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isDecimal(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць на фармат дзесятковага радка.

### Лакальны імпарт функцыі

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v тут — радок (праверана падчас выканання)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isDecimal(value)`
