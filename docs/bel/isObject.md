# isObject

## Апісанне

Вызначае, ці з’яўляецца зададзенае `value` `object` (выключаючы `null`).

### Выкарыстанне

Выкарыстоўвайце `isObject`, каб правяраць невядомыя ўваходныя даныя (напрыклад, распарсены JSON, адказы API, нагрузкі
падзей) перад доступам да ўласцівасцей, гарантуючы, што значэнне — аб’ект, а не `null`.

> **Падказка для карыстальнікаў TypeScript:**
>
> `isObject` — гэта ахоўнік падчас выканання, які вяртае boolean; ён не звужае тып да пэўнай формы аб’екта. Спалучайце
> яго з дадатковымі праверкамі (напрыклад, наяўнасці ўласцівасцей), калі патрэбна больш строгая тыпізацыя.

### Перавагі

- Вяртае `true` толькі для не-`null` значэнняў, у якіх `typeof` роўны `"object"`.
- Прадухіляе распаўсюджаную пастку JavaScript, калі `null` інакш быў бы трактаваны як аб’ект.
- Працуе для простых аб’ектаў і ўбудаваных асобнікаў аб’ектаў (напрыклад, `Date`, `RegExp`).
- Простая, хуткая праверка падчас выканання, прыдатная для абарончага праграмавання і валідацыі ўводу.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isObject(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць на тое, ці з’яўляецца яно `object`.

### Лакальны імпарт функцыі

```ts
import { isObject } from "@type-check/guards";

const input: unknown = { a: 1 };

if (isObject(input)) {
  // input — гэта ненулявы аб’ект падчас выканання
  console.log("Object detected");
} else {
  console.log("Not an object");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isObject(value)`
