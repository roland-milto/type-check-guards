# isFilledArray

## Апісанне

Правярае, ці з'яўляецца `value` масівам з хаця б адным элементам, вяртаючы `true` або `false`.

### Выкарыстанне

Выкарыстоўвайце `isFilledArray`, каб правяраць уваходныя даныя (напрыклад, API payloads, значэнні форм, канфігурацыю)
перад ітэрацыяй, доступам да першага элемента або прымяненнем логікі, якая патрабуе хаця б адзін элемент.

> **Падказка для карыстальнікаў TypeScript:**
>
> `isFilledArray` — гэта runtime-ахоўнік, які вяртае булеў значэнне; ён не звужае тыпы элементаў, акрамя пацвярджэння,
> што масіў непусты.

### Перавагі

- Простая і хуткая праверка непустога масіва з выкарыстаннем `Array.isArray` і праверкі даўжыні.
- Дапамагае пазбегнуць памылак падчас выканання, калі код мяркуе, што масіў мае хаця б адзін элемент.
- Зразумелы булеў вынік: вяртае `true` для непустых масіваў і `false` у іншых выпадках.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isFilledArray(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць, ці з'яўляецца яно непустым масівам.

### Лакальны імпарт функцыі

```ts
import { isFilledArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && isFilledArray(input)) {
  // input — гэта непусты масіў падчас выканання
  console.log(input[0]);
} else {
  console.log("Not a non-empty array");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isFilledArray(value)`
