# areBinaries

## Апісанне

Правярае, ці з'яўляецца перададзенае значэнне непустым масівам карэктных бінарных радкоў, і вяртае `true` толькі калі
ўсе элементы прайшлі валідацыю.

### Выкарыстанне

Выкарыстоўвайце `areBinaries`, калі атрымліваеце невядомы спіс (напрыклад, з JSON, формаў або API) і трэба ўпэўніцца,
што гэта непусты масіў бінарных радкоў перад яго разборкай або апрацоўкай.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areBinaries`, каб правяраць невядомы ўвод перад пераўтварэннем бінарных радкоў у лікі/BigInts; гэта
> гарантуе, што масіў непусты і кожны элемент — карэктны бінарны радок.

### Перавагі

- Правярае, што значэнне з'яўляецца непустым масівам, у якім кожны элемент — карэктны бінарны радок.
- Вяртае просты булеў вынік (`true`/`false`), прыдатны для ахоўных праверак, ранніх выхадаў і валідацыі ўводу.
- Прадухіляе наступныя памылкі разбору, адхіляючы масівы, якія ўтрымліваюць любы небінарны элемент.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areBinaries(array)`

Параметры:

- `array`: Значэнне, якое трэба праверыць.

### Лакальны імпарт функцыі

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // праўда
console.log(areBinaries(b)); // няпраўда
console.log(areBinaries([])); // няпраўда
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areBinaries(array)`
