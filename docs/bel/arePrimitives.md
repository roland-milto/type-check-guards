# arePrimitives

## Апісанне

`arePrimitives` ацэньвае, ці ўсе элементы ў перададзеным непустым масіве з’яўляюцца прымітыўнымі тыпамі.

### Выкарыстанне

Праверце, што ўваходныя даныя (напрыклад, параметры запыту, значэнні радка CSV або спіс ID/тэгаў) утрымліваюць толькі
прымітыўныя значэнні перад серыялізацыяй, хэшаваннем, лагаваннем або перадачай у API, якія не павінны атрымліваць
аб’екты.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `arePrimitives`, калі трэба ўпэўніцца, што `unknown[]` змяшчае толькі прымітыўныя значэнні (string,
> number, bigint, boolean, symbol, undefined або null) перад далейшай апрацоўкай.

### Перавагі

- Вяртае `true` толькі тады, калі кожны элемент з’яўляецца прымітыўным значэннем, што робіць гэта строгай праверкай для
  масіваў «без аб’ектаў/функцый».
- Хутка спыняецца: вяртае `false`, як толькі знойдзены непрымітыўны элемент.
- Таксама вяртае `false` для не-масіваў і пустых масіваў (праз праверку на непусты масіў), прадухіляючы выпадковае
  прыняцце некарэктнага ўводу.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `arePrimitives(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на наяўнасць элементаў прымітыўнага тыпу.

### Лакальны імпарт функцыі

```ts
import { arePrimitives } from "@type-check/guards";

const a: unknown[] = [1, "string", true];
const b: unknown[] = [null, undefined, Symbol("x")];
const c: unknown[] = [1, {}, false];

const r1 = arePrimitives(a); // праўда
const r2 = arePrimitives(b); // праўда
const r3 = arePrimitives(c); // няпраўда
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.arePrimitives(array)`
