# isSet

## Апісанне

Вызначае, ці з’яўляецца зададзенае значэнне `Set`.

### Выкарыстанне

Правярайце ўваходныя даныя з вонкавых крыніц (напрыклад, разбор JSON, увод карыстальніка або API трэціх бакоў), каб
пераканацца, што значэнне — гэта `Set`, перад выкананнем аперацый з `Set`.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isSet`, каб звузіць `unknown`-значэнні перад выклікам API, спецыфічных для `Set`, такіх як `.add`,
`.has` або `.size`.

### Перавагі

- Забяспечвае простую праверку падчас выканання, каб пацвердзіць, ці з’яўляецца значэнне `Set`.
- Дапамагае прадухіліць памылкі тыпаў, дазваляючы рана разгалініць логіку, калі значэнне не з’яўляецца `Set`.
- Працуе з любым змесцівам `Set` (пустым або запоўненым) і паслядоўна вяртае `true`/`false`.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isSet(value)`

Параметры:

- `value`: Значэнне для праверкі.

### Лакальны імпарт функцыі

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // a — гэта Set падчас выканання
  console.log(a.size);
}

console.log(isSet(b)); // false
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isSet(value)`
