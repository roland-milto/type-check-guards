# areSymbols

## Апісанне

Правярае, ці з’яўляецца ўваход запоўненым масівам, элементы якога ўсе з’яўляюцца сімваламі, вяртаючы `true` або `false`.

### Выкарыстанне

Праверце, што поле канфігурацыі (напрыклад, спіс унікальных ключоў, прадстаўленых як сімвалы) — гэта непусты масіў, які
змяшчае толькі сімвалы, перад выкарыстаннем у API, якія патрабуюць `symbol[]`.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areSymbols`, каб правяраць невядомы ўвод перад тым, як разглядаць яго як `symbol[]`; функцыя вяртае
`false` для не-масіваў і пустых масіваў.

### Перавагі

- Вяртае `true` толькі тады, калі ўваходныя даныя — гэта непусты масіў і кожны элемент з’яўляецца сімвалам.
- Прадухіляе хібныя спрацоўванні, адхіляючы не-масівы і пустыя масівы праз унутраную праверку запоўненага масіва.
- Карысна як ахоўнік тыпаў падчас выканання для праверкі спісаў, што ўтрымліваюць толькі сімвалы, перад далейшай
  апрацоўкай.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areSymbols(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на наяўнасць элементаў-симвалаў.

### Лакальны імпарт функцыі

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  // a — гэта масіў толькі з сімвалаў падчас выканання
  const first = a[0];
  console.log(typeof first); // "symbol"
}

console.log(areSymbols(b)); // false
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areSymbols(array)`
