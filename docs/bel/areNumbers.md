# areNumbers

## Апісанне

`areNumbers` правярае, ці з’яўляецца значэнне непустым масівам, у якім усе элементы — лікі.

### Выкарыстанне

Правярайце даныя, атрыманыя ад карыстальніка або з API, каб пераканацца, што гэта непусты масіў лікаў, перад вылічэннем
сум, сярэдніх значэнняў або іншых лікавых агрэгацый.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areNumbers`, каб правяраць невядомыя масівы перад выкананнем лікавых вылічэнняў; ён вяртае `false`
> для пустых масіваў і для масіваў, якія ўтрымліваюць хоць адно значэнне, што не з’яўляецца лікам.

### Перавагі

- Вяртае `true` толькі тады, калі ўваходнае значэнне — непусты масіў і кожны элемент з’яўляецца лікам.
- Прадухіляе хібныя спрацоўванні, адхіляючы пустыя масівы і значэнні, якія не з’яўляюцца масівамі.
- Карысна як ахоўная праверка перад лікавымі аперацыямі (напрыклад, сумаваннем, вылічэннем сярэдняга), каб пазбегнуць
  памылак падчас выканання.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areNumbers(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на наяўнасць лікавых элементаў.

### Лакальны імпарт функцыі

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areNumbers(array)`
