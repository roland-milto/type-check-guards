# isInteger

## Апісанне

Вызначае, ці з'яўляецца зададзенае `value` бяспечным цэлым лікам.

### Выкарыстанне

Правярайце ненадзейны ўвод (напрыклад, параметры запыту, JSON-нагрузкі, зменныя асяроддзя) перад выкарыстаннем яго як
цэлага ліку для індэксаў масіваў, пагінацыі, лічыльнікаў або ID у базе даных.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isInteger`, каб правяраць невядомае ўваходнае значэнне перад тым, як лічыць яго лікавым цэлым; ён
> вяртае `true` толькі для значэнняў, дзе `typeof value === "number"` і `Number.isSafeInteger(value)`.

### Перавагі

- Правярае і тып, і лікавую бяспеку: вяртае `true` толькі тады, калі ўваходнае значэнне — гэта лік і бяспечны цэлы лік.
- Прадухіляе распаўсюджаныя пасткі з лікавым прывядзеннем тыпаў: радкі накшталт "5" карэктна вяртаюць `false`.
- Адхіляе нецэлыя і небяспечныя цэлыя лікі, што робіць яго прыдатным для ID, лічыльнікаў і індэксацыі масіваў.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isInteger(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць на статус цэлага ліку.

### Лакальны імпарт функцыі

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      // праўда
const b = isInteger(-100);   // праўда
const c = isInteger("5");    // няпраўда
const d = isInteger(5.5);    // няпраўда
const e = isInteger(null);   // няпраўда

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isInteger(value)`
