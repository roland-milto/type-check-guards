# isTrue

## Апісанне

`isTrue` вызначае, ці з'яўляецца зададзенае значэнне строга роўным `true`.

### Выкарыстанне

Выкарыстоўвайце `isTrue` для валідацыі сцягоў, пераключальнікаў функцый або значэнняў канфігурацыі, дзе павінны прымацца
толькі літаральнае `true`, а ўсё астатняе трэба лічыць `false`.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isTrue`, калі трэба прымаць толькі булевы літарал `true`, а не проста «праўдападобныя» значэнні.

### Перавагі

- Забяспечвае строгую праверку булевага літарала `true` (без прывядзення тыпаў).
- Дапамагае адрозніваць `true` ад «праўдападобных» значэнняў, такіх як `1`, `"true"` або `{}`.
- Простыя, прадказальныя паводзіны, прыдатныя для ахоўнікаў і канвеераў валідацыі.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isTrue(value)`

Параметры:

- `value`: Значэнне для праверкі.

### Лакальны імпарт функцыі

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // праўда
const b = isTrue(1);         // няпраўда
const c = isTrue("true");   // няпраўда

if (isTrue(a)) {
  // тут a — праўда
}
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isTrue(value)`
