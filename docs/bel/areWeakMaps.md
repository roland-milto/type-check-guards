# areWeakMaps

## Апісанне

`areWeakMaps` правярае, ці з’яўляецца значэнне непустым масівам, у якім кожны элемент — гэта `WeakMap`, і вяртае `true`
толькі ў гэтым выпадку, а інакш — `false`.

### Выкарыстанне

Правярайце даныя падчас выканання (напрыклад, распарсены JSON, увод плагінаў або слаба тыпізаваную канфігурацыю), каб
пераканацца, што гэта непусты масіў асобнікаў `WeakMap`, перад ітэрацыяй і выклікам метадаў `WeakMap`; вяртае `false`,
калі хоць адзін элемент не з’яўляецца `WeakMap` або калі масіў пусты.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areWeakMaps`, каб правяраць невядомы ўвод перад тым, як разглядаць яго як непусты `WeakMap[]`; для
> пустых масіваў ён вяртае `false`.

### Перавагі

- Гарантуе, што кожны элемент у перададзеным масіве з’яўляецца асобнікам `WeakMap`.
- Вяртае `false` для пустых масіваў, прадухіляючы выпадковае прыняцце «няма даных» як карэктнага ўводу.
- Карысна як ахоўная праверка перад выкананнем аперацый, спецыфічных для `WeakMap`, над усімі элементамі.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areWeakMaps(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на наяўнасць асобнікаў `WeakMap`.

### Лакальны імпарт функцыі

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  // list — гэта непусты масіў асобнікаў WeakMap
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  // не непусты WeakMap[]
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areWeakMaps(array)`
