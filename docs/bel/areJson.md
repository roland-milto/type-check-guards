# areJson

## Апісанне

Правярае, ці ўсе элементы масіва з’яўляюцца JSON-радкамі, вяртаючы `true` толькі калі масіў запоўнены і кожны элемент —
карэктны JSON; інакш вяртае `false`.

### Выкарыстанне

Правяраць уваходныя даныя (напрыклад, з query params, зменных асяроддзя або знешніх API), калі вы чакаеце масіў радкоў,
закадаваных як JSON, і хочаце адхіляць пустыя масівы або любыя элементы, якія не з’яўляюцца JSON.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areJson`, калі трэба праверыць, што `unknown[]` змяшчае толькі JSON-радкі перад іх разборкай (
> напрыклад, з дапамогай `JSON.parse`).

### Перавагі

- Вяртае `true` толькі тады, калі кожны элемент з’яўляецца карэктным JSON-радком; у адваротным выпадку вяртае `false`.
- Хутка спыняецца: перастае правяраць, як толькі знаходзіць элемент, які не з’яўляецца JSON.
- Па задуме адхіляе пустыя масівы, вяртаючы `false` для незапоўненага ўводу.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areJson(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на наяўнасць элементаў-JSON-радкоў.

### Лакальны імпарт функцыі

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // праўда
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // няпраўда
const empty = areJson([]); // няпраўда

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areJson(array)`
