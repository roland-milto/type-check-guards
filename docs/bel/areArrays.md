# areArrays

## Апісанне

`areArrays` вызначае, ці з’яўляецца значэнне запоўненым двухмерным масівам, элементы якога ўсе з’яўляюцца масівамі.

### Выкарыстанне

Выкарыстоўвайце `areArrays`, каб праверыць таблічныя або матрычныя ўваходныя даныя (напрыклад, радкі CSV, даныя сеткі
або згрупаваныя спісы) перад выкананнем аперацый з радкамі/слупкамі; функцыя верне `false`, калі ўваходныя даныя не
з’яўляюцца масівам, пустыя або ўтрымліваюць хаця б адзін элемент, які не з’яўляецца масівам.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areArrays`, калі трэба ўпэўніцца, што значэнне — гэта непусты 2D масіў і што кожны радок з’яўляецца
> масівам, перад ітэрацыяй або індэксацыяй ва ўкладзеных масівах.

### Перавагі

- Правярае, што ўваходныя даныя — гэта непусты двухмерны масіў, дзе кожны элемент з’яўляецца масівам.
- Вяртае просты булеў вынік (`true`/`false`), прыдатны для ахоўных праверак і ранняга выхаду.
- Дапамагае прадухіліць памылкі падчас выканання, калі наступны код разлічвае на аперацыі з укладзенымі масівамі (
  напрыклад, мапаванне радкоў).

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areArrays(array)`

Параметры:

- `array`: Уваходныя даныя, якія трэба праверыць.

### Лакальны імпарт функцыі

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value — гэта двумерны масіў з масівамі ў якасці элементаў
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areArrays(array)`
