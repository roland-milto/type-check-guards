# areDecimals

## Апісанне

Правярае, ці ўсе элементы ў масіве з'яўляюцца дзесятковымі лікамі і ці масіў запоўнены, вяртаючы `true` або `false`.

### Выкарыстанне

Валідаваць спісы, пададзеныя карыстальнікам (напрыклад, слупкі CSV або ўводы формы), каб пераканацца, што масіў не пусты
і кожны запіс з'яўляецца дзесятковым значэннем перад разборкай або вылічэннямі.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areDecimals`, калі вам патрэбна хуткая булева праверка, што `unknown[]` не пусты і кожны элемент
> з'яўляецца дзесятковым прадстаўленнем.

### Перавагі

- Гарантуе, што ўвод з'яўляецца запоўненым масівам перад праверкай элементаў, прадухіляючы выпадковае прыняцце пустых
  спісаў.
- Правярае кожны элемент з дапамогай `isDecimal`, таму змешаныя або некарэктныя значэнні адразу даюць вынік `false`.
- Забяспечвае просты булеў вынік (`true`/`false`), прыдатны для ахоўнікаў і патокаў валідацыі з раннім вяртаннем.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areDecimals(array)`

Параметры:

- `array`: Масіў, які трэба праверыць.

### Лакальны імпарт функцыі

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // праўда
console.log(areDecimals(b)); // няпраўда
console.log(areDecimals(c)); // няпраўда
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areDecimals(array)`
