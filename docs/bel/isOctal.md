# isOctal

## Апісанне

Вызначае, ці з'яўляецца значэнне карэктным радком васьмярковага літарала (напрыклад, `0o755`).

### Выкарыстанне

Правяраць увод карыстальніка або значэнні канфігурацыі, якія павінны быць зададзены як радок васьмярковага літарала (
напрыклад, рэжымы правоў доступу да файлаў накшталт `0o644`), перад разборкай або пераўтварэннем.

> **Падказка для карыстальнікаў TypeScript:**
>
> `isOctal` — гэта ахоўнік тыпу (`value is string`). Пасля выніку `true` TypeScript звужае правяраемую зменную да
`string`.

### Перавагі

- Забяспечвае строгую ахову тыпу: вяртае `true` толькі тады, калі ўваходнае значэнне — радок, які адпавядае фармату
  васьмярковага літарала.
- Адхіляе пустыя радкі і радкі з пачатковымі/канчатковымі прабеламі (ASCII кіравальныя сімвалы/прабел), памяншаючы
  выпадковыя супадзенні.
- Падтрымлівае неабавязковы знак і не адрознівае рэгістр для прэфікса `0o`/`0O`.
- Паблажлівы да нерадковых уваходных значэнняў: вяртае `false` замест таго, каб кідаць выключэнне.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isOctal(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць.

### Лакальны імпарт функцыі

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); // праўда
console.log(isOctal(b)); // праўда
console.log(isOctal(c)); // няпраўда
console.log(isOctal(d)); // няпраўда

if (isOctal(a)) {
  // a тут з'яўляецца радком
  const normalized = a.toLowerCase();
  console.log(normalized);
}
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isOctal(value)`
