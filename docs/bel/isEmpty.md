# isEmpty

## Апісанне

Вызначае, ці з’яўляецца зададзенае значэнне пустым, вяртаючы `true` для `null`, `undefined`, пустых/прабельных радкоў,
пустых масіваў, пустых `Map`/`Set` або аб’ектаў без уласных пералічальных уласцівасцяў.

### Выкарыстанне

Выкарыстоўвайце `isEmpty`, каб валідаваць увод і выяўляць адсутныя/пустыя значэнні ў розных тыпах даных (напрыклад, палі
формы, нагрузкі API, аб’екты канфігурацыі), дзе `null`, `undefined`, прабельныя радкі, пустыя калекцыі і аб’екты без
уласцівасцяў павінны лічыцца пустымі.

> **Падказка для карыстальнікаў TypeScript:**
>
> `isEmpty` — гэта ўтыліта, якая вяртае булева значэнне (а не прадзікат тыпу TypeScript), таму сама па сабе яна не
> звужае тыпы; выкарыстоўвайце яе для валідацыі/разгалінавання, а не для звужэння на этапе кампіляцыі.

### Перавагі

- Разглядае `null` і `undefined` як `true` пры праверках на пустату.
- Лічыць радкі, што складаюцца толькі з прабелаў, пустымі, бо абразае прабелы перад праверкай даўжыні.
- Падтрымлівае распаўсюджаныя тыпы кантэйнераў (масівы, `Map`, `Set`) і звычайныя аб’екты без уласных пералічальных
  уласцівасцяў.
- Пазбягае падліку ўнаследаваных уласцівасцяў, выкарыстоўваючы праверкі `hasOwnProperty`.
- Вяртае просты булеў вынік (`true`/`false`), прыдатны для ахоўных праверак і валідацыі.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isEmpty(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць на пустату.

### Лакальны імпарт функцыі

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isEmpty(value)`
