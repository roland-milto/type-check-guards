# isNumeric

## Апісанне

`isNumeric` вызначае, ці лічыцца зададзенае `value` лікавым, параўноўваючы яго вырашаны тып з `NUMERIC_TYPES`.

### Выкарыстанне

Выкарыстоўвайце `isNumeric`, каб валідзіраваць уваходныя даныя (напрыклад, API payloads, значэнні формаў, канфігурацыю)
перад выкананнем лікавых аперацый, і каб паслядоўна прымаць лікападобныя тыпы (такія як `BigInt`) у адпаведнасці з
`NUMERIC_TYPES`.

> **Падказка для карыстальнікаў TypeScript:**
>
> `isNumeric` — гэта прэдыкат, які вяртае булева значэнне; успрымайце яго як праверку падчас выканання, ці належыць
> значэнне да вызначанага бібліятэкай набору лікавых тыпаў.

### Перавагі

- Выкарыстоўвае `getTypeOf` разам з `NUMERIC_TYPES`, каб цэнтралізаваць логіку выяўлення лікавых тыпаў і падтрымліваць
  аднолькавыя праверкі па ўсёй кодавой базе.
- Вяртае просты булеўскі вынік (`true`/`false`) для зручнага разгалінавання і выкарыстання ў стылі ахоўных праверак (
  guard).
- Падтрымлівае некалькі лікавых прадстаўленняў (напрыклад, `number`, `BigInt`) як вызначана ў `NUMERIC_TYPES`.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isNumeric(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць на лікавы тып.

### Лакальны імпарт функцыі

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    // v лічыцца лікавым паводле правілаў тыпаў бібліятэкі
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isNumeric(value)`
