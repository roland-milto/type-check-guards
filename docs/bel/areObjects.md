# areObjects

## Апісанне

`areObjects` правярае, ці змяшчае перададзены запоўнены масіў толькі аб'екты.

### Выкарыстанне

Выкарыстоўвайце `areObjects`, калі атрымліваеце невядомы масіў (напрыклад, пасля разбору JSON або з вонкавых API) і
трэба пераканацца, што ён не пусты і што кожны элемент — аб'ект, перад тым як ітэраваць і звяртацца да ўласцівасцяў
аб'екта.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areObjects`, каб праверыць `unknown[]` перад тым, як разглядаць элементы як аб'екты; для пустых
> масіваў ён вяртае `false`.

### Перавагі

- Вяртае `true` толькі тады, калі ўваходнае значэнне — запоўнены масіў і кожны элемент з'яўляецца аб'ектам.
- Спыняецца датэрмінова і вяртае `false`, як толькі знаходзіцца элемент, які не з'яўляецца аб'ектам.
- Дапамагае правяраць невядомы ўвод перад выкананнем аперацый, спецыфічных для аб'ектаў.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areObjects(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на наяўнасць элементаў-аб'ектаў.

### Лакальны імпарт функцыі

```ts
import { areObjects } from "@type-check/guards";

const value: unknown = [{}, { a: 1 }, new Date()];

if (Array.isArray(value) && areObjects(value)) {
  // value — гэта запоўнены масіў аб’ектаў
  console.log("All items are objects:", value.length);
} else {
  console.log("Not a filled array of objects");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areObjects(array)`
