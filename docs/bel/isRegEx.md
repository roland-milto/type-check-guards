# isRegEx

## Апісанне

Вызначае, ці з’яўляецца пададзенае значэнне асобнікам `RegExp`.

### Выкарыстанне

Правярайце значэнні, пададзеныя карыстальнікам або дынамічныя значэнні (напрыклад, канфігурацыю, payload API, уваходныя
даныя плагінаў), перад тым як разглядаць іх як рэгулярны выраз.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isRegEx`, каб звузіць значэнні тыпу `unknown` (або аб’яднання) перад выкарыстаннем уласцівасцяў або
> метадаў, спецыфічных для RegExp; ён вяртае `true` толькі для значэнняў, якія з’яўляюцца асобнікамі `RegExp`.

### Перавагі

- Забяспечвае просты ахоўнік тыпу падчас выканання, каб праверыць, ці з’яўляецца значэнне `RegExp`.
- Дапамагае прадухіліць памылкі, калі код чакае рэгулярны выраз (напрыклад, перад выклікам `test`, `exec` або чытаннем
  `source`).
- Працуе як з літараламі regex, так і з асобнікамі, створанымі праз `new RegExp(...)`.
- Вяртае зразумелы булеў вынік (`true`/`false`) без выкідвання выключэнняў для ўваходных значэнняў, якія не з’яўляюцца
  regex.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isRegEx(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць.

### Лакальны імпарт функцыі

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  // input тут з'яўляецца RegExp
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isRegEx(value)`
