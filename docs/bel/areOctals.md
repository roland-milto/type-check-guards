# areOctals

## Апісанне

`areOctals` вызначае, ці з’яўляецца пададзенае значэнне непустым масівам карэктных васьмярковых радкоў.

### Выкарыстанне

Выкарыстоўвайце `areOctals` пры валідацыі карыстальніцкага ўводу, значэнняў канфігурацыі або нагрузак API, якія павінны
ўтрымліваць васьмярковыя літэралы (напрыклад, рэжымы правоў доступу да файлаў накшталт `0o755`), і калі вы хочаце
адхіляць пустыя масівы або любыя некарэктныя элементы, вяртаючы `false`.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areOctals`, каб упэўніцца, што ў вас ёсць непусты `unknown[]`, дзе кожны элемент — карэктны
> васьмярковы радок, перад пераўтварэннем (напрыклад, праз `Number(...)` або ўласны разбор).

### Перавагі

- Правярае, што значэнне — гэта непусты масіў, у якім кожны элемент з’яўляецца васьмярковым радком, вяртаючы `true`
  толькі тады, калі ўсе элементы прайшлі праверку.
- Хутка спыняецца: вяртае `false`, як толькі знойдзены невасьмярковы элемент.
- Карысна як ахоўная праверка перад разборкай або пераўтварэннем васьмярковых радкоў, каб пазбегнуць памылак падчас
  выканання і неаднастайнай апрацоўкі ўводу.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areOctals(array)`

Параметры:

- `array`: Значэнне, якое трэба праверыць.

### Лакальны імпарт функцыі

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value — непусты масіў васьмярковых радкоў
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areOctals(array)`
