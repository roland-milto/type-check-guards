# isIndexFound

## Апісанне

`isIndexFound` вызначае, ці з'яўляецца зададзенае значэнне неадмоўным цэлым лікам, што азначае, што індэкс знойдзены.

### Выкарыстанне

Праверыць, што вынік пошуку ўяўляе сабой прыдатны індэкс (цэлы лік `>= 0`) перад індэксацыяй у масіве або радку,
прадухіляючы выпадковае выкарыстанне `-1` або нелікавых значэнняў.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isIndexFound` пасля аперацый накшталт `indexOf`, `findIndex` або карыстальніцкіх пошукаў, дзе `-1` (
> або іншыя некарэктныя значэнні) могуць азначаць «не знойдзена». Калі ён вяртае `true`, значэнне з'яўляецца лікам і яго
> бяспечна выкарыстоўваць як індэкс масіва/радка.

### Перавагі

- Забяспечвае просты ахоўнік тыпу, каб вызначыць, ці быў знойдзены індэкс, правяраючы на неадмоўны цэлы лік.
- Вяртае `true` толькі для карэктных значэнняў, падобных да індэкса (цэлыя лікі `>= 0`), адхіляючы адмоўныя, нецэлыя і
  не лікавыя значэнні.
- Дапамагае пазбягаць памылак «на адзін» і памылак са значэннямі-сігналамі пры працы з API, якія вяртаюць `-1` для «не
  знойдзена».

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isIndexFound(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць на тое, ці з'яўляецца яно неадмоўным цэлым лікам.

### Лакальны імпарт функцыі

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // idx тут з'яўляецца лікам і >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// Тыповае выкарыстанне з indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isIndexFound(value)`
