# areTrue

## Апісанне

Правярае, ці змяшчае непусты масіў толькі булевыя значэнні `true`.

### Выкарыстанне

Выкарыстоўвайце `areTrue`, каб праверыць, што набор перадумоў або сцяжкоў функцый усе ўключаныя (усе значэнні — `true`)
перад працягам, пры гэтым разглядаючы пустыя або няправільна сфармаваныя ўваходныя даныя як невыкананыя (`false`).

> **Падказка для карыстальнікаў TypeScript:**
>
> `areTrue` вяртае `false` для пустога масіва і для масіваў, якія змяшчаюць любое значэнне, што не з'яўляецца строга
`true`.

### Перавагі

- Вяртае `true` толькі тады, калі кожны элемент строга роўны `true` і масіў не пусты.
- Хутка спыняецца: вяртае `false`, як толькі знаходзіцца значэнне, якое не з'яўляецца `true`.
- Адхіляе некарэктныя ўваходныя даныя (не масівы або пустыя масівы), вяртаючы `false`.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areTrue(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на тое, што ўсе значэнні — `true`.

### Лакальны імпарт функцыі

```ts
import { areTrue } from "@type-check/guards";

const a = areTrue([true, true, true]);
const b = areTrue([true, false, true]);
const c = areTrue([]);
const d = areTrue([true, "string" as unknown, true]);

console.log(a, b, c, d);
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areTrue(array)`
