# isFalse

## Апісанне

`isFalse` правярае, ці з'яўляецца зададзенае значэнне строга роўным булеваму літаралу `false`.

### Выкарыстанне

Валідацыя невядомых даных (напрыклад, з JSON, параметраў запыту або ўводу карыстальніка), дзе толькі яўнае булева
значэнне `false` павінна лічыцца валідным сцягам, а ўсё астатняе трэба адхіляць.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isFalse`, калі трэба прымаць толькі літарал `false` і адхіляць усе іншыя «ілжывыя» значэнні; ён
> вяртае `true` толькі для `value === false`.

### Перавагі

- Забяспечвае строгую праверку булевага літарала `false` без прывядзення тыпаў.
- Дапамагае адрозніваць `false` ад іншых «ілжывых» значэнняў, такіх як `0`, `""`, `null` і `undefined`.
- Паляпшае чытальнасць, робячы намер відавочным пры валідацыі невядомага ўводу.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isFalse(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць.

### Лакальны імпарт функцыі

```ts
import { isFalse } from "@type-check/guards";

const input: unknown = false;

if (isFalse(input)) {
  // тут input дакладна false
  console.log("Got false");
} else {
  console.log("Not false");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isFalse(value)`
