# areErrors

## Апісанне

Правярае, ці з’яўляецца масіў непустым і ці змяшчае ён толькі аб’екты `Error`, вяртаючы `true` або `false`.

### Выкарыстанне

Праверыць, што перададзены падчас выканання `unknown[]` (напрыклад, агрэгаваныя збоі, вынікі валідацыі або
дэсерыялізаваныя даныя) — гэта непусты спіс аб’ектаў `Error` перад ітэрацыяй, лагіраваннем або паўторным выкідваннем.

> **Падказка для карыстальнікаў TypeScript:**
>
> `areErrors` вяртае `true` толькі для запоўненага масіва, дзе кожны элемент — гэта `Error`; ён вяртае `false` для
> пустога масіва або калі хоць адзін элемент не з’яўляецца `Error`.

### Перавагі

- Гарантуе, што кожны элемент з’яўляецца асобнікам `Error`, што дазваляе бяспечна апрацоўваць памылкі і весці
  лагіраванне.
- Адхіляе пустыя масівы, прадухіляючы выпадковыя станы «няма памылак», якія могуць быць успрыняты як карэктныя спісы
  памылак.
- Добра працуе як ахоўнік падчас выканання пры працы з уваходнымі данымі тыпу `unknown[]` (напрыклад, з API або з блокаў
  `catch`).

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areErrors(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на наяўнасць аб’ектаў `Error`.

### Лакальны імпарт функцыі

```ts
import { areErrors } from "@type-check/guards";

const value: unknown = [new Error("error1"), new TypeError("error2")];

if (Array.isArray(value) && areErrors(value)) {
  // value — гэта непусты масіў аб'ектаў Error
  for (const err of value) {
    console.error(err.name, err.message);
  }
} else {
  console.log("Not a non-empty Error[]");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areErrors(array)`
