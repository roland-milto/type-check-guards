# areMaps

## Апісанне

`areMaps` вызначае, ці з’яўляецца зададзены масіў непустым і ці ўсе яго элементы — асобнікі `Map`.

### Выкарыстанне

Правяраць невядомы ўвод (напрыклад, з разбору JSON, знешніх API або дынамічных крыніц) перад тым, як разглядаць яго як
непусты спіс аб’ектаў `Map`.

> **Падказка для карыстальнікаў TypeScript:**
>
> Вяртае `false` для пустога масіва; `true` вяртаецца толькі тады, калі масіў запоўнены і кожны элемент — `Map`.

### Перавагі

- Гарантуе, што кожны элемент з’яўляецца асобнікам `Map`, вяртаючы `true` толькі тады, калі праверку праходзіць увесь
  масіў.
- Па задуме адхіляе пустыя масівы, прадухіляючы выпадковае прыняцце «няма даных» як карэктнага ўводу.
- Карысна як ахоўная праверка перад выкананнем аперацый, спецыфічных для `Map` (напрыклад, `.get()`, `.set()`, ітэрацыя)
  па ўсёй калекцыі.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areMaps(array)`

Параметры:

- `array`: Масіў для праверкі.

### Лакальны імпарт функцыі

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // items гарантавана зьяўляецца непустым масівам асобнікаў Map падчас выкананьня
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // false для: пустых масіваў або масіваў, што ўтрымліваюць любое значэньне, якое не зьяўляецца Map
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areMaps(array)`
