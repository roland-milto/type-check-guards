# isOneOfType

## Апісанне

`isOneOfType` вызначае, ці адпавядае зададзенае `value` хаця б аднаму з перададзеных радкоў тыпаў, вяртаючы `true`, калі
знойдзена любое супадзенне, і `false` у адваротным выпадку.

### Выкарыстанне

Валідаваць слаба тыпізаваныя або знешнія даныя (напрыклад, распарсены JSON, параметры запыту), дазваляючы некалькі
прымальных тыпаў падчас выканання (такіх як `number` або `string`) перад працягам далейшай логікі.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isOneOfType`, калі вам патрэбна праверка падчас выканання, што значэнне адпавядае любому з некалькіх
> дазволеных тыпаў; яна вяртае `true`, калі супадае хаця б адзін тып, інакш `false`.

### Перавагі

- Правярае значэнне на адпаведнасць некалькім дазволеным тыпам за адзін выклік, вяртаючы `true` пры першым супадзенні.
- Працуе з уваходнымі значэннямі тыпу `unknown`, што робіць яго карысным на межах выканання (напрыклад, знешнія даныя,
  увод карыстальніка).
- Просты булеў вынік (`true`/`false`), які добра спалучаецца з умоўнай логікай і раннімі вяртаннямі.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isOneOfType(value, types)`

Параметры:

- `value`: Значэнне, якое трэба праверыць на адпаведнасць зададзеным тыпам.
- `types`: Масіў радкоў тыпаў, якія прадстаўляюць магчымыя тыпы значэння.

### Лакальны імпарт функцыі

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // input — гэта аб’ект падчас выканання
}

console.log(isOneOfType(3, ["number", "string"])); // праўда
console.log(isOneOfType("hello", ["number", "boolean"])); // хлусня

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isOneOfType(value, types)`
