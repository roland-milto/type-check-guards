# areNaNs

## Апісанне

`areNaNs` правярае, ці ўсе элементы ў масіве з'яўляюцца `NaN`, і вяртае `true` толькі калі кожны элемент — `NaN`.

### Выкарыстанне

Праверка ўваходных даных, дзе `NaN` выкарыстоўваецца як сігнальнае значэнне, і трэба гарантаваць, што ўвесь масіў
складаецца выключна з `NaN` (напрыклад, выяўленне цалкам адсутнага лікавага шэрагу).

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areNaNs`, калі трэба праверыць, што масіў утрымлівае толькі лікавае значэнне `NaN` (без прывядзення
> радкоў да лікаў).

### Перавагі

- Вяртае `true` толькі тады, калі кожны элемент — `NaN` (строгая праверка ўсіх элементаў).
- Не прыводзіць радкі да лікаў; значэнні накшталт "NaN" застаюцца не-`NaN` і робяць вынік `false`.
- Вяртае `false` для незапоўненых масіваў, прадухіляючы выпадковае `true` на пустым увядзенні.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areNaNs(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на значэнні `NaN`.

### Лакальны імпарт функцыі

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // праўда
const b = areNaNs([NaN, 1, NaN]); // няпраўда
const c = areNaNs([NaN, "NaN", NaN]); // няпраўда
const d = areNaNs([NaN, null, NaN]); // няпраўда
const e = areNaNs([] as unknown[]); // няпраўда
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areNaNs(array)`
