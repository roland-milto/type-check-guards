# isNaN

## Апісанне

Вызначае, ці з'яўляецца перададзенае `value` значэннем `NaN` тыпу `number`, без пераўтварэння радкоў.

### Выкарыстанне

Валідаваць ненадзейны або слаба тыпізаваны ўвод (напрыклад, payload API, значэнні формаў, распарсены JSON), каб выявіць
спецыяльнае значэнне `NaN` і апрацаваць яго яўна, пры гэтым лічыць не-лікавыя ўваходы не `NaN`.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isNaN`, калі трэба выявіць спецыяльнае лікавае значэнне `NaN`, адначасова гарантаваўшы, што ўваход
> сапраўды з'яўляецца `number` (без пераўтварэння радка ў лік).

### Перавагі

- Правярае, ці з'яўляецца значэнне `NaN`, не прымушаючы не-лікі (напрыклад, радкі) ператварацца ў лікі.
- Вяртае `true` толькі для значэнняў, якія адначасова маюць тып `number` і з'яўляюцца `NaN`.
- Бяспечна для ўваходных значэнняў тыпу `unknown` і пазбягае ілжывых спрацоўванняў ад няяўных пераўтварэнняў.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isNaN(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць, ці з'яўляецца яно `NaN` тыпу `number`.

### Лакальны імпарт функцыі

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // праўда
console.log(isNaN(b)); // няпраўда
console.log(isNaN(c)); // няпраўда

if (isNaN(a)) {
  // a — гэта лік, і канкрэтна NaN
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isNaN(value)`
