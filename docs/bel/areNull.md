# areNull

## Апісанне

Правярае, ці ўсе элементы ў зададзеным `array` з'яўляюцца `null`.

### Выкарыстанне

Праверце, што слупок набору даных, спіс палёў API або масіў-заглушка змяшчае толькі значэнні `null` перад ужываннем
логікі, якая мяркуе, што ўсе запісы наўмысна пустыя.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areNull`, калі вам патрэбна строгая праверка, што ўвод — гэта непусты масіў і кожны элемент у ім
> дакладна `null` (не `undefined`, не ілжывыя значэнні).

### Перавагі

- Вяртае `true` толькі тады, калі кожны элемент — `null`, што робіць гэта строгай праверкай «усе супадаюць».
- Адхіляе не-масівы і пустыя масівы, вяртаючы `false`, што прадухіляе выпадковыя праўдападобныя вынікі на некарэктным
  уводзе.
- Добра падыходзіць як праверка перадумовы перад апрацоўкай даных, якія павінны быць цалкам `null`.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areNull(array)`

Параметры:

- `array`: Уваходны масіў для праверкі элементаў на `null`.

### Лакальны імпарт функцыі

```ts
import { areNull } from "@type-check/guards";

const a = [null, null];
const b = [null, 1, null];

const allNullA = areNull(a); // праўда
const allNullB = areNull(b); // няпраўда

const notAnArray = areNull(123 as unknown as unknown[]); // няпраўда
const empty = areNull([]); // няпраўда

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areNull(array)`
