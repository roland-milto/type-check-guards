# isString

## Апісанне

`isString` вызначае, ці з'яўляецца зададзенае значэнне радком.

### Выкарыстанне

Правярайце карыстальніцкі ўвод, палі нагрузкі API або значэнні канфігурацыі падчас выканання, каб пераканацца, што
значэнне — радок, перад ужываннем радковых аперацый (напрыклад, абразанне прабелаў, падзел, змена рэгістра).

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isString`, каб правяраць `unknown` або слаба тыпізаваныя значэнні перад выклікам радковых метадаў; ён
> вяртае `true` толькі калі `typeof value === "string"`.

### Перавагі

- Простая і хуткая праверка з выкарыстаннем `typeof`.
- Вяртае прадказальны булеў вынік: `true` для радкоў, у іншых выпадках `false`.
- Працуе як для пустых, так і для непустых радкоў.
- Карысна як лёгкая runtime-ахова перад выкананнем аперацый, спецыфічных для радкоў.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isString(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць на тып радка.

### Лакальны імпарт функцыі

```ts
import { isString } from "@type-check/guards";

const input: unknown = "Hello World";

if (isString(input)) {
  // input тут зьяўляецца радком
  console.log(input.toUpperCase());
} else {
  console.log("Not a string");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isString(value)`
