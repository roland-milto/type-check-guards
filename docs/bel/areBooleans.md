# areBooleans

## Апісанне

`areBooleans` правярае, ці змяшчае зададзены непусты масіў толькі булевыя значэнні, вяртаючы `true`, калі так, і `false`
у адваротным выпадку.

### Выкарыстанне

Правяраць даныя, прадастаўленыя карыстальнікам або знешнімі крыніцамі (напрыклад, JSON-пэйлоады, параметры запыту,
масівы канфігурацыі), каб пераканацца, што непусты спіс змяшчае толькі булевыя значэнні, перад ужываннем булевай логікі
або перадачай у API, якія чакаюць `boolean[]`.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areBooleans`, каб праверыць `unknown[]` перад тым, як разглядаць яго як `boolean[]`; ён вяртае
`false` для пустых масіваў, таму апрацоўвайце гэты выпадак асобна, калі пусты спіс павінен быць дазволены.

### Перавагі

- Вяртае `true` толькі тады, калі кожны элемент з'яўляецца булевым значэннем і ўваходныя даныя — непусты масіў.
- Прадухіляе ілжывыя спрацоўванні, адхіляючы пустыя масівы (вяртае `false`).
- Добра працуе як праверка падчас выканання перад аперацыямі толькі з булевымі значэннямі (напрыклад, `every`, `some`,
  лагічныя зводы).

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areBooleans(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на наяўнасць булевых элементаў.

### Лакальны імпарт функцыі

```ts
import { areBooleans } from "@type-check/guards";

const values1: unknown[] = [true, false, true];
if (areBooleans(values1)) {
  const allTrue = values1.every(v => v);
  console.log(allTrue);
}

const values2: unknown[] = [];
console.log(areBooleans(values2));

const values3: unknown[] = [true, 1, false];
console.log(areBooleans(values3));
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areBooleans(array)`
