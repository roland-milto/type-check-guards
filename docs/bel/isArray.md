# isArray

## Апісанне

`isArray` правярае, ці з'яўляецца зададзенае значэнне масівам, і вяртае `true`, калі так, у адваротным выпадку —
`false`.

### Выкарыстанне

Правярайце невядомыя даныя (напрыклад, распарсены JSON або адказы API), каб пераканацца, што значэнне — гэта масіў,
перад ітэрацыяй, індэксаваннем або доступам да `.length`.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isArray`, калі вам патрэбна праверка масіваў падчас выканання; яна вяртае булеў значэнне і бяспечная
> для выкліку з значэннямі тыпу `unknown`.

### Перавагі

- Выкарыстоўвае ўбудаваны `Array.isArray` для надзейнага выяўлення масіваў паміж рознымі асяроддзямі (напрыклад,
  iframe).
- Вяртае просты булеў вынік (`true`/`false`), прыдатны для ахоўных праверак і разгалінавання логікі.
- Працуе з любым тыпам уводу, бо параметр мае тып `unknown`.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isArray(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць.

### Лакальны імпарт функцыі

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  // input — гэта масіў падчас выканання
  console.log(input.length);
} else {
  console.log("Not an array");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isArray(value)`
