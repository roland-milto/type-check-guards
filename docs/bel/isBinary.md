# isBinary

## Апісанне

`isBinary` вызначае, ці з'яўляецца значэнне бінарным радком (з неабавязковым прэфіксам `0b`/`0B`) і вяртае `true` або
`false`.

### Выкарыстанне

Правярайце радкі, уведзеныя карыстальнікам (напрыклад, палі формы, аргументы CLI, значэнні канфігурацыі), каб
пераканацца, што яны прадстаўляюць толькі бінарныя лічбы, з неабавязковым прэфіксам `0b`/`0B`, перад далейшай
апрацоўкай.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `isBinary` як ахоўнік тыпу перад разборкай або пераўтварэннем радка ў `BigInt`/`Number`, каб
> пазбегнуць некарэктнага ўводу.

### Перавагі

- Прымае бінарныя радкі з прэфіксам `0b`/`0B` або без яго.
- Адхіляе пустыя радкі і радкі з пачатковымі/канцавымі прабеламі (ASCII ≤ 32).
- Вяртае `true`/`false` без выкідвання выключэнняў, што робіць функцыю бяспечнай для невядомых уваходных значэнняў.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `isBinary(value)`

Параметры:

- `value`: Значэнне, якое трэба праверыць.

### Лакальны імпарт функцыі

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // праўда
const b = isBinary("1010");   // праўда
const c = isBinary("0b1020"); // няпраўда
const d = isBinary(0b1010);     // няпраўда

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.isBinary(value)`
