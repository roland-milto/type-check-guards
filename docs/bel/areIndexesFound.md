# areIndexesFound

## Апісанне

`areIndexesFound` правярае, ці з’яўляецца значэнне непустым масівам, элементы якога ўсе з’яўляюцца карэктнымі індэксамі,
і вяртае `true`, калі гэта так, і `false` у адваротным выпадку.

### Выкарыстанне

Правяраць дадзеныя, прадастаўленыя карыстальнікам або знешняй крыніцай (напрыклад, распарсены JSON), якія павінны быць
спісам індэксаў, перад тым як выкарыстоўваць іх для доступу да масіваў або для іх разразання.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areIndexesFound`, каб правяраць невядомы ўвод перад тым, як лічыць яго элементы індэксамі масіва;
> функцыя вяртае `false` для пустых масіваў і для масіваў, што ўтрымліваюць значэнні, якія не з’яўляюцца індэксамі.

### Перавагі

- Вяртае `true` толькі тады, калі ўваходнае значэнне — запоўнены масіў і кожны элемент з’яўляецца карэктным індэксам.
- Хутка спыняецца: вяртае `false`, як толькі сустракаецца элемент, які не з’яўляецца індэксам.
- Карысна як ахоўная праверка перад выкарыстаннем значэнняў у якасці пазіцый або зрухаў у масіве.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areIndexesFound(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на адпаведнасць індэксам.

### Лакальны імпарт функцыі

```ts
import { areIndexesFound } from "@type-check/guards";

const a: unknown[] = [0, 1, 2];
const b: unknown[] = [0, "a", 2];
const c: unknown[] = [];

console.log(areIndexesFound(a)); // праўда
console.log(areIndexesFound(b)); // няпраўда
console.log(areIndexesFound(c)); // няпраўда

if (areIndexesFound(a)) {
  // Тут `a` пацьверджана як запоўнены масіў індэксаў.
  const firstIndex = a[0];
  console.log(firstIndex);
}
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areIndexesFound(array)`
