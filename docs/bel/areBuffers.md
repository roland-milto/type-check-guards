# areBuffers

## Апісанне

`areBuffers` правярае, ці з'яўляецца пададзенае значэнне непустым, запоўненым масівам, дзе кожны элемент — гэта
`Buffer`, вяртаючы `true`, калі так, і `false` у адваротным выпадку.

### Выкарыстанне

Правярайце ўваходныя масівы частак (напрыклад, са стрэмаў, загрузак файлаў або сеткавых пакетаў), каб пераканацца, што
ўсе часткі — гэта асобнікі `Buffer`, перад канкатэнацыяй, дэкадаваннем або перадачай іх у крыптаграфічныя ці
бінарна-апрацоўчыя функцыі.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areBuffers`, каб правяраць `unknown[]` перад выклікам API, спецыфічных для Buffer, такіх як
`Buffer.concat`, гарантуючы, што функцыя верне `true` толькі тады, калі кожны элемент — гэта `Buffer`.

### Перавагі

- Гарантуе, што кожны элемент ва ўваходных даных з'яўляецца асобнікам Node.js `Buffer`, вяртаючы `true` толькі тады,
  калі ўвесь масіў адпавядае.
- Рана адхіляе некарэктныя ўваходныя даныя, патрабуючы непусты, запоўнены масіў; вяртае `false` для пустых масіваў або
  не-масіваў.
- Карысна як ахоўная праверка перад выкананнем аперацый толькі для буфераў (напрыклад, канкатэнацыя, хэшаванне, бінарныя
  пратаколы).

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areBuffers(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на наяўнасць асобнікаў буфера.

### Лакальны імпарт функцыі

```ts
import { areBuffers } from "@type-check/guards";

const chunks: unknown[] = [Buffer.from("test"), Buffer.from("123")];

if (areBuffers(chunks)) {
  const combined = Buffer.concat(chunks);
  console.log(combined.toString("utf8"));
} else {
  throw new TypeError("Expected a non-empty array of Buffer instances");
}

```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areBuffers(array)`
