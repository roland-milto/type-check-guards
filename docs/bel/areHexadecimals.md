# areHexadecimals

## Апісанне

Правярае, ці ўсе элементы ў масіве з’яўляюцца шаснаццатковымі радкамі, вяртаючы `true` толькі для непустых масіваў, дзе
кожны элемент карэктны.

### Выкарыстанне

Выкарыстоўвайце `areHexadecimals`, каб правяраць увод карыстальніка або знешнія даныя (напрыклад, ідэнтыфікатары,
кантрольныя сумы, каляровыя коды без пачатковага '#') перад шаснаццатковым разборкам або далейшай апрацоўкай.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areHexadecimals`, каб праверыць невядомы ўвод перад разборкай або пераўтварэннем значэнняў (
> напрыклад, перад `parseInt(value, 16)` або пераўтварэннямі ў BigInt).

### Перавагі

- Правярае, што кожны элемент з’яўляецца шаснаццатковым радком, і вяртае `true` толькі тады, калі ўсе элементы
  адпавядаюць.
- Па задуме адхіляе пустыя масівы, вяртаючы `false` пры адсутных уваходных даных.
- Забяспечвае просты булеў вынік (`true`/`false`), прыдатны для ахоўнікаў і валідацыі з раннім вяртаннем.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areHexadecimals(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на наяўнасць шаснаццатковых радковых элементаў.

### Лакальны імпарт функцыі

```ts
import { areHexadecimals } from "@type-check/guards";

const a = areHexadecimals(["1A", "3F", "B2"]);
const b = areHexadecimals(["1A", "3G", "B2"]);
const c = areHexadecimals([10 as unknown as string, "3F", "B2"] as unknown[]);
const d = areHexadecimals([]);

console.log(a, b, c, d);
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areHexadecimals(array)`
