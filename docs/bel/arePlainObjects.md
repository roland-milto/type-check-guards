# arePlainObjects

## Апісанне

Правярае, ці ўсе элементы масіва з’яўляюцца простымі аб’ектамі, вяртаючы `true` толькі калі кожны элемент адпавядае.

### Выкарыстанне

Правярайце знешнія або нетыпізаваныя даныя (напрыклад, распарсены JSON, нагрузкі API, адпраўкі формаў), каб пераканацца,
што вы атрымалі непусты масіў, у якім кожны запіс — просты аб’ект, перад тым як ітэраваць і чытаць уласцівасці.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `arePlainObjects`, каб праверыць невядомы ўвод перад тым, як разглядаць яго як
`Record<string, unknown>[]` (або больш строгую форму аб’екта) у TypeScript.

### Перавагі

- Гарантуе, што кожны элемент ва ўваходным масіве — просты аб’ект, вяртаючы `true` толькі тады, калі ўсе элементы
  адпавядаюць.
- Рана адхіляе некарэктныя ўваходныя даныя (не масівы або пустыя масівы), вяртаючы `false`.
- Лічыць як аб’екты-літаралы, так і аб’екты `Object.create(null)` валіднымі простымі аб’ектамі.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `arePlainObjects(array)`

Параметры:

- `array`: Масіў, у якім трэба праверыць элементы на тое, што яны з’яўляюцца простымі аб’ектамі.

### Лакальны імпарт функцыі

```ts
import { arePlainObjects } from "@type-check/guards";

const a = arePlainObjects([{ a: 1 }, { b: 2 }]); // праўда
const b = arePlainObjects([{}, Object.create(null)]); // праўда
const c = arePlainObjects([{ a: 1 }, 2 as unknown]); // няпраўда
const d = arePlainObjects([] as unknown[]); // няпраўда
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.arePlainObjects(array)`
