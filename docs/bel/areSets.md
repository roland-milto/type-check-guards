# areSets

## Апісанне

Правярае, ці змяшчае зададзены непусты масіў толькі асобнікі `Set`, вяртаючы `true`, калі так, і `false` у адваротным
выпадку.

### Выкарыстанне

Праверце, што значэнне (напрыклад, з уводу карыстальніка, разбору JSON або знешніх API) — гэта непусты масіў аб’ектаў
`Set` перад апрацоўкай кожнага набору.

> **Падказка для карыстальнікаў TypeScript:**
>
> Выкарыстоўвайце `areSets`, каб правяраць невядомыя ўваходныя даныя перад ітэрацыяй і выклікам API `Set` (напрыклад,
`.size`, `.has`, `.add`) для кожнага элемента.

### Перавагі

- Вяртае `true` толькі тады, калі ўваходныя даныя — гэта непусты масіў і кожны элемент з’яўляецца асобнікам `Set`.
- Прадухіляе ілжывыя спрацоўванні для пустых масіваў, вяртаючы `false`, калі масіў не мае элементаў.
- Карысна як праверка падчас выканання перад выкананнем аперацый, спецыфічных для `Set`, над кожным элементам.

## Выкарыстанне

### Сінтаксіс

Функцыя:

- `areSets(array)`

Параметры:

- `array`: Масіў, які трэба праверыць на наяўнасць асобнікаў `Set`.

### Лакальны імпарт функцыі

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  // a — гэта масіў асобнікаў Set падчас выканання
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); // ілжыня
console.log(areSets(c)); // ілжыня
```

### Глабальны імпарт аб’екта

Каб імпартаваць функцыі як глабальныя метады аб’екта, выкарыстоўвайце:

```ts
import "@type-check/guards/register-global-object.mjs";
```

Наступны метад будзе даступны глабальна:

- `Type.areSets(array)`
