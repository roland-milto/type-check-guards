# isSet

## توضیحات

مشخص می‌کند آیا یک مقدار داده‌شده یک `Set` است یا نه.

### مورد استفاده

اعتبارسنجی ورودی‌ها از منابع خارجی (مثلاً تجزیهٔ JSON، ورودی کاربر، یا APIهای شخص ثالث) برای اطمینان از اینکه یک مقدار
`Set` است، پیش از انجام عملیات‌های `Set`.

> **نکته برای کاربران TypeScript:**
>
> از `isSet` استفاده کنید تا مقادیر `unknown` را پیش از فراخوانی APIهای مخصوص `Set` مانند `.add`، `.has` یا `.size`
> محدودتر کنید.

### مزایا

- یک بررسی ساده در زمان اجرا فراهم می‌کند تا تأیید شود آیا یک مقدار یک `Set` است یا نه.
- با امکان شاخه‌بندی زودهنگام وقتی یک مقدار `Set` نیست، به جلوگیری از خطاهای نوع کمک می‌کند.
- با هر نوع محتوای `Set` (خالی یا پر) کار می‌کند و به‌طور سازگار `true`/`false` برمی‌گرداند.

## نحوه استفاده

### نحو

تابع:

- `isSet(value)`

پارامترها:

- `value`: مقداری که باید بررسی شود.

### وارد کردن محلی تابع

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  //‎‎ a در زمان اجرا یک Set است
  console.log(a.size);
}

console.log(isSet(b)); //‎ نادرست
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isSet(value)`
