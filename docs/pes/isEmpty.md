# isEmpty

## توضیحات

مشخص می‌کند آیا یک مقدار داده‌شده خالی است یا نه؛ برای `null`، `undefined`، رشته‌های خالی/فقط فاصله، آرایه‌های خالی،
`Map`/`Set` خالی، یا آبجکت‌هایی که هیچ ویژگی قابل‌شمارشِ متعلق به خود ندارند، مقدار `true` برمی‌گرداند.

### مورد استفاده

از `isEmpty` برای اعتبارسنجی ورودی‌ها و تشخیص مقدارهای گمشده/خالی در چندین نوع داده استفاده کنید (مثلاً فیلدهای فرم،
payloadهای API، آبجکت‌های پیکربندی)؛ جایی که `null`، `undefined`، رشته‌های فقط فاصله، مجموعه‌های خالی و آبجکت‌های بدون
ویژگی باید خالی تلقی شوند.

> **نکته برای کاربران TypeScript:**
>
> `isEmpty` یک ابزار با خروجی بولی است (نه یک type predicate در TypeScript)، بنابراین به‌تنهایی نوع‌ها را narrow
> نمی‌کند؛ از آن برای اعتبارسنجی/شاخه‌بندی استفاده کنید نه برای narrow کردن در زمان کامپایل.

### مزایا

- `null` و `undefined` را برای بررسی خالی بودن، به‌عنوان `true` در نظر می‌گیرد.
- رشته‌هایی که فقط شامل فاصله هستند را با trim کردن قبل از بررسی طول، خالی محسوب می‌کند.
- از انواع رایج ظرف‌ها (آرایه‌ها، `Map`، `Set`) و آبجکت‌های ساده بدون ویژگی‌های قابل‌شمارشِ متعلق به خود پشتیبانی
  می‌کند.
- با استفاده از بررسی‌های `hasOwnProperty` از شمردن ویژگی‌های به‌ارث‌رسیده جلوگیری می‌کند.
- یک نتیجهٔ بولی ساده (`true`/`false`) برمی‌گرداند که برای گاردها و اعتبارسنجی مناسب است.

## نحوه استفاده

### نحو

تابع:

- `isEmpty(value)`

پارامترها:

- `value`: مقداری که باید از نظر خالی بودن بررسی شود.

### وارد کردن محلی تابع

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isEmpty(value)`
