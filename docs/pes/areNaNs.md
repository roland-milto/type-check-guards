# areNaNs

## توضیحات

`areNaNs` بررسی می‌کند آیا همهٔ عناصرِ یک آرایه `NaN` هستند و فقط در صورتی `true` برمی‌گرداند که هر عنصر `NaN` باشد.

### مورد استفاده

اعتبارسنجی داده‌های ورودی در جایی که `NaN` به‌عنوان مقدارِ نشانه (sentinel) استفاده می‌شود و باید مطمئن شوید کل آرایه
منحصراً از `NaN` تشکیل شده است (مثلاً تشخیص یک سری عددی که همهٔ مقادیرش ناموجود هستند).

> **نکته برای کاربران TypeScript:**
>
> وقتی لازم دارید اعتبارسنجی کنید که یک آرایه فقط شامل مقدار عددیِ `NaN` است (بدون تبدیلِ رشته به عدد)، از `areNaNs`
> استفاده کنید.

### مزایا

- فقط وقتی `true` برمی‌گرداند که هر عنصر `NaN` باشد (بررسی سخت‌گیرانهٔ همهٔ عناصر).
- رشته‌ها را به عدد تبدیل نمی‌کند؛ مقدارهایی مثل "NaN" همچنان غیرِ`NaN` می‌مانند و نتیجه را `false` می‌کنند.
- برای آرایه‌های پُرنشده `false` برمی‌گرداند و از `true` شدنِ تصادفی روی ورودیِ خالی جلوگیری می‌کند.

## نحوه استفاده

### نحو

تابع:

- `areNaNs(array)`

پارامترها:

- `array`: آرایه‌ای که باید از نظر مقدارهای `NaN` بررسی شود.

### وارد کردن محلی تابع

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); //‎ درست
const b = areNaNs([NaN, 1, NaN]); //‎ نادرست
const c = areNaNs([NaN, "NaN", NaN]); //‎ نادرست
const d = areNaNs([NaN, null, NaN]); //‎ نادرست
const e = areNaNs([] as unknown[]); //‎ نادرست
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areNaNs(array)`
