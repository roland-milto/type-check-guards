# areSymbols

## توضیحات

بررسی می‌کند آیا ورودی یک آرایهٔ پُر (غیرخالی) است که عناصر آن همگی نماد (symbol) هستند یا نه، و `true` یا `false`
برمی‌گرداند.

### مورد استفاده

پیش از استفاده از یک فیلد پیکربندی (مثلاً فهرستی از کلیدهای یکتا که به‌صورت نمادها نمایش داده می‌شوند) در APIهایی که به
`symbol[]` نیاز دارند، اعتبارسنجی کنید که آن فیلد یک آرایهٔ غیرخالی است و فقط نمادها را شامل می‌شود.

> **نکته برای کاربران TypeScript:**
>
> از `areSymbols` برای اعتبارسنجی ورودی ناشناخته پیش از اینکه آن را `symbol[]` در نظر بگیرید استفاده کنید؛ برای
> غیرآرایه‌ها و آرایه‌های خالی `false` برمی‌گرداند.

### مزایا

- فقط زمانی `true` برمی‌گرداند که ورودی یک آرایهٔ غیرخالی باشد و هر عنصر آن یک نماد (symbol) باشد.
- با رد کردن غیرآرایه‌ها و آرایه‌های خالی از طریق بررسی داخلیِ filled-array، از مثبت‌های کاذب جلوگیری می‌کند.
- به‌عنوان یک نگهبان نوع (type guard) در زمان اجرا برای اعتبارسنجی فهرست‌های فقط-نماد پیش از پردازش‌های بعدی مفید است.

## نحوه استفاده

### نحو

تابع:

- `areSymbols(array)`

پارامترها:

- `array`: آرایه‌ای که باید از نظر نماد بودن عناصر بررسی شود.

### وارد کردن محلی تابع

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  //‎‎ a در زمان اجرا یک آرایهٔ فقط-نماد است
  const first = a[0];
  console.log(typeof first); //‎ "symbol"
}

console.log(areSymbols(b)); //‎ false
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areSymbols(array)`
