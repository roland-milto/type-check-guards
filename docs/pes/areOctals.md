# areOctals

## توضیحات

`areOctals` تعیین می‌کند آیا مقدار ارائه‌شده یک آرایهٔ غیرخالی از رشته‌های هشت‌هشتی معتبر است یا نه.

### مورد استفاده

وقتی ورودی کاربر، مقادیر پیکربندی، یا payloadهای API را اعتبارسنجی می‌کنید که باید شامل لیترال‌های هشت‌هشتی باشند (مثلاً
حالت‌های مجوز فایل مثل `0o755`) و می‌خواهید آرایه‌های خالی یا هر ورودی نامعتبر را با برگرداندن `false` رد کنید، از
`areOctals` استفاده کنید.

> **نکته برای کاربران TypeScript:**
>
> از `areOctals` استفاده کنید تا مطمئن شوید یک `unknown[]` غیرخالی دارید که هر ورودی آن یک رشتهٔ هشت‌هشتی معتبر است، قبل
> از تبدیل (مثلاً با `Number(...)` یا پارس کردن سفارشی).

### مزایا

- اعتبارسنجی می‌کند که یک مقدار، آرایه‌ای غیرخالی است که در آن هر عنصر یک رشتهٔ هشت‌هشتی (octal) است و فقط زمانی `true`
  برمی‌گرداند که همهٔ آیتم‌ها قبول شوند.
- سریع شکست می‌خورد: به محض اینکه یک عنصر غیرهشت‌هشتی پیدا شود، `false` برمی‌گرداند.
- به‌عنوان یک گارد قبل از پارس کردن یا تبدیل رشته‌های هشت‌هشتی مفید است تا از خطاهای زمان اجرا و مدیریت ورودی ناسازگار
  جلوگیری شود.

## نحوه استفاده

### نحو

تابع:

- `areOctals(array)`

پارامترها:

- `array`: مقداری که باید بررسی شود.

### وارد کردن محلی تابع

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  //‎‎ مقدار یک آرایهٔ غیرخالی از رشته‌های هشت‌پایه است
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areOctals(array)`
