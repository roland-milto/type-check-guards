# areMaps

## توضیحات

`areMaps` تعیین می‌کند که آیا یک آرایهٔ داده‌شده غیرخالی است و همهٔ عناصر آن نمونه‌های `Map` هستند یا نه.

### مورد استفاده

اعتبارسنجی ورودی ناشناخته (مثلاً از تجزیهٔ JSON، APIهای خارجی، یا منابع پویا) پیش از اینکه آن را به‌عنوان یک فهرست
غیرخالی از اشیای `Map` در نظر بگیرید.

> **نکته برای کاربران TypeScript:**
>
> برای یک آرایهٔ خالی `false` برمی‌گرداند؛ فقط وقتی `true` برمی‌گرداند که آرایه پر باشد و هر عنصر یک `Map` باشد.

### مزایا

- اطمینان می‌دهد که هر عنصر یک نمونهٔ `Map` است و فقط وقتی `true` برمی‌گرداند که کل آرایه از بررسی عبور کند.
- طبق طراحی، آرایه‌های خالی را رد می‌کند و از پذیرش تصادفی «بدون داده» به‌عنوان ورودی معتبر جلوگیری می‌کند.
- به‌عنوان یک گارد پیش از انجام عملیات مخصوص `Map` (مثل `.get()`، `.set()`، پیمایش) روی یک مجموعه مفید است.

## نحوه استفاده

### نحو

تابع:

- `areMaps(array)`

پارامترها:

- `array`: آرایه‌ای که باید بررسی شود.

### وارد کردن محلی تابع

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  //‎‎ items تضمین می‌شود که در زمان اجرا یک آرایهٔ غیرخالی از نمونه‌های Map باشد
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  //‎‎ نادرست برای: آرایه‌های خالی، یا آرایه‌هایی که شامل هر مقدارِ غیر-Map باشند
}

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areMaps(array)`
