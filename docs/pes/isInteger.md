# isInteger

## توضیحات

مشخص می‌کند آیا `value` داده‌شده یک عدد صحیحِ امن است یا نه.

### مورد استفاده

ورودی غیرقابل‌اعتماد (مثلاً پارامترهای کوئری، payloadهای JSON، متغیرهای محیطی) را قبل از استفاده به‌عنوان عدد صحیح برای
اندیس‌های آرایه، صفحه‌بندی، شمارنده‌ها یا شناسه‌های پایگاه‌داده اعتبارسنجی کنید.

> **نکته برای کاربران TypeScript:**
>
> از `isInteger` برای اعتبارسنجی ورودی ناشناخته قبل از اینکه آن را یک عدد صحیح در نظر بگیرید استفاده کنید؛ این تابع فقط
> برای مقادیری `true` برمی‌گرداند که `typeof value === "number"` و `Number.isSafeInteger(value)` باشند.

### مزایا

- هم ایمنی نوع و هم ایمنی عددی را بررسی می‌کند: فقط وقتی ورودی یک عدد و یک عدد صحیحِ امن باشد `true` برمی‌گرداند.
- از دام‌های رایجِ تبدیل اجباری عددی جلوگیری می‌کند: رشته‌هایی مثل "5" به‌درستی `false` برمی‌گردانند.
- اعداد غیرصحیح و اعداد صحیحِ ناامن را رد می‌کند، بنابراین برای شناسه‌ها، شمارنده‌ها و اندیس‌گذاری آرایه مناسب است.

## نحوه استفاده

### نحو

تابع:

- `isInteger(value)`

پارامترها:

- `value`: مقداری که باید از نظر صحیح‌بودن بررسی شود.

### وارد کردن محلی تابع

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      //‎ درست
const b = isInteger(-100);   //‎ درست
const c = isInteger("5");    //‎ نادرست
const d = isInteger(5.5);    //‎ نادرست
const e = isInteger(null);   //‎ نادرست

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isInteger(value)`
