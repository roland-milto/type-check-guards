# areDecimals

## توضیحات

بررسی می‌کند آیا همهٔ عناصر یک آرایه عدد اعشاری هستند و آرایه پُر است یا نه، و `true` یا `false` برمی‌گرداند.

### مورد استفاده

اعتبارسنجی فهرست‌های ارائه‌شده توسط کاربر (مثلاً ستون‌های CSV یا ورودی‌های فرم) برای اطمینان از اینکه آرایه خالی نیست و
هر ورودی یک مقدار اعشاری است، پیش از پارس‌کردن یا انجام محاسبات.

> **نکته برای کاربران TypeScript:**
>
> وقتی به یک بررسی بولی سریع نیاز دارید که یک `unknown[]` خالی نیست و هر عنصر آن یک نمایش اعشاری است، از `areDecimals`
> استفاده کنید.

### مزایا

- اطمینان می‌دهد که ورودی پیش از اعتبارسنجی آیتم‌ها یک آرایهٔ پُر است و از پذیرش تصادفی فهرست‌های خالی جلوگیری می‌کند.
- هر عنصر را با `isDecimal` اعتبارسنجی می‌کند، بنابراین مقادیر ترکیبی یا نامعتبر فوراً نتیجهٔ `false` می‌دهند.
- یک خروجی بولی ساده (`true`/`false`) ارائه می‌دهد که برای گاردها و جریان‌های اعتبارسنجیِ بازگشتِ زودهنگام مناسب است.

## نحوه استفاده

### نحو

تابع:

- `areDecimals(array)`

پارامترها:

- `array`: آرایه‌ای که باید بررسی شود.

### وارد کردن محلی تابع

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); //‎ درست
console.log(areDecimals(b)); //‎ نادرست
console.log(areDecimals(c)); //‎ نادرست
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areDecimals(array)`
