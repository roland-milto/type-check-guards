# isNaN

## توضیحات

مشخص می‌کند آیا `value` ارائه‌شده یک `NaN` از نوع `number` است، بدون تبدیل کردن رشته‌ها.

### مورد استفاده

اعتبارسنجی ورودیِ غیرقابل‌اعتماد یا با نوع‌دهی سست (مثلاً payloadهای API، مقادیر فرم، JSON پارس‌شده) برای تشخیص مقدار
ویژه‌ی `NaN` و رسیدگی صریح به آن، در حالی که ورودی‌های غیرعددی را `NaN` در نظر نمی‌گیرد.

> **نکته برای کاربران TypeScript:**
>
> وقتی لازم دارید مقدار عددی ویژه‌ی `NaN` را تشخیص دهید و در عین حال مطمئن شوید ورودی واقعاً یک `number` است (بدون تبدیل
> رشته به عدد)، از `isNaN` استفاده کنید.

### مزایا

- بررسی می‌کند که آیا یک مقدار `NaN` است، بدون اینکه مقادیر غیرعددی (مثلاً رشته‌ها) را به عدد تبدیل کند.
- `true` را فقط برای مقادیری برمی‌گرداند که هم از نوع `number` هستند و هم `NaN`.
- برای ورودی‌های `unknown` امن است و از مثبتِ کاذب ناشی از تبدیل‌های ضمنی جلوگیری می‌کند.

## نحوه استفاده

### نحو

تابع:

- `isNaN(value)`

پارامترها:

- `value`: مقداری که باید بررسی شود آیا یک `NaN` از نوع `number` است یا نه.

### وارد کردن محلی تابع

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // ‎درست
console.log(isNaN(b)); // ‎نادرست
console.log(isNaN(c)); // ‎نادرست

if (isNaN(a)) {
  //‎ ‎a یک عدد است و به‌طور مشخص NaN است
}
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isNaN(value)`
