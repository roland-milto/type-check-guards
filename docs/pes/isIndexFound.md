# isIndexFound

## توضیحات

`isIndexFound` تعیین می‌کند آیا یک مقدار داده‌شده یک عدد صحیح نامنفی است و نشان می‌دهد که یک اندیس پیدا شده است.

### مورد استفاده

پیش از اندیس‌گذاری در یک آرایه یا رشته، بررسی کنید که نتیجهٔ جست‌وجو یک اندیس قابل استفاده (عدد صحیح `>= 0`) را نشان
می‌دهد تا از استفادهٔ تصادفی از `-1` یا مقادیر غیرعددی جلوگیری شود.

> **نکته برای کاربران TypeScript:**
>
> `isIndexFound` را بعد از عملیات‌هایی مثل `indexOf`، `findIndex` یا جست‌وجوهای سفارشی استفاده کنید که در آن‌ها `-1` (یا
> مقادیر نامعتبر دیگر) می‌تواند به معنی «پیدا نشد» باشد. وقتی مقدار `true` برمی‌گرداند، مقدار یک عدد است و استفاده از آن
> به‌عنوان اندیس آرایه/رشته امن است.

### مزایا

- یک نگهبان نوع ساده فراهم می‌کند تا با بررسی یک عدد صحیح نامنفی تشخیص دهد آیا یک اندیس پیدا شده است یا نه.
- فقط برای مقادیر معتبرِ شبیه اندیس (اعداد صحیح `>= 0`) مقدار `true` برمی‌گرداند و مقادیر منفی، غیرصحیح و غیرعددی را رد
  می‌کند.
- کمک می‌کند هنگام کار با APIهایی که برای «پیدا نشد» مقدار `-1` برمی‌گردانند، از خطاهای یک‌واحدی (off-by-one) و اشتباهات
  مربوط به مقدارهای نشانه‌ای (sentinel) جلوگیری شود.

## نحوه استفاده

### نحو

تابع:

- `isIndexFound(value)`

پارامترها:

- `value`: مقداری که باید بررسی شود آیا یک عدد صحیح نامنفی است یا نه.

### وارد کردن محلی تابع

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  //‎‎ idx اینجا یک عدد است و >= 0 است
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

//‎‎ کاربرد معمول با indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isIndexFound(value)`
