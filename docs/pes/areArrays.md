# areArrays

## توضیحات

`areArrays` تعیین می‌کند آیا یک مقدار، یک آرایهٔ دوبعدیِ پر (غیرخالی) است که همهٔ آیتم‌های آن آرایه هستند یا نه.

### مورد استفاده

از `areArrays` برای اعتبارسنجی ورودی‌های جدولی یا شبیه ماتریس (مثلاً ردیف‌های CSV، داده‌های گرید، یا فهرست‌های
گروه‌بندی‌شده) پیش از انجام عملیات ردیف/ستون استفاده کنید؛ اگر ورودی آرایه نباشد، خالی باشد، یا شامل هر عنصرِ
غیرآرایه‌ای باشد، `false` برمی‌گرداند.

> **نکته برای کاربران TypeScript:**
>
> وقتی لازم دارید مطمئن شوید یک مقدار یک آرایهٔ دوبعدیِ غیرخالی است و هر ردیف آن یک آرایه است، قبل از پیمایش یا
> اندیس‌گذاری در آرایه‌های تو در تو از `areArrays` استفاده کنید.

### مزایا

- اعتبارسنجی می‌کند که ورودی یک آرایهٔ دوبعدیِ غیرخالی است که در آن هر عنصر خودش یک آرایه است.
- یک نتیجهٔ بولیِ ساده (`true`/`false`) برمی‌گرداند که برای گاردها و خروج زودهنگام مناسب است.
- کمک می‌کند از خطاهای زمان اجرا جلوگیری شود وقتی کدهای بعدی فرض می‌کنند عملیات روی آرایه‌های تو در تو انجام می‌شود (
  مثلاً map کردن ردیف‌ها).

## نحوه استفاده

### نحو

تابع:

- `areArrays(array)`

پارامترها:

- `array`: ورودی‌ای که باید بررسی شود.

### وارد کردن محلی تابع

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  //‎‎ value یک آرایهٔ دوبعدی است که عناصر آن آرایه‌ها هستند
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areArrays(array)`
