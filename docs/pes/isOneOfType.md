# isOneOfType

## توضیحات

`isOneOfType` تعیین می‌کند آیا `value` داده‌شده با دست‌کم یکی از رشته‌های نوع ارائه‌شده مطابقت دارد یا نه؛ اگر هر تطابقی
پیدا شود `true` و در غیر این صورت `false` برمی‌گرداند.

### مورد استفاده

اعتبارسنجی داده‌های با نوع‌دهی سست یا خارجی (مثلاً JSON پارس‌شده، پارامترهای کوئری) با اجازه دادن به چند نوع قابل‌قبول
در زمان اجرا (مثل `number` یا `string`) پیش از ادامهٔ منطق بیشتر.

> **نکته برای کاربران TypeScript:**
>
> وقتی می‌خواهید در زمان اجرا بررسی کنید که یک مقدار با هرکدام از چند نوع مجاز مطابقت دارد از `isOneOfType` استفاده
> کنید؛ اگر دست‌کم یک نوع تطابق داشته باشد `true` و در غیر این صورت `false` برمی‌گرداند.

### مزایا

- یک مقدار را در یک فراخوانی واحد در برابر چندین نوع مجاز بررسی می‌کند و با اولین تطابق، `true` برمی‌گرداند.
- با ورودی‌های `unknown` کار می‌کند و آن را در مرزهای زمان اجرا (مثلاً دادهٔ خارجی، ورودی کاربر) مفید می‌سازد.
- یک نتیجهٔ بولی ساده (`true`/`false`) ارائه می‌دهد که به‌خوبی با منطق شرطی و بازگشت‌های زودهنگام ترکیب می‌شود.

## نحوه استفاده

### نحو

تابع:

- `isOneOfType(value, types)`

پارامترها:

- `value`: مقداری که باید در برابر نوع‌های مشخص‌شده بررسی شود.
- `types`: آرایه‌ای از رشته‌های نوع که نوع‌های بالقوهٔ مقدار را نمایش می‌دهند.

### وارد کردن محلی تابع

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  //‎‎ input در زمان اجرا یک شیء است
}

console.log(isOneOfType(3, ["number", "string"])); //‎ درست
console.log(isOneOfType("hello", ["number", "boolean"])); //‎ نادرست

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isOneOfType(value, types)`
