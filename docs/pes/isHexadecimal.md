# isHexadecimal

## توضیحات

`isHexadecimal` بررسی می‌کند که آیا یک مقدار داده‌شده یک لیترال رشته‌ای هگزادسیمال با پیشوند اجباری `0x`/`0X` است یا نه.

### مورد استفاده

از `isHexadecimal` برای اعتبارسنجی مقادیر پیکربندی، فیلدهای payload در API، یا آرگومان‌های CLI که باید به‌صورت
لیترال‌های رشته‌ای هگزادسیمال ارائه شوند (مثلاً شناسه‌ها، ماسک‌ها یا آدرس‌ها) و نباید فاصلهٔ سفیدِ اطراف داشته باشند
استفاده کنید.

> **نکته برای کاربران TypeScript:**
>
> وقتی لازم دارید ورودی کاربر یا دادهٔ سریال‌شده را به‌عنوان یک رشتهٔ لیترال هگزادسیمالِ سخت‌گیرانه (شامل پیشوند `0x`/
`0X`) قبل از پارس یا تبدیل اعتبارسنجی کنید، از `isHexadecimal` استفاده کنید.

### مزایا

- اعتبارسنجی می‌کند که یک مقدار رشته است و با قالب سخت‌گیرانهٔ لیترال هگزادسیمال مطابقت دارد (نیازمند پیشوند `0x`/`0X`).
- رشته‌هایی را که در ابتدا یا انتها فاصلهٔ سفید دارند رد می‌کند و کمک می‌کند از پذیرش ناخواستهٔ ورودیِ پَدشده جلوگیری
  شود.
- از علامت اختیاری پشتیبانی می‌کند و نسبت به بزرگی/کوچکی حروف در پیشوند و ارقام حساس نیست و به‌صورت قابل پیش‌بینی
  `true`/`false` برمی‌گرداند.

## نحوه استفاده

### نحو

تابع:

- `isHexadecimal(value)`

پارامترها:

- `value`: مقداری که باید بررسی شود.

### وارد کردن محلی تابع

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); //‎ درست
isHexadecimal("-0Xff"); //‎ درست
isHexadecimal("1A2B"); //‎ نادرست (پیشوند وجود ندارد)
isHexadecimal(" 0x1A2B"); //‎ نادرست (فاصلهٔ سفید در ابتدا)
isHexadecimal(0x1a2b); //‎ نادرست (رشته نیست)
```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isHexadecimal(value)`
