# isObject

## توضیحات

مشخص می‌کند آیا `value` داده‌شده یک `object` است (به‌جز `null`).

### مورد استفاده

از `isObject` برای اعتبارسنجی ورودی‌های ناشناخته (مثلاً JSON پارس‌شده، پاسخ‌های API، payload رویدادها) قبل از دسترسی به
ویژگی‌ها استفاده کنید تا مطمئن شوید مقدار یک شیء است و `null` نیست.

> **نکته برای کاربران TypeScript:**
>
> `isObject` یک گارد زمان اجرا است که یک مقدار بولی برمی‌گرداند؛ این تابع به یک شکل مشخص از شیء محدودسازی (narrow)
> نمی‌کند. وقتی به تایپ قوی‌تری نیاز دارید، آن را با بررسی‌های اضافی (مثلاً وجود ویژگی‌ها) ترکیب کنید.

### مزایا

- فقط برای مقادیر غیرِ `null` که `typeof` آن‌ها `"object"` است، `true` برمی‌گرداند.
- از دام رایج جاوااسکریپت جلوگیری می‌کند که در آن `null` در غیر این صورت به‌عنوان یک شیء در نظر گرفته می‌شود.
- برای اشیای ساده و نمونه‌های شیء داخلی (برای مثال `Date`، `RegExp`) کار می‌کند.
- یک بررسی ساده و سریع در زمان اجرا که برای برنامه‌نویسی تدافعی و اعتبارسنجی ورودی مناسب است.

## نحوه استفاده

### نحو

تابع:

- `isObject(value)`

پارامترها:

- `value`: مقداری که باید بررسی شود آیا یک `object` است یا نه.

### وارد کردن محلی تابع

```ts
import { isObject } from "@type-check/guards";

const input: unknown = { a: 1 };

if (isObject(input)) {
  //‎‎ input در زمان اجرا یک شیء غیرتهی است
  console.log("Object detected");
} else {
  console.log("Not an object");
}

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.isObject(value)`
