# areJson

## توضیحات

بررسی می‌کند آیا همهٔ عناصرِ یک آرایه رشته‌های JSON هستند یا نه؛ فقط اگر آرایه پر باشد و هر مورد JSON معتبر باشد `true`
برمی‌گرداند؛ در غیر این صورت `false` برمی‌گرداند.

### مورد استفاده

اعتبارسنجی داده‌های ورودی (مثلاً از پارامترهای کوئری، متغیرهای محیطی، یا APIهای خارجی) وقتی انتظار دارید یک آرایه از
رشته‌های کُدگذاری‌شدهٔ JSON داشته باشید و می‌خواهید آرایه‌های خالی یا هر ورودیِ غیر-JSON را رد کنید.

> **نکته برای کاربران TypeScript:**
>
> وقتی لازم دارید قبل از پارس کردن (مثلاً با `JSON.parse`) اعتبارسنجی کنید که یک `unknown[]` فقط شامل رشته‌های JSON است،
> از `areJson` استفاده کنید.

### مزایا

- فقط وقتی `true` برمی‌گرداند که هر عنصر یک رشتهٔ JSON معتبر باشد؛ در غیر این صورت `false` برمی‌گرداند.
- سریع شکست می‌خورد: به‌محض پیدا شدن یک عنصر غیر-JSON بررسی را متوقف می‌کند.
- طبق طراحی آرایه‌های خالی را رد می‌کند و برای ورودیِ پرنشده `false` برمی‌گرداند.

## نحوه استفاده

### نحو

تابع:

- `areJson(array)`

پارامترها:

- `array`: آرایه‌ای که باید از نظر عناصرِ رشتهٔ JSON بررسی شود.

### وارد کردن محلی تابع

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); //‎ درست
const mixed = areJson(["{\"a\":1}", 123 as unknown]); //‎ نادرست
const empty = areJson([]); //‎ نادرست

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areJson(array)`
