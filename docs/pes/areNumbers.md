# areNumbers

## توضیحات

`areNumbers` بررسی می‌کند که آیا یک مقدار، آرایه‌ای غیرخالی است که همهٔ عناصر آن عدد هستند یا نه.

### مورد استفاده

اعتبارسنجی داده‌های ارائه‌شده توسط کاربر یا API برای اطمینان از اینکه یک آرایهٔ غیرخالی از اعداد است، پیش از محاسبهٔ جمع
کل، میانگین یا سایر تجمیع‌های عددی.

> **نکته برای کاربران TypeScript:**
>
> از `areNumbers` برای اعتبارسنجی آرایه‌های ناشناخته قبل از انجام محاسبات عددی استفاده کنید؛ برای آرایه‌های خالی و برای
> آرایه‌هایی که شامل هر مقدار غیرعددی باشند `false` برمی‌گرداند.

### مزایا

- فقط زمانی `true` برمی‌گرداند که ورودی یک آرایهٔ غیرخالی باشد و هر عنصر آن یک عدد باشد.
- با رد کردن آرایه‌های خالی و ورودی‌های غیرآرایه‌ای، از مثبت‌های کاذب جلوگیری می‌کند.
- به‌عنوان یک گارد قبل از عملیات عددی (مثلاً جمع‌زدن، میانگین‌گیری) مفید است تا از خطاهای زمان اجرا جلوگیری شود.

## نحوه استفاده

### نحو

تابع:

- `areNumbers(array)`

پارامترها:

- `array`: آرایه‌ای که باید از نظر داشتن عناصر عددی بررسی شود.

### وارد کردن محلی تابع

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### وارد کردن سراسری شیء

برای وارد کردن توابع به‌عنوان متدهای سراسری شیء از این استفاده کنید:

```ts
import "@type-check/guards/register-global-object.mjs";
```

در این صورت متد زیر به‌صورت سراسری در دسترس خواهد بود:

- `Type.areNumbers(array)`
