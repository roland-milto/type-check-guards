# isArray

## বর্ণনা

`isArray` পরীক্ষা করে প্রদত্ত মানটি অ্যারে কি না এবং অ্যারে হলে `true`, নইলে `false` ফেরত দেয়।

### ব্যবহারের ক্ষেত্র

অজানা ডেটা (যেমন, পার্স করা JSON বা API রেসপন্স) যাচাই করে নিশ্চিত করুন যে কোনো মান অ্যারে, তারপরই ইটারেট করা, ইনডেক্সিং
করা, বা `.length` অ্যাক্সেস করা।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> যখন আপনার অ্যারের জন্য রানটাইম চেক দরকার, তখন `isArray` ব্যবহার করুন; এটি একটি বুলিয়ান ফেরত দেয় এবং `unknown` মানের
> সাথেও নিরাপদে কল করা যায়।

### সুবিধাসমূহ

- বিভিন্ন রিয়ালম (যেমন, iframes) জুড়ে নির্ভরযোগ্যভাবে অ্যারে শনাক্ত করতে বিল্ট-ইন `Array.isArray` ব্যবহার করে।
- গার্ড এবং ব্রাঞ্চিং লজিকের জন্য উপযোগী একটি সহজ বুলিয়ান ফলাফল (`true`/`false`) ফেরত দেয়।
- প্যারামিটারটি `unknown` হওয়ায় যেকোনো ইনপুট টাইপের সাথে কাজ করে।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `isArray(value)`

প্যারামিটার:

- `value`: যে মানটি পরীক্ষা করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  // ইনপুট রানটাইমে একটি অ্যারে
  console.log(input.length);
} else {
  console.log("Not an array");
}

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.isArray(value)`
