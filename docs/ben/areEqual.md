# areEqual

## বর্ণনা

`areEqual` পরীক্ষা করে একটি অ্যারের সব উপাদান প্রদত্ত প্রত্যাশিত মানের সমান কি না; শুধুমাত্র অ-খালি অ্যেরের ক্ষেত্রে,
যেখানে প্রতিটি আইটেম মিলে যায়, তখনই `true` ফেরত দেয়।

### ব্যবহারের ক্ষেত্র

যাচাই করুন যে একটি তালিকায় শুধুমাত্র একটি অনুমোদিত মানই আছে (যেমন, সব স্ট্যাটাস ফ্ল্যাগ `true`, সব রোল `"admin"`, বা সব
সংখ্যাগত এন্ট্রি একটি প্রয়োজনীয় ধ্রুবকের সমান), এবং খালি ইনপুটকে অবৈধ (`false`) হিসেবে গণ্য করুন।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> যখন আপনার কঠোরভাবে সব-আইটেম যাচাই দরকার, তখন `areEqual` ব্যবহার করুন; খালি অ্যারের জন্য এবং যেকোনো non-array বা
> non-filled ইনপুটের জন্য এটি `false` ফেরত দেয়।

### সুবিধাসমূহ

- শুধুমাত্র তখনই `true` ফেরত দেয় যখন প্রতিটি উপাদান প্রত্যাশিত মানের সাথে মিলে যায়; অন্যথায় `false` ফেরত দেয়।
- দ্রুত ব্যর্থ হয়: কোনো অমিল উপাদান পাওয়া মাত্রই পরীক্ষা বন্ধ করে দেয়।
- ইনপুট যদি পূর্ণ (filled) অ্যারে না হয়, তাহলে `false` ফেরত দিয়ে অবৈধ ইনপুট থেকে সুরক্ষা দেয়।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areEqual(value, expected)`

প্যারামিটার:

- `value`: যে অ্যারেটি পরীক্ষা করা হবে।
- `expected`: প্রতিটি অ্যারে আইটেমের সাথে তুলনা করার উপাদান।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areEqual(value, expected)`
