# areNull

## বর্ণনা

প্রদত্ত `array`-এর সব উপাদান `null` কি না তা পরীক্ষা করে।

### ব্যবহারের ক্ষেত্র

কোনো ডেটাসেট কলাম, API ফিল্ড তালিকা, বা প্লেসহোল্ডার অ্যারে-তে কেবল `null` মান আছে কি না যাচাই করুন, তারপর এমন লজিক
প্রয়োগ করুন যা ধরে নেয় সব এন্ট্রি ইচ্ছাকৃতভাবে খালি।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> যখন আপনার একটি কঠোর যাচাই দরকার যে ইনপুটটি একটি নন-এম্পটি অ্যারে এবং প্রতিটি উপাদান ঠিক `null` (না `undefined`, না
> falsy মান), তখন `areNull` ব্যবহার করুন।

### সুবিধাসমূহ

- শুধুমাত্র তখনই `true` ফেরত দেয় যখন প্রতিটি উপাদান `null`, ফলে এটি একটি কঠোর “সব মিলেছে” গার্ড হিসেবে কাজ করে।
- `false` ফেরত দিয়ে নন-অ্যারে এবং খালি অ্যারে প্রত্যাখ্যান করে, ফলে অবৈধ ইনপুটে অনিচ্ছাকৃতভাবে truthy ফলাফল হওয়া রোধ
  করে।
- যে ডেটা সম্পূর্ণভাবে `null` হওয়া আবশ্যক, তা প্রক্রিয়াকরণের আগে প্রিকন্ডিশন চেক হিসেবে ভালোভাবে কাজ করে।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areNull(array)`

প্যারামিটার:

- `array`: `null` উপাদান আছে কি না যাচাই করার জন্য ইনপুট অ্যারে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areNull } from "@type-check/guards";

const a = [null, null];
const b = [null, 1, null];

const allNullA = areNull(a); // সত্য
const allNullB = areNull(b); // মিথ্যা

const notAnArray = areNull(123 as unknown as unknown[]); // মিথ্যা
const empty = areNull([]); // মিথ্যা

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areNull(array)`
