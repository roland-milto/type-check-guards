# areOctals

## বর্ণনা

`areOctals` নির্ধারণ করে প্রদত্ত মানটি বৈধ অক্টাল স্ট্রিংগুলোর একটি খালি-নয় এমন অ্যারে কি না।

### ব্যবহারের ক্ষেত্র

ব্যবহারকারীর ইনপুট, কনফিগারেশন মান, বা API পে-লোড যাচাই করার সময় `areOctals` ব্যবহার করুন—যেখানে অক্টাল লিটারাল (যেমন
ফাইল পারমিশন মোড `0o755`) থাকা আবশ্যক—এবং আপনি খালি অ্যারে বা কোনো অবৈধ এন্ট্রি থাকলে `false` ফেরত দিয়ে তা প্রত্যাখ্যান
করতে চান।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> রূপান্তরের আগে (যেমন `Number(...)` বা কাস্টম পার্সিংয়ের মাধ্যমে) প্রতিটি এন্ট্রি বৈধ অক্টাল স্ট্রিং—এমন একটি খালি-নয়
`unknown[]` আছে কি না নিশ্চিত করতে `areOctals` ব্যবহার করুন।

### সুবিধাসমূহ

- যাচাই করে যে একটি মান একটি খালি-নয় এমন অ্যারে, যেখানে প্রতিটি উপাদান একটি অক্টাল স্ট্রিং; কেবল তখনই `true` ফেরত দেয়
  যখন সব আইটেম পাস করে।
- দ্রুত ব্যর্থ হয়: কোনো অ-অক্টাল উপাদান পাওয়া মাত্রই `false` ফেরত দেয়।
- পার্স বা রূপান্তরের আগে গার্ড হিসেবে উপকারী, যাতে রানটাইম ত্রুটি এবং অসামঞ্জস্যপূর্ণ ইনপুট হ্যান্ডলিং এড়ানো যায়।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areOctals(array)`

প্যারামিটার:

- `array`: যে মানটি পরীক্ষা করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value হলো অক্টাল স্ট্রিংগুলোর একটি খালি-নয় এমন অ্যারে
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areOctals(array)`
