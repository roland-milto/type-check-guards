# areSymbols

## বর্ণনা

ইনপুটটি এমন একটি filled অ্যারে কি না যার উপাদানগুলো সবই সিম্বল—তা পরীক্ষা করে, এবং `true` বা `false` ফেরত দেয়।

### ব্যবহারের ক্ষেত্র

একটি কনফিগারেশন ফিল্ড (যেমন, সিম্বল দ্বারা উপস্থাপিত ইউনিক কী-এর একটি তালিকা) `symbol[]` প্রয়োজন এমন API-তে ব্যবহার
করার আগে সেটি শুধুমাত্র সিম্বলসমৃদ্ধ খালি নয় এমন অ্যারে কি না তা যাচাই করুন।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> `symbol[]` হিসেবে ব্যবহার করার আগে অজানা ইনপুট যাচাই করতে `areSymbols` ব্যবহার করুন; নন-অ্যারে এবং খালি অ্যারের জন্য
> এটি `false` ফেরত দেয়।

### সুবিধাসমূহ

- ইনপুটটি একটি খালি নয় এমন অ্যারে এবং প্রতিটি উপাদান একটি সিম্বল হলে তবেই `true` ফেরত দেয়।
- অভ্যন্তরীণ filled-array চেকের মাধ্যমে নন-অ্যারে এবং খালি অ্যারে প্রত্যাখ্যান করে ভুল পজিটিভ প্রতিরোধ করে।
- পরবর্তী প্রসেসিংয়ের আগে শুধুমাত্র-সিম্বল তালিকা যাচাই করার জন্য রানটাইম টাইপ গার্ড হিসেবে উপকারী।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areSymbols(array)`

প্যারামিটার:

- `array`: সিম্বল উপাদান আছে কি না তা যাচাই করার জন্য যে অ্যারেটি পরীক্ষা করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  // a রানটাইমে শুধুমাত্র সিম্বল-সমৃদ্ধ অ্যারে
  const first = a[0];
  console.log(typeof first); // "symbol"
}

console.log(areSymbols(b)); // false
```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areSymbols(array)`
