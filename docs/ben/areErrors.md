# areErrors

## বর্ণনা

একটি অ্যারে খালি নয় এবং কেবল `Error` অবজেক্টই রয়েছে কি না তা পরীক্ষা করে, `true` বা `false` রিটার্ন করে।

### ব্যবহারের ক্ষেত্র

রানটাইমে প্রাপ্ত `unknown[]` (যেমন একত্রিত ব্যর্থতা, ভ্যালিডেশন ফলাফল, বা ডেসিরিয়ালাইজড ডেটা) ইটারেট করা, লগ করা, বা
পুনরায় থ্রো করার আগে সেটি `Error` অবজেক্টের একটি খালি নয় এমন তালিকা কি না যাচাই করুন।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> `areErrors` কেবল তখনই `true` রিটার্ন করে যখন অ্যারেটি পূর্ণ থাকে এবং প্রতিটি আইটেম একটি `Error`; খালি অ্যারের ক্ষেত্রে
> বা কোনো উপাদান `Error` না হলে এটি `false` রিটার্ন করে।

### সুবিধাসমূহ

- প্রতিটি উপাদান যে একটি `Error` ইনস্ট্যান্স তা নিশ্চিত করে, ফলে নিরাপদভাবে ত্রুটি হ্যান্ডলিং এবং লগিং করা যায়।
- খালি অ্যারে প্রত্যাখ্যান করে, যাতে ভুলবশত “কোনো ত্রুটি নেই” অবস্থাকে বৈধ ত্রুটি তালিকা হিসেবে গণ্য না করা হয়।
- `unknown[]` ইনপুট (যেমন API বা `catch` ব্লক থেকে) নিয়ে কাজ করার সময় এটি একটি রানটাইম গার্ড হিসেবে ভালোভাবে কাজ করে।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areErrors(array)`

প্যারামিটার:

- `array`: `Error` অবজেক্ট আছে কি না যাচাই করার জন্য অ্যারেটি।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areErrors } from "@type-check/guards";

const value: unknown = [new Error("error1"), new TypeError("error2")];

if (Array.isArray(value) && areErrors(value)) {
  // value হলো Error অবজেক্টগুলোর একটি খালি নয় এমন অ্যারে
  for (const err of value) {
    console.error(err.name, err.message);
  }
} else {
  console.log("Not a non-empty Error[]");
}

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areErrors(array)`
