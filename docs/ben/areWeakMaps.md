# areWeakMaps

## বর্ণনা

`areWeakMaps` পরীক্ষা করে কোনো মান একটি নন-এম্পটি অ্যারে কি না যেখানে প্রতিটি উপাদানই `WeakMap`; কেবল সেই ক্ষেত্রেই
`true` রিটার্ন করে, অন্যথায় `false`।

### ব্যবহারের ক্ষেত্র

রানটাইম ডেটা (যেমন, পার্স করা JSON, প্লাগইন ইনপুট, বা ঢিলেঢালা টাইপ করা কনফিগারেশন) যাচাই করুন যাতে ইটারেট করে `WeakMap`
মেথড কল করার আগে নিশ্চিত হওয়া যায় যে এটি `WeakMap` ইনস্ট্যান্সের একটি নন-এম্পটি অ্যারে; কোনো উপাদান `WeakMap` না হলে বা
অ্যারে খালি হলে `false` রিটার্ন করে।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> অজানা ইনপুটকে নন-এম্পটি `WeakMap[]` হিসেবে ব্যবহারের আগে যাচাই করতে `areWeakMaps` ব্যবহার করুন; খালি অ্যারের জন্য এটি
`false` রিটার্ন করে।

### সুবিধাসমূহ

- প্রদত্ত অ্যারের প্রতিটি উপাদান যে একটি `WeakMap` ইনস্ট্যান্স তা নিশ্চিত করে।
- খালি অ্যারের ক্ষেত্রে `false` রিটার্ন করে, ফলে “কোনো ডেটা নেই” ভুলবশত বৈধ ইনপুট হিসেবে গ্রহণ হওয়া প্রতিরোধ করে।
- সব আইটেমের ওপর `WeakMap`-নির্দিষ্ট অপারেশন করার আগে গার্ড হিসেবে উপকারী।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areWeakMaps(array)`

প্যারামিটার:

- `array`: `WeakMap` ইনস্ট্যান্স আছে কি না যাচাই করার জন্য অ্যারে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  // list হলো WeakMap ইনস্ট্যান্সগুলোর একটি খালি নয় এমন অ্যারে
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  // খালি নয় এমন WeakMap[] নয়
}

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areWeakMaps(array)`
