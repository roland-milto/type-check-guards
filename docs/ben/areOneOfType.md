# areOneOfType

## বর্ণনা

`areOneOfType` পরীক্ষা করে যে একটি খালি নয় এমন অ্যারের সব উপাদান নির্দিষ্ট রানটাইম টাইপগুলোর যেকোনো একটির অন্তর্গত কি
না।

### ব্যবহারের ক্ষেত্র

আগত ডেটা (যেমন, পার্স করা JSON) যাচাই করুন যেখানে কোনো ফিল্ড অবশ্যই একটি খালি নয় এমন অ্যারে হবে এবং যার আইটেমগুলো
পরিচিত প্রিমিটিভ টাইপগুলোর একটি নির্দিষ্ট সেটে সীমাবদ্ধ; অ্যারে খালি হলে বা কোনো অননুমোদিত টাইপ থাকলে `false` ফেরত দিন।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> এই ফাংশনটি একটি boolean ফেরত দেয় এবং কম্পাইল টাইমে অ্যারের উপাদান টাইপ সংকুচিত (narrow) করে না; পরবর্তী
> প্রক্রিয়াকরণের আগে রানটাইম যাচাইকরণ ধাপ হিসেবে এটি ব্যবহার করুন।

### সুবিধাসমূহ

- একটি অ্যারের প্রতিটি উপাদান অন্তত একটি অনুমোদিত রানটাইম টাইপের সাথে মেলে তা নিশ্চিত করে; পুরো অ্যারে পাস করলেই কেবল
  `true` ফেরত দেয়।
- অবৈধ ইনপুট দ্রুত বাতিল করে: `array` বা `types` খালি হলে বা পূর্ণ (filled) অ্যারে না হলে `false` ফেরত দেয়।
- মিশ্র-টাইপ সংগ্রহ (যেমন, সংখ্যা এবং স্ট্রিং) যাচাই করতে `areOneOfType`-এ একবার কল করলেই উপকারী।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areOneOfType(array, types)`

প্যারামিটার:

- `array`: প্রদত্ত টাইপগুলোর বিপরীতে যাচাই করার জন্য উপাদানসমূহের একটি অ্যারে।
- `types`: যে ডেটা টাইপগুলোর সাথে মিলিয়ে পরীক্ষা করা হবে সেগুলো নির্দেশকারী স্ট্রিংগুলোর একটি অ্যারে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areOneOfType } from "@type-check/guards";

const values1: unknown[] = [1, "a", true];
const ok1 = areOneOfType(values1, ["number", "string", "boolean"]);

const values2: unknown[] = [1, "a", {}];
const ok2 = areOneOfType(values2, ["number", "string"]);

const values3: unknown[] = [];
const ok3 = areOneOfType(values3, ["number"]);

console.log({ ok1, ok2, ok3 });
```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areOneOfType(array, types)`
