# isEmpty

## বর্ণনা

প্রদত্ত কোনো মান খালি কি না নির্ধারণ করে; `null`, `undefined`, খালি/শুধু ফাঁকা-স্থানযুক্ত স্ট্রিং, খালি অ্যারে, খালি
`Map`/`Set`, অথবা নিজস্ব কোনো enumerable প্রপার্টি নেই এমন অবজেক্টের জন্য `true` ফেরত দেয়।

### ব্যবহারের ক্ষেত্র

একাধিক ডেটা টাইপ জুড়ে ইনপুট ভ্যালিডেট করতে এবং অনুপস্থিত/ফাঁকা মান শনাক্ত করতে `isEmpty` ব্যবহার করুন (যেমন, ফর্ম ফিল্ড,
API পে-লোড, কনফিগারেশন অবজেক্ট), যেখানে `null`, `undefined`, ফাঁকা-স্থানযুক্ত স্ট্রিং, খালি কালেকশন, এবং প্রপার্টি-হীন
অবজেক্টকে খালি হিসেবে গণ্য করা উচিত।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> `isEmpty` একটি বুলিয়ান-রিটার্নিং ইউটিলিটি (TypeScript টাইপ প্রেডিকেট নয়), তাই এটি নিজে থেকে টাইপ ন্যারো করে না;
> কম্পাইল-টাইম ন্যারোইংয়ের বদলে ভ্যালিডেশন/ব্রাঞ্চিংয়ের জন্য এটি ব্যবহার করুন।

### সুবিধাসমূহ

- শূন্যতা যাচাইয়ের ক্ষেত্রে `null` এবং `undefined`-কে `true` হিসেবে গণ্য করে।
- দৈর্ঘ্য যাচাইয়ের আগে ট্রিম করে কেবল ফাঁকা-স্থানযুক্ত স্ট্রিংকে খালি হিসেবে বিবেচনা করে।
- সাধারণ কন্টেইনার টাইপ (অ্যারে, `Map`, `Set`) এবং নিজস্ব কোনো enumerable প্রপার্টি নেই এমন সাধারণ অবজেক্ট সমর্থন করে।
- `hasOwnProperty` যাচাই ব্যবহার করে ইনহেরিটেড প্রপার্টি গণনা করা এড়িয়ে যায়।
- গার্ড এবং ভ্যালিডেশনের জন্য উপযোগী একটি সহজ বুলিয়ান ফলাফল (`true`/`false`) ফেরত দেয়।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `isEmpty(value)`

প্যারামিটার:

- `value`: শূন্যতা (empty) আছে কি না যাচাই করার মান।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.isEmpty(value)`
