# isNaN

## বর্ণনা

স্ট্রিং রূপান্তর না করে প্রদত্ত `value` `number` টাইপের `NaN` কি না তা নির্ধারণ করে।

### ব্যবহারের ক্ষেত্র

অবিশ্বস্ত বা ঢিলেঢালা টাইপযুক্ত ইনপুট (যেমন API payloads, ফর্মের মান, parsed JSON) যাচাই করে বিশেষ `NaN` মানটি শনাক্ত
করা এবং তা স্পষ্টভাবে হ্যান্ডেল করা, একই সাথে অ-সংখ্যা ইনপুটকে `NaN` নয় হিসেবে গণ্য করা।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> ইনপুটটি সত্যিই `number` কিনা নিশ্চিত করে (স্ট্রিং-টু-নাম্বার কনভার্সন ছাড়া) বিশেষ সংখ্যামূল্য `NaN` শনাক্ত করতে হলে
`isNaN` ব্যবহার করুন।

### সুবিধাসমূহ

- অ-সংখ্যা (যেমন স্ট্রিং) মানকে সংখ্যা হিসেবে জোরপূর্বক রূপান্তর না করেই কোনো মান `NaN` কি না তা পরীক্ষা করে।
- `true` কেবল সেই মানগুলোর জন্যই ফেরত দেয় যেগুলো একসাথে `number` টাইপের এবং `NaN`।
- `unknown` ইনপুটের জন্য নিরাপদ এবং ইমপ্লিসিট কনভার্সন থেকে হওয়া ভুল পজিটিভ এড়ায়।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `isNaN(value)`

প্যারামিটার:

- `value`: `number` টাইপের `NaN` কি না তা যাচাই করার জন্য যে মানটি পরীক্ষা করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // সত্য
console.log(isNaN(b)); // মিথ্যা
console.log(isNaN(c)); // মিথ্যা

if (isNaN(a)) {
  // a একটি সংখ্যা এবং বিশেষভাবে NaN
}

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.isNaN(value)`
