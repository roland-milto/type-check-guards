# isBinary

## বর্ণনা

`isBinary` নির্ধারণ করে কোনো মান বাইনারি স্ট্রিং কি না (ঐচ্ছিকভাবে `0b`/`0B` প্রিফিক্সসহ) এবং `true` বা `false` রিটার্ন
করে।

### ব্যবহারের ক্ষেত্র

ব্যবহারকারী-প্রদত্ত স্ট্রিং (যেমন, ফর্ম ফিল্ড, CLI args, কনফিগ মান) যাচাই করুন যাতে নিশ্চিত হওয়া যায় যে সেগুলো শুধুমাত্র
বাইনারি ডিজিট নির্দেশ করে, প্রয়োজনে `0b`/`0B` প্রিফিক্সসহ, পরবর্তী প্রক্রিয়াকরণের আগে।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> স্ট্রিংকে `BigInt`/`Number`-এ পার্স বা কনভার্ট করার আগে অবৈধ ইনপুট এড়াতে টাইপ গার্ড হিসেবে `isBinary` ব্যবহার করুন।

### সুবিধাসমূহ

- `0b`/`0B` প্রিফিক্সসহ বা প্রিফিক্স ছাড়া বাইনারি স্ট্রিং গ্রহণ করে।
- খালি স্ট্রিং এবং শুরু/শেষে হোয়াইটস্পেস (ASCII ≤ 32) থাকা স্ট্রিং প্রত্যাখ্যান করে।
- এক্সসেপশন না ছুঁড়ে `true`/`false` রিটার্ন করে, ফলে অজানা ইনপুটের জন্যও নিরাপদ।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `isBinary(value)`

প্যারামিটার:

- `value`: যে মানটি পরীক্ষা করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // সত্য
const b = isBinary("1010");   // সত্য
const c = isBinary("0b1020"); // মিথ্যা
const d = isBinary(0b1010);     // মিথ্যা

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.isBinary(value)`
