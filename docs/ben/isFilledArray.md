# isFilledArray

## বর্ণনা

`value` অন্তত একটি উপাদানসহ একটি অ্যারে কি না তা পরীক্ষা করে, `true` বা `false` ফেরত দেয়।

### ব্যবহারের ক্ষেত্র

ইটারেট করার আগে, প্রথম উপাদানে অ্যাক্সেস করার আগে, বা অন্তত একটি আইটেম দরকার এমন লজিক প্রয়োগ করার আগে ইনকামিং ডেটা (
যেমন API পে-লোড, ফর্ম ভ্যালু, কনফিগারেশন) যাচাই করতে `isFilledArray` ব্যবহার করুন।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> `isFilledArray` একটি রানটাইম গার্ড যা একটি বুলিয়ান ফেরত দেয়; এটি অ্যারেটি খালি নয় তা নিশ্চিত করার বাইরে উপাদানগুলোর
> টাইপ আরও সংকুচিত করে না।

### সুবিধাসমূহ

- `Array.isArray` এবং দৈর্ঘ্য যাচাই ব্যবহার করে খালি নয় এমন অ্যারের জন্য সহজ, দ্রুত পরীক্ষা।
- কোড যখন ধরে নেয় যে অ্যারেতে অন্তত একটি উপাদান আছে, তখন রানটাইম ত্রুটি এড়াতে সাহায্য করে।
- পরিষ্কার বুলিয়ান ফলাফল: খালি নয় এমন অ্যারের জন্য `true` এবং অন্যথায় `false` ফেরত দেয়।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `isFilledArray(value)`

প্যারামিটার:

- `value`: মানটি খালি নয় এমন অ্যারে কি না তা যাচাই করার জন্য।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { isFilledArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && isFilledArray(input)) {
  // ইনপুট রানটাইমে একটি খালি নয় এমন অ্যারে
  console.log(input[0]);
} else {
  console.log("Not a non-empty array");
}

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.isFilledArray(value)`
