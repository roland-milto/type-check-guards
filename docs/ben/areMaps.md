# areMaps

## বর্ণনা

`areMaps` নির্ধারণ করে কোনো প্রদত্ত অ্যারে খালি নয় কি না এবং এর সব উপাদান `Map` ইনস্ট্যান্স কি না।

### ব্যবহারের ক্ষেত্র

অজানা ইনপুট (যেমন JSON পার্সিং, বাহ্যিক API, বা ডাইনামিক সোর্স থেকে) `Map` অবজেক্টের একটি খালি নয় এমন তালিকা হিসেবে
ব্যবহারের আগে যাচাই করুন।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> খালি অ্যারের জন্য `false` রিটার্ন করে; অ্যারেটি পূর্ণ এবং প্রতিটি উপাদান `Map` হলেই কেবল `true` রিটার্ন করে।

### সুবিধাসমূহ

- প্রতিটি উপাদান যে একটি `Map` ইনস্ট্যান্স তা নিশ্চিত করে; পুরো অ্যারে যাচাই পাস করলেই কেবল `true` রিটার্ন করে।
- ডিজাইন অনুযায়ী খালি অ্যারে প্রত্যাখ্যান করে, ফলে “কোনো ডেটা নেই” ভুলবশত বৈধ ইনপুট হিসেবে গ্রহণ হওয়া রোধ করে।
- `Map`-নির্দিষ্ট অপারেশন (যেমন `.get()`, `.set()`, ইটারেশন) কোনো সংগ্রহের ওপর চালানোর আগে গার্ড হিসেবে উপকারী।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areMaps(array)`

প্যারামিটার:

- `array`: যে অ্যারেটি যাচাই করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // items রানটাইমে Map ইনস্ট্যান্সগুলোর একটি খালি নয় এমন অ্যারে হওয়া নিশ্চিত
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // মিথ্যা হবে: খালি অ্যারের জন্য, অথবা এমন অ্যারের জন্য যাতে কোনো non-Map মান থাকে
}

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areMaps(array)`
