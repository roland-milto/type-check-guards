# isFloat

## বর্ণনা

`isFloat` নির্ধারণ করে প্রদত্ত `value` একটি সসীম ভাসমান-বিন্দু সংখ্যা কি না (অর্থাৎ একটি `number` যা পূর্ণসংখ্যা নয়)।

### ব্যবহারের ক্ষেত্র

যেখানে ভগ্নাংশ মান প্রয়োজন (যেমন দাম, পরিমাপ, হার) সেখানে ব্যবহারকারী-প্রদত্ত সংখ্যাগত ইনপুট যাচাই করুন এবং
পূর্ণসংখ্যা, `NaN`, ও অসীম মান প্রত্যাখ্যান করুন।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> যখন আপনাকে শুধুমাত্র সসীম, পূর্ণসংখ্যা নয় এমন সংখ্যাগত ইনপুট গ্রহণ করতে হবে তখন `isFloat` ব্যবহার করুন; এটি
> পূর্ণসংখ্যা এবং অসসীম/অসীম নয় এমন সংখ্যা প্রত্যাখ্যান করে।

### সুবিধাসমূহ

- শুধুমাত্র সসীম, পূর্ণসংখ্যা নয় এমন সংখ্যার জন্য `true` ফেরত দেয় (পূর্ণসংখ্যা, `NaN`, `Infinity`, এবং `-Infinity` বাদ
  দেয়)।
- যেকোনো ইনপুট টাইপ (`unknown`) এর সাথে কাজ করে এবং `typeof value === "number"` যাচাই করে নিরাপদভাবে টাইপ সংকুচিত করে।
- পূর্বানুমেয় আচরণের জন্য বিল্ট-ইন সংখ্যাগত গার্ড (`Number.isInteger`, `Number.isFinite`) ব্যবহার করে।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `isFloat(value)`

প্যারামিটার:

- `value`: মানটি ভাসমান-বিন্দু সংখ্যা কি না তা যাচাই করার জন্য।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { isFloat } from "@type-check/guards";

const inputs: unknown[] = [3.14, -0.1, 1e-7, 42, "3.14", NaN, Infinity];

for (const value of inputs) {
  if (isFloat(value)) {
    // মানটি রানটাইমে একটি সংখ্যা; এটি সসীম এবং পূর্ণসংখ্যা নয়
    const rounded = value.toFixed(2);
    console.log("float:", value, "rounded:", rounded);
  } else {
    console.log("not a float:", value);
  }
}

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.isFloat(value)`
