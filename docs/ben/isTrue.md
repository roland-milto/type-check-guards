# isTrue

## বর্ণনা

`isTrue` নির্ধারণ করে কোনো প্রদত্ত মান `true`-এর সাথে কঠোরভাবে সমান কি না।

### ব্যবহারের ক্ষেত্র

ফ্ল্যাগ, ফিচার টগল, বা কনফিগারেশন মান যাচাই করতে `isTrue` ব্যবহার করুন, যেখানে কেবল লিটারাল `true`-ই গ্রহণযোগ্য এবং অন্য
সবকিছুকে `false` হিসেবে গণ্য করতে হবে।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> যখন আপনাকে কেবল বুলিয়ান লিটারাল `true` গ্রহণ করতে হবে, শুধু ট্রুথি মান নয়, তখন `isTrue` ব্যবহার করুন।

### সুবিধাসমূহ

- বুলিয়ান লিটারাল `true`-এর জন্য কঠোর যাচাই প্রদান করে (কোনো কোয়েরশন নয়)।
- `true`-কে `1`, `"true"`, বা `{}`-এর মতো ট্রুথি মান থেকে আলাদা করতে সাহায্য করে।
- গার্ড এবং ভ্যালিডেশন পাইপলাইনের জন্য উপযোগী সহজ, পূর্বানুমেয় আচরণ।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `isTrue(value)`

প্যারামিটার:

- `value`: যে মানটি যাচাই করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // সত্য
const b = isTrue(1);         // মিথ্যা
const c = isTrue("true");   // মিথ্যা

if (isTrue(a)) {
  // এখানে a সত্য
}
```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.isTrue(value)`
