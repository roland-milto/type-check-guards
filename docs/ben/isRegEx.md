# isRegEx

## বর্ণনা

প্রদত্ত কোনো মান `RegExp` ইনস্ট্যান্স কি না তা নির্ধারণ করে।

### ব্যবহারের ক্ষেত্র

ব্যবহারকারী-প্রদত্ত বা ডাইনামিক মান (যেমন কনফিগারেশন, API পে-লোড, প্লাগইন ইনপুট) রেগুলার এক্সপ্রেশন হিসেবে ব্যবহারের আগে
যাচাই করুন।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> RegExp-নির্দিষ্ট প্রপার্টি বা মেথড ব্যবহার করার আগে `unknown` (বা ইউনিয়ন) মানকে সংকুচিত করতে `isRegEx` ব্যবহার করুন;
> এটি কেবলমাত্র `RegExp`-এর ইনস্ট্যান্স এমন মানের জন্যই `true` ফেরত দেয়।

### সুবিধাসমূহ

- কোনো মান `RegExp` কি না তা যাচাই করার জন্য একটি সহজ রানটাইম টাইপ গার্ড প্রদান করে।
- কোড যখন একটি রেগুলার এক্সপ্রেশন প্রত্যাশা করে (যেমন `test`, `exec` কল করার আগে, বা `source` পড়ার আগে) তখন ত্রুটি
  প্রতিরোধে সহায়তা করে।
- `/regex/` লিটারাল এবং `new RegExp(...)` দিয়ে তৈরি ইনস্ট্যান্স—উভয়ের সাথেই কাজ করে।
- নন-রেজেক্স ইনপুটের ক্ষেত্রে থ্রো না করে একটি স্পষ্ট বুলিয়ান ফলাফল (`true`/`false`) ফেরত দেয়।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `isRegEx(value)`

প্যারামিটার:

- `value`: যে মানটি যাচাই করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  // এখানে input একটি RegExp
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.isRegEx(value)`
