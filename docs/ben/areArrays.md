# areArrays

## বর্ণনা

`areArrays` নির্ধারণ করে কোনো মান একটি পূর্ণ (খালি নয়) দ্বিমাত্রিক অ্যারে কি না, যার সব আইটেমই অ্যারে।

### ব্যবহারের ক্ষেত্র

সারি/কলাম অপারেশন করার আগে ট্যাবুলার বা ম্যাট্রিক্স-সদৃশ ইনপুট (যেমন, CSV সারি, গ্রিড ডেটা, বা গ্রুপ করা তালিকা) যাচাই
করতে `areArrays` ব্যবহার করুন; ইনপুটটি অ্যারে না হলে, খালি হলে, বা কোনো নন-অ্যারে উপাদান থাকলে এটি `false` ফেরত দেয়।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> যখন কোনো মান খালি নয় এমন 2D অ্যারে কি না এবং প্রতিটি সারি একটি অ্যারে কি না নিশ্চিত করে তারপর নেস্টেড অ্যারেতে ইটারেট
> বা ইনডেক্স করতে হয়, তখন `areArrays` ব্যবহার করুন।

### সুবিধাসমূহ

- ইনপুটটি একটি খালি নয় এমন দ্বিমাত্রিক অ্যারে কি না যাচাই করে, যেখানে প্রতিটি উপাদানই একটি অ্যারে।
- গার্ড এবং দ্রুত প্রস্থান (early exit)-এর জন্য উপযোগী একটি সহজ বুলিয়ান ফলাফল (`true`/`false`) ফেরত দেয়।
- পরবর্তী কোডে নেস্টেড অ্যারে অপারেশন (যেমন, সারি ম্যাপ করা) ধরে নেওয়া হলে রানটাইম ত্রুটি প্রতিরোধে সহায়তা করে।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areArrays(array)`

প্যারামিটার:

- `array`: যে ইনপুটটি পরীক্ষা করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value হলো উপাদান হিসেবে অ্যারে থাকা একটি ২ডি অ্যারে
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areArrays(array)`
