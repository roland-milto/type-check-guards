# isIndexFound

## বর্ণনা

`isIndexFound` নির্ধারণ করে প্রদত্ত মানটি অ-ঋণাত্মক পূর্ণসংখ্যা কি না, যা নির্দেশ করে একটি ইনডেক্স পাওয়া গেছে।

### ব্যবহারের ক্ষেত্র

কোনো সার্চ ফলাফল ব্যবহারযোগ্য ইনডেক্স (পূর্ণসংখ্যা `>= 0`) কি না যাচাই করুন, তারপর অ্যারে বা স্ট্রিং-এ ইনডেক্সিং
করুন—এতে ভুলবশত `-1` বা অ-সংখ্যা মান ব্যবহার হওয়া প্রতিরোধ হয়।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> `indexOf`, `findIndex`, বা কাস্টম সার্চের মতো অপারেশনের পরে `isIndexFound` ব্যবহার করুন, যেখানে `-1` (বা অন্যান্য অবৈধ
> মান) “পাওয়া যায়নি” নির্দেশ করতে পারে। এটি `true` ফেরত দিলে, মানটি একটি সংখ্যা এবং অ্যারে/স্ট্রিং ইনডেক্স হিসেবে
> ব্যবহার
> করা নিরাপদ।

### সুবিধাসমূহ

- একটি সহজ টাইপ গার্ড প্রদান করে, যা অ-ঋণাত্মক পূর্ণসংখ্যা কিনা তা যাচাই করে কোনো ইনডেক্স পাওয়া গেছে কি না শনাক্ত করে।
- শুধুমাত্র বৈধ ইনডেক্স-সদৃশ মানের (পূর্ণসংখ্যা `>= 0`) জন্য `true` ফেরত দেয়; ঋণাত্মক, অ-পূর্ণসংখ্যা এবং অ-সংখ্যা মান
  প্রত্যাখ্যান করে।
- যেসব API “পাওয়া যায়নি” বোঝাতে `-1` ফেরত দেয়, সেগুলোর সাথে কাজ করার সময় অফ-বাই-ওয়ান এবং সেন্টিনেল-ভ্যালু সংক্রান্ত ভুল
  এড়াতে সাহায্য করে।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `isIndexFound(value)`

প্যারামিটার:

- `value`: অ-ঋণাত্মক পূর্ণসংখ্যা কিনা তা যাচাই করার জন্য মানটি।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // এখানে idx একটি সংখ্যা এবং এটি >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// indexOf সহ সাধারণ ব্যবহার
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.isIndexFound(value)`
