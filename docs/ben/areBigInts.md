# areBigInts

## বর্ণনা

`areBigInts` নির্ধারণ করে কোনো মানটি কি শুধুমাত্র `bigint` মানসমূহ ধারণকারী একটি নন-এম্পটি অ্যারে কিনা।

### ব্যবহারের ক্ষেত্র

অজানা ইনপুট (যেমন, পার্স করা JSON-সদৃশ ডেটা, API পে-লোড, বা `unknown` হিসেবে টাইপ করা ফাংশন প্যারামিটার) যাচাই করুন যাতে
প্রসেস করার আগে নিশ্চিত হওয়া যায় এটি `bigint` মানসমূহের একটি নন-এম্পটি অ্যারে; সব উপাদান `bigint` হলে তবেই `true`,
নইলে `false` ফেরত দেয়।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> অজানা ইনপুটের ওপর `bigint`-শুধু অপারেশন (যেমন, গাণিতিক ক্রিয়া, তুলনা) করার আগে রানটাইম গার্ড হিসেবে `areBigInts`
> ব্যবহার করুন।

### সুবিধাসমূহ

- প্রতিটি উপাদান `bigint` কিনা তা নিশ্চিত করে; পুরো অ্যারেটি মিললেই কেবল `true` ফেরত দেয়।
- ডিজাইন অনুযায়ী নন-অ্যারে এবং খালি অ্যারে প্রত্যাখ্যান করে (`isFilledArray` এর মাধ্যমে), ফলে ভুলবশত অবৈধ ইনপুট গ্রহণ
  হওয়া প্রতিরোধ করে।
- দ্রুত ব্যর্থতা: কোনো নন-`bigint` উপাদান পাওয়া মাত্রই `false` ফেরত দেয়।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areBigInts(array)`

প্যারামিটার:

- `array`: যে মানটি পরীক্ষা করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areBigInts } from "@type-check/guards";

const a: unknown = [10n, 20n];
const b: unknown = [10n, 20];
const c: unknown = [];

console.log(areBigInts(a)); // সত্য
console.log(areBigInts(b)); // মিথ্যা
console.log(areBigInts(c)); // মিথ্যা
```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areBigInts(array)`
