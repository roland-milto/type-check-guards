# isOneOfType

## বর্ণনা

`isOneOfType` নির্ধারণ করে প্রদত্ত `value` কি সরবরাহকৃত টাইপ স্ট্রিংগুলোর অন্তত একটির সাথে মেলে কিনা; কোনো মিল পাওয়া
গেলে `true` এবং না হলে `false` ফেরত দেয়।

### ব্যবহারের ক্ষেত্র

ঢিলেঢালা-টাইপড বা বাহ্যিক ডেটা (যেমন, পার্স করা JSON, কুয়েরি প্যারামিটার) যাচাই করুন—পরবর্তী লজিকে এগোনোর আগে একাধিক
গ্রহণযোগ্য রানটাইম টাইপ (যেমন `number` বা `string`) অনুমোদন করে।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> যখন আপনি রানটাইমে পরীক্ষা করতে চান যে কোনো একটি মান একাধিক অনুমোদিত টাইপের যেকোনোটির সাথে মেলে কিনা, তখন `isOneOfType`
> ব্যবহার করুন; অন্তত একটি টাইপ মিললে এটি `true`, নইলে `false` ফেরত দেয়।

### সুবিধাসমূহ

- একটি মাত্র কলেই একটি মানকে একাধিক অনুমোদিত টাইপের বিরুদ্ধে পরীক্ষা করে, প্রথম মিল পেলেই `true` ফেরত দেয়।
- `unknown` ইনপুটের সাথেও কাজ করে, ফলে রানটাইম বাউন্ডারিতে (যেমন, বাহ্যিক ডেটা, ব্যবহারকারীর ইনপুট) এটি উপকারী।
- সহজ বুলিয়ান ফলাফল (`true`/`false`) যা শর্তাধীন লজিক এবং আগেভাগে রিটার্নের সাথে ভালোভাবে কম্পোজ হয়।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `isOneOfType(value, types)`

প্যারামিটার:

- `value`: নির্দিষ্ট টাইপগুলোর বিরুদ্ধে পরীক্ষা করার জন্য মানটি।
- `types`: মানটির সম্ভাব্য টাইপগুলোকে প্রতিনিধিত্বকারী টাইপ স্ট্রিংগুলোর একটি অ্যারে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // রানটাইমে input একটি অবজেক্ট
}

console.log(isOneOfType(3, ["number", "string"])); // সত্য
console.log(isOneOfType("hello", ["number", "boolean"])); // মিথ্যা

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.isOneOfType(value, types)`
