# areJson

## বর্ণনা

একটি অ্যারের সব উপাদান JSON স্ট্রিং কি না তা পরীক্ষা করে; অ্যারেটি পূর্ণ এবং প্রতিটি আইটেম বৈধ JSON হলেই `true` ফেরত
দেয়; অন্যথায় `false` ফেরত দেয়।

### ব্যবহারের ক্ষেত্র

আগত ডেটা (যেমন query params, environment variables, বা external APIs থেকে) যাচাই করুন যেখানে আপনি JSON-এনকোডেড
স্ট্রিংয়ের একটি অ্যারে প্রত্যাশা করেন এবং খালি অ্যারে বা কোনো অ-JSON এন্ট্রি প্রত্যাখ্যান করতে চান।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> `areJson` ব্যবহার করুন যখন `unknown[]`-এ থাকা উপাদানগুলো পার্স করার আগে (যেমন `JSON.parse` দিয়ে) নিশ্চিত হতে চান যে
> সেগুলো শুধুই JSON স্ট্রিং।

### সুবিধাসমূহ

- শুধুমাত্র তখনই `true` ফেরত দেয় যখন প্রতিটি উপাদান একটি বৈধ JSON স্ট্রিং; অন্যথায় `false` ফেরত দেয়।
- দ্রুত ব্যর্থ হয়: কোনো অ-JSON উপাদান পাওয়া মাত্রই পরীক্ষা বন্ধ করে দেয়।
- নকশাগতভাবে খালি অ্যারে প্রত্যাখ্যান করে, ইনপুটে কোনো উপাদান না থাকলে `false` ফেরত দেয়।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areJson(array)`

প্যারামিটার:

- `array`: JSON স্ট্রিং উপাদান আছে কি না তা যাচাই করার জন্য যে অ্যারেটি পরীক্ষা করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // সত্য
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // মিথ্যা
const empty = areJson([]); // মিথ্যা

```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areJson(array)`
