# isHexadecimal

## বর্ণনা

`isHexadecimal` পরীক্ষা করে কোনো প্রদত্ত মান বাধ্যতামূলক `0x`/`0X` প্রিফিক্সসহ একটি হেক্সাডেসিমাল স্ট্রিং লিটারাল কি না।

### ব্যবহারের ক্ষেত্র

কনফিগারেশন মান, API পে-লোড ফিল্ড, বা CLI আর্গুমেন্ট যাচাই করতে `isHexadecimal` ব্যবহার করুন—যেগুলো অবশ্যই হেক্সাডেসিমাল
স্ট্রিং লিটারাল (যেমন, ID, মাস্ক, বা অ্যাড্রেস) হিসেবে প্রদান করতে হবে এবং আশেপাশে কোনো ফাঁকা স্থান থাকতে পারবে না।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> ইউজার ইনপুট বা সিরিয়ালাইজড ডেটাকে পার্স বা কনভার্ট করার আগে কঠোর হেক্সাডেসিমাল লিটারাল স্ট্রিং (যার মধ্যে `0x`/`0X`
> প্রিফিক্স অন্তর্ভুক্ত) হিসেবে যাচাই করতে হলে `isHexadecimal` ব্যবহার করুন।

### সুবিধাসমূহ

- যাচাই করে যে একটি মান একটি স্ট্রিং এবং কঠোর হেক্সাডেসিমাল লিটারাল ফরম্যাটের সাথে মেলে (অবশ্যই `0x`/`0X` প্রিফিক্স
  থাকতে হবে)।
- শুরুর বা শেষের ফাঁকা স্থানসহ স্ট্রিং প্রত্যাখ্যান করে, ফলে প্যাড করা ইনপুট ভুলবশত গ্রহণ হওয়া এড়াতে সাহায্য করে।
- ঐচ্ছিক সাইন সমর্থন করে এবং প্রিফিক্স ও অঙ্কগুলোর ক্ষেত্রে কেস-ইনসেনসিটিভ, পূর্বানুমেয়ভাবে `true`/`false` রিটার্ন করে।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `isHexadecimal(value)`

প্যারামিটার:

- `value`: যে মানটি যাচাই করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // সত্য
isHexadecimal("-0Xff"); // সত্য
isHexadecimal("1A2B"); // মিথ্যা (প্রিফিক্স অনুপস্থিত)
isHexadecimal(" 0x1A2B"); // মিথ্যা (শুরুর ফাঁকা স্থান)
isHexadecimal(0x1a2b); // মিথ্যা (স্ট্রিং নয়)
```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.isHexadecimal(value)`
