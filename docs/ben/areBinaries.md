# areBinaries

## বর্ণনা

প্রদত্ত মানটি বৈধ বাইনারি স্ট্রিংগুলির একটি অ-খালি অ্যারে কি না তা পরীক্ষা করে এবং সব আইটেম যাচাই পাস করলেই কেবল `true`
ফেরত দেয়।

### ব্যবহারের ক্ষেত্র

যখন আপনি একটি অজানা তালিকা (যেমন JSON, ফর্ম, বা API থেকে) পান এবং পার্স বা প্রক্রিয়াকরণের আগে নিশ্চিত হতে চান যে এটি
বাইনারি স্ট্রিংগুলির একটি অ-খালি অ্যারে, তখন `areBinaries` ব্যবহার করুন।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> বাইনারি স্ট্রিংগুলোকে সংখ্যা/BigInts-এ রূপান্তর করার আগে অজানা ইনপুট যাচাই করতে `areBinaries` ব্যবহার করুন; এটি
> নিশ্চিত করে যে অ্যারেটি অ-খালি এবং প্রতিটি উপাদান একটি বৈধ বাইনারি স্ট্রিং।

### সুবিধাসমূহ

- যাচাই করে যে একটি মান একটি অ-খালি অ্যারে, যেখানে প্রতিটি উপাদান একটি বৈধ বাইনারি স্ট্রিং।
- গার্ড, আগাম রিটার্ন এবং ইনপুট যাচাইয়ের জন্য উপযোগী একটি সহজ বুলিয়ান ফলাফল (`true`/`false`) ফেরত দেয়।
- যে অ্যারেগুলিতে কোনো অ-বাইনারি এন্ট্রি থাকে সেগুলি প্রত্যাখ্যান করে পরবর্তী ধাপের পার্সিং ত্রুটি প্রতিরোধ করে।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areBinaries(array)`

প্যারামিটার:

- `array`: যে মানটি যাচাই করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // সত্য
console.log(areBinaries(b)); // মিথ্যা
console.log(areBinaries([])); // মিথ্যা
```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areBinaries(array)`
