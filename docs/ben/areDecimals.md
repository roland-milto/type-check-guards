# areDecimals

## বর্ণনা

একটি অ্যারের সব উপাদান দশমিক সংখ্যা কিনা এবং অ্যারেটি পূর্ণ (খালি নয়) কিনা পরীক্ষা করে, `true` বা `false` ফেরত দেয়।

### ব্যবহারের ক্ষেত্র

ব্যবহারকারী-প্রদত্ত তালিকা (যেমন, CSV কলাম বা ফর্ম ইনপুট) যাচাই করে নিশ্চিত করুন যে অ্যারেটি খালি নয় এবং পার্সিং বা
গণনার আগে প্রতিটি এন্ট্রি একটি দশমিক মান।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> `unknown[]` যে খালি নয় এবং প্রতিটি উপাদানই দশমিক উপস্থাপনা—এটি দ্রুত বুলিয়ানভাবে যাচাই করতে হলে `areDecimals`
> ব্যবহার করুন।

### সুবিধাসমূহ

- আইটেম যাচাই করার আগে ইনপুটটি পূর্ণ (খালি নয়) অ্যারে কিনা নিশ্চিত করে, ফলে ভুলবশত খালি তালিকা গ্রহণ হওয়া রোধ করে।
- `isDecimal` দিয়ে প্রতিটি উপাদান যাচাই করে, তাই মিশ্র বা অবৈধ মান থাকলে সঙ্গে সঙ্গে `false` ফলাফল দেয়।
- গার্ড এবং আগেভাগে রিটার্ন-ভিত্তিক যাচাই প্রবাহের জন্য উপযোগী একটি সহজ বুলিয়ান ফলাফল (`true`/`false`) প্রদান করে।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areDecimals(array)`

প্যারামিটার:

- `array`: যে অ্যারেটি পরীক্ষা করা হবে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // সত্য
console.log(areDecimals(b)); // মিথ্যা
console.log(areDecimals(c)); // মিথ্যা
```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areDecimals(array)`
