# areNaNs

## বর্ণনা

`areNaNs` যাচাই করে একটি অ্যারের সব উপাদান `NaN` কি না এবং শুধুমাত্র তখনই `true` ফেরত দেয় যখন প্রতিটি উপাদান `NaN`।

### ব্যবহারের ক্ষেত্র

ইনকামিং ডেটা যাচাই করুন যেখানে `NaN` একটি sentinel মান হিসেবে ব্যবহৃত হয় এবং আপনাকে নিশ্চিত করতে হবে যে পুরো অ্যারেটি
একচেটিয়াভাবে `NaN` দিয়েই গঠিত (যেমন, সম্পূর্ণ অনুপস্থিত সংখ্যাগত সিরিজ শনাক্ত করা)।

> **TypeScript ব্যবহারকারীদের জন্য ইঙ্গিত:**
>
> যখন আপনাকে যাচাই করতে হবে যে একটি অ্যারেতে শুধুমাত্র সংখ্যাগত `NaN` মানই আছে (স্ট্রিং-টু-নাম্বার coercion ছাড়া), তখন
`areNaNs` ব্যবহার করুন।

### সুবিধাসমূহ

- শুধুমাত্র তখনই `true` ফেরত দেয় যখন প্রতিটি উপাদানই `NaN` (কঠোর সব-উপাদান যাচাই)।
- স্ট্রিংকে সংখ্যায় রূপান্তর (coerce) করে না; "NaN"-এর মতো মানগুলো `NaN` নয়ই থাকে এবং ফলাফলকে `false` করে।
- অপূর্ণ (non-filled) অ্যারের জন্য `false` ফেরত দেয়, ফলে খালি ইনপুটে ভুলবশত `true` হওয়া প্রতিরোধ করে।

## ব্যবহার

### সিনট্যাক্স

ফাংশন:

- `areNaNs(array)`

প্যারামিটার:

- `array`: `NaN` মান আছে কি না যাচাই করার জন্য অ্যারে।

### লোকাল ফাংশন ইমপোর্ট

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // সত্য
const b = areNaNs([NaN, 1, NaN]); // মিথ্যা
const c = areNaNs([NaN, "NaN", NaN]); // মিথ্যা
const d = areNaNs([NaN, null, NaN]); // মিথ্যা
const e = areNaNs([] as unknown[]); // মিথ্যা
```

### গ্লোবাল অবজেক্ট ইমপোর্ট

ফাংশনগুলোকে গ্লোবাল অবজেক্ট মেথড হিসেবে ইমপোর্ট করতে ব্যবহার করুন:

```ts
import "@type-check/guards/register-global-object.mjs";
```

তাহলে নিম্নলিখিত মেথডটি গ্লোবালি উপলব্ধ হবে:

- `Type.areNaNs(array)`
