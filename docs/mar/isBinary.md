# isBinary

## वर्णन

`isBinary` एखादे मूल्य बायनरी स्ट्रिंग आहे का (पर्यायी `0b`/`0B` उपसर्गासह) हे ठरवते आणि `true` किंवा `false` परत करते.

### वापर प्रकरण

वापरकर्त्याने दिलेल्या स्ट्रिंग्स (उदा., फॉर्म फील्ड्स, CLI args, कॉन्फिग मूल्ये) यांची पडताळणी करा, जेणेकरून पुढील
प्रक्रिया करण्यापूर्वी त्या फक्त बायनरी अंक दर्शवतात आणि पर्यायाने `0b`/`0B` उपसर्गासह आहेत याची खात्री होईल.

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> स्ट्रिंगचे `BigInt`/`Number` मध्ये पार्सिंग किंवा रूपांतरण करण्यापूर्वी अवैध इनपुट टाळण्यासाठी `isBinary` ला टाइप
> गार्ड म्हणून वापरा.

### फायदे

- `0b`/`0B` उपसर्गासह किंवा त्याशिवाय बायनरी स्ट्रिंग्स स्वीकारते.
- रिकाम्या स्ट्रिंग्स आणि सुरुवातीला/शेवटी व्हाइटस्पेस (ASCII ≤ 32) असलेल्या स्ट्रिंग्स नाकारते.
- अपवाद न फेकता `true`/`false` परत करते, त्यामुळे अज्ञात इनपुटसाठी सुरक्षित आहे.

## वापर

### सिंटॅक्स

फंक्शन:

- `isBinary(value)`

पॅरामीटर्स:

- `value`: तपासायचे मूल्य.

### लोकल फंक्शन इम्पोर्ट

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // खरे
const b = isBinary("1010");   // खरे
const c = isBinary("0b1020"); // खोटे
const d = isBinary(0b1010);     // खोटे

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन्स ग्लोबल ऑब्जेक्ट मेथड्स म्हणून इम्पोर्ट करण्यासाठी वापरा:

```ts

```

यानंतर खालील मेथड ग्लोबली उपलब्ध असेल:

- `Type.isBinary(value)`
