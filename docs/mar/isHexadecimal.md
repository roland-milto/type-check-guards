# isHexadecimal

## वर्णन

`isHexadecimal` दिलेले मूल्य अनिवार्य `0x`/`0X` उपसर्ग असलेले हेक्साडेसिमल स्ट्रिंग लिटरल आहे की नाही ते तपासते.

### वापर प्रकरण

कॉन्फिगरेशन मूल्ये, API पेलोड फील्ड्स, किंवा CLI आर्ग्युमेंट्स जे हेक्साडेसिमल स्ट्रिंग लिटरल्स (उदा., IDs, masks, किंवा
addresses) म्हणूनच दिलेले असणे आवश्यक आहे आणि ज्यात आजूबाजूला व्हाइटस्पेस नसावा, यांची पडताळणी करण्यासाठी
`isHexadecimal` वापरा.

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> पार्स किंवा कन्व्हर्ट करण्यापूर्वी वापरकर्ता इनपुट किंवा सिरिअलाइझ्ड डेटा कठोर हेक्साडेसिमल लिटरल स्ट्रिंग ( `0x`/`0X`
> उपसर्गासह) म्हणून पडताळायचा असेल तेव्हा `isHexadecimal` वापरा.

### फायदे

- एखादे मूल्य स्ट्रिंग आहे आणि कठोर हेक्साडेसिमल लिटरल स्वरूपाशी जुळते याची पडताळणी करते ( `0x`/`0X` उपसर्ग आवश्यक).
- सुरुवातीला किंवा शेवटी व्हाइटस्पेस असलेल्या स्ट्रिंग्स नाकारते, त्यामुळे पॅड केलेला इनपुट चुकून स्वीकारला जाणे
  टाळण्यास मदत होते.
- ऐच्छिक चिन्हाला समर्थन देते आणि उपसर्ग व अंकांसाठी केस-इन्सेन्सिटिव्ह आहे, `true`/`false` अंदाजे पद्धतीने परत करते.

## वापर

### सिंटॅक्स

फंक्शन:

- `isHexadecimal(value)`

पॅरामीटर्स:

- `value`: तपासायचे मूल्य.

### लोकल फंक्शन इम्पोर्ट

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // खरे
isHexadecimal("-0Xff"); // खरे
isHexadecimal("1A2B"); // खोटे (उपसर्ग नाही)
isHexadecimal(" 0x1A2B"); // खोटे (सुरुवातीला पांढरी जागा)
isHexadecimal(0x1a2b); // खोटे (स्ट्रिंग नाही)
```
