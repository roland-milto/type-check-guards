# areNaNs

## वर्णन

`areNaNs` अ‍ॅरेमधील सर्व घटक `NaN` आहेत का हे तपासते आणि प्रत्येक घटक `NaN` असेल तेव्हाच `true` परत करते.

### वापर प्रकरण

येणारा डेटा पडताळा जिथे `NaN` हे sentinel मूल्य म्हणून वापरले जाते आणि संपूर्ण अ‍ॅरेमध्ये फक्त `NaN`च आहेत याची खात्री
करणे आवश्यक असते (उदा., पूर्णपणे missing असलेली संख्यात्मक मालिका ओळखणे).

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> स्ट्रिंग-टू-नंबर coercion न करता एखाद्या अ‍ॅरेमध्ये फक्त संख्यात्मक `NaN` मूल्यच आहे याची पडताळणी करायची असेल तेव्हा
`areNaNs` वापरा.

### फायदे

- फक्त तेव्हाच `true` परत करते जेव्हा प्रत्येक घटक `NaN` असतो (कठोर सर्व-घटक तपासणी).
- स्ट्रिंग्सना संख्यांमध्ये जबरदस्तीने रूपांतरित करत नाही; "NaN" सारखी मूल्ये non-`NaN`च राहतात आणि निकाल `false` करतात.
- भरलेली नसलेल्या अ‍ॅरेसाठी `false` परत करते, त्यामुळे रिकाम्या इनपुटवर चुकून `true` होणे टाळले जाते.

## वापर

### सिंटॅक्स

फंक्शन:

- `areNaNs(array)`

पॅरामीटर्स:

- `array`: `NaN` मूल्यांसाठी तपासायचा अ‍ॅरे.

### लोकल फंक्शन इम्पोर्ट

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // खरे
const b = areNaNs([NaN, 1, NaN]); // खोटे
const c = areNaNs([NaN, "NaN", NaN]); // खोटे
const d = areNaNs([NaN, null, NaN]); // खोटे
const e = areNaNs([] as unknown[]); // खोटे
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन्स ग्लोबल ऑब्जेक्ट मेथड्स म्हणून इम्पोर्ट करण्यासाठी वापरा:

```ts

```

यानंतर खालील मेथड ग्लोबली उपलब्ध असेल:

- `Type.areNaNs(array)`
