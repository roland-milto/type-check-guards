# isSet

## वर्णन

दिलेल्या मूल्याचे `Set` आहे की नाही हे ठरवते.

### वापर प्रकरण

बाह्य स्रोतांमधून (उदा., JSON parsing, वापरकर्ता इनपुट, किंवा तृतीय-पक्ष API) येणारे इनपुट्स पडताळा, जेणेकरून `Set`
ऑपरेशन्स करण्यापूर्वी मूल्य `Set` आहे याची खात्री होईल.

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> `.add`, `.has`, किंवा `.size` सारख्या `Set`-विशिष्ट API कॉल करण्यापूर्वी `unknown` मूल्ये संकुचित (narrow) करण्यासाठी
`isSet` वापरा.

### फायदे

- एखादे मूल्य `Set` आहे की नाही हे निश्चित करण्यासाठी सोपी रनटाइम तपासणी प्रदान करते.
- मूल्य `Set` नसताना लवकर शाखांकन (branching) करण्याची परवानगी देऊन प्रकार त्रुटी (type errors) टाळण्यास मदत करते.
- कोणत्याही `Set` मधील सामग्रीसोबत (रिकामे किंवा भरलेले) कार्य करते आणि सातत्याने `true`/`false` परत करते.

## वापर

### सिंटॅक्स

फंक्शन:

- `isSet(value)`

पॅरामीटर्स:

- `value`: तपासण्यासाठीचे मूल्य.

### लोकल फंक्शन इम्पोर्ट

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // a रनटाइममध्ये Set आहे
  console.log(a.size);
}

console.log(isSet(b)); // खोटे
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन्स ग्लोबल ऑब्जेक्ट मेथड्स म्हणून इम्पोर्ट करण्यासाठी वापरा:

```ts
import "@type-check/guards/register-global-object.mjs";
```

यानंतर खालील मेथड ग्लोबली उपलब्ध असेल:

- `Type.isSet(value)`
