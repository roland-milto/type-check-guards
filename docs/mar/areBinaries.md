# areBinaries

## वर्णन

दिलेलं मूल्य वैध बायनरी स्ट्रिंग्सचा न-रिकामा अ‍ॅरे आहे का हे तपासते आणि सर्व घटक पडताळणी पास झाल्यासच `true` परत करते.

### वापर प्रकरण

अज्ञात यादी (उदा., JSON, फॉर्म्स किंवा APIs मधून) मिळाल्यावर आणि पार्स/प्रोसेस करण्यापूर्वी ती बायनरी स्ट्रिंग्सचा
न-रिकामा अ‍ॅरे आहे याची खात्री करायची असेल तेव्हा `areBinaries` वापरा.

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> बायनरी स्ट्रिंग्सना numbers/BigInts मध्ये रूपांतरित करण्यापूर्वी अज्ञात इनपुटची पडताळणी करण्यासाठी `areBinaries`
> वापरा; हे अ‍ॅरे न-रिकामे आहे आणि प्रत्येक घटक वैध बायनरी स्ट्रिंग आहे याची खात्री करते.

### फायदे

- एखादे मूल्य न-रिकामे अ‍ॅरे आहे आणि त्यातील प्रत्येक घटक वैध बायनरी स्ट्रिंग आहे याची पडताळणी करते.
- गार्ड्स, लवकर परतावा (early returns) आणि इनपुट पडताळणीसाठी योग्य असा साधा बूलियन निकाल (`true`/`false`) परत करते.
- कोणतीही नॉन-बायनरी नोंद असलेले अ‍ॅरे नाकारून पुढील टप्प्यातील पार्सिंग त्रुटी टाळते.

## वापर

### सिंटॅक्स

फंक्शन:

- `areBinaries(array)`

पॅरामीटर्स:

- `array`: तपासायचे मूल्य.

### लोकल फंक्शन इम्पोर्ट

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // खरे
console.log(areBinaries(b)); // खोटे
console.log(areBinaries([])); // खोटे
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन्स ग्लोबल ऑब्जेक्ट मेथड्स म्हणून इम्पोर्ट करण्यासाठी वापरा:

```ts
import "@type-check/guards/register-global-object.mjs";
```

यानंतर खालील मेथड ग्लोबली उपलब्ध असेल:

- `Type.areBinaries(array)`
