# areDecimals

## वर्णन

अ‍ॅरेमधील सर्व घटक दशांश संख्या आहेत का आणि अ‍ॅरे भरलेला आहे का हे तपासते, आणि `true` किंवा `false` परत करते.

### वापर प्रकरण

वापरकर्त्याने दिलेल्या याद्या (उदा., CSV स्तंभ किंवा फॉर्म इनपुट्स) पडताळण्यासाठी, पार्सिंग किंवा गणना करण्यापूर्वी
अ‍ॅरे रिकामा नाही आणि प्रत्येक नोंद दशांश मूल्य आहे याची खात्री करा.

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> `unknown[]` रिकामा नाही आणि प्रत्येक घटक दशांश प्रतिनिधित्व आहे याची जलद बूलियन तपासणी हवी असेल तेव्हा `areDecimals`
> वापरा.

### फायदे

- घटकांची पडताळणी करण्यापूर्वी इनपुट भरलेला अ‍ॅरे आहे याची खात्री करते, त्यामुळे रिकाम्या याद्या चुकून स्वीकारल्या
  जाण्यापासून प्रतिबंध होतो.
- `isDecimal` सह प्रत्येक घटकाची पडताळणी करते, त्यामुळे मिश्रित किंवा अवैध मूल्यांमुळे त्वरित `false` परिणाम मिळतो.
- गार्ड्स आणि लवकर-परत (early-return) पडताळणी प्रवाहांसाठी योग्य असा सोपा बूलियन परिणाम (`true`/`false`) देते.

## वापर

### सिंटॅक्स

फंक्शन:

- `areDecimals(array)`

पॅरामीटर्स:

- `array`: तपासायचा अ‍ॅरे.

### लोकल फंक्शन इम्पोर्ट

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // खरे
console.log(areDecimals(b)); // खोटे
console.log(areDecimals(c)); // खोटे
```
