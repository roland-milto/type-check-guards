# isTrue

## वर्णन

`isTrue` दिलेले मूल्य `true` शी कडकपणे समान आहे की नाही हे ठरवते.

### वापर प्रकरण

फ्लॅग्स, फीचर टॉगल्स, किंवा कॉन्फिगरेशन मूल्ये व्हॅलिडेट करण्यासाठी `isTrue` वापरा, जिथे फक्त लिटरल `true` स्वीकारले
पाहिजे आणि इतर सर्व गोष्टी `false` म्हणून हाताळल्या पाहिजेत.

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> फक्त बूलियन लिटरल `true` स्वीकारायचे असेल, केवळ truthy मूल्ये नाही, तेव्हा `isTrue` वापरा.

### फायदे

- बूलियन लिटरल `true` साठी कडक तपासणी प्रदान करते (कोअर्शन नाही).
- `1`, `"true"`, किंवा `{}` यांसारख्या truthy मूल्यांपासून `true` वेगळे ओळखण्यास मदत करते.
- गार्ड्स आणि व्हॅलिडेशन पाइपलाइन्ससाठी योग्य असे सोपे, अंदाज करता येण्यासारखे वर्तन.

## वापर

### सिंटॅक्स

फंक्शन:

- `isTrue(value)`

पॅरामीटर्स:

- `value`: तपासण्यासाठीचे मूल्य.

### लोकल फंक्शन इम्पोर्ट

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // खरे
const b = isTrue(1);         // खोटे
const c = isTrue("true");   // खोटे

if (isTrue(a)) {
  // इथे a खरे आहे
}
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन्स ग्लोबल ऑब्जेक्ट मेथड्स म्हणून इम्पोर्ट करण्यासाठी वापरा:

```ts
import "@type-check/guards/register-global-object.mjs";
```

यानंतर खालील मेथड ग्लोबली उपलब्ध असेल:

- `Type.isTrue(value)`
