# areOctals

## वर्णन

`areOctals` दिलेले मूल्य वैध ऑक्टल स्ट्रिंग्सच्या नॉन-एम्प्टी अ‍ॅरे आहे की नाही हे ठरवते.

### वापर प्रकरण

वापरकर्ता इनपुट, कॉन्फिगरेशन मूल्ये, किंवा API पेलोड्स पडताळताना `areOctals` वापरा, जेथे ऑक्टल लिटरल्स (उदा., `0o755`
सारखे फाइल परवानगी मोड्स) असणे आवश्यक आहे, आणि तुम्हाला रिकामे अ‍ॅरे किंवा कोणतीही अवैध एंट्री आढळल्यास `false` परत करून
नाकारायचे आहे.

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> कन्व्हर्ट करण्यापूर्वी (उदा., `Number(...)` किंवा कस्टम पार्सिंगद्वारे) तुमच्याकडे प्रत्येक एंट्री वैध ऑक्टल स्ट्रिंग
> असलेला नॉन-एम्प्टी `unknown[]` आहे याची खात्री करण्यासाठी `areOctals` वापरा.

### फायदे

- एखादे मूल्य नॉन-एम्प्टी अ‍ॅरे आहे का आणि त्यातील प्रत्येक घटक ऑक्टल स्ट्रिंग आहे का हे पडताळते; सर्व आयटम्स पास
  झाल्यावरच `true` परत करते.
- लवकर अपयशी ठरते: नॉन-ऑक्टल घटक आढळताच लगेच `false` परत करते.
- रनटाइम त्रुटी आणि विसंगत इनपुट हाताळणी टाळण्यासाठी ऑक्टल स्ट्रिंग्स पार्स किंवा कन्व्हर्ट करण्यापूर्वी गार्ड म्हणून
  उपयुक्त.

## वापर

### सिंटॅक्स

फंक्शन:

- `areOctals(array)`

पॅरामीटर्स:

- `array`: तपासण्यासाठीचे मूल्य.

### लोकल फंक्शन इम्पोर्ट

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value हा ऑक्टल स्ट्रिंग्सचा रिकामा नसलेला अ‍ॅरे आहे
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन्स ग्लोबल ऑब्जेक्ट मेथड्स म्हणून इम्पोर्ट करण्यासाठी वापरा:

```ts
import "@type-check/guards/register-global-object.mjs";
```

यानंतर खालील मेथड ग्लोबली उपलब्ध असेल:

- `Type.areOctals(array)`
