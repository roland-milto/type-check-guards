# isDecimal

## वर्णन

`isDecimal` तपासते की एखादे मूल्य हे सुरुवात/शेवटी व्हाइटस्पेस नसलेले आणि वैध दशांश फॉरमॅट असलेले दशांश स्ट्रिंग
प्रतिनिधित्व आहे का.

### वापर प्रकरण

पार्स किंवा स्टोअर करण्यापूर्वी, कोणताही भोवतालचा व्हाइटस्पेस नसलेला दशांश स्ट्रिंग (ऐच्छिकपणे साइनसह) म्हणूनच दिला जाणे
आवश्यक असलेल्या फॉर्म फील्ड्स, API पेलोड्स किंवा कॉन्फिगरेशन व्हॅल्यूजची पडताळणी करा.

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> `Number(value)` सारख्या पद्धतीने रूपांतर करण्यापूर्वी वापरकर्ता इनपुटची पडताळणी करण्यासाठी `isDecimal` वापरा, विशेषतः
> जेव्हा व्हाइटस्पेस नाकारणे आवश्यक असते.

### फायदे

- इनपुट स्ट्रिंग आहे आणि दशांश-लिटरल नमुन्याशी जुळते याची काटेकोर पडताळणी करते.
- अस्पष्ट पार्सिंग टाळण्यासाठी सुरुवातीचा आणि शेवटचा व्हाइटस्पेस (कंट्रोल कॅरेक्टर्ससह) नाकारते.
- regex चालवण्यापूर्वी जलद प्री-चेक्स (टाइप चेक आणि पहिला/शेवटचा कॅरेक्टर) करते.
- गार्ड्स आणि इनपुट व्हॅलिडेशनसाठी योग्य असा साधा boolean निकाल (`true`/`false`) परत करते.

## वापर

### सिंटॅक्स

फंक्शन:

- `isDecimal(value)`

पॅरामीटर्स:

- `value`: दशांश स्ट्रिंग फॉरमॅटसाठी तपासायचे मूल्य.

### लोकल फंक्शन इम्पोर्ट

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v इथे स्ट्रिंग आहे (रनटाइम-प्रमाणित)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन्स ग्लोबल ऑब्जेक्ट मेथड्स म्हणून इम्पोर्ट करण्यासाठी वापरा:

```ts
import "@type-check/guards/register-global-object.mjs";
```

यानंतर खालील मेथड ग्लोबली उपलब्ध असेल:

- `Type.isDecimal(value)`
