# areJson

## वर्णन

अॅरेमधील सर्व घटक JSON स्ट्रिंग आहेत का ते तपासते; अॅरे भरलेला असेल आणि प्रत्येक आयटम वैध JSON असेल तरच `true` परत करते;
अन्यथा `false` परत करते.

### वापर प्रकरण

येणारा डेटा (उदा., query params, environment variables, किंवा external APIs मधून) वैध ठरवा, जिथे तुम्हाला JSON-एन्कोडेड
स्ट्रिंग्सचा अॅरे अपेक्षित आहे आणि रिकामे अॅरे किंवा कोणतीही नॉन-JSON नोंद नाकारायची आहे.

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> `unknown[]` मध्ये फक्त JSON स्ट्रिंग्स आहेत याची खात्री करून त्यांना (उदा., `JSON.parse` सह) पार्स करण्यापूर्वी वैधता
> तपासण्यासाठी `areJson` वापरा.

### फायदे

- फक्त तेव्हाच `true` परत करते जेव्हा प्रत्येक घटक वैध JSON स्ट्रिंग असतो; अन्यथा `false` परत करते.
- जलद अपयश: नॉन-JSON घटक आढळताच तपासणी थांबवते.
- डिझाइननुसार रिकामे अॅरे नाकारते; भरलेले नसलेल्या इनपुटसाठी `false` परत करते.

## वापर

### सिंटॅक्स

फंक्शन:

- `areJson(array)`

पॅरामीटर्स:

- `array`: JSON स्ट्रिंग घटकांसाठी तपासायचा अॅरे.

### लोकल फंक्शन इम्पोर्ट

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // खरे
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // खोटे
const empty = areJson([]); // खोटे

```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन्स ग्लोबल ऑब्जेक्ट मेथड्स म्हणून इम्पोर्ट करण्यासाठी वापरा:

```ts
import "@type-check/guards/register-global-object.mjs";
```

यानंतर खालील मेथड ग्लोबली उपलब्ध असेल:

- `Type.areJson(array)`
