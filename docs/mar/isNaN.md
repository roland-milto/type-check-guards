# isNaN

## वर्णन

स्ट्रिंग्स रूपांतरित न करता दिलेले `value` हे `number` प्रकारातील `NaN` आहे का ते ठरवते.

### वापर प्रकरण

अविश्वसनीय किंवा सैल टाइप केलेले इनपुट (उदा. API payloads, form values, parsed JSON) वैध ठरवून विशेष `NaN` मूल्य ओळखणे
आणि ते स्पष्टपणे हाताळणे, तसेच नॉन-नंबर इनपुटना `NaN` नसल्याप्रमाणे वागवणे.

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> इनपुट खरोखरच `number` आहे याची खात्री ठेवत (स्ट्रिंग-टू-नंबर रूपांतरण न करता) विशेष संख्यात्मक मूल्य `NaN` ओळखायचे
> असेल तेव्हा `isNaN` वापरा.

### फायदे

- नॉन-नंबर (उदा. स्ट्रिंग्स) मूल्यांना नंबरमध्ये जबरदस्तीने रूपांतरित न करता एखादे मूल्य `NaN` आहे का ते तपासते.
- `true` फक्त त्या मूल्यांसाठी परत करते जे `number` प्रकाराचेही आहेत आणि `NaN` सुद्धा आहेत.
- `unknown` इनपुटसाठी सुरक्षित आहे आणि अप्रत्यक्ष रूपांतरणांमुळे होणारे चुकीचे पॉझिटिव्ह टाळते.

## वापर

### सिंटॅक्स

फंक्शन:

- `isNaN(value)`

पॅरामीटर्स:

- `value`: `number` प्रकारातील `NaN` आहे का हे तपासण्यासाठीचे मूल्य.

### लोकल फंक्शन इम्पोर्ट

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // खरे
console.log(isNaN(b)); // खोटे
console.log(isNaN(c)); // खोटे

if (isNaN(a)) {
  // a हा एक संख्या आहे आणि विशेषतः NaN आहे
}
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन्स ग्लोबल ऑब्जेक्ट मेथड्स म्हणून इम्पोर्ट करण्यासाठी वापरा:

```ts
import "@type-check/guards/register-global-object.mjs";
```

यानंतर खालील मेथड ग्लोबली उपलब्ध असेल:

- `Type.isNaN(value)`
