# areSets

## वर्णन

दिलेल्या न-रिकाम्या अॅरेमध्ये फक्त `Set` इन्स्टन्सेस आहेत का ते तपासते; असल्यास `true` आणि अन्यथा `false` परत करते.

### वापर प्रकरण

प्रत्येक सेट प्रक्रिया करण्यापूर्वी एखादे मूल्य (उदा., वापरकर्ता इनपुट, JSON पार्सिंग, किंवा बाह्य APIs मधून) हे `Set`
ऑब्जेक्ट्सचे न-रिकामे अॅरे आहे याची पडताळणी करा.

> **TypeScript वापरकर्त्यांसाठी सूचना:**
>
> प्रत्येक घटकावर `Set` APIs (उदा., `.size`, `.has`, `.add`) कॉल करण्यापूर्वी अज्ञात इनपुटची पडताळणी करण्यासाठी
`areSets` वापरा.

### फायदे

- इनपुट न-रिकामा अॅरे असून प्रत्येक घटक `Set` चा इन्स्टन्स असेल तेव्हाच `true` परत करते.
- अॅरेमध्ये कोणतेही घटक नसतील तर `false` परत करून रिकाम्या अॅरेसाठी चुकीचे पॉझिटिव्ह टाळते.
- प्रत्येक घटकावर `Set`-विशिष्ट ऑपरेशन्स करण्यापूर्वी रनटाइम गार्ड म्हणून उपयुक्त.

## वापर

### सिंटॅक्स

फंक्शन:

- `areSets(array)`

पॅरामीटर्स:

- `array`: `Set` इन्स्टन्सेससाठी तपासायचा अॅरे.

### लोकल फंक्शन इम्पोर्ट

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  // a हे रनटाइमला Set इन्स्टन्सेसचे अॅरे आहे
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); // खोटे
console.log(areSets(c)); // खोटे
```

### ग्लोबल ऑब्जेक्ट इम्पोर्ट

फंक्शन्स ग्लोबल ऑब्जेक्ट मेथड्स म्हणून इम्पोर्ट करण्यासाठी वापरा:

```ts
import "@type-check/guards/register-global-object.mjs";
```

यानंतर खालील मेथड ग्लोबली उपलब्ध असेल:

- `Type.areSets(array)`
