# areNumbers

## คำอธิบาย

`areNumbers` ตรวจสอบว่าค่าเป็นอาร์เรย์ที่ไม่ว่างซึ่งทุกองค์ประกอบเป็นตัวเลขหรือไม่

### กรณีการใช้งาน

ตรวจสอบข้อมูลที่ผู้ใช้ให้มาหรือข้อมูลจาก API เพื่อให้แน่ใจว่าเป็นอาร์เรย์ของตัวเลขที่ไม่ว่างก่อนคำนวณผลรวม ค่าเฉลี่ย
หรือการรวมเชิงตัวเลขอื่น ๆ

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areNumbers` เพื่อตรวจสอบความถูกต้องของอาร์เรย์ที่ไม่ทราบชนิดก่อนทำการคำนวณเชิงตัวเลข; ฟังก์ชันนี้จะคืนค่า `false`
> สำหรับอาร์เรย์ว่างและสำหรับอาร์เรย์ที่มีค่าใด ๆ ที่ไม่ใช่ตัวเลข

### ข้อดี

- คืนค่า `true` เฉพาะเมื่ออินพุตเป็นอาร์เรย์ที่ไม่ว่างและทุกองค์ประกอบเป็นตัวเลข
- ป้องกันผลบวกลวงโดยปฏิเสธอาร์เรย์ว่างและอินพุตที่ไม่ใช่อาร์เรย์
- มีประโยชน์ในการใช้เป็นการ์ดก่อนการดำเนินการเชิงตัวเลข (เช่น การหาผลรวม การหาค่าเฉลี่ย)
  เพื่อหลีกเลี่ยงข้อผิดพลาดขณะรันไทม์

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areNumbers(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบว่าองค์ประกอบเป็นตัวเลขหรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areNumbers } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && areNumbers(input)) {
  const total = input.reduce((sum, n) => sum + n, 0);
  console.log(total);
} else {
  console.log("Not a non-empty number array");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areNumbers(array)`
