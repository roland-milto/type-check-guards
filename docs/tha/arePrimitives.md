# arePrimitives

## คำอธิบาย

`arePrimitives` ประเมินว่าองค์ประกอบทั้งหมดในอาร์เรย์ที่ระบุและไม่ว่างเป็นชนิดค่าปฐมภูมิหรือไม่

### กรณีการใช้งาน

ตรวจสอบความถูกต้องว่าข้อมูลที่เข้ามา (เช่น พารามิเตอร์คิวรี ค่าแถว CSV หรือรายการของ ID/แท็ก)
มีเฉพาะค่าปฐมภูมิก่อนทำการซีเรียลไลซ์ แฮช บันทึกล็อก หรือส่งต่อไปยัง API ที่ต้องไม่รับอ็อบเจ็กต์

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `arePrimitives` เมื่อคุณต้องการให้แน่ใจว่า `unknown[]` มีเฉพาะค่าปฐมภูมิ (string, number, bigint, boolean, symbol,
> undefined หรือ null) ก่อนการประมวลผลเพิ่มเติม

### ข้อดี

- คืนค่า `true` เฉพาะเมื่อทุกองค์ประกอบเป็นค่าปฐมภูมิ ทำให้เป็นตัวป้องกันแบบเข้มงวดสำหรับอาร์เรย์ที่
  “ไม่มีอ็อบเจ็กต์/ฟังก์ชัน”
- ล้มเหลวอย่างรวดเร็ว: คืนค่า `false` ทันทีที่พบองค์ประกอบที่ไม่ใช่ค่าปฐมภูมิ
- คืนค่า `false` เช่นกันสำหรับค่าที่ไม่ใช่อาร์เรย์และอาร์เรย์ว่าง (ผ่านการตรวจสอบว่าเป็นอาร์เรย์ที่มีข้อมูล)
  เพื่อป้องกันการยอมรับอินพุตที่ไม่ถูกต้องโดยไม่ตั้งใจ

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `arePrimitives(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบว่าองค์ประกอบเป็นชนิดค่าปฐมภูมิหรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { arePrimitives } from "@type-check/guards";

const a: unknown[] = [1, "string", true];
const b: unknown[] = [null, undefined, Symbol("x")];
const c: unknown[] = [1, {}, false];

const r1 = arePrimitives(a); // จริง
const r2 = arePrimitives(b); // จริง
const r3 = arePrimitives(c); // เท็จ
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.arePrimitives(array)`
