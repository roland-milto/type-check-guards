# areErrors

## คำอธิบาย

ตรวจสอบว่าอาร์เรย์ไม่ว่างและมีเฉพาะอ็อบเจ็กต์ `Error` เท่านั้น โดยคืนค่า `true` หรือ `false`

### กรณีการใช้งาน

ตรวจสอบว่า `unknown[]` ที่ได้มาขณะรันไทม์ (เช่น ความล้มเหลวที่ถูกรวบรวม ผลการตรวจสอบความถูกต้อง
หรือข้อมูลที่ถูกดีซีเรียลไลซ์) เป็นรายการของอ็อบเจ็กต์ `Error` ที่ไม่ว่าง ก่อนทำการวนลูป บันทึกล็อก หรือโยนข้อผิดพลาดซ้ำ

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> `areErrors` จะคืนค่า `true` เฉพาะสำหรับอาร์เรย์ที่มีข้อมูลและทุกรายการเป็น `Error`; จะคืนค่า `false`
> สำหรับอาร์เรย์ว่าง หรือหากมีองค์ประกอบใดไม่ใช่ `Error`

### ข้อดี

- รับประกันว่าแต่ละองค์ประกอบเป็นอินสแตนซ์ของ `Error` ทำให้จัดการข้อผิดพลาดและบันทึกล็อกได้อย่างปลอดภัย
- ปฏิเสธอาร์เรย์ว่าง ป้องกันไม่ให้สถานะ “ไม่มีข้อผิดพลาด” ถูกมองว่าเป็นรายการข้อผิดพลาดที่ถูกต้องโดยไม่ตั้งใจ
- ทำงานได้ดีในฐานะตัวตรวจสอบ (runtime guard) เมื่อจัดการอินพุตแบบ `unknown[]` (เช่น จาก API หรือบล็อก `catch`)

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areErrors(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่ต้องการตรวจสอบว่าเป็นอ็อบเจ็กต์ `Error` หรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areErrors } from "@type-check/guards";

const value: unknown = [new Error("error1"), new TypeError("error2")];

if (Array.isArray(value) && areErrors(value)) {
  // value เป็นอาร์เรย์ที่ไม่ว่างของอ็อบเจ็กต์ Error
  for (const err of value) {
    console.error(err.name, err.message);
  }
} else {
  console.log("Not a non-empty Error[]");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areErrors(array)`
