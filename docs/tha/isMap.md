# isMap

## คำอธิบาย

ตรวจสอบว่า `value` ที่กำหนดเป็น `Map` หรือไม่ โดยคืนค่า `true` หากเป็น และ `false` หากไม่ใช่

### กรณีการใช้งาน

ใช้ `isMap` เมื่อคุณได้รับค่าชนิด `unknown` (เช่น จากการพาร์ส JSON, API ภายนอก หรืออินพุตจากผู้ใช้)
และต้องการให้แน่ใจว่ามันเป็น `Map` ก่อนทำการดำเนินการของ `Map`

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> `isMap` เป็นการ์ดขณะรันไทม์ที่คืนค่า `true` เมื่อค่านั้นเป็น `Map` และคืนค่า `false` ในกรณีอื่น ๆ; ใช้มันเพื่อทำให้
`unknown` แคบลงก่อนเรียกใช้ API ของ `Map`

### ข้อดี

- ให้การตรวจสอบขณะรันไทม์อย่างรวดเร็วว่า ค่านั้นเป็น `Map` หรือไม่
- ช่วยป้องกันข้อผิดพลาดของชนิดข้อมูลโดยการป้องกันเส้นทางโค้ดที่ต้องใช้เมธอดของ `Map` เช่น `get`, `set` และ `has`
- ทำงานได้ดีในฐานะขั้นตอนการตรวจสอบความถูกต้องแบบเบา ๆ เมื่อจัดการอินพุตชนิด `unknown`

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isMap(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isMap } from "@type-check/guards";

const input: unknown = new Map<string, number>([["a", 1]]);

if (isMap(input)) {
  input.set("b", 2);
  const a = input.get("a");
  console.log(a);
} else {
  console.log("Not a Map");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isMap(value)`
