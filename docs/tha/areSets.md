# areSets

## คำอธิบาย

ตรวจสอบว่าอาร์เรย์ที่ไม่ว่างที่กำหนดมีเฉพาะอินสแตนซ์ของ `Set` เท่านั้นหรือไม่ โดยคืนค่า `true` หากใช่ และ `false`
หากไม่ใช่

### กรณีการใช้งาน

ตรวจสอบว่าค่า (เช่น จากอินพุตผู้ใช้, การแยกวิเคราะห์ JSON หรือ API ภายนอก) เป็นอาร์เรย์ที่ไม่ว่างของอ็อบเจ็กต์ `Set`
ก่อนประมวลผลแต่ละเซ็ต

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areSets` เพื่อตรวจสอบความถูกต้องของอินพุตที่ไม่ทราบก่อนทำการวนลูปและเรียกใช้ API ของ `Set` (เช่น `.size`, `.has`,
`.add`) กับแต่ละองค์ประกอบ

### ข้อดี

- คืนค่า `true` เฉพาะเมื่ออินพุตเป็นอาร์เรย์ที่ไม่ว่างและทุกองค์ประกอบเป็นอินสแตนซ์ของ `Set`
- ป้องกันผลบวกลวงสำหรับอาร์เรย์ว่างโดยคืนค่า `false` เมื่ออาร์เรย์ไม่มีองค์ประกอบ
- มีประโยชน์เป็นตัวตรวจสอบขณะรันไทม์ก่อนทำการดำเนินการเฉพาะของ `Set` กับแต่ละองค์ประกอบ

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areSets(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบว่าเป็นอินสแตนซ์ของ `Set` หรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areSets } from "@type-check/guards";

const a = [new Set(), new Set([1, 2]), new Set()];
const b = [new Set(), {}, new Set([1, 2])];
const c: unknown[] = [];

if (areSets(a)) {
  // a เป็นอาร์เรย์ของอินสแตนซ์ Set ในขณะรันไทม์
  for (const s of a) {
    console.log(s.size);
  }
}

console.log(areSets(b)); // เท็จ
console.log(areSets(c)); // เท็จ
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areSets(array)`
