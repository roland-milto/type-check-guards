# areBinaries

## คำอธิบาย

ตรวจสอบว่าค่าที่ให้มาเป็นอาร์เรย์ที่ไม่ว่างเปล่าของสตริงไบนารีที่ถูกต้องหรือไม่ และจะคืนค่า `true`
ก็ต่อเมื่อทุกรายการผ่านการตรวจสอบ

### กรณีการใช้งาน

ใช้ `areBinaries` เมื่อคุณได้รับรายการที่ไม่ทราบแน่ชัด (เช่น จาก JSON, ฟอร์ม หรือ API)
และต้องการให้แน่ใจว่าเป็นอาร์เรย์ของสตริงไบนารีที่ไม่ว่างเปล่าก่อนทำการแยกวิเคราะห์หรือประมวลผล

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areBinaries` เพื่อตรวจสอบอินพุตที่ไม่ทราบแน่ชัดก่อนแปลงสตริงไบนารีเป็นตัวเลข/BigInts;
> ฟังก์ชันนี้ช่วยให้มั่นใจว่าอาร์เรย์ไม่ว่างเปล่าและทุกองค์ประกอบเป็นสตริงไบนารีที่ถูกต้อง

### ข้อดี

- ตรวจสอบว่าค่าเป็นอาร์เรย์ที่ไม่ว่างเปล่า และทุกองค์ประกอบเป็นสตริงไบนารีที่ถูกต้อง
- คืนค่าผลลัพธ์แบบบูลีนอย่างง่าย (`true`/`false`) เหมาะสำหรับการทำ guard, การคืนค่าก่อน (early return)
  และการตรวจสอบความถูกต้องของอินพุต
- ป้องกันข้อผิดพลาดในการแยกวิเคราะห์ในขั้นตอนถัดไป โดยปฏิเสธอาร์เรย์ที่มีรายการที่ไม่ใช่ไบนารีอยู่แม้เพียงรายการเดียว

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areBinaries(array)`

พารามิเตอร์:

- `array`: ค่าที่ต้องการตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areBinaries } from "@type-check/guards";

const a = ["0b1010", "1101"];
const b = ["1010", "1020"];

console.log(areBinaries(a)); // จริง
console.log(areBinaries(b)); // เท็จ
console.log(areBinaries([])); // เท็จ
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areBinaries(array)`
