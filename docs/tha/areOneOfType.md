# areOneOfType

## คำอธิบาย

`areOneOfType` ตรวจสอบว่าองค์ประกอบทั้งหมดในอาร์เรย์ที่ไม่ว่างเปล่าเป็นหนึ่งในชนิดข้อมูลขณะรันไทม์ที่ระบุหรือไม่

### กรณีการใช้งาน

ตรวจสอบข้อมูลที่เข้ามา (เช่น JSON ที่ถูกพาร์ส)
ซึ่งฟิลด์หนึ่งต้องเป็นอาร์เรย์ที่ไม่ว่างเปล่าและรายการภายในถูกจำกัดให้เป็นชุดชนิดข้อมูลพื้นฐานที่ทราบแน่ชัด; คืนค่า
`false` เมื่ออาร์เรย์ว่างหรือมีชนิดข้อมูลที่ไม่อนุญาตอยู่ภายใน

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ฟังก์ชันนี้คืนค่าเป็นบูลีนและไม่ทำให้ชนิดขององค์ประกอบในอาร์เรย์แคบลงในช่วงคอมไพล์ไทม์;
> ใช้เป็นขั้นตอนตรวจสอบขณะรันไทม์ก่อนการประมวลผลเพิ่มเติม

### ข้อดี

- รับประกันว่าแต่ละองค์ประกอบในอาร์เรย์ตรงกับอย่างน้อยหนึ่งชนิดข้อมูลขณะรันไทม์ที่อนุญาต โดยจะคืนค่า `true`
  ก็ต่อเมื่อทั้งอาร์เรย์ผ่านการตรวจสอบทั้งหมด
- ปฏิเสธอินพุตที่ไม่ถูกต้องตั้งแต่เนิ่น ๆ: คืนค่า `false` เมื่อ `array` หรือ `types` ว่างเปล่า
  หรือไม่ใช่อาร์เรย์ที่มีข้อมูล
- มีประโยชน์สำหรับการตรวจสอบคอลเลกชันที่มีหลายชนิดข้อมูลปะปนกัน (เช่น ตัวเลขและสตริง) ด้วยการเรียก `areOneOfType`
  เพียงครั้งเดียว

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areOneOfType(array, types)`

พารามิเตอร์:

- `array`: อาร์เรย์ขององค์ประกอบที่จะตรวจสอบเทียบกับชนิดข้อมูลที่ให้มา
- `types`: อาร์เรย์ของสตริงที่แทนชนิดข้อมูลเพื่อใช้ตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areOneOfType } from "@type-check/guards";

const values1: unknown[] = [1, "a", true];
const ok1 = areOneOfType(values1, ["number", "string", "boolean"]);

const values2: unknown[] = [1, "a", {}];
const ok2 = areOneOfType(values2, ["number", "string"]);

const values3: unknown[] = [];
const ok3 = areOneOfType(values3, ["number"]);

console.log({ ok1, ok2, ok3 });
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areOneOfType(array, types)`
