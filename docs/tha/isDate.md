# isDate

## คำอธิบาย

`isDate` ใช้ตรวจสอบว่าค่าที่ให้มาเป็น `Date` หรือไม่ โดยคืนค่า `true` สำหรับอินสแตนซ์ `Date` และคืนค่า `false`
ในกรณีอื่น

### กรณีการใช้งาน

ตรวจสอบและทำให้ค่าที่ไม่ทราบแน่ชัดแคบลง (เช่น ข้อมูลคำขอ, ค่าคอนฟิก หรือ JSON ที่พาร์สแล้ว) ก่อนทำการดำเนินการกับ `Date`
เช่น การจัดรูปแบบ การเปรียบเทียบ หรือการเรียก `toISOString()`

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isDate` เพื่อทำให้ `unknown` แคบลงเป็น `Date` ขณะรันไทม์; มันจะคืนค่า `true` เฉพาะสำหรับอินสแตนซ์ `Date`
> จริงเท่านั้น (ไม่ใช่สตริงวันที่)

### ข้อดี

- มีตัวป้องกัน (guard) ขณะรันไทม์ที่เรียบง่ายเพื่อยืนยันว่าค่าเป็น `Date` หรือไม่
- ช่วยป้องกันข้อผิดพลาดด้านชนิดข้อมูล โดยทำให้มั่นใจว่าเฉพาะอินสแตนซ์ `Date` เท่านั้นที่ผ่านการตรวจสอบ
- มีประโยชน์สำหรับการตรวจสอบอินพุตที่ไม่ทราบแน่ชัด (เช่น เพย์โหลดจาก API) ก่อนใช้งานเมธอดที่เกี่ยวข้องกับวันที่

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isDate(value)`

พารามิเตอร์:

- `value`: ค่าที่จะตรวจสอบว่าเป็นชนิด `Date` หรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isDate } from "@type-check/guards";

const input: unknown = new Date();

if (isDate(input)) {
  // ที่นี่ input เป็น Date
  const iso = input.toISOString();
  console.log(iso);
} else {
  console.log("Not a Date");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isDate(value)`
