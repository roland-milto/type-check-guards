# isBinary

## คำอธิบาย

`isBinary` ใช้ตรวจสอบว่าค่าเป็นสตริงไบนารีหรือไม่ (อาจมีคำนำหน้า `0b`/`0B`) และคืนค่า `true` หรือ `false`

### กรณีการใช้งาน

ตรวจสอบสตริงที่ผู้ใช้ระบุ (เช่น ช่องฟอร์ม อาร์กิวเมนต์ CLI ค่าคอนฟิก) เพื่อให้แน่ใจว่ามีเฉพาะเลขฐานสองเท่านั้น
และอาจมีคำนำหน้า `0b`/`0B` ก่อนนำไปประมวลผลต่อ

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isBinary` เป็น type guard ก่อนทำการ parse หรือแปลงสตริงเป็น `BigInt`/`Number` เพื่อหลีกเลี่ยงอินพุตที่ไม่ถูกต้อง

### ข้อดี

- ยอมรับสตริงไบนารีทั้งแบบมีหรือไม่มีคำนำหน้า `0b`/`0B`
- ปฏิเสธสตริงว่างและสตริงที่มีช่องว่างนำหน้า/ต่อท้าย (ASCII ≤ 32)
- คืนค่า `true`/`false` โดยไม่โยนข้อยกเว้น ทำให้ปลอดภัยสำหรับอินพุตที่ไม่ทราบแน่ชัด

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isBinary(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isBinary } from "@type-check/guards";

const a = isBinary("0b1010"); // จริง
const b = isBinary("1010");   // จริง
const c = isBinary("0b1020"); // เท็จ
const d = isBinary(0b1010);     // เท็จ

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isBinary(value)`
