# isIndexFound

## คำอธิบาย

`isIndexFound` ใช้กำหนดว่าค่าที่กำหนดเป็นจำนวนเต็มที่ไม่ติดลบหรือไม่ ซึ่งบ่งชี้ว่าพบดัชนีแล้ว

### กรณีการใช้งาน

ตรวจสอบว่าผลลัพธ์จากการค้นหาเป็นดัชนีที่ใช้งานได้ (จำนวนเต็ม `>= 0`) ก่อนนำไปใช้เข้าถึงอาร์เรย์หรือสตริง
เพื่อป้องกันการใช้ `-1` หรือค่าที่ไม่ใช่ตัวเลขโดยไม่ตั้งใจ

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isIndexFound` หลังการทำงานอย่าง `indexOf`, `findIndex` หรือการค้นหาแบบกำหนดเองที่ `-1` (หรือค่าไม่ถูกต้องอื่น ๆ)
> อาจหมายถึง “ไม่พบ” เมื่อมันคืนค่า `true` ค่านั้นจะเป็นตัวเลขและปลอดภัยที่จะใช้เป็นดัชนีของอาร์เรย์/สตริง

### ข้อดี

- มี type guard ที่เรียบง่ายเพื่อใช้ตรวจจับว่าพบดัชนีหรือไม่ โดยตรวจสอบว่าเป็นจำนวนเต็มที่ไม่ติดลบ
- คืนค่า `true` เฉพาะสำหรับค่าที่เป็นดัชนีที่ถูกต้องเท่านั้น (จำนวนเต็ม `>= 0`) โดยปฏิเสธค่าติดลบ ค่าที่ไม่เป็นจำนวนเต็ม
  และค่าที่ไม่ใช่ตัวเลข
- ช่วยหลีกเลี่ยงข้อผิดพลาดแบบ off-by-one และความผิดพลาดจากค่า sentinel เมื่อทำงานกับ API ที่คืนค่า `-1` เพื่อหมายถึง
  “ไม่พบ”

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isIndexFound(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบว่าเป็นจำนวนเต็มที่ไม่ติดลบหรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isIndexFound } from "@type-check/guards";

const idx: unknown = "3";

if (isIndexFound(idx)) {
  // ตรงนี้ idx เป็นตัวเลขและมีค่า >= 0
  const next = idx + 1;
  console.log(next);
} else {
  console.log("No valid index found");
}

// การใช้งานทั่วไปกับ indexOf
const pos = "hello".indexOf("e");
if (isIndexFound(pos)) {
  console.log("Found at", pos);
}
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isIndexFound(value)`
