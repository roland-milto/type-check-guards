# isRegEx

## คำอธิบาย

กำหนดว่าค่าที่ให้มานั้นเป็นอินสแตนซ์ของ `RegExp` หรือไม่

### กรณีการใช้งาน

ตรวจสอบความถูกต้องของค่าที่ผู้ใช้ให้มาหรือค่าที่เป็นไดนามิก (เช่น คอนฟิก, เพย์โหลด API, อินพุตของปลั๊กอิน)
ก่อนนำไปใช้เป็นนิพจน์ปกติ

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isRegEx` เพื่อทำให้ค่า `unknown` (หรือยูเนียน) แคบลงก่อนใช้งานพร็อพเพอร์ตีหรือเมธอดเฉพาะของ RegExp;
> ฟังก์ชันจะคืนค่า `true` เฉพาะเมื่อค่าเป็นอินสแตนซ์ของ `RegExp` เท่านั้น

### ข้อดี

- มีตัวป้องกันชนิด (type guard) แบบรันไทม์ที่เรียบง่ายเพื่อใช้ตรวจสอบว่าค่าเป็น `RegExp` หรือไม่
- ช่วยป้องกันข้อผิดพลาดเมื่อโค้ดคาดหวังนิพจน์ปกติ (เช่น ก่อนเรียก `test`, `exec` หรืออ่าน `source`)
- ทำงานได้ทั้งกับ regex literal และอินสแตนซ์ที่สร้างผ่าน `new RegExp(...)`
- คืนค่าผลลัพธ์แบบบูลีนที่ชัดเจน (`true`/`false`) โดยไม่โยนข้อยกเว้นสำหรับอินพุตที่ไม่ใช่ regex

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isRegEx(value)`

พารามิเตอร์:

- `value`: ค่าที่จะตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isRegEx } from "@type-check/guards";

const input: unknown = /abc/i;

if (isRegEx(input)) {
  // input เป็น RegExp ที่นี่
  console.log(input.test("ABC"));
} else {
  console.log("Not a RegExp");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isRegEx(value)`
