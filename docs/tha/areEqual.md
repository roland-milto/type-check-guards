# areEqual

## คำอธิบาย

`areEqual` ตรวจสอบว่าองค์ประกอบทั้งหมดในอาร์เรย์เท่ากับค่าที่คาดหวังที่กำหนดหรือไม่ โดยจะคืนค่า `true`
เฉพาะสำหรับอาร์เรย์ที่ไม่ว่างซึ่งทุกรายการตรงกันเท่านั้น

### กรณีการใช้งาน

ตรวจสอบว่ารายการมีได้เพียงค่าเดียวที่อนุญาต (เช่น ธงสถานะทั้งหมดเป็น `true`, บทบาททั้งหมดเป็น `"admin"`,
หรือค่าตัวเลขทั้งหมดเท่ากับค่าคงที่ที่กำหนด) โดยถือว่าอินพุตว่างเป็นค่าไม่ถูกต้อง (`false`).

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areEqual` เมื่อคุณต้องการตรวจแบบเข้มงวดว่าทุกรายการต้องตรงกัน; ฟังก์ชันนี้จะคืนค่า `false` สำหรับอาร์เรย์ว่าง
> และสำหรับอินพุตใด ๆ ที่ไม่ใช่อาร์เรย์หรือไม่ใช่อาร์เรย์ที่มีข้อมูล

### ข้อดี

- คืนค่า `true` เฉพาะเมื่อทุกองค์ประกอบตรงกับค่าที่คาดหวังเท่านั้น; มิฉะนั้นจะคืนค่า `false`
- ล้มเหลวอย่างรวดเร็ว: หยุดตรวจทันทีที่พบองค์ประกอบที่ไม่ตรงกัน
- ป้องกันอินพุตที่ไม่ถูกต้องโดยคืนค่า `false` เมื่ออินพุตไม่ใช่อาร์เรย์ที่มีข้อมูล (
  ไม่ใช่อาร์เรย์ที่มีอย่างน้อยหนึ่งค่า)

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areEqual(value, expected)`

พารามิเตอร์:

- `value`: อาร์เรย์ที่จะตรวจสอบ
- `expected`: องค์ประกอบที่ใช้เปรียบเทียบกับแต่ละรายการในอาร์เรย์

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areEqual } from "@type-check/guards";

const allOnes = areEqual([1, 1, 1], 1);
const allTests = areEqual(["test", "test"], "test");
const notAllTwos = areEqual([2, 3, 2], 2);
const emptyIsFalse = areEqual([], 5);

console.log(allOnes, allTests, notAllTwos, emptyIsFalse);
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areEqual(value, expected)`
