# isObject

## คำอธิบาย

ตรวจสอบว่า `value` ที่กำหนดเป็น `object` หรือไม่ (ไม่รวม `null`)

### กรณีการใช้งาน

ใช้ `isObject` เพื่อยืนยันความถูกต้องของอินพุตที่ไม่ทราบชนิด (เช่น JSON ที่แปลงแล้ว, การตอบกลับจาก API,
เพย์โหลดของอีเวนต์) ก่อนเข้าถึงพร็อพเพอร์ตี เพื่อให้แน่ใจว่าค่านั้นเป็นอ็อบเจ็กต์และไม่ใช่ `null`

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> `isObject` เป็นการ์ดขณะรันไทม์ที่คืนค่าเป็นบูลีน; มันไม่ได้ทำให้แคบลงไปเป็นรูปทรงอ็อบเจ็กต์แบบเฉพาะเจาะจง
> ควรใช้ร่วมกับการตรวจสอบเพิ่มเติม (เช่น การมีอยู่ของพร็อพเพอร์ตี) เมื่อคุณต้องการการพิมพ์ชนิดที่เข้มงวดมากขึ้น

### ข้อดี

- คืนค่า `true` เฉพาะสำหรับค่าที่ไม่ใช่ `null` และมี `typeof` เป็น `"object"` เท่านั้น
- ป้องกันข้อผิดพลาดที่พบบ่อยใน JavaScript ซึ่ง `null` อาจถูกมองว่าเป็นอ็อบเจ็กต์ได้
- ใช้ได้กับอ็อบเจ็กต์ธรรมดาและอินสแตนซ์ของอ็อบเจ็กต์ที่มีมาในตัว (เช่น `Date`, `RegExp`)
- การตรวจสอบขณะรันไทม์ที่เรียบง่ายและรวดเร็ว เหมาะสำหรับการเขียนโปรแกรมเชิงป้องกันและการตรวจสอบความถูกต้องของอินพุต

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isObject(value)`

พารามิเตอร์:

- `value`: ค่าที่จะตรวจสอบว่าเป็น `object` หรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isObject } from "@type-check/guards";

const input: unknown = { a: 1 };

if (isObject(input)) {
  // input เป็นอ็อบเจ็กต์ที่ไม่เป็น null ในขณะรันไทม์
  console.log("Object detected");
} else {
  console.log("Not an object");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isObject(value)`
