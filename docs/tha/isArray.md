# isArray

## คำอธิบาย

`isArray` ตรวจสอบว่าค่าที่กำหนดเป็นอาร์เรย์หรือไม่ และคืนค่า `true` หากเป็นอาร์เรย์ มิฉะนั้นคืนค่า `false`

### กรณีการใช้งาน

ตรวจสอบข้อมูลที่ไม่ทราบแน่ชัด (เช่น JSON ที่พาร์สแล้วหรือการตอบกลับจาก API)
เพื่อให้แน่ใจว่าค่าเป็นอาร์เรย์ก่อนทำการวนลูป เข้าถึงด้วยดัชนี หรือเข้าถึง `.length`

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isArray` เมื่อคุณต้องการตรวจสอบอาร์เรย์ขณะรันไทม์; ฟังก์ชันนี้คืนค่าเป็นบูลีนและปลอดภัยที่จะเรียกใช้กับค่า
`unknown`

### ข้อดี

- ใช้ `Array.isArray` ที่มีมาในตัวเพื่อการตรวจจับอาร์เรย์ที่เชื่อถือได้ข้าม realm (เช่น iframe)
- คืนค่าผลลัพธ์เป็นบูลีนแบบง่าย (`true`/`false`) เหมาะสำหรับการทำ guard และตรรกะแบบแตกแขนง
- ทำงานได้กับอินพุตทุกชนิด เพราะพารามิเตอร์เป็น `unknown`

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isArray(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (isArray(input)) {
  // input เป็นอาร์เรย์ในขณะรันไทม์
  console.log(input.length);
} else {
  console.log("Not an array");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isArray(value)`
