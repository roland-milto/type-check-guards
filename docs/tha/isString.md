# isString

## คำอธิบาย

`isString` ใช้ตรวจสอบว่าค่าที่กำหนดเป็นสตริงหรือไม่

### กรณีการใช้งาน

ตรวจสอบอินพุตของผู้ใช้ ฟิลด์ในเพย์โหลดของ API หรือค่าคอนฟิกในขณะรันไทม์
เพื่อให้แน่ใจว่าค่าเป็นสตริงก่อนนำไปทำงานกับสตริง (เช่น การตัดช่องว่าง การแยกสตริง การแปลงตัวพิมพ์)

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isString` เพื่อตรวจสอบค่า `unknown` หรือค่าที่กำหนดชนิดแบบหลวม ๆ ก่อนเรียกใช้เมธอดของสตริง; ฟังก์ชันจะคืนค่า
`true` เฉพาะเมื่อ `typeof value === "string"` เท่านั้น

### ข้อดี

- ตรวจสอบได้อย่างง่ายและรวดเร็วด้วย `typeof`
- ให้ผลลัพธ์แบบบูลีนที่คาดเดาได้: `true` สำหรับสตริง มิฉะนั้นเป็น `false`
- ใช้ได้ทั้งกับสตริงว่างและสตริงที่ไม่ว่าง
- มีประโยชน์เป็นตัวป้องกัน (guard) แบบเบา ๆ ในขณะรันไทม์ก่อนทำงานที่เฉพาะกับสตริง

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isString(value)`

พารามิเตอร์:

- `value`: ค่าที่จะทดสอบว่าเป็นชนิดสตริงหรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isString } from "@type-check/guards";

const input: unknown = "Hello World";

if (isString(input)) {
  // input เป็นสตริงที่นี่
  console.log(input.toUpperCase());
} else {
  console.log("Not a string");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isString(value)`
