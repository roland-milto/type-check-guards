# isNaN

## คำอธิบาย

ระบุว่า `value` ที่ให้มาเป็น `NaN` ของชนิด `number` หรือไม่ โดยไม่แปลงสตริง

### กรณีการใช้งาน

ตรวจสอบอินพุตที่ไม่น่าเชื่อถือหรือมีชนิดหลวม ๆ (เช่น payload จาก API, ค่าจากฟอร์ม, JSON ที่แยกวิเคราะห์แล้ว)
เพื่อค้นหาค่า `NaN` แบบพิเศษและจัดการอย่างชัดเจน โดยถือว่าอินพุตที่ไม่ใช่ตัวเลขนั้นไม่ใช่ `NaN`

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isNaN` เมื่อคุณต้องการตรวจจับค่าตัวเลขพิเศษ `NaN` พร้อมทั้งยืนยันว่าอินพุตเป็น `number` จริง ๆ (
> ไม่มีการแปลงสตริงเป็นตัวเลข)

### ข้อดี

- ตรวจสอบว่าค่าเป็น `NaN` หรือไม่ โดยไม่บังคับแปลงค่าที่ไม่ใช่ตัวเลข (เช่น สตริง) ให้เป็นตัวเลข
- คืนค่า `true` เฉพาะสำหรับค่าที่เป็นทั้งชนิด `number` และเป็น `NaN` เท่านั้น
- ปลอดภัยสำหรับอินพุตชนิด `unknown` และหลีกเลี่ยงผลบวกลวงจากการแปลงแบบปริยาย

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isNaN(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบว่าเป็น `NaN` ของชนิด `number` หรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isNaN } from "@type-check/guards";

const a: unknown = NaN;
const b: unknown = "NaN";
const c: unknown = 123;

console.log(isNaN(a)); // จริง
console.log(isNaN(b)); // เท็จ
console.log(isNaN(c)); // เท็จ

if (isNaN(a)) {
  // a เป็นตัวเลขและโดยเฉพาะคือ NaN
}
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isNaN(value)`
