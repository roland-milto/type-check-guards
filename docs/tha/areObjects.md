# areObjects

## คำอธิบาย

`areObjects` ตรวจสอบว่าอาร์เรย์ที่มีข้อมูล (ไม่ว่าง) ที่ให้มามีเฉพาะอ็อบเจ็กต์เท่านั้นหรือไม่

### กรณีการใช้งาน

ใช้ `areObjects` เมื่อคุณได้รับอาร์เรย์ที่ไม่ทราบชนิด (เช่น จากการแปลง JSON หรือ API ภายนอก)
และต้องการให้แน่ใจว่าอาร์เรย์ไม่ว่างและทุกองค์ประกอบเป็นอ็อบเจ็กต์ก่อนทำการวนลูปและเข้าถึงพร็อพเพอร์ตีของอ็อบเจ็กต์

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areObjects` เพื่อตรวจสอบ `unknown[]` ก่อนจะปฏิบัติต่อรายการต่าง ๆ ว่าเป็นอ็อบเจ็กต์ โดยมันจะคืนค่า `false`
> สำหรับอาร์เรย์ว่าง

### ข้อดี

- คืนค่า `true` เฉพาะเมื่ออินพุตเป็นอาร์เรย์ที่มีข้อมูล (ไม่ว่าง) และทุกองค์ประกอบเป็นอ็อบเจ็กต์
- หยุดตรวจทันทีและคืนค่า `false` ทันทีที่พบองค์ประกอบที่ไม่ใช่อ็อบเจ็กต์
- ช่วยตรวจสอบความถูกต้องของอินพุตที่ไม่ทราบชนิดก่อนทำการดำเนินการที่เฉพาะเจาะจงกับอ็อบเจ็กต์

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areObjects(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบว่าองค์ประกอบเป็นอ็อบเจ็กต์หรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areObjects } from "@type-check/guards";

const value: unknown = [{}, { a: 1 }, new Date()];

if (Array.isArray(value) && areObjects(value)) {
  // value เป็นอาร์เรย์ของอ็อบเจ็กต์ที่มีข้อมูล
  console.log("All items are objects:", value.length);
} else {
  console.log("Not a filled array of objects");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areObjects(array)`
