# areBigInts

## คำอธิบาย

`areBigInts` ใช้กำหนดว่าค่าหนึ่งเป็นอาร์เรย์ที่ไม่ว่างและมีเฉพาะค่า `bigint` เท่านั้นหรือไม่

### กรณีการใช้งาน

ตรวจสอบอินพุตที่ไม่ทราบชนิด (เช่น ข้อมูลลักษณะ JSON ที่ถูกพาร์ส, เพย์โหลดจาก API
หรือพารามิเตอร์ของฟังก์ชันที่กำหนดชนิดเป็น `unknown`) เพื่อให้แน่ใจว่าเป็นอาร์เรย์ที่ไม่ว่างของค่า `bigint`
ก่อนประมวลผล; คืนค่า `true` เฉพาะเมื่อทุกสมาชิกเป็น `bigint` มิฉะนั้นคืนค่า `false`

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areBigInts` เป็นการ์ดขณะรันไทม์ก่อนทำงานที่รองรับเฉพาะ `bigint` (เช่น การคำนวณทางคณิตศาสตร์ การเปรียบเทียบ)
> กับอินพุตที่ไม่ทราบชนิด

### ข้อดี

- รับประกันว่าสมาชิกทุกตัวเป็น `bigint` โดยจะคืนค่า `true` ก็ต่อเมื่อทั้งอาร์เรย์ตรงตามเงื่อนไขทั้งหมดเท่านั้น
- ปฏิเสธค่าที่ไม่ใช่อาร์เรย์และอาร์เรย์ว่างตามการออกแบบ (ผ่าน `isFilledArray`)
  เพื่อป้องกันการยอมรับอินพุตที่ไม่ถูกต้องโดยไม่ตั้งใจ
- ล้มเหลวอย่างรวดเร็ว: คืนค่า `false` ทันทีเมื่อพบสมาชิกที่ไม่ใช่ `bigint`

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areBigInts(array)`

พารามิเตอร์:

- `array`: ค่าที่ต้องการตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areBigInts } from "@type-check/guards";

const a: unknown = [10n, 20n];
const b: unknown = [10n, 20];
const c: unknown = [];

console.log(areBigInts(a)); // จริง
console.log(areBigInts(b)); // เท็จ
console.log(areBigInts(c)); // เท็จ
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areBigInts(array)`
