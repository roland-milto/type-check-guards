# areArrays

## คำอธิบาย

`areArrays` ใช้กำหนดว่าค่าหนึ่งเป็นอาร์เรย์สองมิติที่มีข้อมูล (ไม่ว่าง) และรายการภายในทั้งหมดเป็นอาร์เรย์หรือไม่

### กรณีการใช้งาน

ใช้ `areArrays` เพื่อตรวจสอบอินพุตแบบตารางหรือคล้ายเมทริกซ์ (เช่น แถว CSV, ข้อมูลกริด หรือรายการที่จัดกลุ่ม)
ก่อนทำการดำเนินการกับแถว/คอลัมน์; ฟังก์ชันจะคืนค่า `false` หากอินพุตไม่ใช่อาร์เรย์, ว่างเปล่า หรือมีองค์ประกอบใด ๆ
ที่ไม่ใช่อาร์เรย์

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areArrays` เมื่อคุณต้องการให้แน่ใจว่าค่าหนึ่งเป็นอาร์เรย์ 2 มิติที่ไม่ว่าง และแต่ละแถวเป็นอาร์เรย์
> ก่อนทำการวนซ้ำหรือเข้าถึงด้วยดัชนีในอาร์เรย์ซ้อนกัน

### ข้อดี

- ตรวจสอบว่าอินพุตเป็นอาร์เรย์สองมิติที่ไม่ว่าง และทุกองค์ประกอบเป็นอาร์เรย์
- คืนค่าผลลัพธ์แบบบูลีนอย่างง่าย (`true`/`false`) เหมาะสำหรับใช้เป็นการ์ดและการออกก่อนกำหนด
- ช่วยป้องกันข้อผิดพลาดขณะรันไทม์เมื่อโค้ดภายหลังสมมติว่ามีการทำงานกับอาร์เรย์ซ้อนกัน (เช่น การ map แถว)

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areArrays(array)`

พารามิเตอร์:

- `array`: อินพุตที่จะตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areArrays } from "@type-check/guards";

const value: unknown = [[1, 2], [3, 4]];

if (areArrays(value as unknown[][])) {
  // value เป็นอาร์เรย์ 2 มิติที่มีอาร์เรย์เป็นองค์ประกอบ
  const lengths = value.map(row => row.length);
  console.log(lengths);
} else {
  console.log("Not a 2D array of arrays");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areArrays(array)`
