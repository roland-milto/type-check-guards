# isEmpty

## คำอธิบาย

กำหนดว่าค่าที่กำหนดนั้นว่างหรือไม่ โดยคืนค่า `true` สำหรับ `null`, `undefined`, สตริงว่าง/มีแต่ช่องว่าง, อาร์เรย์ว่าง,
`Map`/`Set` ว่าง หรืออ็อบเจ็กต์ที่ไม่มีพร็อพเพอร์ตีที่ enumerable ของตัวเอง

### กรณีการใช้งาน

ใช้ `isEmpty` เพื่อยืนยันความถูกต้องของอินพุตและตรวจจับค่าที่ขาดหาย/ว่างเปล่าข้ามหลายชนิดข้อมูล (เช่น ฟิลด์ฟอร์ม,
payload ของ API, อ็อบเจ็กต์การตั้งค่า) โดยที่ `null`, `undefined`, สตริงที่มีแต่ช่องว่าง, คอลเลกชันว่าง
และอ็อบเจ็กต์ที่ไม่มีพร็อพเพอร์ตี ควรถูกมองว่าเป็นค่าว่าง

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> `isEmpty` เป็นยูทิลิตีที่คืนค่าเป็นบูลีน (ไม่ใช่ TypeScript type predicate)
> ดังนั้นมันจะไม่ทำให้ชนิดแคบลงด้วยตัวมันเอง; ใช้มันสำหรับการตรวจสอบ/แตกแขนงเงื่อนไขมากกว่าการทำ narrowing ตอนคอมไพล์

### ข้อดี

- ถือว่า `null` และ `undefined` เป็น `true` สำหรับการตรวจสอบความว่าง
- มองว่าสตริงที่มีแต่ช่องว่างเป็นค่าว่าง โดยทำการ trim ก่อนตรวจสอบความยาว
- รองรับชนิดคอนเทนเนอร์ที่ใช้บ่อย (อาร์เรย์, `Map`, `Set`) และอ็อบเจ็กต์ธรรมดาที่ไม่มีพร็อพเพอร์ตีที่ enumerable
  ของตัวเอง
- หลีกเลี่ยงการนับพร็อพเพอร์ตีที่สืบทอดมาโดยใช้การตรวจสอบ `hasOwnProperty`
- คืนค่าผลลัพธ์เป็นบูลีนแบบง่าย (`true`/`false`) เหมาะสำหรับ guard และการตรวจสอบความถูกต้อง

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isEmpty(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบความว่าง

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isEmpty } from "@type-check/guards";

const values: unknown[] = [
  null,
  undefined,
  "   ",
  "Hello",
  [],
  [1],
  new Map(),
  new Set(["x"]),
  {},
  { a: undefined }
];

const results = values.map(v => ({ value: v, empty: isEmpty(v) }));
console.log(results);

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isEmpty(value)`
