# areDates

## คำอธิบาย

`areDates` ใช้กำหนดว่าอาร์เรย์ที่กำหนดมีข้อมูลและมีเฉพาะอ็อบเจ็กต์ `Date` เท่านั้น โดยจะคืนค่า `true`
ก็ต่อเมื่อทุกองค์ประกอบเป็นวันที่ที่ถูกต้อง

### กรณีการใช้งาน

ใช้ `areDates` เพื่อตรวจสอบอินพุตที่ไม่ทราบชนิด (เช่น JSON ที่แปลงแล้ว ข้อมูลฟอร์ม เพย์โหลดจาก API)
ก่อนรันตรรกะที่เกี่ยวข้องกับวันที่ เช่น การเรียงลำดับตามเวลา การจัดรูปแบบ หรือการคำนวณช่วง

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> คืนค่า `true` เฉพาะสำหรับอาร์เรย์ที่ไม่ว่างและทุกองค์ประกอบเป็น `Date`; อาร์เรย์ว่างจะได้ค่า `false`

### ข้อดี

- รับประกันว่าอาร์เรย์ไม่ว่างก่อนตรวจสอบเนื้อหาภายใน ช่วยป้องกันการได้ค่า `true` สำหรับอินพุตที่ว่างเปล่า
- ตรวจสอบว่าแต่ละองค์ประกอบเป็นอินสแตนซ์ของ `Date` และจะคืนค่า `false` ทันทีเมื่อพบรายการแรกที่ไม่ตรงกัน
- มีประโยชน์ในฐานะการตรวจสอบแบบ guard ก่อนทำงานที่เกี่ยวข้องกับวันที่กับรายการในอาร์เรย์

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areDates(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบว่าเป็นอ็อบเจ็กต์ `Date` หรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areDates } from "@type-check/guards";

const a: unknown[] = [new Date(), new Date("2021-01-01")];
const b: unknown[] = [];
const c: unknown[] = [new Date(), "not a date"];

console.log(areDates(a)); // จริง
console.log(areDates(b)); // เท็จ
console.log(areDates(c)); // เท็จ

if (areDates(a)) {
  const timestamps = a.map(d => d.getTime());
  console.log(timestamps);
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areDates(array)`
