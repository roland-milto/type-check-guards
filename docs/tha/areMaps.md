# areMaps

## คำอธิบาย

`areMaps` ใช้กำหนดว่าอาร์เรย์ที่กำหนดนั้นไม่ว่างและองค์ประกอบทั้งหมดเป็นอินสแตนซ์ของ `Map` หรือไม่

### กรณีการใช้งาน

ตรวจสอบอินพุตที่ไม่ทราบแน่ชัด (เช่น จากการแยก JSON, API ภายนอก หรือแหล่งข้อมูลแบบไดนามิก)
ก่อนจะนำไปใช้เป็นรายการของอ็อบเจ็กต์ `Map` ที่ไม่ว่าง

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> คืนค่า `false` สำหรับอาร์เรย์ว่าง; จะคืนค่า `true` ก็ต่อเมื่ออาร์เรย์มีข้อมูลและทุกองค์ประกอบเป็น `Map`

### ข้อดี

- ทำให้มั่นใจว่าแต่ละองค์ประกอบเป็นอินสแตนซ์ของ `Map` โดยจะคืนค่า `true` ก็ต่อเมื่ออาร์เรย์ทั้งหมดผ่านการตรวจสอบเท่านั้น
- ปฏิเสธอาร์เรย์ว่างตามการออกแบบ เพื่อป้องกันการยอมรับ “ไม่มีข้อมูล” โดยไม่ตั้งใจว่าเป็นอินพุตที่ถูกต้อง
- มีประโยชน์ในฐานะตัวป้องกันก่อนทำงานที่เฉพาะกับ `Map` (เช่น `.get()`, `.set()`, การวนซ้ำ) กับทั้งคอลเลกชัน

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areMaps(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areMaps } from "@type-check/guards";

const items: unknown[] = [new Map<string, number>([["a", 1]]), new Map<string, number>()];

if (areMaps(items)) {
  // รับประกันว่า items เป็นอาร์เรย์ที่ไม่ว่างซึ่งประกอบด้วยอินสแตนซ์ของ Map ในขณะรันไทม์
  for (const m of items) {
    m.set("x", 42);
  }
} else {
  // ให้ค่าเป็น false สำหรับ: อาร์เรย์ว่าง หรืออาร์เรย์ที่มีค่าใด ๆ ที่ไม่ใช่ Map
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areMaps(array)`
