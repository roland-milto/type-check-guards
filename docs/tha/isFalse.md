# isFalse

## คำอธิบาย

`isFalse` ตรวจสอบว่าค่าที่กำหนดมีค่าเท่ากับลิเทอรัลบูลีน `false` แบบเข้มงวดหรือไม่

### กรณีการใช้งาน

ตรวจสอบข้อมูลที่ไม่ทราบแน่ชัด (เช่น จาก JSON, query params หรืออินพุตผู้ใช้) ในกรณีที่ควรถือว่าเฉพาะค่าบูลีน `false`
ที่ระบุอย่างชัดเจนเท่านั้นเป็นแฟล็กที่ถูกต้อง และควรปฏิเสธอย่างอื่นทั้งหมด

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isFalse` เมื่อคุณต้องการยอมรับเฉพาะลิเทอรัล `false` และปฏิเสธค่า falsy อื่นทั้งหมด; ฟังก์ชันจะคืนค่า `true`
> เฉพาะเมื่อ `value === false` เท่านั้น

### ข้อดี

- ให้การตรวจสอบแบบเข้มงวดสำหรับลิเทอรัลบูลีน `false` โดยไม่มีการแปลงชนิด (coercion)
- ช่วยแยก `false` ออกจากค่า falsy อื่น ๆ เช่น `0`, `""`, `null` และ `undefined`
- ช่วยเพิ่มความอ่านง่ายโดยทำให้เจตนาชัดเจนเมื่อทำการตรวจสอบอินพุตที่ไม่ทราบแน่ชัด

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isFalse(value)`

พารามิเตอร์:

- `value`: ค่าที่จะถูกตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isFalse } from "@type-check/guards";

const input: unknown = false;

if (isFalse(input)) {
  // ที่นี่ input เป็น false อย่างแน่นอน
  console.log("Got false");
} else {
  console.log("Not false");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isFalse(value)`
