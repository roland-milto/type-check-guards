# isFilledArray

## คำอธิบาย

ตรวจสอบว่า `value` เป็นอาร์เรย์ที่มีอย่างน้อยหนึ่งองค์ประกอบหรือไม่ โดยคืนค่า `true` หรือ `false`

### กรณีการใช้งาน

ใช้ `isFilledArray` เพื่อยืนยันความถูกต้องของข้อมูลที่เข้ามา (เช่น payload จาก API, ค่าจากฟอร์ม, การกำหนดค่า)
ก่อนทำการวนลูป (iterate), เข้าถึงองค์ประกอบแรก, หรือใช้ตรรกะที่ต้องการอย่างน้อยหนึ่งรายการ

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> `isFilledArray` เป็นการ์ด (guard) ระดับรันไทม์ที่คืนค่าเป็นบูลีน;
> มันไม่ได้ทำให้ชนิดขององค์ประกอบแคบลงไปมากกว่าการยืนยันว่าอาร์เรย์ไม่ว่าง

### ข้อดี

- ตรวจสอบอาร์เรย์ที่ไม่ว่างได้อย่างง่ายและรวดเร็วด้วย `Array.isArray` และการตรวจสอบความยาว (length)
- ช่วยหลีกเลี่ยงข้อผิดพลาดขณะรันไทม์เมื่อโค้ดสมมติว่าอาร์เรย์มีอย่างน้อยหนึ่งองค์ประกอบ
- ผลลัพธ์แบบบูลีนที่ชัดเจน: คืนค่า `true` สำหรับอาร์เรย์ที่ไม่ว่าง และ `false` ในกรณีอื่น

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isFilledArray(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบว่าเป็นอาร์เรย์ที่ไม่ว่างหรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isFilledArray } from "@type-check/guards";

const input: unknown = [1, 2, 3];

if (Array.isArray(input) && isFilledArray(input)) {
  // input เป็นอาร์เรย์ที่ไม่ว่างเปล่าในขณะรันไทม์
  console.log(input[0]);
} else {
  console.log("Not a non-empty array");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isFilledArray(value)`
