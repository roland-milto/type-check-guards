# areWeakMaps

## คำอธิบาย

`areWeakMaps` ตรวจสอบว่าค่าเป็นอาร์เรย์ที่ไม่ว่างและทุกองค์ประกอบเป็น `WeakMap` หรือไม่ โดยจะคืนค่า `true`
เฉพาะในกรณีนั้น และคืนค่า `false` ในกรณีอื่น

### กรณีการใช้งาน

ตรวจสอบข้อมูลขณะรันไทม์ (เช่น JSON ที่พาร์สแล้ว อินพุตจากปลั๊กอิน หรือคอนฟิกที่กำหนดชนิดแบบหลวม)
เพื่อให้แน่ใจว่าเป็นอาร์เรย์ที่ไม่ว่างของอินสแตนซ์ `WeakMap` ก่อนทำการวนลูปและเรียกเมธอดของ `WeakMap`; จะคืนค่า `false`
เมื่อมีองค์ประกอบใด ๆ ที่ไม่ใช่ `WeakMap` หรือเมื่ออาร์เรย์ว่าง

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areWeakMaps` เพื่อตรวจสอบอินพุตที่ไม่ทราบชนิดก่อนจะปฏิบัติกับมันเป็น `WeakMap[]` ที่ไม่ว่าง โดยมันจะคืนค่า
`false` สำหรับอาร์เรย์ว่าง

### ข้อดี

- รับประกันว่าองค์ประกอบทุกตัวในอาร์เรย์ที่ให้มาเป็นอินสแตนซ์ของ `WeakMap`
- คืนค่า `false` สำหรับอาร์เรย์ว่าง ช่วยป้องกันการยอมรับ “ไม่มีข้อมูล” โดยไม่ตั้งใจว่าเป็นอินพุตที่ถูกต้อง
- มีประโยชน์สำหรับใช้เป็นตัวป้องกัน (guard) ก่อนทำงานที่เฉพาะเจาะจงกับ `WeakMap` กับทุกรายการ

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areWeakMaps(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่ต้องการตรวจสอบว่าเป็นอินสแตนซ์ของ `WeakMap` หรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areWeakMaps } from "@type-check/guards";

const list: unknown[] = [new WeakMap<object, number>(), new WeakMap<object, number>()];

if (areWeakMaps(list)) {
  // list เป็นอาร์เรย์ที่ไม่ว่างเปล่าของอินสแตนซ์ WeakMap
  for (const wm of list) {
    wm.set({}, 1);
  }
} else {
  // ไม่ใช่ WeakMap[] ที่ไม่ว่างเปล่า
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areWeakMaps(array)`
