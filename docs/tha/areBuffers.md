# areBuffers

## คำอธิบาย

`areBuffers` ตรวจสอบว่าค่าที่ให้มาเป็นอาร์เรย์ที่ไม่ว่างและมีสมาชิกครบถ้วน โดยทุกองค์ประกอบเป็น `Buffer` หรือไม่
หากใช่จะคืนค่า `true` มิฉะนั้นคืนค่า `false`

### กรณีการใช้งาน

ตรวจสอบอาร์เรย์ของชังก์ที่เข้ามา (เช่น จากสตรีม, การอัปโหลดไฟล์ หรือแพ็กเก็ตเครือข่าย)
เพื่อให้แน่ใจว่าทุกส่วนเป็นอินสแตนซ์ `Buffer` ก่อนทำการต่อรวม, ถอดรหัส
หรือส่งต่อให้ฟังก์ชันด้านการเข้ารหัสลับหรือการประมวลผลไบนารี

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areBuffers` เพื่อตรวจสอบ `unknown[]` ก่อนเรียกใช้ API เฉพาะของ Buffer เช่น `Buffer.concat`
> เพื่อให้มั่นใจว่าฟังก์ชันจะคืนค่า `true` ก็ต่อเมื่อทุกองค์ประกอบเป็น `Buffer`

### ข้อดี

- รับประกันว่าองค์ประกอบทุกตัวในอินพุตเป็นอินสแตนซ์ `Buffer` ของ Node.js โดยจะคืนค่า `true`
  ก็ต่อเมื่อทั้งอาร์เรย์ตรงตามเงื่อนไขทั้งหมดเท่านั้น
- ปฏิเสธอินพุตที่ไม่ถูกต้องตั้งแต่เนิ่น ๆ โดยกำหนดให้ต้องเป็นอาร์เรย์ที่ไม่ว่างและมีสมาชิกครบถ้วน; คืนค่า `false`
  สำหรับอาร์เรย์ว่างหรือค่าที่ไม่ใช่อาร์เรย์
- มีประโยชน์ในฐานะตัวป้องกันก่อนทำงานที่รองรับเฉพาะบัฟเฟอร์ (เช่น การต่อรวม, การแฮช, โปรโตคอลไบนารี)

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areBuffers(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบว่าเป็นอินสแตนซ์ของบัฟเฟอร์หรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areBuffers } from "@type-check/guards";

const chunks: unknown[] = [Buffer.from("test"), Buffer.from("123")];

if (areBuffers(chunks)) {
  const combined = Buffer.concat(chunks);
  console.log(combined.toString("utf8"));
} else {
  throw new TypeError("Expected a non-empty array of Buffer instances");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areBuffers(array)`
