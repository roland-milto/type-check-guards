# areFalse

## คำอธิบาย

`areFalse` ตรวจสอบว่าองค์ประกอบทั้งหมดในอาร์เรย์ที่ให้มาเป็นบูลีน `false` อย่างเคร่งครัดหรือไม่.

### กรณีการใช้งาน

ตรวจสอบว่ารายการของ feature flags, การตรวจสอบ หรือผลลัพธ์จาก guard ทั้งหมดเป็น `false` ก่อนดำเนินการต่อ (เช่น
ยืนยันว่าไม่มีเงื่อนไขที่ขัดขวางอยู่).

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areFalse` เมื่อคุณต้องการการตรวจสอบแบบเคร่งครัดว่าอาร์เรย์ไม่ว่างและมีเฉพาะค่าบูลีน `false` เท่านั้น.

### ข้อดี

- รับประกันว่าแต่ละองค์ประกอบเป็น `false` อย่างเคร่งครัด (ไม่มีการแปลงแบบ truthy/falsey).
- คืนค่า `false` สำหรับค่าที่ไม่ใช่อาร์เรย์หรืออาร์เรย์ว่าง โดยกำหนดให้ต้องเป็นอาร์เรย์ที่มีข้อมูลผ่าน `isFilledArray`.
- หยุดตรวจทันทีเมื่อพบองค์ประกอบแรกที่ไม่ใช่ `false` เพื่อประสิทธิภาพ.

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areFalse(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบ ซึ่งมีองค์ประกอบได้ทุกชนิด.

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areFalse } from "@type-check/guards";

const a = areFalse([false, false, false]); // จริง
const b = areFalse([false, true, false]);  // เท็จ
const c = areFalse([false, "false", false]); // เท็จ
const d = areFalse([]); // เท็จ
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areFalse(array)`
