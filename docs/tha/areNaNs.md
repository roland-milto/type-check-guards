# areNaNs

## คำอธิบาย

`areNaNs` ตรวจสอบว่าองค์ประกอบทั้งหมดในอาร์เรย์เป็น `NaN` หรือไม่ และจะคืนค่า `true` ก็ต่อเมื่อทุกองค์ประกอบเป็น `NaN`
เท่านั้น.

### กรณีการใช้งาน

ตรวจสอบความถูกต้องของข้อมูลที่รับเข้ามาซึ่งใช้ `NaN` เป็นค่าสัญญาณ (sentinel)
และคุณต้องแน่ใจว่าอาร์เรย์ทั้งหมดประกอบด้วย `NaN` เท่านั้น (เช่น การตรวจจับชุดข้อมูลตัวเลขที่ขาดหายทั้งหมด).

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areNaNs` เมื่อคุณต้องตรวจสอบว่าอาร์เรย์มีเพียงค่า `NaN` แบบตัวเลขเท่านั้น (โดยไม่บังคับแปลงสตริงเป็นตัวเลข).

### ข้อดี

- คืนค่า `true` เฉพาะเมื่อทุกองค์ประกอบเป็น `NaN` (ตรวจสอบแบบเข้มงวดว่าทุกองค์ประกอบเป็น `NaN`).
- ไม่บังคับแปลงสตริงเป็นตัวเลข; ค่าที่เป็น "NaN" จะยังคงไม่ใช่ `NaN` และทำให้ผลลัพธ์เป็น `false`.
- คืนค่า `false` สำหรับอาร์เรย์ที่ไม่มีการเติมค่า ป้องกันการได้ `true` โดยไม่ตั้งใจเมื่ออินพุตว่างเปล่า.

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areNaNs(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบว่ามีค่า `NaN` หรือไม่.

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areNaNs } from "@type-check/guards";

const a = areNaNs([NaN, NaN]); // จริง
const b = areNaNs([NaN, 1, NaN]); // เท็จ
const c = areNaNs([NaN, "NaN", NaN]); // เท็จ
const d = areNaNs([NaN, null, NaN]); // เท็จ
const e = areNaNs([] as unknown[]); // เท็จ
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areNaNs(array)`
