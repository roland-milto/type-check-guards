# isSet

## คำอธิบาย

ระบุว่าค่าที่กำหนดเป็น `Set` หรือไม่

### กรณีการใช้งาน

ตรวจสอบความถูกต้องของอินพุตจากแหล่งภายนอก (เช่น การแยกวิเคราะห์ JSON, อินพุตจากผู้ใช้ หรือ API ของบุคคลที่สาม)
เพื่อให้แน่ใจว่าค่าเป็น `Set` ก่อนทำการดำเนินการของ `Set`

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isSet` เพื่อทำให้ค่า `unknown` แคบลงก่อนเรียกใช้ API เฉพาะของ `Set` เช่น `.add`, `.has` หรือ `.size`

### ข้อดี

- มีการตรวจสอบขณะรันไทม์ที่เรียบง่ายเพื่อยืนยันว่าค่าเป็น `Set` หรือไม่
- ช่วยป้องกันข้อผิดพลาดของชนิดข้อมูลโดยทำให้สามารถแยกเงื่อนไขได้ตั้งแต่เนิ่น ๆ เมื่อค่าไม่ใช่ `Set`
- ทำงานได้กับเนื้อหา `Set` ทุกแบบ (ว่างหรือมีข้อมูล) และคืนค่า `true`/`false` อย่างสม่ำเสมอ

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isSet(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isSet } from "@type-check/guards";

const a: unknown = new Set([1, 2, 3]);
const b: unknown = [1, 2, 3];

if (isSet(a)) {
  // a เป็น Set ในขณะรันไทม์
  console.log(a.size);
}

console.log(isSet(b)); // เท็จ
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isSet(value)`
