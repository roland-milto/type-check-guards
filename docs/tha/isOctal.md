# isOctal

## คำอธิบาย

ระบุว่าค่าหนึ่งเป็นสตริงลิเทอรัลฐานแปดที่ถูกต้องหรือไม่ (เช่น `0o755`).

### กรณีการใช้งาน

ตรวจสอบอินพุตของผู้ใช้หรือค่าคอนฟิกที่ต้องแสดงเป็นสตริงลิเทอรัลฐานแปด (ตัวอย่างเช่น โหมดสิทธิ์ไฟล์อย่าง `0o644`)
ก่อนทำการพาร์สหรือแปลงค่า

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> `isOctal` เป็น type guard (`value is string`). หลังจากได้ผลลัพธ์เป็น `true` แล้ว TypeScript
> จะทำให้ตัวแปรที่ตรวจสอบถูกจำกัดชนิดให้เป็น `string`.

### ข้อดี

- มีตัวป้องกันชนิด (type guard) ที่เข้มงวด: คืนค่า `true` เฉพาะเมื่ออินพุตเป็นสตริงที่ตรงกับรูปแบบลิเทอรัลฐานแปด
- ปฏิเสธสตริงว่างและสตริงที่มีช่องว่างนำหน้า/ต่อท้าย (อักขระควบคุม/ช่องว่างแบบ ASCII) ช่วยลดการจับคู่โดยไม่ตั้งใจ
- รองรับเครื่องหมายบวก/ลบที่เป็นตัวเลือก และไม่สนใจตัวพิมพ์เล็ก/ใหญ่สำหรับคำนำหน้า `0o`/`0O`
- ผ่อนปรนสำหรับอินพุตที่ไม่ใช่สตริงโดยคืนค่า `false` แทนการโยนข้อผิดพลาด

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isOctal(value)`

พารามิเตอร์:

- `value`: ค่าที่จะตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isOctal } from "@type-check/guards";

const a: unknown = "0o123";
const b: unknown = "+0O755";
const c: unknown = "0o128";
const d: unknown = 0o123;

console.log(isOctal(a)); // จริง
console.log(isOctal(b)); // จริง
console.log(isOctal(c)); // เท็จ
console.log(isOctal(d)); // เท็จ

if (isOctal(a)) {
  // a เป็นสตริงที่นี่
  const normalized = a.toLowerCase();
  console.log(normalized);
}
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isOctal(value)`
