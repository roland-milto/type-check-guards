# areOctals

## คำอธิบาย

`areOctals` ใช้กำหนดว่าค่าที่ให้มาเป็นอาร์เรย์ที่ไม่ว่างเปล่าของสตริงเลขฐานแปดที่ถูกต้องหรือไม่

### กรณีการใช้งาน

ใช้ `areOctals` เมื่อตรวจสอบอินพุตของผู้ใช้ ค่าในการกำหนดค่า หรือเพย์โหลดจาก API ที่ต้องมีลิเทอรัลเลขฐานแปด (เช่น
โหมดสิทธิ์ไฟล์อย่าง `0o755`) และคุณต้องการปฏิเสธอาร์เรย์ว่างหรือรายการที่ไม่ถูกต้องใด ๆ โดยคืนค่า `false`

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areOctals` เพื่อให้แน่ใจว่าคุณมี `unknown[]` ที่ไม่ว่างเปล่า
> โดยแต่ละรายการเป็นสตริงเลขฐานแปดที่ถูกต้องก่อนทำการแปลง (เช่น ผ่าน `Number(...)` หรือการพาร์สแบบกำหนดเอง)

### ข้อดี

- ตรวจสอบว่าค่าเป็นอาร์เรย์ที่ไม่ว่างเปล่า โดยทุกองค์ประกอบเป็นสตริงเลขฐานแปด และจะคืนค่า `true`
  ก็ต่อเมื่อทุกรายการผ่านการตรวจสอบเท่านั้น
- ล้มเหลวอย่างรวดเร็ว: คืนค่า `false` ทันทีที่พบองค์ประกอบที่ไม่ใช่เลขฐานแปด
- มีประโยชน์ในการใช้เป็นการ์ดก่อนการพาร์สหรือแปลงสตริงเลขฐานแปด
  เพื่อหลีกเลี่ยงข้อผิดพลาดขณะรันไทม์และการจัดการอินพุตที่ไม่สอดคล้องกัน

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areOctals(array)`

พารามิเตอร์:

- `array`: ค่าที่ต้องการตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areOctals } from "@type-check/guards";

const value: unknown = ["0o123", "+0O755"];

if (Array.isArray(value) && areOctals(value)) {
  // value เป็นอาร์เรย์ที่ไม่ว่างของสตริงเลขฐานแปด
  const parsed = value.map(v => Number(v));
  console.log(parsed);
} else {
  console.log("Not an array of octal strings");
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areOctals(array)`
