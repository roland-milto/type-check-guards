# areSymbols

## คำอธิบาย

ตรวจสอบว่าอินพุตเป็นอาร์เรย์ที่มีข้อมูลและองค์ประกอบทั้งหมดเป็นสัญลักษณ์หรือไม่ โดยคืนค่า `true` หรือ `false`

### กรณีการใช้งาน

ตรวจสอบว่าฟิลด์การกำหนดค่า (เช่น รายการคีย์ที่ไม่ซ้ำซึ่งแทนด้วยสัญลักษณ์)
เป็นอาร์เรย์ที่ไม่ว่างและมีเฉพาะสัญลักษณ์เท่านั้น ก่อนนำไปใช้กับ API ที่ต้องการ `symbol[]`

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areSymbols` เพื่อตรวจสอบอินพุตที่ไม่ทราบชนิดก่อนจะปฏิบัติต่อมันเป็น `symbol[]`; ฟังก์ชันนี้จะคืนค่า `false`
> สำหรับค่าที่ไม่ใช่อาร์เรย์และอาร์เรย์ว่าง

### ข้อดี

- คืนค่า `true` เฉพาะเมื่ออินพุตเป็นอาร์เรย์ที่ไม่ว่างและทุกองค์ประกอบเป็นสัญลักษณ์ (symbol) เท่านั้น
- ป้องกันผลบวกลวงโดยปฏิเสธค่าที่ไม่ใช่อาร์เรย์และอาร์เรย์ว่างผ่านการตรวจสอบอาร์เรย์ที่มีข้อมูลภายใน
- มีประโยชน์ในฐานะตัวป้องกันชนิด (type guard) ระหว่างรันไทม์สำหรับตรวจสอบรายการที่มีแต่สัญลักษณ์ก่อนประมวลผลต่อ

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areSymbols(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบว่าองค์ประกอบเป็นสัญลักษณ์หรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areSymbols } from "@type-check/guards";

const a = [Symbol("a"), Symbol("b")];
const b = [Symbol("a"), "b"] as unknown[];

if (areSymbols(a)) {
  // a เป็นอาร์เรย์ที่มีแต่สัญลักษณ์ในขณะรันไทม์
  const first = a[0];
  console.log(typeof first); // "symbol"
}

console.log(areSymbols(b)); // false
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areSymbols(array)`
