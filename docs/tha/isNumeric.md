# isNumeric

## คำอธิบาย

`isNumeric` ใช้กำหนดว่าค่า `value` ที่ให้มาถือว่าเป็นตัวเลขหรือไม่ โดยตรวจสอบชนิดที่ถูกแก้ไขแล้วของมันเทียบกับ
`NUMERIC_TYPES`

### กรณีการใช้งาน

ใช้ `isNumeric` เพื่อตรวจสอบความถูกต้องของอินพุต (เช่น payload ของ API, ค่าจากฟอร์ม, คอนฟิกูเรชัน)
ก่อนทำการคำนวณเชิงตัวเลข และเพื่อยอมรับชนิดที่คล้ายตัวเลข (เช่น `BigInt`) อย่างสม่ำเสมอตาม `NUMERIC_TYPES`

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> `isNumeric` เป็นเพรดิเคตที่คืนค่าเป็นบูลีน;
> ให้มองว่าเป็นการตรวจสอบขณะรันไทม์ว่าค่าหนึ่งอยู่ในชุดชนิดตัวเลขที่ไลบรารีกำหนดไว้หรือไม่

### ข้อดี

- ใช้ `getTypeOf` ร่วมกับ `NUMERIC_TYPES`
  เพื่อรวมศูนย์ตรรกะการตรวจจับชนิดตัวเลขและทำให้การตรวจสอบสอดคล้องกันทั่วทั้งโค้ดเบส
- คืนค่าเป็นบูลีนแบบง่าย (`true`/`false`) เพื่อให้แตกแขนงเงื่อนไขและใช้งานแบบ guard ได้สะดวก
- รองรับรูปแบบการแทนค่าตัวเลขหลายแบบ (เช่น `number`, `BigInt`) ตามที่กำหนดโดย `NUMERIC_TYPES`

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isNumeric(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบว่าเป็นชนิดตัวเลขหรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isNumeric } from "@type-check/guards";

const inputs: unknown[] = [42, 3.14, BigInt(1000), "123", null, undefined];

for (const v of inputs) {
  if (isNumeric(v)) {
    // v ถูกพิจารณาว่าเป็นชนิดตัวเลขตามกฎชนิดข้อมูลของไลบรารี
    console.log("numeric:", v);
  } else {
    console.log("not numeric:", v);
  }
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isNumeric(value)`
