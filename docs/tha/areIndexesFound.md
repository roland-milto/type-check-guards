# areIndexesFound

## คำอธิบาย

`areIndexesFound` ตรวจสอบว่าค่าเป็นอาร์เรย์ที่ไม่ว่างซึ่งองค์ประกอบทั้งหมดเป็นดัชนีที่ถูกต้องหรือไม่ โดยจะคืนค่า `true`
หากใช่ และ `false` หากไม่ใช่

### กรณีการใช้งาน

ตรวจสอบข้อมูลที่ผู้ใช้ให้มาหรือข้อมูลภายนอก (เช่น JSON ที่ถูกพาร์ส) ซึ่งคาดว่าจะเป็นรายการของดัชนี
ก่อนนำไปใช้เพื่อเข้าถึงหรือแบ่งส่วนอาร์เรย์

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areIndexesFound` เพื่อตรวจสอบอินพุตที่ไม่ทราบชนิดก่อนจะถือว่าองค์ประกอบของมันเป็นดัชนีของอาร์เรย์ โดยมันจะคืนค่า
`false` สำหรับอาร์เรย์ว่าง และสำหรับอาร์เรย์ที่มีค่าที่ไม่ใช่ดัชนี

### ข้อดี

- มันจะคืนค่า `true` ก็ต่อเมื่ออินพุตเป็นอาร์เรย์ที่มีข้อมูล (ไม่ว่าง) และทุกองค์ประกอบเป็นดัชนีที่ถูกต้อง
- ล้มเหลวอย่างรวดเร็ว: คืนค่า `false` ทันทีที่พบองค์ประกอบที่ไม่ใช่ดัชนี
- มีประโยชน์ในการใช้เป็นตัวป้องกันก่อนนำค่าไปใช้เป็นตำแหน่งหรือออฟเซ็ตของอาร์เรย์

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areIndexesFound(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบว่าเป็นไปตามเงื่อนไขของดัชนีหรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areIndexesFound } from "@type-check/guards";

const a: unknown[] = [0, 1, 2];
const b: unknown[] = [0, "a", 2];
const c: unknown[] = [];

console.log(areIndexesFound(a)); // true
console.log(areIndexesFound(b)); // false
console.log(areIndexesFound(c)); // false

if (areIndexesFound(a)) {
  // ที่นี่ `a` ได้รับการยืนยันว่าเป็นอาร์เรย์ของดัชนีที่มีการเติมค่าแล้ว
  const firstIndex = a[0];
  console.log(firstIndex);
}
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areIndexesFound(array)`
