# isTrue

## คำอธิบาย

`isTrue` ใช้กำหนดว่าค่าที่ให้มานั้นเท่ากับ `true` แบบเข้มงวดหรือไม่.

### กรณีการใช้งาน

ใช้ `isTrue` เพื่อยืนยันความถูกต้องของแฟล็ก การสลับเปิด/ปิดฟีเจอร์ (feature toggles)
หรือค่าคอนฟิกที่ควรยอมรับเฉพาะลิเทอรัล `true` และต้องถือว่าทุกอย่างอื่นเป็น `false`.

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isTrue` เมื่อคุณต้องการยอมรับเฉพาะลิเทอรัลบูลีน `true` เท่านั้น ไม่ใช่แค่ค่าที่เป็น truthy.

### ข้อดี

- ให้การตรวจสอบแบบเข้มงวดสำหรับลิเทอรัลบูลีน `true` (ไม่มีการแปลงชนิดโดยปริยาย).
- ช่วยแยก `true` ออกจากค่าที่เป็น truthy เช่น `1`, `"true"`, หรือ `{}`.
- พฤติกรรมเรียบง่าย คาดเดาได้ เหมาะสำหรับ guard และกระบวนการตรวจสอบความถูกต้อง (validation pipelines).

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isTrue(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบ.

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isTrue } from "@type-check/guards";

const a = isTrue(true);      // จริง
const b = isTrue(1);         // เท็จ
const c = isTrue("true");   // เท็จ

if (isTrue(a)) {
  // ที่นี่ a เป็นจริง
}
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isTrue(value)`
