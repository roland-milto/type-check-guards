# areDecimals

## คำอธิบาย

ตรวจสอบว่าองค์ประกอบทั้งหมดในอาร์เรย์เป็นตัวเลขทศนิยมและอาร์เรย์มีข้อมูล โดยคืนค่า `true` หรือ `false`

### กรณีการใช้งาน

ตรวจสอบรายการที่ผู้ใช้ให้มา (เช่น คอลัมน์ CSV หรืออินพุตจากฟอร์ม)
เพื่อให้แน่ใจว่าอาร์เรย์ไม่ว่างและทุกค่าที่ป้อนเป็นค่าทศนิยมก่อนทำการแปลงหรือคำนวณ

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areDecimals` เมื่อคุณต้องการการตรวจสอบแบบบูลีนอย่างรวดเร็วว่า `unknown[]` ไม่ว่างและทุกองค์ประกอบเป็นรูปแบบทศนิยม

### ข้อดี

- รับประกันว่าอินพุตเป็นอาร์เรย์ที่มีข้อมูลก่อนตรวจสอบรายการ ช่วยป้องกันการยอมรับรายการว่างโดยไม่ตั้งใจ
- ตรวจสอบทุกองค์ประกอบด้วย `isDecimal` ดังนั้นค่าที่ปะปนหรือไม่ถูกต้องจะทำให้ได้ผลลัพธ์เป็น `false` ทันที
- ให้ผลลัพธ์แบบบูลีนที่เรียบง่าย (`true`/`false`) เหมาะสำหรับ guard และโฟลว์การตรวจสอบแบบคืนค่าก่อน (early-return)

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areDecimals(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areDecimals } from "@type-check/guards";

const a: unknown[] = ["1.0", "2.5", "3.14"];
const b: unknown[] = ["1.0", "abc", "3.14"];
const c: unknown[] = [];

console.log(areDecimals(a)); // จริง
console.log(areDecimals(b)); // เท็จ
console.log(areDecimals(c)); // เท็จ
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areDecimals(array)`
