# areJson

## คำอธิบาย

ตรวจสอบว่าองค์ประกอบทั้งหมดของอาร์เรย์เป็นสตริง JSON หรือไม่ โดยจะคืนค่า `true`
ก็ต่อเมื่ออาร์เรย์มีข้อมูลและทุกรายการเป็น JSON ที่ถูกต้อง; มิฉะนั้นจะคืนค่า `false`

### กรณีการใช้งาน

ตรวจสอบความถูกต้องของข้อมูลที่เข้ามา (เช่น จากพารามิเตอร์ของคิวรี ตัวแปรสภาพแวดล้อม หรือ API ภายนอก)
เมื่อคุณคาดหวังอาร์เรย์ของสตริงที่เข้ารหัสเป็น JSON และต้องการปฏิเสธอาร์เรย์ว่างหรือรายการใด ๆ ที่ไม่ใช่ JSON

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `areJson` เมื่อคุณต้องตรวจสอบว่า `unknown[]` มีเฉพาะสตริง JSON เท่านั้นก่อนทำการพาร์ส (เช่น ด้วย `JSON.parse`)

### ข้อดี

- คืนค่า `true` เฉพาะเมื่อทุกองค์ประกอบเป็นสตริง JSON ที่ถูกต้องเท่านั้น; มิฉะนั้นจะคืนค่า `false`
- ล้มเหลวอย่างรวดเร็ว: หยุดตรวจสอบทันทีที่พบองค์ประกอบที่ไม่ใช่ JSON
- ปฏิเสธอาร์เรย์ว่างตามการออกแบบ โดยคืนค่า `false` สำหรับอินพุตที่ไม่มีข้อมูล

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `areJson(array)`

พารามิเตอร์:

- `array`: อาร์เรย์ที่จะตรวจสอบว่าองค์ประกอบเป็นสตริง JSON หรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { areJson } from "@type-check/guards";

const ok = areJson(["{\"a\":1}", "{\"b\":2}"]); // จริง
const mixed = areJson(["{\"a\":1}", 123 as unknown]); // เท็จ
const empty = areJson([]); // เท็จ

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.areJson(array)`
