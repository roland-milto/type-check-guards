# isDecimal

## คำอธิบาย

`isDecimal` ตรวจสอบว่าค่าเป็นการแทนค่าแบบสตริงของจำนวนทศนิยมหรือไม่ โดยไม่มีช่องว่างนำหน้า/ต่อท้าย
และมีรูปแบบทศนิยมที่ถูกต้อง

### กรณีการใช้งาน

ตรวจสอบฟิลด์ของฟอร์ม เพย์โหลดของ API หรือค่าคอนฟิกที่ต้องระบุเป็นสตริงทศนิยม (อาจมีเครื่องหมายบวก/ลบ)
โดยไม่มีช่องว่างล้อมรอบ ก่อนทำการพาร์สหรือจัดเก็บ

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isDecimal` เพื่อตรวจสอบอินพุตของผู้ใช้ก่อนแปลงค่า (เช่น ด้วย `Number(value)`)
> โดยเฉพาะเมื่อจำเป็นต้องปฏิเสธช่องว่าง

### ข้อดี

- ตรวจสอบอย่างเข้มงวดว่าอินพุตเป็นสตริงและตรงกับรูปแบบลิเทอรัลทศนิยม
- ปฏิเสธช่องว่างนำหน้าและต่อท้าย (รวมถึงอักขระควบคุม) เพื่อหลีกเลี่ยงการแยกวิเคราะห์ที่กำกวม
- มีการตรวจสอบล่วงหน้าแบบรวดเร็ว (ตรวจชนิดและอักขระตัวแรก/ตัวสุดท้าย) ก่อนรัน regex
- คืนค่าผลลัพธ์เป็นบูลีนแบบง่าย (`true`/`false`) เหมาะสำหรับใช้เป็นการ์ดและการตรวจสอบความถูกต้องของอินพุต

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isDecimal(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบว่าอยู่ในรูปแบบสตริงทศนิยมหรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isDecimal } from "@type-check/guards";

const inputs: unknown[] = ["123.45", "0.99", "-42.0", 123.45, " 123.45", "123.45 "];

for (const v of inputs) {
  if (isDecimal(v)) {
    // v เป็นสตริงที่นี่ (ตรวจสอบความถูกต้องขณะรันไทม์แล้ว)
    console.log("decimal:", v);
  } else {
    console.log("not decimal:", v);
  }
}

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isDecimal(value)`
