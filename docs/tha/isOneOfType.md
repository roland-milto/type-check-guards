# isOneOfType

## คำอธิบาย

`isOneOfType` ใช้กำหนดว่าค่า `value` ที่กำหนดตรงกับสตริงชนิดที่ให้มาอย่างน้อยหนึ่งรายการหรือไม่ โดยจะคืนค่า `true`
หากพบรายการที่ตรงกัน และคืนค่า `false` หากไม่พบ

### กรณีการใช้งาน

ตรวจสอบความถูกต้องของข้อมูลที่ชนิดไม่ชัดเจนหรือมาจากภายนอก (เช่น JSON ที่พาร์สแล้ว, พารามิเตอร์คิวรี)
โดยอนุญาตชนิดขณะรันไทม์ที่ยอมรับได้หลายแบบ (เช่น `number` หรือ `string`) ก่อนดำเนินตรรกะเพิ่มเติม

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isOneOfType` เมื่อคุณต้องการตรวจสอบขณะรันไทม์ว่าค่าตรงกับชนิดที่อนุญาตหลายชนิดใด ๆ; ฟังก์ชันจะคืนค่า `true`
> หากมีอย่างน้อยหนึ่งชนิดที่ตรงกัน มิฉะนั้นจะคืนค่า `false`

### ข้อดี

- ตรวจสอบค่ากับชนิดที่อนุญาตหลายชนิดได้ในการเรียกครั้งเดียว โดยจะคืนค่า `true` เมื่อพบชนิดที่ตรงกันเป็นรายการแรก
- ทำงานกับอินพุตชนิด `unknown` ได้ ทำให้มีประโยชน์ที่ขอบเขตของการทำงานขณะรันไทม์ (เช่น ข้อมูลภายนอก, อินพุตผู้ใช้)
- ให้ผลลัพธ์แบบบูลีนที่เรียบง่าย (`true`/`false`) ซึ่งนำไปประกอบกับตรรกะแบบมีเงื่อนไขและการคืนค่าก่อนกำหนดได้ดี

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isOneOfType(value, types)`

พารามิเตอร์:

- `value`: ค่าที่จะตรวจสอบเทียบกับชนิดที่ระบุ
- `types`: อาร์เรย์ของสตริงชนิด (type strings) ที่แทนชนิดที่เป็นไปได้ของค่า

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isOneOfType } from "@type-check/guards";

const input: unknown = JSON.parse('{"count": 3}');

if (isOneOfType(input, ["object"])) {
  // input เป็นอ็อบเจ็กต์ขณะรันไทม์
}

console.log(isOneOfType(3, ["number", "string"])); // true
console.log(isOneOfType("hello", ["number", "boolean"])); // false

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isOneOfType(value, types)`
