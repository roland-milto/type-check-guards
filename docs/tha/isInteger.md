# isInteger

## คำอธิบาย

กำหนดว่า `value` ที่กำหนดเป็นตัวเลขจำนวนเต็มที่ปลอดภัยหรือไม่

### กรณีการใช้งาน

ตรวจสอบอินพุตที่ไม่น่าเชื่อถือ (เช่น query params, JSON payloads, environment variables)
ก่อนนำไปใช้เป็นจำนวนเต็มสำหรับดัชนีอาร์เรย์ การแบ่งหน้า ตัวนับ หรือ ID ในฐานข้อมูล

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isInteger` เพื่อตรวจสอบอินพุตที่ไม่ทราบแน่ชัดก่อนนำไปใช้เป็นจำนวนเต็มเชิงตัวเลข; ฟังก์ชันจะคืนค่า `true`
> เฉพาะสำหรับค่าที่ `typeof value === "number"` และ `Number.isSafeInteger(value)` เท่านั้น

### ข้อดี

- ตรวจสอบทั้งความถูกต้องของชนิดข้อมูลและความปลอดภัยเชิงตัวเลข: คืนค่า `true`
  เฉพาะเมื่ออินพุตเป็นตัวเลขและเป็นจำนวนเต็มที่ปลอดภัยเท่านั้น
- ป้องกันข้อผิดพลาดที่พบบ่อยจากการแปลงชนิดตัวเลขโดยอัตโนมัติ: สตริงอย่าง "5" จะคืนค่า `false` อย่างถูกต้อง
- ปฏิเสธค่าที่ไม่เป็นจำนวนเต็มและจำนวนเต็มที่ไม่ปลอดภัย ทำให้เหมาะสำหรับ ID, ตัวนับ และการทำดัชนีอาร์เรย์

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isInteger(value)`

พารามิเตอร์:

- `value`: ค่าที่ต้องการตรวจสอบว่าเป็นจำนวนเต็มหรือไม่

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isInteger } from "@type-check/guards";

const a = isInteger(5);      // จริง
const b = isInteger(-100);   // จริง
const c = isInteger("5");    // เท็จ
const d = isInteger(5.5);    // เท็จ
const e = isInteger(null);   // เท็จ

```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isInteger(value)`
