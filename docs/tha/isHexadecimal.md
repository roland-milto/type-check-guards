# isHexadecimal

## คำอธิบาย

`isHexadecimal` ตรวจสอบว่าค่าที่กำหนดเป็นลิเทอรัลสตริงเลขฐานสิบหกที่ต้องมีคำนำหน้า `0x`/`0X` หรือไม่

### กรณีการใช้งาน

ใช้ `isHexadecimal` เพื่อตรวจสอบค่าคอนฟิก ฟิลด์ในเพย์โหลดของ API หรืออาร์กิวเมนต์ของ CLI
ที่ต้องระบุเป็นลิเทอรัลสตริงเลขฐานสิบหก (เช่น IDs, masks หรือ addresses) และต้องไม่มีช่องว่างล้อมรอบ

> **หมายเหตุสำหรับผู้ใช้ TypeScript:**
>
> ใช้ `isHexadecimal`
> เมื่อคุณต้องตรวจสอบอินพุตของผู้ใช้หรือข้อมูลที่ถูกซีเรียลไลซ์ว่าเป็นสตริงลิเทอรัลเลขฐานสิบหกแบบเข้มงวด (รวมคำนำหน้า
`0x`/`0X`) ก่อนทำการพาร์สหรือแปลงค่า

### ข้อดี

- ตรวจสอบว่าค่าเป็นสตริงและตรงตามรูปแบบลิเทอรัลเลขฐานสิบหกแบบเข้มงวด (ต้องมีคำนำหน้า `0x`/`0X`).
- ปฏิเสธสตริงที่มีช่องว่างนำหน้าหรือท้าย ช่วยหลีกเลี่ยงการยอมรับอินพุตที่ถูกเติมช่องว่างโดยไม่ตั้งใจ
- รองรับเครื่องหมายบวก/ลบแบบเลือกได้ และไม่สนตัวพิมพ์เล็ก/ใหญ่สำหรับคำนำหน้าและตัวเลข โดยคืนค่า `true`/`false`
  อย่างคาดเดาได้

## การใช้งาน

### ไวยากรณ์

ฟังก์ชัน:

- `isHexadecimal(value)`

พารามิเตอร์:

- `value`: ค่าที่จะตรวจสอบ

### นำเข้าฟังก์ชันแบบโลคัล

```ts
import { isHexadecimal } from "@type-check/guards";

isHexadecimal("0x1A2B"); // จริง
isHexadecimal("-0Xff"); // จริง
isHexadecimal("1A2B"); // เท็จ (ไม่มีคำนำหน้า)
isHexadecimal(" 0x1A2B"); // เท็จ (มีช่องว่างนำหน้า)
isHexadecimal(0x1a2b); // เท็จ (ไม่ใช่สตริง)
```

### นำเข้าอ็อบเจ็กต์แบบโกลบอล

หากต้องการนำเข้าฟังก์ชันเป็นเมธอดของอ็อบเจ็กต์แบบโกลบอล ให้ใช้:

```ts
import "@type-check/guards/register-global-object.mjs";
```

จากนั้นเมธอดต่อไปนี้จะพร้อมใช้งานแบบโกลบอล:

- `Type.isHexadecimal(value)`
